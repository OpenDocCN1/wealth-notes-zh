# 表2 手工刨加工的弊病及排除方法

| 弊病 | 外观 | 原因 | 排除方法 |
|---|---|---|---|
| 锉  满 | 木料表面光亮处有连续性纹状，或刨时刀半 | 1. 锉嘴口太宽 2. 锉齿与刨刀刃口太远 3. 刨刀出铁部分太大 4. 逆纹刨削 | 1. 在锉嘴口前加盖木条或金属片，减小锉嘴口的距离 2. 减小锉齿至刨刀的距离 3. 调整刨刀出铁的长度 4. 顺纹刨削 |
| 不松紧 木料 | 刨刀切不进木料 | 1. 刨底起翘 2. 刨底前高后低 3. 刨角不符合造 | 1. 整平刨底 2. 将刨底前高后低处用砂纸整平 3. 调整刨角角度，若刨终料切削角大时，可用砂纸将刨刀高角增大切削角 |
| 刨削费力 |  | 1. 锉嘴紧力大 2. 刨刀太慢 3. 贴身角度不正确 | 1. 涂油润滑 2. 及时清理刨刀 3. 操作时应顺纹使用 |
| 塞刨花 | 刨花堵塞刨刀与刨底，刨盖之内的缝隙中或靠近刨花出口 | 1. 刨刀与刨底配合不严 2. 刨刀与座盖不吻合 3. 刨花出口不光滑或太小 | 1. 轻微调节刨刀的松紧（即不要紧夹刨刀） 2. 重新研磨刨座 3. 用锉等修光刨花出口 |
| 刨痕 | 木料表面有条形纹路 | 刨刀有缺口 | 1. 重新研磨刨刀 2. 检查材料表面是否有砂粒、钉子等并及时清除 |
| 夹紧有规则的波纹现象，刨削时“尖”、“实”发响 | 刨刀与刨底不严密配合 |  | 用锉修整刨底板，使之紧密配合 |
|  | 刨刀没夹紧 |  | 旋紧刨柄，拧紧刨刀 |
| 凸字状很痕 | 刨中间凸太凹；使刨刀口端太凸 | 将石笔修整平直，重新刨削刨刀 |
| 刨削刀刃侧有明显的条形痕 | 刨刀磨太直 | 重新研磨刨刀，使刨刀中间凸起
