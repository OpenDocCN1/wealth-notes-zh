# 显象管使用寿命。

7. 彩色电视接收机，使用交流磁压器调谐器时，应把电视机离开这些强磁场部位。比1米以上，否则会影响彩色清晰，造成显彩色故障。收看彩色节目时会显色偏，收看彩色节目时会有彩色污染。

8. 防潮、散热、防尘：潮湿天气应多开机工作，防止电视机受潮使元件受变质或霉断。温度太高也会损坏元件，机器外壳散热孔应畅通，有保护木箱的也应适当撤木箱的散热问题。除尘时应用较长毛刷或吸尘器，注意不要损坏元件。

9. 观看电视时注意不要把所有的灯都关掉，以免太暗损伤眼睛，预防视力衰退。照与荧光屏的距离一般不小于荧光屏对角线的5倍。

10. 保护显像管。电视机接收到的图象信息，是由显像管显现在它的荧光屏上。显像管是一个密封的玻璃泡，其表面是坚硬的，如果碰会发生爆炸，造成事故。因此，电视机应安置在稳固的地方，移动时不要摇着箱布卷动。显像管受震会冷凝热也会震坏，应注意防震。为延长寿命最好使用零性， 应避免长期直射时，观看时不要长时间过大。 使用中如发现荧光屏上有一垂直（或水平）亮带，应立即将亮度关小，并关机检查，否则会烧坏显像管。另外，电视不必，开关机次数频繁。开机又马上关机等，都不要经常长期的使用为念。

11. 非维修人员不要打开电视机后盖，机内有上万伏高压，小心触电。

# 机内天线的应用

一般电视机都配有机内家用天线（拉杆天线）。在市内收看电视节目时，电视信号很弱（在100毫伏/米以上），只要用机内收音电视就清楚很好。用时，只要把天线从套筒内拉出，朝向信号塔方向即可。用双拉杆天线时，要把两根天线调整成90°角，并使天线的平面对准电视台。如果效果不佳，可以试改套筒天线长度，方向或夹角（指两根天线）的方式，以改善电视机，频率越高，则天线越短。天线应时整趋翘时，也可以改变电视机安装地方，一个故障总到调整效果。如效果还不理想，而电视台播出的质量又很好的，就必须使用外接天线。
