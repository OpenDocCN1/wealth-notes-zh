# 自行车修理一般知识

车胎检查与车泵调查

内胎检查，首先检查气门芯是否破损，将下方气门大取，取出气门针，查看皮膜有否发皱或破裂，就拆卸气门芯，将气门针点水，再将新气门芯装到阀体四处再把气门芯底部轻轻，使充气轻便，然后把气门针针插入门，针尖气门大时进气，如果迟滞气，就要把内胎放下，充气后放在水里检查有无漏气，顺上一小竹签或火柴杆，然后放气，用挤垫捣被刺孔阻塞净，清净干净清除胶屑，再用一块大边中的白内绒，继毛用胶打四周边进清热制面，成圆形，然后在两处用手将垫烧棉水洗同上（溶剂为灶，不能过硬），随后干后将补粘皮对内贴破孔处用力压平，使其密贴合或用木锤轻敲，但不要立刻紧用胶水。如发现气门阻与内贴结合处漏气，先将气门阻六角母拧紧，如仍无效，需换垫打孔。

车圈调整，由于安装与使用过程中的。车轮松力不均，或意外碰创起变形。如作车置调整，可以把车轮放平，用车条板手在车上松紧圈节，假如变形较大，必需调整车条松紧条反位力来校正校平。ár 将车轮校正后，用双手把握前或后轮把车轴左右回位，而车轮恢复正常原位。
