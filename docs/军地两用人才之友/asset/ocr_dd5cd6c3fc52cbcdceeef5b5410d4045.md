# 收音机

# 收音机的选择

有关收音机的一些基本概念
收音机能接收广播电台发出的无线电波，并还原出声音。
由于广播电台发射的无线电波的频率不同，有的频率很低，波长很长，称为短波；有的频率不高，波长较长，称为中波。
我国规定用于中波广播的频率范围是535～1605 KHz，短波广播的频率是3.5 MHz～18 MHz。

有收音机能接收到远距离电台的微波电台的广播，有收音机只能接收本地或邻近电台的广播，收音机的这种接收微弱电台信号的能力称为灵敏度。灵敏度越高是衡量收音机质量的重要标准之一。

收音机接收电信号并对外，还能克服分散分离成声音信号的能力。这个称为收音机的选择性。选择性越好就越能把所收频率信号的频率分离出来。

不同收音机放出的声音大小是不相同的，发声的大小称音量。决定音量的是收音机的输出功率，每一台收音机的音量大小总是在某个范围内连续可调。 каждая收音机都具有一个确定的输出功率。

为了使收音的声音更加柔和和悦耳，在某些收音机上加入了音调控制电阻，可以调整放音时高低音声成分的比例。

收音机的分类
收音机按所用大器件的不同，分为电子管收音机和半导体收音机。
按其电路类型来分，收音机可分为高放式、再生式和超外差式三类。目前生产收音机几乎都是超外差式的，因为它具有灵敏度高、选择性好、抗干扰等优点。
按接收的波段数来分，可分为单波段（中波）、二波段（中波、短波）、三波段（中波、短波Ⅰ、短波Ⅱ）和四波段（中波、短波Ⅰ、短波Ⅱ、调频）四种。
按体积大小来分，可分为台式、便携式、袖珍式及微型机。
按整机的电气指标来分，可分为特级机、一级机、二级机、三级机、四级机。
