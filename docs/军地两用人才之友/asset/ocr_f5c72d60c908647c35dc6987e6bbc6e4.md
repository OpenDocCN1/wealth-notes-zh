以防板被湿胀。裁好后的拼板四周要做成一定的斜度，使边缘厚度小于槽宽，以便于装配。

# 安装

安装也称装配，是将整修好的工作件拼为一个整体最后成型，它不仅包括装配，还要将一些附件（如抽屉、橱门等）用五金件装上好，以及整修修饰面等。由于工作内容多，技术难度大，因而是木工最关键的一个工序。另外，一些半成品的质量问题或造成返工等差等情况都会在这个工序出， These 就会... 这就要求要做得流畅合理。

安装前将所有工作件找齐，并将工作件的榫、眼进行核对并作上标记分大致分组，以便安装时挑选，款者往往按这种有序的堆会工作，但在装配时手忙脚乱，甚或造成返工。

安装程序有很大的灵活性，要视不同的制品、不同的结构而定。以一组椅为例，基本上是按下面顺序：
细木框——组装框——（台面）（或桌门等）——橱门制做——轴
腮制做——打槽板、等——安装橱门、抽屉——修整。

# 防止木制品变形的 方法

木材的变形或木材本身来说是不可避免的，如其翘胀、干缩、翘曲等，但是只要采取合理的措施是完全可以牵制和避免的。

今起时制作组合板时，构木板胶合一定要在一定的尺寸范围内，再将成型板进行向前或向后（钟形摆放一段）。如图16所示的板假如相反的方向放裁，因其反翘的方向不同，能互相抵消一部分应力，再加上定的粘结力就能减少或避免翘曲。当木板过宽时，应该板宽限定在一定的范围。板厚在25毫米以下，板宽在80—120毫米之间较好，板子过宽时应当改变使用。
