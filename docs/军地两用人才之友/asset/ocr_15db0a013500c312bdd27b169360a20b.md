# 夜间进攻战斗中的战士

战士在夜间进攻战斗中，应发挥灵活机动、孤胆战斗的精神，秘密迅速地接近敌人，突然勇猛地冲上去，以匕首刺击、手榴弹、刺刀、爆炸磁雷封杀消灭敌人和步兵。

# 秘密迅速接近敌人

战士接受任务后，应秘密迅速地做好战斗准备。记住班（组）和自己的任务及信号（记）号，严密伪装，选择好武器、弹药和反坦克器材。

+   一、进攻方法与要点。夜间接战，战士应根据敌情、地形、任务和能见度等情况，正确地掌握前进时机，利用有利地形，灵活地运用各种姿势前进。在前进中，应保持方向，严守行动纪律，不时观察紧（组）长的指挥。秘密迅速接近敌人。
二、情况处置。避截照明时，如地形简陋，应迅速采取低姿匍匐前进，地形开阔，应立即卧倒，卧倒时不要发出声响，卧倒后不要随意移动身体，并利用照明弹照明姿势，地形、前进道路、照明一过，迅速前进。如跌不照明，且地形不利，应按班（组）长命令，采取适当姿势迅速接近。
当敌使用夜视器材时，应充分利用地形物，选择沟渠、土坑和坑凹地等隐蔽处，隐蔽迅速地前进。
发现敌侦察、警戒时，应立即报告，并根据情况迅速撤离地线，或秘密将其制服、消灭。情况紧急时，也可根据班（组）长的命令用火力消灭之。
避截射击时，应沉着冷静，判明情况，若发现自目射击，应避开其射向，藏进掩蔽物处；如被敌发现，应根据班（组）长的命令，在我火力掩护下，利用地形地物，采取迂回迂势，迅速接近敌人。
