# 头部部份的包扎

头部部份的伤处比较压重和多见的损伤。头部血管非常丰富，而且在头部保护着脑、眼和内耳等重要器官。在战场上的急救，主要是在保持呼吸道通畅、止血和暂除防感染。急救时应注意：

+   （1）保护呼吸道通畅，清切口腔异物，将伤员衣服解开，采取侧卧或俯卧使伤员侧卧，这样能防止呕吐物的吸入。头部放在垫高枕头上，两侧用衣服垫塞固定，防止后送时颠簸晃动。

+   （2）妥善包扎和止血。遇有一般出血，将伤组织压住后，加以包扎即可止血。大血管出血，可用指压止血法或用绷夹夹板，或用对侧上肢包扎，施行单面加压包扎止血。颈部伤不能用环形包扎止血，以免发生窒息。如有脑膜破裂，不要塞进伤口去，应立即用消毒纱布作垫护包扎。或用干净小毛巾压住，然后包扎。包扎时不可用力过重，以免组织坏死。如果出血，可选用加压包扎（图十四）。
