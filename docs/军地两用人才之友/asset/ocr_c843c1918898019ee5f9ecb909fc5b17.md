保持菜肴的鲜味，原料经过挂糊后，不直接与油接触，油不易浸到原料内部，而原料内部的汁液、鲜味也较少外流，因此，能保持原
料的原味，同时，糊经过油炸后即变香脆，使菜肴达到外焦里嫩，增加滋味。

保持菜肴的形状，有<|message|> 原料切成薄片、细丝等形状，加热时容易碎烂破坏，也容易在翻炒干燥，改变原形。经挂糊后，就能保持菜肴的形状完整和美观。

# （2）锅熊的种类和制作方法  制作锅熊的主要原料有鸡蛋、淀粉、面粉，淀粉和面包糠。一般常用的锅熊有以下几种：

+   - 蛋清糊（又称蛋白糊）：是用蛋清和淀粉调制而成。原料经挂糊烹调后，使菜肴呈洁白清润。主要用于熘、炒、滚等。
- 蛋黄糊（又称全清糊）：是用鸡蛋和淀粉调制而成。原料经挂糊烹调后，使菜肴呈金黄色。多用于炸、溜、煨等。
- 蛋清糊（又称雪白糊）：是把蛋清打成泡沫，再加入干淀粉调匀而成。经常调制，使菜肴色如白雪。多用于坍和制作菜<|start|>类菜肴。
- 水淀粉（又称干菜糊）：是用淀粉和水调制而成。经常调后，菜肴呈乳白色，极清香。多用于生炒、干炒和滚等。
- 麦淀粉（又称粉糊）：是用面粉、淀粉和水调制而成。经烹调后，菜肴呈淡黄色，外香酥，内软嫩。多用于炸的菜肴。

把蛋清糊是把原料先沾上面粉，再蘸鸡蛋糊，经烹调后，菜肴呈金黄、味脆烂，多用于干菜、锅贴等。
把蛋面包糊，是把原料先蘸上鸡蛋糊然后再沾上面包糠。经烹调后，菜肴呈深黄色，并带有粒屑，香脆可口。多用于炸牛排、炸猪排等。

掺入菜肴汤汁中，使菜肴汤汁浓稠，或在菜肴烹调完毕后，将芡
