+   （1）新车“磨合”終了，应当时行检验、清洗化油器、油阀、更换曲轴箱机油。
（2）需活塞环、活塞环、槽、汽缸盖垫垫、汽缸各孔位、消音器排气管紧夹等。
（3）擦洗各轴轮、轴、轴承并加润滑油。

# 常见故障识别与排除

发动机是两轮车的动力装置，出现故障就不能运转，失去作用，所以需要不断实践、总结经验，增加识别能力，及时予以预防与维修，使之正常工作。发动机故障多出在油、气、火等方面，所以要求燃料配合好，润滑油选、混合气适当，雾化好，点火提前、电流压力，不高就出问题，起动困难不过气顺畅，运转不均，断火、熄火，动力不足等现象，还有其他机械作用故障，多是配套与操作不当，常见故障及排除方法如下：

+   不能起动
1. 先检查油箱是否有油，拔下油管看油是否畅通，再按下浮子下沉箱，取出针刺体检查，提进油后再起动试车。
2. 取出火花塞是否有油浸湿注意旷起动多现象，如果没有，把火花塞放在汽缸座上，转动磁钢飞轮，检查火花，如火花微弱，多是白金触点或火花塞电极间隙过大，电容器电极或高压线圈漏电、短路，如果没有电火花，多是磁钢或接触点松脱，还有高压线圈断路，调整或更换零件后，按规定操作，排除。
3. 火花正常、排气管有放炮，点火不准或是、过迟或混合气过浓，起动困难且不能起动。
4. 压缩不足。活塞环磨损、断裂、粘结，汽缸垫片漏气，也会导致起动困难且不能起动。
5. 汽缸过热：曲轴油封损坏、咬痕，需时要更换零件，清除积炭。
6. 行车起浓烟火、低速正常：多是白金或火花塞间隙过大，发火架弹簧过硬，给以调整更换即可。
7. 行车起浓火、高进正常：发火架弹簧过硬，白金间隙或火花塞间隙过小。
