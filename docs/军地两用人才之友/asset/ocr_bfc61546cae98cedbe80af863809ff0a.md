# 计算器的类型与用途

电子计算器按其用途，可分为以下五种类型：
1. 一般型；一般型电子计算器又称普通型电子计算器，其英文品名 为ELECTRONIC CALCULATOR。这一类计算器的显示位数字为八位，没有一个存储器。它具有四则混合运算、存储运算、常数运算以及百分数、平方、正弦数学指数、开平方、倒数等计算功能。有的计算器还设有正负变换键 ± 和周年率键 。
东舶型电子计算器有很多卖家，常的有CASIO牌ML—720，ML—831，ML—840和ML—860型等。
上述计算器适用于供 Na、营业、财务、仓库、计划、劳工等各行企业及个人家庭日常使用。

2. 高级型：函数型电子计算器又称工程型电子计算器或科学型电子计算器，其英文名为SCIENTIFIC CALCULATOR。这一类计算器的显示位数以八位和十位数多，有一个或多个存储器。
