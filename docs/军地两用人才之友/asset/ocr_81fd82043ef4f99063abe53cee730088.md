# 单斜面立窗温室

单斜面立窗温室是在单斜面温室的一面坡玻璃下，支起60厘米高的地窗（见图4），使玻璃倾前面稍抬高，方便管理，增加了前沿土地利用率，消灭了温室中的低温死角。立窗角度在80～90度之间，故玻璃倾角做为30度以下。这样温室的优点是早春光充足，后期温室的温度较大一面窗室较低。通风，保温容易控制，最低温能保持在10℃左右，最高温可达30℃。这种温室用两个炉子取暖，属于中温温室型。主要用于春季生产瓜类或育苗。

# 双斜面温室

双斜面温室也叫欧良式温室。南面的一面玻璃屋面为双向斜面，下坡玻璃屋面倾角45度，上坡玻璃屋面倾角26度，由于上坡屋面倾角偏小，温室内中午温度较高，炎热温室难散，通风散热易，但保温效果较差，属于中温温室型。适于栽培番茄或育苗（见图5）。
