# 预警飞机

预警飞机是美国一种裝有高效能电子探測和通信设备的波音707喷气式飞机。这类飞机把空中管制与空中指挥两种职能集中在一起，既能实施电子侦察，又能进行空中指挥，所以也叫做“机载预警与控制系统飞机”。 预警飞机具有性能良好的雷达、电子对抗系统、通信系统、导航系统、数据处理计算机系统、电子干扰及反敌武器装备。飞机能一系统论证中确定出战斗飞机的飞行、举例的航行或部队运动的信号，能发现一般雷达不易发现的低空飞机，可同时识别同一地区的敌机与友机，并发出时间和位置给战斗机实施预警指挥、它能提供情报、观察担负、卡车等运动目标、提供早期警报、获取敌人地面部队方向等。它还能与飞机、军舰及地面各据点指挥所以至白营进行通信联系，指挥飞机、军舰进行空中或海上的战斗。根据飞机高度的不同，它可监视25萬里至350万里地面内的敌情。能以八百多公里的时速，持续飞行11个小时。
