# 良种繁育

良种繁育的任务是为大面积生产提供优良纯净的种子，并通过良好的栽培技术，不断提高良种园良种的优良特性。因此必须认真搞好“种子生产专业化、种子加工机械化、种子质量标准化、品种布局区域化和以县为单位供种”的“四化一供”，以适应农业现代化所需。

种子田是繁育良种、统一收获种子的田和种子田两种。
一级种子田 是用繁殖优良纯系选出较好的单株或株组，混合假种为种子田的种子，在种子田里再选出下一年种子田的种子，其余去杂去劣，供大田使用(见图2)。繁育系数高的物种类于零采用这种方法。
