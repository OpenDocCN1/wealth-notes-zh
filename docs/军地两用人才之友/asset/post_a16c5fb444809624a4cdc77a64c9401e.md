# 合理施肥

合理施肥，充分发挥肥料的增产作用，是实现高产、稳产、低成本的一个重要措施。

一、合理配施、互补促进 有机肥料和化肥配合，氮、磷配合，是合理施肥的重要原则。有机肥料营养齐全，肥效慢；化肥肥力见效快，特别是化学肥料中含有大量的有机质，微量生物作用，形成腐殖酸，能改变土壤结构，使其疏松绵软、透气良好，这不仅有利于作物根系生长发育，而且有助于提高土壤保水、保肥能力。化肥可以供给微生物活动最需要的速效养分，加速微生物繁殖和活动，促进有机肥料分解，释放出大量的二氧化碳和其他养分，这就利于土壤中难溶性养分的分解。因此有机肥料和化肥配合使用，能取长补短，互相调剂，充分发挥这两种肥料的作用。

有机肥料一般较少磷多，和氮肥配合一般有良好反应，和磷肥配合

合，或霉影响腐皮效果。施土氮肥刺激根瘤，有机肥用量又少，可以施用少量磷肥外，一依般情况下，有机肥和磷肥最好分别施在不同田块，以充分发挥肥料的作用。

磷肥若经长的后效，不须每年作作物都施。应重点施在较高梨茎口上。例如，小麦和玉米、谷子等作前地施。磷肥应施在小麦、玉米、谷子利用其后效；小麦（或油菜）和水稻轮作地区，磷肥应施在小麦（或油菜）上，水稻利用其后效。磷肥和双料轮作时，磷肥要施后迟施肥，以缓解增酸，早、晚稻利用其后效。

二、根据多年作物后效果差异，合理用肥作物的不同，对养分需要的种类、品种、数量指标亦不相同。

首先，要养作物合适的肥料品种，小麦、玉米、水稻、玉米、高梁、粟子、谷子等，需氮较多，磷酸。钾肥较少。应以施用氮肥为主，供应条件，配合磷、钾肥。豆科作物常有根瘤菌固氮，但需较多的磷、钾、葵花、烟草、麻、甘蔗、甜菜等，号称“喜钾作物”，在缺钾的土层上要特别注意钾肥利用。

其次，要养作物的配置是。玉米、高梁等作物生育期短，需肥量大，应施肥位置当高施以不含谷类作物。小麦养分较娇，氮肥用量过高，容易引起倒伏，损害其经济价值。河南农业大学肥料多点试验，以每亩20斤尿素增产显著，经放牧效果也较差。

三、合理施肥，这就体现一种方法。基肥、种肥和追肥是施肥的三大环节，有机肥和磷肥施作基肥；钾肥作种肥或兼作；钾肥作追肥等。结合起来，掌握光照规律，充分发挥肥料的作用。

根据农业大学试验组试验，小麦一般大田氮肥的关键时期是苗期，苗期施氮可以促进分蘖分蘖，为丰产奠定基础。因此同样数量的氮肥以前追（重施早春和全苗期）效果好。玉米穗口期同样数量的氮，追施氮肥可使植大，粒多、粒重。同样数量的氮肥，以分成四份，种肥每亩各用一份；即乱肥配用2份，增产效果最好。又据全国各地经验，早稻一般施肥期、施肥期、施肥期、前、中、后左右。施肥除重视分蘖期外，还要注意壮秆肥。棉花配施氮肥、稻施肥、重施花铃肥。谷子要重施拔节肥、孕穗肥。总之要根据具体情况，认真实践，摸索出当地作物的施肥高效率。

深施肥时，保肥效果“肥料越进土，一亩顶二亩”。肥料深施，能减少损失，提高肥效。

农家肥深施，肥料分布整个耕层，便于作物吸收，减少蒸发分解损失，并提土温施肥。增产力大。

所以，农肥深施，有的地方学校土层较肥厚，万斤土营作肥层深6~7寸，平均每亩土增产小麦10.7斤；浅施2~3寸，只增产3.6斤。

磷肥提效，营养保留在有效磷含量较低的表层内，而有胶质含量低的下层土壤则反而得不到磷酸。作物只能在苗期从表层土壤中吸收磷肥，根系伸长以后就难以吸收利用。深施，有效磷含量低的下层土壤也能得到较多的磷酸，从而提高养分。实地发现增产。有的农家土层肥效较差，30斤硫酸铵施在5~6寸土层内，每亩稻肥增产小麦6.7斤；浅施在表层内，仅增产3.13斤。

经试验尤为显著 肥料和氮气，容量易挥发损失，严重影响。

其它氮肥品种，也应深施。深施可使氮肥紧贴根系，防止挥发；铵可被土壤吸附，状态也很少；肥料分布在根系附近，便于作物吸收。稻田深施，可使铵态氮处于缺氧环境，防止生成硝酸而淋失，或变成氨气挥发。

氮肥深施可采取以下方法：

（一）基肥深施。硫酸铵或碳酸铵可作基肥施用。旱地将含钾肥料顺沟平铺，或挑进浅沟，稻田在秧田、旱地、等处，施后即用锄细搅匀，至于填埋，以后还要...

（二）种肥深施。小麦、玉米、谷子等作物，在墒情较好的情况下，播前开沟或用简易农具集中条施在种子下面或种子下方，使种子邻近吸收。

（三）秧肥深施。把硫酸铵蔡和干细土（按需要可加磷肥）混合，用造粒机于压成颗粒，或将硫酸铵直接压制成颗粒，然后深施。各地试验，效果显著。肥料中，肥效较长，不适于水田或旱地，不利于作物作好相应增产。球肥肥效较缓，宜注意早施，并且要制造、随装、随用，不宜久存。

（四）追肥沟施穴施。对小麦、谷子、玉米、棉花等追施硫酸铵、氨水和原尿，应疏松或穴施后覆土。要紧贴各种植机具，把氮肥施入3寸以下土层中。

# 农药

## 农药的概念及分类

农药主要用于防治危害农林作物及其产品的害虫、螨类、病菌、线虫、杂草、鼠类以及调节植物生长的化学药物。

农药的种类很多，一般按下述几种方法进行分类：

1. 按农药的防治对象和用途可分为：
杀虫剂，用来防治有害昆虫的药物，如1605，杀虫双。
杀菌剂，用来防治作物病害的药剂，如硫酸锌、波尔多液。
除草剂，用来防治农田杂草的药剂，如草骈腈。
杀线虫剂，用来防治线虫的药剂，如磷化锌。
杀软体动物药剂，用来防治蛞牛、钉螺等有害软体动物的药物，如硝酸。
2. 按农药的原药属性和化学成份可分为：
有机农药；由人工合成的有机化合物，属有机类农药。在杀虫剂中主要有：有机杀虫剂，有机杀螨剂，有机杀虫剂，在杀菌剂中主要有：有机杀菌剂，有机杀菌剂，有机杀线虫剂，有机杀鼠剂等。

植物性农药；以植物为原料，经过加工制成的农药，如硫酸烟碱、鱼藤精等。

## 农药的剂型和规格

1. 粉剂 是原药和填料制成的细粉状混合物。粉剂的特点是使用方便，施药效率高，适宜喷雾和拌土撒施，但不能用作浸种。
2. 可湿性粉剂 由不溶于水的原药和稠性物料加入湿润剂混合制成，可悬浮于水中。可湿性粉剂主要用于喷雾和浸种。
3. 乳剂 是不能溶于水的原药加乳化剂或机油制成油状液滴，乳油一经稀释即为乳液。乳油一般可供喷雾和浸没使用，它的特点是分散性好，适宜于作物和害虫身上展着性和渗透性强。
4. 水剂 又明稀释，是可溶于水的原药不必经加工而直接制成的水剂。使用时再加水稀释，可用来喷雾、浸种。这种剂型制造简单，使用方便。
5. 颗粒剂 是原药和吸附剂（或填料）混合后制成的颗粒状物。其特点是药效期长，使用方便，对作物不易产生药害。
6. relieve 雾化剂 一般为原药，有的制成片剂，这种农药在自然条件下易挥发气化。

## 农药的施用方法

1. 喷粉 特别是工效高、不需水，其缺点是粉剂易在空中飘扬，受风的影响大，对作物和虫体的粘着性差，用药量较大，施用过多次会影响作物的光合作用。
2. 撒毒粉 粉剂或可湿性粉剂与细土拌匀，用手撒于田间。这种施肥方法不需喷雾器，工效较高，药粉不易在空中飘扬，但用手直接接触，对人不利安全。
3. 喷雾 利用喷雾器将稀释后的药液均匀地布于作物上。这种方法的优点是耗药量少，药液粘着性强，药效期长，防治效果好，但使用非机动喷雾器时，施药工效较低，在某些地方还受到水源的限制。
4. 浸透 用较多的水稀释农药，均匀地泼洒在农作物上，由于用水量多，所以可增加药液与病虫接触的机会，特别是防治钻蛀性害虫和在植茎甚至作物根的病虫效果好，但工效较低，劳动强度较大。
5. 种苗处理 用一定数量的药剂同种子均匀拌种和叫拌种，用一定浓度的药液浸种子、根苗、块茎、検苗叫浸种。它的特点是用药量很少，省工、效果好，但只能用于防治寄生于子房的病虫，地客害虫和孵苗期的病虫。
6. 烤烟 将熏蒸剂置于密闭和比较密闭的场所（如仓库、粮库、帐篷、土壤内），使其在自然条件下释放，杀死害虫。一般用于防治仓库或土壤中害虫。
7. 土壤处理和深层施药 将药剂施在土壤中或撒在田面，再行翻耕、中耕、移栽，这种方法主要用来防治线虫类的病害和地下害虫。近年来还利用某些内吸性农药深施来防治作物生长期间的害虫，这样可以降低药害的分散程度，延长药效，同时因为农药深施，农药受到直接降解的虫体，害虫因取食中毒而死亡，而取食害虫的天敌却不受损害，从而协调了化学防治与生物防治，对天敌起到保护作用。

## 农药的安全管理

大多数农药，对人畜都有一定的毒性，因此，对农药需要集中进行保管，并应放在专库或专用柜内，不能乱放。农药仓库要通风、干燥、门窗紧靠，门把要加锁，室内防鼠和防腐。农药要分类单独存放保管，严格保管各类农药的使用范围，不需要农药及其包装就废弃它。装过农药的空瓶、空袋也要妥善处理，不能拿去餐具。

根据用途时要注意操作人员的防护，不得与粮食、瓜果、蔬菜等食品和用品混装贮藏，以免发生中毒事故。
