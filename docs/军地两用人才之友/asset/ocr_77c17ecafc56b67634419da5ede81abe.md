# 装玻璃用的工具

工作台 一般是用木料制成。台面大小根据需要而定，常用的有 1×1.5米、1.2×1.5米或1.5×2米。为了保持其平面整，台面板厚 度不能薄于5毫米。裁切大块玻璃时要铺绒布，其厚度要求3毫米以 上。

+   - 或铁刀 又称金属锯条，一般分为划2～3毫米和4～6毫米厚玻璃等不同规格。

+   - 直尺、木折尺 用木料制成。直尺按其大小及用途分为：5×40毫米的，专为裁划4～6毫米厚玻璃用；12×12毫米的，专为裁划2～3毫米厚玻璃用；5×30毫米（长度1米以内）的，专为裁划装饰线条用。木折尺用象牙或塑料做。

+   - 钢丝钩 板脱玻璃用扣条系。

+   - 毛笔 裁划5毫米以上的玻璃时抹油用。

+   - 凿刀 安装玻璃时敲钉子及抠油灰用。

+   - 木枪线锤 开玻璃窗用。

+   - 刮刀 清理废土及抹油灰用。

# 裁切玻璃

要注意的要点工作 裁切时将室内和工作台打扫干净。运进的原璃 玻璃要靠墙放置，存放一面。裁切玻璃最好全都放在工作台上。经裁切 后的玻璃应整堆叠立于板条上。

常料或玻璃板方法 裁划2～3毫米厚的平板玻璃，可用12×12 毫米钢条或直尺。先采用折尺或玻璃尺定位，再在尺寸定裁玻璃时用此 尺寸，这样，要考虑第三空隙和2毫米刀口。对于北寒冷地区的 钢门窗，考虑到门窗收缩的特性，留出适当空隙更是不可忽略的。裁 划时可把直尺的一小钉紧靠着玻璃的一边，玻璃刀紧靠直尺的另一端， 一手握着小钉按住的玻璃边口使动勿动，另一手握着刀则顺向后退 划，不能有轻重弯曲。
