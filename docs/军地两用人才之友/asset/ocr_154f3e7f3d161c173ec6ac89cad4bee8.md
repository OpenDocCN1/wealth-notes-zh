# 制作沙盘

沙盘是根据地形图或实地地形，按一定的比例用泥沙等雕制的，能形象地显示实地的地形和地貌情况。侦察分队可以用以研究侦察行动方案和向首长报告侦察结果。

# 准备工作

确定沙盘比例及计算沙盘大小。根据任务的需要，先在图上标出制作沙盘的区域，再确定沙盘比例尺，然后据此算出沙盘的大小。

假定分隔仪用的尺度，其比例尺一般取大于1：500。显示地域通常采用地形图比例为一倍。应按地形图高度二倍。如图上标的区域，其须遥长度相应的实地距离为600米，沙盘比例尺为1：500，则沙盘纵边长应为1.6米。

图上作业。为便于在沙盘上较准地堆砌地形，应先在图上已标出的区域内画小方格并编号（图一）。然后用彩色铅笔在地图上标出最低的等高线，能量地绘制基本形状的等高线和制高点，并将必须显示的地物作出记号。并根据等高线和放大倍数计算出各高地的山顶、鞍部、山脚等在沙盘上的高度。
