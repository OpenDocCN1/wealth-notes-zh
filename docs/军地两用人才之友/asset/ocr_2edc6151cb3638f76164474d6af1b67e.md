单ciplina 有功电度表主要由一个可旋转的铝盘、分别绕在铁芯上的一个电压绕组以及一个电流绕组所组成。它的测量机构，主要由六个部分组成。

+   (1) 电流系，在装装的优质硅钢片上，用粗导线绕成的电流绕组组成了电流元件，用导线绕成的电压绕组组成了电压元件。

+   (2) 可动部分，在偶合或组合合金转轴上紧固定铝盘，并用上下轴承支持住，使轴与铝盘一起转动。

+   (3) 永久磁铁，永久磁铁用铝镍钴磁钢制造，并有调节磁性强弱的装置。

+   (4) 支架。由钢板冲制或用铝合金、锌合金压铸而成。

+   (5) 积算器。

+   (6) 外壳及端钮，外壳用铝板冲制或用塑料制造，底座用钢板冲成，端钮盒用酚醛粉压制。电度表的内部结构如图1。
