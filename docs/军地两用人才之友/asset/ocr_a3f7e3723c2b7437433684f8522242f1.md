样散落在爆区和下风方向的一定范围内，使地面、物体、空气受到污染染。这就是放射性沾染。故放射性沾染不可避、即不容，和放射辐射一样，能够造成放射线。人员受到一定剂量辐射后也能导致放射性。如果吸入或吞入体内，伤害作用更大。

# 核武器的杀伤力和可防性

原则上，核武器同其它武器一样，也有两重性，它们既有一定杀伤破坏作用，又有很大的局限性和可防性。只要我们掌握核爆炸四种杀伤破坏因素的特点，认真做好各方面的准备工作，核武器是可以防的。

四种杀伤破坏因素的局限性、可防性是：

+   1. 冲击波：地形条件对冲击波的杀伤破坏作用限制很大。山地能够有效地削弱冲击波，配置在背风心区和建筑的人或武器可以大大减小或避免冲击波的伤害，利用简单的工事等掩蔽、散兵坑、土墙、地窖或建筑物以冲击波的杀伤半径缩小一半到三分之二，带有转弯的窗口、效更加显著。甚至倒在开阔地上，也能大大减小冲击波的伤害。在坚型工事坑道内，即使距离很近，也能完全避免冲击波的伤害。

+   2. 光辐射：光辐射和太阳光一样是直线传播的，也容易天地方的的影响。阴雨、雾天，尤缓的云等半透明大颗粒物，一到通量光的物体会影响工事、窗口、石头、弹药等光辐射不能达到的地给出，都能减少或完全避免光辐射的伤害。白色与浅色的衣服和物体也能起一定的防护作用。

+   3. 各项条件：各种物体都能削弱贯穿辐射，有掩蔽的工事、地下室和混凝都有较好的防护作用。工事土盖加厚是最简单有效的方法。一米以上的土层就可以被贯穿辐射射分之九以上了。

+   4. 放射沾染：放射沾染布满范围和沾染程度，主要取决于爆炸方式和风速、风向、原空。空气中爆炸时，地面放射性沾染很轻微，对部队行进作战并无影响。地面爆炸时，在爆区和风向的一定范围内可能形成严重的沾染，但是沾染的程度随着时间的增长而不断减弱。一般时间每增加七倍，地面上辐射（表指示减弱单位
