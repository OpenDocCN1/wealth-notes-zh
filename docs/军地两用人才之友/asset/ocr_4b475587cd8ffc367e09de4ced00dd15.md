# 蔬菜栽培

蔬菜中含有人体生理活动所必需的维生素、矿物质盐类、碳水化合物及其它营养物质，对维持神经系统、消化器官以及分泌器官等活动有很 大的作用。这些营养物质缺乏时就会引起很多疾病，并可使生机衰退和生长发育停止。例如缺少维生素A时，幼儿生长停止，成年 人就会引起眼病。患上以及对传染病的抵抗力减弱，缺少维生素B时，就引起脚气病。缺乏和肌肉萎缩；缺少维生素C时，就会发生坏血病，牙出血或脱落，神经系统紊乱，体力和抗病能力减弱。蔬菜还含有人体生理上所需要的铁、钙、磷等矿物盐类和有助于消化的纤维素。同时蔬菜都是碱性食物，能中和中米、麦和肉类食物过程中产生的酸反应，以维持血液平衡，避免血水中中毒。此外，蔬菜还含有蛋白质、脂肪和有助于食欲的芳香物质。所以蔬菜含有多种营养物质的食物，它不能用其他的食物所代替。

# 西红柿
