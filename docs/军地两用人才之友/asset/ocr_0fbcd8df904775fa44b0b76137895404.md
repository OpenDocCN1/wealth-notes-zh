# 自行车产品质量与装配质量的鉴别

（1）产品质量长条，金属板层饱满光洁，没有剥皮脱落，露黄或黑色<|message|>，无明显抛光痕迹；镀铬部分不起泡或没有镀铬及局部焦黑或有黑色条纹，烤漆要色泽鲜亮，无砂批、流痕现象。

接头部分，除少数使用铆钉铆接外，大部分采用黄铜焊接；要求连接部都应—定尺寸并密窑衔接，焊水要饱满，焊口要平整光洁。焊接部分如圆管接头处必须正向焊接，接头要平整无歪斜，鏨光后无明显焊痕。金属管制品成型无凹陷、弯曲、锈蚀，有针对部分如车把、车架、后叉、前叉、左右臂、梁等部位左右高低应平对齐。查看车架有无裂纹或开焊地方，可用手握住梁架搭一遍，就可感觉出有无开焊痕迹。查看后—下车子三通、五通，后叉子等焊接有无开焊现象。

检查后轮车圈断口处是否齐整，如将车轮转轻，用手将车圈两边，就可感觉出有无不平滑的地方。

转动各零配件要求硬度符合运转圆顺灵敏准确，牙嵌大小角度吻合。热处理后，装的东西应力适中。表面有平滑保护，如蜂根后不发黄，防止起锈。封锁的表面要光洁，涂装少受与阻力。
