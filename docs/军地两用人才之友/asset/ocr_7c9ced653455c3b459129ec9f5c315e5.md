# 绿肥（鲜用）作物种植及施用要点

| 名 称 | 主要栽培特性及适宜地区 | 用 法 |
| --- | --- | --- |
| 草木犀 | 阳早播种，耐盐碱。适宜风沙、干旱地区种植 | 在盛花期收割，堆沤作底肥，或直接播入土中 |
| 油 莱 | 耐盐碱，耐寒 | 播前先深翻整地入土中 |
| 田 萝 | 耐盐碱，耐寒，耐瘠薄。适于盐碱地种植 | 在花前收割，堆沤作底肥，或割后扛翻入土中 |
| 皇葱概 | 耐盐碱，耐旱、耐涝。适于沟边、坡下、道路种植 | 收割后翻入田间作底肥 |
| 冬黑麦 | 播种期较早，耐盐碱。至冬25度能越冬。适于水田等潮湿地生长，注意施用底肥 | 抽穗前直接翻入土中 |
| 绿 萝 | | 水面放养，可作绿肥变饲
