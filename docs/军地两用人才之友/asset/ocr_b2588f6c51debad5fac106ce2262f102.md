# 淡水养殖

# 池塘养鱼

池塘养鱼必须抓好三件工作：养池、鱼种和饲养管理。

池塘养鱼要求水深、水宽、水活。水深2～3米，水面10亩左右为宜，水源要方便，能灌能排。池周围无咏稻场，土壤为壤土或略有淤泥的池塘比较适宜。

根据鱼种的差异，鱼食、分层生存习性和对饲料的不同，实行混养提高密度。一般以鲤鱼草、鳊、鲢鱼为主，搭配其它鱼种（如尼罗罗非鱼、日本鳃和鲍鱼等）。根据各高经济价值，要求提高单产，故养鱼种的重量和尾数也要相应增加，大体标准是：要求产量500公斤的，放养鱼种为800尾，重量170公斤；产量1000公斤，为1300～1400尾，重量280～280公斤；产量1500公斤，为2200～2500尾，重量500公斤；产量2000公斤，为3000尾，重量800公斤（指混合鱼种全养在内）。混养的比例以主体为生，如鲢鱼和鳙鱼编占60%，草鱼占30%。搭配鱼类占10%；草鱼混养草鱼占60%，鳊鱼种占30%，搭配鱼类占10%。

按鱼类生长季节和食性差异不同，合理搭配饲料，一般动物性饵料（如鱼肉及加工的下脚料、血虫、蚯蚓、泥、泥蚶、蚯蚓、小虾、腐虫、水蚤等），为养鱼的好饲料，适当多投喂一些，能使鱼体生长健壮，并能提高对饵料的利用率。植物性饵料（如包括各种水草和饲料）是草、苔、稻草等草食性鱼类的主要饲料。另处，粮作加工的副产品，如各种油柏、糠、麸、糠、渣和土杂面等粉，也是鱼类的好饲料。如将各种饲料混配成颗粒饲料，按饲料的总量加1×1.2%的硬酸钾和钙等，改善营养，增强营养吸收，要去混养水草很投资。池内如饲养小鱼种，可将粪料打成糠状沉池内。
