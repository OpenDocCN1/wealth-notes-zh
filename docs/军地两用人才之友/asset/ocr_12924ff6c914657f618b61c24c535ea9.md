# 判定方位

军队机动性大，活动地域广，经常遇到各种复杂的天候和地形条件。因此，每一个战士都应在各种地方，在暗黑的夜晚、浓密密林、沼泽沙漠和草原上都能判定自己的位置。本章介绍判定方位的方法很多，这里只介绍几个简单常用的方法。

# 用指北针判定方位
