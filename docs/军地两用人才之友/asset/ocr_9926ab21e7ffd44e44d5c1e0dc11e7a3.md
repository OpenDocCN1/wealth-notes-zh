# 续表

| 常见故障 | 原 因 | 排除及修复方法 |
|---|---|---|
| 洗衣机属配机箱下部有滴漏水现象 | 1. 洗衣机上的密封圈损坏，引起轴孔细细，大号弯轮上着漏水
2. 主轴垫筒上的大垫母未紧，连接洗衣箱底部护孔的圆圈漏水
3. 洗衣机箱底下排水接头松紧不严密，或被胶被裂，或水管脱落，造成渗漏水
4. 排水阀本体安装不严密，或其排出口与排水管相联处松脱，连接漏水
5. 洗衣机底部的水管破损开裂，向外漏水 | 1. 更换新密封圈
2. 拧主轴锁筒与轴孔的连接大螺母拧紧，并注意套肥在孔中心
3. 拧紧水接头安装严密，或更换损坏水接头、断排水管等
4. 拧紧水阀与排水管紧固件安装牢靠，或用密封胶纸、橡胶胶纸对接缝进行密封密试验
5. 对处处开裂破损进行修复补，或更换新洗衣箱 |
| 排水阀关闭不严，排水向外溢水 | 1. 排水软管堵塞太紧，排水阀闭不严严
2. 排水软管中，有杂物如毛发、小纸片、硬币等卡住，造成排水阀关闭不严 | 1. 威松排水管延长管，妥合理长化
2. 扳下排水软后，清理排水阀内的杂物，并地使排水阀关闭严密 |
| 排水管外水太多能（待水时超 2 分钟，或污水不出来 | 1. 排水阀上的控制拉带，常经长使用后控制拉带步被拉太松，不能完全松开阀门
2. 排水管弯处被物，产生压差，压现观现相内排水孔上有点物堵塞
3. 排水拉带的拉拉完全破损，造成排水阀皮只靠空间移动 | 1. 调整排水控制拉带，并按检修养例，以排水管不向外排水为原则
2. 检修排水管，避免扭曲和压死，或更换排水管，并及时清理排水孔上堵塞物
3. 更换或调整给排水拉带，与排水阀皮的联结，保证可靠牢
