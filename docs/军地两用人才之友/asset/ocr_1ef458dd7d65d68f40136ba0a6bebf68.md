# 烹调

# 食物的合理烹调

烹调目的有三，一是使食物变熟以增加食物的消化吸收率，二是增加食物的色、香、味，以提高食物的感官性状和谐进食欲；三是杀灭食物中存在的有害微生物，以保证饮食卫生。所以食物在食用前必须经过烹调处理。

但是，食物经过烹调后，可能会造成一些营养素的破坏或损失，例如，抗坏血酸（促进细间质中胶原形成的，参与体内氧化还原过程，增强肝脏的解毒能力，促进抗体形成和提高白细胞的噬菌能力，并促进人体生长发育）和硫胺素（促进人体生长发育，增加消化功能，维持正常代谢），可因高温而被破坏，水溶性维生素和无机盐，也可在烹调过程中被浸洗而损失。

1. 高温暖和烹调，某些维生素易溶于水（水溶性维生素），可因溶于水而造成损失。常见的损失有：

+   ① 用米散饭，在米中煮散米损失率可达40～60%，核黄素和尼克酸损失可达23～25%。水温水温度高，煮洗次数越多，米浸泡时间越长，维生素损失也越大。

+   ② 掉皮煮米饭，把米放在水中煮到半熟后再将米捞出蒸熟。剩下下的米汤大量丢弃。它可使硫胺素损失67%，核黄素（维持组织细胞的呼吸功能，促进人体生长发育）损失50%，尼克酸（调节代谢和维持细胞呼吸功能，是构成辅酶Ⅰ、Ⅱ的主要成分）损失78%。
