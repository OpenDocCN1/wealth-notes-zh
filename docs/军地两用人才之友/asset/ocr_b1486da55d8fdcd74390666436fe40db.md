# 图十八 三角巾下颌包扎

④ 下颌伤三角巾包扎。先把三角巾叠成四指宽带形约模放置的带状，取 1/3 处扭在下颌，两头轻轻向前上提，长头绕过头顶至对侧耳前太阳穴处，与腮下字交叉，然后向前缠绕长头相叠打结（图十八）。也可*用毛巾包扎，其方法是：把毛巾折叠成四指宽的带形，两端各系一条带子，放在额下，然后用两手把毛巾两端上提，一端是头前在对侧与另一端作十字交叉，绕颈部和枕部后，在同侧耳上前方打结（图十*九）。

⑤ 眼伤三角巾包扎。把三角巾折叠成带形四指宽，将 2/3 向下斜放于伤侧额部，从耳下绕经头后绕侧耳上前额，压住上端绕头一周打结（图二十）。
