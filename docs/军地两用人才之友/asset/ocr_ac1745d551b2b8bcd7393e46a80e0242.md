# 音 箱

音箱，是扬声器箱的简称。一般由箱体及一至多个不同尺寸的扬声器组成的。

# 音箱的 chế制

# 正确选择

容积的选择：音箱容积的大小关系到音质的优劣，必须根据扬声器的参数和运用有关公式计算出它的容积，确定它的大小，才能充分发挥扬声器放音效果。

尺寸的选择，若箱体尺寸设计不合理和外部条件过薄都会在音箱内产生驻波振动，容易使箱体共振。因此，当音箱容积确定后，要按一定比例决定音箱的长、宽、高。宽、深比例之比出现整倍数关系。合理的音箱的高、宽、深比例大致有：①7:5:3 ②7:5:2 ③1:0.6(~0.8):0.4(~0.6) ⑤5:3:2 ⑥2.5:1.4:1.1。

# 材料的选择：

木材：可用木质硬、比重大、不易变形的木头。也可选 ਕੀ七层、九层胶合板或木制制成的胶合板，但避免用有节疤、虫害和裂纹的木材。音箱的箱壁厚度要与扬声器直径成正比，或根据箱内容积适当加以选择。

上注：①箱体可用水泥、石灰按1:1比例配料，加水拌匀，浇模型，再经精磨而成。②用砖头砌成箱体表面抹以水泥，然后涂上油漆。

铸塑板：由于钢筋板能敲、刨、钉、棒、可象木材一样来制作，所制成的音箱的箱音还具有清晰高亮、层次分明等特点，是目前制作音箱的新型材料。
