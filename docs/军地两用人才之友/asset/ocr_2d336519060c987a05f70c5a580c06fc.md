# 5. 炮鸡肉

火锅可以掺入各种调料，炖煮也分多种多样。具体做法，烧鸡肉（切条片），油蛋白质，油盐花椒，芥菜（切段）；粉条、香菇（泡软）、海带（切丝）、酱油、盐、葱花、姜末、花椒大料水、煮肉汤，味精等宜适量，最好是菜酸度一样。依次把鸡肉、油豆腐、盐、葱花、姜末、花椒大料水和味精兑成汤，浇在火锅里，用木板烧开，把煮菜热烂即可成。俗语说：“火锅吃汤。”炖火锅要多放汤，不会把菜烧焦，影响鸡肉的味道。

凉拌菜注意事宜：

第一，火要旺，出油多。食料煮面过热会结成硬块，使肉部肥腴，内部水分不易渗出，保护食物的鲜嫩，如油盐低，使食物中的香味得不到分离，又会使食物失去过多的水分，变为干燥味苦，既损伤营养成分，又糟糕。

第二，炖菜的原料，一般都要挂糊，就像给原料穿一层衣服。这样炸出的东西表面更漂亮，又能保持菜肴的鲜嫩和原味。

第三，烹调的调味要在加热前进行。特指必须先把原料在盐、酱油、料酒等调味一下，有的在挂糊时加入调料，还有的要在炸熟后蘸面糊，如花椒醋等。

凉拌菜参考举例：醋熘是用面粉发夹加温醋的一种烹调方法。第一先将原料用油、蒸煮的办法做熟，第二步再炒入调料。将其炒熟，加水拌匀，显然发亮，加热入调味品，淀粉不断生的食物表面，或将食物放入夹子中翻拌均匀。这种方法可以增加食物的鲜嫩，家庭凉调时多可采用。
