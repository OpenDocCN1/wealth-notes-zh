# 灵敏度下降，手拿变小

1. 收音机军绕上的线圈，一般用多股丝包线制造。如果某处外断路多，会引起灵敏度明显下降，应予检查，重新焊年。

2. 绕线在磁棒上的位置，是用有点固定好的。如果磁圈松动而位置，令某处有一圈圈的灵敏度下降，成平行调谐后并不重新固定。

3. 检查电容的质量低劣或滤波电容失效，会使灵敏度大小下降，

4. 电源电压太低，也影响收音机灵敏度。可以在放音前测量电池端电压，如果下降至额定值的75%，即应更换新电池。

5. 晶体管的老化或工作点不正常，也会引起灵敏度下降。修复或更换晶体管。

# 杂大

1. 外部大功率噪声，雷击时，各种电器工作时，都会向空中发射电磁波，这些电磁波被收音机接收下来，就是噪声。这不是收音机本身故障，尽量避免。

2. 调谐时发现有“沙沙”的噪音，说可变电容局部发生短路，应修复或更换。

3. 调谐量发出“沙沙”的嗡声，并发生音时断时续的现象，原因是电位器使用日久，动弹触点磨损积垢或其碳膜上积污物，使之接触不良。应更换或使用汽油清洗。

4. 收音机一开机就发出“咝咝咝”的噪声，原因为元器件虚焊或脱落，应小心拆出印刷电路板，将之重新焊牢，也可能机内有异物，应小心取出。
