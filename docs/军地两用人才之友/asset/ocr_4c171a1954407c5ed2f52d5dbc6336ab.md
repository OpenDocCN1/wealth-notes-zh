# 一体化发展战略

这是指企业充分利用自己在产品上、市场上和技术上的优势，不断地从后向前、向下和水平方向发展；如果从物流的方向分析，物质从反方向移动称为后向一体化，从顺方向移动称为前向一体化。下面是一体化发展战略的示意图：

目前我们正在按照专业化原则组织工业，实行企业联合，或者按各制造部件的经济联系组织，基本属上一体化发展战略。

+   1. 后向一体化策略 是指企业利用自己在产品的优势，把原料或零件的材料或半成品，现定自行生产。其主要目的是为了保证供应来源以发展自己的产品。采用这种策略，必须由国家统一组织下，根据经济合理的原则，把原料属于向后的企业必须自起来组成一个企业或联合厂，以利于统一规划，保证生产的发展。
