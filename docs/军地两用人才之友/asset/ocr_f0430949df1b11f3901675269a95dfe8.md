使用各种仪表设备，因此，家用电度表需要校验时，最好送有关电业部门进行。电度表的检修技术难度比较高，需要一定的修理工知识，可结合“故障现象及原因分析”一表，查明故障原因，然后有针对性地加以修理。

# 家用灯具

家用灯具一种是白炽灯（俗称灯泡），一种是日光灯。白炽灯是电流通过玻璃泡中的钨丝，使钨丝发热呈白炽状态发光。白炽灯安装方便，但发光效率低。日光灯的发光效率高（约为白炽灯的3倍），寿命长，光色显接近阳光，但有些偏紫，在日光下观察物体有色差，使用不当，容易使人产生视觉疲劳。

白炽灯由灯头玻璃被泡组成。玻璃泡内充满少量惰性气体，泡内的钨丝通过引线与灯头连接。选购灯泡时，要检查灯头是否歪斜、与灯头的粘接是否牢固或松脱。

安装白炽灯时，拧开开关在火线上。

使用白炽灯泡应注意以下几点：

+   1. 在更换灯泡时，绝不要让手或其它物触及灯头或灯头的螺丝口，以防安装时发热，降低灯泡的使用寿命。换灯时要先关闭电源，安装完毕后，再开启电源，以免触电。
2. 灯泡的额定工作电压与电源电压应相等，若低或高，则很快烧坏。
3. 灯泡灯丝断，若无备用灯泡而需临时拧换时，应先切断电源，搭接好后再打开开关，否则可能因搭接时灯丝工作部分过热，会发出刺眼的光。保证绝缘断路。或因灯泡内温度急剧上升使灯泡炸裂伤人。
4. 螺口灯泡不亮，常见的是灯头内铜片因过热而失去弹性，使之与灯泡电极接触不良。对此，可关掉开关，用平钳片或牙刷柄等绝缘物将铜片向外拨出少许，旋上灯泡即可重新发光。
