# 家用缝纫机的日常保养

保养 一部质量合彰的缝纫机，平时注意保养，在经常使用的情况下，可使用20年左右。应且须经常进行日常保养工作。
保养中，保持机器的清洁非常重要。缝纫机应放置在不潮湿、不受日光曝晒的地方，防止机器受潮腐蚀或机表脱落。为了防止尘土侵入机器内部，保持机头表面的整洁。藏式台板缝纫机不用时，应将机头盖入机斗中，平缝纫机机可用布帛、塑料布、纸板布或木板等罩在机头上。缝纫机工作时，由于缝料和缝线经常送布牙和机针的摩擦，使布或毛线、线头等不断地送入布牙处、针板底面和针床内，因此需要及时做好机器的清洁工作，清洁污物时应使用温和清洁剂，否则将破坏现物料架、噪音过大道灰沉积物等。送布牙齿隙间及针板表面的污垢可用毛刷清理。针床的导线槽两侧缝以及缝布图平面要用软布条蘸软料沾点，ROME用水稍滴的水后清除干净，以防生锈。每次拆装后，要更换到点油，切勿使水和稍滴的水后清除干净，以防生锈。每次拆装后，要更换到点油... ...
