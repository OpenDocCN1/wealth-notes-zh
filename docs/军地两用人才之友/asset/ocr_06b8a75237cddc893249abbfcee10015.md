# 猴头菌

猴头菌属味鲜美，营养丰富，与熊掌、海参、鱼翅并列为四大名菜。

猴头是一棵木材寄生菌，多栽生在深山密林中阴，阔叶树如椴树及立木上，目前有些地方试用人工栽培，观将栽培方法简单介绍如下：

+   1. 栽培种的培养基配料比例如下：①圆木树木屑 78%，麸皮20%，石膏 1%。②白糖1%，玉米粉88%，石膏1%，白糖1%。将培养料加60～65%水拌匀，手捏指缝间有水滴而不流为宜。然后装瓶至瓶肩处填实，在1.5公斤/瓶2压力下压紧，小口冷后封瓶。用无菌操作将取好的菌种接入瓶中，投入培养箱内，一支管可达3～4用。接瓶后放入培养室，使温度达到20～25℃，空气相对湿度递增达到80～65%，约30～40天，菌丝长满培养料，形成菌核，当菌膜1子实体管理 接瓶培养

+   2. 子实体管理 播放结束后，室温保持18～20℃，温度过高时，中午关闭门窗，早晚通风。温度低时，可在中午通风。室内湿度保持85～95%，低时地面撒水，保持经常湿润，同时，每天还可在空气间喷雾三次以上。半月后即可进行实体管理。

用菌木屑和播子壳做培养料相比，播子壳培养料具有菌丝快、杂菌少、子实体形成早等优点，比菌木屑培养料提前半月左右形成实体。

+   3. 采收 子实体长如鸽蛋大时，停止生长发长，表面面由灰白色转时即可采收。采下的子实体可晒或烘干，放在塑料袋内密封贮藏，注意防霉防腐。
