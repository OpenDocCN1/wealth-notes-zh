## 烹调

## 食物的合理烹调

烹调目的有三，一是使食物变熟以增加食物的消化吸收率，二是增加食物的色、香、味，以提高食物的感官性状和谐进食欲；三是杀灭食物中存在的有害微生物，以保证饮食卫生。所以食物在食用前必须经过烹调处理。

但是，食物经过烹调后，可能会造成一些营养素的破坏或损失，例如，抗坏血酸（促进细胞间质中胶原形成的，参与体内氧化还原过程，增强肝脏的解毒能力，促进抗体形成和提高白细胞的噬菌能力，并促进人体生长发育）和硫胺素（促进人体生长发育，增加消化功能，维持正常代谢），可因高温而被破坏，水溶性维生素和无机盐，也可在烹调过程中被浸洗而损失。

1. 高温和烹调，某些维生素易溶于水（水溶性维生素），可因溶于水而造成损失。常见的损失有：

+ ① 用米散饭，在米中煮散米损失率可达40～60%，核黄素和尼克酸损失可达23～25%。水温水温度高，煮洗次数越多，米浸泡时间越长，维生素损失也越大。

+ ② 掉皮煮米饭，把米放在水中煮到半熟后再将米捞出蒸熟。剩下下的米汤大量丢弃。它可使硫胺素损失67%，核黄素（维持组织细胞的呼吸功能，促进人体生长发育）损失50%，尼克酸（调节代谢和维持细胞呼吸功能，是构成辅酶Ⅰ、Ⅱ的主要成分）损失78%。

越多 ⑤ 炒菜预先用开水将菜煮熟一下，捞出沥筛去菜汁，然后再炒，这种烹调方法会损失菜中维生素C。炒菜时加水过多，使维生素溶解在菜汤里，吃菜营养，便维生素隐之损失。

2. 加热过度或时间过长，维生素损失增多。如蔬菜切成块，食用油炒 9～10分钟，抗坏血酸损失16%，胡萝卜素[促进人体正常发育，维持正常视觉功能和一切上皮组织及皮肤的完整和对细胞的抗病力]，抗坏血酸损失24%等。油菜切成丝，用油炒5～10分钟，抗坏血酸损失36%，胡萝卜素损失24%等。炸菜因为高温和高温油炸，可使硫胺素完全损失，核黄素和尼克酸损失50%左右。烹调时高温，蔬菜的损失，在红烧和清炖时损失60～65%。蒸和油炸时损失43～47%。

3. 氧化而损失 蔬菜切碎后放置过久，抗坏血酸可通过切口与空气接触被氧化而损失；蔬菜烹调后不宜即食，故放置过久，也使抗坏血酸损失。

4. 加入碱而损失 在烹调食物时加碱可增加硫胺素和抗坏血酸的破坏损失。而煮菜加醋，则可减少抗坏血酸的损失。

## 烹调简介

1. 火候：指火力的强弱和用火时间的长短。掌握火候是烹调蔬菜的一个重要关键。不同的火力与不同的用火时间[即火候]可以得到不同的加热效果。用各种不同的原料，就似做各式各样的饭菜。在烹调中，常用的火力有旺火、中火、小火和微火四种。

旺火：火势强而猛烈，呈白色黄色，光明度大，热度很强。旺火适用于快速烹制使原料容易成熟的烹调方法，如炒、溜、炙、蒸等。中火：火势稍弱，火色呈红色夺目，热度很高。中火适用于炸、爆、烹等速捷调理方法。小火：火势低而绵长，呈青蓝色，光度较暗，热度较低。小火适用于较慢烹制使原料被吸入味的烹调方法，如炖、煮、焖、扒等。微火：火势很微。微火适用于较长时间烹制使原料酥烂的烹调方法

法，如煨、焖等。

## 2. 调味 调味是烹调过程的一个重要环节。所谓烹调，就是包括“烹”和“调”两个方面。“烹”是指加热，就是要正确掌握火候，而“调”是指调味，就是要正确使用调味方法。通过调味，将主料、辅料和调品的共同滋味加以调和，以除去原味的不好滋味，增加烹调的美味。适当应用调味，能使味道差的原料成为美味的佳菜；相同的原料若采用不同的调味方法，就可以得到不同滋味的佳菜，因此，调味的妙用直接关系到菜肴的质量。

### (1) 调味品，也称调料或佐料。调味品的种类很多，常用的有以下各种：

+ 咸味: 食盐、酱油、酱醋浆等。
甜味: 白糖、红糖、砂糖、冰糖、蜂蜜、糖精等。
酸味: 白醋、红醋、醋精、酸梅等。
辣味: 辣椒粉、胡椒粉、芥末、生姜、葱、蒜等。
香味: 桂皮、茴香、花椒、大料、丁香、砂仁、桂花、香草、香油、香精等。
苦味: 陈皮、杏仁等。
鲜味: 虾籽、鲍鱼、特精等。
酸甜: 榨酱汁、西红柿酱、山楂酱等。
甜咸味: 甜面酱等。
辣咸味: 豆瓣酱、酱油等。
鲜咸味: 鲜酱油、虾子酱油、虾酱等。
香咸味: 椒盐等。
香辣味: 细调品、芥末酱等。

### (2) 几种调味品的制作方法

椒盐：香味咸，用干于烤菜的佐料。
原料——精盐1斤，花椒面1两。
方法——先将盐放碗内，再放入花椒面，炒至色发黄，且出香味，倒出凉后即可。
芥末酱：香味味，用干拌凉菜。
原料——芥末面1斤，温水8两。

方法——将温水倒入芥末面中搅拌，用盖盖上，焖半小时后出锅味方能使用。

咖喱汁；香辣味。
原料——咖喱酱、洋葱、姜末、大蒜等。
方法——锅内放油烧热，放洋葱、姜末炒出香味，渐加咖喱泥和咖喱粉炒出香味，姜末等色，即成香辣的咖喱油汁。

西红柿汁；甜酸味菜肴。
原料——西红柿酱、精盐、糖等。
方法——锅放适量油烧热，放西红柿酱煸炒，再放精盐、糖，炒成火红色发亮即可。

香辣汁；香辣味。
用酱油、醋、糖、蒜末、豆瓣酱、红干椒椒丝等烹制而成。

（3）调味的方法一般可分为三个阶段；
加熟前调味——即下锅前的调味（基本调味）。原料在下锅前，根据不同菜品种类的要求，先盐、酱油、糖、醋、蘑菇汤等调味品调拌，使调味品的滋味在烹制前渗进原料之中。以免菜肴异味，增加滋味。
加熟过程中间调味——即下锅后的调味（决定性调味）。原料下锅后根据菜肴的不同口味要求，加人调味品，或盐、或酸、或咸。大多数的菜肴都要求在进入烹制之时，又或分段的调味，可以决定一份菜肴的滋味。
加熟后的调味——即出锅后的调味（辅助调味）。菜肴出锅后，盛入盘内，再调上味菜品。如麻辣豆腐最好先盛入盘内，再浇上香油；溜肉段出锅盛入盘内，再浇上橙醋汁等。

3. 挂糊，挂糊就是在加熟前，根据不同菜肴的需要，在原料表面上涂上一层淀粉等调制的糊，它对增进菜肴的色、香、味、形、营养方面具有重要作用。

（1）挂糊的作用
保持菜肴的营养成分：在加热时，如果原料直接与高温的热油接触，会使菜肴中的蛋白质、脂肪以及维生素等营养素遭到破坏而损失。经挂糊后，原料不直接与高温的热油接触，就能减少营养素的损失。

保持菜肴的鲜味，原料经过挂糊后，不直接与油接触，油不易浸到原料内部，而原料内部的汁液、鲜味也较少外流，因此，能保持原料的原味，同时，糊经过油炸后即变香脆，使菜肴达到外焦里嫩，增加滋味。

保持菜肴的形状，有原料切成薄片、细丝等形状，加热时容易碎烂破坏，也容易在翻炒干燥，改变原形。经挂糊后，就能保持菜肴的形状完整和美观。

## （2）挂糊的种类和制作方法 制作挂糊的主要原料有鸡蛋、淀粉、面粉，淀粉和面包糠。一般常用的挂糊有以下几种：

+ - 蛋清糊（又称蛋白糊）：是用蛋清和淀粉调制而成。原料经挂糊烹调后，使菜肴呈洁白清润。主要用于熘、炒、滚等。
- 蛋黄糊（又称全蛋糊）：是用鸡蛋和淀粉调制而成。原料经挂糊烹调后，使菜肴呈金黄色。多用于炸、溜、煨等。
- 蛋清糊（又称雪白糊）：是把蛋清打成泡沫，再加入干淀粉调匀而成。经常调制，使菜肴色如白雪。多用于烩和制作菜类菜肴。
- 水淀粉（又称干菜糊）：是用淀粉和水调制而成。经常调后，菜肴呈乳白色，极清香。多用于生炒、干炒和滚等。
- 麦淀粉（又称粉糊）：是用面粉、淀粉和水调制而成。经烹调后，菜肴呈淡黄色，外香酥，内软嫩。多用于炸的菜肴。

把蛋清糊是把原料先沾上面粉，再蘸鸡蛋糊，经烹调后，菜肴呈金黄、味脆烂，多用于干菜、锅贴等。
把蛋面包糊，是把原料先蘸上鸡蛋糊然后再沾上面包糠。经烹调后，菜肴呈深黄色，并带有粒屑，香脆可口。多用于炸牛排、炸猪排等。

## 4. 勾芡 勾芡就是在烹调菜肴接近成熟时，将调制好的淀粉糊
掺入菜肴汤汁中，使菜肴汤汁浓稠，或在菜肴烹调完毕后，将芡汁淋在菜肴上面的一些菜肴加味。大部分菜肴都要经过勾芡，而勾芡的花样，对菜肴的色、香、味、形、营养都有很大影响。
芡类的原料主要是淀粉，它的种类很多，其中以麦淀粉最好，因吸水性强，粘性大，色泽洁白。小豆、土豆、玉米淀粉则次之。
（1）勾芡的作用

增加菜肴的美味：菜肴在烹调时要加某些调味汁计，原热加热时也要渗出一些汁液，这样，原热渗出的汁液和调味品的物质不能与原热融和。通过焙烂后适当的增加酸性，菜在原热的表面，使菜更鲜美。

增加菜肴的美观：菜肴经过芡后，汁液变浓，粘性增加，芡汁浸在菜表面，使菜色泽鲜艳，外形美观。

保持菜肴的温度：芡汁菜在表面的表面，使其热度散发较慢，在短时间内有一定的保温作用。

## (2) 芡汁的调制和使用

对芡：将调味品、汤和各种调味品在碗内调制而成。当菜肴接近成熟时，即将芡汁淋入锅内，再经很短时间的加热，便可食用。对芡多用于汤、炒菜。因为这些菜要求放较多菜肴时要先放芡汁加热时间较短，各种调味品在短时间内进入菜肴要求一次性投入锅内，使菜肴鲜美入味。

计芡：特将调味品调制在锅内，等到菜肴将成熟时将汤连菜肴一同装入锅内，使菜肴原汁原味。计芡多用于烧、扒、烩等。因为这些烹调方法加热的时间较长，所以可以将调味品分次逐渐投入，使其能更好地渗透到原热内，等到菜肴即将成熟时，最后再将芡汁淋入锅内，使菜汁渗入菜，与原粉料烹熟一点。芡汁应注意，芡汁烹调的菜的口味和汤汁量适当的时间进行宰，否则焙后无法再调整。

## 烹调方法

+ 1. 凉菜：
炖菜是把主料和辅料切成丝、条、片、块等形状，用开水稍爆或用温油稍炸，挤去水分，趁热（也可晾凉，但热时容易入味）和花椒油、盐、味精、姜末等调料拌匀，使调料渗透到原料内部。如猪肉、鸡丝等。
特点：口味清淡，鲜嫩不腻，适于作下酒菜肴。

拌菜是把生料或煮熟的熟料切成丝、片、条、块等形状，加上调料拌匀即成，如拌肉丝青菜、拌萝卜丝等。拌菜的调味品主要是酱油、醋、香油、辣椒油、蒜末、姜汁、芝麻酱、白糖等。

特点：清润、爽口、鲜辣色美，有通气开胃、解腻、解热作用。

卤菜的原料大都采用肉类、禽类及其内脏等。

把原料经过水焯或煮制后，放入卤汁内卤泡适当时间，使其渗入原料内即可食用。如卤鸡、卤白鱼。卤菜的计是用盐、味精、花椒、肉蔻等调制而成。

特点：色味醇和，软嫩可口。

卤菜的制作方法大致有两种。一种是把原料放在酱汁锅内煮烂焖熟，待酱汁熬浓时，浇在原料表面即成；另一种是把原料放入酱汁锅内煮熟即成（锅内酱汁可以连续使用）。如酱鸡、酱鸭、酱鸡。

酱汁以及其他酱料，茄酱好、主料放锅内盖子上面盖着，锅煮大料、花椒等调味品在小姐烧好上覆。

特点：质地烂，味鲜香，肥而不腻。

蒸：将主料加辅料经过蒸煮或熟后，在蒸锅内或木桶或蒸笼以及其他食品材料，把煮好的主料放置在蒸锅子里上盖上盖，锅盖加紧，使香料燃烧，发生浓烟，吸到被蒸原料的表面上即成。如蒸鸡、蒸肉、蒸蛋、蒸豆腐等。

特点：有烟熏的清香味，色泽微黄，食之别有风味。

## 2. 汤类：

煨汤菜是用鸡汤、鸭汤或清汤，把汤煮开，放入主料，调料煮熟，盖起浮沫即成。或将主料生熟，揿出盘在碗里，另外已做好的块的原材料中，倒入碗中即成。如水白菜、丸子、煨鱼等。

酥烂成。如炖肉、焖鸡等。
特点：主料酥烂，汤汁鲜美。

煮 煎煮是将主料放在热水中煮熟后，添上汤（汤要没过原料），加上调味品，用文火那样煮，即如菜片脱白菜等。
特点：原料鲜嫩、汤汁清淡。

焖 焖菜是将原料放汤锅内，加上调味品煮熟，勾芡出锅即成。如焖附花、焖丝丝、焖鱼等。
特点：汤汁浓鲜，味浓适口。

3. 油滑类：
烹 烹菜是将主料挂糊或不挂糊，放在油勺内小火煎，两面呈金黄色后，再加上辅料和调料焖熟即成。如焖黄菜、干鱼黄鱼、煎饼等。
特点：色泽美观，口感鲜美。

炒 炒是广泛使用的一种烹调方法。炒菜是将勺内放少量油，用葱、姜炒散，放人主菜炒至半熟，再放人辅料和调料炒熟即成。炒肉片、炒猪肝、炒肉丝等。
特点：烹煮柔软、鲜嫩不腻，色泽美观。

div 蒸菜是将主食经加工加大功，具有的挂梗糊，经过油炸；有的挂软糊，经过油滑，有的不是挂糊的。另是油焖，放人少量油，先加上辅料煸炒，然后再加上主料将倒入事先对好的关汁煸炒即成。如煮鱼里脊、滑三条等。
特点：酥香嫩脆，色形美观。

炸 炸菜是把原料加工改刀后，挂糊或不挂糊直接用油炸熟即成。如干炸丸子、炸虾条、软炸里脊等。
特点：外酥里嫩，口感好。

煨 煨菜是将主料加工改刀，经过油炸、油滑或水炖后，另起油勺，用葱、姜煸炒，放人主料，倒入已调好的汁，翻出即成。如煨鱼丁、油焖鸡、宫廷鸡炖等。
特点：脆、嫩、鲜、香。

烹 烹菜是将主料挂糊或不挂糊，用热油炸成金黄色，再用各种不同的调料对煮汁，锅要受热，煮汁与主料同时下勺烹熟即成。如

炸烹肉段、清蒸鱼等。
特点：外焦里嫩，色泽美观，口味香艳。

## 4. 外类里:

拟荤菜是将主料，辅料放入勺内，加调料，汤，用小火焖烂，勾芡出勺即成。如虾仁扒菜、扒白菜卷、红扒鸡等。
特点：原汁原味，口味浓香。

焖 烹菜是将主料或煮或焖后，放入辅料、调料，酱汤，用小火焖到一定时间勾芡出勺即成。如红扒胡子、红扒肉、红扒鱼等。

焖 烹菜是将主料加工改刀后，有时过的过，有时用水炸过。另一说油锅，用油制成或放酱料液体后，放入主料，用小火煮至原来即史。可如红烧肉、红烧丸子、红烧元鱼等。
特点：色泽明亮，滋味浓郁。

煮 蒸菜是将主料加工改刀后，加调料上笼蒸熟即成。如清蒸鸡、清蒸白鱼、玉米蒸等。
特点：原形，原味，肉烂不腻。

浇 镶菜是将主料煮后，用葱、姜绽锅，随即嵌入调料，添汤，用小火慢煮出勺即成。如嫩肉段、爆排骨、烩大虾等。
特点：汁浓色正，口味香浓。

5. 挂类。
挂笋及又称挂装，它是将主料挂糊或不挂糊，直接用油炸后，趁热挂上由白糖、水、油熬成的糖浆，吃时用筷子夹起主料能出丝丝缕缕的细纱，称为挂丝。如挂丝山药、挂丝率菜、挂丝里脊等。
特点：脆香可口，色美形佳。

即成,这种做法适用于不易烂的原料,如蜜汁白梨、蜜汁山药条等。

## 刀 工

# （5）靠刀

+ 1. 推片刀与拉片刀 推片刀是将刀身放平，与砧（或原料）平行，刀进原料后，由里向外推移的片法。拉片刀是將刀身放平，与砧（或原料）平行，刀进原料后，由外向里移动的片法。这两种刀法适合于煮熟回软的脆性与韧性的原料，如熟笋、玉兰片、肉等（见6～7图）。

+ 2. 滚料片 滚料片是左手扶稳原料，右手持刀，先将刀平切进原料，并随着左手的原料向后滚动，刀刃紧紧靠向前面进的一种刀法。

这种刀法适用于长圆形的脆性原料，如瓜皮等（见图 8）。

3. 锯刀片 锯刀片是推刀片与拉刀片相结合的一种刀法，片时，先将刀由里向外推移，接着刀片向外里移动，一推一拉，象拉锯一样的片法。这种刀法适用于较大的脆性原料，如肉等（见图 9）。

# （7）其它刀法

+ 1. 剞刀法（又称花刀），是适用直刀法和斜刀法将原料切上相成深度的（一一般为原料的三分之二或五分之四）各种刀纹的阵法。用剞刀法在原料表面划上各种花刀纹，不仅使原料易于渗透调味，受热均匀，形成熟透，保持其原地脆嫩，而且使原料受热后弯曲成各种美观的形状，起到美化菜肴的作用。剞刀法主要用于卸带中间或整条鱼等原料。如猪肉、瘦、肚、鹿等（见图12）。
