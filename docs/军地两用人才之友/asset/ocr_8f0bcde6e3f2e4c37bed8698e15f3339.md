# 家用缝纫机的一般故障及排除

家用缝纫机出现各种各样的故障后，应该仔细找出原因，然后予以维修。

断线 断线是故障中最常见的现象，主要原因是由于操作不熟练，使用缝纫线过度拉紧而大针力而撕断；也由于使用不当的机器，使家缝纫条件要到极后后，在缝纫通过时被割断；因为没有按机器的要求，拆卸后又安装不妥或定位错误而使缝线断裂。另因零件的自然磨损或旋用的零件质量不佳等也会引起断线。

细究断线原因，底二根缝线交叉起来时，所以在断线的故障中可分为断面线和断底线二个类型。由于面线的牵引复杂，经过的零件也多，因此断面的故障就比较复杂的多。
