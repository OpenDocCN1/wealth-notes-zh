# 蔬菜无土栽培

在非土壤基质上，应营养液栽培蔬菜称为蔬菜无土栽培。此法是蔬菜生产工厂化的重要方法。现在欧美及日本都在积极发展蔬菜无土栽培。

蔬菜无土栽培可以是从育苗到收获的整个过程都实行无土栽培；也可以只在蔬菜生产采取无土栽培，然后将苗移栽到土壤中进行蔬菜生产，此法叫无土育苗。无土栽培需有较高的自动化程度，自动化的大型温室，有加热、通风、光照、喷雾等设备自动化程度高，要求条件较高。我们把这种方法列入科研项目，尚未大规模应用于生产。无土育苗要求设备比较简单，适合我国目前的生产水平。

蔬菜无土育苗也叫做营养液育苗，是以通风良好的固体材料作为基质和用各种养分元素配制成的营养液代替土壤的育苗方法。蔬菜无土育苗需要一些设备和材料。

育苗室是育苗的主要设备，供种子发芽出苗用。小型储苗室可用塑料、玻璃等材料组装而成，大型储苗室可用木板、铁板或砖制成。无论哪种类型的储苗室都要有加热设备，并能自动调温，保持恒温30℃。储苗室内设有苗盘架，其上放置苗盘，盘内盛放发芽的种子。
