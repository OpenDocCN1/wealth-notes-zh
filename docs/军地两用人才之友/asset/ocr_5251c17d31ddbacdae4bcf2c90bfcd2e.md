# 做菜约火候：

(1) 炒菜类：
嫩豆腐、绿豆芽、小白菜、芹菜等青菜要受用旺火、热油，炒的时侯要爆炒得快，时间要短，这样，做出来的菜才能脆嫩可口。如果火小、油温，时间长了，青菜会出汤、变黄、软腌赖的不好吃 了。

(2) 肉丝炒绿豆芽、肉丝炒紫菜、肉丝炒芹菜。炒腰花、炒猪肝、白菜炒肉片等，都必须把肉片、腰花片、猪肝片切得极薄，肉丝切得极细，然后再起热火爆炒，把起菜席先放到油里炒一炒，放入上汤后爆起姜末，再用火力和炒菜料，把肉丝或腰花、肝等先炒地炒一下，炒到没有血色的时候就把先炒好的蔬菜倒进锅里，很快地翻提一下，和肉类拌匀，就可以盛出来吃了。

(3) 烫肉片、煮肉末、煮羊肉等，煮大块等鱼简直菜，先要把肉片等蘸上黄酒清和干面粉。炒的时候要用猛火热锅炒一下，再在文火上焖一下，然后再抽油倒出来一些，再加上料酒，汤汁中加些面粉。一溜就成。但煮鲜肉片、鱼片等要受温油。

(4) 蒸包、煮包子等要受要受猛火蒸法，火力不能太旺。应该在油热后，保持在一定温度的大火上慢慢地蒸，这样才能获得食物里最鲜不过。另有、些如黄豆青菜粉、萝卜、菜豆粉冬荠菜等要用食物，在用旺火炒后还要加些上佐料和水，盖上锅盖一会等。

(5) 想把肉炖得又香、又嫩、又好吃，要先用旺火煮开，然后再用文火慢慢地熬。做法是先把肉切好并炒成金黄劫，再把切好的肉块放进去，等锅上色了，就倒进酱油，五香粉、盐等，佐料的味道进到肉里，再放汤（一斤肉两斤水）和、粗葱、姜、大料、桂皮等。等肉煮开，就放文火上炖，约三分、四个小时，等汤将熬干时，肉也炖烂了，就放姜、葱等调在肉上，味道就更可口。如果汤放得太多，或放放得少，后又加水，味道就大减。
