# 葡萄

葡萄是蔓性营养果树物。栽种 3 — 5 年开始结果、蔓长可达 9丈左右。寿命可达 200 ~ 300 年。葡萄的适应性强，沙土、<|message|> 多砂质的土壤都易栽培，而且能在含全石灰的土壤中生长。繁殖用扦插、压条、嫁接、靠接等。栽种后需于定植穴下铺设防渗物，若在春天，翌年春即可开花。葡萄对氮、磷、钾肥要求较高。要适时适地施肥、浇水。葡萄需架支撑，一般采用棚架、篱笆、架式、便干管理。

葡萄的修剪分夏、冬两次进行。冬季修剪主要是防寒过冬，因架式不同，修剪方法也不同。主要是视蔓势情况，适当留芽，长梢留芽12个以上，中梢留芽 8 个左右，短梢留芽 3 — 4 个。夏季修剪，主要是指及时除萌、摘心、除枯枝、延迟冬、保持充实养分、疏果等着结实果。

# 树种的采集和贮藏

选好母树。一般来说，应选择生长健壮、没有病虫害的壮年生木。生长不好的树木，未能正常结年鉴的幼树和过熟老树，以及有病虫害的树木，均为不合格母树系。

适时条件。各树种的种子成熟期有早有晚，必须掌握好时机。林木种子成熟时一般带红或紫、重量增加、种仁饱满，种子外面厚而有一定光泽，果实多由绿色变为较深褐色。采种过早，种于未成熟，不仪不好保存，而且发芽力低。采种晚了，有的种子容易散落失效。还要单采单收，品种不可混杂。要注意保护母树，不得折断新梢或剥皮。

及时处理夏回种子。为避免种子发热，霉烂受虫、根腐质腐烂。球果、干果等不同果类，应分别采用洗捣、堆晒、晒干等方法及时进行。如杏套杏皮果类，果实有肉汁，含精分比率多，密实度骤然降低。采后应及时脱粒，脱粒时，先用水浸，果肉软化后敲烂果皮，冲洗去果肉，就能得到纯净。要及时将种子阴干，以便贮藏。落叶松等球果类，果实熟后，果瓣逐渐干裂，种子很容易散出。所以采果时，应该还未开裂的球果。容易裂开的球果，可用暗晒
