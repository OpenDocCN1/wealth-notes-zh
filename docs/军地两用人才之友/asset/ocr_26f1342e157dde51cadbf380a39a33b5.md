# 驯苗

泥鳅的繁殖季节是5—8月。可采取投放自然的办法培育种苗：即在泥鳅繁殖季节，收集体长4—5寸，体重两斤以上的、体质健壮、肚皮肥圆的亲鱼，挟1只的睡鳖比卵绒的池内，养分置一敌人工作巢(用水泥袋或塑料拍即可)，被可以促进它产卵。受精卵在水温25℃时，大约2天就能孵出鱼苗来。出苗1天后，每10万尾鱼苗每日喂熟鸡蛋1个。研究后请加计投喂。每日换水2次，10天后放入鱼池中。孵出的幼苗章养殖，到年底，平均每条可长到半截左右，作为下年间养的种苗。

# 饲养方法

池塘 选址住宅附近、向阳和水源充足的池塘，用水泥建池，面积约为0.15亩左右为宜，池深一般三、四尺左右，水深1—1.5尺(高温季节可深一尺)，进出口要设网拦等。池塘最好离岸高或排水口处<|start|>斜，以方便鱼苗进出和捕捉。放养时，池底要放8寸到1尺深的肥泥。

0.1亩鱼池可放小泥鳅(苗种) 5—6千条(即苗种30斤左右)，如有流水条件，放养量可适当增加。放养时，先施足基肥(牛、猪、鸡、鸭粪等均可)，以繁殖饵料生物。也可投喂蝇蛆、米糠、豆饼、豆腐渣、菜叶等。投饲养种时应严格控制水温为宜：一类水性在22℃以下时，以投喂性食物营养为好，22—25℃时，可喂动、植物性饵料；25—28℃时投喂动物性饵料；在5—9月间，当气温升到25—28℃时，泥鳅非常活跃，吃饭最盛，要经常保持水肥适度，以促进泥鳅生长长。当气温超过30℃，泥鳅就会进入夏季中暑，这时，要经常灌注新水，以增加水中氧气和调节水温。11月至次年3月甚至上不需投饵。在放养期里，要控制水质和水质流入池中。如果浮游生物褐色或泥绿色时定期用药。碱性水和咸淡水、要防止肥料。深水时常灌注水。到10月份，泥鳅平均每尾长到三、四条左右，便可捕捞。
