# 消灭突入之敌

敌突入我阵地时，战士应坚强顽强，孤胆作战，以火力、手榴弹、刺刀和爆炸物消灭突入之敌，坚决守住阵地。

当敌迫近，装甲车突越战壕时，应利用阵地内工事堡垒、交通壕接近敌坦克、乘其缝隙或隧道等有利时机，掀毁紧壕，迅速跃起，向其投、挂燃烧器材，将其炸毁。敌坦克、装甲车老练越过壕堑时，应利用工事或迟滞跃出壕堑，以爆炸物将其炸毁。当敌坦克、装甲车进入我两块阵地间时，应利用工事迅速启动或废除路障，待其接近后，将其炸毁。火箭筒手或迎装甲，装甲战车被我障碍所阻、减速、转向等有利时机，以钢铁、钢钉、反射火力将其击毁。
当敌步兵突入时，应迅速靠近其动，以扼近射击、手榴弹、刺刀将其消灭。如敌人沿路挖扩张时，应以移动路障物堵塞壕堑、交通壕阻敌扩大，利用壕的拐弯处和纵向射击设备消灭敌人。

# 进攻战斗中的步兵班

步兵班在进攻战斗中，通常在排的编成内担任突击班、预备队或开辟通路等任务。

班（组）在进攻战斗中，必须贯彻集团、近战、火力、近战协同的思想。发挥勇敢战斗、不怕牺牲、不怕疲劳和连续作战的能力，迅速克服地接近敌，突然展开地冲击，坚决歼灭敌人。班（组）长应不断观察敌情地形，勇敢到战斗指挥战斗，以自己的模范行动，带领全班（组）坚决完成战斗任务。
