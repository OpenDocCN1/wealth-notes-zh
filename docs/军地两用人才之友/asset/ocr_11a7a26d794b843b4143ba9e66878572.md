# 商业企业管理

商业企业管理，要为实现商业企业的基本任务服务，一定要适应社会主义现代化的要求。商业企业管理的任务是通过对企业的人力、物力、财力实行的有效组织、指挥、监督和调节，充分发挥企业职工的积极性，保证商品流通过程顺利进行，力争以最小的劳动消耗取得最大的经济效益。

# 商业企业管理的职能

商业企业管理职能。一般来说，有如下五个方面。
一、计划 计划是企业管理的重要职能，计划制订不同于企业的计划业务，企业计划业务不是计划管理的部分内容。计划制订还包括预测未来和决策目的。确定经营方针和方针，选择实现计划任务的最优方案等等。计划往往要考虑企业发展和繁荣的各种可能因素和所有条件，很不稳定，还必须考虑影响企业发展和繁荣的各种可能因素和所有条件，也就是必须预测未来。这里包括对国内政治经济形势发展变化的预测，党和国家大政经济措施对国内市场影响的预测。国民经济计划的安排与实施的而测。承受政府各项经济政策的调整对企业影响的程度的预测，国内市场商品供给关系变化的预测。社会购买力特别是居民购买力变化对销售的影响，商品需求构成和购买欲望变化，习惯变化的预测等等。只有对影响商业企业管理的各方面因素周围环境的变化，才能根据绝对企业的发展期或近期奋斗目标及实现预计项目有关的某些重大问题掌握。在周密预测和正确决策的基础上，才能制定出能够对企业进行经营的经营活动、实现所确定的目标，按照最优方案落实管理工作。计划制订，随着我国经济管理体制改革，企业管理权限的扩大， provision 决策和计划的同余复杂，将显得更为重要。
