# 离心泵常见故障和排除方法

| 现象 | 产生原因 | 排除方法 |
|---|---|---|
| 1. 水泵不出水 | 1. 加水不足或真空泵吸不上水 2. 吸气管路漏过水泵接管 3. 进水管泄气 4. 水泵转速不对 5. 水泵转向太慢 6. 进水口叶片轮流道堵塞 7. 闸板关闭 8. 叶轮磨损太大 9. 叶轮磨损严重 10. 叶轮制造或更换材料 11. 叶轮间隙过大及磨损出尖 | 1. 继加水或换气 2. 改善安装位置，改变管路，弄好检查 3. 用火烛检查管路，并堵严 4. 改变方向 5. 增加转向 6. 检查并疏通 7. 卸下叶轮 8. 降低水泵转速减少水头损失 9. 更换新叶轮 10. 压低叶轮或更换材料 11. 更换叶轮 |
| 2. 水泵出水不足 | 1. 进水管路焊接度不够，案内吸入空气 2. 进水管泄气 3. 闸板开度不足够或止回阀有缺陷导致 4. 进水管或叶轮流道中有杂物 5. 转速不修 6. 饮水环境太差脱水严重 7. 吸水扬程太大 | 1. 增加进水管长度 2. 检查堵塞 3. 开大闸或将止回阀送止阀 4. 停车修 5. 增加转速 6. 更换新河 7. 更换按推荐水泵降低吸水高度 |
| 3. 动机机停止不动或相继故障 | 1. 水泵转速太高 2. 泵轴弯曲，轴系错过过大或损伤 3. 叶轮重量太大 4. 叶轮和泵壳住或负荷停常 5. 流量太大 6. 动力机低功功率太小 | 1. 降低转速 2. 校直装配，更换新鲜轴承 3. 调整基座 4. 调整停转，调至同心度 5. 限制最大流量，减少超载 6. 更换发动机动力机 |
| 4. 水泵运转中有声响、振动 | 1. 轴向打滑 2. 泵内异物堵塞 3. 叶轮不平衡 4. 吸水扬程太大，产生汽蚀 5. 案内吸空气 | 1. 扩容松动的螺钉 2. 停车清除异物 3. 送厂检修并重新找行校正 4. 降低吸水扬程 5. 校直基准气处并堵漏 |
