
# 对直升飞机的打法

直升飞机可垂直升降或在空中停留。最大水平飞行速度约为60—70公里/时巡航速度在40公里/时左右；垂直升降的速度一般为5米/秒左右，飞行高度通常在四千米以下。其目标是飞行速度慢，高度低，体积大，所以更便于地面射击。当目标进入有效射程内时，应立即即随射击；当目标垂直降落或在空中停留不动时，是最佳的射击时机，应不失时机，集中火力猛烈射击。

# 对多架敌机的打法

应集中火力先对我威胁最大，飞得最低或速度最慢、机体较大、的敌机。

# 打 空 降

空降兵又叫伞兵，是乘飞机从空中降落到地面作战的部队（分队）。其着落方法分为空降和机降两种。利用降落伞将人员、武器和物资器材落到地面的是，叫伞降。用飞机（直升机）将人员、武器和物资器材直接降落到地面的，叫机降。

# 空降兵作战的特点

空降兵具有高速机动、隐蔽突袭、出现在不意地带降落对敌方后方作战迅猛有效。但是，也有以下缺点：①在降落中不能有效地发挥火力。②通常着陆比较分散，组织、供给需要一定的时间。③对地形及气候情况敏感，后方支援和补给困难，不能坚持长时间的战斗。④受一定的地形和天气的影响。

敌人为达到隐蔽、突袭的目的，通常选择在夜间、黎或黄昏突降空降。

一般在地形平坦便于隐蔽和机降的地方空降，也可借空降在较高地上的空空降。

敌人空降的高度一般是200—2000米。为了缩短空中停留时间，高

度在500米以外的为多。张力高度常为200—400米。开伞后的降落速度大约为6米/秒，顺风飘时，水平运动速度等之风速。从各个高度降落到地面的大约时间是：一千米，约三分半钟 五百米，约一分半钟 二百米，约半分钟。

# 消灭敌人空降兵的有利时机

消灭敌人空降兵有利时机通常是：敌机临空停降时，正降落时。着随后尚未集结的混乱之时，集结后，立足未稳，尚未展开时。

# 打着陆前空降兵应注意的问题

集结兵力各方歼灭敌人, 近战歼敌的原则, 也完全适用于打敌空降兵, 但应注意重。

+   (1) 空降兵在降落当中, 通常夹带着空投的物资。 在射击中, 要注意把人和物分清楚。 不要把物当人打。 判断人和物的标志: 人在空中是动的, 物是 不动的; 物的体积一般比人重; 通常物比人重, 所以物一般打来的人快。

+   (2) 注意对人射打。 因为伞衣面积大(一般为60—80平方米) 而且有加强筋, 打上一些弹头关系, 空降兵照样可以安全着陆。

+   (3) 射击中应注意观察, 是否已被击中。 判断降落中的敌空降兵是否被击中, 简单的观察就是看降落伞下面两个手和两脚的情形。 空降兵在降落中, 正常的姿势是: 两手向上握着接绳带, 两腿并拢稍弯曲。 如果不是这样, 而是两手下垂, 两腿在下坠拉着, 就说明已被击中。

# 对刚着陆之空降兵的冲击

敌人连以下小分队空降时, 从着陆到集结完毕, 大约需要15—30分钟, 在这段时间内, 敌人比较混杂, 战斗力不强。 因此, 应抓住这个时机, 猛打,猛冲, 力求在敌人未集结之前, 予以歼灭。 如敌人已集结, 并占据了一定阵地, 应乘敌人防御准备不足和不稳定的时机, 迅速地接近敌人, 以火力掩护下, 迅速发起冲击, 以打乱射击, 削弱敌...

手榴弹杀死敌人。

如敌人线路降时，应先集中主要兵力，迅速弹出前抗击敌之故，占领空降场，同时以部分兵力对付续降之敌。

# 防 原 子

# 核武器之杀伤破坏作用

原子弹、氢弹爆炸后，产生四种杀伤破坏因素：冲击波、光辐射、贯穿辐射，放射性沾染。

冲击波、光辐射和放射性沾染的作用时间有几秒钟到十几秒钟，放射性沾染的作用时间较长，有时能持续几天到十几天。

+   1. 冲击波；冲击波是核爆炸最主要的杀伤破坏因素。其性质同台风相似，不传速漏速是复合风，压力也比台风大得多。
一颗中型原子弹空爆时，能使距爆心两三至四公里的暴露人员受到中等程度的伤害，对地面上暴露的轻型坦克和各种火焰的破坏半径约为七百到一千米。

+   2. 光辐射；光辐射是核爆炸后火球发出的强光，能烧伤人员皮肤和引起一类物质燃烧。一颗中型原子弹空爆时，距爆心距离点三到四公里内的暴露人员，可可能受到不同程度的烧伤，能使二到三公里内的武器、装备器材的燃烧部分起火燃烧。
由突然出现的闪光时，能使距爆心几十公里内暴露人员的眼睛暂时花。

+   3. 贯穿辐射：贯穿辐射是原子弹爆炸时放出的大量射线。它和爱克斯光相似，但作用要强得多。射线是看不见摸不着的，但它具有很强的贯穿能力，能够穿透各种物体。
贯穿辐射对人体器官没有什么时候破坏作用，但破坏人体细胞组织的正常功能，人类受到一定剂量的照射（100伦以上）后就会引起放射病，出现身体虚弱、头痛、恶心、呕吐、白血球减少等症状。
中型原子弹空爆时，能使距爆心一到两公里以内暴露人员患中等放射病。

+   4. 放射性沾染；核爆炸时能产生大量的放射性物质，杀炎尘—

样散落在爆区和下风方向的一定范围内，使地面、物体、空气受到污染染。这就是放射性沾染。故放射性沾染不可避、即不容，和放射辐射一样，能够造成放射线。人员受到一定剂量辐射后也能导致放射性。如果吸入或吞入体内，伤害作用更大。

# 核武器的杀伤力和可防性

原则上，核武器同其它武器一样，也有两重性，它们既有一定杀伤破坏作用，又有很大的局限性和可防性。只要我们掌握核爆炸四种杀伤破坏因素的特点，认真做好各方面的准备工作，核武器是可以防的。

四种杀伤破坏因素的局限性、可防性是：

+   1. 冲击波：地形条件对冲击波的杀伤破坏作用限制很大。山地能够有效地削弱冲击波，配置在背风心区和建筑的人或武器可以大大减小或避免冲击波的伤害，利用简单的工事等掩蔽、散兵坑、土墙、地窖或建筑物以冲击波的杀伤半径缩小一半到三分之二，带有转弯的窗口、效更加显著。甚至倒在开阔地上，也能大大减小冲击波的伤害。在坚型工事坑道内，即使距离很近，也能完全避免冲击波的伤害。

+   2. 光辐射：光辐射和太阳光一样是直线传播的，也容易天地方的的影响。阴雨、雾天，尤缓的云等半透明大颗粒物，一到通量光的物体会影响工事、窗口、石头、弹药等光辐射不能达到的地给出，都能减少或完全避免光辐射的伤害。白色与浅色的衣服和物体也能起一定的防护作用。

+   3. 各项条件：各种物体都能削弱贯穿辐射，有掩蔽的工事、地下室和混凝都有较好的防护作用。工事土盖加厚是最简单有效的方法。一米以上的土层就可以被贯穿辐射射分之九以上了。

+   4. 放射沾染：放射沾染布满范围和沾染程度，主要取决于爆炸方式和风速、风向、原空。空气中爆炸时，地面放射性沾染很轻微，对部队行进作战并无影响。地面爆炸时，在爆区和风向的一定范围内可能形成严重的沾染，但是沾染的程度随着时间的增长而不断减弱。一般时间每增加七倍，地面上辐射（表指示减弱单位

位伦/时)减弱到十分之一。如爆后一小时地面辐射转为100伦/时，爆后七小时即降为10伦/时。爆后的两天多四十九小时)即降到伦/时。沾染的散布范围还很轻，即距爆离心远处辐射越高，远处辐射较低。我们可以利用它的布设规律和随时间变化规律来组织部队行动，减少射线的伤害。防毒面具、口罩、毛巾等都能有效地防护放射性沾染进入体内。

# 对核武器的防护方法

+   1. 在敌人核袭击前，主要防护措施是：靠山，分散，掩洞。

靠山——就是要利用有利地形，靠山躲藏，根据敌我人可进行绕袭击的方向，尽量把部队配置在爆炸心的反斜面.

今次——就是把伤仓大队分散到不同和远近和两面，高配置。一个中小型的原子弹杀伤破坏半径只有几公里，部防就配置，原子弹就发挥不了大作用。

掩洞——就是掩蔽躲各种工事，特别是坚固掩蔽。各种工事对核武器都有很好的防护效能。人员、武器、车辆等要构筑掩蔽工事。蓦露的易燃物要盖上土或或瓦块，或用沙土土覆盖起来。从防护效果来说，最好的就是有重型无遮无无遮蔽的,有重型比轻掩盖的好,背向原子弹爆炸心方向原子弹爆炸心好。

筑洞须与确方便，节省器材，防护效果较好，应该广泛适用。在结构方面，除洞口要背向可能爆发的方向外，最好有三个出口，有一、两个拐弯(不同受弹角度),并要特别注意通风气体的作用。

2. 在敌人核袭击时，要迅速隐蔽。

原子弹爆炸的闪光，是敌人核袭击时确切的信号。闪光出现到冲击波到达的时间，一般有两三秒钟的时间，只要在这两三秒钟内迅速隐蔽，就能大大减小核武器伤害。因此，在发现核爆炸的闪光时，应立即进入就近的工事进行隐蔽。如果附近没有工事，可以利用两三步内的附近沟壑、地物、坑、虚内、障碍、坑包、土堆等掩蔽等隐蔽。在开阔地的人员要立即卧倒。卧倒时，应向简心脸蹲下，两手放 在身下将头紧紧(防止强烈地震震伤脸腔),紧闭眼睛以避免晃眼 睛流花， 张开口， 防止震破耳膜。 过了十秒钟或冲击波过去以后， 就可

以来继续战斗。

# 3. 在放射袭击以后，要组织侦、防、消、救。

侦——就是及时查明配置区域或行动方向上是否遭受放射性沾染。现有的辐射侦察器材如辐射剂量仪、乙基仪等，都能及时、准确地发现和查明是否遭受沾染，并能测出沾染的高低。

防——就是要采取防护措施，避免或减少对放射性沾染的伤害。在沾染地域内行动时，要穿防毒面具或口罩等，以免吸入放射性物质。在沾染地域内不要吃饭、亲手，以免污染到皮肤或装入体内。通过侦察地域时，要高速度通过，尽量缩短在沾染地域内停留的时间。

消——就是及时进行洗消。人员、车辆在沾染地域停留或通过沾染地域时，人员和物体表面都可能沾染放射性物质，可用几种简单的办法将这些放射性物质清除(简略洗消)。方法是：拂拭、拖刷、拍打、抖摇、携等方法，看起来很“土”。实际洗消效果很好。例如一支沾染的半自动步枪，用肥皂片洗消，清洗效果为 85%。对沾染凝露拍打三次，拍动次数为 95%。皮肤沾染后用水洗，清除率可达 97%。因此，在敌人核袭击以后，应当紧抓战斗间隙，利用随身携带的水壶、毛巾，掸拂一沾除和双手，用被布或粪布、掸除凝露，武器装备的表面，用手擦、铁鞋杠扣和刷子将粪的表面。类似沾染疙瘩，还可以服用下服装、封堵几次。如果沾染严重，在战况情况允许时，可以到洗消站进行洗消。

救——就是救护。

# 防 化 学

化学武器（主要指毒剂）也是一种大杀伤杀伤性武器。苏、美两个超级大国都十分重视发展化学武器。

# 化学武器的特点

化学武器在战斗中使用有四个特点：

+   1. 条份范围广。能使空气、地面、武器装备、物质器封杀毒。杀害空气功能散到林木、凹地、工事、建筑物内，杀伤敌人的生动力

2. 作用时间长。毒剂施放后，在一定时间内仍能保持杀伤作用，有些毒剂杀伤作用可以持续几小时甚至几天。

3. 中毒途径多。除通过呼吸道进入人体外，还可通过食物、饮水进入人体或皮肤接触引起中毒。

4. 条件依赖。地形影响很大，刮大风、下雨、下雪都不利敌人使用化学武器。

# 苏、美装备的军用毒剂主要性能

苏、美装备的几种主要毒剂，按毒害作用的特点，大体上可分为五类：

+   1. 神经性毒剂：能够破坏神经系统的正常功能，中毒后能引起瞳孔缩小、视力模糊、呼吸困难、肌肉跳动，严重时能引起全身抽搐致死。主要毒剂有沙林、维（V）类毒剂。苏联还有樱毒、塔铬。
2. 氯疮性毒剂：能够破坏皮肤，引起红肿、起泡、糜烂，也能伤害肺部和眼睛。主要有芥子气、路易氏剂。
3. 窒息性毒剂：能够破坏呼吸器官，特别是肺部，引起肺水肿。主要毒剂是光气。
4. 全身中枢性毒剂：能够破坏全身各组织细胞的呼吸功能，使肌体不能利用氧气，于是头晕、呼吸困难、瞳孔散大。主要毒剂是氢氰酸。
5. 刺激性毒剂：能够刺激眼部和呼吸道，引起流泪、咳嗽、喷嚏、呕吐。主要毒剂是苯乙酰氯、亚当氏气。

由于敌人经常将毒剂混合使用，因此实战时化学武器引起的伤害是多方面的。

# 对化学武器的防护方法

化学武器使人中毒的途径与放射性沾染基本相同。因此，防原子弹的措施和方法也基本适用防御化学，只要避免吸入  зараж空气、接触污染泄漏损害、误食被毒害食物，就能够不受伤害。但化学武器对人体的伤害一般比放射性沾染迅速，因此对化学武器的防护和消毒要更加及时迅速。一般

说，防护方法有四种：

# 一、侦察：

通过化学侦察，可以发现和确认敌人是否使用了化学武器，使用了哪些毒剂。除了化学侦察器具，如侦毒器、化验瓶、检毒箱等能鉴别他人使用情况以外，还可以采用一、二间的办法。

一、就是看征候。化学炮弹、炸弹爆炸时，通常可以看到爆炸烟幕，敌机在蓝天洒毒，则可看见飞机尾后有黑色浓云条，如果看到地面上有青油状斑点，植物叶子出现斑点，并出现叶子枯萎，水面积有油膜状的东西，雪上有斑点或液滴渗透的孔洞，昆虫大批死亡等现象，都可做为是否有敌人用毒的根据。

二、就是闻人气味。因很多毒剂都有特殊的气味。如沙林有类似水果香味，芥子气有类似大蒜味。

# 二、防护：

# (1) 对呼吸器官的防护，防毒面具可能当地防护多种毒剂。没有面具时，可以采用最简单的方法办法，如毛巾、口罩都有一定防护能力，浸有石灰水的湿毛巾能防氢氨氯气十分钟。叠成12层的湿毛巾可防沙林、二十分钟。毛巾内包上三厘米厚的小颗粒土上可防沙林四十分钟以上。

几种就就的防护器制造方法：

# 三、 消毒：

+   (1) 皮肤消毒。皮肤接触后，应及时用“防毒盒”内的皮肤消毒包清洗。皮有防水的药，也可用肥皂水清洗，次氯酸钙或次氯酸钠水溶液消毒。也可用酒精水，最好的涂上肥皂或洗衣服，多洗几次。如果皮肤上发现有毒剂液滴，要先用棉花、布或纸吸去毒剂液滴，注意不要扩大染毒面。
(2) 武器消毒：可用漂白粉、三合二 (三次氯酸钙与二氧化锰)、漂白粉精水溶液消毒。对神经性毒剂还可使用氨水、石灰水消毒。也可用肥皂水或石灰水刷洗。
(3) 地面消毒：除用漂白粉、三合二外，还可用锌除、掩埋、火烧等方法消毒。

在敌人使用毒剂后，如果发现自己或战友中毒，要立即进行自救和互救。

+   (1) 如果发现现视力模糊、胸部发闷等症状，要立即卸下防毒盒内神经性毒剂盒吸入。
(2) 皮肤、服装上如果发现有毒剂液滴，要立即用棉花、被布等擦去，并用防护盒内的皮肤消毒包进行消毒。
(3) 如果呼吸道感到刺激，可以用防毒盒内的共烟混合剂，将小安许剂放于鼻前吸入。
(4) 积极救护中毒的战友。首先帮助他们脱上保护器材，避免继续中毒，如果已出现中毒症状，要及时带到打急救针和消毒。如果呼吸或心跳一且停止，可进行人工呼吸和按心脏搏。战斗情况允许

应及时将中毒同志送出毒区，后续治疗。

# 防生物武器

战争中采用杀伤人、畜，毁坏农作物的致病微生物（包括细菌、立克次体、衣原体、病毒等）和细菌所产生的毒素叫微生物战剂。装有生物战剂的各种炸弹、导致弹头和气溶胶发生器、布酒器等生物武器。

# 生物战剂照对人员伤害程度分类

+   (1) 失能性战剂，主要使人员暂时丧失战斗力。如布氏杆菌、炭疽杆菌与脑炎病毒等。

+   (2) 致死性战剂，使人员患严重疾病，死亡率大于10%。如鼠疫、黄热病病毒等。

按照所致疾病有无传染性分类：

+   (1) 传染性战剂，传染很强，一旦流行，能持续一定的时期。如鼠疫、天花等。

+   (2) 非传染性战剂，只感染接触者。如肉毒毒素等。 mainly用于对地方疫、设施目标。

# 生物战剂的施放方式
