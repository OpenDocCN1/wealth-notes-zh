在增减记录法中，试算平衡工作，是运用一定的公式和采用一定的表格来进行进行的。按照增减记录法的记录规律，对每项经济业务涉及的资金增加或减少进行反映的结果，其资金运用科目的增加或减少额之差额也必等于资金来源科目的减少发生额之差额。这样就可以得出如下公式，
资金运用 资金运用 资金来源 资金来源
增加额 - 减少额 = 增加额 - 减少额
这个公式是日常核算资金进行试算平衡的基本公式。根据数学移项的原理，还可以推导出下面两个公式：
资金运用 资金来源 资金运用 资金来源
增加额 - 增加额 = 减少额 - 减少额
资金运用 资金来源 资金来源 资金运用
增加额 + 减少额 = 增加额 + 减少额

前两个公式是“差额”求平衡，称为“差额平衡公式”；后一个公式是“合计”求平衡，称为“合计平衡公式”。
