# 图五 利用土坑

树木：利用大树可取各种射击姿势，较小的树通常采取卧姿。如取立姿时，应尽量将身体左侧和大树靠或左小臂和左膝紧靠大树右肩侧，右臂稍向后摇，进行射击（图六）；如用卧姿，应将左小臂紧靠树木右后侧以树的根部作依托（图七、八）。

高窗、丛林地：尽量利用房屋近敌方的边窗内，以避免观察、射击。

墙壁、门口、墙角：按其情况取适当姿势。墙壁高于是人时，可将枪管装高或射击孔（图九）。矮墙可利用顶端。门口通常利用左侧，左侧放离开（图十）。抵进射击（图十）。墙角通常用右角，左侧靠墙角（图十一）。
