点，善于运用深、使人物的主要部分处于画面的明亮部分而其特别清晰，次要的部分可以模糊些，人物面部遮光要俯视，这样画面才有质感，精神面貌才能生动感人。

# 风光摄影

# 大自然景物摄影

风光摄影大画面较多，拍摄距离较远，应从处处谨慎，从而突出发，着重表现其间架和气够，而不是去追求细微末节。一幅照片虽然只有两或三定位，但对建筑物，都应表现出现宽、窄、额外三视觉感觉。同一被摄对象正面照，相隔着不同宽度、高度等原因，在拍摄时常有明显差异，立体感就弱了。建筑物由正面拍摄，就看不到侧面的形态和结构，由斜侧面拍摄，就见不到其空间。拍摄位置较高或低，空间感也有差别。自然风光要素要深远感，同一景物，在形影则同大后小同顺一色，在彩调上则近浓远淡。因此在拍摄黑景时，常利用调和的云雾，把一层一层的密续分开，增加深远的感觉。

光线的运用。一幅照片景深、较好的时间是日出后一、二小时日落前一、二时之间。在采用阳光时，改变曝光量可以获得神秘不同的调试的效果，如果按常规曝光，阴影部分就会曝光不足，照片上将会有大量黑色调子，就难以取景。如果拍摄暗晦晚，阴部分分度就高了，高光部分的图片就被破坏。如要堤明，暗中的中间部分曝光，可以获得丰富的层次，这也是最常用的曝光方法。天空是风光照片中重要部分，云彩可以弥补天空的平淡，造成构图上的缺陷。对蓝天下空气中的深蓝，应采用深蓝黄色来突出它。反之，对于深蓝色的天空中有白色浮云，则要用淡黄色滤镜，以避免天空深暗，给予人压抑之感。

拍风光，通过宽幅或高窄的景物，不应要紧紧压紧的顾虑，可按次拍摄后来加以合并成一幅照片。以使重点的景物显现为主导。拍摄时应注意，①要掌握阳光的变化，防止底片曝光不一致，或光线角度不一致。②拍摄地片标记，防止拍不完整，两片衔接处古底片的五分之一即可，防止底片利用率不高。③拍摄高度要一致，即照相机中轴线与水平高
