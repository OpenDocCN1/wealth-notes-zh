# 养 牛

牛的品种：目前，我国饲养牛的品种，主要有黄牛、水牛、牦牛等种类。从用途分类又分为役牛、乳牛、肉牛（菜牛）等。

议论牧牛年龄：要求牧牛中有经验的牧民、干部，不仅可根据牛的外貌特征、角状形状，左分别老、壮、幼年牛，而且可根据牙齿计算出牛的准确年龄。

牛有四对门齿，中等间隙为缺齿，两侧最外的一对称为侧齿，靠雌齿的一对内中问齿，靠颊齿的一对称为外中问齿。由于年龄不同，牙齿的表面出现了不同的磨损情况，年龄就是根据磨损情况而确定的。

蒙牛一脱牙齿的变化情况：

+   2.5-3岁，乳齿脱永久斲齿出；
3-4岁，永久内中问齿出；
4-5岁，永久外中问齿出；
5-6岁，永久侧齿出；
7岁，全部门齿齿面平，外中问齿呈黄色条纹；
8岁，全部门齿齿面平，都有黄色条纹；
9岁，雌齿中部呈现圆形点；
10岁，内中问齿中部呈现圆形点；
11岁，外中问齿中部呈现圆形点；
12-13岁，全部门齿中部都呈现椭圆形点。

牛最合适吃的饲料：

一是牧草等饲草中包括野苜蓿、野菜、天鹅牧草、人工种植牧草、稗叶、水生植物等。这些饲草等含有丰富的蛋白质、维生素和矿物质。其中豆科草，如苜蓿、红三叶、紫云英、豆类作物等饲料价值高。
