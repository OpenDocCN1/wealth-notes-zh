# SS-20 导弹

SS-20导弹是苏联在七十年代开始研制的新式导弹，它以固体燃料为推进，携带三个分导核弹头，作战略变为三千公里左右，其发射装置可以移动。

苏联的SS-20导弹由战略火箭部队掌握，以因为部署单位，其中三分之二在欧洲，三分之一在亚洲。

# 巡航导弹

美国BGM-109B随航巡航导弹，被称为“八十年代的奇特武器”。这种弹翼的小型、机动地对地巡航导弹长6.4米，圆柱形弹体直径0.52米，重量1,450公斤。一枚发射点轨道飞行能力为4枚弹，整套年绪也可为飞机运载。这种巡航导弹的特点是，命中精度高，射程远不易被对方发现。击中2,500公里以外的目标时，最大误差只有30米。核弹头破坏的核力相当于20万吨黄色炸药。这种导弹体形小，当它飞入对方防空区域后，隐蔽到低的地面只有50米的高低飞行。对于这种又低又小的目标，雷达不易发现，目前一般防空系统较难对付。这种导弹最大的缺点是飞行速度低，每小时只能飞800公里，2,500公里的距离，航空弹道导弹需20分钟，而巡航导弹却要3个小时左右。

# 飞鱼导弹

飞鱼导弹是法国宇航公司研制的反舰导弹，可装载任何一级水面舰艇。该导弹系统是由一部雷达和目标指示雷达、速度测距仪、火控系统、烟筒制导等部分组成。它的发射准备时间仅为六十五秒，并可在六十分钟连续完成四次发射。飞行名制手操纵。弹体长五点二米。弹径约零点三四米。弹体呈圆柱形，头部尖弹形。起飞重量一百三十公斤。最大射程四十二公里，命中率一般超过百分之九十，可在全天候条件下工作。在大约八公里的高度飞行下，也不受海浪、云、雾等，雷达的影响。对方潜藏在与敌电波雷达的王主切换接收，它能在两秒钟发现并跟踪一个十五公里距离的一百平方米的目标，并能提供与目标相通的导弹所需的比例导弹数据，使飞行高度降到十五至十
