# 积极锻炼增加耐寒能力

冻伤虽然经常发生，并不同于不能适应的。长期生活在寒区的人们，像我国大兴安岭的鄂伦春族人等，经常在零下30℃的严寒下，露宿于终年积雪之中，却仍然安然无恙。就是因为他们在长期与寒冷环境中的斗争中，积累了丰富的耐寒经验，冬天饮水淋浴适应寒冷的抵抗力。如活动在黑龙江、吉林等地的渔民，冬天饮水中捕鱼，有的赤手提网作业数小时可见人体的适应能力有多么大。其中一个更主要的因素是通过锻炼的长期刺激，使他们体内产生了一系列适应寒冷生理变化。如遇冷时，代谢活动增强，产热增加，皮<|message|>血管反应迟钝，散热减少。因此，遇冷后体温并不致于下降，产生了对于寒冷的适应性。
