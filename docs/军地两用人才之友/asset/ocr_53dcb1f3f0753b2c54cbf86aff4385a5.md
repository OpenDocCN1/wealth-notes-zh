# 图27 托撑的安装

1.托撑 2.号板

合方法有两种，一种是换接，一种是钉灯。两者都可以，但有一点必须注意，托撑梁必须在安装前钉好上号板，即一木长条，与号板小条也通，这种木条要做成止住板面左右摆动作用而用钉系后钉拴，不马上拆开否则不方便。

框装法即用横梁等将框做成一个整体的框架。横梁较薄，宜选用桦柳等，组装后加固固定。加固时要先用扁铲或斧子在框头打一缺口，然后将框与治胶锯入。组装后也要校正对角线差和翘曲，以免安装镶灯时留下缝隙。应注意镶框要装上海面上的框架，待胶料干燥（约是夏四小时）晒爆后，晒干后再光亮面、楔子榫接等较多余的部分，将框面架上表面擦拭光亮，用木螺丝将台面固定。衬木螺丝之前要将台面底部找平，否则挤村不严密。台面固定后不要立即用细砂律光，因为其他部分还没齐完成，台面净光易弄伤、碰撞、给油工造成不便。
