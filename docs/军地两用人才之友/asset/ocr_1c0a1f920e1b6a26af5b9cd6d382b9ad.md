2. “几几作几”口诀。当被除数小于除数并且能除尽时，使用这种口诀。口诀中第一个汉字数字表示除数，第二个表示被除数，后面的阿拉伯数字表示商。“作几”就是直接把除数本档数字改成商。如五四的“五四作8”就是用5除4时，把被除数本档上的4改为商8。

3. “几几余几”口诀。当被除数小于除数在除法后有余数时，使用这种口诀。口诀中第一个数字表示除数，第二个数字表示被除数。一些阿拉伯数字表示商。使用这种口诀时，一方面要把被除数改成商，另一方面要把余数加在商数后一档上。如七四的“七四余5”就是用七除四时，把4改成5，把余数5按在下一档上。

4. “几几下加几”口诀。当被除数小于除数，除法后商与被除数相同并有余数时，使用这种口诀。口诀中一个数字表示除数，第二个数字表示被除数，后面的数字表示余数。使用这种口诀时，被除数不变，直接作为商，只是在被数在除数右边一档上。

在上述口诀中，分一定定商口诀和初商口诀。例如6÷3=2，为齐次商。32÷8=4，当8除3时，得3余6，这是初商，余6加下加1进8，进商1，这时商为4，才是对应商。
