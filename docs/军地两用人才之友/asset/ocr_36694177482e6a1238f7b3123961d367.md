# 薇

种植，薇要选择积水或田泥沉淀较深、保水保肥力强的池塘或沟洼为好。薇苗要肥多，应能足基肥。一般每亩施腐熟皮100担，再加人粪20担左右。薇秧要选择粗壮、整齐、节间，有两节以便于子蘖和抬秧，随挖、随运、随栽。并注意切勿沾染酒糟，以防腐烂。每亩种蔸250—400株。

栽种时一般行距5—7尺，穴距3—5尺，每穴窝全插一支，或亲蔸子插一支，深度4—5寸，斜植于沟内，蘸头稍深，后节稍露，蔸头（即蔸端）不要朝顶边，各行种植位置要互相错开，藕头相对互为对应，便于顶部分布均匀。栽后20—30天和40—50天，各施腐熟酸粪液（每亩30斤）一次。蔸发新后保水1—2寸，旺盛生长阶段加深到4—5寸，长藕阶段又放浅到1—2寸，最后保持土壤松软湿润就进行了。

薇有蝼蛄（菱根虫虫）和蛞蝓为害，防治蝼蛄每亩撒生石灰20—30斤，也可结合油肥撒湿水草，闷死害虫。蛞蝓每亩用6％氰性六六粉1.5—2斤，加水200斤喷杀，每周一次，共施两、三次。到了寒露，霜降时分，便可挖取。

# 菱

菱是深水作物，适应性强，只要底部松软肥沃，即便水深达1.5丈的高湾、沟渠、湖荡、池塘，都可用来越菱。

一文以下浅水面种植，多为直播。清明前后播种，每亩用刚发芽的菱种40—50斤，均匀撒入水中。大水面也可条播，行距8—10尺，根据地形划成几纵行，在行的两端插上竹竿作为标记，一人撑船，一人撒种。如果在深水种菱，最好将菱浸水育苗，每天播种150斤。可移栽5—8寸苗，为防止种苗适应深水长，当出水后再移入深水。移植从芒种到夏至移栽，先将种菱泡水8—10天为一朵，用小麻绳扎扎下蒂，放在船上用菱杖拨菱或搓，按行距7—10尺逐条撒入水底泥中。

菱菜一般不需要施肥。
