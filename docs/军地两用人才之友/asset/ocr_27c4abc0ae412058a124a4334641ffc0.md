# 化肥包装、运输和贮存时注意事项

| 注意事项 | 最易措施 | 注释 |
|---|---|---|
| 防潮、防水分 | 用防水物包装，如纸袋中再制薄膜，用塑料袋及防水塔。运输途中需防雨淋，合堆干篷、阴凉处 |
| 防火、防爆 | 严禁烟火，防晒防直射，不要剧烈撞击，不与易燃物相联系 | 晒破裂、硝酸钾 |
| 防止分解挥发 | 严密包装，密闭贮存，环境冷凉 | 如硫酸、氨化硫酸、液体氨 |
| 防腐蚀 | 对有腐蚀性肥料要防腐措施，加用塑料袋装 | 如硫酸、过磷酸钙 |
| 防中毒 | 工作时要戴口罩、手套，工作完毕要洗手。要用带标记，严禁误用 | 如石灰氮 |
