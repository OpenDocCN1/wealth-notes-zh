# 努力学习军地两用知识

# 李德生

近几年来，我们军区部队响应中央军委关于学习科学文化知识、培养军地两用人才的号召，出现了多年少有的学习热潮，取得了丰硕的成果。这项工作的开展，对调动干部战士自身国防和“四化”的积极性，提高部队的素质，改革教育训练的方法，稳定部队的思想，加强基层建设，都起到了很大的推动作用。同时，为干部战士回到地方广开就业门路、勤劳致富创造了有利条件，得到了地方同志和军属的大力支持；也丰富了军民共建精神文明活动的内容，扩大了我们军在人民群众中的影响。事实证明，学习科学文化知识，培养军地两用人才，对于军队、地方和国家文化知识、经济建设都有利，也有利于提高部队战斗力，增强军队的凝聚力，个人利益也得到保证地解决了起来，确确实实是一件利国、利军、利民的好事。它符合历史潮流，符合建军方针，符合广大干部战士和人民群众的愿望，我们应当满腔热诚地予以支持，因势利导地向前推进。

深入开展学习科学文化、培养军地两用人才的活动，是我军的优良传统在新形势下的发展和运用，是

新时期军队建设的一项重要内容。毛泽东同志曾经提出，要把解放军办成一个大学校，更好地发挥人民军队的作用。一九七七年，邓小平同志进一步阐述了这个思想，明确指出：把教育训练提高到战略地位，就包括把军队办成一个大学校，使干部既学会到现代战争知识，又学会到现代科学知识和生产知识，还要学会做政治工作和管理工作，既能在军队建设中发挥作用，到地方也能发挥作用，成为军队和地方都合用的干部。他们到地方工作或者回到地方工作，是个很重要的问题。邓小平同志的这些指示，意义非常深刻。军队其他领导同志对这项工作也都提出过明确的要求。老一辈无产阶级革命家的远见卓识，既是我们时在新的历史条件下巩固和建设部队的前进方向，又是我们做好培养军队两用人才工作的根本指导思想，我们一定要坚决贯彻执行。
我们正处在一个全面开创社会主义现代化建设新局面的重要历史时期。无论经济建设，还是国防建设，都需要大力普及文化，有知识的人才。各级领导一定要有爱才之心，有才之方，发挥创造精神，舍得智力投资。要从实际出发，因地制宜制宜，采取积极的办法，在时间、教师、教材、场所等方面为干部战士学习、增长知识提供方便。要不断分析情况，总结经验，采取具体措施，及时解决矛盾，推动这项活动的深入发展。

展。广大干部战士要立振兴中华之志，学建设“四化”之才，胸怀全局，立足本职，克服困难，勤奋努力。要在学好自己的专业前提下，兼学一些回到家乡能够用得上的专业技能，使自己成为：在军中似掌握现代化武器的勇士，到地方是建设富裕家乡的能手。

为了帮助大家学习军地两用知识，军区政治部研究室的同志选编了这本《军地两用人才之友》。这是一本多学科，两用皆有，文图并茂，通俗易懂的读物。它既可以作为授课的教材，又可以供干部战士自学参考。这本书的出版，将会对军队部队学习科学文化知识培养两地两用人才的活动，起到积极的推动作用。希望大家本着认真学习的精神，从中选学一些必须掌握的知识，在“四化”建设中作出更大的贡献。

一九八四年六月
