# 抢救

将溺者救上岸后，应先排出鼻水和口、鼻内的泥沙。方法是：救护者或躺坐，将溺者腹部放在自己的大腿上，使其头和胸自然下垂，用手搓拍溺者背部（图17）。若溺者咽喉牙齿时，可用手捏揉其腋部肌肉，使喉张开，以便吐出积水和泥沙等。若溺者失去知觉，除找医生外，还应在现场实施人工呼吸，进行急救。

进行人工呼吸时，应先使溺者仰卧，并在其腰部下面垫上衣服卷，把颈横开，拉出舌头，禁后救护者跪在头前，握其两小臂向后轻拉，放开头部，使溺者吸气（图18①）。稍停1—2秒钟后，再屈其两臂，放至溺者胸部，从两胸压其肋骨，使溺者吐气（图18②）。如此连续做下去，每分钟约十八次，直到溺者恢复自然呼吸为止。
