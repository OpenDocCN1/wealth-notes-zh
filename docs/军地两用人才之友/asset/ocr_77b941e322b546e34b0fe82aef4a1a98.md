# 针距表述当

针距，就是缝制时两个针孔之间的距离。针距调节器目前公制英制两种。英制针距橡自面上刻有“6～30”的字样，表示每英寸（约25mm）内有若干线数，如针距调节板在“10”的位置上，表示每1英寸内有10个线迹，数字表示每英寸，针距越细。公制针距调节板刻有“0～4”的字样，数字表示每针线迹的长度mm数。当针距调节板在“0”的位置时，缝制不针，在“2”的位置上，表示线迹长度每针线迹长度约2mm。由此数字越大，针距越细。叠加针距超过，脚线上的刺孔过窄，会缝制强针密度带来一定损伤。所以缝制时要选择适当的针距。

当缝制衣料时，都经常用的针距较大.均较宽。选配适当操作时根据需要调节针距机构。—一般说来，针距和缝线的密度为“15～20”个线迹/时，普通缝料“10～15”个线迹/时，厚料缝料“6～8”个线迹/时宜。

# 压脚压力与送布牙高度

压脚压力指送布时，链牙与送布牙之间所需的压力。压脚不仅用来压紧缝料，使缝料不易抽动，不会左右摆动，还可以配合送布布牙将布夹送缝制。在缝制过程重，由压脚压力不当或不均匀，轻微会造成缝迹不均匀。等等缝制被缝被压宽，大都由于压脚压力调节不当造成的。所以，调节好压脚压力对缝制质量有非常重要的关系。

压脚 弹簧的压力来自于压紧压杆加压入针机头发动机的调节压脚调节部和弹簧的强力， 压脚则与调节旋钮上， 调节螺杆拧入机头的螺牙部分受力， 压杆对压脚产生的压力增大。反之压力愈小。 调节压脚压力，要根据缝料的厚薄和布料的柔软度来测定。 绣得好，只需要尽量地推差即可，压力不可过太，如压脚压力过大与送布牙量出针面距离过近，缝纫则会缩短和底面咬破一条系布形缝迹的现象，使缝斜类现象；在缝制质料或多层缝制时， 需要适当增加压脚压力。送布牙露出面过高或过低也会影响针线不均匀的现象。 如果布面抽动不均，易于走，对准，针迹重叠和需密不均及缝科翘落等现象。

目前，有设有布牙升降机构的新颖家用缝纫机（如JB型），调节送布牙的高度更为方便。其它中，下三档，作刺绣或缝补时。
