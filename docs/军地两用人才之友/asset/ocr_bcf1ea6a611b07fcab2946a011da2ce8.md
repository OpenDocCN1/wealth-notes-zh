车架正面受重力碰撞，车架的上下管、前叉变形，时许，将自行车翻转侧放在地上，一人用力压车架平齐，脚踩车架后部，一人双手握前叉下端，同时用力拉使之回位。上述方法不能到正时，可将车架及各部件拆下，将一根硬质细圆木棒插入前管，两端绑米圈脚锁在老虎钳上压紧回位，将木棍套回车架后部，用力使其复原。或者将25毫米圆钢插入老虎钳上压紧回位。 如有前叉立管弯曲，可将立管夹在钳夹架弯曲定位，用铁棒插入前叉底部带动回位，前叉腿也可同办法办，双手用力一只只拉回原位。

# 家用缝纫机

缝纫机是由机头、台板、机架三大部分 成。机头是主体，结构精密灵活，台板是工作台面，形式多 目标；机架是机器的支架和动力部分。

# 缝纫机类型的区分

国家轻工业部1958年颁布了我国自己的缝纫机统一型号，是以两个汉语拼音字母和两个阿拉伯数字组成。如“JAJ-1”、“JBI-1”等。

（1）第一个字母代表缝纫机的用途分类
“J” 字是“家”用ර议拼音音“JIA”的第一个字母。
“F” 字是“服”务用的汉语拼音“FU”的第一个字母。
“G” 是“工业”用议拼音“GONG”的第一个字母。
（2）第二个字母代表缝纫机的结构、结构机种划分
按照各种缝纫机的不同机构，分别用英文的十五个字母表示。这些字母都表示一定的含义。如“JA”表示家用凸轮挑线，链 锁线，双线连锁<|start|>。每一台缝纫机说明书上都有注释。
