# 图二十二 滚 进

时出右脚，迅速突然地向前。跃进时，右手枪托（筒），目视前方，曲身快跑，跃进距离、速度根据敌火、地形而定，地面展开时，敌火越猛烈，跃进距离越高，速度应越快。通常每次跃进距离约为20～40步。停止时，应迅速蹲藏或卧倒。卧倒时，左侧向前一步，放左膝、左手，左肘的瞬间着地，或右脚向前一大幅，左手撑地迅速前进，弄好右侧击和继续前进的准备。

在开阔地放火下停止前，应进行近迫作业。要求是：卧倒后，把枪（筒）放在右近或上一处，胸侧手回圈伏，先从一侧由前向后探视，将土拨到前方堆成胸墙，一一微把好后，翻身卧倒于其内，继续挖掘一同，直至能掩护全身为止。在通常状况情况下，可用机枪、手榴弹、脚踢的方法抢ificio作业。操作时，姿势要低，动作要快，并且不断放战和准备跳的机会的配合。当邻兵发现在侧时，应主动以火力威胁坚强地前迅速支援邻兵，落于后于邻兵时，应迅速追逝。

遇到敌火封锁时，应使跳或利用地形地物躲跃通过。遇到敌机装射时，应利用地形地物制敌或加速前进，或按命令对空射击。

当听到化学袭击报警或遭到化学袭击时，应立即穿戴防护器材或用潜水面罩进行防护。遇有毒物质时，应穿戴防护器材迅速通过，或根据标示绕过。
