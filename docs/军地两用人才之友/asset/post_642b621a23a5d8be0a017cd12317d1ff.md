
能是有利的，现在生产上多采用先铺膜后播种的方法进行栽培。就是在铺好薄膜的畦上按作物所需要进行的行距用刀片割十字形切口，然后进行手播播种。种子播下之后，要用土覆上将播种孔周围的薄膜压住，以保护膜下的温度和湿度，防止土壤裸露风吹。当然，如果覆盖膜有孔洞，亦可使用点播器播种。

育苗移栽，除了散粮食、棉花及大部分果类都采用这种方法种植。操作方式的不同，也有先移栽定植后覆盖薄膜和先覆盖薄膜后定植幼苗之分。采用先定植后覆盖的方法，就是在苗子定植以后，栽苗子的位置覆盖，将覆盖膜成十字形的方式打开，将苗子从薄膜上的破裂处套入，清膜再铺平在地面上。这种方法不但容易损伤苗子的叶片，而且也不利于保持地面的平整。另一种方法则先铺膜后定植。定植或移苗孔是事先开好的，也可用铺膜刀片割开。将定植孔下面的土挖出、掀开。再将挖出的土覆盖，一同将定植孔和周围的薄膜压住，并使其周围平整，防止雨水将来从定植孔或播种孔流进内部形成局部高漫和病害。

播种时要求播量一致，深浅一致，覆土均匀。特别注意种子不要播在土上。

需育苗移栽的作物如蔬菜等，最好用直径为6—8厘米的营养土方育苗，移栽前注意控制水，降低温度，培育壮苗。移栽前还要浇水浸透营养土。定植或播种后一般不要或少浇水，以利地温上升，加速根系和苗土的结合。

如果某植株的莳黄超过60厘米，为了增强抗风能力，可以在畦面中央每隔一定距离用土压数点。

## 施肥

整地时宜施基肥，增加疏松、御肥及覆膜后及时检查修补薄膜破口，是塑料覆盖地面栽培管理中的两个重要措施。

（一）在整地过程中，尽量使面膜和基肥施用相结合。将定植的有机肥或返效应化肥作为基肥一次性施入到15—20厘米深的土壤中去，以确保作物生长各个时期的营养。根据土壤肥力水平及栽培作物的不同，一般应减20—30%氮素的施用量，并适当增加磷钾

肥。在生长期因覆盖了塑料薄膜，一般不便于追肥。但也可以通过叶面追肥或将随灌溉水追施少量化肥。

（二）在塑料薄膜地面覆盖中，特别是在早春多风的季节，要经常注意对薄膜的维护，及时检查破裂口并随即用细土压好。

## 温室类型介绍

温室生产是保护地栽培的一种形式。它可以为地创造适宜的栽培环境，使蔬菜按旺盛生长的要求。在外界气温低，自然条件不利蔬菜生产的情况下，温室生产可以不受风、雨、雪、雾、低温等不利自然条件的影响，获得蔬菜高产稳产，能够供应市场。温室生产可以越冬农业栽培区、实现四季北耕，增加蔬菜新品种，可以在冬季种植喜温夏季生长期长的蔬菜。温室栽培又与大棚及其它保护地栽培形式配套的基础。下面介绍几种常用温室类型。

## 加温温室

## 蔬菜无土栽培

在非土壤基质上，用营养液栽培蔬菜称为蔬菜无土栽培。此法是蔬菜生产工厂化的重要方法。现在欧美及日本都在积极发展蔬菜无土栽培。

蔬菜无土栽培可以是从育苗到收获的整个过程都实行无土栽培；也可以只在蔬菜生产采取无土栽培，然后将苗移栽到土壤中进行蔬菜生产，此法叫无土育苗。无土栽培需有较高的自动化程度，自动化的大型温室，有加热、通风、光照、喷雾等设备自动化程度高，要求条件较高。我们把这种方法列入科研项目，尚未大规模应用于生产。无土育苗要求设备比较简单，适合我国目前的生产水平。

蔬菜无土育苗也叫做营养液育苗，是以通风良好的固体材料作为基质和用各种养分元素配制成的营养液代替土壤的育苗方法。蔬菜无土育苗需要一些设备和材料。

育苗室是育苗的主要设备，供种子发芽出苗用。小型储苗室可用塑料、玻璃等材料组装而成，大型储苗室可用木板、铁板或砖制成。无论哪种类型的储苗室都要有加热设备，并能自动调温，保持恒温30℃。储苗室内设有苗盘架，其上放置苗盘，盘内盛放发芽的种子。

缢化室，用于幼苗缢化。设置苗盘架，将出苗的苗盘置于架上，经日光照射使幼苗转绿。缢化室要有加热设备。
成苗室，即保温温室。供缢化后的秧苗移播。室内设置有苗床、苗床内放入栽培基质。将转苗移播其中，然后，按需要喷洒营养液，直 到常规播于田园土壤中。
常用的栽培基质有炉渣、砂粒、稻壳等。
营养液是无土育苗所需营养的唯一来源，其成分除氮、磷、钾三大要素外，还有钙、镁、锰、锌、铜、铁、钼、硼、碘等多种微量元素。
蔬菜无土育苗具有很多优点。苗龄短，一般可比土壤育苗缩短苗龄15~25天；根系发达，苗株抗病力增强可提高1~5倍；苗壮、单株产量可增加10~6倍等。苗成活率高，单季蔬菜成本比上土壤育苗降低14~60％；提早采收期3~15天，并有增产作用。无土育苗可离专业化工厂、集中供应蔬菜秧苗。

据此后的管理方法：
（1）控制堆温。草堆接种之后，堆温逐渐上升，第四天温度上层高达50℃，下层达45℃。为了避免高温杀死菌丝，此时立即降温，揭开草被，撒水一次，喷水量每100斤草砖四、五斤，使堆温控制在40~50℃，使菌丝快长最长。

喷水方法为每天一次，两次，上午10点，下午3点，按上述喷水量喷。阴天少喷或不喷。用喷雾器来回喷雾，喷的伤一定要变成雾状，更不能喷湿，以免影响通风造成缺氧。下雨时，用草帘或塑料薄膜覆盖。雨停立即拿掉。

（3）鉴别与喷膜。草帘接种后用塑料薄膜覆盖，有利于保温保湿和提早出菇。塑料薄膜要根据具体情况而不是定期进行短期揭膜，每次揭开30~60分钟。揭开塑料薄膜时白天，夜间及光照强。如揭膜时间长了，草帘则易于干燥，造成菌丝萎缩，则在草堆周围喷一次薄水，待半小时后盖上薄膜或保温保湿。实践证明，出菇后的可用薄膜覆盖，以代替草被。覆盖了薄膜，可避免空气氧的影响。

为害草菇的病虫种类很多，主要病菌有菌核、主要害虫有菇蝇，还有害螨。防治这些病虫的办法，在草菇生产中应丸用1％的石灰浸液稻草，防治小⻬菌核，局部感染区可用1％石灰水处理。发现草菇蛆孑孑，应用立即杀除，局部感染区可用2％福尔马林消毒。对菌袋的防治，应在应答草菇分离时，防治棉雨落等。在草菇四周放0.5％敌敌畏稀释液或在草堆上铺上报纸，喷上糖水和敌敌畏进行诱惑诱杀。然后盖上塑料袋的防治，办法，在菌袋应用六六六粉、滴滴涕、鱼油(0.1％)防治天。但在草菇发菌期间不能喷药，以免害蜜。此外，用硫磺粉可杀除菇螨。石灰水、煤粉剂能杀灭菇螨。5％食盐和700倍的氢氧化钠能防治菇螨。

## 香菇

香菇在国内被誉为“蘑菇后星”。其蛋白质、脂肪、碳水化合物、矿物质、维生素等含量都很高。在室内培植香菇的方法有以下几点。

+   1. 配制营养料 配方有：(1) 杂木屑78%、麦麸20%、石荮粉1%、白糖1%。(2) 甘蔗渣湿75%、米糠24%、石膏粉1%。(3) 金针菇30%、木屑28%、米糠20%、石膏粉1%、红糖1%；(4) 稻草78%、麦麸20%、糖1%、石膏粉1%。
2. 菌种培养 培养料加水调制好后，进行装瓶、灭菌、接种(在9~10月进行)，窒室常温下培养，大约一个月左右菌丝即可以长满全瓶(菌丝优势的，可用塑料薄膜袋代替)。
3. 花直反处 好苗种后，将其从瓶中挖出。挖菌的工具、盛放及搬运外，更要1％的高锰酸钾溶液消毒。将挖出的菌株，在干净的塑料薄膜上，压成一尺见方、一半厚约的菌床。每个菌床需用已培养好的菌种10~12瓶。压块时，四周要轻压，以免漏境。
4. 苗床管理 嗅味可置于木条网架上，若大面积栽培时要搭架成床。尽量于菇床上培土，?每头至少要有一层隔层，否则会出现合在一起。本条棚的四周及棚盖均用塑料薄膜覆盖。菇床架的上下游须用塑料薄膜覆盖，以使压好的菌株能得到保温和保护。第一周内会长出大的菌新?丝、菌丝金枝节节而菌菇不?易被破坏，这时千万不能搬动菌?面，不必担心菌种会意外死亡。一周后，每天必须浇水

膜一次，如发现菌丝由红色小水珠渗出，应及时用脱脂棉或纱布拭去，否则菌丝块的表面和瓶盖边缘会被绿色硬壳，阻碍菌丝的形成。至三、四周时，在温、湿适宜条件下，会出现大量蘑菇。

5. 此菇容易当白色菌丝初露时，用木箱培植的，便要把瓶盖掀开，使其两面通透，或置于室内一室空间，用玻璃板遮盖的，这时应把薄膜提高，像喂隔窗养一样，也可把薄膜在室内四周挂起，每两块菌丝培植“人”字形，造成条水，使进菌丝长大极不匀称。

6. 菌菇污染 污染了往往会加快生长速度，不须另行处理。须待菌丝愈合好后再处理。栽培室要加强换气降温。霉菌产生在表面，未到料里，用PH 8～10的生石灰水撒净霉菌。霉菌产生较严重，已伸入料内，可以挖净霉菌，然后把被堵种植孔上。个别培植块霉菌发生特别严重时，只需将其用热水清洗冲洗，晾干，两、三天后再把杀菌处表面控制，补上栽培种。

## 平菇

平菇，又名白平蘑菇，也叫淡菇，北凤菌。是一个生活能力旺盛，适应性强，易于栽培，产量较好的品种。

适宜栽培平菇的材质较好，效果较好的基质有棉籽壳、木屑、甘蔗渣、麦草粉等。也可适当添加少量豆粕、豆类和花粉、树叶之类的植物营养粉。生料栽培不宜过烂米秆、麦秆等营养较贫乏的农作物产品。

+   1. 培养基配制 如利用棉籽壳作为培养基的，其具体做法是将新鲜棉籽壳和清水按1：2拌匀，浸泡30分钟，挤出多余水分，手握稍有水滴出但不成线为度。再将棉籽壳装入栽培内压实成形（规格为长1.2×0.9×0.3）。一头留有活扣以利脱模），然后接穴行足2×2寸深接种孔。

+   2. 接种管理 选择的菌种必须发育应旺盛，纯白、整齐。是菌形若松散不健全，呈松散状致发，侧眼而且纯白不能进行作业。挑选取菌丝，并将其填入接种穴中，再将紧周围的培养料，使菌料贴合，有利于发菌。一般500毫米稻草菌种可接两块菌种（10万瓶养分）。接种完毕，贴上蜡纸。上面用塑料薄膜覆盖严好，以利保温、保持培养。接种一个星期后，检查成活率。接种穴周围长出白色菌丝的成活，若

则需要补种。

# 3. 蘑菇培养 在菌丝生长繁殖阶段，不可过多或较长时间的揭开薄膜，以免造成湿度过小，影响菌丝正常发育，同时更不能在菌丝还未长满培养料前直接揭膜、直接喷水，只要过程稍养充分透水、地面保持湿润，蘑菇营养室，气温在15～20℃时，一个月左右，菌丝即可长满基质，直到菌落后出菇表面出现小白点时。

# 4. 出菇管理 当菌床长出小白点时，隔离加强管理。此时可将菌床揭开、揭开薄膜（也可搭架覆盖保湿），并适当喷水，以增大空气中的湿度。随著菇长的长大和增多，喷水量可逐渐增加。但在冬季低温和春夏季雨季节，应减少或不喷，保持出菇期间的空气湿度在80%左右。

# 5. 适时采菇 平菇的菌丝从初见到长成子实体，在适宜的条件下，约经7天左右，当子实体长到八成熟时即可采收。
