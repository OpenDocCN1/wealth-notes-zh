# 一般民用手表种类划分。

+   1. 手表
{ 机械手表
  普通手表
    二针表
    小三针表
    长三针表
  有附加装置的手表
  电机机械手表（电子表）
    电子振荡机构表
    电子音叉机构表 }

+   2. 杯表
{ 普通怀表
  二针表
  小三针表
  长三针表
  特殊怀表
  秒表
  有附加装置的怀表 }

3. 专业用表，如航空表、航海表、汽车表等。
