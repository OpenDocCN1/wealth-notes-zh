# 几种有效的土农药

| 药剂名称 | 使用方法 | 防治对象 |
|---|---|---|
| 狼毒 | 有效成分是一种生物碱。将狼毒根切成薄片晒干，晾晒过罗，制成粉末喷雾；或将狼毒根一斤加水30斤煮沸或浸24小时过滤，每亩喷200斤。 | 蚜虫、菜青虫、地下害虫等 |
| 苦参 | 含有苦参碱。苦参一斤加水10斤煮半小时浸设24小时，过筛滤液。具胃毒作用 | 柔虫青、蚜叶虫等 |
| 蒺芦 | 有效成分是蒺芦碱。一斤蒺芦根用水20斤浸他24小时，过筛滤液，其毒性作用 | 柔虫虫、蛴虫及其他夜间害虫 |
| 洋蓍 | 含有大黄素鞣、洋蓍毒素。一斤洋蓍加水5斤，浸泡1~2天，过滤喷雾 | 蚜虫、红蜘蛛、小麦蚜虫 |
| 胡桃《核桃》 | 有效成分为胡桃鞣素，核外青皮、树枝等药。一斤洋蓍水浸15~20斤，没没过滤后喷雾，或晒干磨粉使用 | 蚜虫、蚜害虫、蚜虫、蚜蚜、褐下害虫等 |
| 烟草 | 有效成分为尼古丁、烟碱、烟叶等加水20~40倍（药液若加硫酸铁处理），浸泡24小时后过滤喷雾（加入石灰可增加速效），或吸烟粉制成粉剂喷撒 | 蚜虫、红蜘蛛、介壳虫、潜叶蛾、稻飞虱等 |
| 除草草 | 有效成分是除草素 萘酸等一斤晒干晒加水5斤，煮沸小时或浸一夜，加水15~20斤喷雾 | 蚜虫、蚜害虫、菜青虫及小麦锈病 |
| 断筋草 | 根、皮含三硝基，一斤粉加水熬10斤，或晒粉泡加7~8倍水后成原液，再对水8~9倍喷雾，具胃毒作用 | 蚜虫害虫、食叶害虫等 |
| 大蒜、葱 | 3~5斤磨烂或，锈筛对水100斤喷雾。 | 对蚜苗、蚜、小麦锈病、土壤线虫病害有效 |
