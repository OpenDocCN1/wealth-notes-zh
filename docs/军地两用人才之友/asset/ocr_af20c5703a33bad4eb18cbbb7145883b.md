# H — 2 H 为刨。

勒子 它是在工件上划平行线得力工具，如刨料时工件的宽度和厚度；槽孔的位置厚度等都是用勒子划取。勒子的形状很多，做法各异，制作材料用普通软木，自由铅笔，勒子组成。所划线可用 2 毫米的铁钉来将板平而，更常用的办法是用 100 张纸的圆钉，将纸或四周容器薄，垂直嵌入木导板中一样划线，应注意像的倾斜一些用其划线。导板被吸木板时，在导板上钻孔，钉孔要略小于钉子的直径，这样钉子穿入孔内时有较大的摩擦力能否让钉子活动。这种勒子在科研时使用比较方便，如一个工件需要刨为 50 毫米宽，可将勒子的刃口与导板的距离取为 50 毫米。

墨斗 在较长的工件上划长线时多用墨斗。墨斗内有滚送墨计的丝棉（海绵、塑料泡沫也可），当线绳由轮子牵动通过墨斗时，细线上的就装满了粉笔，就是利用该装置将墨粉的线绳。线绳用 0.3 毫米（大的）细线。弹线时将板紧靠工件用于相对垂直提起。松手后线便在工件上留下痕迹。墨斗弹线主要的优点是长度长、省清而易如屋梁、横梁的纵向划线，板材纵向断时常利用墨斗弹线为好。

# 手 工 具

刨 它用来制作槽孔和刨槽。是由刨刀、刨把、铁被组成。刨的规格以刨刃口的大小为。

新刨刀使用前，必须切磨，背面和面前一定要切磨的平直，但其刃口处要求的两边拐角整齐，中问微凸，这样下刨快，而且开槽孔方便。

铲 铲和扁凿于一类类型，只是稍微于细，多用来修削木材，剩下木材的局部。因此要求铲凿必须具备轻便、锐利的特点，它的刀体宽度平，刀刃一般较窄小通常在 25° 左右，为了修刻时方便，铲的木把特别长，长约为 200 毫米，在修刻木材表层时，铲的平面朝下，角度近似刻削的角。

斧 斧的主要用途是劈砍和敲击。斧分为单刃、双刃两种。这两种斧各有刺利，双刃斧使用灵活，咬木量大；单刃斧导向性好，砍出的面很平整。
