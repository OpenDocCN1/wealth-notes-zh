# 日光灯结构图

1. 灯管 2. 启辉器 3. 镇流器 4. 开关

镇流器由铜片连成的铁心上绕以漆包线构成。在合上开关后，它与启辉器配合，在灯管两端产生一个很高的瞬间电压，使灯管发光。在灯管工作正常时，镇流器两端又消耗一部分电压，使灯管两端电压降至110伏以下，同时也限制了电器的工作电流。

启辉器，外壳是绝缘板胶按成的的小圆筒（也有用塑料制成），里面装有一个很细一小电容器，氖气中有一对双金属片触点，电容器两端与氖气管两端并联。

在配合日光灯开关时，启辉器中双金属片触点在220伏电压作用下发生火花放电现象，火花放电产生的高温使双金属片弯曲，两触点相接，电流通过。另一电点相接，火花被放电停止，温度降低，双金属片又恢复原状，触点分离，电弧断开。镇流器是在触点分离的瞬间产生高电压的。在日光灯正常工作时，由于启辉器与灯管并联，所以启辉器两端的电压也在110伏以下，热量对电触点间不再放电，启辉器就不再作用了。此时，将灯关下，对日光灯的工作毫无影响。

启辉器中的小电容的作用是减少日光灯发光时对电视机、收音机的干扰，它对日光灯本身是可有可无的。

灯座：灯座有两个，一般用酚醛塑料制成，起装灯管作用。

功率：灯管是发光体，瓦数分别有8、12、15、20、30、40瓦几种。它只表示灯管本身消耗的功率，而不包括镇流器所消耗的功率。如40瓦的日光灯，加上镇流器消耗的功率，总消耗约49瓦左右。
