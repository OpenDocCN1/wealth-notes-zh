# 计算器的输入与输出装置

计算机键盘上的键钮和控制台选择器是信息输入装置。键有一键一功能或一键多功能，因此，电子计算器的性能完备与否，不能单纯地看键数的多少，主要看各键是否能做较多的功能操作。

显示器是计算器的信息输出装置。它有两种不同的形式，一种是由通常七则管或“8”字管的发光二极管或发光二极管构成，另一种是由液晶构成。前者显示明亮，但在过于强烈的光线下操作反而影响结果，而且耗电大，后者节省并不发光，在常外光线的反射下反显而显示，因此适宜于光线强烈的工作场。 此外，液晶显示屏能显示出各种适配符号，而荧光显示屏只能显示出少量而简单的运算符号。

# 计算器的电源

电子计算器的电源通常有1.5、3、4.5、6或9伏等标准的额定电压，其中以3伏最多。

液晶显示的计算器采用干电池或扣式电池为电源。荧光显示的计算器制造成交直流两用，机壳的上面或下面侧面设有外接电源插口，可用电源电池、充电电池或电源转换器供电或。

干电池通常用锌锰干电池或钮扣式锌锰电池或碱性锌锰电池。扣式电池可采用银锌电池即氧化银电池（silver oxide battery）、碱性锌锰电池（alkaline manganese battery）或锂电池（lithum battery）。扣式电池的底部为正极，上盖为负极。
