# 1. 出车前要检查：

+   (1) 全车零部件是否拧紧牢固。
(2) 油料按规定配合，搅抖均匀，过滤后加入油箱。
(3) 轻载车检查曲轴箱润滑油是否充足。
(4) 链条松紧是否合适。
(5) 刹车、离合器复位弹簧是否灵活可靠。
(6) 轮胎气压是否充足。
(7) 起动后检查灯光、喇叭是否正常。
(8) 随车工具（套筒扳手、螺丝刀、活动扳手）、备件（火花塞、发火白金、汽化芯等）是否齐全。

# 2. 起动与停车：

+   (1) 旋动油箱出油口的油阀。
(2) 将油门把扳向外提到慢速位置。
(3) 压下化油器的起动体橡皮体或浮子下沉器。
(4) 停车与减速。

两用车不可用离合器处于分离不彻底状态来控制行车速度，这会使离合器提早磨损，应当用离合器小油门或刹车制动减速停车。在高速行驶时，防万万不可急刹车突然放气使起火的办法停车。因为在高速运转内机油箱环位都有碳化物积着，碳化物是非常坚硬的物质，遇到突然熄火冷却和凝固，会“拉缸”或“咬缸”。

# 各零件的调整。

新车出厂时，各部分是经过调整的，如行车正常，就不用调整。如发现运转声音与工作不正常，功率降低，就必须进行调整。1. 化油器调整：要求必须通畅，经济性能良好，用旋转化油器盖上空心螺钉，调整进油油，向下旋转进油少；旋出，增加进油量，功率增大。2. 点火时间调节：就是调整点火提前角，点火时间准确与否直接关系到起动难易，功率大小。3. 离合器调节：操纵手把放松时应有一定自由间隙(自由行程)，一般为2～3毫米，这样才能保证离合器彻底分离与结合，旋转钢丝
