# 电唱机的使用与维护

电唱机的合理使用和注意维护是提高音效效果和延长使用寿命的重要条件。

注意电源电唱机电源变换插头一般都要 220 伏特上，若当地电压有110伏，必须更换电源变换插头，否则机器无法正常工作。

注意放置 电唱机应放置平稳，不能摇动，否则唱盘上会出现动影响放音效果。

注意防震 人的走动与外界振动，都能引起电唱机的振动。严重时，使唱头跳出唱片的音槽而造成唱针与唱片的损坏。目前生产的电唱机一般都在面板上安装防震装置，并用螺丝固定。如图所示，使唱时应将防震弹簧松起，使防震装置运作。不用时，或常需要放置，应将防震弹簧绕紧，防止面板松起。必须注意，即使装上了防震装置，也只能减少震动对电唱机的影响，在使用过程中仍要注意防震。
