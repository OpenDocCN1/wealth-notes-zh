# 抛射式喷火器

"抛射式喷火器"最早是由美国研制成的，目前，"抛射式喷火器"按使用的燃料剂，主要有两类：一类火焰弹以催裂三乙基酯为燃料。这种燃料的凝点为-45.5℃，沸点为186℃，燃烧空气能自动产生1000℃以上的高温，遇水会燃烧，如因作坊内火焰被蒙蔽，不能点火机动，一旦燃烧，就很难扑灭。如美国的M20A1火焰弹，就装有这种燃料。第二类以黄磷或红磷作燃料，黄磷是一种蜡状固体，在44℃时开始发烟，280℃时产生。它与空气接触会继续氧化而自燃，产生火焰，并带有白烟色，危险和剧毒作用。黄磷对人的皮肤有强烈的烧伤作用，伤口很难愈合，它还能引起牙疼器官、肌肉萎缩等症状。苏联的"抛射式喷火器"就采用这种红磷剂。西德和其它一些国家"抛射式喷火器"多采用红磷作燃料，这种红磷并不自然，但可以使它变成黄磷而自燃，其燃烧特性和黄磷相似。
