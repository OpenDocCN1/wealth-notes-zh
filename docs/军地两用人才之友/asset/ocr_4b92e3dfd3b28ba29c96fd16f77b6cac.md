# 基础埋置深度的确定

从设计地面到基础底面的距离叫做基础埋置深度。基础埋置深度的大小，对节省柱的造价、施工技术措施、施工期以及保温房屋正常使用等都有很大影响。基础埋得太深，不但会增加房屋造价，而且在有些情况下，还可增大基础的沉降、埋埋得太浅，常又不能保证房屋的稳定性。在确定基础埋置深度时，在安全可靠和最经济的条件下，确定合适的基基础埋置深度。

现以下列五种典型地基为例(图6)，说明基础埋深的确定原则。

第1种情况。在地基压缩层范围内由均匀的压缩性较小的土构成。这时基础埋置深度由地基土的冻胀性、房屋用途、作用在地基上的荷载以及影响最小埋置深度(一般不小于50厘米)等条件确定。

第2种情况。在地基压缩层范围内土层由均匀的高压缩性的软土构成。如果这种软土层埋置较深，地基内不能满足变形要求时，则需采用人工地基，必须时加强上部结构的刚性。这时，基础埋置深度应由地基土的承载性、房屋用途、作用在地基上的荷载以及基础最小埋置深度等条件确定。

第3种情况。在地基压缩层范围内由两层土构成，上层是压缩性较大的软土，而下层是压缩性较小的良好土。在这种情况下，基础埋置深度应根据上层软土厚度和谐土层的承载力等因素确定。
