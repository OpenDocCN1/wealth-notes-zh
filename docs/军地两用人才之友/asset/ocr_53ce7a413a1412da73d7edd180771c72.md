为了使毛石墙平直美观，在墙角处要竖立辅杆，砌时上挂水平线，逐皮砌砌，转角处采用砖砌角楼搭接法，即先把抱角石砌成五进五出的“丁”字形，然后根据水平线每间距中毛石墙。

# 砌毛石墙应注意几点：

+   （1）砌好的石块不要震动。

+   （2）如有洞口、沟道，应作预留，不得后凿。有沉降缝处应分两段砌筑，不要搭接。

+   （3）基础砌完后要随作回箍子，基础面要抹找平层，弹好墙身线砌毛石墙基础。

+   （4）毛石砌筑完要用水草等或麻袋盖严养护。

+   （5）毛石墙的砌筑高度不得超过1.2米。

+   （6）接茬时要有茬高的石块，要清除砂浆，用清水冲刷后再砌。

+   （7）每砌一步架要找平一次，封顶时要用1:3水泥砂浆抹平。

+   （8）砌完皮数墙，墙面要基本平整，均匀缝的缝子要高出毛石墙面5毫米左右。

# 小型构件的安砌方法

目前常用的通用住宅设计图集，采用的木门窗，洞口都是用标准混凝土预制过梁，代替了砖砌过梁，节约了木材，方便施工，也利于施工进展。

使用门窗、洞口的混凝土小型构件过梁，是由施工方法来决定的：后塞口的门窗是先放混凝土过梁，先立门窗则要后放置混凝土过梁。如采用钢筋一般都是预留窗口，后安窗扇，故也须预先安放混凝土过梁。
