幼林长起，新植幼林要及时除草、灌水。需水，栽苗当年不修剪，修剪缓和根部新梢，生长度和修剪间隔相同减薄密度。定植后第一年不可修剪，10年生以前保留树冠长度为树高的3/5～1/2，10年以后保留树冠长度为树高的1/2～1/3。夏季修剪伤口易愈合。修剪时不留桩，要剪切平滑。

# 泡桐
桐

泡桐材质较软，防潮耐热，不翘不裂，是做板空型、胶合板、乐器、箱柜的好材料。桐木是我们国家重要的出口商品。泡桐易繁殖，生长快，成材早，被精管理时，7～8年就可砍伐利用。

# 育苗

常翘埋根育苗。即在拇苗时，搜集遗留在圃地的断根或苗木假地下部根长作为地种。种根含水较多，应埋贮1～3天，否则埋下容易腐烂。

春、秋育苗种。为带根苗长3～5寸的小苗，直接埋地埋入整好的苗圃内，种根上端与地面平齐稍微低于地面，上土埋实成一小土堆。每亩1,000株左右。露天后播水。出苗后每株保留1个壮秧。
