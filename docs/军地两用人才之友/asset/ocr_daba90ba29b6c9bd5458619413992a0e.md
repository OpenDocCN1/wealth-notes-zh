和加强的火器数量而定。连通常编为三个四小組，每组三至四人，火筒皆由班长直接指挥，値副每人每组都具有独立打退突的能力。

# 二、拟定任务，进行试才任务。班长擬定任务时，首先到定任务，指定方位，然後分明。

+   ①敌前沿壕克、装甲战车、火力点的估计，
②上部的工作简，
③弹药的任务，运动路线及冲出突发阵地，
④尾随火器的位置、任务和支援的方法；
⑤支援火器、坦克和友邻任务，
⑥进行协同的方法。
⑦信（记）号。

班长确定任务后，应进行战斗动员，说明战斗的重要性，提出完成任务的要求，鼓舞斗志，坚定必胜信心。情况许可时，应发扬军事实事民，讨论如何完成战斗任务。

# 三、准备好作战工具材料。装（组）应根据任务和上级规定，准备好弹药和打击武器。防御于、防化学等器材。为进行打击的需要，班应有四至五种进攻武器、器材，小组应有两种以上。战士应有一至两件。器材的携带要便于行动和战斗。班长及时检查准备情况，完成战斗准备，向排长报告。

# 迅速撤离接敌

班（组）在接敌时，应善于利用地形地物和火中顺、减弱、转移或躲避火力威胁。都应适宜等到时机时，灵活地运用各种战术队形，采取撤离。迅速投入战斗，全班同时或各班组相继冲破进攻，望注意保持前方与后方（东）长的联系，迅速撤离地形地势出突发情况。
