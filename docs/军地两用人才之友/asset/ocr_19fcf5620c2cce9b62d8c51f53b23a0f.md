增。选用电度表要根据用户用电情况加以确定。用电负荷的上限应不超过电度表的额定容量；下限不应低于电度表允许谦誉规定的负荷电流值。例如，一户居民家装有三个灯泡，分别是15瓦、20瓦、40瓦，又装有25瓦台灯一个、40瓦电视机一台、100瓦洗衣机一台，其用电总安装容量的计算公式计算方法；

```
I = P / V
```

```
I = (15 + 20 + 40 + 25 + 40 + 100) 瓦 / 220伏 ≈ 1.09 安
```

根据以上计算的结果，还应该考虑备各家电、地，这户选用电度表，最好是1.5安或2安级。额定电压220伏的单相电度表。电度表是由电气元件和机械元件所组成，在制造和正常计数过程中，由于物理特性不同会造成电度表本身的误差。在正常情况下，本身误差为±3％。另外由于电压改变、频率改变、温度、倾斜等影响所产生的误差，新为附加误差。这些误差是常常条件不同而有所不同。

必须注意，不按实际用电情况选用电表壳，会因电度表本身规定的基本误差范围出现不符合要求的现象。因为电度表的规格越大，规定允许误差也越大。如装得大，这户居民多付电费；如装得小，误差减少付费少。另外，电度表的容量选得太小，电度表容易被烧坏，太大则可能里检测不到。
