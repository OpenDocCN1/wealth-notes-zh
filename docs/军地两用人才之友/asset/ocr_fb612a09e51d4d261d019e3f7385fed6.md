# 家用电度表的使用、读数和用电度的估算

# 家用电度表的使用

1. 家用电度表装好后接入负荷，转盘的转动方向与所标定的箭头相同一致。如果采用互感器的电度表，应检查一下接入电度表的电压与电流的相位是否相符。例如 A 相的电压和 A 相电流接入电度表相应 A 相一根元件，B 相与 C 相也同样如此。Ic 外还要注意互感器的极性。

2. 有些电度表在使用中发出一种易察觉的嗡嗡声，这是由于电度表内交变电磁场作用的缘故。这种声音并不影响电度表的准确度正常使用。

3. 正常的电度表在安装后，如无负荷（全部电灯关闭），表内圆盘应会微微地转动，但不会一直转，即会停止转动，这是正常现象。

4. 对用户一户用电或一楼每户的用电负荷的总数应不超过电度表规定的许可容量，如果超过时，应由用户办理增容手续。
