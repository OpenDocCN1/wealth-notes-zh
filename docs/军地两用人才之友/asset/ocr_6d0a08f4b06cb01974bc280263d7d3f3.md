# 三相异步电动机的故障及排除方法

| 故障 | 原因 | 排除方法 |
|---|---|---|
| 电动机不能启动，有嗡嗡声 | 有一相线路不通或单相运行 1. 缺电容熔断。\n2. 保险丝熔断。\n3. 开关或起动设备有一相接触不良。 | 1. 修复线路。\n2. 更换熔丝。\n3. 查出故障。 |
|  | 旋带机机械卡住。 | 检查排除。 |
|  | 电压太低。 | 1. 检查线路、导线接头、起动电压降低，线接好。\n2. 将每相接成电动机构成星形。\n3. 电源电压低，可将变压器调高压。 |
|  | 电动机有一相绕组断路。 | 用万用表或试灯方法，短路绕组，检查修复。 |
| 起动器或过载保护器熔断 | 开关至电动机的线路有短路。 | 拆下开关机接线头，检查绝缘，消除故障。 |
|  | 定子绕组有一相烧坏。 | 判别烧坏端，改线连线。 |
|  | 定子绕组烧坏或接地。 | 找出故障点，重新绕线或另换绕。 |
|  | 旋带机被卡住。 | 检查维修，排除故障。 |
|  | 保险丝太细。 | 换装适当保险丝。 |
| 起转或选转缓慢 | 电源电压低。 | 检查线路。 |
|  | 三角形绕组的电动机接成星形。 | 检查接线检查。 |
|  | 转子滑环弹簧条脱裂。 | 检查修复。 |
|  | 定子绕组有一相局部线圈烧坏，此时电动机不平衡。 | 检查电动机各绕组的极性。 |
