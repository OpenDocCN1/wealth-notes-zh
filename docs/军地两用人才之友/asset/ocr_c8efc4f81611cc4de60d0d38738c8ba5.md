# 篆刻

# 篆刻与书法的关系

篆刻与书法都属于造型艺术的范畴。篆刻是书法艺术通过刀刻以后的再现。因此，书法是篆刻艺术的基础。篆刻也和书法一样，具有实用与艺术的双重性。我们日常社会中使用的印章（如木质图章、橡皮图章等），大都属于实用一类，并不具有艺术性。只有用优雅的书法组合为一个完美的构图，并用巧妙的刀法刻出来的印章，才能称作篆刻艺术。篆刻上的书法，晚要求每个字都安排得很妥当，又要将全部文字组合在方寸大的“小天地”里，构成一个完整的和谐的整体，因它具有了优秀的书法、章法和刀法的这三基本条件。篆刻艺术所采用的书体，以篆书为主，因为篆书的结构变化较多，富于装饰趣味，用篆书字体入印，能产生绘画般的效果。如果采用隶、楷、行书体入印，也未尝不可，但艺术效果要差得多。所以，有志此道的同志，仍应从先学习篆书入手，才是正确的途径。

# 篆刻的布局

篆刻艺术是要在方寸大小的范围里设计出一个完美无缺的“小天地”。由于卧蝇编版较为精致，稍微有点毛病就很容易发现而影响美观不易斧正，因此篆刻组版必须十分讲究。总的来说，印章要做到线条分明、气势贯串，疏密配合、虚实相衬，也即是要在不统一中求统一、不平衡之中求平衡。印章的布局可分为两类：
