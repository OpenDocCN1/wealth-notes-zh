20厘米。模版要比接口小，大的一头宽为20厘米，小的一头宽为19厘米，模高为5.5厘米。木模宽的一边放成能推动活动板，以便倒出装培块。当培养室在木模中压实后，抽掉活动板，套上聚丙烯塑料袋，再将塑料袋连同培养包个身，在木模上轻拍一下，使装培块落在塑料袋里，抽出木模，并把塑料袋捆接到塑料袋的顶，袋口扎严后就可进行消毒。

3. 消毒。常压蒸汽灭菌从100℃开始计算时间6小时，如果高压灭菌，在孢平功率为1.5公斤的底下，灭菌1小时。

# 二、接种

消毒完毕，将装培块取出，冷却后迅速接种棒。喷1％浓度的酒精。经近30～40分钟后就可接种。接种前，操作人员先用肥皂将手洗净，擦干，再用75％酒精擦手进行消毒。瓶盖用75％酒精擦拭。接种应放在菌种操作进行。取出菌种，将成菌种的瓶盖绑扎好，取下瓶盖，再把麦皮的膜剥去，然把接种针切割成如针尖大小，装种时在接种块表面，再用塑料袋把装培块的袋培块包扎好，就可放入室内培养，如温度适宜（30℃左右），只要20天菌丝就能以表面长到底部；若在25℃左右时培养，发菌的时间就会延长。

# 三、长平过冬的事项

把菌块培养好的装培块取出到塑料袋，以后可放在室内培养，也可放在室内养护。在室内培养的，栽培袋要经常喷水（温度在85％），每隔一定时间，要在袋面上浇水或喷水。从长耳到采收，一年为10～15次。如在室外培养的，要选遮荫平坦、避风、接近水源的地方，搭好简易棚架，并在封口或塑料袋料上。既利于透过光线，又能保持较好的通风条件，促进蘑菇生长。在栽培期间要经常保持装培块湿润。当耳长平时，则以手摸耳片边，若有硬的感觉就要及时喷水。或水的次数要视天气情况而定。晴天多喷，晴天多喷。如晴天又有风要增加喷水量。阴天少喷，雨天不喷。
在栽培过程中，应把握好每个环节，力争不感染杂菌。一旦发现杂菌污染，及时用PH 11左右的石灰水擦换杂菌。如杂菌已进入培养料，应予以挖除，以防蔓延。第一批耳采收以后，可封扎栽培箱缝一些，让菌丝繁殖，然后喷水，使菌块长出一批耳芽。
