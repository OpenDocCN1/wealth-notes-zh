# 乱送或跳动

使用缝纫机，有时会发现驱动机器很费劲，和提起压脚用手拨动上轮时感到张缓不均匀的情况，甚至在声音较高大并带有噪音，这是机器运转方面不良的情况。其原因：

+   1. 保养中做脏，零件受润滑影响正常运转，再严重的锈蚀将使机器报废。
2. 运输不稳，导致机器受损。如果上轮外轮经受压力冲击发生严重偏摆，可用木锤敲击偏侧的相对方向加以纠正。
3. 缝部部分内有横丝、油污、线头等杂物所致，有的由于没有安装正确或装设过松导致，也有产生运动负载的现象。
4. 送布牙与针板露出针板而太高以及针板牙槽与送布牙齿相互干涉。
5. 请用缝纫机润滑最易引起机器运转沉重，主要是运转零件断裂油或生锈。
6. 传动皮带太紧而主轴轮受的拉力过大。相反，皮带过长，主动轮摩擦力减小就会引起逆向的毛病。
7. 别的修整的机器发生机器运转沉重现象，一般是机头底板下面的顶尖螺丝或锥形螺丝地方过紧，但也可能是机架下的顶尖螺丝和圆轴承螺丝过紧的。这情况以松紧调适适当为止。

发条的放力矩，持续时间短，而且矩大，不能直接与擒纵调速机构联系，只有通过传动机构中一组齿轮的作用，将力矩变小平稳的持续不断地传递给擒纵调速机构，同时也借助传动机构把擒纵调速机构的角位移，分别转换为秒针、分针和时针的位移，从而达到计时目的。

④擒纵调速机构。擒纵机构一般是由擒纵轮、擒纵叉、双圆盘以及叉限位钉组成。它是利用擒纵轮齿与叉叉的“擒纵”动作，以及叉头与双圆盘的相互配合，将发条力矩经调速部件进行持续的运动，同时与调速部件配合，使发条力矩均匀地放出（见图5）。

机械手表的调速机构由摆轮、游丝和快慢针等部件组成。快慢针用于调节摆丝的使用长度，摆轮摆丝的使用长度相配合以获得一定的摆动周期—频率。一般表的频率为18000次/小时，21600次/小时等。

游丝的内端通过内桩装入摆轴，外端通过外桩固定在框架板上。当摆轮受力偏离平衡位置时，游丝就被扭转而产生恢复力矩，外力消失后，摆轮受到两个力矩的影响，即摆轮的质量与游丝的惯性力矩，游丝恢复力的力矩决定摆轮的旋转方向。摆轮摆动时惯性力矩与游丝的恢复力矩不但处在摆轮运动的进程，而且互相转化，使摆轮能量不断转化为游丝的恢复力矩，到后来取得平衡位置时，摆轮就由游丝恢复力矩支配回摆，当游丝回到平衡位置时，恢复力矩完成

# 手表的使用和保养

+   1. 不要随意自行开启后盖，以避免尘、纤维等物进入表机，影响手表正常走时和破坏表机的防水性能。
2. 手表虽有防磁、防震、防水的性能，但在使用中仍应避免剧烈震动，如打锤、搬举、打球等。如果没有防震装置的手表，则更为严重。轻轻佩戴手表，手表要定，震动厉害者会使摆轴损伤，使手表走时变慢，或时走时停。
3. 应避免与水直接接触，以免水蒸气侵入内机，使手表字盘面变花、发霉点，机件生锈受损。
4. 每天定时上足发条。一般手表，上满条数为 6 1/2 圈至 7 圈，工作 24 小时后，发条刚刚好转动了 3 1/2 圈。上满发条便摆轮经常在较大的摆幅下工作，走势便稳定。
自动手表，在自动机构的作用下能自动上条。放置后仍可继续工作，但也应以佩戴时的具体情况上条，以补充能量不足。
上条应使摆轮单向转动，尽量不要双方向空转，以避免两头橡胶圈增加不必要的磨损。手表使用时间过久，感觉轴轮上条紧，可在弹簧内加些润滑油。
5. 按针微调原络可均，倒拨针时，秒针有可能停止或倒退，这是正常现象。将针轴推移后，秒针就会转会转正常。拨针时，将柄头拉出，拨针完毕后立即回原位，否则针机便会停止。
6. 发现指针走时不准，时针、分针不走，拉出柄头拨针时比往常松动，则分条松动，只要将分条拧紧一些便能正常走动。
7. 佩戴手表时，手上的汗水对表壳有腐蚀作用。特别是半钢表壳多镀铜的，长与汗水接触，容易腐蚀，应经常用软质布擦去汗水或在运动后上表时，以防止汗水使表。
8. 手表长期存放不戴，应每月定期上一次发条，使机件不致长期处于停止状态，以保证表机的运转性能。手表不宜存放在潮湿的衣物柜内，以发条油保持。

手表常见故障排除
手表零件细小，结构复杂、零件精细。一只停走的手表，首先检查故障原因，不要急于修理。表揭走未必都是表机的毛病，有时是表扣或表壳的毛病，只要小修，便可排除故障。

一般常见的故障维修方法有：

1. 停表、手表走时不准的原因很多，有时是由于表盘面和表针的故障。应首先检查表盘面和表窗部分。拉出钢轴，扞动柄轴，查看三指针（时针、分针、秒针）相互之间有否碰擦，秒针与鼓盖之间有否无碰擦，再观看表盘面有否松动，观察时针。秒针转动时，如时针与表盘面的距离有一边大一边小或变硬，则出钢轴偏曲。上述故障维修排除的办法：

+   （1）调整三指针相互间的距离。
（2）调整表盘孔，使它正对时轮中心。
（3）发现秒针等时应铅直，如折断了应配换，当秒针管变形时应更换。

如表盘面未发现故障，可启盖后检查一下，如果是游丝摩擦摆轮或游丝碰擦链，应将游丝调整平正，使它上不碰夹板，下不碰摆夹。经调整平正后，手表就能走动。还有一些其他的故障，如摆轮摆动的故障、轮系的故障、能动机构的故障等，比较复杂，没经过一定的训练，学习，不易掌握，暂不介绍。

2. 走时快慢的处置。
手表靠精密的计时机构，但由于表机的种种原因，常会引起走时或快或慢。遇到这种情况，启盖后可见摆夹板上刻有“+”和“−”的符号，如果是走时过快，就将快慢针往“−”方向调整。走慢就往“+”方向调整。一般每调整一个刻度为60秒。在没有仪器校正时只能按经验调整。

# 3. 玻璃盒内雾气的处理:

手表的玻璃盖上出现雾气和水滴，说明表机内已渗入水分，在温度高时变成水蒸气，附着在玻璃盒上，玻璃盒的温度较低，形成雾气和水珠。发现雾气和水现象要及时排除，以免机芯生锈和表盘变色。
排除雾气先将表与外界水源隔离，打开后盖，用对表开启过，首钉打开2~3颗拉掉螺丝，若有拧干无绒丝的，用夹子压第一层，把表头拉出 来，表机取出，用干净布擦干雾气后烘干除湿，再装上表机。

4. 针头发紧，不易旋转。由干汗水渗入使柄头弹簧头圈脱落或生锈，影晌柄头受力而不易旋转。为使柄头旋轻松转，顺开头发，先用擦绢干清洁柄头周围，放一点硅脂增加润滑就可顺利发条：

5. 发条一重上不紧的几种原因。螺爪弯等形成断折，螺钉松蚀。折断或变形，大铜轮轴针旋转或没有紧靠，钩钢轴线扭坏，以致不能上条或拨针。

6. 上条轮松弛。原因，螺爪齿张大宽，不能灵活转动；条盒轮没有清油或太脏干鳄生锈，横轴弯曲压紧表芯，柄头防水圈太紧，套着表柄轴等部件，转动就不会灵活。

7. 拨针困难。原因，小钢轮螺钉过紧，玻璃离合能或拉挡螺钉松动，分辫过紧；跨轮压体螺钉松动，使被钉轮在上位移。

# 电子手表的性能与保养

液晶显示石英电子手表用非常敏感材料制成，无须考虑防磁。这种表虽有防震防水性能，但应当尽量避免较大震动或沾水，特别是按钮不能进水。

电子手表温度在25～28℃时，误差计时误差在1秒以内，当温度降至0℃以下或升至50℃以上时，每昼夜会慢两秒钟。当温度高达到80℃时，液晶板会变黑；温度降到0℃以下时，液晶板就会失去显示作用。因此，到冬季，电子手表只能放在腕上，寒人体的温度来保持它的正常状态。另外，高温还会过热造成电池漏液，损坏机心。

电子手表电池一般可用一年以上，但照相灯耗电量大，开关一次秒钟所耗电量相当于计时用一小时以上。电池快用完了，灯光会变暗，或在开关时，数字会骤然变暗甚至消失。更换电池，如不懂得表技术，放松表应安装。由于电池没有标准化，牌号很多，不可随意采用。

使用电子手表，按钮不可用力过猛，以免失灵；液晶板使用 5 ~ 7 年需要更换的。电池无电要及时取出，以免腐蚀使机心。发现灯不亮，按钮失灵，计时突然有较大误差时要及时修理，可能是元件焊接点脱落或脱焊。

(2) 走针部分；中心轮轴是三轮带动的，通过中心轮轴的转动（在盘针上能看到针的走动），来完成针表的作用。这部分共有三个组，即中心轮、驭轮、针轮。中心轮轴上有两个轮，一个是小的分轮，一个是大的中心轮，它们和二轮轴轮系在分轮活动系，下而有 一个针锁簧，利用钢丝弹簧向上弹力把中心轮扳紧，故在拨针时 分轮能够放松，中心轮在原地不动，因而它是不起二轮带动作用。虽下 面还有一个针轮的挡针点的，叫挡闸锁机，另外还有一个等曲弹簧于， 还有一个针是打半点的，在相对的地方也有一个钉闸锁弹簧，分轮的齿 轮等与寻轮齿的三分之一，而时针齿轮等于时针轮的四分之一，故 中心轴转12周，时轮转一周，时轮的圆形齿在在时轮面上。分轮是放 跟齿轮方齿安在中心轴上，拨针时注意在打点时把针拨向十二点，否则 则在三、六、九点打点，因它为四方形，可以指向四方。

(3) 钟器部分；钟时的准确性主要是靠游轮、擒纵叉、摆簧、

撞锤等零件，它们都有相互关系。和击锤、合奏的原理是相同的，只是机芯制造不同。悬挂钟的擒纵机构只有冲角，没有锁角。因此，把它叫做“反式冲击机构”。当卡子随着缓绳轮尖端到反锁冲击作用，造成缓绳叉与拖轮锯齿尖发生摩擦，这就是我们听到的滴答滴答的声音。

擒纵叉是钢货的，有进角、出角，需要有准确的角度，因为它是钟时最关键的一个环节，如果角度不对，使擒纵叉和钟轮接触面大而产生阻力，钟的声音不均匀，时走时停，接触面过小，而钟的摆动难以起来，也不能。

摆轮：上端是一用一根钢片，下端是一块较轻组件。钢片的弹力大，稍有差距，摆力过强，摆幅不稳定，不会一致。经过钟的摆动。下端的铁丝是摆轮的环，它的长度配合摆力较慢而，是走慢整走时快慢的一部分。钢片摆锤的弹力是靠擒纵叉的冲击推动，使它加大动荡力。

钟摆，一般是用铜，绕做成圆扁形的，这样看起来可以减少空气阻力，其重量大小是配合击钟力确定的。从轴的中间穿过直立丝杆，在下方有竖立和摆动可用上拖盘来控制快慢。
（4）打点部分，共有四个零件，主要是减低各轮的运转速度，使打点有节奏。其原理是利用风轮片和空气的接触产生的阻力来控制速度。打点机阶梯以上五个轮外，还有一计数轮片安装在前面板打点轮的上面。

三轮上附有跳爪片是使开阀子起落作用的，缺口上有两个钉是拨轮轴用钉点。
四轮上有一个杠状的钉子，是打点完毕和开关后使控制轮子不能自转。

榫子，是结合在中心钉子端的，也是由走时和打点直接取得联系和发生接触的关键。

闸闸子，拾合闸子，有三个钩,即: 拾闸钩、回点钩、拾钩钩。拾闸钩和是挡闸接触后，开始起拾闸作用的。回点钩和开阀刀接触后拾闸作用的。另外，打点不对，可以用回点钩校正打点用。拾钩钩在开

# 2. 闹钟的结构及工作原理

目前我国生产的闹钟是统一机构，构造较为简单，多是“销钉式”的。

基本结构由二大部份组成：
(1) 能源机构：是发电驱动力来推动其它轮子。由走轮轮（发条轮）、二轮、三轮、四轮等集合组成，走轮轮中间有一个条轴，轴上有十挂钩，钩套紧贴的地方孔，外条套，钩在发条立柱上，发条上面有一个齿轮（棘轮）在旁边装有棘爪（项头的千斤钮），还有一个棘爪簧（千斤锤簧）紧贴在棘爪上随着上拨活动，发条回旋，棘爪

由钢丝弹簧紧靠着擒纵角，顶住作用，只能前进不能后退，向一方转动，从而利用发条与弹簧推动二轮、三轮、四轮等转动，这就是发条弹簧力作为动力的原理。

# (2) 传输轮系

由发条发出的动力经过二、三、四轮传到擒纵机构上叫传动系统。传动系统共有五个齿轮，一个伽锁叉。走头轮齿54个，二轮齿54个，三轮齿40个，四轮齿40个，五轮（擒纵轮）齿15个。

上紧一次发条走36小时，则头轮能转6圈，它的周期为0.6秒。发条上紧时，摆轮旋转最大为260度，24小时以后，旋转就小了。如果超过260度，就会出摆振现象（卡钟），如果小于180度，摆轮就不稳定，因此要调整在一定摆幅之间，同时在摆轮安装摆轴轴承相应保持一定的间隙（间隙为0.05～0.15mm），这又叫分幅。摆轮和轴要保持清洁并注入细机油。见同一钟机芯机构图。
