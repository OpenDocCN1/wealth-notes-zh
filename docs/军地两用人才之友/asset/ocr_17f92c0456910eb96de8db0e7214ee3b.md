# 三、准备冲击。

接到上级准备冲击的命令或信号时，班长应立即发出“准备冲击——”的口令，全班迅速做好冲击准备，尔后向排长报告。班长应注意观察冲击信号，我炮兵火力准备的效果及敌情变化。如冲击出发阵地距敌前沿较远时，应根据上级指示，利用我炮火准备效果，提高全班承受冲击速度，尽量靠近敌人，缩短冲击距离。

# 强迫冲击

冲击战具有压倒一切敌人的英雄气概，充分利用我火力突击效果，一举突入敌人群地，发挥近战的威力，坚决歼灭敌人。当听到冲击口令或看到冲击信号时，班（组）长应立即下达“冲击——前进”的口令，并瞄准实战（即猛烈冲击，迅速抓住敌火力衰竭的火力点时，应以火力摧毁或压制，毫不犹豫地冲击前进。
通过通路时，如猛烈敌人，敌火力被破坏，班（组）应利用地形，寻觅掩护前进，迅速突破小路，敌火力被我火力压制，可或一、二部以阶梯通过。通过敌，迅速从进行间歇开枪向预定目标。近到投掷距离高时，依班长口令或自行向敌建筑内准确投掷。兼手榴弹爆炸喧，大喊“杀”声，冲入敌陷坑，以抵近打击，手榴弹刺刀和爆破材料实施歼灭，继续向指定目标猛进冲击前进。
火管筒和轻喷火器通常在战斗冲击队形内前进，随时准备消灭敌坦克、装甲战车和火力点。
如有战机到来时，班应随即反击前进，消灭敌反坦克手，并及时给班长指示目标。坦克不能前进时，应趁敌坦克难以转向敌人冲击。
