# 土壤含水量测定方法

烘干法 取新鲜土的重量，取土10~20克放在铝盒中，称重（置土壤+盒重）。然后放在烘箱里，置于105~110℃下烘6小时，取出冷却，称重（干土重+盒重）。按下列表公式计算土壤含水量。

土壤含水量（%）＝（湿土＋盒重）－（干土重＋盒重）／（干土重＋盒重）－盒重 ×100 ＝ 失水差重量／干土重量 ×100

酒精燃烧法 称蒸发皿（或铝盒）的重量。取土约3~5克（除去土中的石块和植物残渣），放在蒸发皿中，称重（湿土壤＋皿重）。然后倒入酒精3~5毫升，稍加摇动使之润匀，点燃酒精，并用玻璃棒搅动。酒精燃烧后再次加入酒精2毫升，进行第二次燃烧。如果为黏重土壤进行第三次燃烧。燃烧完毕，称重（干土重＋皿重）。按下列公式计算土壤含水量。
