# 扰妨方程式故障

最常见的是调谐传动机构故障，即齿轮磨损破损，或齿轮钉断，不能转动。如珐琅已断，应换新的齿轮，最好是尼龙轮、摩擦力大，且不带磁。其次可以选用罗纹、但因罗纹螺丝搭档将松，所以在重用前可用光油在齿轮上涂打一遍。如果齿轮松脱，应将松脱处卸下，给修复后重新装上。

有时发现调谐指针已走了一段小距离，而电容量没有变，这可能是因为齿轮盘与可变电容器之间的固定螺丝松动，可重紧螺丝。

如出现指计数刻度不准确，可先将可变电容器全部旋入，这时指针应指示的偏离就可发现。再将指针稍微松动，使之指示在中游段535于指示盘上吻合。

如果发现齿轮打滑，可能是齿轮太松，可以将固定弹簧多动一个位置，使齿轮重新紧拉紧，或者用少量松香粉加于齿轮和传动轮槽上，以增加摩擦力。
