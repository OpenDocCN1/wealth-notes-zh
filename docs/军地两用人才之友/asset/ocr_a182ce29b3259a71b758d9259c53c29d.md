# 室内装修

房屋修缮主体构造工程外，尚须做室内外装修工程。

1. 室内装修，按工程项目分，有ذكر、木门窗、内墙、顶棚、楼梯地面及附属的装饰装修分项。按材料分，有木质装修、塑料制品装修、石青花装饰条、轻质装饰板、贴面装饰及以新型的金属材料、玻璃、制品等装饰。按操作方式分，有操作作业修缮和非操作作业修缮以及预制产品装配等。

在门窗工程方面，一般采用钢窗、木门、装饰窗、做油漆。有做木门窗，也有采用空腹钢窗、钢木门或钢窗门。常有特殊条件外多采用铁沐窗窗窗窗，外墙上设设或有纱窗、纱门，各部门上配有预制（或玻璃）的窗帘板玻璃。

内墙抹灰不论是砌砖墙体、轻质加气混凝土土系板、砖块，还是钢筋砼墙体均可均可用抹灰、刷（喷）浆。在门、窗上须做防水处理，窗台下面现浇透水混凝土的，也有顶浇浆泥窗台和窗台板空隙处，窗台表面现浇透水混凝土的，也有顶浇浆泥窗台和窗台板空隙处。凡用钢筋模制或现浇的混凝土墙、柱、梁面，其表面光滑平整，可采用刮腻子喷浆。但在排缝、接头或有毛面处，必须抹灰或喷贴腻子喷。

在 大厅、走道、会议室、厕所、厨房、盥洗室设内墙面抹灰，有的抹水泥、水磨石、油漆等。

2. 室外装修常见的工程项目：
清水泥面，大部分地面比为 1：1 水泥砂浆勾缝，砖块要选用整齐砖块，灰缝也要求横平竖直，不得有游丁走缝和其他缺陷。其他如楼梯、女儿墙、腰线、窗台、雨棚、门柱、踏步和散水等部位，还需做防水处理，以美观房屋的外观。

楼外墙面是指整个房屋的外墙面不露砖面，做抹灰装饰。许多高层房屋的建装修工程常进行外墙装修作业，代替了外墙砖，以减少劳动强度。如加快了工程进度，并降低了工程造价。同时为了美观、必要加强建筑的艺术形式。如配色、线条图案、附设花饰，常见的有白水泥抹线条、外墙都做水刷石、水磨石、大理石、面砖贴面等工程项目。某些房间还做各种花饰、图案等。
