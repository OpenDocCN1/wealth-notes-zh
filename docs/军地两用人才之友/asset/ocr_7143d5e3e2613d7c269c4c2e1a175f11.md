三相交变电流，可产生旋转磁场。三相感应电动机的定子绕组就是由三个这样线圈组组成的，所以在定子绕组中通入三相交流电后就能产生旋转磁场。

![](bbox=[0.18, 0.18, 0.82, 0.55])

安装在转子铁芯上的转子绕组，由于处在旋转着的磁场中，就Sz因切割磁力线而产生感应电流，转子绕组彼此连通，因此在转子绕组中就有感应电流通过。又因通有电流的导线在磁场中会受到电磁力的作用，因此转子绕组也会受到电磁力的作用使转子转动。所以，三相感应电动机的基本工作原现是：在三相定子绕组中通入三相交流电后产生旋转磁场，旋转磁场切割到转子绕组使绕组中产生感应电流而产生感应磁场，旋转磁场相互作用产生电磁转矩使电动机转动起来。

电动机转子与旋转磁场相对静止的转子磁场，因而若是两者相对，即奚其间不存在相对运动，无相对运动，转子导线就不能切割磁力线，也就不能产生感应电流。转子绕组中无感应电流通过，就不会作用有电磁力而发生转动，因此转子的转速就不能与旋转磁场“同步”，所以感应电动机又名异步电动机。

旋转磁场的转速称为同步转速。它与三相定子绕组通入三相交流电后所生成的磁极数有关。所产生的磁极数又与定子绕组的绕法有关。同步转速与磁极数之间的关系式为：

```
n = 60 × f / P
n 为同步转速，单位为转/分。
```
