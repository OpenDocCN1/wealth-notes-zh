# 日用电炉质量的检查：

+   1. 热效率，开启式不低于56%.
2. 温限：在电压为105%，通电一小时后，电炉提柄上手握持部分不高于55℃.
3. 绝缘性能：
   热态时不低于1兆欧；变换违规电阻后不低于0.25兆欧。电炉的绝缘，应能承受下列数值频率50赫兹的试验试验电压，历时1分钟的耐压试验，不应发生击穿或闪络现象。
   （1）冷态时为1500伏。
   （2）热态时为1000伏。
4. 外表质量：金属外壳的保护层不得有其点、起层、剥落等缺陷。经在105%额定电压下通电一小时后，表面保护层不得有起层、剥落等现象。
5. 接地装置。电炉外露金属壳体应有接地的装置，并有明显的接地标记。带电源线的电炉应有接地线，从接地线的接线端子至外露金属壳体的电阻应不大于0.2欧
