# 冲洗程序

各种不规则性和性能的胶卷，各种不同配方的冲洗工艺，除显影时间不同外，其他基本相同。

前药：显影前进行水洗，叫做“前洗”。它的作用是先把药液浸透，使其能够均匀地与胶片接触。时间约0.5分钟，水温最好是18°~20℃。

显影：在配药、温水、搅拌等因索都定的情况下，胶片质量几乎完全取决于显影时间是否适当。因此，显影是冲洗胶卷最重要的工序，必须认真操作。

由于各厂的生产工艺不同，即使同一工厂生产的同记号的同一类胶卷，性能也各有差异。因此，最好显影时间并不一律。此外，感光度相同的135胶卷比120胶卷的显影时间短，进口胶卷比国产胶卷的显影时间，都需注意掌握。

冲洗胶卷的最好温度是20℃±0.5℃。如无法控制在在这个温度时，应努力增减或延长时。

停药：停药有两个作用。一是使胶卷立即停止显影；二是避免胶卷上的显影液带进定影，而降低定影能力。停药时间5~10秒钟。
