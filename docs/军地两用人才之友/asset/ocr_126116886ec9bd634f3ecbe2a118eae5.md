# 主要强 点

火力强，能对近远不同目标进行射击。

机动性能强。最大时速60—64公里，平均时速，公路32—35公里，土壤22—27公里，最大爬坡度30—32度，越壕宽1.68—2.7米，通    过垂直高0.61—1.1米，涉水深1.2—1.8米。苏、美装甲车的浮渡能力。苏军T—72和T—62坦克能潜渡5米深的江河，并携带夜视器材，便于夜间行动。

防护能力强。坦克炮弹穿甲厚220毫米，车体前部装甲厚100—204毫米，两侧装甲厚80毫米，后部装甲厚45毫米。装甲车的装甲厚15—45毫米。装甲车多有防原子、防化学、防辐射等装置。
