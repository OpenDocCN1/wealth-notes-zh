# 图23 一锁多用

+   1. 活动木条 2. 圆棒 3. ... 抽扳托架

方的（10×10毫米）。木条搭座保持在抽屉关好时，木条上的木销正好嵌入斜槽上端。

其关闭的原理是当第一个抽屉关同时，因其尾部都有一个斜执行，斜槽在前进进抽屉锁向上，圆棒使活动整木条向上，于是会使的几木条也分别被抽屉展带的凹槽内，于是抽屉就开不了。如欲开启只有将第一抽屉开启后，木条下降到原来位置，也就能提起开。

字母门 在特制的橱类品中常用帘式门，优点是减少占用空间，方便、灵活。并能利用碎小木料且易于装配。

其结构如图所示，整门是由板多块组成，板中同钻孔，用尼龙带穿连而成（也可将胶粘在尼龙带吊上）。箱体的两边座板等间距挖凹槽，槽的宽度等于板厚。帘门关闭时拉下，开启时推上。为了使帘门目由弯曲，板条底部要做上圆弧，香板不同等宽点。
