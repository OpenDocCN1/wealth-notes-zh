# 育苗 一般采用播种育苗。秋播（11月）、春播（3月中旬至4 月初）均可。播前要进行催芽，其方法有：

+   1. 沙藏催温，先用60℃温水浸种，经两昼夜后，选温暖向阳的地产进行沙播，待种子开裂露芽时播种。
2. 浮浸催芽，用冷水浸种 6～7天，每天换水一次，然后捞出，放在太阳下晾晒2小时，大部分种子开裂后即可播种。

秋播可用已成熟的青皮核桃簇架播种。
一般果实开始落点时，沟宽6～8寸，沟深2～3寸，株距2寸左右，每畦播种400斤左右。播时最好使核桃的缝合线与地面垂直，以利于根发育。

# 连 补 直插播植，植苗宜种和施肥桃生育两地。

+   1. 苗种选择、播前应选择好土地。春播在3月中旬，秋播宜在核桃成熟时，随采随播。干旱地区为保险苗，可采用深坑换或深播去土的水法。苗前要湿坑换透土，留上坑穴以营养雨水。后来是深密集厚肥土，当核桃芽露出时，倒去上部土堆，形成浅坑，以利蓄水保温。
2. 种植植株，秋冬落叶后或春发芽前，随起苗，随栽植。核桃根须发达，根系较浅，起苗时注意保持好根系，并保持根部湿润。栽植株株株距1.5～21英尺。

核桃怕荒芜，造林后，每年松土除草2～3次，结合间作，合理施肥。如在山坡栽种，应扩大树盘堆、培好土堤，管水保土。

# 油 橄 榄 樇 油橄榄已被我国各省重要木本油料树种之一。果实含油率因品种不同，一般在22～34%。是较好的食用油。
