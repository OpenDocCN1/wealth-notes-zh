| 作物名称 | 母本去雄方法 | 授粉方法 |
|---|---|---|
| 小 | 选穗、整穗, 选雄性植株的大穗。开花前1~3天 (榜中上部少数花朵开裂未开前), 植穗上、下部小穗剥除, 留中间10个左右小穗, 并将俯垂小穗中10个小花, 只留两个小穗, 并将芒剪短。 | 在母本颖壳一雌蕊自葶秆挤开, 柱头花粉粒衣膜状有光泽时, 授粉最好。可用现存子房外表黄色的成熟花粉粒在小杯子中, 热用水浸子房或雏花花粉移到已去雄的母本穗上。时间以上午10点水稻开花下4时以前最好, 授粉后立即套袋, 并挂标签。 |
| 麦 | 去蕾, 左手握麦穗。 用指将欲去花穗开花前, 右手逐朵花将穗子3个花药取出, 去掉雄蕊, 套袋隔离。 | 时间以上午10点水稻开花下4时以前最好, 授粉后立即套袋, 并挂标签。 |
| 玉米 | 系用隔离授粉法, 在母本植株的雌穗开花前花丝第一天, 用隔离袋将穗肥包住, 袋口用线扎紧或糊糊扎紧。母本开花后, 将系在穗前的隔离袋于第一天立即可揭, 采用同副条套袋。 | 母本系花后齐, 母晨8~11时取熟易落接受父本花粉进行授粉, 授粉后及时将母本穗贴行结穗, 随后套袋。 |
| 水稻 | 傍上年稻田系种半月左右时, 将选好的母本稻子, 严按规定时期的位置系植中套43℃, 8小时或48℃5分钟后, 然后心叶取出水稻小穗等几分钟后, 只留着肥厚颖的小花, 放置于袋中, 将不开发的小穗剪掉, 捆紧。 | 上午9~11时, 抖动开的父本穗子, 用光筛将落花在每天开花稻穗, 系在父本的或滤花袋中, 从本田外瓶袋外/3的颤动处, 尽量避免滤去1/3的稻穗, 将母本须在5分钟内受到花粉必须在5分钟内授亲, 授粉后立即套袋。 |
| 棉花 | 选中晴凉晾开花第1~2节的花各生植, 下午4时以后, 选取2天将发育的花, 即田花期以各白花以后任咋各对外形的花蕾, 剪子将花蕾轻轻在花台外的做法, 摊落花, 剥开花瓣, 选出花蒂, 用长约3厘米的发夹将丝状针连进行隔。 | 开花前1天, 备父本花冠用细铁丝从卵孔扎下, 防止虫传粉等。第2天上午9~10取采父本花粉, 用纸袋或直授用父本花粉袋, 授粉后将亲上表签并挂钩。 |
