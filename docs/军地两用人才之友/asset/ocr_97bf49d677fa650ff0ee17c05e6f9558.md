# 手扶拖拉机的故障和排除方法

发动机故障及其排除方法：见柴油机部分。
底盘的故障和排除方法如下：

| 故障 | 原 因 | 排 除 方 法 |
|---|---|---|
| 离合器打滑\n（负载增加，发动 机转速减 明显下降，而 拖拉机速度 逐渐减慢） | 1.摩擦片或压盘上装有油污。\n2.分离杠杆头部与分离轴承平面 之间间隙或间隙过小。\n3.离合器踏板磨损过多。\n4.离合器弹簧弹力衰弱。 | 1.拆开离合器清洗。\n2.调整间隙至 0.3—0.5毫米。\n3.更换。\n4.更换。 |
| 离合器分离 不清。 | 1.离合器前盖内有油箱和积 累了灰尘影响。\n2.离合器拉杆自由行程太大。 | 1.拆开离合器，用汽油 洗净。\n2.根据油污，离合器调 节拉杆的自由行程为 25 —50毫米的自由行程（工 艾—11型为 20—24毫 米）。\n3.将换算弹簧高度一致 级。 |
| 离合器不能 分离。 | 1.离合器分离轴承6688 09卡死。\n2.离合器拨叉轴 60 20 6轴圆检 坏。\n3.离合器花键轴与片内花键花 咬死。 | 1.更换。\n2.更换轴图。\n3.拆开离合器，用柴油 或汽油清洗去锈。 |
| 变速箱中有 较大的杂音和 敲击声。 | 1.齿轮表面及齿侧面有毛刺。\n2.齿轮过度磨损或表面有剥落现 象。\n3.轴承松脱严重。\n4.换挡齿轮油不合适。 | 1.去掉毛刺。\n2.更换。\n3.更换。\n4.换油或更换。 |
| 拖箱。 | 1.主变速齿配合不正确。\n2.齿轮机械工作不正确。\n3.被叉以及二、五档齿轮轮轴 （二、五档齿轮）。\n4.停车传动向外间有松动及轴承 擦机（三、六档拖轮）。 | 1.校正。\n2.更换。\n3.更换叉以及齿。\n4.更换轴承，适当调 整轴承间隙。 |
