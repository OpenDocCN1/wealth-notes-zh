# 丝绸和丝织技术

丝绸是中国驰名世界的传统产品。我国古代在长期生产丝绸的过程中，曾经在对古代世界属于最高平的织锦技术，对世界蚕丝科学的发展、生产丝绸的经营，是中国和世界科学文化交流中重要部分。
我国古代制造丝绸，至今早已有五千多年的历史。最先用野蚕丝，后来改成家蚕丝。制造丝绸的技术细致，工序复杂。主要是缫丝、练丝、穿梭、穿经、装造和绘花布。丝绸的品种丰富多彩，最有代表性的丝绸、锦、缎、绢、绸。

我国丝织技术，早在公元前就传到日本，在东张开通西域后又传入中亚细亚和欧洲。.symmetric西方记载，波斯新学派使者来我国学习丝织技术，日本人来新江浙拓染缎等技术。公元七世纪以后，中国的丝织技术传入日本、中亚细亚、欧洲等地影响更为显著。
我国古代的丝绸，历来以精美著称。不只是中国各个时期主要的衣着资料之一，也是我国古代对外贸易的重要商品。古代罗马和埃及都把中国的丝绸看作“光辉丝、人力几何”的珍品。罗马皇帝大难道记载中国丝绸在制造丝绸、中国丝绸每兹高达达黄金十二两，但一直是西方市场的畅销品。

# 圆 周 率

圆周率就是圆周的长同它直径的比，用希腊字母π来表示；π = 3.14159265358979323846……
我国南北朝时期，杰出的数学家祖冲之，把圆周率推算到非常精确的程度，取得了极其光辉的成就。‘魏书·律历志’记载，祖冲之确定了它不是近似值是 3.1415926，超过近似值是 3.1415927，π的真值在这两个近似值之间。同时，祖冲之还确定了π的两个分数形式的近似值：约率π=22/7≈3.14，密率π=355/113≈3.1415929。
