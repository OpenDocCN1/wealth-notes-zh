# 腹（腰）部伤的包扎

腹部内有胃肠、膀胱、肝脏、脾、肾等脏器，这些脏器受损伤后，不仅功能能受影响，而且还可能有内出血，危险性较大。

急救包扎的要点是：腰腹部受伤立即用大块敷料和三角巾包扎。伴有内脏损伤时，不能喝水、吃东西、吃药。并要在包扎后尽快送医院。抬送伤员应仰卧，使伤员腹部悬空，并在膝下用衣物等垫起，使腹部松弛。如伤口与身体平行，后送时使伤员俯卧直腿（图二十五）。

腹部伤包扎用三角巾最好。包扎的基本要求是：三角巾的边要拉紧，缠绕牢实，中 间平整、包扎方法：把三角巾顶角向下，放在一侧大腿根部下方，用一底角包绕大腿与腹部拉拢，一角自腹股沟转过腰与底部近钮结（图二十六）。或是将三角巾顶角朝下，底边被放
