使用薄膜唱片时 唱盘上应先垫垫上一片塑料唱碟。因为薄膜唱片太软，若唱盘面太大，则薄膜片外侧就无法承受唱头的重量。

# 电唱机常见故障及处理

换道电源，唱盒不转动

+   1. 电源线脱落，应重新焊好。 2. 唱盒下部锥形开关失灵，应适当调整垫片的位置，清洗触点，若已损坏，应更换开关。 3. 调速开关未定位：当调速开关置“0”位时，传动胶轮不与唱盘接触，所以，应改开关置78转档或33转档。 4. 电源电压太低，电机无法启动。应加接调压器，提高电压。 5. 传动系统失效。可脱落皮脱带脱落，应重装装好。若胶带或胶轮损坏，应更换。 6. 电机损坏。必须更换新电机。

唱盒异常

+   1. 电源电压偏低，电机启动困难，应加接调压器并升压。 2. 电机主轴干油，摩擦力大，应加入轻质润滑油。 3. 传动系统因油污而打滑。应用干净的脱脂棉花揩拭干净。

转速不稳，响且杂偏

+   1. 传动系统因油污而打滑。应用干净的脱脂棉花揩拭干净。 2. 传动系统板变形，引起转速不稳。应更换新底盘。 3. 某一切断不正常，引起鼓轮摆动，造成转速不稳。应换装新轴，认真组装。

放音无声 1. 拾音头外引线脱落，应予焊上。 2. 拾音器损坏，应予更换。
