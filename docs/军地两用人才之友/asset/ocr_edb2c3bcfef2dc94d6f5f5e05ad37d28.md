# 收音机的调试

+   （1）试听灵敏度：将波段开关置“中波”位，开启电源，并略调大音量。通过调谐选择拋出本地的几个电台，开大音量，听音响嗓量是否足够。
（2）试听失真度：在“中波”位，当音量开得较大时，声音是否发生嗡鸣，变换砂纸等情况。
（3）试听灵敏度：由频率低侧到频率高侧缓慢点读节，在整个波段内接收的电台数目越多，嗡鸣越小，说该灵敏度越高。
（4）试听噪音：接收一台本地较弱的电台，将音量开至适中位置，试听在广播间隙处是否有噪音。然后将频率调至无电台的空档处，再听一听。应该很静，无任何杂音或嗡鸣（即交流声）。
（5）试听选择性：先选一强一近电台，或调收音机收音方向，使之声音最强。然后调谐调谐旋钮，使频率向两侧偏移约10千周左右，这近电台信号应消失。才说明选择性好。若在收听某一电台广播时，同时还串入其它电台的广播节目，就说明选择性差。
（6）检查机械性能：在中段接收一电台，将波段开关在中、短波之间来回拨动几次数，当回到集中位置时，所接收电台应正常收音。换后再接收一强电台，重复以上实验。若收音机放音正常，说该段开关接触良好。

# 收音机的使用及维护

收音机的各开关、旋钮及插孔的功能

+   1. 波段选择开关。可选择所收听的波段。不同的机型，开关形式及数量也不同。型式常见的有旋转式、拨动式和琴键式。
2. 电源开关。电源开关常与音量开关联在一起。功能是开启电源。
3. 音量控制开关。控制收出音量的大小，在形式上主要有旋转与滑动式。
4. 音调控制开关。用以调整高低音分量的比例，使音质丰满、声动悦耳。
