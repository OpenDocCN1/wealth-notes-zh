# 压水过程。

吸水过程。水果泵水过程是当叶轮旋转时，水在离心力作用下被叶轮甩出去，水原先占据的地方即叶轮的中心部位形成一个低压区（低于大气压力）。而吸水管里的水面还受大气压力的作用，水在内外部压差的作用下，冲开吸水管下部的底闸逆向进入叶轮中心部位。叶轮中心部位的压力越低，吸水的力量就越大，这就是离心泵的吸水过程。随着叶轮的连续转动，水泵就不断地吸水和压水，水也就源源不断地从低位被送到高位。

# 离心泵的性

在离心泵的外壳上都钉有一块铭牌，上面注明了水泵的具体规格、型号和主要性能。这对于选泵、使用和维修水泵都有很大帮助。在使用中要注意使铭牌完好和丢失。例如，
B（BA）型离心泵的铭牌

| 清水泵总式水泵 | | |
| --- | --- | --- |
| 型号 6BA-12 | 扬程 20.1米 | |
| 流量 160米3/分钟 | 效率 81% | |
| 轉速 1450转/分 | 允许吸上真空高度 7.米 | |
| 配套功率 17千瓦 | 泵质量 146公斤 | |
| ××水泵厂制造 | | |

离心泵的有些性能如下：
流量；又称出水量或输水量，它表示水泵在单位时间内排出的水量。单位为升/秒或米3/小时。因为1升清水重1公斤，1立方米清水重1吨，所以它也把升/秒写成公斤/秒。把米3/小时写成吨/小时。
吸程；它包括水泵吸出口水管口中心线到水面之间的垂直距离加上各项损失，即：

总扬程 = 吸程 + 压程 + 损耗扬程

扬程的单位为米。不同型号的水泵有不同的扬程。一个水泵的扬程是随流量的大小变化的。水泵铭牌标出的扬程，一般是指这个水泵最高效率的扬程。
