+   ① 直检检验（内膜检验）：用于病原体较大及种子外表有明显症状的病害，如地瓜黑斑病、水稻稻瘟病、小麦纹枯病等。

+   ② 过筛检验：利用病原体和种子大小不一，通过筛选整理将全部或部分病原体筛出，再就其筛出物做大镜检验，如豌豆锈、油菜中的菌核等。

+   ③ 剖芽检验：用于检验种子中可在萌芽阶段侵染的病原体，如棉花、大豆疫病、小麦根腐病等。具体做法与发芽试验相似，但所用器皿和检验物须更清洁。

# 种子的贮存

+   （一）贮存种子的仓库，应当坚固安全，上不漏雨、下不返潮，清洁无虫，能防鼠、蜜，有 arguably 开启门，便于通风和密闭。种子仓库内严禁堆放杂物、化肥、农药及其它物品。

+   （二）贮存种子的工具、包装物、仓库事先进行清扫消毒，种子一经运出，亦要及时地清扫、消毒，保持工具、包装物、仓库的高度清洁、无虫无霉。

+   （三）种子入库时，要认真做好种子品检验工作，入仓库种子的水分、净度、纯度、发芽等率，应达到国家规定的种子分级标准。入库要分别品级、分等级堆放，不同品级种子的间隔要有一定空间，所存的种子品种，堆高不得超过2米。对入库的种子要建立连续卡片和保管管、敲到品种、等级、数量的帐、卡、物三相符。

+   （四）能种应由专人保管。做到无虫、无霉、无鼠、无盗、无事，放种子安全存放。

+   （五）对贮存种子的仓库要定期检查，特别是风、雨天要随时检查。如发现仓库有漏雨或渗雨情况，应及时维修。仓库内外经常保持清洁卫生。仓库四周可用666药剂喷打虫蚁线路，以防外界害虫侵入。

+   （六）灵活运用通风晾晒，以达到调节种子仓内的温湿度。将种子干燥到安全含水量。或密封窑，结合作当通风的措施是贮存种子的良好方法。
