压脚板姬与机相或装簧装机针产生断针。当压脚发生位移时应首先检查压脚螺钉是否松紧，压脚压板是否变形，若不是上述原因，则需松动压杆导架螺钉使正压脚。

# （2）针与针板针孔冲突。机针在针孔中的偏斜原因较多，应首先检查机针是否有变形，也可能针板变形，检查针孔与摆梭平面间隙。检修时要看偏斜多少，然后把针杆升到最高位，用小铁丝轻轻敲针杆下端的针尖，使间隙达到正常状态（0.04～0.15mm）。倘若针板设有对准针板上的针孔，而机头的车壳与底板连接处的损坏就会明显的影响到，能使通过过程中因不被遮盖而先起针，影响机针与针板针孔的不同心。此时只能送工厂修理或更换。

# 跳针（气跳）跳针指缝纫过程中，缝线上面或底面与面线不交叉的现象。产生的原因可分为缝纫后设有正确形成和摆梭钩与针线环两个方面。有时是几个因素集合在一起。跳针分为偶然性、断续性和连续性三种

# 偶然性跳针：

+   （1）缝纫厚度不匀的缝料，由于机针锋细且缝速较快，使机针弯曲产生跳针。可改正堆积或减速进行。
（2）机针安装不妥当，使针钩至梭与摆梭钩成正交，应重新安装机针或换用质量较好的机针。
（3）缝线质量最差，粘性太大，使线环形成不稳定。特别是在有弹性较高的缝纫品生产缝针时，应改用纤维丝做成的弹性强韧纱。
（4）缝制资料时或刺割时用针杆太粗，应选用9号或11号的。
（5）压脚压力太大造成跳针，特别在刺割时没有把缝线撑紧，此时应加大压脚压力，铜繁紧度。
（6）由于钩针钩的磨脱而把针装置的太高。
（7）摆梭钩的尖端已变形或尖端断落而影响钩线。

# 断续性和连续性跳针：

+   （1）机针与摆梭的钩针位移变动。调整方法：在机针处最低位置，旋松下曲柄夹紧螺钉，用小铁锤和硬笔轻敲丝盖梭的凹槽处，使摆梭的前端露出机针刃中心6～6 mm，然后用螺丝刀拧紧下曲柄夹紧螺钉。
