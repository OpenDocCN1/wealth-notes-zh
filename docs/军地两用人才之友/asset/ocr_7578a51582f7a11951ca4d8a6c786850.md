# 电视机的安放、保养及外接天线

# 电视机安放

+   1. 电视机安放地点应远离烟囱、暖气管、煤炉、自来水管、浴池等地方；注意防潮、防尘、防水腐蚀。电视机荧光屏应避免阳光直射，不收看时可用玻璃布或布蒙盖。
2. 电视机应安放平稳，要通风良好有一定距离（10厘米左右）。放置时，应注意通风散热。

+   1. 擦拭电视机机箱时，必须在交流电源插头拔除之后用柔软的湿布进行，切忌不要用酒精、汽油、苯、氨水等化学物品擦洗。荧光屏可用擦眼镜的软布或毛玻璃拭。
2. Carrier感情
3. 电视机上面极微薄，不要放置重物。橡胶平板或塑料物品长期放置在电视机上面会使外壳上视频。
4. 不看电视时，应拔除电源插头和室外天线插头。特别在雷雨时，不要使用无避雷装置的室外天线（这时应把室外天线接地），避免雷击破坏电器。
5. 用户若住木板楼面房子，收视机应注意防震。最好用一块橡胶皮放在电视机下面。
6. 如果当地电压太低，电视机荧光屏可能不亮，或虽有光但行幅偏偏缩小，这不是电视机故障。是当地电压太低的结果。补救办法，可以外接一个交流稳压装置或调压装置。如果是使用调压装置，应注意在晚九点以后当地电压回升时应减少调压器输出电压，这样能延长
