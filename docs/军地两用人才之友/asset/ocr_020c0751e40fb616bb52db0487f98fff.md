# 音箱的放置

+   1. 音箱周围不要能有易受振而发声的木板、铁片等杂物和一些松动的物体。避免使音效失真加大。
2. 木料音箱不要放在潮湿和近炉火的地方，以免音箱变形，影响音质或损坏设备。
3. 在摆设室内家具时，注意不要让它们遮挡在音箱扬声器前面，因为中低音波长较长，还可以绕射，而高音就不能绕射，传不了多远就被遮着衰减掉了。
4. 为了增强中低音，音箱宜放在贴墙或屋角，这样可以利用音箱夹角的增强叠加助音向头。
