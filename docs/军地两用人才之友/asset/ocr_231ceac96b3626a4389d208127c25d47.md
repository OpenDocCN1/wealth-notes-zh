# 借贷记账法

借贷记账法，是以“借”、“贷”作为记账符号，运用复式记账原理来反映资金增减变化的记账方法。简单地说，是资金的平衡关系。用公式表示出来就是：资产总额＝负债总额＋所有者权益总额。

以一个企业为例，它要运营一个家庭的生产业务，首先必须拥有一定数量的资金。这些资金的存在形式和分布状况（如固定资产、材料、产品、银行存款等），称为资金运用；在社会计量经济中，企业的资金全部是从一定的来源取得的，有的由国家拨入，有的唤内部形成，有的从外部借入。这些资金的取得或形成的方式（如国家资金、银行贷款、应付账款、利润等），称为资金来源。例如，上级单位拨给人民银行贷款50,000元的专项资金。这项经济业务的发生，使企业资金总额增加50,000元。在资金运用方面，表现为银行存款增加50,000元。这项资金是企业从某渠道来的，所以在资金来源方面，表现为上级拨款增加50,000元。一项资金，既从来源形态，又从运用的渠道两个方面来观察，就可以对它进行全面完整的反映和监督。从这里可以看见：资金运用和资金来源是同时出现，有一定的数额的资金运出，就必然有相同数额的资金来源；反之，有一定的资金来源，也必然有相同数额的资金运用。就一个企业来说，它有多少资金运用，就必定有多少资金来源，有多少资金来源，就必定有多少资金运用。资金全部都部分运用的总计等于全部资金来源的总计的关系。这种资金运用和资金来源在总额上的相等关系，叫做资金的平衡关系。例如某单位共有资金2,000,000元，即表现为资金运用总计和资金来源总计都是2,000,000元。具体项目，如表所示：

| 资金运用 | | 资金来源 | |
|---|---|---|---|
| 固定资产 | 1,500,000 | 国家资金 | 1,350,000 |
| 机器 | 900 | 银行贷款 | 15,000 |
| 产 设备 | 100,000 | 应付账款 | 11,000 |
| 库存现金 | 2,000 | 企业资金 | 4,000 |
| 银行存款 | 80,000 | 利润 | 20,000 |
| 收入结算款 | 18,000 | | |
| 合 计 | 2,000,000 | 合 计 | 2,000,000 |
