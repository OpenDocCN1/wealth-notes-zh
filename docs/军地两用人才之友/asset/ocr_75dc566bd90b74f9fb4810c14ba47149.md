# 身体各部骨折的固定

图三十九 脱脱前桡式包扎 图四十 肩部骨折悬带反折包扎

肩骨骨折：把两块夹板分别放在肩部靠胸和背侧，整好后用绷带或三角巾固定。在上举 § 架时，可先在手心放一棉花团，让伤员握住，使腕关节稍向弯曲，然后固定。此时用三角巾将前臂悬吊胸前。无夹板时，先将前臂屈曲。手腕略沉，用三角巾悬于胸前，再用一 条三角巾向上绕和肩胛前骨的三角巾一同固定在胸部。图四十一。

无三角巾时，可用伤员上衣固定。其方法为：伤肢屈曲贴于胸前，将手插入第三、四钮扣间前衣襟内，再将伤侧前臂置于上反折，衣襟系紧带。提到肩前上，袋到伤侧肩前与上的上衣襟打结。然后再用一带将前反折的衣襟下压固定在胸前（图四十二）。
