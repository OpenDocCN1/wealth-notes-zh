# 图三十六 三角巾小腿足部断托

巾内，悬挂在胸前，再把顶角的多余部分折叠固定。由于前臂骨骨折或受伤，包扎时要注意骨折患肢的高低，使伤员感到舒适。由于前臂骨折受伤，手部要稍高干肘，手搭要露在三角巾外，以使腕部要恒紧手指有无浮紫发胀的现象（图三十七）。

小志愿等：把三角巾折成适当的带子，吊起前臂，两顶角在颈后打结。此法用于锁骨骨折以及肩关节和上臂受伤（图三十八）。

# 图三十八 小悬臂带

三角巾悬起手扎：分别将三角巾底边中间、顶角打结成风帽，然后将肢体损伤绕入风帽内，再拉紧两底角，于近心端互相反口打结（图三十九）。

绳等前臂骨折或反包扎：此法与缠底包扎基本相同，但每层必须反折缠带一次；反折时以左手按住缠带上的反折处，右手缠带顺反折向下，然后绕肢体拉紧，反折处不可在伤口或凸突处起（图四十）。这种方法比较牢固，除了前臂骨折，也可以用在小腿上。
