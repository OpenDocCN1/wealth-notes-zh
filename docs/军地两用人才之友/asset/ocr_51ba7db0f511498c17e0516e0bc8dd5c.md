# 比萼续断高度

种蔸选择与处理。最好无病，应于收获（10月份）的同时，进行种蔸选择。野生天麻在五、六月份挖采，挖时尚须防止此时时间过早和挖伤、砸伤。选种标准：大白胖、中白麻、小白麻和米麻四种均可的繁密培养。简易种蔸加工业需要。不必保留种蔸。一级嫩茎连角与嫩根同时进行，所以种蔸不需饱满。短期间可放在温度不超过15℃的室内或室内，贮藏时间不宜过长。

选地：应选择排水良好的一块阳面平地为好，阴地易受凉害。土质以砂质壤土或疏松土与腐殖质土均可。土质不宜肥沃，但应保持潮润和通气良好。

栽种方法：以平栽法为最好。在作业之前，先进行倒土，将树根、石块碎石，然后进行作畦。栽法：一层苗材，暗深6～7寸；再层腐竹，暗深9寸，长为18尺，中层铺5寸巨宽的土壤，以防虫害和腐烂。作业部位宽1.5尺宽。堆成平直，先铺一层沙或腐熟粪渣土，可利于渗水。然用腐熟好的腐植一批块上层，置间隔距离为1～2寸，边坡填充粗物，以黄木屑末和沙（1：1）为好，或加腐熟废土也可，不能用枯腐质。苗将种材置于一处，附近用中间，紧闭对放上种株，种株离黄箱边缘大而小。种蔸最好用，即用网线，沙或腐殖质土壤，上面覆3～4寸腐殖土。应高出地面，以免雨水渗入造成。如需两层时，在栽完第一层后，用疏松物填平，再加垫第二层，然后覆土，将暗面压实，加厚一层厚一层松树叶防透避免。冬季春天融冰后，将覆盖物除去，可种豆类作物，能起遮荫作用。

注意:

+   （1）浇水保湿：保持土壤湿润，当土壤含水量降至50％以下时，应马上浇水。
（2）松土除草：天麻、密环菌生长都需空气，土壤表面被绒，应及时进行松土。
（3）防寒越冬：应选择背风向风处栽植，栽植不宜过晚，以10月中旬为宜。栽后立即加盖枯枝落叶，严寒地区也可采取初冬全部收栽，除腐蔸加工后，将白麻种块放在室内用沙埋藏，待来春用培养好的菌材栽植。虽产量较低，但不易受害。
