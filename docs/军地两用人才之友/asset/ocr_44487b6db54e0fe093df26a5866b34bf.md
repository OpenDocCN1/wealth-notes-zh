# “第二渔业”介绍

第二渔业是不同于天然水域的人造水体渔业。

第二渔业不单纯是为生产和满足人们食用的需要，而且已进入家庭、工厂、与文化、艺术、娱乐相结合作，使渔业具有全民性。日本发展工业捕鱼，淡水鱼的生产迅速上升，近七年比比往七年增长了四倍；苏联放养大湖水体面积，十五年中增加了五倍，使淡水鱼产量增产剧增。近年来，我国“第二渔业”也正在蓬勃发展中。

山顶养鱼 利用山顶流水养鱼，是在高原两岸堆石成池进行的，我国山区多，没有条件发展常规渔业的有很多一个重要资源。各地山区养鱼，已取得很大发展。如浙江省省会嘉兴的三十二个公共山、七个公共国有取源水养鱼。广大金省会养鱼的已达十万户。每户有一个二十三三十平方米的水池。阳奉县虽公共水池六十个，年产鱼五十万斤。

换水系统 随城市建筑的发展，城市房屋以平顶为多。盛夏季节，为了防晒隔噪，四四川地区的一些养鱼场，在楼顶凿了深20厘米的水容，冬天水进行喷养，每张水池的本只有半分米。夏天散热避暑，冬天采暖保温，调节室内温度，改善职工生活，真是一举数得。

越顶养鱼，日照较好，但日夜温差大。因此，白天宜覆盖，以防日照过强，也可防天敌，夜间注意保温。

工业养鱼 利用工业余热发展水体鱼业已被各国重视。我国有从五十年代开始发展废水养鱼的。目前已在二十多个省市的一百多家大厂中进行。湖库桃花洲养鱼工一九八〇年年产量六万斤，加鱼苗投入四万斤。净利八千元。新江苏省山水库流鱼饲养率产值三万元以上。上海音湖以金刚机械化鱼场，一九八年获利十万元。国防工厂的养鱼，亦是欣欣向荣。

养井养鱼 我国大西南有许多地下溶洞形成的地下河，水温终年变化不大，冬暖夏凉，适宜鱼类生长。四川峨边有五十五处这样的。
