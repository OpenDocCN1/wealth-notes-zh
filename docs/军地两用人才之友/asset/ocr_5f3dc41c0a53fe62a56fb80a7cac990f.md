# 三、指挥 指挥是保证企业正常经营、实施计划不可缺少的职能。

指挥是指决策实施计划、命令等手段地指挥下属机构和人员履行自己的职责、实现计划任务的重要职能。计划任务不能安排得十分具体，在执行过程中还会出现某些事件先于预料的新情况和新问题，所以，在计划时对下达时，管理人员应有必要对自己的下属机构和人员提出应进行指挥，有时甚至需要做出具体措施帮助，直至下属机构告诉他应该如何以及何时去完成任务。实施指挥职能，固然需要高度的权威和 thats认可，但是这种权威是建立在下属人对、尊重下属人员的意见和建议，在上下层之间建立平等而的互交关系、当双方中下层人员的智慧、克服困难和尝试经济规律的指挥。指挥应当具体、却又不能越超产位，应应当把积极性创造在在下级提出主要想法办法，充分发挥下属人员的主动性、积极性和创造性。

# 四、监督 监督职能能能指挥职能作用不同。指挥的主要作用是发动下级人员的积极性，帮助他们尽力把工作做好。监督的作用是考核下级机构和下级工作人员完成如、是否有履行了自己的职责。经营管理活动中有高度经济责任与向好处，适应并政府的政策和国家法律地方。监督的根据是计划任务和奋斗目标，党和政府的政策，国家法律和有关的企业制度。监督包括两个方面，一方面是对人的监督，另一方面是对物资对企业计划的检查。社会各方面监督，主要的是自上而下的监督，也有自下而上的监督，以及平级的相互监督。这种监督根本不同于资本主义企业家长对工人的专制。社会主义企业实行监督的目的是不断地推动企业的正常工作，而为了担当了目的企业计划进行任务的执行，更好地发挥他们的作用。监督的主要手段是检查、批评、总结。
