# 砌毛石墙的方法

毛石在建筑史上的应用历史悠久，早被人们作为建筑工程中的一项主要材料。因地制宜，就地取材，既方便又较经济。使用石材必须选料，风化、裂缝、腊片者均不得使用。使用前要用清水冲洗干净，除去泥砂杂质。

砌石砂浆，一般用50号水泥混合砂浆，有些平房用白灰砂浆砌筑，因石材吸水量较少，使用砂浆厚度要小些，以于楔成团，落地开花为宜。

砌毛石基墙，施工前要检查地坪标高、验线、监控、清底以及铺边垫料是否安全妥妥，其它如打孔门板、铁件等均应同时预埋工程。砌毛石基墙参见图11。

砌毛石墙体，要先10厘米左右的砂浆找平，毛石块要大小搭配，大面朝下，石块间要将砂浆铺挤严实平整，在第一层石块砌好后，在大块石缝隙中填入1/3～1/2砂浆，再用小石块填连，轻轻捣实，禁止用小石块堆满窍塞，避免有空隙影响工程质量。
