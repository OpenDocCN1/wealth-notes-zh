2. 唱针被磨损掉，应更换新唱针。

3. 声音抖动，这是由机械传动部分的老化引起的，按“转速不稳、向前或掉转”一节中的故障参考方法处理。

4. 唱片旧也会引起大的噪音。应更换新唱片。

1. 薄膜唱片的修复
薄膜唱片变形发软，可取玻璃面积比唱片略大的玻璃，洗净后放入50℃左右的热水中，然后将唱片也置于水中，并用玻璃夹紧，留在热水中15分钟。取出后，打开玻璃，用柔软的布将唱片揩干，并用纸包好。重新置于玻璃片中，半小时后取出，即可整理如故。
