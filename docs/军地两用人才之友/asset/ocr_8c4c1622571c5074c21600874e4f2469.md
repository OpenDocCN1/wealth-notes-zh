# 黑白电视机的调节旋钮

有的装在机壳的侧面或后面。

（1）频道选择旋钮。这个旋钮是用来选择电视频道的，要靠着个频道的数目，频道选择旋钮档数。现在我国生产的黑白电视机，一般只有12个频道可以调选；而且进口黑白电视机是全频道接收机。有些高频／超高频接收开关，它可以通进超高频段接收、接收 VHF 的 1—12 个频道，也可接收 UHF 的 13—57 频道。
频道选择旋钮一般装在正面，使用时，根据所收节目的频道，转动这个旋钮，使这个旋钮（数字）对照面板上的标定符号（三角形或点）即能。进口黑白电视机中也有采用旋钮型频道选择开关的。

（2）频率微调旋钮。这个旋钮大多数是装在频道选择旋钮外面的。有少数电视机设有这个旋钮，也有的是一条旋钮的旋钮。
旋钮的外面（大轮子）有这两个表皮，一种是直接可做调频。另一种是先加热去热后才能调谐的，平稳旋钮与内幕微调电容相合，调谐时须将微调旋钮向里推，使之与内部电容器相合，然后顺时针作用。
频率微调旋钮好使反应直接关到整机到调频和伴音质量，因此在频道选择好后，应细心调节这个旋钮，兼顾图像和伴音质量，配合天线位置和夹角的顺序，得调音量制作为止。

（3）电源开关兼音量控制钮。这个旋钮有两个作用，一是用來开关黑白电视机的电源，二是用來控制伴音音量的大小，它与收音机的电源旋钮控制旋钮的作用是一样的。一般是顺时针旋转先关电视机，然后将旋钮转动，音量增大，有一种电视机是采用旋钮式开关开关电位器，使用时先把开关旋钮拉出来，接到电源，然后顺时针转动调节音量；关机时再推上。个别的电视机是把电源开关和熄亮开关合为一个的。

（4）亮度调节旋钮。它是用来控制图像亮度的，顺时针转动，亮度增强，反时针旋转，亮度变弱，一般顺时针旋转增加。

（5）对比度调节旋钮。这个旋钮用来控制图像信号强弱。调节它，可以使图像黑、白、灰、白层次分明，若有对比度太小，图像就是太淡薄、灰白；若有对比度太大，则白得太白，黑的太黑，图像则胀。
