# 2. 内机结构及工作原理

机架表的内机结构由五个部分组成。这就是上条拔针机构、原动机构、传动机构、擒纵调速机构及指针等组成，它们的作用及其相互之间的关系如下：

![](bbox=[0.12, 0.26, 0.88, 0.39])

# ① 上条、拔针机构：上条、拔针机构的主要作用是外力传递给原动机构，发条上紧，具有回复力短，产生位能，使机械表转动的动力的。另一个作用就是拨动手针，校对时间。

# ② 原动机构：原动机构主要由发条、条盒盖、条盒盖和条轴等零件组成。外力通过大小钢轮、条轴传递给发条零件，发条储存有矩形弹性原条件。表体的体积小，发条的活动受到了限制。为了避免与其他轮子相撞，减少发条在放松工作时的圆周摆动和心烦思虑。使加在发条上的润滑油不易消耗以及保持表机和发条的清洁，一般都采用条盒框架定发条零件。当发条完全以后，条轴固定不动，条轮为发条力
