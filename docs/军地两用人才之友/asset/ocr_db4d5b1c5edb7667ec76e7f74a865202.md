# 图44 屋架节点

1.2.上弦顶节点 3.4.下弦中节点 5.6.斜撑上弦节点 7.8.斜撑下弦节点

略；下弦如用原木拼对最好把大头使用在端节点处，上、下弦中的好面应使用在下面，有疙瘩的都可使用在上面（图木材的轴线与杆件的中心线以下，其剖割高度部分各略而不计，故在上面略有疙瘩影响不大）。下弦若弯曲时应将曲率小的一面向上，不可下等及弯等使用。

上弦受力最大的地方也是与下弦交接的节点处，所以较好的一端应使用在端节点处，用原木做竖时，因上弦需找平，因此有疙瘩的《或一定要的都可使用在上面。上弦弯曲时应弯翘下（因等朝上时上弦一平会使木材断面损失太大）。

割槽、制榫、钻孔的地方应避免疙瘩、劈裂、腐朽。在这些地方若有疙瘩时，不能保证质量。
