# 按时保养

根据说明书和机器的技术状态，进行定期的技术保养是保证拖拉机经常处于良好状态和延长使用寿命的一项重要工作。

技术保养期类：

| 保养类别 | 工作 小时 间隔 |
|---|---|
| 每日保养 | 10-20 |
| 一号技术保养 | 100 |
| 二号技术保养 | 500 |
| 修整 | 1500-2000 |
