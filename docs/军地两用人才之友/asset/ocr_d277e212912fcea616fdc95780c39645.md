# 龟，鳖养殖

乌龟和鳖栖息于江湖、湖泊和池沼之中，繁殖属于安静的环境中， 在风和晴朗的天气，常爬出水面在岸边石上“晒背”。在气温 10℃ 以下即冬眠，待来年水温回升到 15℃ 以上时，正常活动，且大量摄 食；当气温达到 20℃ 以上时，雌雄交配，上岸寻找适当的地点挖穴产 卵。在适宜温度下，受精卵经 60～80 天即可孵化。乌龟一般体型半平 以上述上高而圆，而鳖体型 4～5 年，体重达 2 斤左右为成熟。并且以 田螺、鱼、虾、植物为食。

饲养环境（1）养殖面积为 2 亩左右，水深 1.5 米左右。池 底应有 20～30 厘米的泥水，活水和死水各半。（2）池的周围必须筑 埂防逃。增高，养龟，半米即可，养鳖，则需筑 1 米以上才行。增建 要求光滑。（3）围墙和池塘之间要设 1.5～2 米宽的空地，还可在 池中筑一个小，三平方 米的岛，岛和池和 池之间的地面要有一定坡 度，便于龟、鳖上岸活动。池塘四周及岛适当种植柳树、芦竹及高 纤作物之类，地面应铺以沙质粗粒黄沙，以供其活动和晒卵。为解决一 部 分问题，可在池中增设水花生种 。（4）池周围保持安静，适当安 装些电灯，便于夜间观察活动情况。
