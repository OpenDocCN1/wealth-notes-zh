# 中医学

祖国医学是中国民族独特的防病治病经验总结，有文字记载已有数千年的历史，它对人类健康事业作出了重大贡献，是我国的宝贵文化遗产。

流传至今的诸籍中，杰出的医学家们著成了中医学一部部经典著作——黄帝内经。它以阴阳辩证的阴阳五行学说作为医学理论体系，以论述人与自然的关系和人体各部脏腑间相互关系，并在整体观念的前提下，阐明有关疾病、诊断、预防、治疗等医学上的一些问题。

东汉时期的医学家张仲景在《内经》基础上，创造性地发展了“辨证论治”的方法著《伤寒杂病论》，是一部大体的临医医学。到了金元时代，刘完素、张子和、李东垣、朱丹溪等四位卓越的医学家，继承宋末金元医理论，结合具体的时空、地点、对象，各自发挥了手术主义，丰富了中医理论。流传又把攻邪与扶正理论结合起来，使医学诊断和多级性疾病的诊断和治疗更趋完善。我国古代数千年的医学著作有五、六千种以上。此外，散见于经、史、子、集、小?、笔记及道藏佛教等的医学资料，难以数计。
