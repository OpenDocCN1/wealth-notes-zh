# 苏、美装备的军用毒剂主要性能

苏、美装备的几种主要毒剂，按毒害作用的特点，大体上可分为五类：

+   1. 神经性毒剂：能够破坏神经系统的正常功能，中毒后能引起瞳孔缩小、视力模糊、呼吸困难、肌肉跳动，严重时能引起全身抽搐致死。主要毒剂有沙林、维（V）类毒剂。苏联还有樱毒、塔铬。
2. 氯疮性毒剂：能够破坏皮肤，引起红肿、起泡、糜烂，也能伤害肺部和眼睛。主要有芥子气、路易氏剂。
3. 窒息性毒剂：能够破坏呼吸器官，特别是肺部，引起肺水肿。主要毒剂是光气。
4. 全身中枢性毒剂：能够破坏全身各组织细胞的呼吸功能，使肌体不能利用氧气，于是头晕、呼吸困难、瞳孔散大。主要毒剂是氢氰酸。
5. 刺激性毒剂：能够刺激眼部和呼吸道，引起流泪、咳嗽、喷嚏、呕吐。主要毒剂是苯乙酰氯、亚当氏气。

由于敌人经常将毒剂混合使用，因此实战时化学武器引起的伤害是多方面的。
