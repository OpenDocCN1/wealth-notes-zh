# 对海上浮游目标射击

海上视界，射界广阔，气象变化较大，有时阳光照射水面产生反射光，目标游荡不定。因此，测距距离容易读近，瞄准偏差较大，击发时机不易掌握。但只要反复练习，掌握规律，就能提高对海上浮游目标射击的技能。

射击时，通常应采取稳态表尺，瞄点中中央或下半部。当目标在浪尖（谷）时，注意保持瞄准点与缺口的平正关系，并平压扳机，在前浪刚过，后浪爬起的缓慢间隙，迅速果断击发。

# 戴防毒面具射击

戴防毒面具时应按要领戴好防毒面具，并尽量使瞄准的那只眼睛上的镜片与缺口垂直。抵肩要稳实，头部不应过度前倾，以免射击时碰破镜片。戴面具最好装上照明片或涂上照明膏。
