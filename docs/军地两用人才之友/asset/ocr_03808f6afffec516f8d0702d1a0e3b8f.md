# 洗衣机的工作原理与分类

+   1. 工作原理：洗衣机的整个洗涤过程是仿效人工洗涤的某几种方式，如：搓洗、锤击、甩打、冲刷等，在洗衣桶内浸浓水温一定的条件下，使衣物和水、洗涤剂（洗衣粉、皂粉之类的相对耐碱运动），依靠在水流冲击中产生的水流冲击及其它机械力，如：水流的上下载流、水平回转力、涡卷力、腔壁挤压、甩打力等的物理去污作用，加上洗涤剂的去污特性，达到洗净衣物的目的，保证了洗衣机能洗净衣物。
