# 土壤水分

土壤是一个疏松多孔体，其中布满著大大小小蜂窝状的孔隙，直径0.001～0.1毫米的土壤孔隙叫做毛细管孔隙。存在于土壤毛管孔隙中的水分能够作物直接吸收利用，同时，还能溶解和输送土壤养分。

毛管水可以上下左右移动，但移动的快慢决定于土壤的松紧程度。松紧适宜，移动速度最快；过松过紧，移动速度都较慢。

降雨或灌溉后，降雨地面积水蒸发，下层水分沿着毛管迅速向表上升，应在分离层及时采取耕中、耙、耙等措施，使地表形成一个疏松的隔离层，切断上下层毛管的联系，防止透晒。“锄头有水”的科学道理就在是里。

土壤含水量降至萎蔫点以下时，毛管水运行基本停止，土壤水分主要以气化方式向大气散失。这时进行耕行（耙地），使地表形成略为紧实的屋层，一方面可以截通已断裂的毛细管，使底部储蓄水作用不上来；另一方面可以减少大孔隙，防止水分快速散失，以免风吹‘晒’子裂缝，产生‘板结’。疏松后地面，使底层上再形成一个平整而略松的隔离层，保持效果更好。

# 土壤气

土壤空气对作物种子发芽、根系发育、微生物活动及养分转化都能产生较大的影响。生产上应用深松土、破除板结、排水、晒田（蓄稻田）等措施，以改善土壤通气状况，促进作物生长发育。

# 土壤砂粘程度简易识别方法

| 土壤质量 | 特征 | 识别 | 简易识别方法 | 适种作物 |
|---|---|---|---|---|
| 沙土 | 肥力低、保水差 | 含有大量粗砂、细砂和少量粉砂。土壤颗粒干松而无团粒结构，湿润时，不能捏成团，稍微用手一碰即散开。 | 粗砂土、沙土 | 地瓜、土豆、花生和谷子等 |
| 沙壤土 | 保水性较强 | 含砂量多，细砂少,8成砂土2成粘土。用手捏成团时，易碎易散开，团块轻轻捏碎后，不能捏成条。耕作时对有轻度的板结现象 | 高粱、谷子、玉米、地瓜、棉花等 |
| 壤土 | 肥力高、保水保肥力强 | 含沙量与粘含量差不多。用手捏时颗粒能有砂粒存在，颗粒能以较长的长度拉长，但不能弯成环状。用手捏挫不散手 | 高粱、玉米、大豆、棉花、糖菜等 |
