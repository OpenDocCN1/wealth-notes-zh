# 录音机的选择

磁带录音机有盘式和盒式两种。

盘式，指使用金属或塑料盘、盒磁带和供带的录音机，通常使用的带宽度为6.25毫米。走带速度有9.53厘米/秒和19.05厘米/秒两种。这种录音机具有较高的电声指标，但使用时首先必须穿引磁带，操作复杂，易于损坏磁带，且体积大，携带不便，售价高，一般家庭很少使用。

盒式，指使用统一规格的盒式磁带的录音机。它又分为普通、微型和大型式三种。其磁带装在制成的磁带盒中，普通盒式磁带宽度3.81毫米，走带速度为4.75厘米/秒，磁带盒外部尺寸为100×63×10毫米。小型式机带盒尺寸为150×106×13毫米，带宽为6.25毫米，带速为9.53厘米/秒；微型盒式机磁带盒为50.2×33.5×8.15毫米，带宽为3.81毫米，带速为2.38厘米/秒。

由于盒式机器具有体积小、重量轻、携带方便，不易损伤磁带等优点，因而应用十分普遍。现各型盒式录音机。

录音机按其功能可分，有单放机、录放机、收、录两用机，立体声机和多用机。

# 录音、消音

录音机的录音过程就是声音→电能→磁能的转换过程。录音机的放音过程和录音过程相反，其能量转换过程是磁能→电能→声。概括起来，录、放音就是电流、电能、磁能的相互转换。

+   （1）录音。录音信号源输出的音频信号电流（电压）进入录音机，经录音放大器进行放大，这些信号电流（电压）可以来自电视机、调频式收音机的鉴频输出或调幅式收音机的检波输出，也可以来自机内、外话筒等。故放大的音频信号电流通过录音磁头线圈时，

便产生随音频电变化的磁通（磁力线）。当磁带紧贴着磁头的磁隙不断地移动时，变化着的磁力线就通过磁头磁隙形成感应，于是磁带因磁化而将声音记录下来。录音的同时，还给磁头加上一个由超音频振荡器产生的超音频偏磁电流。这样的偏磁电流下的信号放在放音时失真小、音质好，并可以在磁带上长期保存。

# （2）消音。录音机的交流消音和重放消音磁头，交流消音

的过程是，录音时，移动中的磁带，在录音磁头前面先经过一个消音磁头，可使磁带上已有信息的信号消失，然后再经过录音磁头。消音磁头和录音磁头的缝隙有一段，不同时的，是消音磁头围绕着通过磁带所产生的强大超音频电流，在消音磁头的缝隙处产生一个与超音频相对应的交流磁场。这个磁场在消音磁头的中心为最强，而已存在磁带上原有的信号被这个强磁场全部消掉，磁带经过消音头时，就被强度逐渐增大的磁场所磁化。当磁带走到缝隙中心达到最强时，把磁带上原来记录声音的剩余磁信息全部抵消。当磁带继续向前走时，磁场强度又逐渐减弱，一直到零。最后磁带上原来的声音被完全消掉，于是又可进行新的录音。一般高级的盘式录音机采用的是交流消音法，消音盒式录音机大多用直流消音法。直流消音法比较简单，只是在消音磁头绕组里通入强大的直流电流，使磁带经过消音磁头时被直流磁场磁化到饱和为止，从而实现消音。交流消音法比直流消音法效果好，消音干净，而且其耗电小。

# （3）放音。录音机的放音和录音，是通过电源开关进行转换，共用一个磁头。其结构是由具有空隙的环状铁芯和线圈等部分组成。

在放音时当录好声音的磁带按录音时相同的方向和速度紧贴放音磁头缝隙移动时，由于磁化了的磁带与磁头的缝隙状磁力线因磁场强弱不同，磁头中的铁芯上，磁带上的音频剩余磁化磁力线就通过铁芯，并随着磁带的变换感应磁头线圈，从而产生与原来录音一样的音频电流，经放大器放大得到原声音的声音。

普通录音和立体声录音

盒式录音机的磁带录音方法多采用二声轨单声道的普通录音和四声轨双声道的立体声录音。

二声轨单声道录音方式是对声放在第一声轨上录音（即磁带的“A”面或“1”面），当磁带用完时，再换磁放到“B”面或“2”面，送到第三声轨上录音。目的都是给单声道录音机或这两种方式用。

立体声四声轨双声道的录音方式是最初在“A”面放第一和第二声轨上录音，当磁带用完时，将磁带倒过来“B”面进行第四和第三声轨上的录音。用下来磁带，录音有两个系统，磁头磁隙和线圈也有两个，分别称为左、右声道。左声道是第一和第四声轨，右声道是第二和第三声轨。

立体声盒式录音机所采用的就是一种双声道立体声录音方式。录制立体声节目时，由于声源的空间分布位置不同，使得到达两只录音话筒时的左右声道信号的强度和时间，相位各有不同，两者的信号强度差、时间差和相位差构成立体声的定位信息，立体声重放时，通过

左右两声道经两只扬声器放出声音，将显这种强度差、时间和相位差，立体声节目正是由用人的双耳能够分辨来自不同方位的声音的特点（人耳双耳效应），使听者感到，声音并非单纯的来自两侧扬声器，而是出现在了两侧扬声器之间的空间的某一点，因为它以似“声源”的形式呈现在他的声音上，从而使听者获得重放声音的立体感和场感。由于此可知，立体声音箱左右两声道扬声器所发出的声音是不一样的，它们必须各自有独立的录、放音通道，有两个以上的扬声器或两条组合放声系统。

有某些扬声器的录音机不一定就是立体声录音机。有些单声道的录音机设计成两个扬声器的样子，其目的就是为了扩散扬声器散发的高频影响和根据产品造型上的美观，加强产品的商品性。

# 录音机的选择

挑选录音机主要从电气性能、机械性能和外观三方面去观察。

+   (1) 机械性能的挑选：
①操作各键应灵敏、准确、不费力。
②在正带正常、卷带快速时，走带系统的机械摩擦和振动的声音应小。同时观磁带的卷绕应平整不松不平。
③磁带盒转动方便，不发生磁带门关闭不严或打不开的现象。

+   ①音响效果的关键影响因素是录放磁头的质量优劣。可以打开盖门，并拆下套纸盘，使磁头伸出，仔细观察磁头包角是否圆滑。若有凹陷或不平整现象，部也许造成效果。

+   ②用试听带进行放音，试听喇叭的质量如何，并调节音量，音调旋钮，看其是否控制灵敏，若有失控、间断或跳变现象，说明质量不好。

+   ③进行试录。若选择收录两用机，可以先利用收音机录一段音乐节目，然后放音比较。应当与收音效果接近而不应出现明显失真。再利用机内话筒在距话筒较近一处或靠近一只收音机，然后重放比较。应适当有真实感，而且声音宏大，若录音已载回放的磁带重放一收录一放一记录，再放音，仔细听声音是否干净，有否其他杂音。如果原来记录完全清晰，也无“咔哒”的噪声，说明拾音也是很好的。

插口：

+   （1）话筒输入插口（MIC）；利用外接话筒录音时，由此插入。
（2）线路输入插口（LINE IN）；电视机，收音机或其他高电平信号源时，信号由此插入。
（3）线路输出插口（LINE OUTPUT TACK），将机内的信号输出，一般用于转录或外接功率放大器。
（4）耳机输出插口（EARPHONE OUTPUT TACK）；当需要耳机输出时，耳机由此插入，同时切断机内扬声器电路使之不发声。
（5）外接扬声器插口（EXTERNAL SPEAKER JACK）；如需外接扬声器使用音箱，可由此插入。
（6）遥控插口（REMOTE），与外接遥控配合使用，可以利用外接开关控制机器的工作。其功能相当于一个外接的“暂停键”。

旋钮系：

+   （1）电源选择开关（POWER）；使用交流电时，应将它转至相应的电压档位上。一般为110v，220v两档。
（2）功能选择开关（FUNCTION SELECTOR）；在放音；
收录两机上设置此开关，以选择收音（RADIO）或录放音（TAPE）两功能。
（3）工作方式开关（MODE）：立体声机上才具有此开关，用来选择立体声或单声道两种方式。
（4）磁带选择开关（TAPE SELECTOR）：一般有三档，用以选择使用不同磁带时适应的工作方式。○
（5）监听开关（MON）：为监听录音内容而设。
（6）波段开关（BAND SELECTOR），在收录两用机上，用此开关选择收音的波段，一般有“中波”、“短波”、“调频”三档。
（7）音调控制旋钮（TONE），用此来控制收音时高低频成分的比例，以提高音质。有些还采用滑动开关来做控制。
（8）音量控制旋钮（VOLUME）；用于控制播放音量的大小。对不少录音电平有自动拍动的机器，还有着录音电平调节作用。
（9）调谐旋钮：在收播放机和收录两用机上，用此旋钮选择所需收听的电台信号。使用时应与调谐指示盘配合。
（10）平衡旋钮（BALANCE），在立体声机上，用来分别调节左右声道的输出以达到平衡，使立体声效果增强。
（11）拍频开关（BEAT CUT SWITCH），打开此开关，可以消除超音频振荡与收音机本机振荡，或与某电台信号所产生的拍频噪声。

# 使用

由于内外录音机产品型号较多，设计各有不同，使用方法也不一样。因此在使用前应首先阅读使用说明书，了解该机的特点，明确使用注意事项。特别是要熟记该机的各个按钮、控制旋钮、插口位置及其功能，以免在使用时发生错误动作。

# 录音机的维护与保养

注意维护与保养录音机，将能提高录放音效果与延长使用寿命。
录音机日常维护与保养应注意以下几个方面:
“七防”；1. 防尘：不用时应盖布罩好，防尘积止。平时不可随盖打开后盖，以免机芯沾上灰尘。

+   2. 防潮：录音机应置于干燥处或潮湿处。? 每天应通电工作 1 ~ 2 小时以驱除潮气。在野外使用时注意防潮雨。3. 防热：录音机应防止日晒曝晒，勿置于温度高于60℃的场所。4. 防震：电视机、收音机、小音箱等震动之处，不宜放置录音机，更不可直接将磁带置于以上所举的电器设备上。5. 防撞：使用或搬动时，注意轻拿轻放，防止撞碰和外壳等的冲撞。6. 防腐蚀：为了保证外形美观，需要擦拭时勿用蜡布。不可常常接触其他化学药品。长期不用时，应认真将电池取出，以防电池腐蚀而腐蚀破坏。7. 防雷击：雷雨天应改用机内电池供电而不要用交流电源，以防雷电损坏机件。雷雨天在室外使用时请勿拉出拉杆天线或外接或调频节目。

清洗：录音机的磁头、主驱动、压轮轮等部位，使用时积了颗有油脂和磁粉，会影响到录音效果，须用棉棒沾酒精或清凉油小心加以擦拭。

法：录音机使用一段时间（半年左右），应当清洗并调整。要在换电池时，如马达、主轴轴、压轮轴等，可加几滴精制润滑油 1 ~ 2 滴。注意切忌太多，以防流出轮轴使磁带转动打滑，时间长了还可能使轮轴变松。

润滑：录音机长期使用后，磁头将不同程度地被磁化，从而导致录放音效果衰变，高音明显衰减。所以磁头使用50小时之后应用消磁器消磁一次。

最后一项注意事项，使用完毕，应使各功能键回复原位，以免触内弹簧或长时间被拉伸而丧失弹性。胶轮等长期受压力可产生变松。

使用时注意减少噪音，磁带平时应盖好，不可于强磁源附近。

磁带：普通录音机只能使用普通磁带。某些磁带并开关键的录音机，在使用可逆性磁带时，应注意将磁带选择开关扳到相应的位置上。

录音机收音或连续使用时间不宜过长，一般不要超过四个小时。若需连续使用，中间必须停机休息半小时。使用中如有发现机壳过热，或有烧灼臭味，应立即检修检查。

# 简单故障的排除

录音机简单故障时，切勿乱拆乱卸修，应当仔细分析故障现象，作出正确判断后再动手维修。

+   1. 不工作；当发现录音机不能工作，电动机也不能转动时，应立即切断电源，停机检查一下各功能按键是否处在于恰当位置，特别注意排除停止钮与暂停钮。若开关，按钮均处正位置，可改用机内电源试试能否工作。若能工作，说明是外电源输入部分的故障，应检查电源线、电源选择开关、变压器等是否接触良好。若仍不能工作，说明是机内故障，应检查。

+   2. 声音内；走带正常而收音无声时，应先关一键测试是否放音。若仍无放音，应检查各按键、开关位置是否正确，有否错误操作。然后查各音量旋钮是否已打开，扬声器是否有短路，录音放音头的引线是否可靠，磁头与磁带是否良好接触。发现毛病即应修复。

+   3. 不能录音；走带正常，放音正常而无法录音，一般原因为控制开关失灵或不到位。此处，内线或活动插头，"话筒输入"和"线路输入"插口接触不良或引出线断，也会引起无法录音。录放音磁头损坏也可能造成无法录音，但同时也无法放音。

+   4. 放音单；走带正常，录、放音均正常而只是音轻，最常见的原因在于录音、放音头表面被污物，或使用日久，磨损处出现严重磨损。应于清洗或更换。内线局部电容断开或振荡频率过低，也可能造成音轻微弱。可将磁带装于另一台完好的机器上放音一次，便可对照判断出毛病所在。

5. 噪声大；使用不当，往往使录音时失真严重。如录音电平选择太大，利用线路输入时没有适当用衰减器等等，都是原因。磁带质量很差，也会产生失真声音。此外，则是机内电路工作不正常所致，这种故障应请个别检修恢复。

予以调整。

要导必免，电源电压的漂移，电机转速不稳定，机内稳压电路损坏会导致磁带播放走不稳。传动机构工作不正如传动胶轮变形，传动带老化或沾上油污打滑，或是某一转轴不正，转轴轴承发涩都会造成带速不稳。应根据验证修复更换或加润滑油，注意应加润滑油。另 外，也可能因为盒式磁带的磨擦带片和磨擦带片相互导致摩擦力不均，或卷带过松打滑，应当更换磁器垫片。或先将磁带用快进键卷紧一遍，再倒带使运用。

带松、严重。放音时，发现声音发抖，主要故障出于机械传动方面。
先查音传动胶轮与压带轮是否沾有油污或偏动不正。另 外可检查磁带是否有点带过的现象。若带带过紧，可将磁带置于左手心，用右手轻轻拍打，使其松弛，或用铅笔插入轮芯，并转动磁带盒使磁带重新绷紧。

轧带。所 录音中，即磁带被缠绕到机壳上 主轴上。常见的原 因是操作不当所损伤，如快进时突然 转到放音，就 牵引发生带拉伤。原因 轮不清洁或变形，也造成轧带。发现轧带应立即停机，切断电源，然后打开匣门，将盒盖取出，再用镊子夹住被轧的磁带轻轻拉出。如 果拉不出，应小心打开后盖，用手轻轻反向转动，然 后后轮就可取下。应 轧带后，应更换偏垫，若继续使用，无 严重产生 轧带，放出磁带除 。
