# 绿表

| 名 称 | 含氮量(%) | 性 质 | 施 用 方 法 |
|---|---|---|---|
| 硫 酸 铵 | 44～46 | 白色结晶，中性，吸湿性强。加氮剂制黑瘦 数缓，肥效较几种铵肥慢 | 宜作底肥和追肥。独用昌此比其他氮肥迟。追肥应比其他氮肥早施5～7天。叶面喷施浓度为0.2～2％ |
| 石 灰 氨 | 18～22 | 黑褐色粉末，碱性，有刺激性和腐蚀性，不溶于水，肥效较缓 | 宜作底肥，必须在播种前半个月施用。如作追肥，必须事先将石灰氨与堆肥或土拌10～20天再用。盐碱土上不宜直接施用 |
| 硝酸铵钙 | 20～25 | 淡灰色或浅黄色粉末，.碱性，遇湿大时易结化，速效 | 宜作早追肥 |
| 硝酸铵镁 | 25～27 | 淡黄色粉末，酸性，有腐蚀性，速效 | 宜作追肥或底肥 |
| 过磷酸钙 含磷量(%) | 14～18 | 灰白色粉末，酸性，有腐蚀性和吸湿性，速效 | 作底施。口形和苗圃，旱田杀虫或速效。
水稻田苗圃，本田最好将过磷酸钙掺入土中，或沾扶胡桃，施于沙土、黑土以及流胶盐碱的“红蛮滩”上，效果高 |
| 磷酸镁肥 含磷量(%) | 16～18 | 淡灰色粉末，碱性，不溶于水，缓效 | 宜作底肥。施用前与有机肥料掺和20～30天，酸性土壤和豆科作物施用效果高 |
| 磷酸铜肥 含磷量(%) | 20～30 | 灰褐色粉末，微碱性，不吸湿，缓效 | 宜作底肥 |
