# 2. 电表的工作原理

当电流表接入电路后，电压线圈与电流线圈所产生的两个相位不同的磁场形成了躲避磁场，这个磁场作用在铝盘上冲击出涡流。由涡流与磁场相互作用的结果，彼使铝盘产生一定方向的转动动力矩，驱动铝盘一直方向转动。铁芯使永久磁铁起制动作用，产生制动力矩与载荷作用力矩平衡。使铝盘均匀运动于制动磁铁间同时，铝盘转动与载荷器联动，通过铝盘轴上的涡环带动计数器，所以可以记录电路上消耗的电能。由于负载上电路，电能以及它们相角差的余弦的乘积，因而积累的读数就等于电路中消耗的有功电能。
