# 机动脚踏两用车

# 机动脚踏两用车结构及工作原理

机动脚踏两用车(简称两用车)是轻型机动交通工具，目前国产都以单汽缸两冲程式汽油内燃机作动力。它的特点：体积小，机身轻，运动平稳，是汽油和空气在汽缸外化油器中混合成一定比例，在活塞下移时吸入汽缸点火燃烧。用发动机火花塞点火火花线，利用燃气膨胀的热能变成机械能。活塞往复直线运动，带动连杆曲柄旋转运动，经过齿轮传动，推动车轮向前滚动进行。当发动机不工作时，能以脚踏驱动自行车使用，故称两用车。

发动机工作原理解说：发动机的活塞在汽缸内从上止点(汽缸体最高位置)，达到下止点(汽缸体最低位置)，被称为一个冲程，上下一个完成就是两个冲程；连续完成四冲程，压缩、燃烧、膨胀、排气四过程，合起来就是一个循环，而实际上下两个冲程发动机工作，只有膨胀过程做功、产生人力作用，其他是曲轴惯性停驱动进行，还会消耗能量；如轻骑15型、永久103型两用车用外露锥齿轮，行星大齿轮带动锥齿轮，增加惯性作用，使曲轴旋转速度变小些，在低速运转时平稳。永久105型发动机的是一种内藏飞轮的齿轮小，在低速行车多发运动转“惯轮”时快时慢不均须现现象，要加大手门增加速度，曲轴转速增高，行车才趋正常。

两用车发动机系采用浮子式化油器，燃料是用汽油与机油混合液，在经过时油箱进入化油器的化油器，与经过滤清器的空气混合挥发变成混合气体；这个作用的原理为浮碗滴渗与油器相间，混合气对发动机工作影响很大，通常一公斤汽油完全燃烧，需要十五公斤空气，如果空气与汽油比例在6：1时，混合气过浓，选到着火极限，在混合气不能燃烧时，浓度在1：12：1时气过稀燃烧，功率减少、耗油明显增大，因氧气不足，燃烧不完全，排出浓烟，内部机件会严重积碳；在13～14：1这时较稳，功率最大，耗油量比正常情况会增加20％。所以油气混合比采用15：1比例，虽然功率小些，省油，...
