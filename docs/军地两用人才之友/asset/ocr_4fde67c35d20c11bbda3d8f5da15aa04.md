# 压缩式冰箱的结构原理

压缩式冰箱由箱体、制冷系统和电器控制系统三部分组成如图1。箱体包括外壳、内壳、门及各种附件。内、外壳之间充填绝热材料。除外壳用铁皮包覆制成以外，其余构件如内壳、门封、钉钮、绝热层、容器、箱梁等，几乎都用塑料制造。

制冷系统由压缩机、冷凝器、节流阀、蒸发器四部分组成，它们之间充满制冷剂（如氟利昂、氨等），构成一个密闭的循环系统。压缩机是电冰箱的核心，是电冰箱的动力所在。电冰箱性能的好坏，在很大程度上决定于压缩机的质量。最常用的是在旁边装有蒸发器的卧式压缩机，与电动风机相连，并装在箱内两内。冷凝器装在箱外，用来将制冷系统中的致冷剂微液化。小型家用冰箱多用空气自然冷却的方法。蒸发器装于箱体内靠，它利用氟化液的原热使箱内部分温度下降。节流器起调节流量作用，家庭用电冰箱普遍采用毛细管作为节流器，它结构简单，制造成容易，举停以后使系统内的压力逐渐达到平衡，有利于压缩机的再次启动。
