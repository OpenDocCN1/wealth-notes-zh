# （三）夜间驾驭仪。主要供坦克和各种车辆夜间行载使用。

夜视器材按使用原理分为主动式与被动式两种。

# （一）主动式夜视器材，是利用红外辐射源对射红外线，并由受相管将目标反射回来的红外线变化可供观察用。

# （二）被动式夜视装置材，本身没有红外辐射源，它又可分为两种。

一种是热相仪，是利用目标本身的热辐射，即目标与背景的温度差来测定目标。属于红外夜视器材的范围，另一种是微光夜视器材，它能把照射到目标上的微弱自然光线（月光、星光）增敞放大数万至几万倍，从而使眼睛能在夜间观察到目标。

主动式夜视器材最容易被对方发现，而被动式夜视器材则比较隐蔽。但被动式夜视器材在雾（雾）的夜间，其性能不如主动式夜视器材好。

# 夜视器材的缺点

夜视器材虽然能提高夜间观察、侦察和射击的效能，但在技术性能上也还存在着一定的缺点，主要是：

+   （一）分辨能力差。观察场景和目标，不如白间那么清晰、直观。不能区分地物、目标周围环境的自然色彩，只能根据外形、轮廓以及各种物体不同亮度对比来判定目标性质。
（二）受室外照明、红外夜视器材依赖于人工光源，用电流的电源发射，黑暗的环境下，开机时间内，虽对敌方无影响。
（三）受气候等条件的影响。如遇雨、雪、雾等天气和烟尘等，近红外和微光、热相夜视器材的观察效能便受到影响，暴雨、大雪、浓雾等天气，甚至可使一般夜视器材对付不清视标。
（四）受地形、地物的影响。起伏的地形地物也会降低夜视器材的观察效能，如在观察地带内有高地、从林、土（雪）堆、堤岸、沟渠、暗壕、夜视器材的作业距离就会显著缩短。地形地物所构成的死角，夜视器材也难以克服。
（五）视界有限。观察和搜索目标不便。夜视器材的视界一般为8—16度，最大的视界为28—30度。
