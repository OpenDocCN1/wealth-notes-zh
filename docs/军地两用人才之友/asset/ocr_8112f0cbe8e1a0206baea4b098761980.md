试运转中应注意的问题：

+   1. 试运转应由专人负责进行。
2. 试运转中要着重听发动机机的声音，观察有无漏油、漏水、工作是否正常。发现<|start|>出问题即应排除。
3. 拖拉机运转中要观察机器的工作情况，检查各操纵机构动作是否正常、传动、变速箱内有无异常声响、运转部分、轴承等处有无过热现象。发现异常应立即停车检查。
4. 试运转结束后，应按第一、二技术保养时举行保养，按照二号技术保养要求更换发动机曲轴箱和变速箱内润滑油。先放尽脏油(因黏合而附着油网上有许多金属屑)，再用柴油清洗，放出清洗柴油，加入新润滑油。
5. 柴油机在更换某些零件(如活塞环、活塞、轴瓦、气缸套等)后，也应进行假设试运转，顺序也是由低速到高速空转，再逐渐增加负荷，试运转结束后，也应清洗油箱，更换润滑油。
