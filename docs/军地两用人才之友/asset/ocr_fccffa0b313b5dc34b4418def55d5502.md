# 几种军用卫星

自从一九五七年十月第一颗逃离地球卫星发射成功以来，苏美出于争霸世界的目的，都在拼命发展军用卫星，并使卫星变成了所謂战略武器的重要组成部分。近十年来，军用卫星的发展相当迅速。按照不同的用途，大致可分为：

1. 侦察卫星。主要用于发现地面、海 showing 和空中 的敌人各种目标。在卫星上有电视、摄影和红外线观察等光电仪器，利用摄影等手法获取敌人为目标的外部形象，卫星上的电子摄像器材则制造出敌方雷达信号。通过信号电台系统传递到地面站所发生的电子信号及其位置。并从通信中取得 Mitsubishi 情况，从电波信号的特性中取得到关人电子设备的技术情报。你察卫星所获得的信息自动保存刻在记录器中，当卫星飞经本国的地面接收站上空时，就自动射出信息并被接收单位。 2. 导弹预警卫星。它用于洲际弹道导弹的发射井，卫星上的红外线感应接收器，能接收到被那区域发射洲际弹道导弹时所辐射的动热并立刻传讯。卫星上的监测装置可以测出敌导弹的弹道参数、从而测算其落弹目标。导弹预警卫星通常是处在地球同步轨道上。它的轨道在赤道上空三万五千八百约公里的高度上。卫星自同东云东行，与地球自转其有相同 的方向和相应的周期，在地球上一圈大约为“静止的”，所以人们称之为同步卫星或静止卫星。实际上同步卫星一直是以每小时一万一千零七十公里的速度在围绕地球的轨道上运动的。3. 导航卫星。导航卫星的用途是测定位于海洋上的舰队或空中飞机的精确位置的。此外还有气象卫星、通信卫星、测星卫星和一些其它用途的军用卫星，如核探测卫星等等。
