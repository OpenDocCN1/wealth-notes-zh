# 2. 注意事项

安装的地点应远离高温、通风以及无蒸汽等腐蚀性气体的地方，表应该先放在板上或木箱里，然后再固定在稳定的地方，避免震动，以免表内机械零件损坏，产生误差。安装的位置要高一些，离地面应不小于1.8米；以一根成人立直不弯着为好，以避免触电。几个电度表并列安装时，其中心距离不小于200毫米，距离太近时，容易发生异响，接线盒内的螺丝应全部拧紧，爱防止雨淋和受潮，并保持干燥；每一个电度表要配一个保险保险闸盒，在保险闸盒的拉环上，应系一根细绳，其长短以成人手伸到恰好合适。万一发生漏电、走火、触电时，可以迅速拉开闸盒，切断电源；保险丝的选用要与电度表安放
