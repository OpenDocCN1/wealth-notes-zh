# 门、窗扇的制作

和门，窗扇比较，门、窗扇要求贵一些或者说要细一些。因门窗扇结实洁净和美观。在结构上门、窗扇大都是在门窗边上做榫孔、门、窗档（或称横梁）上做榫。

普通门扇厚度是40毫米，窗扇厚度是35毫米。至于拉门、自门也差不多各一类。门、窗扇的常规做法和门、窗框的构造是一样，<|message|> 应当讲究着把门框开口线起，或着要设计成玻璃开口或骑马时要以榫厚为标准。在画门窗线时以起线面做为基准面，这样能够保持线坪整。
