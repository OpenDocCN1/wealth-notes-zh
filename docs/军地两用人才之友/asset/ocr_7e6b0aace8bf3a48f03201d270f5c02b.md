# 照相机的选择

# 照相机性能选择：

照相机按机体和镜头可分为大、中、小及微型等几类，每类照相机均有自己的用途和优缺点。大型照相机（即座盘照相机，拍摄的幅面可达一平方米到数平方米） 像于制作大幅幅片或制作印刷，影像的技术质量比其它较好。中型照相机机身易携卸，携带较为方便，有者需要三角架支撑稳定，有者则可手持拍摄。小型照相机体积小，重量轻，携带轻便，运送灵活，便于拍摄生动的瞬间。也可连续拍摄，以便事后从中选取最佳照片。微型照相机体积很小，它配有超高焦距分辨率的镜头，所需照片可以满足光学放大的要求。有的还备有电子测光和曝光自动控制系统，以提高照片的质量。

新闻摄影及业余爱好者通常用的小型照相机，从135照相机、120照相机等135、120张照相机三种。

# 照相机的选择要根据用途

用途；选择照相机首先明确自己的用途与要求，是作普通摄影还是特殊用途摄影。

镜头质量的优劣对摄影效果起着600作用。挑选的鉴别方法：检查镜头面，开足光圈，打开B门，对光检查，看镜头面是否有霉点或像似似痕。

观察镜头的清晰度。在照相机后面感光片的位置上放一塊磨砂玻璃，通过它观察书报上的字迹，越清晰的越好。

观察镜头的分辨率。把书报按成线板，观察相面范围内能分辨的线条、线数越多，镜头分辨力越强。

色彩的检验。以红、黄、蓝三色作为检验的目标物，调焦后如发现蓝色焦点聚在前，黄色在中间，红色在后，三者不能同时清晰就是说明镜头存有色差缺点。

# 照相机的使用

# 使用照相机应注意的事项

拍摄时相机必须保持平直，以免影像在底片上出现倾斜，失去画面的平衡。仰、俯拍摄应适宜，否则影像变形特别明显，尤其拍摄人。
