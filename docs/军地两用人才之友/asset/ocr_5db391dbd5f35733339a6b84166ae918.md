# 油漆材料

漆油 可作为厚漆和防锈漆调配时的油料用，也可单独使用，但油膜柔软，易发粘。

自取漆油 在建筑工地上用的最广，不论木材面、抹灰面和一般物件等刷油前都先用它打底。

厚漆 又名钝油，需要加油，溶剂等稀释后才能使用。可作建筑面漆的涂漆配，也可单独表面涂刷，但光亮度、坚硬性较差。厚漆也可用来调配油色和腻子等。

调合漆 分为油性和酸性两类。油性调合漆适用于室外表面涂刷。磁漆等适用于室内较适宜。

清漆 是一种不含颜料的，以树脂作为主要或唯一的物质的透明油漆，分油漆清漆和树脂清漆两类。油漆清漆俗称凡立水，如酚醛清漆、醋胶清漆、酯酸清漆、醇酸清漆等。树脂清漆不含干性油，如虫胶清漆等。

+   1. 酚醛清漆 适用于木器家具、门窗、板壁等的涂刷及金属表面上光。
2. 醇酸清漆 适用于室内外木器和金属面装饰。
3. 醋酸清漆 俗称三宝清漆。适用于喷、刷室内外金属、木材表面。
4. 虫胶清漆 俗称稀立水。适用于木材面的底漆和高级家具的出光。一般用于木器家具装饰。
5. 酚醛清漆，又名喷涂漆，俗称腊光。适用于高级建筑的门窗、板壁、扶手等装饰上。
6. 氨基清漆 适用于仪表木壳、收音机、缝纫机台板、家具等涂饰，是一种较理想的涂料。但干燥方法受一定条件的限制，操作比较麻烦。
7. 丙烯酸木器清漆 适合喷高级木制品及家具等。
