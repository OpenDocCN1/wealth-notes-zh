电路控制系统中有起动继电器、保护继电器、温度控制器和化霜装置等，分别起电动机的起动、保护、温度的调节与试验和蒸发器表面化霜的作用。
冷冻室内的水汽在冷冻过程中会凝结在蒸发器上面形成一层霜。由于霜层的导热系数低，它的存在大大降低了蒸发制冷的效率，所以必须及时清除掉。化霜的方法有自然升温融化与蒸发器上附加的电热丝通电加热融化两种，后者为化霜较，对箱内温度影响小。

# 电冰箱的质量检查

对电冰箱进行质量检查，一般只能进行直观检查。要求外观漂亮无明显划痕、胶套、手把等电镀一般亮、机件装配紧固。当关上开箱门时，开合力大约应适中，门封条或磁性无明显扭曲变形，门关闭后不应有大的缝隙；旋转温度控制器应灵敏。至于内在质量，各制冷厂在产品出厂前均按规定做过各种性能试验，尚能保证。

# 电冰箱在使用中注意的问题

电冰箱如要运远，安装不当时，会影响到它的使用效果。搬运时要保证冷藏室平稳，窄斜会使冷凝器液滴冲击冷凝系统或蒸发器内，造成使用效果不良，而且容易把压缩机装配弹簧脱钩。
电冰箱应放置在通风好，干燥、远离热源及煤燃盛放于20厘米以上的室内，箱体与房和的顶壁间约为50厘米以上。因为放在夏日炎热近热源、通风差的地方，会使电冰箱冷凝散热困难，使压缩机负荷相对加重，耗电量也增加。坏境潮湿及高湿度危险机的影响相对。
通电时应先预冷试验约2~3小时，在运行正常、冷却效果良好时(蒸发器结霜均匀即温度均匀)，即可将食品贮存箱内。如果冰箱第一起动，保经杂志标准，一般是由电冰箱制冷器装得太小了。保险丝的电流规格应按冷冻箱额定电流的6~7倍选用。
