# TM—46式防坦克地雷（图6）

雷壳是金属的，内装猛葱棕炸药5.7公斤，中间有一直径40毫米圆柱形猛葱爆炸簧药块。地雷全重8.5公斤，能挂戴中型坦克履带。

此雷使用MB—5引信或46式地雷引信。当使用MB—5引信时，用普通触发盖盖，也可带46式不可取出引信装置盖盖，使用MB—5引信时，当盖盖上受到200—700公斤的压力地雷即爆炸。有时雷下设有效发的计数装置。

# 与敌夜视器材作战

近年来，外军特别是苏、美军，夜视器材的种类、数量和质量，都有很大发展，为其夜间战斗行动创造了一定的有利条件。但是，夜视器材的效果有限，它不能从根本上改变夜晚这一自然条件的特点。因此，正确认识夜视器材的作用，了解其性能和特点学会对付它们的办法，对于削弱我军的行动图出其不意地消灭敌人，有着重要的意义。
