# 6. 四种类型洗衣机的优、缺点比较

| 类型 | 优点 | 缺点 |
|---|---|---|
| 颚式破碎机 | 洗涤时间短, 洗净度高, 结构简单, 成本低, 容易制造和维修 | 对衣物的损伤大, 特别对纤细排列的织物损伤更严重, 洗涤时易使衣物缠绕、撕裂, 洗净度的均匀性不好, 破损洗衣机的产量愈来愈少 |
| 搅拌式 | 一次可洗较大衣物, 洗净度适中, 对纤细的织物损伤率较低, 洗涤的均匀性较好 | 洗涤时间较长, 搅拌机构复杂, 制造困难, 成本高, 维修对要求高, 需电多, 噪声大, 占地面面积大, 机体庞重, 宜用热水洗涤, 经济性差 |
| 摇臂式 | 用水量较省, 衣物洗后不拧皱, 洗衣盆较大, 可达 5 ~ 20 公斤(一衣), 洗衣粉用量少, 对衣物的磨损较轻 | 洗涤时间较长, 一般需 40 分钟 ~ 1 小时, 故耗电量大, 洗净度低. 为提高洗净度, 需经常换水、洗涤。洗衣机结构复杂, 造价高。常用不锈钢、铝板或钢板制造, 材料费昂贵, 成本高, 不宜制造小型洗衣机 |
| 波轮式 | 洗涤时间短, 洗净度好, 结构简单, 制造和维修容易, 成本低, 耗电少, 占地面面积小, 对衣物磨损率较低, 可用热水洗涤, 综合效益较好 | 对短纤细的织物损伤率略大, 用水量较大, 不宜制造大型洗衣机 |
