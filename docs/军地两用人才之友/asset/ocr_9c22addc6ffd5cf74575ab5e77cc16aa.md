士应利用敌坦克、地堡射击的火光、观察敌坦克、地堡的位置，选择便于观察、撤离邻近的路线。大胆从侧面迅速逼近敌坦克、地堡，要边接近边观察，将爆破器材准确地放置到敌坦克、地堡的要害部位，突然后将其破坏。火箭筒手应从暴露尽量接近敌坦克、地堡，占据有利地形，以其准确强大的火力将其破坏。

二、打扰或运动战法。战士夜间同打扰运输运动部队时，应利用照明、火光和透空观察，判明敌坦克运动的方向、路线，迅速在敌坦克经过之时，放砲或弹地堡弹、炸药包等，将其炸毁。也可以占据有利地形等待时机，当敌坦克运动至适当距离，乘其转向、上下坡、越障、减速等有利时机，迅速靠近，接近敌坦克，爆破器材将其炸毁。火筒筒、单兵火药手，应以猛烈射击将其击毁。

# 打 坦 克

战士同敌坦克作战斗争，要发扬英雄顽强、不怕牺牲的精神，顽强突<|start|>，灵活机动、快、准、狠地将敌坦克消灭。

# 爆破敌坦克的准备工作

战士要接受打敌坦克的任务后，首先要树立坚定歼敌的信心，并迅速做好准备：①认真观察、有关情况、大看地。②准备好爆破器材，检查拉火药。雷管和导线的连接、固定是否妥当。③整理好装备、装备，捆好炸药器材。④根据敌坦克的位置、前进方向，充分利用有利地形，选择接近路线，确定打敌坦克的方法，做好接近敌坦克的准备。

# 对固定坦克的爆破方法

打固定坦克，应利用地形地物和敌坦克观察、射击的死角，迅速而蔽地接近，以炸药包、爆破筒、反坦克手雷、炸药将其炸毁。
