# 一、准备击杀。

当听到准备击杀的口令时，应迅速装填子弹（火药手榴弹或手雷），关上保险，准备好手榴弹、借助好爆炸器具；整理好服装，整齐。战士在遵从命令时，动作要迅速，在不妨碍火器发挥原有性能的前提下，切实采取防毒面具措施。最好既是或联出搜索的雀、并在阵地（组）长指挥。

当担任隐蔽联通道路任务时，应选择接近线路，秘密迅速地见到指定位置，注意观察、潜听，听着迅速地完成破障物，同时应做好强攻弃的准备。

在开放全地中开辟通路时，应应用地形地物掩蔽，查清是否有音响、照明装置，如有应加以排除。如使用胶桥剪破铁丝网时，应先将前进面前的铁丝，从木桩附近剪一遍，然后双手抓住带胶丝的两端，蘸前由木桩处一端，慢慢将其折断，将长的一端抛入地底，尔后由下向上依次进行。

在敌区附近联通道路时，应首先探测地雷的位置，查明有无设计埋雷，再进行布置。布置时，用手轻拨探伤雷，然后拨到另一侧清除掉连接装置，同时释放信号及信号与信号的触合方法，后后进行拆除。完成开辟通路任务后，应进行标示，并立即报告，同时做好守备的准备。

# 二、奇袭时

奇袭时，战士得到奇袭信号后，应肃静跃起或跃出壕堑，快速前进，注意观察敌情、地形，保持冲击方向和联络，秘密迅速地通过通道，避免过度地突击、不要“喊”声，勇猛冲入敌阵，以抵近射击，手榴弹、刺刀、爆炸器材破坏敌阵，消灭敌步兵。

# 炸毁坦克、地堡

夜间炸毁坦克、地堡，应发挥勇敢顽强，不怕牺牲的精神，乘敌乱之际，秘密迅速地接近，突然将炸药撤下。
