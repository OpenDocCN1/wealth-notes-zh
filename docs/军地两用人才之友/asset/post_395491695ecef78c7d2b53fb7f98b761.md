一、顺入双刀法。刀子运行的方向是由上到下，或者说是自外向内。每一笔笔画两端要先刻就中间，先起刻如逆一刀，然后转弯处，再刮左边的一刀，嘎面流出来。如果还有不足之处，可略加修复，但不能够待太多太多等，否则就会有精神了。
二、顺入单刀法。刀子运行的方向和上一种相同。每一笔画只用一刀刻成，或者是由右向左沿路线下刻，横面可以形成逆向方刻通。刀子的角度应比上一节多倾一些，如果下刀太直，则刻出的笔画就会不够粗，但倾斜过分，笔画会过于太浅，应掌握适当地。
三、逆入双刀法。刀子运行的方向与前两种相反，是由下而上，或者说是自内向外推出。每一笔画也是两刀刻成。
四、逆入单刀法。逆入方法与上一节相同。每一笔笔画一刀刻成。以上四种刻刀法，在雕刻的过程中，有时要重复，有时要轻一笔，有时要重一点，有时要直切下笔，有时要平抛过去，有时刀锋要显露一点，有时又要把刀锋藏隐起来，如此运笔用笔，才能把概念表现，充分发挥生动。
总之，用刀如用笔，继承方法与刀法相当，古人把刻刀称为“铁笔”，也很有道理。齐白石曾说过，刻印有三种刀法：剔、蚀、刻。所谓“刻”，就是用刀如用笔。混凝细细刻下去，不似修描，自是成形。这是正确的方法。所谓“蚀”，就是象蚕食叶一样，小点点地啃进边去；所谓“剔”，就是到边缘处，一刀又一刀地轻轻地剔出来。这两种方法，刻不出笔法和神采来。一般学者认为，往往不是大胆运用，或者顾忌到难以用刻刀法，粗细难也掌握不好，这就严重影响，不必气馁。待到久久不成功，刀与笔融会贯通，刀法笔法浑然一体，这就达到成熟的境界了。

# 平印写稿

平印章 买回的石章，外表涂过白蜡，表皮又粗糙，需裱加工磨光才能应用。蘸印面时，宜将砂纸平放在玻璃板上，用力须四周均衡，像磨墨那祥，磨几下换一祥，否则印面不平整，不要使四角陷下去。

写印稿 在纸定印章后，先持一小块烟型纸夹在印面上用手轻轻压出印章轮廓，用毛笔描成轮廓，再按计划的释字习惯在框里面。墨色要浓，不要用褪墨，宿墨著水则化，不能应用。

透写稿 印稿写好后，须带放时，可operating稿上，其法如下：

+   （1）将印稿正反面置于纸位，放置位置，用左手提定四边。
（2）用少许清水使纸面润湿，另以毛边纸二层蒙于其上，亦要四边稳贴，不让笔墨移动。
（3）露出印面部分，用右手拇指的指甲在纸面上反复磨研磨（如右图），先四边后中间，至印面全部反磨剥为止。
（4）轻轻揭露纸面，印稿上的墨迹便完全被印到上。

如果发现有不够清晰的地方，可以用毛笔补足之。

除文直接写在印面上外，也有著作者把印文反写在印面上，有的将印稿先写在透明纸上，然后将纸背向上一，照着反面所印的笔画模仿在印面。描成后，对照观察，再作修改。这两种方法，虽较简便，但初学不易掌握，不如用透写的方法为好，等熟练以后，再采用直接在印写写稿的方法，较执适宜。印稿漾到印面上以后，就可以开始动刀刻了。

# 寻名署款

印面刻好以后，刻者还可以以在印章的左侧面或顶部署上一个款。署款有长有短，长款却纪念印动机或感想，或表达印文的含义等；短款只署姓名，或加印月而已。凡作长款，一面容纳不下，可向左顺序继续下去，直至画眉，最后总至举于顶部。

# 拓款用具

检刚（如右图），用棕榈皮薄扎而成，长约八厘米，直径约三点五厘米。松色，可以自制，用棉花一小团裹以塑料薄膜，绘画毛笔一执，外系纸包光滑细密的薄钢丝起条，扎住即成，大小略略等盛珠。

白炭水 白炭可向中药店购买，用二至三片泡成一小盏微棕的白炭水备用。

干净毛笔 择纸纸、选史纸、墨、础及少许毛边纸，如无选史纸，可用绵纸或毛糙纸。

# 拓款方法

+   一、这款刻成后，如需拓在纸上，应先制净勒屑，并使表面清洁无油蜡。
二、用白炭水使表面湿润，蒙上选史纸，用干净毛笔水抹上去，使拓面略为湿透为度，继以毛边纸复在上面用手掌按着使其紧贴，然后揭去毛边纸。
三、用剪具纸缓在上面，一手执住印章，一手拿刷在背纸纸上反复刷擦，先刷右边，要四面周到。押纸纸随刷随移，不使受湿破碎。手法轻重度，力量要适当。
四、刷破后，字迹便清晰地显露出来，此时即可移开裱纸，用拓包蘸少许浓墨在面上扑打，先拓空白，后及文字，得墨色浓厚，字迹完全清晰即告完成。待于揭下，便成。

# 国画书籍托裱方法

国画书法一版都用宣纸绘就，纸质薄而有韧性，经过托裱之后，画面平展无皱，基色更显层次，形象更加突出，能提高表现效果。局画书法的裱装需要在学习传统裱装技法的革面上通过实践不断摸索，不断总结，才可率掌握。这里简略介绍一下托裱、裱画书法的方法将其背面向上放在工作案上，先用清水喷匀，成为湿润状态，使纸张伸展，也可变换用滚水在纸上轻轻均匀地涂刷前纸的淀粉糊液。再把裱画的里子纸（用细纱的净水纸如棉纸、单宣、皮纸等先喷湿卷起米）平铺在底面上，用绵刷排匀，将两层纸粘合。随后将粘合的纸翘起米使画面面向上，在四边都裁一道具装裱画裁纸或裁纸板上（画裱黑以便保护），即可吊裱下裱法。这是一种平托法。另一种一些工艺类原本，历年早可采用飞托的方法。飞托法与平托法在地区方法有些细微差别。
①托心：在字画的背面托上一层裱心。托心的办法是将画底背面向上放在工作案上，先用清水喷匀，成为湿润状态，使纸张伸展，也可变换用滚水在纸上轻轻均匀地涂刷前纸的淀粉糊液。再把裱画的里子纸（用细纱的净水纸如棉纸、单宣、皮纸等先喷湿卷起米）平铺在底面上，用绵刷排匀，将两层纸粘合。随后将粘合的纸翘起米使画面面向上，在四边都裁一道具装裱画裁纸或裁纸板上（画裱黑以便保护），即可吊裱下裱法。这是一种平托法。另一一些工艺类原本，历年早可采用飞托的方法。飞托法与平托法在地区方法有些细微差别。
在里子纸上，再把画毯托裱上去，其操作方法与平托法相同。
②配纸：将要裱面的纸质、纹纹纸或线条等供给（用线子时，常先用胶将裱），接画面的大小，选择适当的裱装好裱装。
③模条：在画面四边裱上色彩、宽度合适的边条，以衬托画面。裱时，先把配好的边条放在工作案上，先在一边粘上约0.3厘米宽的糊糊糊，再贴到画的边缘上，再把一层纸手掌推压，要防止边条打起、皱皱，然后逐边贴粘。
如果是在画面上需要引进一连贯样的辅助色线，可用半纸毫米宽的色条，先贴在画面四边之上，粘贴三分之一露出三分之二，然后翻过来贴到画上，在四边的纸条上半粘上浆糊，把缠边的纸条贴上。这样留出一条细的色纸条。
④方形：按裱据尺寸将裱边裁齐。

⑤复背：在托好底、镶了边的画面背后，再裱个衬一层夹裱纸。
复背时，先在背面用棕刷蘸清水或喷水，使纸上湿度均匀后，卷起放在一边；把复背纸放在工作案上涂刷糨糊。然后将画面揭开，画面胸上粘在复背纸上，边展开边用羊毛毡轻拍，使其被贴实。再翻过来从背面用棕刷将其抹宽，待最后揭起贴到纸墙上或靠在竹竿上晾干，干后取下来裱方。

# 编织藤篮

用竹、藤之类编织的日用品，是中国民间传统手艺。这里介绍一种藤篮的编织法，用的是皮条。藤皮在专门出售藤类的商店有售。藤皮质地各异的薄厚，也有外面包有一层塑料，后者有多种颜色，织起来成品外表更美观。

首先编织箪底，像（图一）所示，用十多条二十厘米长皮条成放射状，每根皮条的长短相同，以整一个箪底的直径加上底皮加几分松位为准。编织底皮时，用一根藤皮交叉地围绕着放射状皮条中央，一圈一圈地编成小花，如（图一）那样。

# 塑料板加工

塑料板的裁制，可以做成沸水中煮一会使它变软，然后可以用剪刀像剪布那样来对塑料板进行裁剪。用锯也可对塑料板进行裁剪。

在裁剪的过程中，如果遇到有不整齐的地方，可以先用粗砂纸再用细砂纸来打磨，然后用市面上一些牙膏来作成一步步的打磨。只要耐心，用这个方法可以把不太光滑的塑料板镜面般地磨得干净。

要想把塑料板做成所需的形状，方法有二。要是比较简单的变形，用一个吹发的电风筒的热风来吹欲改变形状的部分，塑料板软化之后，就可以随意弯它、剪、折、扭等的形状改变；
在【图一】中看到被热化了的塑料板板等的简单的工作如圆筒、木方之类来加工成不同形状的过程。要注意在这个过程中只有在塑料板软化的条件下才能进行，硬化便不能加工。因此，在有需要的时候，可以反复进行对加工件的软化，或者不断地让风筒的蒸气加热下来进行。
