片中需要表现雾，使用蓝色的滤色镜可以加重雾的效果。如果雾气较重，不必另加滤色镜。选择背景，要尽量避免天空占据面积太大，最好以远山、森林和其它建筑物为背景。选择拍摄点，最好要有远、中、近景物。选择拍摄时机，最好是云雾缭绕或雾霾较多的情况。为了在照片上表现雾的气氛，曝光必须预先补，而在显影时适当缩短时间。借以获得较调的底片。

# 水上摄影

水上共有的特点是: ①平均光值比同样光照度下的陆地强; ②由于水面反光和水蒸气多，景物反差较小; ③条、夏季光值较低，空气中水蒸气多能见度差，常有水天一体，表现逆光和天空反射强度。水上拍摄近景，无须用滤光，逆光、和地色上亮、按明和部分光值曝光。拍远景，正常曝光反差由于层次和次数减少，宜缩小一线或半线光圈，如上午八至十点钟，用B 21“全色片，加一枚中黄滤色镜，可用1/1的光圈，1/250秒。逆光水面范围闪光点会增加水的气势，但也要避免水面光点过于集中，防止底片发生光晕。由于水上摄影的对象颜色比陆地上单调，红、橙、绿色少，用低感度的微粒片，层次、色调、模拟完毕都比较理想地发挥效果。

水上摄影大部分情况都需使用滤色镜，以求抵天空和水面反射光的强度，使底片反差适中。经常用的滤色镜有淡黄、中黄滤色镜和偏光镜。淡的黄、橙色滤色镜可使天空、它被水面间的天空透视效果，使用的色调深沉，而且还分低天空变成棱一面的无界明显的沉闷的感觉。欲显示水深、波浪澎湃，在大侧光或逆光情形下，可用中黄或起滤色镜，比如加增强对比度，适当加深水的颜色，突出水面起伏的白色浪花，以显示此种高速度前进。

在船上活动，由于拍摄距离狭窄，活动的余地小，选择拍摄角度限制很大，除精心选择拍摄位置外，船相机必须配备防水壳。冬季，船舱内温度差异大，由船面传入镜头，雾气易形成。镜头上往往产生蒸汽水珠，碗等水拿或隔开才能拍照，否则影响摄影的清晰度，最好是注意小心照相机的温度差，使其镜头上不产生水珠。
