力大，身体易下沉，呼吸困难和容易疲劳，所以动作要领要有相应的改变；

+   1. 划臂、握枪的力量要适当加大，但不过量超过快；呼吸次数相对减少（一旋臂划 2—3 次作一次呼吸），以便节省体力，持久运游。
2. 两臂划水时，稍向下压，两腿蹬夹水时，稍向后下方向用力，同时小腹微收，使臀部撑起，以保持身体平衡，防止下沉。

# 分队武装泅渡

分队武装泅渡，主要是根据条件组织的组织指挥和分队的协同动作。

+   1. 选点出发。横渡江河、海峡，为了能继续到达预定登陆点，泅渡必定进行 víz 运动方向和当地群众调查，根据地形、水情和泅渡技术状况选定越渡点，并计算出偏差距离（图 2）。

![](bbox=[0.18, 0.52, 0.78, 0.78])

计算公式：
偏差距离 = 河宽（米） / 流速（米／秒） × 流速（米／秒）

通常每宽 500—800米，流速每秒 0.5米以下正常时，可按 25—30 度角：流速每秒 0.6—1米时，按 45—55度角 流速每秒 1—1.5 米时，可按 55—65度角选择越渡点。

为了准确掌握越渡的方向，应在对岸选择几个方位物，条件许可，应组织试渡。泅渡时，还应由领队引导分队前进。

+   2. 洞 流 队 形。洞 队 形 的 编 制，应 根据当时情况、水情、任务。
