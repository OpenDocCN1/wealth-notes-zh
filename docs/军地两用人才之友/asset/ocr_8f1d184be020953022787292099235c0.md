# （4）肺丝虫。肺丝虫寄生在羊的气管和支气管内，引起 menus 咳嗽。

咳嗽。严重时羊体消瘦，出现窒息死亡。

治疗：①用稀碘酒进行气管注液。用碘片1克，碘化钾1.5克，冷开水150毫升，配成注射液。当天配制当天用。预防的犬小，体表瘦弱，病久以后8～10毫升作气管注液。隔1～2天后再注一次。每只内服复方乙醚合剂。内服时按每公-_ 羊体重17.5毫克作药用，并配成10%的水剂内服。注射时用10%的溶液，按每公斤体重用0.15毫克作皮下或肌肉注射。

# 防治羊的外寄生虫：

+   ① 单身螨。它寄生在绵羊和附近的腋窝内。
症状：由于妈虫刺破皮肤，引出瘙痒和炎症，流出大量脓疱。
治疗：用1%的精制敌百虫溶液浸洗羊的患处。

+   ② 羊疥癣（又称生螨）寄生部位常见羊毛脱落，露出皮肤，皮变得厚实，表面不平，到处疮疤，引出瘙痒。
治疗：①将制敌百虫的0.5%的清水溶液喷雾器对准患部喷洒，或直接涂擦。②将可湿性六六六粉直接涂擦患部，但不可用油调。用前两种药治疗疥癣时，一次涂擦的面积，最多不能超过整个全身的三分之一，以免中毒。

# 防治羊东瘟病疥：

羔羊稍断奶后7天以内的易于易感染。由于气温剧变、潮湿、畜温过低、或营养不良、羔羊瘦弱，更易导致本病发生。
症状：不想吃、拉稀，粪便先是灰白或淡黄色，后变红色和褐色，并有恶臭。常在2～3天内死亡。
治疗

+   ①用氨苄素制剂作肌肉注射。每次12.5万单位，每天2次。
②磺胺嘧啶1克，硫酸蛋白0.2克，碳酸氢钠0.2克，一次内服，每天三次。
③取大蒜50克，放入100克养酒精中浸泡7天，取出大蒜酒1份加温水4份，每次以10～15毫升灌羊，连续2～3天。
