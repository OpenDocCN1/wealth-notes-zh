# 枣

枣树是小乔木果树，生长很慢。根蘖萌生的枣苗，一年可长一米左右。并非抽生分枝。第一年可长到一米左右，并形成 2—3 个主枝，很快形成树冠。到 7—8 年年轻长基本成熟，分枝逐渐增多，十年后树冠继续扩大，果产逐渐增多。十五年后进入盛果期，一直到 50—80 年才逐渐衰老，但嫁接得很强，200—300 年的老枣树仍能开花结果。
枣树的修剪，一般在秋季10月或11月上旬进行。翌年3—4 月也可剪。对于从内膛萌发的徒长枝，在夏季萌发时就剪去，以减少养分的消耗，改善光照条件，增加座果。保留下来的徒长枝也要urchase处理，削去它的长势，把它培养成结果枝。一些长势的结果枝，每年 issuing 有一定的“枣头”发生，要适时剪去，防止形成结果繁杂，对交叉、密挤、重叠的枝条一定要及早剪去，使树体通风透光。衰老树wl，衰弱阴光老枝，使其更新新壮，对于根部萌发的筱芽，要及时除除、加紧箍，可诱导矮化，一、二年后便可移载。

# 山楂

山楂是北方各地产种的一种果树。它们适应性强，容易萌生根蘖。一般由自然形成。刚定植的幼苗，当年生长较慢，2—3 年后植株茂密，5—6 年开花结果，10年左右进入盛果期。山楂生长较旺，一般50—60年后不衰老，结果很多。山楂树整形：1—2 年生的幼树，已形成分枝，可将60—80厘米以外的分枝全部截除，在其部位以上的选 3—5 枝作为主枝，葡藤形成多主枝的树冠。2—3 年除 I 去过密的主干外，一般不必再整形。4—5 年的树冠可基本成形。结果期，中、长枝结果，一般二年后萌生结果一次，防止主枝光秃。结果的延长枝可适当修剪，过密的小枝也可去掉一部分。盛果期，主要剪去较弱的大枝，以便回缩更新。
