# 搬运伤员

常用的伤员搬运法、除躺架搬运外，还有如下方法：

侧身弯身搬运法：这种方法用于平坦开阔地。救援人员侧卧于伤员背后，屈曲贴地的肩腿，使伤员倒向向上，其胸腹部倒卧在救援人员胸的上，使伤员上身稍斜仰（或斜仰）在救援人员的右侧。救援人员在上的手将伤员下伸到自己胸部或系住伤员的肩部。另一臂屈曲，前臂着地撑起上身，用上前面的腿腿推，推动身体带着伤员前进（图四十八）。

俯卧背负搬运法：这种方法适于不易颠震的平坦开阔地，姿势较低，救援人员手脚比较自由，但比载力。此法不能用于胸、腹部、四肢骨折的伤员。适用与头、背部。方法如下：先使伤员自侧躺，腿屈于膝下，或弯成屈膝在自己一侧，将伤员的右手先放在自己的右侧腰下，再把伤员的左腿放在自己的腿中间，用左手将伤员的左臂拉到自己的左臂上，有右手抓住伤员两手，再以左手扶住伤员右侧臀部的衣服，用力拉起，使伤员身体靠近自己的背部。用力翻转身体，可将伤员翻到背上。这时扶伤员成正面向前，两手再随放开接 obiect 前进（低姿或高姿）的方针前进（图四十九）。
