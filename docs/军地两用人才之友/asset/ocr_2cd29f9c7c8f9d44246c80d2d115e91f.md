# 三相鼠笼型感应电动机的构造

三相鼠笼型感应电动机主要由定子和转子两部分组成。定子是固定不动的部分，转子是旋转的部分，转子装在定子当中，从此之间存在着一个很小的间隙，称为气隙。其间的动能传递是由电磁感应作用来完成的，因此称为三相感应电动机。

由于转子绕组结构形式的不同，三相感应电动机有鼠笼型和绕组型之分，鼠笼型三相感应电动机的外形及部件见图1。

# 1. 定子

图 1 三相鼠笼型感应电动机的构造

定子是由机座、定子铁芯和定子绕组三部分组成。定子铁芯是由厚度为 0.5毫米，表面涂有绝缘漆的圆形硅钢片迭压而成，固定在机座中，作为磁路。在定子铁芯的内圆上，冲有嵌放定子绕组的狭槽。定子绕组是由绝缘包线绕制，在三相感应电动机的定子铁芯中嵌放着对称为三相定子绕组。三相绕组的三个线头用大头别出线联接后分别接到装在机座外壳上的引线盒中。
