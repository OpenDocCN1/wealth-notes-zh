# 绿肥

绿肥来源广，质量好，投资小，见效快，收益大，是一个重要的农家有机肥源。

栽培的绿肥多是豆科植物，根上长有根瘤，根瘤里面有根瘤菌，能固定空气中的氮素，供给豆科植物，并将多余部分分泌到土壤中。绿肥作物压榨烂后，增加了土壤中的氮素养分。

豆科绿肥作物具有很强的根系，可以吸收利用土壤深层的养分，同时还分泌各种有机酸，溶解帮助一般作物难以吸收利用的养分，绿肥作物压榨烂后，丰富了耕层土壤养分，为后套作物创造了肥力条件。

绿肥草含有机质含量占 15～20％，如以亩产草率 3,000公斤计算，就能增加有机质 300～400斤，可以改善土壤的保水、保肥、通气和温度的能力。

豆科绿肥含蛋白质多，营养丰富，是家畜的优良饲料。蛋白质经家畜吸收后，其中大部分来自粪尿中排出。绿肥先饲畜，后作肥料，是更经济的利用方法。
