# 会计 业务

# 会计的基础工作及会计职能

现阶段的社会主义会计，是以货币为主要计量单位，反映和监督社会主义再生产过程中资金运动的一种方法，是管理经济的一个工具。它包括会计核算、会计分析和会计检查三大部分。

从整个会计工作来说，会计核算工作是会计的基础工作，也就是记账、算账和报账这三方面的工作。它的具体内容：（1）审核和填制各种原始凭证、记账凭证；（2）运用会计科目、子目、细目、设虚总分类账户和明细账户；（3）登记日记账、明细账和总账，核对各项科目；（4）计算各种成本和各项收支；（5）计算和提取各项专用基金；（6）清点盘点各项财产物资；（7）编制各种会计报表；（8）整理保管会计档案。

会计的主要作用，可以概括为三个方面：（1）反映作用。（2）监督作用。（3）报道作用。也就是反映经济活动和经济状况，监督经济活动过程和结果，报道生产和生活情况，促进企业提高管理水平。因此，会计的一切作用，都是通过这种职能来实现的。反映和监督是密切联系的。会计监督必须以如实反映为基础，如果没有监督就没有反映，则会计监督就从实际上说，反之，如果只有反映，没有监督，会计工作就只起到记账、整理和报表的的作用，而不能发挥监督产生、经营经济，因此，在进行会计核算的同时，必须切实执行会计监督的职能，积极发挥会计监督的作用，使会计工作成为管理经济的有效工具。
