# 烟幕武器

早在第一、二世界大战中，各交战国都曾使用过烟幕并组织过专门烟幕部队。1943年10月至11月，苏军强渡第聂伯河时，有效地使用了烟幕，在六十九个夜晚实施伪装，致使敌人出动攻击二十三百多次，但只有6枚炸弹命中敌口。\n成功后，烟幕技术一夜被推迟。第二次大战争后，各国军事部门对烟幕技术的研究，苏美两国又大力发展烟幕武器。美国还新建了烟幕部队。许多战例证明，战争中使用视距不到10～15米的中间距离反X次波段烟幕，可减少部队伤亡90%以上，坦克及装甲车的损失可减少几分之二至四分之三。在原子弹战争条件下，烟幕还是制造光辐射破坏的有效武器，在核爆前10分就制造烟幕，根据爆炸距离影响点的面积，可将光辐射作用减低到原来的三分之一到四分之一。所以，烟幕武器在现代战争中，也是一个将必不可少的遮蔽和伪装武器。

目前，世界大多数国家武器库中的发射器材和发射药药种繁多，如发烟炮弹、发烟火箭弹、发烟榴、发烟手榴弹、发烟枪榴弹、发烟地雷，含多个发子于炸弹之发射烟、发烟筒、发烟车以及飞机场发烟器诀等。
