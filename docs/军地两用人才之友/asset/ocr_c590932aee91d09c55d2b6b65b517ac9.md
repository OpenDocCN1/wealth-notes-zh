# 防生物武器

战争中采用杀伤人、畜，毁坏农作物的致病微生物（包括细菌、立克次体、衣原体、病毒等）和细菌所产生的毒素叫微生物战剂。装有生物战剂的各种炸弹、导致弹头和气溶胶发生器、布酒器等<|start|>生物武器。

# 生物战剂照对人员伤害程度分类

+   (1) 失能性战剂，主要使人员暂时丧失战斗力。如布氏杆菌、炭疽杆菌与脑炎病毒等。

+   (2) 致死性战剂，使人员患严重疾病，死亡率大于10%。如鼠疫、黄热病病毒等。

按照所致疾病有无传染性分类：

+   (1) 传染性战剂，传染很强，一旦流行，能持续一定的时期。如鼠疫、天花等。

+   (2) 非传染性战剂，只感染接触者。如肉毒毒素等。 mainly用于对地方疫、设施目标。
