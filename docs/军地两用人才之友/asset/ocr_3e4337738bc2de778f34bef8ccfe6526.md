# 黄芩

黄芩为耐性性蔬菜，多采用育苗移栽，苗龄以到四到六片真叶时比较合适。因播种季节不同，培育适宜幼苗所需要时间也不一样，一般要25~40天。北方地方，一般9月上旬到10月上旬播种。直接播于圃即可。出苗后适当浇水，保持阴润。移栽在露地的苗，定植前，要搭荫棚，并在土壤<|start|>结前浇水，覆盖稻草、马粪等，保护越冬。

幼苗长到五、六片真叶，即可起苗定植。株行距25~30厘米。覆盖越冬的幼苗，于土壤解冻时，去除覆盖，定植前，苗墩浇透水、追肥。

在莲座叶形成期之前，宜早定植水，加密株种，提高苗温，促进早行蹲苗。当苗龄至已充分长大，模式开花时，要较早蹲苗，并在进行浇水、追肥。离苗肥大时，要保持土壤湿润，水、肥每次不宜太大，以免发生裂果现象。追肥一般需三次。

# 辣椒

辣椒适宜当早播种。育苗期需90天左右。

播种前，种子在0℃温水浸种8~10小时，然后取出保湿催芽，在25~30℃温度下催芽。种子大部分露白后，即可播种。播种室内温度要保持20℃以上，有利于迅速出苗。

育苗要选择多能育有机育苗土疏松、温暖、最好配合有机肥施入一些速效化肥。播种后使温度保持较高温度。当苗长到四、五片叶时，移栽一次，株行距7厘米左右，每穴1~3株。

栽培辣椒宜选择排水、排灌都方便和肥力较高的沙壤土为好，要求3年以上未重茬的地，多施基肥，并移入适当碎砖、碎肥，以利发根、结果。

由于定植初期气温较低，要注意少浇淡水。定植后浇一次水，中耕一次，生长现低，再浇一次水，同抬苗施肥浇水，深中耕第二次，进行蹲苗，直到底有核很大小，果实进入迅速生长时期，则要结束蹲苗，浇水、追肥，促进发枝和开果的生长。
