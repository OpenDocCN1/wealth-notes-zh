# 国画书籍托裱方法

国画书法一版都用宣纸绘就，纸质薄而有韧性，经过托裱之后，画面平展无皱，基色更显层次，形象更加突出，能提高表现效果。局画书法的裱装需要<|message|>在学习传统裱装技法的革面上通过实践不断摸索，不断总结，才可率掌握。这里简略介绍一下托裱、裱画书法的方法将其背面向上放在工作案上，先用清水喷匀，成为湿润状态，使纸张伸展，也可变换用滚水在纸上轻轻均匀地涂刷前纸的淀粉糊液。再把裱画的里子纸（用细纱的净水纸如棉纸、单宣、皮纸等先喷湿卷起米）平铺在底面上，用绵刷排匀，将两层纸粘合。随后将粘合的纸翘起米使画面面向上，在四边都裁一道具装裱画裁纸或裁纸板上（画裱黑以便保护），即可吊裱下裱法。这是一种平托法。另一种一些工艺类原本，历年早可采用飞托的方法。飞托法与平托法在地区方法有些细微差别。
①托心：在字画的背面托上一层裱心。托心的办法是将画底背面向上放在工作案上，先用清水喷匀，成为湿润状态，使纸张伸展，也可变换用滚水在纸上轻轻均匀地涂刷前纸的淀粉糊液。再把裱画的里子纸（用细纱的净水纸如棉纸、单宣、皮纸等先喷湿卷起米）平铺在底面上，用绵刷排匀，将两层纸粘合。随后将粘合的纸翘起米使画面面向上，在四边都裁一道具装裱画裁纸或裁纸板上（画裱黑以便保护），即可吊裱下裱法。这是一种平托法。另一一些工艺类原本，历年早可采用飞托的方法。飞托法与平托法在地区方法有些细微差别。
在里子纸上，再把画毯托裱上去，其操作方法与平托法相同。
②配纸：将要裱面的纸质、纹纹纸或线条等供给（用线子时，常先用胶将裱），接画面的大小，选择适当的裱装好裱装。
③模条：在画面四边裱上色彩、宽度合适的边条，以衬托画面。裱时，先把配好的边条放在工作案上，先在一边粘上约0.3厘米宽的糊糊糊，再贴到画的边缘上，再把一层纸手掌推压，要防止边条打起、皱皱，然后逐边贴粘。
如果是在画面上需要引进一连贯样的辅助色线，可用半纸毫米宽的色条，先贴在画面四边之上，粘贴三分之一露出三分之二，然后翻过来贴到画上，在四边的纸条上半粘上浆糊，把缠边的纸条贴上。这样留出一条细的色纸条。
④方形：按裱据尺寸将裱边裁齐。
