# 手表的使用和保养

+   1. 不要随意自行开启后盖，以避免尘、纤维等物进入表机，影响手表正常走时和破坏表机的防水性能。
2. 手表虽有防磁、防震、防水的性能，但在使用中仍应避免剧烈震动，如打锤、搬举、打球等。如果没有防震装置的手表，则更为严重。轻轻依谱挂表，手表要定，震动厉害者会使摆轴损伤，使手表走时变慢，或时走时停。
