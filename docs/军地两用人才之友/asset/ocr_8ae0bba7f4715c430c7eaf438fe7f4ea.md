# 做好防御准备

班（组）受领任务后，应接上级命令（信号）荫蔽迅速进入阵地，在规定的时间内，积极完成防御准备。

+   一、派出观察员，指定值班火器。 进入阵地后，班长应立即派出观察员、值定值班火器，并明确：观察员和值班火器的位置、方位角，敌人可能出现的方向；观察（射击）地、特别注意的方向和地段，发现情况报告的方法；值（记）号自己的位置。

+   二、规定任务，进行动员。 班长在规定任务前，应向前敌传达任务，视情况带领骨干或全班带弹侦察地形，分析敌情，判断敌坦克和步兵可能接近的道路和冲击道路。发扬军事民主，研究兵力、火器配置、障碍物设置及各种情况下战斗战斗方法。

+   三、规定战术，指定火力点。 尔后明确：①敌人的位置、可能进攻的方向和冲击地段；②排、班的防御阵地和特别固守的地段，射击范围，集中射击位置，放坦克的措施；③友邻位置、各级上级配置在班阵地内的火器位置、任务，与其协同的方法；④各班（战斗）的位置与任务；⑥配属火器的任务，基本发射阵地和预备发射阵地，射击地段，补助射击地段；⑦原子、防化学的措施，进出掩蔽部或战道的顺序；⑧完成防御准备的时间；⑨信（记）号。 班长规定任务后，应进行战斗动员，提出完成任务的《要求》，树立英勇杀敌、坚守阵地的必胜信心。

+   三、构筑工事，设置障碍。 班（组）应善于利用地形构筑工事。工事应便于发扬火力，便于打坦克，便于机动，力求坚固、低干、疏散、荫蔽，并严密伪装。 构筑工事时，班（组）长应结合规定作业任务和伪装的措施，明确工事的位置，设置障碍物和扫清视界、射界的地段、完成的时间。 构筑工事应集中力量迅速完成。作业顺序应选主后次，通常先扫清视界、射界，构筑单人掩体和火器发射阵地，再连接掩堤、构筑集蔽部和交通塹，并重点设置障碍物。在与敌直接接近时，应组织火力掩护，先完成火器发射阵地及单人掩体，尔后逐次加强。
