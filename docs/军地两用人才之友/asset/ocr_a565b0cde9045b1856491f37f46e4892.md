# 地基计算的基本原理

地基承受上部结构的全部重力。为了保证上部结构的安全和正常 
使用，要保证不出现在下两种情形：

第一，地基不能超出地基地极限。为了防止地基丧失稳定，地基必 
须具有足够的强度。对_web承受荷载的地基，应满足下列条件；

+   (1) 中心受压地基
P < R
式中 P —— 基底面底面处的总压力（吨/米²）；
R —— 修正后地基土的容许承载力（吨/米²）。

+   (2) 偏心受压地基
除符合公式 P < R 要求外,尚应符合下式要求:
Pmax < 1.2R
式中 Pmax —— 基底面边缘的最大压力（吨/米²）。

第二，地基变形不能过大或不均匀。地基在建筑物荷载作用下要产 
生变形，变形过大危害建筑物的安全。为了防止出现这种情况，地 
基需核算变形计算，即应满足下述条件；

+   S < f
式中 S —— 地基变形值；
f —— 地基容许变形值。

# 地基变形的分类

由于不同类型的建筑物，对地基变形的适应性是不同的。所以， 
在应用公式 S < f 验算地基变形时，要考虑不同建筑物采用不同的地 
基变形特征来进行比较和控制。地基变形依其特征可分为四种。
