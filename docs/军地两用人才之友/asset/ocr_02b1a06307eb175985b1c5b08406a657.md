# 准确曝光（曝光指数表的运用）

光圈与速度关系：光圈与光圈，光圈与速度的指数是成反比的。指数越大，光通量越小；指数越小，光通量越大。在同样情况下，要保证得到相对等的光通量，一般说来，光圈开大一挡，速度也必须提高一挡。反之，每缩小一挡光圈则必须降低一挡速度。各种相机的光圈和速度指数，都是以倍数来计算的。每一个相邻的速度指数之间的光圈相差一挡，但光圈指数仅在 8 以下每个指数才是一挡，8 以后的每是半挡。
