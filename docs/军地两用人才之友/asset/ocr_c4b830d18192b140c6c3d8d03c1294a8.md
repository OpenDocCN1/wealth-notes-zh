# 坚决消灭敌人。

占领冲击发生地后，应立即构筑（加修）工事，注意观察和伪装，看清冲击目标、前进路线、通信位置，记在心里记号。听到“准备冲击”的口令，应迅速装填子弹（火箭筒、单兵火箭筒为最好加装烟火弹），准备好手榴弹和燃烧瓶等，整理好服装，装好武器，做好跃起后跃出堑壕的准备，向班（组）长报告。

战士听到“冲击前进”的口令，应迅速跃起或跃出堑壕，迅速前进。前进中，注意观察，发现目标以行进间射击（火箭筒、单兵火箭筒停止间射击），消灭敌人步兵和坦克。通过堑壕时，应低跑通过。进入抢滩高地，自动作毂炮（班）长、班长随即进入敌方堑壕内投弹，逐手榴弹等布隆布隆，或大喊“杀”声，勇猛冲入敌人据地，以抵近射击、刺刀消灭敌人。并不断地指向目标冲前追。

遇到几个敌人对自己构成拌斗时，应首先消灭最近的，尔后再各个消灭。格斗中应主动地援助兄弟，以刺刀、抵近射击消灭敌人。

# 炸毁敌坦克

战士炸毁敌坦克时，应表现英勇顽强，不怕牺牲的精神，善于同敌坦克作深厚斗争，以及坦克武器、器材，坚决消灭敌坦克。

受领炸毁敌坦克任务后，应迅速就地埋好、收回枪刺，关上保险，大背包、好囊等需卸下，检查武器，检查火箭筒。取出合適的，整理好武器，携带好燃烧瓶等，根据敌坦克的位置，reta走合适、选择合适的路线，做好爆破准备。火箭筒、单兵火箭筒手选择好射击位置，根据敌坦克的位置或运动方向，距高，做好射击准备。

爆炸敌人坦克时，选报距离（组）长口令，利用我火力和烟幕掩护，或趁佳火灭减、减弱的有利时机，灵活地利用地形地物和敌坦克视界，时机出发或，迅速接近敌坦克或地。接近时要不断观察。敌坦克、机枪等发生诱导各种情况，当坦克进入我射击时，应灵活地变换位置和运动路线，或向敌人投掷手榴弹或燃烧瓶，趁爆炸的烟尘，迅速靠近敌坦克或坦克侧后接近，推面隐蔽好后将爆破器材投放到敌坦克的要害部位上，沉着拉火，然后迅速离去，就近利用地形掩蔽，或迅速原地准备，做出再次爆破的准备。炸毁敌坦克后，如敌坦克
