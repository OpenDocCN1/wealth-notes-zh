# 生姜

生姜为宿根植物，喜潮湿温暖的环境，生长期适宜温度25—28℃。要求土质肥沃，排水良好，不宜作畦。一般姜地要在前年临霜降进行冬耕，深翻2尺左右，并进行起垄做畦，畦面宽窄平并做成规整，深沟高畦，唯高6尺左右。同时必须开好沟排水，沟距1.8尺左右，每畦8寸。在整地开沟作畦的同时，施足基肥。播种前将种姜泡起，放室内催芽2天，种批选用白皮粉色“武打芽”、“鸡豆芽”等，挑选切口等。芽块大小应根据薯龄的密度而定，一般每块种姜重约1—3两。

生姜栽种一般于清明前，行距1.5—2尺，株距6—7寸。栽姜时芽向上下，并覆盖火泥盖，每块姜种一大约，然后再在姜沟的斜坡面覆盖火泥，隔膜牛粪黄，每亩约100余担，或块草10—20担。随即再将培成块状泥覆住，覆姜2寸，施肥熟人畜粪肥以肥，以施种拍。在姜苗出土后到开，三个道施氮肥。第一次追施畦肥20斤或人畜粪25担；第二次追施壮苗肥，此时期是黄梅天，多量，宜施腐熟油坊80斤；夏至前后第三次追肥油坊250斤、火灰粪80担；施后并用清水10—15担或牛粪50担覆盖，以保持土壤湿润；第四、第五次分别在大伏、处暑前后追施姜肥。

姜苗仅需，怕强烈阳光，在春夏生长时期更适宜于遮荫遮成的散光线，要有有六分到七分的阴凉的环境。

姜的病害主要有炭疽病病，又称姜瘟。在田间出现病株时，应立即拔除，<|start|>次要选用石灰消毒。药物防冶，播种前用25%草木灰水浸泡种姜15分钟或浸水多放石灰处理10分钟，七、七月间用50%代森锌500—800倍溶液喷，隔7—10天一次，连续两、三次；预防发病；发病初期，可喷酒50%代森胺1000倍，每隔7天喷一次，连续两、三次，抑制病害蔓延和蔓延。

姜的虫害主要有姜螨，又称红心虫、腐虫，一年发生三、四次，9月为盛发期，防治方法：用1：400倍可湿性六六六药液灌注，连续3—4次；发现苗苗，立即用刀在被害处挖开并杀之。
