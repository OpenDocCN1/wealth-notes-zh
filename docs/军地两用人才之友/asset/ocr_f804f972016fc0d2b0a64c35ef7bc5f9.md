2. 加热过度或时间过长，维生素损失增多。如蔬菜切成块，食用油炒 9～10分钟，抗坏血酸损失16%，胡萝卜素[促进人体正常发育，维持正常视觉功能和一切上皮组织及皮肤的完整和对细胞的抗病力]，抗坏血酸损失24%等。油菜切成丝，用油炒5～10分钟，抗坏血酸损失36%，胡萝卜素损失24%等。炸菜因为为高温和高温油炸，可使硫胺素完全损失，核黄素和尼克酸损失50%左右。烹调时高温，蔬菜的损失，在红烧和清炖时损失60～65%。蒸和油炸时损失43～47%。

3. 氧化而损失 蔬菜切碎后放置过久，抗坏血酸可通过切口与空气接触被氧化而损失；蔬菜烹调后不宜即食，故置过久，也使抗坏血酸损失。

4. 加入碱而损失 在烹调食物时加碱可增加硫胺酸和抗坏血酸的破坏损失。而煮菜醋，则可减少抗坏血酸的损失。

# 烹调简介

1. 火候：指火力的强弱和用火时间的长短。掌握火候是烹调蔬菜的一个重要关键。不同的火力与不同的用火时间[即火候]可以得到不同的加热效果。用各种不同的原料，就<|message|>似做各式各样的饭菜。在烹调中，常用的火力有旺火、中火、小火和微火四种。

旺火：火势强而猛烈，呈白色黄，光明度大，热度很强。旺火适用于快速烹制使原料容易成熟的烹调方法，如炒、溜、炙、蒸等。中火：火势稍弱，火色呈红色夺目，热度很高。中火适用于炸、爆、烹等速捷调理方法。小火：火势低而绵长，呈青蓝色，光度较暗，热度较低。小火适用于较慢烹制使原料被吸入味的烹调方法，如炖、煮、焖、扒等。微火：火势很微。微火适用于较长时间烹制使原料酥烂的烹调方法
