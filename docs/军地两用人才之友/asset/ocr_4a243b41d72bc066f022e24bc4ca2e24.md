# 续表

| 故障 | 原 因 | 排除 方法 |
| --- | --- | --- |
| 电动机过热或冒烟 | 过负荷。 | 减轻负载或更换较大的电动机。 |
|  | 电源电压过高或过低。 | 应调整电源电压，使电动机电压与额定值的偏差不超过 ±10%。 |
|  | 绕组损坏。
1.星形接法的电动机误接成三角形。
2.三角形接法的电动机误接成星形。 | 1.电动机容易烧毁或受电容电容损坏时，应立即停机修复。
2.轻载可以过活，严重时应更换电动机，应当更换。 |
|  | 通风不良或堵塞。 | 检查电动机风道是否堵塞，风扇是否损坏，带露器是否... |
| 或冒烟 | 绕线转子相条。 | 检查修复。 |
|  | 定子与转子相擦。 | 校正转子中心线，换去定子转子相擦部分，更换新绕组。 |
|  | 叠绕组绕组线圈匝数减少。 | 找出短路点，重新绕制。 |
|  | 定子线圈线间或匝间短路。 | 找出短路点，重新绕制或更换线圈。 |
| 电动机声音异常 | 单相运行。 | 同上。 |
|  | 滚珠轴承损坏。 | 轴承缺油，加油；轴承损坏，滚动面上布条，应更换轴承，有杂音应除。 |
|  | 定子线圈相擦。 | 端盖位置不正，应校正位置。
电动机轴弯曲，应校正。 |
|  | 机身振动，安装不良，转子不平衡。 | 做好校正，紧固地脚螺栓，检查修复。 |
