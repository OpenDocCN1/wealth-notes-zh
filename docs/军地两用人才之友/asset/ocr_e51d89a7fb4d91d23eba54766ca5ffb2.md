初学木工的人创制时的通病是创出的料不直，这种不直又多是两端低中间高，原因是创端的下不平。正确的创制姿势，应是左脚在前，右脚在后，挺住于向前而推动，手的姿势是手掌在创柄上，两个食指压在创刀前柄，两个拇指压在创刀后部，手指向后而起扳，在创刀接触木材时，食指压着的创前柄指用力很缓，而食后部渐渐移到底木材上时，拇指不向前而指还要意识地下压，这样才使创出的木料平直。

# 钜锉 又名锉板、架锯。从形式上分为钜锉、刀锉、钢丝锉等。

锉条 由用不同制，其长短、宽厚等相对应的不一样，一般是因为锉条的长短变化。锉条的长度定于锯条之间锯条的长度，一般的长度大约为长度的二分之一。锉条与锯架之间的距离略有稍大，目的是能锯解较宽的木料。被锯的木料应当干燥、不易变形而有较高的强度、韧性，可用软木、橡胶等制做。锯拐用红松、杉木制做。

锯条 是用来锯割的刀具，都是由工厂中正式化生产，所用规格应根据需要选取。

初学木工的人，在纵向锯解较长较厚的木件时往往产生锯口偏斜《跑锯》的毛病，除与操作技术和锯的锋修质量有关外，工作所置的稳妥与否也是一个原因，往往由于工件没有被放好，锯解时便握锯晃晃、此时握锯牵制，力掌握不住，即使再好的锯子也不能锯好。必须将工件牢牢地看住。

# 刀锉 多用钢板做成，常用的刀锉系双刃锉。一面为顺锉；一面为横锉。其优点是构造简单、使用方便；缺点是行程较短，导致性差甚。

# 锉锉 或称线锉，它和刀锉的结构一样，主要区别是锉条较窄、长愈大都在800毫米以下用木制锯柄制成。锯解条锉，锯解的曲线半径愈小。在锯解条锉条不要侧偏，保持垂直向前，否则会导致合为锯的变形。条。若有内外圆时先锯内圆后锯外圆。锯条先钻一孔，然后从孔处入锯。

钢丝锉 又名锉弓子，其形状像弓一样因而得名。常用它锯解曲面线形诸之工作，锯身用毛竹做成。其工具为一直径0.8~1毫米的钢丝。钢丝的面都有齿。
