# 图12 榫孔示意

榫孔的主要要求是榫头正和内壁与工件表面的垂直（钢眼除外），初学木工的人由于掌握不好很可能出现图13所示的几种情况。在透榫中间图13（1）的情形尤其忌讳的，当榫通过时引起榫孔凸起，榫受挤压，而榫贯通后其弹性恢复，使榫和孔紧配合，不容易松动。若加榫质量就更好。除了个优点外其底面还不易被榫顶坏，有时有意识的这样塞。但是不要做的太太，每边越大1、2毫米，这要看木料质量如何。
