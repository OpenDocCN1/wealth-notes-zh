# 对核武器的防护方法

+   1. 在敌人核袭击前，主要防护措施是：靠山，分散，掩洞。

靠山——就是要利用有利地形，靠山躲藏，根据敌我人可进行绕袭击的方向，尽量把部队配置在爆炸心的反斜面.

今次——就是把伤仓大队分散到不同和远近和两面，高配置。一个中小型的原子弹杀伤破坏半径只有几公里，部防就配置，原子弹就发挥不了大作用。

掩洞——就是掩蔽躲各种工事，特别是坚固掩蔽。各种工事对核武器都有很好的防护效能。人员、武器、车辆等要构筑掩蔽工事。蓦露的易燃物要盖上土或或瓦块，或用沙土土覆盖起来。从防护效果来说，最好的就是有重型无遮无无遮蔽的,有重型比轻掩盖的好,背向原子弹爆炸心方向原子弹爆炸心好。

筑洞须与确方便，节省器材，防护效果较好，应该广泛适用。在结构方面，除洞口要背向可能爆发的方向外，最好有三个出口，有一、两个拐弯(不同受弹角度),并要特别注意通风气体的作用。

2. 在敌人核袭击时，要迅速隐蔽。
