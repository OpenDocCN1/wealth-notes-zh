# 量 具

在木工行业中，量具是衡量轻重、大小（体积）、长短的标准。

木工常用的量具有：

尺 可以分别量长、钢板尺、木折尺、卷尺等不同的类型，是用来量度木工件的长、宽、厚，或在工作上划线的工具。

直角尺 直角尺或称三角尺，主要是划垂直线和平行线，测量工件表面是否平直，测量相邻两平面是否垂直。木制直角尺使用不易变形硬木，如红木、楠木等制成。它由两部分组成，一是尺身，一是尺脚，直尺痕宽不要大于5毫米，导和减少为了使用方便不要小于20毫米。自己做时按直径尺长度在导尺上打槽，槽的尺寸应使两尺紧密配合为好，当检叠时即能放出针状类困。铁制直角尺，多为工厂生产，已经过检验，比钢板尺，主用于划线。

游尺 游尺又叫滑板尺或活动斜角尺，主要用于各种角度的刻划。使用时先将导尺贴紧工件的待测量面再将直尺按到需测的角度再划线。

斜角尺 木工艺中常称45°角尺。角尺型式和游尺一样，只是在直尺和导尺成45°的工件上把它固定住。

菱角易 俗称半圆仪，主要量到一些特殊的角度，使用时应注意不要将量角器的边对准基准线，而要以量角器上的水平刻线线为准。
