# 胸（背）部位的包扎

胸（背）部位绝大多数都是重伤，尤其是胸部穿透伤，常有肋骨骨折、血胸、气胸，伤情往往十分严重和复杂。急救包扎时要点是保持呼吸道通畅，止住出血。开放性气胸须立即封闭，严密包扎伤口，包扎要牢，防止进出中松脱。胸部伤件有多数根肋骨骨折的，除用敷料包扎外，还应使用绷带环绕胸部包扎固定。

对一般胸部伤员，只需敷料包敷口，用三巾包敷带包扎即可。如果没有三角巾，可以把毛巾对折放在一条带子上，系在颅部，再把毛巾上片折成三角形，提到一侧肩上；把毛巾下片也折成三角形，提到另一侧肩上，两角各系一条带子，经肩到背后与横带打结。背部包扎法与其相同。

也可以利用伤员自身上衣包扎，先解开伤员上衣，在第三、四肋打之间做一条一系带子，把两衣襟重合各贴两条，两条分别侧翻胸背后拉紧打结；然后把后衣襟反折向上，两条衣襟各系一条带子，交叉由肩上拉到背后，与反折的后衣襟打结扣结（图二十三）。

或者另取一件上衣，双手捉取两衣襟，衣领内翻，放在胸背上四部两衣袖分别外提，经前拉到背后交叉，与两衣底领角打结（图二十四）。
