# 苏图一95D熊式电子侦察机

近年来，苏联图一95D熊式电子侦察飞机稍出鬼没进行空中间谍活动。
图一95D熊式电子侦察飞机，全长49.4米，翼展50.4米，乘员11人，最大飞行蓬928公里，线航时16个小时以上，航程可达一万四千多公里。由于它能航时同长，飞行距离远。侦察手段多，所以主要被用于执行远距离轰炸侦察任务。该机腹部装有一个庞大的椭圆形窗口，似乎装了二十一英寸电子侦察设备，以及敌我识别系列、导弹发射控制传感系统等，能侦收200至250公里范围内的各种雷达、无线电通信信号，并可将侦察情况实时侦输给潜艇。同时，机身中部还装有高空侦查摄像机和电子侦察设备，除进行电子侦察外，还能进行照相侦察，甚至能下降到200米进行超低空侦察。
