# 2. 调味 调味是炭调过程的一个重要环节。所谓烹调，就是包括“烹”和“调”两个方面。“烹”是指加热，就是要正确掌握火候，而“调”是指调味，就是要正确使用调味方法。通过调味，将主料、辅料和调品的共同滋味加以调和，以除去原味的不好滋味，增加烹调的美味。适当应用调味，能使炭差的原料成为美味的炭菜；相同的原料若采用不同的调味方法，就可以得到不同滋味的炭菜，因此，调的妙味直接关系到炭菜的质量。

# (1) 调味品，也称调料或<|message|>。调味品的种类很多，常用的有以下各种：

+   咸味: 食盐、酱油、菽醋浆等。
甜味: 白糖、红糖、砂糖、冰糖、蜂蜜、糖精等。
酸味: 白醋、红醋、醋精、酸梅等。
辣味: 辣椒粉、胡椒粉、芥末、生姜、葱、蒜等。
香味: 桂皮、茴香、花椒、大料、丁香、砂仁、桂花、香草、香油、香精等。
苦味: 陈皮、杏仁等。
鲜味: 虾籽、鲍鱼、特精等。
酸甜: 榨酱汁、西红柿酱、山楂酱等。
甜咸味: 甜面酱等。
辣咸味: 豆瓣酱、酱油等。
鲜咸味: 鲜酱油、虾子酱油、虾酱等。
香咸味: 椒盐等。
香辣味: 细调品、芥末酱等。

# (2) 几种调味品的制作方法

椒盐：香味咸，用干于烤菜的佐料。
原料——精盐1斤，花椒面1两。
方法——先将盐放碗内，再放入花椒面，炒至色发黄，且出香味，倒出凉后即可。
芥末酱：香味味，用干拌凉菜。
原料——芥末面1斤，温水8两。
