说，防护方法有四种：

# 一、侦察：

通过化学侦察，可以发现和确认敌人是否使用了化学武器，使用了哪些毒剂。除了化学侦察器具，如侦毒器、化验瓶、检毒箱等能鉴别他人使用情况以外，还可以采用一、二间的办法。

一、就是看征候。化学炮弹、炸弹爆炸时，通常可以看到爆炸烟幕，敌机在蓝天洒毒，则可看见飞机尾后有黑色浓云条，如果看到地面上有青油状斑点，植物叶子出现斑点，并出现叶子枯萎，水面积有油膜状的东西，雪上有斑点或液滴渗透的孔洞，昆虫大批死亡等现象，都可做为是否有敌人用毒的根据。

二、就是闻人气味。因很多毒剂都有特殊的气味。如沙林有类似水果香味，芥子气有类似大蒜味。

# 二、防护：

# (1) 对呼吸器官的防护，防毒面具可能当地防护多种毒剂。没有面具时，可以采用最简单的方法办法，如毛巾、口罩都有一定防护能力，浸有石灰水的湿毛巾能防氢氨氯气十分钟。叠成12层的湿毛巾可防沙林、二十分钟。毛巾内包上三厘米厚的小颗粒土上可防沙林四十分钟以上。

几种就就的防护器制造方法：

毛巾面罩——毛巾浸水后〔也可浸在石灰水或尿〕拧干，叠十二层搭在口上，也可在外面加一个口罩上。

泥土口罩——取干燥湿泥土，制作成0.1—0.3厘米的小颗粒，装在布袋内〔长20厘米，宽15厘米，厚3—5厘米〕做成泥土口罩，也可临时用毛巾包湿泥土〔半于的湿泥土进行〕堵住口鼻。如图一〕

此外还可用细管、铁筒、竹筒等装上土两端用棉花或布塞上，做成“滤毒管”，使用时罩在口上呼吸。

工业上的防尘面罩、防毒面罩也有很好的防护作用。

# (2) 眼睛的防护；除防毒面具外，自制防毒眼膜效果很好。用铁丝做一个眼镜箍的框子，用细线把棉花或丝在框上，上而粘一层透明塑料，或者外用一条透明塑料薄膜在框上。在眼膜上。为了防止漏气，制作时要注意贴紧，在有缝隙的地方多加些棉花。
