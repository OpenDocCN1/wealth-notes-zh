# 日光温室

日光温室是用塑料薄膜代替玻璃做前屋面，以太阳热能为主进行生产，必要时才辅助加温设施。这种温室建造简单，成本低廉，适于农牧<|message|> 家庭后屋后的菜园生产。

日光温室前屋面所用的塑料薄膜最好选用耐低温的聚乙烯薄膜（聚乙烯乙烯酸共聚物）可耐寒于零下70度的低温并可透过紫外线，有90％以上的紫外线可被菜类吸收利用。因此，日光温室生产的蔬菜有香味、产量高、营养丰富。如日光温室生产的番茄中维生素C的含量比栽培室内的多20％，而矿山好色。太阳中的紫外线冬少夏多，夏季较为充足，利于日光温室生产其更有优势性。

温室材质有木杆和钢管的两种。日光温室主要由土墙、后屋面、塑料薄膜屋面、防寒被等与防寒沟组成（见图6）。

日光温室高7米，长度18～30米，后墙高1.7米，厚1.7米，后屋面宽3.1米、薄膜前屋面6.4米，立管高60厘米。中柱高3.2米、前柱高2.3米。后墙距中柱1米、中柱距前柱3.1米、中柱距立管3.4米、倾斜角22度。
