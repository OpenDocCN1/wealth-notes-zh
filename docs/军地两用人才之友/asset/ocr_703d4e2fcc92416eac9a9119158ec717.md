# 图12 四声道立体声音箱排列

音箱的装饰 面板前可选色彩艳丽的木孔或轻薄的尼龙喇叭布和绸缎作为装饰布。装饰时，最好把喇叭布缝镶在一个木框上，然后再用尼龙带扣附在音箱面板上。

木制音箱不要用热水和硬布擦涂油漆面。宜应用布沾酒米水或用棉花蘸酒精（或白醋）擦拭，这样既保持音箱表面明亮又省力气。

音箱的保养 要防止尘尘和金属器件等外物侵入，装箱时可用干净布将箱的保护部件2～3层，然后从外部盖好套到箱面上。

组合式音箱的使用 使用组合式音箱时，高低音扬声器分频点一般选在高音扬声器谐振频率的一个倍频值以上为好，同时要调整高音扬声器的灵敏度，以保持频率特性的平衡。 urmare也要把扬声器各个单元按正确的极性连接到底对应的分频器输出端。确定极性方法很简单，即用一节一号干电池，把它的正负极与扬声器两端直接通电，会使纸盆向前运动。此时选定音箱喇叭为指向音箱的正极。
