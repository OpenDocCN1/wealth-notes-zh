# 3. 在放射袭击以后，要组织侦、防、消、救。

侦——就是及时查明配置区域或行动方向上是否遭受放射性沾染。现有的辐射侦察器材如辐射剂量仪、乙基仪等，都能及时、准确地发现和查明是否遭受沾染，并能测出沾染的高低。

防——就是要采取防护措施，避免或减少对放射性沾染的伤害。在沾染地域内行动时，要穿防毒面具或口罩等，以免吸入放射性物质。在沾染地域内不要吃饭、亲手，以免污染到皮肤或装入体内。通过侦察地域时，要高速度通过，尽量缩短在沾染地域内停留的时间。

消——就是及时进行洗消。人员、车辆在沾染地域停留或通过沾染地域时，人员和物体表面都可能沾染放射性物质，可用几种简单的办法将这些放射性物质清除(简略洗消)。方法是：拂拭、拖刷、拍打、抖摇、携等方法，看起来很“土”。实际洗消效果很好。例如一支沾染的半自动步枪，用肥皂片洗消，清洗效果为 85%。对沾染凝露拍打三次，拍动次数为 95%。皮肤沾染后用水洗，清除率可达 97%。因此，在敌人核袭击以后，应当紧抓战斗间隙，利用随身携带的水壶、毛巾，掸拂一沾除和双手，用被布或粪布、掸除凝露，武器装备的表面，用手擦、铁鞋杠扣和刷子将粪的表面。类似沾染疙瘩，还可以服用下服装、封堵几次。如果沾染严重，在战况情况允许时，可以到洗消站进行洗消。

救——就是救护。
