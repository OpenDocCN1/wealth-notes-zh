# 采集工具

要根据四季提提前准备好标<|start|>式蜂箱若干个，巢框若干片，草帽、防螨面具、割蜜刀、峰带、收集器、蜂王诱入器、薄竹片、三角支架等。另外，还需准备平板车、肩担等运送工具。

# 采集蜂箱的规格

标准蜂箱，长46.2厘米，宽38厘米，高24.8厘米，箱板厚2.5厘米左右，箱底板厚1.5—2.3厘米。

标准蜂箱上巢架长55厘米，宽2.7厘米，厚2厘米；下梁长42.5厘米，宽1.5厘米，厚1厘米 边条长22.6厘米，宽2.7厘米，厚1厘米；内阁长42.5厘米，内阁高20.5厘米，外阁长44.5厘米，外阁高23.5厘米。

# 准备选育种群

推广优良优良蜂种，是培育强群，获得高产和稳产的重要措施，也是解决养蜂和提高蜂蜜种的一项重要保证。选种要“今年选种，明年用种”，抓好群群优化和蜂群两个环节，使优良蜂种维生素和发展下去。

所谓就群就是蜂群，不好分群，具有抗病能力、产量，产王和蜂群越冬能力高；所谓纯蜂是指蜜蜂的形态特征、性能有相对的稳定性。没有佳种和，蜜蜂高产是难以实现的。选种要注重六个方面，①选产量、产胶、产胶量高的蜂群，作为母蜂群和父群；②选群势大，不好分群的蜂群；③选抗病和越冬能力及抗病虫害的蜂群；④选性情温顺，不爱袭人，蜂群时间短的蜂群；⑤选遗传的蜂王和蜂群，能够满足养蜂生产需要；⑥选亲王和蜂群需要隔10公里左右，才不可能会相互交叉。

# 培养优良蜂王

优良蜂王是蜂群强弱和产蜜高低的关键。培育好优良蜂王要抓好四个环节。①要选群势高，优良的蜂群作为培育蜂王。一定要蜂群左右。较弱的蜂群或营养差的蜂群，不能作为培育蜂王的蜂群。②选蜂日龄较幼的幼虫。一般从优质的产卵脾中央部位挑选幼虫，日龄短的幼虫几乎与卵一般大小，最好选择一日至内幼虫作为培育蜂王。③注意培育蜂王的时间。北方地区在春季秋前都可以养王。这一时间要紧秦蜜源
