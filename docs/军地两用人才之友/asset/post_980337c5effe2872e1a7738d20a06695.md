在任何情况下，千万不可在同一个供电系统中，把一部分电器武术采用“保安接地”，而把另一部分电器武术采取“保护接地”。因为当“保护接地”的电器武术发生漏电时，其它“保安接地”电器的外皮就回产生危险电压，人工保护接地的电阻越大，所产生的电压也越大，很不安全。
由于城市住宅建筑有新建和旧建两种，在供电系统上关于“接地”、“接零”的方式比较复杂，因而进行接地（接零）的处理时应引起特别重视。
人工接地体的安装材料，过去差不多都是使用大块的紫铜板，在铜板附近嵌入木炭以盐等物以减小接地电阻。但铜是比较贵重的金属，以后经过研究和实验，  Fem 采取铁管或铁线代替铜板，既经济，又方便，效果也很好。
采用铁管或铁线制作接地体时，铁管的壁厚应度应 在 3.5 毫米以上。
直径应为 38 毫米以上（采用铁线时直径不小于 12 毫米），长度应为 2.5~3 米。埋设的接地体不得小于两根，接地体要垂直埋设，埋入地内的接地体顶端离地面不得小于 0.8 米。每个接地体之间的间距应为 2.5 米以上。
若接地体之间，用要截面积不小于 48 平方毫米的扁铜线，或直径不小于 6 毫米的软铅线，用焊锡焊接，将地体的顶端连接起来。接到电器具上的导线，铜质的截面积不小于 4 平方毫米，铁质的不应小于 6 平方毫米。铝质导线，由于机械强度不够，不得采用。

## 触电后的紧急措施

- 1、使触电人远离电源
人触电后，大多发生颤性痉挛（即抽筋）。如果是手触碰了电线，往往是把电线抱得更紧，不易松开。故旁人不可直接去接触触电的人，应按下小孩儿般按控。
（1）在家庭中发生触电，应迅速拨掉插座或拉开电表处的電闸盒以切断电源。如果电发现在距电源较远的地方，可用干燥的木棍、竹竿等不导电的东西挑开触电人身上的电线或电器具。最好在救护者, 带着绝缘手套或脚下垫上干燥的木板（图11所示）。

（2）如果一时不容易使触电人与导线隔开（如触电人手紧抓住电休）时，由于电流总是通过触电者的身体流入地下，也可以地木板插入触电者的身下，使身体与大地隔离开来，或用干燥的绳索套在触电者的两只脚上，把它拉离地面，使触电人脱离电源。

## 2. 触电急救

（1）如果触电人曾一度昏迷，但没有失去知觉，呼吸、心脏均有，此时应保会安静，尽快请医生抢救或将触电人送往邻近的医院。如果触电人没有外伤，神智清醒，能行活动，可让触电人静躺，经过一小时后若触电人没有不舒服的感觉，就没有什么问题，否则必须请医生诊治。

（2）如果触电人已失去知觉，但呼吸和心跳都没有停止，应当一面使他平坦地地方舒安俯地仰卧，解开上衣和腰带（注意不要灸凉），保证空气流通，还可以让触电者吸闻“阿马尔平水”，或在触电者身上洒些冷水（不用药去喷），并摩擦触电者的全身使其发热。一面尽力请医生前来，或把触电者送往医院。此时，如果发现触电人的呼吸困难，或呼吸衰弱，或断续地有抽搐现象时，应立即施行人工呼吸。

（3）如果触电人的呼吸、心跳已停止跳动，出现“假死”现象，应迅速地为触电者施行人工呼吸，进行紧急救护。除触电人有明显的致命外伤（如全身电烧伤，或由高处跌下而摔断头骨等）外，都不能认定为没有救治的希望。在绝大多数人在很短几个小时的过程中，经过不断的紧急救护给予被救治的。

人工呼吸常用口对口（鼻）人工呼吸法和胸外心脏按压法。也可同时兼用这两种方法，它是急救触电人的主要方法。

```
I = P / V
```

```
I = (15 + 20 + 40 + 25 + 40 + 100) 瓦 / 220伏 ≈ 1.09 安
```

根据以上计算的结果，还应该考虑备各家电、地，这户选用电度表，最好是1.5安或2安级。额定电压220伏的单相电度表。电度表是由电气元件和机械元件所组成，在制造和正常计数过程中，由于物理特性不同会造成电度表本身的误差。在正常情况下，本身误差为±3％。另外由于电压改变、频率改变、温度、倾斜等影响所产生的误差，新为附加误差。这些误差是常常条件不同而有所不同。

必须注意，不按实际用电情况选用电表壳，会因电度表本身规定的基本误差范围出现不符合要求的现象。因为电度表的规格越大，规定允许误差也越大。如装得大，这户居民多付电费；如装得小，误差减少付费少。另外，电度表的容量选得太小，电度表容易被烧坏，太大则可能里检测不到。

## 家用电度表的结构与工作原理

## 1. 家用电度表的结构

单ciplina 有功电度表主要由一个可旋转的铝盘、分别绕在铁芯上的一个电压绕组以及一个电流绕组所组成。它的测量机构，主要由六个部分组成。

- (1) 电流系，在装装的优质硅钢片上，用粗导线绕成的电流绕组组成了电流元件，用导线绕成的电压绕组组成了电压元件。

- (2) 可动部分，在偶合或组合合金转轴上紧固定铝盘，并用上下轴承支持住，使轴与铝盘一起转动。

- (3) 永久磁铁，永久磁铁用铝镍钴磁钢制造，并有调节磁性强弱的装置。

- (4) 支架。由钢板冲制或用铝合金、锌合金压铸而成。

- (5) 积算器。

- (6) 外壳及端钮，外壳用铝板冲制或用塑料制造，底座用钢板冲成，端钮盒用酚醛粉压制。电度表的内部结构如图1。

## 2. 电表的工作原理

当电流表接入电路后，电压线圈与电流线圈所产生的两个相位不同的磁场形成了躲避磁场，这个磁场作用在铝盘上冲击出涡流。由涡流与磁场相互作用的结果，彼使铝盘产生一定方向的转动动力矩，驱动铝盘一直方向转动。铁芯使永久磁铁起制动作用，产生制动力矩与载荷作用力矩平衡。使铝盘均匀运动于制动磁铁间同时，铝盘转动与载荷器联动，通过铝盘轴上的涡环带动计数器，所以可以记录电路上消耗的电能。由于负载上电路，电能以及它们相角差的余弦的乘积，因而积累的读数就等于电路中消耗的有功电能。

3. 表面光洁平滑，不应有凹槽、裂缝、毛刺和氧化发黑，但许可有轻微的氧化色、丝纹、轻度的划痕和腐蚀。

## 家用电度表的使用、读数和用电度的估算

## 家用电度表的使用

1. 家用电度表装好后接入负荷，转盘的转动方向与所标定的箭头相同一致。如果采用互感器的电度表，应检查一下接入电度表的电压与电流的相位是否相符。例如 A 相的电压和 A 相电流接入电度表相应 A 相一根元件，B 相与 C 相也同样如此。Ic 外还要注意互感器的极性。

2. 有些电度表在使用中发出一种易察觉的嗡嗡声，这是由于电度表内交变电磁场作用的缘故。这种声音并不影响电度表的准确度正常使用。

3. 正常的电度表在安装后，如无负荷（全部电灯关闭），表内圆盘应会微微地转动，但不会一直转，即会停止转动，这是正常现象。

4. 对用户一户用电或一楼每户的用电负荷的总数应不超过电度表规定的许可容量，如果超过时，应由用户办理增容手续。

## 家用电度表读数和用电度的估算

电度表刻度盘一般有五位数字，表盘上有五个空格。用不同颜色（黑色和红色）区别。黑色代表整数，红色代表整数以后的小数。5安培以下电度表有三个或四个窗格为黑格，有二个或一个窗格为红色，它的单位是千瓦小时。起用电度表时，应将表上的数字从左到右记录下来，每次计量用电量时，只要按同样的方法记录累计数字，并将即时的数字减去前一次的数字，这个差数就是这一期间的用电量。如第二次抄表是26.3，第一次数抄表是18.8。见表：

0 0 1 8 • 8 —第一次抄表
0 0 2 6 • 3 —第二次抄表

那么，26.3−18.8＝7.5。这一次期间用电度数为7.5度。

如果使用电压互感器（简称“PT”）和电流互感器（简称“CT”）时，实际消耗的电度应为度表的读数乘以电压互感器和电流互感器的变比。例如电压互感器的变比是200/5，即变比为40，那么，实际抄表的数字若是10.5，则10.5乘上40，才是实际的电度数。
10.5×40＝420（度）

有的电度表为了扩大量程和消除小数位，往往在铭牌上注明“×10³”、“×100”或“×1000”等系数，电度表的读数乘以此系数就是实际电度数。这与乘系数作电度表的本身倍率。

电度表的常量通常于表中与它盘转数相等。例如某一电度表标注：“2000转＝1千瓦小时”，即该电度表铝盘每旋转2000转，电能消耗是一千瓦小时（俗称1度）。就是1千瓦的电器，在正常电压下，使用1小时所消耗的电量。

当一个总的计数电度表后面接有许多分表时，分表和钒线的消耗就反映在总表的指示上，所以总表的读数总是大于所有分表读数的总和，只有加上分表和钒线的损耗时，两者才会相等。

## 常见故障及原因分析

| 故障现象 | 原因分析 |
|---|---|
| 1. 误差超差规定 | （1）制动磁铁位置不对，不能指挥作用力平衡到，造成磁盘转铁不匀。
（2）相位器布置不当，在功率系数为0.5时误差太大。
（3）铝质转盘和磁瓦位置设置不妥，在轻负载时误差大。
（4）电压元件和电流元件两者间的时间常数太大，或磁盘通路的短路现象，促使转矩减少，轻负载时较误差大。 |
| 2. 有源负载现象 | 出示时“请查”。 |
| 3. 转盘卡住（负载仍常有电） | （1）制动片领取受损，表内有异物卡住转盘。
（2）轴承润滑（使用日久，表内密封不严，制油箱氧化结垢挂上轴承）。
（3）计数器磨损，或计数器转轴不灵活，甚至卡住（一般在轴 0 时或第首机位）。
（4）电动机断电。
（5）端盖内小分子松脱。 |
| 4. 机械故障 | 运输中受剧烈撞击，供电光玻璃，内部铝轴锁住不能转动。 |
| 5. 无负载时，转盘转动不止。 | （1）短路现象电动。
（2）与其它用户分线不均。
（3）电表表头失。 |
