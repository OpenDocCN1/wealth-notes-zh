# 风道

即在木板背面开一凹槽, 防止木板反翘变形, 另外它还起着与地热板和板与板的开作用。如果木板在与毛边板上之后, 由于打了风道, 地板便会紧贴地面与毛边线结合成一块, 当人踏上时不易“咔、咔”做响, 否则不易易响。在较宽的门窗框背面（与墙贴地的的地方）也可做风道（图19）。
