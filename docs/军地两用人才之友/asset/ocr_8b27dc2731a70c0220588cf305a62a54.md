# 四肢伤的包扎

四肢伤中，四肢创伤最多。四肢伤主要问题是骨折和血管损伤。因此，四肢伤急救的要点是迅速止血、正确固定和良好的包扎。包扎要贴实皮肤，对出血的伤口要加压包扎，但也不可过紧。用绷带包扎时，每周绷带要压住前一圈的 1/2 - 1/3。除手指或是足趾必须暴露孔外，四肢伤包扎时，要把手指或足趾露出，以便随时观察血液循环情况。

四肢各处伤的包扎方法有以下几种：
燕尾单车式包扎：燕尾尖侧向上。放在伤侧肘上，向后的角压住向前的角，并大于向前的一角；燕尾边沿包缠至肘上部打结，然后两燕尾角分别绕腕穿过对侧腋下打结（图二十九）。
