# 钟表的种类与机械性能

钟的钟类
钟的品种繁多，式样各异。大体可分为：座钟、挂钟、闹钟、小台钟、旅行闹钟、暗室钟、半导体钟、半导体收音机钟、电钟、电子钟等。

钟等有3″、3½″双铃和骨铃、半导体喇叭及小台钟 2—31/2″等尺寸。

走时数数表有七天、八天、十五天、三十天等。电源钟有蓄电池和无蓄两种。电池钟和半导体钟一般约走一年。

有凸钟和无凸钟。一般双发条闹钟有 2 占，旅行钟 5 占、7 占。

随着科学技术的发展，钟壳、钟面及附加装置愈加新异。常用钟壳一般是木壳喷漆的，有的附加塑料贴面。盘面多铝质，有的带有日历或星期历。

闹钟小台钟在造型方面，有圆型、椭圆型、方型、立体型、孔雀型、无线电型、电视机型、照相机型等。还有的带有日历、红亮灯、装动活物动、移盘针、鸽类风向表面等钟等。
