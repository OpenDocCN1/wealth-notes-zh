# 图一 火箭弹风偏

对被风影响的修正，首先判定出射击时的风速。用瞄准镜瞄准时，风速是几米/秒除修正之几为方向细分。如风速是 4 米/秒，就做三分之四方向细分，即 2 个方向细分；1 米/秒除修正二之一为方向细分，即 0.5 个方向细分。余类推。风从哪边吹来，方向分划就放在哪边。例如，测得 4 米/秒横风从右吹来。目标距离 300 米，应右侧方向细分 “2” 和距离分划 “3” 的交点，瞄准目标中央（图二）。
