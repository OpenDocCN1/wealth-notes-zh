将基础做在表层的软土内，以避免开挖大量土方、延长工期和增加加工程造价。至于具体埋深，应根据决定基础埋深的其它条件综合考虑确定。3. 如果软弱土层厚度大于1米，对于低层轻型建筑以及单层房屋的一层或二层结合房屋以及无房低层或轻型工业厂房。应以利用表土作为，最好与附近上部结构或地梁的断面或采用人工地基。为对于地下室的房屋和高层建筑是否将基础做在下面的好土层上面，或采用基础人工地基，则应根据基础土的均匀性和施工设备等条件确定。4. 特别情况：地基由下而上厚度不断减小，上土是压密性较小的好土，而下面却是压缩性较大的软土。在这种情况下，应根据基础的荷载来确定埋深。如果表土层有足够的厚度时，那么就要将基础做到地基埋深一般，可做小范围的图室内对热度。如此不必，可将外设设计地而提高到距地而以上（即在天然地面上面扩台）；如果表土层的净土很薄，按其它条件确定的埋藏深度下面好土层厚度所剩下时，那么就应按第2种情况的地基考虑。第5种情况：地基由若干层交替的好土和软土构成。这时控制深度应根据各土层的厚度和压缩性质，根据减小基础沉降的原则，按上述情况来决定。

# 墙体、支柱

墙体和支柱是房屋构造中基础以上主要受力的组成部分。工业建筑常与房屋的结构联系紧密，有砖、石、木结构、钢筋结构、胶凝多的有钢筋架的结构、钢筋混凝土结构等。这些建筑具有平面，有多层的楼层。

外墙 按其荷载情况分为承重外墙和非承重外墙大类。承重外墙不传有本身的荷载，还传有、板传递的荷载。非承重外墙和框架中的维护墙，仅有本身荷载而无其它条件传递的荷载。按其宽度分有 240、360、490（?）厘米(?)之墙。 按结构分项目：有各种的村山墙、前、后墙、楼梯间墙、窗间墙。柱间墙及屋顶部分的女儿墙等。按操作分有清水墙和清水墙两种。按建筑用材料分；有土坯墙、空斗砖墙、实心砖墙、夹心砖墙、石墙、钢筋混凝土墙（钢筋及混凝土）以及木制、全金属板墙等等。
