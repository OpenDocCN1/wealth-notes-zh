# 农用电机

电动机的种类很多,在农业上用得最多的是三相交流电源的三相感应电动机,特别三相鼠笼型感应电动机,它结构简单、制造容易、运行可靠、维护简便而且效率高、重量轻、价格低,因此被广泛用于驱动排灌机组、脱粒机和各种农副产品加工机械。
