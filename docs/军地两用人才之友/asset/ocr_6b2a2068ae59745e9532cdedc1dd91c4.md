右记录下来，每次计量用电量时，只要按同样的方法记录累计数字，并将即时的数字减去前一次的数字，这个差数就是这一期间的用电量。如第二次抄表是26.3，第一次数抄表是18.8。见表：

0 0 1 8 • 8 —第一次抄表
0 0 2 6 • 3 —第二次抄表

那么，26.3−18.8＝7.5。这一次期间用电度数为7.5度。

如果使用电压互感器（简称“PT”）和电流互感器（简称“CT”）时，实际消耗的电度应为度表的读数乘以电压互感器和电流互感器的变比。例如电压互感器的变比是200/5，即变比为40，那么，实际抄表的数字若是10.5，则10.5乘上40，才是实际的电度数。
10.5×40＝420（度）

有的电度表为了扩大量程和消除小数位，往往在铭牌上注明“×10³”、“×100”或“×1000”等系数，电度表的读数乘以此系数就是实际电度数。这与乘系数作电度表的本身倍率。

电度表的常量通常于表中与它盘转数相等。例如某一电度表标注：“2000转＝1千瓦小时”，即该电度表铝盘每旋转2000转，电能消耗是一千瓦小时（俗称1度）。就是1千瓦的电器，在正常电压下，使用1小时所消耗的电量。

当一个总的计数电度表后面接有许多分表时，分表和钒线的消耗就反映在总表的指示上，所以总表的读数总是大于所有分表读数的总和，只有加上分表和钒线的损耗时，两者才会相等。
