# 乘法口诀

珠算乘法有的与笔算一样，要用口诀运算。乘法口诀共有八十一句，每句口诀有四个字，前两个字表示乘数和被乘数，后两个字表示乘积的十位数和个位数。在十位数和个位数中，有的是一位数，有的是两位数。两位数口诀有五十六句，一位数口诀有二十三句。在一位数口诀中前边都有一个“〇”，也要跟两位数衔接。如“二三〇六”，“〇六”的“0”表示乘积是十位数，虽没有计数，但计算中“〇”要占一位，只是用拨珠表示。这样的好处是加乘时避免加错位置。乘法口诀不表示拨珠动作，运用时只要用心默念口诀前两个字，手往算盘上加乘积。口诀内如加下表。

上表斜线右上方一般称为“小九九”口诀，四十五句：“大九九”口诀还包括左下方三十六句，共八十一句。“小九九”每句口诀第一、二两个字不固定表示乘数或被乘数，例如，只有三七21，没有七三21。而到七乘以三时，就要靠七、三的顺序相乘，这样，不但要费时，而且容易造成乘数或被乘数的颠倒，从而产生计算上的错误。“大九九”口诀的排列是科学的，它完全能适应各种乘法的运算，不需要颠倒乘数与被乘数的顺序，不易受读错误。所以，使用“大九九”口诀运算要比“小九九”口诀好得多，应该下功夫熟记它。
