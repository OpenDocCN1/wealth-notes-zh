# 雪地摄影

关于雪景的曝通，通常情况下的亮度要超过天空的亮度，比人物的亮几级。拍远景，用测光表测到的曝光指数，一般说来偏暗，因为新雪的反射率高达百分之九十以上，而测量的反光的测光表反映的是相机设置的18％的反射光密度的值，也正反映片中的奖密需要，因此，曝光时须增加1—2级光圈，方能避免白雪饱嗝的高调。拍近距离景物，测光应该尽量对准主体，记住避免测光的偏角，不过多的散射光进入测光表的电量管，以免曝光不足。

该雪都是最好的天然的反光板，阴影部分的层次如果曝光正确就是能表现出来镜的，利用摄影机的脚印、雪堆、冰块的投射，拍摄用光或也可以表现出来的黄绿色相擦，如加强雪的层次感和透明。阴投前景的雪景在画面成层面无层次。拍摄雪景，应选择较暗的背景或有风的天气，适用1/30—1/60秒下的慢速震动成像，夜时快，速度太快，雪花变成雪景底的白色，下雪的影像就消失了。夜时则需要灯光照明，拍出的下雪情景更为逼真，不论白天或夜晚，要避免雪花靠近镜头结上镜头，可在相机上支起伞。雪落天时，是拍人像的好时机，地面上的雪还能反射拍摄人体，人物是会在得到丰富多变的。

在蓝或天下面拍摄彩色摄影者，为避免景物的阴影部分变黑，在拍摄时尽量不使阴影部分过大而稀疏，甚至有必要采用侧光的光线。
