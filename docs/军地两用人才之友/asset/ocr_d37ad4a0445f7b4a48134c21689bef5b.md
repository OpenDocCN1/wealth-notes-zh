# 图 3 录音声轨的形成

声道又称通道，它和声机不是一回事，它是录制磁带的录音系统和磁带放音所需要的效声系统的总称。若录音机具有两个声…放现能系统的称为二声道。普通非立体声录音，是用一个声道，称为单声道。录制立体声的场合则需要用二声道（又称双声道）；立体声的左侧称为左声道，右侧称为右声道。
