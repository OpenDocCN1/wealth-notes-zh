# 营养元素对农作物的生理作用

|元素名称|主要生理作用|作物吸收形态|
|---|---|---|
|碳、氧、氢|作物进行光合作用时，利用碳、氢、氧合成糖类，并进一步合成淀粉、纤维素、以及将碳与氮、磷、硫等化学物、氮和氢在作物体内氧化还原过程中起着重要的作用|二氧化碳、氧、水|
|氮|氮是蛋白质、氨基酸、叶类素、多种维生素和酶的主要成分，起着作物物质、调节和促进生命微循环的作用。增加产量和色，加快生长，可能会对病虫害及其它营养元素吸收|
硝酸态、铵态、作物吸收根部吸收氨气态氮|
|磷|磷是核酸、脂肪和糖酸的主要成分，对作物作物体、养分的合成和运输、新陈代谢的作用。能帮助根系发育和萌芽、助根生长，促进作物发育、早熟和安稳|正磷酸离子、偏磷酸离子|
|钾|能够提高抗寒力和抗盐碱度，增强抗倒伏和病虫能力，提高分蘖，促进根系和块茎发育良好|阳离子态钾|
|钙|钙是组成细胞壁的成分，能促进根系发育良好，能中和体内有机酸，促进新陈代谢，增强抗病虫害能力|阳离子态钙|
|镁|镁是叶绿素的主要成分，直接参与光合作用，参与酶的代谢，能影响硝酸盐和C的含量|阳离子态镁|
|硫|硫是蛋白质的主要成分，多集中在和种子里。参与氨基酸构成，促进根系生长|硫酸离子|
|铁|铁是植物叶绿素的必要成分，许多酶和酶都含有铁，能够增强酶抑制作用，加速生化氧化过程促进作物早熟|氧化态及亚氧化态铁|
