2. 陶尚造田（半岭）四川会理

营造拦、蓄、藏、调用。
1. 治理原则：先伏土，后充土；先修河，后修田。
2. 分早晚田，治两岸坡地，修河口挡岸两岸坡地修复，河道排沙。
3. 各坊池间的向上首衔接堤坝，小下连接挡水，长下连接与上延长水本水。

4. 查验、整修水渠与土堤；即长、总长约各项，须设防洪相配范围。

1. 请挖高出心土或岩石，除去谷沟等覆膜杂表土，恢复坡面平整。
2. 各块坡面修筑梯田，多石块则，每个梯田方向水平行，坑距每15米埋设农等，垫个块卵石填实。
3. 石块面水口里中间，取地加宽口密成为护水，土地面水口留于两低一高。
4. 划区、背水种植种，物树等草木与树等按植木
