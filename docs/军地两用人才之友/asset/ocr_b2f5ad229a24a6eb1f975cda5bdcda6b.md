克复坦克和战给你打片混乱时机，利用地形和敌克坦观察封锁的死角，迅速隐蔽接近敌坦克，以炸药包、爆破筒等爆破器材，各击破敌坦克。

# 夜间打扰坦克

夜间作战视度不良，给指挥、协同带来一定的困难，因此，班在进攻之前，应认真做好准备，充分发挥各率民主，研究战斗中可能出现的情况。各级战队，每一个战士，每个小组成员明确通信的办法和信号（记号）。在战句话，摄长要灵活利用各种指挥通信联系的方法，实施灵活指挥。各级战斗小组，要发挥独立战斗，主动协同和近战开敌的精神。

夜间进攻，敌坦克主要依靠红外线夜视仪观察，班在进攻中，应利用敌坦克常用夜视仪观察“沟渠黑一点，坑洼黑一片，相同颜色分不清，断续下视看不见”等弱点，把进攻、冲锋出发地选择在尽量靠近敌人的有利隐蔽处，完全利用夜幕和有利地形，严密隐蔽，谨慎地接近敌人，隐蔽发射地处起射击，勇敢冲破敌坦克内部，靠近敌坦克打。

突入敌战车后，班长应指挥全班，大胆倒回宰捕，避开敌坦克的正面，割断敌步坦联系，绕到敌坦克的侧后去。各级战斗小组要互相支撑，又要有独立与敌坦克作斗争的精神，充分利用夜暗，乘敌混乱之机，发扬近战敢战的威力，大胆地逼近敌坦克，以火雷筒、炸药包、爆破筒等武器器材，坚决将敌坦克击毁。

# 步兵班防御战中打敌坦克

步兵班在防御战斗中，必须要做到积极防御和近战坑敌坦克思想，采取积极的战斗手段，坚守阵地，抗击敌坦克的冲击。

通常情况下，敌坦克攻击，通常是利用飞机和航空兵火力突击效果，突袭多或伏，快速度的进攻。步兵班在防御战斗中，必须勇敢、坚定、沉着、准确判断情况，组织好各种反击坦克障碍，充分利用我阵地前沿防御坦克障碍物，层层打、坏，坚决将敌坦克消灭在阵地前。
