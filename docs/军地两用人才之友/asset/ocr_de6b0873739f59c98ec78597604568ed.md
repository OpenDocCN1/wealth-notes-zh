推刀剞：推刀剞与反片剞相似，左手扶住原料后部，右手持刀，刀刃向外紧贴推，或刀口原料为拟削，刨入原厚度之三分之二，留三分之一相连。如鱼仁、乌鱼都可用此切法。

拉刀剞：拉刀剞与正片剞相似，是不剥离原料。左手按住原料，右手执刀，刀身外侧，将刀由向外里拉拢，削的深度与推刀剞相同。

拉刀大块都用于整条鱼的反面两面。

直刀剞：直刀剞的刀法与推切相似，剞的深度约为原料厚度之三分之二，留三分之一相连。如猪腹子推刀剞后，再直刀剞切成块加热后则成卷片。

剞：一般要求先片后切，而且在切片时，要求深浅相同，距离相等，整齐划一，相其对称。如果先切后片，原料易动，不仪花纹不均匀整齐，而且原料易被碎。如果切片不均，则达不到成形美观的要求。

+   2. 刷 用刀将原料上的脏物毛发制掉。 3. 剔 肛部的一种刀法。剔骨时不能带肉，不能将肉剔乱、胗碎。 4. 削 用薄刀削皮，用手托住原料。削的刀法可分为由里向外，和由外向里削两种。如削果皮、茄子皮、土豆皮等。

# 烹调要领

烹会调味，调味、就是酸、甜、苦、辣、咸诸味要调配得合乎口味，减少要避免，酸甜要适口，麻辣要适中。调味要根据食用人员的口味爱好，才能配好于妥，烹调出各具基本的味采。

烹调时，将搭配起来提问各一項基本本。应声明各种营养成分的搭配外，还要注意数量的搭配，口味的搭配，质地的搭配，颜色的搭配和形状的搭配。数量搭配以各样原料在一切菜中的比例；口味搭配是酸、甜、味、辣、咸的分配，质地搭配是硬、脆、软、嫩、形和色是搭配着的形状颜色，要搭配协调合理，引人欲食。
