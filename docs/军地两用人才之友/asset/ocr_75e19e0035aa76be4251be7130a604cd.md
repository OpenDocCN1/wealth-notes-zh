织物和化纤制品，最好垫一层布。

+   6. 使用电焊要轻拿轻放，防止掉落地下，不要用电焊打表面他物，否则会使内部的发热元件及绝缘物损坏。

+   7. 在使用过程中，若不使用时，应收电焊包并挂起来，不要放置在工作台上，以免烫伤人，也不要放在吸阻物上，以免搬运底面的磨损绝缘。

+   8. 电源线应采用三芯纤维编织软线（俗称花线）。如发现电源线有断路或外表绝缘物破损，应使用同规格线换上，禁止使用塑胶软线。

+   9. 熨烫完后，要等电熨斗完全冷却后再收起来，要把电熨斗放在干燥地方，避免受潮。

# 日用电冰箱

# 电冰箱的分类

电冰箱是利用电能在箱体内人为地制造低温环境，使各种食品能在气温较高时仍能不腐烂变质，同时也可以制冷冷饮食品。
家常用电冰箱一般就放在200升以下，多用于相互交流220伏电低电压。家用的为单式电冰箱，只有冷藏室，其温度约为0～8℃；双门的称为双温电冰箱，包括冷藏室和冷冻室，其冷藏室温度为0～8℃，冷冻室温度为－6～－18℃。按构造情况分为箱箱、无霜两类。按箱外形分为单开门式和双开门式两种。按箱门开和否。

家用电冰箱制冷方式不同，一般有压缩式（包括电机压缩式和电磁压缩式）、吸收式和半导体制式三种（具体见表）。目前使用较多的是电机压缩式

# 几种制冷式电冰箱的特性
