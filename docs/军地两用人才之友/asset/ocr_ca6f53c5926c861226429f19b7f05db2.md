# 企业计划指标

企业计划指标是指企业在计划期内的具体生产技术经济条件下，预期要达到的具体指标和水平。

国家对企业较为重视的指标有前四项：①产品产量；②产品品种，③产品质量；④主要原材料、燃料、动力消耗；⑤劳动生产率；⑥产品成本；⑦流动资金；⑧利润。称为“八大指标”。1979年起，国家对企业主要考核这四项指标：①产品产量指标；②产品质量指标；③利润指标；④合同履行情况。对外出口产品，则考核额约率和收汇额。
