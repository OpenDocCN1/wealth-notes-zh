# 油漆涂料品种与调配

# 涂料的组成

涂料品种包括各种油脂漆、天然树脂漆、合成树脂漆以及辅助材料等。涂料既能保护物件免受外界来源各种侵蚀,又能起到装饰的作用。

涂料是一种混合剂,基本上是由粘结剂、颜料、稀释剂和辅助材料（如催干剂、增塑剂、固化剂）等组成。

粘结剂是涂膜于被涂物面，形成坚韧涂膜的主要成分，是主要成膜物质。粘结剂有油料和树脂两类。油料一般多用于干性油，如桐油、亚麻油、崂油等。树脂有松香、虫胶、醇酸树脂、酚醛树脂。硝基纤维素等。在水性涂料中则有各种天然和合成树脂作为粘结材料。

颜料是涂料中的固体部分，也是形成涂膜的组成部分，但不能离开主要成膜物质单独成膜，胶状颜料为次要成膜物质。涂料中所用的颜料基本上分成三类，即着色颜料、防锈颜料和体质颜料。着色颜料主要是使涂料具有色彩,一般常用的品种有：锌红、锌黄、氧化铁红、铅白、铅黄、炭黑、绿青、群青等。防锈颜料主要是使涂料具有防锈功能，常用的一种颜料有：红丹、铬黄、氧化铁等。体质颜料又称填无料，用以增加涂膜的厚度和加强涂膜的体积等，提高涂膜的耐磨和抗久性能。常用的品种有：重墨石粉（硫酸钡）、大白粉（碳酸钙）、滑石粉（硅酸盐）、云母等。

稀释剂由溶剂、助剂稀释剂和稀释剂三部分组成，用以溶解或稀释涂料，改变涂料的稠度，使之便于施工。稀释剂是一些能挥发的液体，并且具有溶解或软化成膜物质的能力，常用的稀释剂有：松香水（200号溶剂汽油）、松节油、汽油、香蕉水、苯、稀释水、乙酸戊酯的俗称、以及各种混合溶剂。

催干剂又各涂料、燥煤、煤头水、它们的作用是加剧涂料的干燥，有和催油反应类。固体的有铅、钴、锰等金属氧化物和金属盐类，目前多使用“铅、锰、钴催干剂”和“液体钴干剂”等液体催干剂。增塑剂用以增加涂膜的柔韧性，克服涂膜硬的缺点，常用的有增塑脂肪酸。
