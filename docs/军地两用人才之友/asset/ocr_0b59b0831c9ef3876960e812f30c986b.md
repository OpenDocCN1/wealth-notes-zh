# 军事知识

# 进攻战斗中的战士

战士在进攻战斗中，通常在班（组）内行动，以火力、手榴弹、刺刀和爆炸器材炸毁敌阻，消灭敌人步兵。

在进攻战斗中，战士必须贯彻近距离歼敌的思想，发挥勇敢战斗、不怕牺牲、不怕疲劳和连续战斗的作用，灵活地利用地形地物，善于防御敌人、化学武器和火力袭击，迅速隐蔽地接近敌人，勇猛冲击，与友邻部队士卒密切协同，坚决消灭敌人，完成战斗任务。

# 利用地形地物

利用地形地物的目的是于躲蔽躯体，发扬火力，只有充分地发扬火力，消灭敌人，才能有效地保存自己。因此，在利用地形地物时，应首先着眼于发扬火力。

地形：是指地貌和地物的总称。地貌是地面高低起伏的状态，如山地、平原、凹地等。地物是地面上的固定物体，如房屋民宅、道路、土堆、江河、树木等。

利用地形地物的方法：战士利用地形地物时，应做到：便于观察、射击、 साफ藏躯体；不妨碍班（组）长指挥、火器射击和较高兵动作；不要几个人埋伏在一起，以免增大伤亡；尽量雷开独立、明显的物体和难以通行的地方。火箱前、单兵掩蔽于利用地形地物时，应有良好的射界，在火器射击方向的草线上不应该有坚硬障碍物；枪（筒）后面三十米内，不能有人，以免伤害自己。
