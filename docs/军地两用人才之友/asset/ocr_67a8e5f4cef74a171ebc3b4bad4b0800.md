例如图上某山顶的高程为 150 米，该地最低处的等高线为 50 米，高差即为 100 米，沙盘水平比例尺为 1：500，垂直比例如按比例放大为二倍，则山顶的高差为

```
100米 × 1/500 × 2 = 0.4米（40厘米）
```

器材准备。制作沙盘所使用的材料应根据使用的目的和物管条件而定。一般需要细沙、泥土、竹（木）签、兵棋、说明居民地和高地名称所使用的纸条等。

# 制作沙盘与要领

办法一般，先设摆放沙盘的方位，然后铺上干湿适度的沙土，制平面，作为最低等高线的平面。依比例在沙盘上钉与地图相应的方格网，注上相应的编号（图二）。

操作步骤。（1）依方格将地图已选定的等高线、各高地的山顶、蔽塞、山脚和江河等画到沙盘上。（2）将山顶、鞍部等定位在分 别钉竹签。以上竹签和沙盘上的高低相等都。（3）在最低等高线范围内，以竹签和等高线为依据，先绘制山顶、山脊、散部等的轮廓形状作为骨干，再填充其余部分，最后对照地图全面检查和修改（图三）。

这些地物。沙盘上的地物，通常相应地模拟或颜色表示。如房屋、桥梁、独立地物等可用相似的模型表示；道路用宽窄不等、颜色不同的纸条表示；河道用蓝色的纸条或表格表示；树林可用小树枝代替。
