提前量的计算公式是：
提前量（人体） = 降落速度（6米/秒）×弹头飞行时间 / 人体高（1.5米）

# 打着陆前空降兵应注意的问题

集结兵力各方歼灭敌人, 近战歼敌的原则, 也完全适用于打敌空降兵, 但应注意重。

+   (1) 空降兵在降落当中, 通常夹带着空投的物资。 在射击中, 要注意把人和物分清楚。 不要把物当人打。 判断人和物的标志: 人在空中是动的, 物是 Lai 不动的; 物的体积一般比人重; 通常物比人重, 所以物一般打来的人快。

+   (2) 注意对人射打。 因为伞衣面积大(一般为60—80平方米) 而且有加强筋, 打上一些弹头关系, 空降兵照样可以安全着陆。

+   (3) 射击中应注意观察, 是否已被击中。 判断降落中的敌空降兵是否被击中, 简单的观察就是看降落伞下面两个手和两脚的情形。 空降兵在降落中, 正常的姿势是: 两手向上握着接绳带, 两腿并拢稍弯曲。 如果不是这样, 而是两手下垂, 两腿在下坠拉着, 就说明已被击中。

# 对刚着陆之空降兵的冲击

敌人连以下小分队空降时, 从着陆到集结完毕, 大约需要15—30分钟, 在这段时间内, 敌人比较混杂, 战斗力不强。 因此, 应抓住这个时机, 猛打,猛冲, 力求在敌人未集结之前, 予以歼灭。 如敌人已集结, 并占据了一定阵地, 应乘敌人防御准备不足和不稳定的时机, 迅速地接近敌人, 以火力掩护下, 迅速发起冲击, 以打乱射击, 削弱敌...
