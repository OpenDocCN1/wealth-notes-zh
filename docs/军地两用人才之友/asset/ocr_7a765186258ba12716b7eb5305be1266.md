# 灵芝

灵芝是一种木材腐生菌，最宜在温度25—28℃，良好的空气、较高的空气湿度Present和一定的散射光下生长。自然界灵芝多生在枯死的阔叶树的空洞上。

# 菌种培养

1. 培养基的制备  糖醋粟20克，土豆（去皮）200克，琼脂20克，水1000毫升。制法是将土豆去皮切成薄片，然后切成薄片，加水1000毫升，煮到胶而不过烂，过滤除去渣滓，滤液加琼脂煮沸，琼脂要预先用少量水浸泡，过煮的琼脂往往难以溶解，以防止烧焦和不能滤清，则琼脂完全溶解，加糖醋，重新置锅中，加水至1000毫升。尔后，分装试管，装量为试管长度约1/5 —1/4。塞好棉塞，在1.2/5公斤/厘米压力下灭菌半小时，于冷却后前放置室内。热后也无异常反应。

2. 菌种培养 从原有灵芝菌种取菌丝较大的菌块一块，置于新的培养基培养上。在温度25℃左右培养，20天后可长满菌面。菌丝长长后应及时移植到木屑培养基上，进行瓶栽培养。

# 原木栽培

1. 栽培菌配料 ①木屑、松、杉、樟等含养素棉纤维较多的木屑均可使用。78%，<|start|>皮或米糠20%，蔗糖1%，石膏1%。②木屑和麦麸比为三比一。将水、蔗皮（或米糠）、石膏粉拌匀，将蔗糠于水中倒入料内，加水并加培养料，用手握时在指缝间有水而不滴为好。然后装入瓶子、压紧，距瓶口留4—5厘米空隙，再用小手指蘸的木屑在瓶中央上而下拍一圈。瓶盖外要密封，塞好棉塞。用墨锅间歇夹蒸1次，或用高压灭菌锅蒸1小时。

2. 其它培养 天窗后，在无菌室或干净的地方用接种针将存放较大的菌块一块，放入培养基瓶的中央处，塞好棉塞，置25—28℃的地方保温培养。此时不需要光线，一般经过15—20天白色菌丝即可长满全瓶。
