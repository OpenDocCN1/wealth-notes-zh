# 水表的性能

水表，也叫做旋翼式水表。它是用來計量自來水流經管道的總量，只能用于单向水流。因内部机构全部浸于水中，故称之为浸式水表。

水表的主要结构由外壳、累积测量机构和<|start|>遥指示机构组成。当水流入水表后，自测盘机内下部翼轮盒的下排孔沿缝线方向流入，冲击败舞轮旋转，然后由翼轮盘的上排孔流出，翼轮转速与水流速度成正比，经过减速传动，计算器即指示出通过水表的总水量。水表的外型如下图。

水表的口径有多种，规格也各不相同。选择水表规格时，应先了解管路流量，使水表负荷不会过大，应以经常使用流量接近（小于）额定流量为宜。
