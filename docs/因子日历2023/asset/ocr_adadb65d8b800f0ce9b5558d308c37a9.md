# 价量相关性趋势因子

+   ① 每月月底，回溯每只股票过去20个交易日的价量信息，每日计算该股票分钟收盘价与分钟成交量的相关系数；

+   ② 将每只股票的20个相关系数 $\rho_t$ 对时间 $t$ 回归，取回归系数 $\beta$，即 $\rho_t = \beta t + \varepsilon_t$，其中，$t = 1,2,3,...,20$；

+   ③ 将所有股票的回归系数 $\beta$ 在横截面上剔除市值、传统价量类因子（20日反转、20日换手率、20日波动率因子），得到的结果即为价量相关性趋势因子 PV_corr_trend。

# 说明

PV_corr_trend越小，即价量相关系数随时间推移变小的股票，未来收益倾向于越高。
