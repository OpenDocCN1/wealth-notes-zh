# 理想反转因子

① 对单只股票，回溯取其过去20日的数据，计算每日日内逐笔成交金额分布的13/16分位值；

② 13/16分位值高的10个交易日，涨跌幅加总，记作 M_high ；
13/16分位值低的10个交易日，涨跌幅加总，记作 M_low ；

③ 计算理想反转因子：M = M_high − M_low 。

# 说明

早期版本的理想反转因子是以 “每日的平均单笔成交金额（成交金额/成交笔数）” 作为切割标准；作者分析得出 “反转之力的微观来源，是大单成交”，由高分位值较高（即大单成交较多）的那些交易日得到的反转因子，具有更强的反转特性。
