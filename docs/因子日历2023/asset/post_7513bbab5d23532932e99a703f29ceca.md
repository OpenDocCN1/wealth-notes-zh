## 时间加权平均的股票相对价格位置

计算股票相对价格位置，即股票当期价格相对区间最高最低价的分位数：

RPP_{i,t} = (P_{i,t} - L_i) / (H_i - L_i)

将股票相对价格位置对时间进行积分，得到时间加权平均的相对价格位置ARPP：

ARPP_i = ∫₀^T RPP_{i,t} · dt ⇒ ARPP_{i,t} = (∫₀^T P_{i,t} · dt - L_i) / (H_i - L_i)

### 其中

+ ① RPP_{i,t} 表示股票 i 在某一时间区间内的时刻 t 的相对价格位置；
② H_i 和 L_i 为该时间区间内股票 i 的最高价和最低价；
③ ∫₀^T P_{i,t} · dt 表示股票 i 在时间区间0到T内的时间加权平均价格（即 TWAP），可以用分钟线高开低收均值在时序上的均值作为区间的 TWAP。

## 说明

衡量股票在价格相对高位停留的时间长短，股票在价格相对高位停留的时间越长，因子取值越大。

【参考文献】
朱剑涛, 2020, 基于时间尺度微的日内买卖压力, 东方证券.

## 方向标准离差指标

技术因子-超买超卖型

```
DMZ = IF(HIGH+LOW<=HIGH[1]+LOW[1],0,
MAX(ABS(HIGH-HIGH[1]),ABS(LOW-LOW[1])))
DMF = IF(HIGH+LOW>HIGH[1]+LOW[1],0,
MAX(ABS(HIGH-HIGH[1]),ABS(LOW-LOW[1])))
DIZ = SUM(DMZ,N)/(SUM(DMZ,N)+SUM(DMF,N))*100
DIF = SUM(DMF,N)/(SUM(DMZ,N)+SUM(DMF,N))*100
DDI = DIZ-DIF
若分母为 0, 则令 DDI = 0
默认: N = 20
```

## 说明

DDI指标，即方向标准离差指数，一般用于观察一段时间内股价相对于前一天向上波动和向下波动的比例，并对其进行移动平均分析。通过分析DDI柱状线，可以判断是买入信号还是卖出信号。

[参考文献]
常规通用技术指标.

## 归属母公司股东权益环比增长率

abs(上一报告期归属母公司股东权益)

## 说明

③ 至于增长率和增量，表现相差不大，增长率更具可比性，增量更不易受基础指标取值异常的影响。

## 操纵性总应计盈余

分行业分年度进行如下截面回归：

TA_{i,t} / A_{i,t-1} = α_{i,1} 1/A_{i,t-1} + α_{i,2} ΔREV_{i,t} / A_{i,t-1} + α_{i,3} PPE_{i,t} / A_{i,t-1} + ε_{i,t}

将上述回归得到的回归系数代入下面的方程，即得到非操纵性总应计盈余：

NDTAC_{i,t} = α_{i,1} 1/A_{i,t-1} + α_{i,2} (ΔREV_{i,t} - ΔREC_{i,t}) / A_{i,t-1} + α_{i,3} PPE_{i,t} / A_{i,t-1}

将非操纵性总应计盈余从总应计盈余中扣除：

DTAC_{i,t} = TA_{i,t} / A_{i,t-1} - NDTAC_{i,t}

### 其中

+ ① TA_{i,t} 为股票 i 在 t 期的总应计盈余，计算细节见相关页；
② A_{i,t-1} 股票 i 在 t-1 期的总资产，用于标准化各财务指标；
③ ΔREV_{i,t} 为股票 i 在 t 期相对 t-1 期的营业收入增加额；
④ ΔREC_{i,t} 为股票 i 在 t 期相对 t-1 期的应收账款增加额；
⑤ PPE_{i,t} 为股票 i 在 t 期的期末固定资产总额。

## 说明

上述计算方法对应的是修正后Jones模型，只需去掉应收账款项就能得到原始的Jones模型；总应计盈余可以分为非操纵性总应计盈余和操纵性总应计盈余2部分，其中的操纵性应计盈余对应的就是企业出于某种动机而进行的盈余管理，其与股票未来收益负相关。

【参考文献】

① Dechow P., Sloan R., Sweeney A, 1995, Detecting Earnings Management, The Accounting Review 70(2), 193-225.

② Jones J., 1991, Earnings Management During Import Relief Investigations. Journal of Accounting Research 29(2), 193-228.

## 总偏度

最近K个月的日度收益率的偏度，K=6、12等，即：

Skew_i = \frac{\frac{1}{T}\sum_{t=1}^{T}(r_{it} - \bar{r}_i)^3}{\left(\frac{1}{T}\sum_{t=1}^{T}(r_{it} - \bar{r}_i)^2\right)^{\frac{3}{2}}}

## 说明

总偏度与股票收益负相关，由于投资者追求具有正偏度的股票，导致其价格容易被高估，使得预期收益率较低，属于低风险异象。

[参考文献]
Ang, Andrew, Robert J. Hodrick, Yuhang Xing, and Xiaoyan Zhang, 2006, The cross-section of volatility and expected returns, Journal of Finance 61, 259-299.

## 趋势动量

以月度因子为例，在每月 t 最后一个交易日 d 计算每只股票在不同时间尺度 L 的移动平均价格作为趋势信号：

```
$MA_{jt,L} = \frac{P_{j,d-L+1}^t + P_{j,d-L+2}^t + \dots + P_{j,d-1}^t + P_{j,d}^t}{L}$
```

### 其中

$P_{j,d}^t$ 股票 j 在第 t 月的每个交易日的收盘价，L 是移动平均的窗口宽度；

由于不同股票的价格在量级上存在差异，为了使趋势信号在截面上具有可比性，将移动平均价格序列除以 d 日最新收盘价，做标准化处理：

```
$M\tilde{A}_{jt,L} = \frac{MA_{jt,L}}{P_{jd}^t}$
```

不同时间尺度 L(L=3、5、10、20、50、100、200、400、600、800 以及 1000 个交易日)上的移动均线即为不同级别的趋势信号，这些趋势信号可能代表动量，也可能代表反转；

光大证券将不同时间尺度的趋势信号 $M\tilde{A}_{jt,L}$ 作为趋势动量因子；然后利用代表散户集中度的流动性因子和流通股占比因子对趋势因子进行横截面中性化处理，提纯后的动量因子的单调性和多空收益都改善显著。

## 说明

趋势因子综合考量了在不同时间点上，不同时间跨度的动量或者反转因子对股票未来收益的贡献。

〔参考文献〕

> Chan, Louis K. C., Josef Lakonishok, and Theodore Sougiannis, 2001, The stock market valuation of research and development expenditures, Journal of Finance 56, 2431-2456.

## 阿隆指数

技术因子-动量反转型

AROON上升数 = (计算期天数-最高价后的天数) /计算期天数*100

AROON下降数 = (计算期天数-最低价后的天数) /计算期天数*100

## 客户动量因子-基于多层客户关系

利用供应链的相关数据，结合图网络有关特征，计算如下客户动量因子：

```
cmom_i^{TM} = Σ_{l=1}^{L} Σ_{(m,n)∈G_u} w_{mn}^{centrality} mom_n^{TM}, i = 1,2,...,N
```

```
w_{mn}^{centrality} = c_{mn} / Σ_{l=1}^{L} Σ_{(m,n)∈G_1} c_{πn}
```

### 其中

+ ① mom_j^{1M} 为 i 的客户 j 过去一个月收益率；
② 权重 w_{mn}^{centrality} 为考虑了多层（L层）客户关系的边中介中心度权重。

## 说明

该因子同样采用了供应链图网络的边中介中心度Edge Betweenness Centrality作为权重，而且考虑了多层关系客户（客户的客户）；作者发现对比于只考虑直接的客户，客户的客户能带来更多的增量信息。
