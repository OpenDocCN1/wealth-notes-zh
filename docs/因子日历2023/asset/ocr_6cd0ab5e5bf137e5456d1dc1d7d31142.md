# 盈余公告回报

动量因子

公告日当天及前后交易日共3天的个股票累计收益 - 对应时间段上的预期累计收益

其中

预期累计收益率 = 大盘指数的累计收益率

# 说明

盈余公告回报捕捉了市场对公司盈余公告中包含的意外信息的反应，是PEAD效应的衡量指标。
