# 相对强弱指标

技术因子-超买超卖型

```
UM = IF(CLOSE-CLOSE[1]>0,CLOSE-CLOSE[1],0)
DM = IF(CLOSE-CLOSE[1]<0,CLOSE[1]-CLOSE,0)
UA(N) = (UA[1]*(N-1)+UM)/N
DA(N) = (DA[1]*(N-1)+DM)/N
RSI = 100*(UA/(UA+DA))
UA初始值 = SMA(UM,N)
DA初始值 = SMA(DM,N)
默认: N = 14
```

# 说明

RSI指标多在30-70之间变动，通常80甚至90时被认为市场已到达超买状态，至此市场价格自然会回落调整。当价格低跌至30以下即被认为是超卖状态，市价将出现反弹回升。
