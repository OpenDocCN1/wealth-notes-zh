# 有形资本回报率

财务质量因子-盈利能力

# 其中

有形资本 = 净营运资本 + 净固定资本

净营运资本 ≈ 流动资产 - 流动负债

净固定资本 ≈ 固定资产

# 说明

有形资本是日常经营活动所需的资本投入，衡量有形资本的收益回报程度。
