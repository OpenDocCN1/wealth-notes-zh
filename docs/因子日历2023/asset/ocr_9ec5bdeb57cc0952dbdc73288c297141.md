# 成交量比值

高频因子

```
VR_t = 1/d sum_{i=1}^{d} w_{t-i} * (Vol_moring / Vol_afternoon)_{t-i}
```

其中

+   ① (Vol_moring / Vol_afternoon) 为每日上午、下午开盘的前 30 分钟成交量比值；
② w_{t-i} = { (1-α)^{i-1} / sum_{i=1}^{∞} (1-α)^{i-1}, 指数加权; 1, 等术平均 } 为时间权重因子；
③ α 为信息的衰减强度，即 α = 2 / (1 + d)；
④ d 为每月最后一个交易日向前回溯移动平均的交易日个数。

# 说明

上午开盘30分钟的成交量越小或者下午开盘30分钟的成交量越大，即成交量比值因子的值越小，对于股票次月收益预测的有效性越强。

【参考文献】
刘均伟, 2017, 高频因子: 日内分钟的成交量蕴藏玄机, 光大证券.
