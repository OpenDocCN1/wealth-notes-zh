# 理想振幅因子

对单只股票，回溯取其最近N个交易日（默认N=20）的数据，计算每日的振幅（最高价/最低价-1）;

选择收盘价较高的 λ（默认25%）有效交易日，计算振幅均值得到高价振幅因子 $V_{high}(λ)$；选择收盘价较低的 λ（默认25%）有效交易日，计算振幅均值得到低价振幅因子数学公式: $V_{low}(λ)$；

计算理想振幅因子： $V(λ) = V_{high}(λ) - V_{low}(λ)$。

# 说明

基于股价将振幅因子进行切割得到的理想振幅因子，考虑了不同价格区间的振幅分布信息差异（高价振幅因子具有更强的负向选股能力），选股能力更强。
