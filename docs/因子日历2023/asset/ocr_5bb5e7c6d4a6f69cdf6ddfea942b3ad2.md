# 异常尾部概率E

波动率因子

```
E_φ = ∫_{k}^{+∞} f(x)dx − ∫_{-∞}^{-k} f(x)dx = P(x ≥ k) − P(x ≤ −k)
```

# 其中

+   ① x 为特质收益率 ε_{i,d}，通过 R_{i,d}=α_i+β_i R_{m,d}+γ_i R_{m,d}^2+ε_{i,d} 估计得到；

+   ② k 为左、右异尾的阈值，如k=1.5；

+   ③ 可以使用过去3个月的日度收益数据计算上述因子。

# 说明

优于偏度的新的收益非对称性的度量方式之一；若该因子大于零，则表示该股票在过去出现大涨的概率胜于大跌的概率，而投资者出于“追涨”的心理往往乐于购买此类股票，从而使得此类股票在未来下跌的概率增大。
