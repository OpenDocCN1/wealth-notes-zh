# 垂直水平过滤指标

技术因子-趋势型

```
HCP = MAX(HIGH,N)
LCP = MIN(LOW,N)
A = ABS(HCP-LCP)
B = SUM(ABS(CLOSE-CLOSE[1]),N)
VHF = A/B
若分母为 0, 则令 VMI = 0
默认: N = 20
```

# 说明

VHF指标用来判断当前行情处于趋势阶段还是振荡阶段，类似MACD等指标也能帮助识别行情趋势，但当行情处于盘整阶段时会出现经常发出错误信号，而RSI在振荡行情时能准确识别超买超卖的状态，但在趋势行情时总是发出错误信号。VHF指标通过识别趋势的强弱，来帮助投资者选择相应的指标（如MACD或RSI）。
