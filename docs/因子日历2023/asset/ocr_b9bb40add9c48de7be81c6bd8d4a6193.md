# 估值趋势偏离度

假设个股的估值水平VR由长期趋势项和短期偏离项共同决定：

```
VR_t^i = Trend_t^i + Deviation_t^i
```

长期趋势项Trend可以看作是行业基本趋势和个股特异性因素共同决定，其中：

```
Trend_i^i ≜ C^i × SVR_t^i
```

引入误差修正模型来对上述的关系进行建模：

```
ΔVR_t^i = α^i × ΔSVR_t^i + λ^i × ECM_{t-1} + ε_t^i
```

```
ECM_{t-1} = (VR_{t-1}^i - C^i × SVR_{t-1})
```

长期趋势项Trend可以看作是行业基本趋势和个股特异性因素共同决定，其中：

```
DR ≜ (VR_t^i - C^i × SVR_t)/VR_t^i
```

# 其中

+   ① SVR_t^i 为股票 i 所属行业所有成分股在 t 时刻的估值中位数；
② C^i 是股票 i 的特异性因素，取值与时间无关；
③ λ^i 为短期偏离的回复速度，λ^i ∈ [-1,0]；
④ VR_t^i 估值水平可以选择市净率、市销率的倒数等估值指标；
⑤ 每日计算，样本为过去每间隔20个交易日的36个样本点。

# 说明

该因子从时序维度刻画了估值趋势的短期偏离程度；因子的绝对值越大，说明当期估值对长期趋势的偏离越明显，潜在的投资获益空间也越大；因子的正负方向代表着估值水平相较于当前趋势来说是低估还是高估。
