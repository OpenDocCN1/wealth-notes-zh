# 1.什么是演化？演化有方向吗？人类整体总是在进步吗？

进化 (evolution) 这个词，现在有很多人士号召翻译成“演化”，因为进化的“进”字似乎暗示它有一个从低级到高级的方向。长时间大尺度来看，的确有这样的趋势，但具体到演化的每一步，其实都是没有方向的。

几十万年前地球上至少有六种不同的人种，之前还有更多，我们这一支最后统治地球，纯属偶然。
