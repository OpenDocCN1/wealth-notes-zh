# 第五種資產是: 保值對象, 就是可以保值, 同時具備升值空間的物品。

這一類物品有很多，包含黃金、古董、紅木、玉石、藝術品、老茶、醇酒、限量版跑車、限量款奢侈品等。
這些物品的價值多數會隨著時間提升，只要你有足夠的鑒定眼光與掌握買賣的時機。像我親愛的奶奶，她以前特別喜愛蒐集郵票，特別是限量發行的紀念版，收藏到如今也增值不少。
我十三歲那年，在發生大地震之後，父親前往房屋坍塌的地方尋找爺爺奶奶的遺物，從斷瓦殘垣中挖出了三本集郵冊，有奶奶每逢節日到郵局採購的，也有跟馬來西亞、新加坡、各國友人通信所搜集下來的郵票。記得我小時候還經常幫奶奶把撕下來的郵票都浸泡在水桶裡，讓它們從信封上脫落後再曬乾。
當你了解這五種不同類型的資產，你就知道耳熟能詳的「不要把雞蛋放在同個籃子裡」該如何操作了。
