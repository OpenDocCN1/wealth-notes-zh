# 推薦序 6 嘿～你準備好醒來跟我一起去尋寶了嗎？

財務自由是很多人心中曾有過的夢想，然而絕大多數的人若不是從來沒有真正行動過，就是行動中遇到一些挫折就放棄了，真正能夠實現財務自由的人可說是鳳毛麟角。

你是否也跟曾經的我一樣思考著：為什麼這個閃著耀眼光芒，在對我們招手的寫著財務自由的大大看板，卻有如沙漠中的海市蜃樓，永遠走不到？答案不光是選擇去做什麼，更重要的是你帶著什麼樣的「意識」去做，唯有帶著正確的「金錢意識」，才能夠有效地把金錢顯化到自己的身邊。

我漸漸覺察到這個通往真正的、終極的自由，其背後的藍圖大致上是長什麼樣的，於是我一直很想將其描繪出來，幫助更多人能夠縮短摸索期。何其有幸的是，芳誼老師寫出了這本書，把很多我想講的事情，都講了，不止如此，而且講得精彩有趣。對於想在紅塵中修行，又想要在經濟上能夠過上富裕生活的人，這本書不但給了你地圖，還很佛心地連指南針跟手電筒都一併打包好給你了。

「如夢初醒」是芳誼老師創辦的成長學院品牌，就我的觀察，絕大多數的人都在睡夢中，只是他們不知道自己正在做夢，一旦他們醒來了，就有機會拿回自己應有的力量、智慧與財富。相信這本書的發行，將會帶動世界上更多的人提升意識層級，有機會活出一個升級版本的人生，因此，我極為樂意為此書為文推薦，並廣為宣傳此書給我身邊的人。祝《喚醒財富腦》不止暢銷，而且長銷！
