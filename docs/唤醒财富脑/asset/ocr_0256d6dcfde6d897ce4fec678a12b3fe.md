# 章節小結

有錢等於擁有財富嗎？

+   1、 金錢並非是一個固定不動的東西，它的價值隨時隨地都在變化。
   錢的本質就是貨幣，需要去流通，若錢沒有流動，價值就會越變越低。 
2、 現金不等於資產，貨幣只是資產的其中一種。

你是窮人？還是有錢人？

+   1、 世界觀下的貧富評判標準：大多數人都比自己想像中富有。 
2、 多數人要做到是一種平衡的心態，才有助於平穩的財富創造與輸出，這就要仰賴更正確的自我認知。

如何打造吸金體質？

+   1、 財商是剛需：衡量一個人財商高低的關鍵在於，他能夠在時間中把擁有的錢發揮出多高的效益。 
2、 你應該擁有的淨資產＝你的稅前年收入 x 你的年紀 ÷ 10 
3、 認清自己的理財水平，提升管理財富的能力，才能積累出匹配自己收入水平的淨資產。
