# 你的 人生與財富曲線

![](bbox=[0.406, 0.144, 0.63, 0.312])

如果有一張圖可以預測你的人生發展、甚至是你的財運走勢，你會不會想看一看？

首先我們來看到這張圖表，如此簡單的幾條線，怎麼會跟賺錢有關呢？事實上，讀懂且體會到這張圖的深意，你就掌握了這一 生去創造價值、財富、愛與幸福的關鍵。

在做任何說明之前，你會如何解讀這張圖呢？首先是我們中學都學過的 X Y 軸，一條垂直線和水平線畫出一方天地，然後是一條往上走的斜線，接著在斜線底下是另外一條曲線，帶著緩慢的成長率逐步往上，後面越走越陡峭，最後直沖雲霄。我在課堂中會請同學跟著依樣畫葫蘆，在紙張的空白處畫出這張圖，現在我也邀請你這麼做，在畫出這兩條線的過程中，思考一下它們代表什麼含義。

![](bbox=[0.313, 0.653, 0.736, 0.826])

如果用這張圖表來看圖說故事，你認為 X Y 軸、這兩條線、以及星號分別代表什麼？你的成功與財富跟它們又有什麼關係呢？
