# 快速成長的良方：如何向上結交？

個體是環境影響下的產物，環境又是由另一群人所組成的。

懂得如何向上結交，但又不趨炎附勢、唯利是圖，這其中需要很大的智慧。有點像是我們在第五、六章談到的「放下面對金錢的上位感與下位感」，回歸到與金錢對等而流動的關係裡，面對財富維度、見識經歷在我們之上的人，也是相同的原則。

談到交友，有些人只喜歡跟比自己弱的人玩，一遇到強者就會自慚形穢。例如在學生時期，你會發現有些女生很漂亮，但只喜歡找特別不會打扮的女生一起玩，這是因為在潛意識裡，人們享受被綠葉襯托，跟比自己弱小的人在一起，會使人享受到優越的舒適感。

甚至，不僅僅是在外表，當我希望自己在各方面都可以鶴立雞群時，就會找財富維度比我低的人玩，找見識比我少的人玩，所謂寧為雞首不為鳳尾就是這個道理。

這樣會使自我覺得很安全，不會有自卑或不自信感，只要一直向下兼容，遠離各方面條件優於自己的人，就不需要面對內在不自信的不舒適感。

但是有另外一種人，除了跟同儕交流外，也經常尋求機會「向上結交」，這並不是說功利主義，而是帶著一種學習者的態度去擴充交友圈。結交比自己好看、富有、事業做得更好的朋友，希望通過往來交流學習到對方的優點。
