# 致富的目的與意義

我們想要提升財商、創造更多的財富，大部分的人肯定不只是為了積累銀行帳戶裡一個更漂亮的數字，而是為了財富能夠帶給我們的其他事物與體驗。當我們更清晰想要通過財富獲得什麼，就會得到更長遠的財務動力。

你希望財富能夠為你實現什麼樣的生活呢？

當有一天完全不需要擔心金錢，源源不絕的金錢就出現在你的生命之中時，你會想要去做些什麼？財富能夠為你創造什麼？

也許有人想要環遊世界（在此祈願疫情快快緩解）；有人想要有更多的閒情逸致；有人想要學畫畫，去做一些無用的藝術創作；有人想要好好陪伴家人、孩子；有人想投入公益活動，去做一些當下沒有立即的經濟效益，但是能夠撫慰人心的事。

生命的意義、蓬勃和精彩雖然並不是金錢本身能帶來的，卻是通過金錢得以實現的，這也是NLP之母朱迪芙老師為我寫下的推薦序裡所說的，金錢的目的 是讓我們去實踐更多的生命價值。

當我們想要賺錢，背後卻沒有足夠多的動力（motivation），我們就會覺得有或沒有都沒有差，遇到挫折就會呈現比較消極的狀態。當一個人內在消極的時候，旁人再怎麼鞭策他也沒有用。

現在請跟著下面這個練習，列舉出十條以上的財富願景：當你財富自由的時候會想去做什麼？當你完全不需要為了金錢煩惱的時候，你會想如何體驗人生？除了自己此生想要獲得的體驗外，你還能為世界帶來什麼呢？

從這兩個角度去思考，你將能夠感受到財富帶給你微觀與宏觀的雙重意義。
