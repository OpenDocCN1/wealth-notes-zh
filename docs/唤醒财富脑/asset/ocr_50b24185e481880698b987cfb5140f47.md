# 關係是照妖鏡

第二種迅速照見自己的方式是關係，特別是最親密的伴侶關係。

我們和枕邊人的關係通常就像照妖鏡一樣，無論多少年的修行，都可能因為一句話、一個矛盾而瞬間破功、現原形。我們往往容易把內在和童年沒有被療癒、滿足的部分投射到另一半身上，當我們認為另一半不重視我們時，往往是因為我們內在沒有真正重視自己，才會有這樣的投射。

但是伴侶關係也可以是照神鏡，當你在對方身上看到如神一般的<|message|>天性，你看到一個充滿潛力、天賦、英姿勃發的男人，代表你內在也是一個充滿著天賦、美麗和智慧的女人，反之亦然。

沒有發生衝突的時候，我們都很好，你也很好，我也很好，為什麼我們兩個湊在一起就不好了呢？因為關係就像一面鏡子，會把你所有內在正面的、負面的都加以放大照映出來，這也是親密關係能夠作為修道場的原因。
