# 推薦序 7 人人都該擁有的斜槓資產

熟識芳誼已超過十年，能夠為她的第一本大作寫序，我感覺無比榮幸，這幾年我見證了她的能量逐漸由內而外、發光發熱，並影響成千上萬人生命的過程。

舉個令我印象深刻且貢獻了一些意見的段落，書中芳誼歸納了致富必備的五大資產，其中，智慧財產權少見地被列為致富資產的一種。過去，智慧財產權是為了商業而存在的權利，藉由專利和商標保護核心競爭力，企業才能發展出獨佔的市場。因此，若沒有意圖進行商業行為或只想賺短視近利的快錢，專利商標對你而言僅僅只是消耗甚至是負債。反言之，若企業重視長期且穩定的獲利，那麼書中列舉了很多因智慧財產權而成就偉大企業的案例。

隨著時代的變化，自媒體的蓬勃發展，智慧資產也漸漸成為人人皆可以斜槓累積的資產。如芳誼爸爸的大學教科書、芳誼自己的翻譯作品與創作，又例如素人 Youtuber 等，這些創作都是著作權資產，也是人人都可以為自己建立的被動收入來源。

書末還有一個神奇章節，讓我想起大女兒剛學走路的樣子，一開始她急著想往前，常常跌倒，但她每次都笑著爬起來，直到最後會爬、會走、會跑、會跳。透過她的生命，我深深地對創造財富所需的力量有所體悟，嬰兒什麼時候放棄？他們從不放棄（直到會走為止）。
