# 推薦語

不知道從什麼時候開始，我從以前充滿好奇與熱情地學習財富的知識，到用厭倦的態度看待市面上的財富書籍，但我不知道是什麼信念卡住了我，而閱讀本書帶給我許多的啟發。書中非常直白地將那些隱晦不明、不容易覺察的限制性信念指了出來，還提供了許多的思考方向與案例。

第一次遇見芳誼時聽到她說：「我的願景是成為能夠影響、幫助許多生命的演說者！」她述說時發出了充滿靈魂、生命力的能量，後來我才明白她的底蘊來自汲取各大師的生命菁華。想像一下，有一位武學奇才，長期跟隨全球各大門派的掌門人，融會貫通各家的菁華，並用簡單易懂、直指人心的方式寫出一本書，讓更多人學習到致富之道，那會是一本怎樣的書？答案，就在你手中。

星澄

星澄管理顧問有限公司創辦人

心靈吧台網站主持、線上課程研發者及教練

身為世界著名人士所指定的同步口譯，我於 2012 年首次與作者一起前往馬來西亞進行工作。當時這位臨危授命但並未流露出緊張的年輕小姐，讓我刮目相看。我看到了作者在工作態度、專業能力以及個人靈性的持續成長。也很佩服作者，在經過多年學習摸索，發掘出真正的自己之後的努力與割捨。當我看見她堅持不懈地找到並活出自己的「本心」時，真是替她感到高興！我清楚地知道：與當今市面上噱眾取寵、誇大炫富、「毁」人不倦的人比起來，Rosie 真的是一位很溫柔，契合自己本心，令人放心的老師。
