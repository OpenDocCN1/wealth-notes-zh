# 你的生活是正能量還是負能量？

1、照見自己的方法：
第一種，觀察身體，覺察不適所帶來的啟示。
第二種，觀察關係（尤其是親密關係），來看見內心真實的自己。
第三種，觀察金錢，慾望的本質就是人性的本質，跟金錢的關係就是跟世界的關係。
2、身體姿勢會直接影響我們的能量狀態：舒展、敞開的姿勢，往往呈現那個人的自信與力量，而退縮、包裹、防禦的姿勢則呈現不自信和自卑。

# 保持高頻能量是關鍵

1、提升狀態、能量的四句話：
I’m sorry。對不起。
Please forgive me。請原諒我。
I love you。我愛你
Thank you。謝謝你。

2、培養富足感的方法
第一種，每個月挑選一天，盡情享受金錢帶來如同國王／王后一般的生活。
第二種，通過不找零或付小費，建立內在的豐盛感。
第三種，在親朋好友群中發紅包，體驗到分享和給予帶來的快樂。
第四種，參加學習，讓現場的高能量衝擊身體。
