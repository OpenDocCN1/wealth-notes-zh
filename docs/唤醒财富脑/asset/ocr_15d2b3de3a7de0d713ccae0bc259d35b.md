# 如何越花越有錢

有錢人與窮人的第二個區別是花錢方式，也就是支出方式的不同，最關鍵的就是：有錢人買資產，窮人買負債。

「有錢人買資產，窮人買負債」，這是什麼意思呢？乍聽之下，你會覺得這是廢話，債務人人都避之唯恐不及，誰會想要買負債呢？資產就更不用說了，當然是越多越好啊。

但其實對沒有財商概念的人來說，不經大腦思索地花錢，很容易就買進負債。許多窮人平時不敢花錢，有時候又突然因為意外或衝動而做了完全超出能力的消費，反而感覺越省越窮。

多數有錢人勇於花錢，錢卻越花越多，是因為有錢人對於花錢有長期規劃，因此能讓花出去的錢成為資產。而窮人大部分花錢都在進行消費和衝動型支出，導致錢如東流水一去不復返。

還記得我們在序章做的財富阻礙測驗嗎？本章將更深入去探討，那些負面信念如何導致我們為了別人眼中的形象、為了補償自己壓抑的情緒、為了逃避生活責任而消費。由於內在的財富阻礙而產生的消費，往往最後都會成為負債。
