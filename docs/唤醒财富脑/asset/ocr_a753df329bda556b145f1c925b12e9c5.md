# 推薦序 5 一本驚為天人的財富經典之作

2011 年是我人生最低潮的時刻，那是我失業、失意、不知道人生方向的一年，也是我人生最大轉換點的一年。那時我報名了「有錢人想的和你不一樣」量子飛躍系列，也在第一個海外課程「覺醒戰士營」裡認識了作者芳誼……那時令我印象十分深刻的是，她不只擔任翻譯，還親自體驗了所有的挑戰環節，展現出強大的自信與勇氣。

十年後的今天，‘看到芳誼的這本《喚醒財富腦》，真的令我大大驚喜與讚嘆。驚喜的是芳誼這本著作，結合了我這十年來飛往世界各地上大師課裡菁華中的菁華，「看了這本書，少走十年路」。除此之外，芳誼旁徵博引許多的科學研究數據，還給了大家實用的測驗與工具。看了這本書不只是會升級你的財富腦，更會為你的人生進行大升級、大改造。著實是不得不看的一本驚天之作。

有人說十年磨一劍，芳誼的這本著作更勝一籌，我翻開第一頁之後就停不下來，很想一頁又一頁地閱讀下去並咀嚼書中智慧。如果你有緣翻起這本著作，就把它帶回家，好好閱讀，一定能為你的財富開啟一條光明的富足之道。在我的許多課程中，我也常跟學生分享我的意圖，就是此生要走在「向上向善」的人生道路上。

在此我想要恭喜芳誼新作問世，也恭喜你即將透過這本書活出幸福、快樂的人生！

林達宏
達陣教育創辦人、網路行銷趨勢講師
《找到人生使命》、《凡事往好處想的遊戲》作者
