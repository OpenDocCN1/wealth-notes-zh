# 推薦序 4 從印度海邊吹來的財富奧秘

得知我的好姐妹芳誼要出版一本結合心理學與財富創造的書，拿到書稿的那個晚上，我挑燈夜讀到天亮，心中充滿了讚嘆。這本書實在是創造豐盛的阿拉丁神燈，也是涵蓋了身心靈全訊息場的致富寶典。

回想起我們姐妹倆一起走過的日子，心中興起點點感動的星光。多年後我在一場重大疾病後開始反思生命的價值，從企業人忙得腳跟不著地的生活，轉入身心療癒的世界，並開始引入各式西方的療癒體系，而如何找到專業、走心、有能量的口譯老師，就是當時的一大苦惱。

遇見芳誼之後我們一拍即合，她的認真專業與內外合一的能量，為我們引入華語世界的課程增色許多。爾後，我們一起走過新加坡、北京、甚至到印度的海邊，連接上越來越廣大的世界，而我也見證了這位靈魂姊妹在心靈和財富上的大幅成長。

我一直相信人的內在世界會創造他的外在世界，但這個世界充滿了負面、嘈雜的聲音，因此如何維持內在世界的富足與喜悅，事實上是財富之路最重要的一關鍵。很喜悅看到這本書總結了芳誼多年來與眾多國際大師密切工作的經驗，為我們挖掘出大師們不為人知的致富秘訣，真心推薦給你們。
