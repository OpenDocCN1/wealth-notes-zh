# 主動收入與被動收入

當你了解掙錢與賺錢的不同，你就打開了被動收入的大門。

主動收入，就是親力親為所換來的收入，窮人花大部分的時間賺取主動收入，做一小時有一小時的收入，做兩小時有兩小時的收入，做五小時有五小時的收入。幹就有錢，沒幹就沒錢。

被動收入，則是不工作也能進帳的收入，例如房租就是很好理解的被動收入來源，有些包租婆一個月工作兩天，28 號抄水錶、30 號收房租，其他時間就是打麻將和上美容院。

主動收入帶來的是相對被動的人生。並不是說主動收入不好，能夠靠一己之體力、能力去換得金錢，是十分值得驕傲的事情，也能建立紮實的成就感。

但是具備財富腦思維的人，會以主動收入作為基礎的生活保障，同時不斷思考賺取被動收入的方法，這就需要我們密切留意「時間貨幣」的運作。

# 時間即貨幣

根據能量守恆定律²，固定系統中能量守恆，不能生成或摧毀，但可以改變形式。金錢是一種能量，是由其他能量轉換和交換來的，例如透過你的體力、智力、天賦形成產品或服務，進而交換成金錢。

獲取財富，其實就是將你擁有的資源（能量）轉換為金錢的過程。
