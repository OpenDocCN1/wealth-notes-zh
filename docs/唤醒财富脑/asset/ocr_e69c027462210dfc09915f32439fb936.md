# 推薦語

我與芳誼老師結識於英國，那時我剛打完一場雙 11 的勝仗（我的本行是電商大數據分析），在她的國際工作坊中，我感受到她結合東西文化allenges的美好品質，形成一種特別滋養人的氣場，我內心暗想：「若有朝一日我要把十幾年的身心靈愛好轉為事業，我想找她做夥伴」。驀然回首，當時的「有朝」已成「今朝」，我們成為了閨蜜與戰友。芳誼老師的才華洋溢，讓我在設計教學上如虎添翼，同時又能持續得到全方位的支持，很感恩她出現在我的生命中，我的靈魂再也不孤獨了。

COCO 院長（錢坤）
數字心理學導師、成長美學家
神秘學導師，精通塔羅、薩滿等身心靈成長工具

後疫情時代，我們的財富、工作、生活、身心都面臨重大改變，世界財富也將重新分配，一切快速大洗牌。這本《喚醒財富腦》，來得正是時候。未來正在獎勵那些擁有不斷更新的學習腦、財富腦、身心靈腦的人。芳誼擁有圍繞在世界頂尖成功人士身邊的第一線體會，加上多年來在身心療癒、財富探索上獲得巨大的收穫，無私貢獻了如何喚醒財富腦，以及不被疫情洪流擊敗、不被自身認知邊界給限制住的秘訣。同是身為教育家、長年在知名企業擔任講師和顧問的我，看了這本書大受啟發。相信這本書絕對會幫助你，安然度過這個混亂不安的時代，且脫穎而出，成為真正的得勝者！
