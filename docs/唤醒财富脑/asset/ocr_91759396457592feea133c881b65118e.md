# 放心，車子不一定是負債

經過上個案例說明，現在我們來練習分析一下：車子是資產還是負債？這次你可能學聰明了，知道有財商的回答是：看情況。

不管是購買哪一種車，每年的稅金、保險、油資、停車費、維修費都是一筆不小的支出。

對某些人來說購車是很實質的需要，例如家裡距離公司遠又沒有大眾運輸系統，或是剛生了寶寶，需要經常載孩子、購買家用等情況。

但假如不是出於需要，而是因為想要展現給別人看，剛有一筆比較大的進帳，就急忙投入奢侈、虛榮型消費，喜提一台寶馬（BMW）。結果因為工作忙，一年根本開不到幾次，還需要特別找時間把車開出去遛躂以免壞掉，那這台車很明顯地就成為了你的負債。

也許剛買的時候，它讓你在朋友圈裡收割了一波羨慕之聲，但從此它就成為了負債，不斷消耗你的收入，同時沒有產出更多的收益。

上一章我們學習區分了消費背後三種不同的心理狀態：「需要」、「想要」以及「別人想要」，我們現在看到這三種心理狀態所形成的支出模式，讓我們更能看見不同的心理狀態如何導致不同的行為，最後形成不同的結果。

必要型消費是我為了自己的需要支出，維持食衣住行的基本需求，事實上許多人的必要支出都比實際支出要少很多，也就是有很多超出生存所需的開銷。

享受型消費是我為了自己的想要支出，增加了生存需求以外的消費，例如一週做一次全身 SPA 油推、一個月看一場文藝表演等興趣型和享受型支出。

虛榮型消費則是我為了別人的讚歎聲支出，也就是想要透過買來的玩意兒讓別人發出羨慕嫉妒恨的光波。例如為了博取其他人的讚歎而買入多台名車，卻根本沒時間開，讓車子成為車庫裡的怨婦。
