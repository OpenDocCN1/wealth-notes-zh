# 調整收入方式，才是變富的開始

從本章開始到第八章，我們會一一探討有錢人與窮人的六大區別，再次強調，這種說法並不是以存款或資產來衡量任何人的高低優劣，而是以人們頭腦的運作方式加以區別，方便作主題的探討。所謂窮人指的是擁有「窮人思維」（貧窮腦）的人，有錢人指的是擁有「有錢人思維」（財富腦）的人，只要有心，人人都可以打造自己的財富腦。

接下來談及「有錢人」、「窮人」的相關論述，我們就不多作名詞解釋了，請朋友們毋須爭論「窮人這個詞太污辱人」這種概念性的問題囉！其實，為了與大局或重點無關的事情爭論不休，在唇槍舌戰中消耗精力，也是一種「導致人變窮的行為」。建立好默契，我們就可以把關注力都放在學習上。

當你認識到了貧窮腦與財富腦的核心區別，你就能學會怎麼思考、怎麼行動能讓你更有錢，也更清楚哪些行為會讓你沒錢，這樣你與財富就會越來越近。

一個具備有錢人思維的人，即使手上現金不多，也能越來越有錢；而一個即便是繼承了龐大家產的人，如果腦袋裡裝的是窮人思維，家產也可能越來越少，甚至總有一日坐吃山空。

有錢人與窮人的第一條區別，在於他們賺錢的方式不同，也就是創造收入的方式不同：「窮人掙命掙錢，掙主動收入，有錢人懂得賺錢，賺被動收入。」

貧窮腦成天忙著「掙錢」，而財富腦則成天規劃著怎麼「賺錢」，這兩者的區別究竟何在？在古人的造字中有答案。

古人的造字學很有趣，掙這個字有一個「手」的部首，代表用你的手去掙錢，掙到的就是所謂的血汗錢。窮人思維堅信用手掙錢是美德，揮汗如雨換來的米飯才特別香。有錢人思維則是喜歡研究怎麼賺錢，用各種方式放大錢的價值。
