# 是什麼阻礙了你變有錢？

說明：測驗過程中，請放空頭腦，不帶任何評判地回答。不需要假設「這樣回答好不好、對不對」，只是根據當下真實的感受和想法回答，這樣才會有最好的測驗效果。

請為下列描述評分（0 是完全不同意、5 是態度中立、10 是完全同意）：

+   1. 我無法獲得大量金錢，因為我不夠好，能力不夠強
2. 我無法讓金錢滾滾而來，因為我不是個唯利是圖的人
3. 我能獲得一定數額的金錢，但更大的財富需要靠攀附關係
4. 君子愛財，取之有道，有些錢我不想賺
5. 如果需要拍馬屁、做蘇狗，我還寧願賺辛苦一點的錢
6. 我無法很輕鬆就賺到很多錢
7. 錢很難掙
8. 如果我比身旁的人都有錢，我可能會變得更孤單
9. 金錢是邪惡的，所以我不想要它
10. 我應該把別人的需要放在自己的需要之前，否則很自私
11. 我應該避免賺取太多的金錢，因為這會帶來矛盾與痛苦
12. 不一定只有金錢才能創造美好的生活
13. 要賺更多錢，可能必須犧牲我的自由、甚至是關係和健康
14. 我不擅長理財
15. 如果我賺了很多錢，可能會被物欲所控制、從而失去一切
16. 依照我的現有條件，很難成功
17. 錢買不到幸福，所以不需要太看重金錢
18. 如果要賺很多錢，過程中可能會得罪人，甚至荼負一些人
19. 再多錢也無法買到內心真正的平安
20. 追求利益會導致關係失調、家庭失和
