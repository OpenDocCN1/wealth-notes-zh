# 感謝是迅速調頻的方法

再講一個故事，非洲有一個部落長期乾旱，大家都束手無策，不知道怎麼辦。最後他們請出了一位巫師，巫師是能夠與天地溝通的人，從古文造字中就可以看出「巫」這個字源自於能連結天地的人。

於是這個巫師開始祈福，但是他並不是讓自己處在匱乏或焦慮的頻率說「拜託下雨吧！再不下雨我們部落的人都要渴死了、作物都要幹死了」，他沒有用匱乏的狀態去祈求，以能量層級來說匱乏、焦慮的能量頂多只有100。

相反的，他調動自己的狀態，進入到感恩的頻率裡面，在接近500的愛和幸福感當中，他說：「上蒼啊，感謝你用乾旱來告訴我水源的可貴。感謝你讓農作物龜裂、無法收成，讓我明白糧食的可貴。感謝你用沒有水的日子，讓我明白有水的日子是多麼美好。」

他不斷地表達著喜悅和感謝，他沒有抱怨村子缺水，而是在讚揚水的美好。當這位巫師完成祈福之後，居然真的天降甘霖了。

這讓我們學習到，當我們有願望想達成的時候，感恩是一個能快速拔高頻率的辦法。先感恩你所擁有的，你就會擁有更多。事實上，學歷、權力、財富、地位等世俗成就，都會受到人的意識層級所影響。也就是說能量層級越高，越容易去拔高自己的財富和成就維度。
