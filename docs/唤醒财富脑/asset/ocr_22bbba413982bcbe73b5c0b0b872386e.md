# 金錢的生命在於流動不息

![](bbox=[0.315, 0.138, 0.665, 0.271])

- 金錢能量的流動：給予和接受 -

金錢本身是能量，而能量的通道有兩端：有來、有往，有給予、也有接受，就像陰陽互補，陰陽一起形成太極的整體，沒有哪一邊更為重要。

如果有人一味付出，不懂得接受，他的金錢能量是不流動的。同樣的，如果有人一味索取，卻沒有給予，能量也是不流動的。

錢從哪裡來？從別人的口袋裡來，別人願不願意把錢交到你口袋，要看你有沒有吸引他的價值。即便他願意給你錢，但是你的口袋是封起來 的，錢依然流不進來。

限制性思維，包含種種阻礙財富的感受，都會讓我們的口袋封起來。

甚至可以說，當你拒絕金錢的時候，就是拒絕這個世界要給你的愛。

這一點很有趣，有些人在拒絕金錢時，有很多的心理說法，例如「無功不受祿（清高感）」，「天下沒有白吃的午餐（不配感）」，讓我們時刻提防，害怕自己會不會「拿太多了」「倒欠別人了」？

如果感覺到自己拿得多了，心裡會特別不舒服，總想著要趕緊還給別人，讓天秤恢復平衡，這種過度強烈的「公平感」，同時具備清高感和不配感的性質：我不屑於多拿，也害怕拿多。

「公平感」特別強烈的人，可能從小並沒有得到父母、特別是母親很豐沛且無條件的愛，或者物質上被教育出匱乏感。
