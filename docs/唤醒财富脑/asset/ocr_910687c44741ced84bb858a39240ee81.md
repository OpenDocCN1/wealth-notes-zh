新東方創始人俞敏洪曾做過一個比喻：「不要把自己變成『存錢罐』，因為沒有人能夠僅靠存錢變富；但一定要把自己變成『印鈔機』，需要錢的時候可以隨時靠能力去取。」

怎麼成為印鈔機？就是不斷學習和提升自己，將專注力發揮到極大值。

# 寫作練習：掌握專注力

回想你平常一天的時間中，有哪些 15 分鐘是浪費在毫無意義的事務上？並且決定在接下來 21 天裡，每天將這本來浪費掉的時間，投入在一件有意義且可以增值的事務所上。

| 浪費掉的時間 | 可以增值的事務所 |
|--- |--- |
| 活動 | 消耗時間 | 活動 |
| 漫無目的地刷新聞 | 30 分鐘 | 閱讀理財書籍 |
| 打網路遊戲 | 45 分鐘 | 學習英文單詞 |
|  |  |  |

每當你要做一個選擇時，問問自己：「接下來這個行動會讓我更靠近金錢，還是遠離金錢？」

日積月累，當你掌握了無形的時間和專注力資本，你必定會朝財富越走越近。
