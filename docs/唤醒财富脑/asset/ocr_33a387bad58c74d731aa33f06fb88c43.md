# 影響財富的三大人生選擇

要建立真正的財富自由，有三大選擇至關重要：伴侶、圈子、教練，因為這些人的平均水平，就是你在財富、思想、能量等各方面的維度水平。

美國知名企業家吉姆羅恩（Jim Rohn）提出五人平均值（Average of Five）理論，強調人必須時常審視自己的人際關係。

你花最多時間相處的五個人的各種平均素質就形成當下的你，這五個人可能是你的伴侶、朋友、同事或精神導師，他們的思想、價值觀和人生態度會對你產生重大影響。

如果這三個選擇做對了，你的眼界和格局會因此得到開拓，你也更有動力追逐夢想中的自己，你創造財富的機率也會大大提升。

如果這三個選擇做錯了，你就算擁有財富，也可能隨時會失去，正如同一句話所說：「憑運氣掙來的，遲早會憑實力敗掉」。

# 伴侶：機會的共創者

人生第一重要的選擇是你的伴侶。

五人平均值理論說你是最常交往的五個人的平均值，你們擁有差不多的背景、談論差不多的話題、也擁有差不多的見識，因此你們的財務狀況也不會相去太遠。這五個人中，伴侶是我們花最多時間在一起的人，也是互相影響最多的人。

如果有一位知識淵博的伴侶，你會被帶動不斷成長，更可能把握時機創造財富，但如果你的伴侶保守封閉，那即使你有什麼好點子或好項目，他可能也不會支持你去實現它。

金錢是能量，具備高能量狀態的人，更能夠吸引金錢來到他的生命中。而你最常交往的人，是帶給你正能量多，還是負能量多呢？如同第六章談到能量層級決定了我們一生的財富層級，而你的能量狀態也是你最常接觸的五個人的平均水準。古話所說的近朱者赤、近墨者黑，更應該說是近富者富，近窮者窮。
