# 推薦語

那些年，我們聽著她的聲音學習成長！那是一段不甚美好的時光，我因為投資失利而踏上學習之路，海外課程所費不貲，還要加上食宿機票，但我硬著頭皮去上課，因為我知道那是我翻身的機會……感謝耳機裡專業傳達外籍講師教學的芳誼，讓我完成學習，並能學以致用。她把多年來的經驗毫無保留地在《喚醒財富腦》中分享給大家，精闢地點出「你的外在世界就是你內在世界的投射」，想改變外在就得從內在開始動工。《喚醒財富腦》無疑是一本值得收藏的好書，不同的時間點看，會有不同的收穫！它不只是一本讀物，更是一本工具書，讓我們在遇到困難的時候，透過書裡章節找出自己當下的盲點，相信它可以喚醒你的財富腦，陪你邁向成功！

Max
臉書千萬廣告操盤手

認識芳誼是在一堂國際名師的成長課程上，當時我是學生，而她擔任中英口譯，對她的認真投入和聰慧慧捷留下了深刻的印象。後來幾次接觸，得知芳誼從事口譯工作經驗早已非常豐富，曾為許多鼎鼎有名世界級的課程翻譯，那時我就心生羨慕地想：哇！這個女生多年都待在這些超級大師身邊，不是都學到精髓中的精髓了嗎？果然，後來她開始自己授課，現在又匯集各派大師們的智慧出了她的第一本書，等於幫我們整理好重點了呀！邁向自由的人生，一起喚醒財富腦！
