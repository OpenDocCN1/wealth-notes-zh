# 本章小结

調整收入方式，才是變富的開始

+   1、窮人與有錢人的第一個區別在於收入方式不同：窮人掙主動收入，有錢人賺被動收入。\n2、出賣時間的方式決定你長期在變窮還是變富：\n a、同一時間段只能賣一次：低價值、較缺乏長期成長性。\n b、批量出售：依然只能出售一次，但是創造的價值更高，同時也更有成長性。\n c、同一段時間反復出售：花時間製作出可以反覆銷售的產品，如此創造出來的就叫被動收入或是睡後收入。

# 理解財富的六個層次

+   1、NLP 思維六層次由下而上是：環境、行為、能力、價值觀、身份、精神，越高層次的影響力越強。\n2、真正重要的生命議題，如親密關係、家庭與財富，都需要從上至下改變思維層次。

# 財富四象限

+   E 象限：僱員，擁有固定工作、固定薪水。\nS 象限：專業人士，技能具有不可替代性，一般收入比僱員更高。\nB 象限：企業家，運用團隊為自己賺錢。\nI 象限：投資者，運用錢為自己賺錢。

# 金錢自由公式

+   1、財富自由的公式：被動收入大於支出\n2、一方面要建立被動收入，另一方面我們要評估自己的理想生活需要多少支出。\n3、三種不同心理狀態形成的消費層級：需要、想要、別人想要。\n4、每個月都有現金流，會讓你的財務和心態保持相對穩定，你的金錢體質就是比較健康的狀態。
