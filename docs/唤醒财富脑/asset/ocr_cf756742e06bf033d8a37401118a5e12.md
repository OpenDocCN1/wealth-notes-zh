# 有錢等於擁有財富嗎？

這本書叫做《喚醒財富腦》，為何不叫做《喚醒金錢腦》呢？很顯然，財富與金錢並不是完全相等的，可以說金錢是財富的一種形式，而財富是一個更加宏觀且抽象的概念，需要深度思考才能更加理解。

那金錢呢？看似無所不在、甚至無所不能的金錢，我們真的理解它嗎？

記得與朋友一起去印度泰姬瑪哈陵時，還來不及品咂蒙兀兒帝國第五代皇帝沙賈汗對亡妻「綿綿無絕期的」思念，身旁就圍上了一群小朋友，伸著手不斷說著「Hello？Hello？Money？Pen？Money？Chocolate？（哈囉？哈囉？錢？筆？錢？巧克力？）」為了要在惡劣的條件下生存，許多印度小朋友沒上學就會的英文單詞裡，肯定有money（錢）。

錢究竟是什麼呢？許多人成天嘴上說要賺錢，但若對於金錢的理解僅侷限於現金時，其實會為自己未來的財務狀況埋下很大的風險。
