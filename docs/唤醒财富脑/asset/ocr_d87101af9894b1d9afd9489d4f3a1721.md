# 冰山下的財富阻礙

上一章我們介紹了財富阻礙表，是我從工作經驗與大師系統中總結出來的，阻礙人們無法獲得渴望的財富的內在絆腳石，透過表格我們做個簡單的複習。

| 財富阻礙 | 主幹感受 | 衍生情緒 | 核心思維方式 |
|---|---|---|---|
| 上位感受 | 清高感 | 傲慢、不屑、優越 | 認為金錢是俗物，自己的精神價值比金錢更高尚。 |
|  | 虛榮感 | 吹牛、好面子、支配 | 認為金錢能夠彰顯出自己的價值，支配金錢就能支配一切。 |
|  | 逃避感 | 不想管、怕麻煩 | 認為管理金錢太繁瑣，船到橋頭自然直。 |
| 下位感受 | 不配感 | 覺得自己不夠好、能力不足、不值得獲得 | 認為更多金錢屬於更好、更優秀、更幸運、更…的人，自己不配得或享受金錢。 |
|  | 辛苦感 | 焦慮、憤怒、不公平、犧牲 | 認為賺錢是很辛苦的事，怎麼努力都像老鼠跑轉輪，看不到頭。 |
|  | 匱乏感 | 恐懼、短視近利、小氣 | 認為缺錢是世界上最可怕的事，需要即時反饋，難以承受長期無現金流。可能成為市場韭菜族。 |
