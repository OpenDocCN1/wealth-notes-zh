# -學習金字塔-

學習效果由低到高，第一層是「聆聽」，就像現在大家喜歡在閒暇時聽音頻，但是這種聽多少算多少且比較單一的方式，只能讓我們學習到 5% 的內容。

第二層是「閱讀」，買了一本書之後，好好花時間讀完它，那麼你可以吸收到內容的 20%。書本總結了作者多年的知識與經驗精華，就算只是簡單粗略地閱讀和部分吸收，也是非常划算的。比較擔心的是「封面族」，就是買書回家、翻了封面就覺得心安了，接著就把書放進書櫃養老，這樣肯定就沒什麼作用。

第三層是「討論」，這樣可以把吸收效果提高到 50%。這也是為什麼現場課程有著特別強的魅力和吸引力，人們可以面對面交流，在討論的過程中激蕩不同的觀點，彼此的學習效果都提升了。疫情後許多課程轉為線上，只要技術上能支持討論，成效還是錯誤的。像我參與的一些心理研究與共修項目，成員來自世界各地，互動全都運用線上平台，平台也針對討論需求設計了「討論小房間」、「共享螢幕」等多元的功能。

第四層是「體驗」，能把學習效果一下子拉升到 75%，這也是為什麼我線上及線下的財商課中都設計了各種的互動活動。大家不僅僅是聽課，還能身體力行地去感受到金錢能量的流動，在體驗金錢流動的過程中，自己的認知、行為和模式都會清清楚楚地呈現出來，比起紙上談兵，實際操練帶來的收穫絕對是更加刻骨銘心的。知道春天兩個字怎麼寫，跟實際在四月走入花園聞香，哪一個印象深刻？讀一本愛情小說，跟真正談一場戀愛，感覺能一樣嗎？
