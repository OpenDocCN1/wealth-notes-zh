# 快速提升的三大法門：如何覺察最有效率？

我們可以肯定的 btw：「意識創造人生，負面能量加負面思維帶來負面人生，正面思維加上正面能量帶來正面人生。」

正面能量來自於你不再把攻擊的劍靶指向外在說，「你們怎麼這樣，你們怎麼這樣對我，都是你們害的」等等。因為我們責怪外在環境的時候，就失去了主動權，我們成為了受害者、控訴者，並且對這一切無能為力。

當你真的醒悟到，外在所經歷的所有人、事、物，都是你的內在世界創造出來的，那一刻起你就自由了。你不再是被動抱怨，而能夠主動創造。

你的財務狀況、情感狀況、健康狀況，都是從你的內在開始創造的，不管你喜不喜歡當下的狀態，當你明白自己不再是環境的受害者，哪怕你外在發生很多糟糕的事情，你把一切責任拿回自己身上，你就拿回主導權了。

我承擔起現況的所有責任，不管情況多糟糕，我願意接受這是我過去的所思、所想、所創造出來的，既然我有能力把環境變糟，我就有能力把環境變好。

當我們想覺察自己的時候，我們可以用以下三個方面去照見內在的狀態。

# 身體是忠實的傳信使

第一種是觀察自己身體的狀態，這是一種迅速呈現我們身心狀態的方式。

我們身體出現的所有舒服的、不舒服的感受，事實上都是身體給我們的信息。因為身體是誠實的，如果你的能量淤堵、情緒卡堵，身體一定就會有一部分是僵硬的、凍結的、無法打開的，甚至可能在相應區域造成組織堆積、甚至骨刺。
