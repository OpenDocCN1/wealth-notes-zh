# 尋找長期價值的所在

前面我們學到了有錢人與窮人的五大關鍵區別，從收入、支出、思維、狀態、面對未來的方式這五個角度切入，幫助我們更好地創造財富。當我們成功建立財富之後，又該怎麼做才能讓財富綿延不絕呢？

我們在第三章談到了「有錢人如何賺錢」，並且說到有錢人賺錢、窮人掙錢，根本區別在於是否有長期價值思維和放大價值的工具。本章我們以此為基礎繼續延伸探討。

唯有真正擺脫掙錢的短期價值思維，我們才能將獲得的金錢，進一步化為源源不絕的財富。大部分人之所以都還停留在「掙錢」裡，就代表它還是有好處的，不然人們為什麼還要掙錢，而不都改成賺錢呢？

因為掙錢可以讓你的付出立即得到回饋，心理學的概念叫做立即滿足（immediate gratification），就像按一個按鈕就有獎品掉出來一樣令人開心。

所有生物底層的動物性（animal spirit）都需要立即滿足，有養小狗的人就知道，小狗做錯或做對事情時，你都要立即進行獎懲教育，他才會建立相關的神經迴路。例如，如果小狗在地毯上撒了一泡尿，你大半天才把他叫過來一頓教訓：「你怎麼會這樣！不准在這裡尿尿！尿了就該打喔！」小狗肯定不知道你在幹嘛，還會覺得你很奇怪，因為他們需要當下的立即反饋。

多年的制式教育某種程度也助長了短期回饋思維，孩子習慣以成績作為唯一的考核標準，形成了做對一件事就想要有獎勵的本能習慣，就像考了好成績，回家馬上會被稱讚。離開學校後卻發現，想在社會上有所成就，可是比答好一張考卷要困難多了。

但是短期思維習慣已經養成了，追求短期價值和立即滿足，變成了許多人無意識的選擇，例如選擇送外賣，只要這一單送完了，就可以立即看到這一單的入帳。
