# 推薦序 1 誰能活出財富的真正價值?

我滿心喜悅地支持芳誼（Rosie）並推薦她的最新力作《喚醒財富腦》。有些人說金錢或財富是萬惡的淵藪，我相信的是，若你認為財富具有內在價值（intrinsic value），而非具備功能價值（functional value）的話，那可能真的是如此……事實上，財富可以實現許多功能，讓我們為社會作出更大的貢獻，但它並不像德行（integrity）或愛一樣具有內在價值。財富只是給予我們機會去實踐和表達出愛、德行這些更深層的價值，因此財富具備的僅僅是功能價值。

人們與財富的關係時有糾結，就像面對時間一樣……可會有足夠的一天？當我們檢視自己與財富相關的經驗時，我們可以去檢視其中的什麼（what）、如何（how）、為什麼（why）、誰（who）以及還有誰（who else）。我的意思是，你想獲取什麼樣的財富？你試圖用什麼策略獲得它？你對財富抱有什麼樣的信念與價值？你是如何作為一個富有的人？其他人是否能從你的財富中獲益？

如果只有我和我的家人獲益，那就形成了一個以小我驅動的金錢世界，我會活在有天失去財富的恐懼中。但如果我將財富以有意義的方式與我的社群分享，那我就是在平衡小我與靈性……我跟財富的關係也會更加平衡，看見更多的機會，而不是限制。

這一本書是當今時代所需，而我也感謝芳誼願意探討如此重要的議題。願妳持續行走在美善之中，與世界分享妳的豐美精神，芳誼。
