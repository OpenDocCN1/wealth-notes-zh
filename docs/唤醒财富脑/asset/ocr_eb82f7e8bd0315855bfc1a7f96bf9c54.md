# 為什麼有些人充滿焦慮、恐懼, 但是也賺錢?

可能有人會問說, 我看有些人賺到了很多錢, 但是他的狀態也不是很好, 也是在一種低頻的、恐懼的、憤怒的或者證明的狀態, 雖然他外在條件是挺有錢的, 但我也不覺得他的頻率特別高, 這又是如何解釋呢?

你也有過這種觀察嗎? 有時候我們會聽到「暴發戶」這種說法, 就是發現一個人的內在素養並不符合他所獲得的巨額財富。既然說高頻吸引豐盛富足, 低頻吸引匱乏恐懼, 為什麼感覺相對低頻的人, 卻還是能夠吸引到金錢呢?

有一種解釋是因為金錢是中性的能量, 只要能量大你就能夠得到它, 不管這個大能量是高頻、喜悅、富足的, 還是恐懼、害怕或者想要證明自己很厲害的, 這些也是很大的能量, 同時可能當事人對於獲取金錢的目的感非常強烈, 驅除了其他一切動機, 這樣也是能夠吸引到金錢的。

金錢是中性的能量, 它不是判斷道德的法官, 當有人慾望夠強時, 也能夠吸引到它, 但是取之無道的金錢也會攜帶負面的能量糾纏, 後續產生的負面效應可能會在其他部分體現出代價。

# 金錢是能量放大器

金錢只是能量的放大器, 它並不會改變一個人的本質。一個善良的人有了錢, 會成為一個有錢的好人, 而一個混蛋有了錢, 就成了一個有錢的混蛋。許多人往往更願意相信, 有了錢就能改變一切、改變命運、甚至改變自己的性格。但事實上, 所有我們渴望的一切(健康的身體、和諧的關係、豐富而有意義的生活)都必須先努力去創造和擁有, 錢才會被吸引而來。

當你用愛作為出發點去做事業和賺取金錢, 金錢的流入同時也會放大你的愛; 而當你出於恐懼、自我證明、比較和憤怒等負向狀態去掙錢時, 只要你的能量夠強、目標夠堅定, 錢也會被吸引而來, 但是同時你的恐懼、憤怒、比較和證明等一切負向狀態也會跟著被放大。
