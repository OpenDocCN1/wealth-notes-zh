# 推薦語

跟芳誼身為戰友多年，長久與世界頂尖人士共事下，她不僅將所學實踐在自己的人生道路上獲得成功，更在這本書裡傾囊相授，毫無保留。從書中言語文字我看得出她對讀者一也就是「你」的在乎，迫不及待想把最好的給你，這是她對這個世界愛的展現。現在是有史以來人們最需要學習成長的時代，芳誼結合了個案的輔導經驗，協助你打造真正的「財富腦」。這與我個人帶領的「喚醒你的財務天才」與「有錢人想的和你不一樣」等世界頂尖訓練有異曲同工之妙。而芳誼透過文字帶領讀者踏上一場酣暢淋漓的內外在財富之旅，我很驕傲與榮幸可以跟你分享這本好書—《喚醒財富腦》。

Jackie 周啟達
傑期國際教育學院創辦人
富爸爸財務課程華語培訓師

認識芳誼，是在 2015 年澳洲的黃金海岸，安東尼羅賓的「與命運有約」課程現場。那時我因為投資失敗而破產負債上千萬，我不明白自己怎麼墜入了失敗的深淵，原來當時 39 歲的我，財富腦卻只有幼兒園的年紀。感謝芳誼將多年為各領域國際大師貼身口譯的經驗及實作的成果分享出來，成就了這本《喚醒財富腦》。本書不單單只是告訴你所謂的「財商知識」，更一步步地帶領讀者們朝向深層意識探索。《喚醒財富腦》無疑將為人們帶來巨大的幫助，我期盼每一個人都能在本書的引導之下，讓沈睡中的財富腦能被真正地喚醒，不只是意識上，更是身心靈全方位的覺醒，一步步走向完全平衡的幸福。

張為堯
