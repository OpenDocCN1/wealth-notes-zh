# 冰山理論：是什麼讓你被負面思想纏繞

+   1、我們關注了一件事情，就很難再關注另外一件事情——所以若關注了負面的事物，就很難同時關注正面的事物。\n2、冰山理論：許多說得出來的思維只是表像，形成這個思想的底下還有更多的記憶、成長背景和家庭模式。\n3、人無法獲得巨大財富的最大阻礙往往是：潛意識沒有真正允許自己有錢。

# 相信自己值得更多金錢

+   1、貧窮只是貧窩，放下清白感與不配得感才能迎接財富。\n2、面對金錢的恐懼感分為兩種：一種是擔心錢不夠的生存恐懼，另一種是對金錢的流入與流出都感到緊張，可能源自於祖輩的影響，心理學上也稱之為表觀遺傳學。\n3、金錢的流動就等於價值的流動，而當你不敢要的時候，其實你是害怕自己沒有辦法給到對方足夠多的價值，你對自己不夠有自信。
