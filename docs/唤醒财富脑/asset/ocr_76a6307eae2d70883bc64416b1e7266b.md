# 推薦語

芳誼本身就是她所倡導的生命整合式價值觀的榜樣：如何活得美麗、健康、有靈性且又富裕！與她合作共事多年，我感到她的喜悅與智慧油然而生。她運用獨一無二的願景與思考，串連和療癒我們內在的矛盾與分裂。Rosie，為妳喝彩！

詹姆斯·華納斯博士（James Wanless）
國際企業顧問、開拓型導師
「領航者塔羅：新時代導航地圖」系統創始人

芳誼導師的財商課終於出書了，我一邊看一邊想，這不是我一直都在做的嗎？二十歲開始出來創業，我經歷過巨大的成功，也曾經慘淡失敗，但總是有一股力量推動著我繼續向前，獲得下一個良機。常常有人想跟我學商業，我也不知道怎麼把已經成為我直覺的東西分享給他們，通過本書系統化的梳理和清晰的案例，我一路創業的心法總算能成為方法論了。這本書為個人、創業者，和任何有志與金錢打好交道的人，指了一條明路。

我從商業進入產業，開始深入到另一個層次，以生態系的角度運作團隊和項目，每天面臨系統結構中各方動能的變化、權衡與協商，漸漸進入到了純以頭腦之術無法駕馭的領域。本書中的「意識能量層級管理」，讓我能以道的視角、游刃有餘地繼續踐行我的人生圭臬：「高高山頂立，深深海底行」。

于子淇
