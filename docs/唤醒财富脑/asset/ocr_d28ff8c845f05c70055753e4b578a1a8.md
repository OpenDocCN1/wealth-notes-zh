# 章節小結

# 你的人生與財富曲線

+   1、現實中很少有直線增長，爆發前都需要積累。\n2、一邊確保安全一邊冒險，是辭職創業前的穩健做法。\n3、耐心等待生命中的拐點和里程碑的出現。

# 是什麼決定了富有或貧窮

+   1、決定一個人貧富的關鍵是思維和行為。\n2、舊有思維會讓人始終被限制在固定的財富維度中。\n3、建立財富的能力與我們的腦袋、行為模式有關。\n4、我們所想要獲得的一切，都可以通過與我們的大腦攜手合作來達成。\n5、讓「財富腦」變強大，從建立正確的學習習慣開始。\n6、需要升級心智系統的關鍵提示：當你覺得不舒服的時候。

# 如何創造高效的學習

+   1、效果最差的學習方式是「聆聽」，只能讓我們學習到 5% 的內容。\n2、第二層是「閱讀」，可以吸收到內容的 20%。\n3、第三層是「討論」，可以把吸收效果提高到 50%。\n4、第四層是「體驗」，可以把學習效果拉升到 75%，這也是線下課中一定要設計各種互動的原因。\n5、最高層級的學習方式是「分享與教學」，能將效果提升至 90%。當能夠教學的時候，代表已經從「接收者」進化到「給予者」。\n6、決定學習效果最關鍵的因素：學習者是被動的，還是主動的。
