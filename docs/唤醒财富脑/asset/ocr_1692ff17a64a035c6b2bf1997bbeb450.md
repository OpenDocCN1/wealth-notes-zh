# 後記：關於持續成長

「人的靈魂像是橡樹種子，種子是很小的，但裡面蘊含了蒼天大樹的生命藍圖。」以上這句話出自榮格學派心理學者詹姆斯希爾曼的《靈魂密碼》一書，我也是抱持著這樣的信念，在創作課程和帶領有緣相遇的人們，過程中收穫了滿滿的感動。

「我決起而飛，搗 Сен，時則不至而控於地而已矣，奚以之九萬里而南為？」莊子《逍遙遊》裡，�ensions 與學鴻嘲笑著大鵬鳥飛至九萬里外的<|start|>高空，卻得忍受飢寒孤獨。意思是，我們輕輕一振翅，很快就能飛上枝頭品嚐甜美的果實，而且若是不小心掉下來，也不過就是在泥土上翻個滾罷了，無傷痛癢。而你，選擇飛去南冥一個未知之地，要面對諸多未知、險阻與不測，究竟圖什麼呢？

圖什麼呢？人生在世圖什麼？圖愛情、圖財富、圖功名、圖地位、圖享受、圖內心的滿足和存在的意義感。然而最終面對無常時，一切已圖得和未圖得，都不能保證我們的心是否能安然。我們依舊得在每一天、每一刻，為自己內在的鯤鵬與蝴鴿做出選擇。

我們來到地球修煉賺錢、戀愛、創業，種種給予自己的挑戰，不都是為了演化與成長，藉以修得成熟與智慧嗎？演化的過程是充滿血淚與疼痛的，第一隻被拋上地面、被迫在陸地上學會呼吸的魚，並不知道陸地能夠給牠什麼，卻需要先放棄整片海洋。

人的認知偏差是如此強烈，對於不符合自己先入為主的、習以為常的感官訊息，很容易就不屑一顧或嗤之以鼻，這也是為什麼，引領時代的總是一小群人。

你有這份緣份打開這本書，而且又看到了最後一頁，可想見的是你絕對非等閒之輩，而是對於自己的生命、事業、情感都有著更大願景的領袖人物。

既然你心有鴻鵠之志，希望你就務必要把握資源和機會，運用有生之年去活出最偉大版本的自己。
