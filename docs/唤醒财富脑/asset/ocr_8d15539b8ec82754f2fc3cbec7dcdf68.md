# 老闆思維就是組織思維

組織或團隊的四層金字塔結構，每個層級的人負責的板塊不同：
基層：負責銷售，出去衝鋒陷陣。
中層：負責管理，建立公司的人事系統。
高層：學習領導，時時傳遞公司的戰略方向，確保不會有所偏移。
頂層：老闆，要學的是影響力，學習如何將願景一層層地落實到公司每一個人的心裡和行動之中。

# 影響財富的三大人生選擇

人生三大選擇對財富影響至關重要：
伴侶：願意不斷成長的伴侶，一起把握時機、創造財富。
夥伴和圈子：尋找彼此支持不斷帶來正面影響的啦啦隊，遠離潑冷水的滅火隊。
人生教練：不斷為自己提醒目標、加油打氣以及提供建議，他們是讓你對自己的承諾說到做到的人。

# 快速成長的良方：如何向上結交？

1、環境：人是環境的產物，除了跟同儕交流外，也要經常尋求機會「向上結交」。
2、發揮圈層效應的三種方法：
混圈層：用混的方式去打進高於你的圈層，可能迅速有效但並不穩固。
搭圈層：透過你的專業、技術、能力搭建橋樑，不會輕易被取代。
建圈層：當擁有一定的資源時，透過無形的價值觀建立屬於自己的圈層。
