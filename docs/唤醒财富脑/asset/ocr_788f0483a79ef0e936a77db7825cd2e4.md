# 能量與物質本為一體

本來存在於頭腦中的想法、信念與意識，能夠顯化為實際存在的金錢，原理在於：無形世界與有形世界並不是一分為二的，兩者本質上是相通的。

科學家已經發現，在最微觀的層次裡面，萬物都可以細切為原子、質子、中子、電子，甚至到更小的量子、夸克與超弦。想像用顯微鏡一層層無限向下探的時候，其實一切都是由快速旋轉的粒子所組成的。如佛陀在菩提樹下打坐七七四十九天悟道時所說：萬物本一體。

課堂中所使用的話筒、講台、螢幕，還有你舉目所見的樹木、花朵、馬路，乃至於家裡的桌子、椅子、電腦和身旁的人，看似毫不相干的萬物，底層其實都是相通相連的。

借用狹義相對論的知名公式 E = mc²，意思是物體的質量乘以光速平方就等於它的能量，等式兩邊相通，所以能量與物質本質相通。

例如水可以變化為冰塊、水蒸氣等不同的形態，但本質的化學組成都是 H₂O，只要找到變化的關鍵就可以自由轉換狀態。

因此，一個人的思想、意識與他所體驗到的物質世界，本質上也是相通的，於是他的意識境界，將會以某種方式形成他的財富狀態，只是具體轉換的公式可能需要另一個愛因斯坦來發現了。

本章便試圖整合目前心理、身心靈、神經語言程序學等領域對於「意識如何顯化為金錢」的一些理解，首先這需要我們從根本上正視自己思想的力量。

「世上的 一切皆與其他萬物相連。我們的力量被喚醒之前，處於冬眠狀態。要喚醒如此非凡的力量，對自己在世界中角色的看法必須加以改變。」這是從科學探討心靈領域的卓越經典《無量之網》一書中的描述。
