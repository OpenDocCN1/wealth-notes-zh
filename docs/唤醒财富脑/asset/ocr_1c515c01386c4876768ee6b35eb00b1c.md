# 推薦語

我曾問學生為何想念金融系，學生回答：因為想賺很多錢！我笑了笑說：「不只你想，我也很想！」本書從身、心、靈這三個視角，全方位地喚醒我們的財富腦，也有許多鮮明的實證案例。我相信作者對於財務金融的思想貢獻是具有承先啟後、繼往開來的啟發性的。

2012 年左右我就和作者成為朋友，一路上見證了她的成長與蛻變，從專業翻譯到心靈成長導師，從羞澀女孩到性感女人。她多變的風貌與多元的才識，著實為她的著作做了最好的詮釋。對於她一路上成長，我除了敬佩、欣賞與驚艷，更希望從她身上學到成功蛻變的秘訣。我在大學教授財務金融的知識，講的大多是別人的事蹟，而作者講的卻是她親身經歷的致富故事。讀完芳誼的書後，下次我會跟學生說：想致富，你要跟芳誼學習如何「喚醒你的財富腦」！

陳倩儀博士
青島大學經濟學院金融系特聘教授

當財富的定義變得僅侷限於金錢時，我們最終會將心靈抵押來換取銀行帳戶裡的數字增長。這本書可以幫助你釐清、喚醒和活出你生命中更深的價值觀。金錢可以成為工具，將你的光和愛傳播給這個世界。

尼克·萊佛士博士（Nick LeForce）
