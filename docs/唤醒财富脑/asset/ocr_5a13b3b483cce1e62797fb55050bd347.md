# 最新潮的賺錢關鍵詞

當我們說，你所能想像的一切都已存在，只是還沒有顯化出來，這是什麼意思呢？為什麼許多國外的導師喜歡說我們要學習如何「顯化（manifest）」金錢？怎麼理解這個詞要表達的意思呢？

我的大學專業是外國語文學，因為我從小就喜愛文字與語言，也經常參與文學比賽。我們試著從中英文的字源來理解一下，被眾多心靈成長導師所愛用的「顯化」一詞，為何與金錢建立了聯繫，甚至於取代了掙錢、賺錢這些傳統說法？

英文詞彙「Manifest」的溯源可以追溯到14世紀時，代表「宣揚（個人名聲）」或「直接展現」，從拉丁詞「manifestare」衍伸出「發現、揭露」的意思，1560年後則表示「以行動揭示」。從英文中，看到它包含了由隱晦至顯明的行動意義。

中文字「顯」，在金文中由（絲，聯、系）+（頁，頭部）兩個部分組成。造字的本義是：用絲線將珠玉、寶石等發光飾品掛在頭部，藉以展現自我。

中文字「化」，始見於商代甲骨文，古字形由一個頭朝上的人和一個頭朝下的人組成，本義為變化，引申指自然界從無到有創造和化育的過程。

從中文二字中，我們看到「顯化」一詞加在一起，代表從無到有，且彰顯了頭部的力量。

從不嚴謹的語言運用角度，我們可以延伸理解為，「顯化」表示以頭部（思維、意識）從無到有地創造，「顯化金錢」則可延伸理解為「以思維及意識，從無到有地創造金錢」。
