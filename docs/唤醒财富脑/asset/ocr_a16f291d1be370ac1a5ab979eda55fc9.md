# 跟著《大宅門》學資產配置

如何循序漸進地，將五大資產都納入到投資計畫中呢？

我們可以借用三百年中藥老店同仁堂的例子，據說《大宅門》就是以他們的故事為歷史原型拍攝的。

同仁堂創立於1669年，他們早期開中藥鋪的時候，領導者就說我們不租商鋪，我們在哪開店就一定要擁有那間店的門面，所以他們首先就建立了第一種資產：房產。

接著他們發行股票，建立有價證券資產（這裡比一般投資人高超了，一般人是持有，他們是發行）。同時他們還有很多的藥方，屬於專利權的資產。

然後他們把很多珍稀藥材，妥善保存在保險櫃裡面，這就屬於可以保值、升值的物品。百年基業就是這麼一步步積累出來的。

看到這裡，你是感覺到興奮，「哇，我可以有這麼多種方式建立資產」，還是感到沮喪，「唉，我只擁有其中的一、兩種」呢？

我們說「你與金錢的關係，反映了你與世界的關係」，把這一 路學習時產生的感受，都當作一個比知識乾貨更有價值的回饋，這樣你會更清楚自己面對金錢和財富的卡點在哪裡。

我們的這一 生像是電影，有些人出生就有主角光環，拿到了特別好的劇本，但結果自己恃寵而驕、亂演一通，最後混亂收場；而有些人可能一開始的角色不怎麼樣，但是卻珍惜自己拿到的每一句台詞和上場機會，結果戲份越來越多，觀眾緣越來越好，最後成就了精彩磅礡的佳作。
