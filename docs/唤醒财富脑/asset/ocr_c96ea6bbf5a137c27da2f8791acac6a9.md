# 保持高頻能量是關鍵

通過這個能量層級表，我們能夠隨時隨地提醒自己、照見自己：「啊，我現在感到很憤怒，我的能量只有 150 了；啊，我現在覺得悲傷無助，能量只有 75 了」。

一旦發現能量往下走時，迅速採取行動調整，才不會越陷越深。如果你發現自己有憤怒、悲傷、抱怨、憎恨、內疚等情緒，就要提醒自己，「我已經在 200 以下了」，然後趕緊修正，因為低頻狀態只會帶來低頻的結果。

你可以通過運動、閱讀、上課、找教練疏導，讓自己盡快回到 200 的層級。200 是一個有勇氣的狀態，無論面對什麼難題，只要有勇氣，我都可以一步步地面對它、處理它，接著人就會建立最基本的自信。

人的一生中，只要能讓自己的平均能量層級穩定地維持在 200 以上，他就具備了創造豐盛人生的優良基礎。
