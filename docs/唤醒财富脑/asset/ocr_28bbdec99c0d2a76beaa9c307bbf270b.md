# 是什麼阻礙了你變有錢？

面對財富，除去某些出生在富豪之家或官宦之門的天之驕子不談，每個肢體健全、擁有標準智商的人都在相對公平的起跑線上，必須運用差不多的條件為自己的人生創造更多的成就和財富。但為何有些人看似更加輕鬆地就成功了？而有些人忙碌不已卻苦無成果，總是事倍功半？

你是否覺得自己當下的財富成就 Bolsonaro 你的天賦才華？你是否覺得自己肯定還有沒發揮出來的潛能，只是不知道那些潛能在哪，該如何開發？

我們先來做一個關於財富的小測驗，它就像是一個小偵探，可以幫助你以簡單便利的方式，找出目前你的財富潛能在裡受到阻礙，你只需要輕鬆地根據直覺回答就可以了。

# 財富阻礙指數測驗

說明：測驗過程中，請放空頭腦，不帶任何評判地回答。不需要假設「這樣回答好不好、對不對」，只是根據當下真實的感受和想法回答，這樣才會有最好的測驗效果。

請為下列描述評分（0 是完全不同意、5 是態度中立、10 是完全同意）：

+   1. 我無法獲得大量金錢，因為我不夠好，能力不夠強
2. 我無法讓金錢滾滾而來，因為我不是個唯利是圖的人
3. 我能獲得一定數額的金錢，但更多財富需要靠攀附關係
4. 君子愛財，取之有道，有些錢我不想賺
5. 如果需要拍馬屁、做獵狗，我還寧願賺辛苦一點的錢
6. 我無法很輕鬆就賺到很多錢
7. 錢很難掙
8. 如果我比身旁的人都有錢，我可能會變得更孤單
9. 金錢是邪惡的，所以我不想要它
10. 我應該把別人的需要放在自己的需要之前，否則很自私的
