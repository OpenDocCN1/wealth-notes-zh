
但是通過建立學歷與專業，就能找到產能價值更高的工作。

例如我曾經大量與國際導師們合作，為他們面對華語學員的授課進行翻譯，雖然翻譯工作也是根據時間買斷的，但是單位價值高，日收入可達數萬，工作內容也具備成長性。

不過翻譯費用可以根據經驗、專業、名聲的積累而提升，翻譯師的能力、見識與控場能力也都在同步成長。這樣雖然時間只能販售一次，卻創造了當下更高的金錢價值和未來的長期價值。

第二種販賣時間的方式是：批量出售。

這是將時間大面積打包出售，不像接案子這一單做完，不知道多久才會有下一單。大部分人為了節省案件之間的時間空檔，就會應聘一個工作崗位，把早上九點到晚上六點這段時間打包出售。

批量出售時間的方式，更能透過中長期的專案、項目來展現自己的綜合能力，因此創造出來的價值更高。如果多年在同一個崗位專注打磨，獲得重用、升職，個人的能力和收入都會一併成長。

就像我很欽佩的一位阿姨，她是日本知名藥業的亞洲區老總，特別優雅也特別會經營生活。她的工作生涯是從藥廠流水線崗位開始的，由於她把當下的每件事都做到最好，經常表現出遠超崗位的能力，於是升職、成為主管就是順理成章的事情了。

第三種販賣時間的方式是：把同一段時間反覆出售。

要怎樣才能把一段時間反覆出售呢？答案就是製作你的分身。

寫書、拍影片、出專輯、錄製線上課程這些可以反覆銷售的產品，就是製作你的分身，如此創造出來的就叫被動收入或是睡後收入，因為你睡覺的時候，這些搖錢樹、金雞母都還在不停歇地為你創造財富。

知識付費是一種很好的建立睡後收入的方式，疫情之後線上教育產業急速發展。例如我們的線上導師培訓計畫，你錄了一套音頻課程，也

許只賣個幾百元，但是它一直在網路上向人們招手，你睡覺的時候有個深夜睡不著的人去聽了覺得很喜歡，掃碼付了幾百塊，你就有睡後收入了。

現在也有很多國內外平台開放創作者與使用者之間的付費方式，我有個朋友為他家的貓咪製作表情包一下子爆紅，光靠表情包收入就可以付每個月的貓糧了！所以他每天都拿手機追著貓咪說：「胖胖，趕緊來賺你的飯錢囉！」

![](img/c2747cd0c5bf820d125459594a169642_105_0.png)

如果你有插畫或繪圖能力，你可以把數位創作掛上一些版權網站，授權全世界喜歡這張圖的人去使用它，賺取授權費用。

不管你處於哪一個行業，都可以用以上這三個維度去思考你販售時間的方式，做好當下的工作，並不斷拉高你的時間價值。

## 理解財富的六個層次

提升財商的目的，在於建立一種「創造財富的思維方式」，因為所有的成功案例都是不可複製的，唯有創造成功的思維方式是可以學習的。

⑧如西方奇幻小說《魔戒》譯者朱學恒的案例，據傳當初這部作品因為搭上電影熱潮，讓他足足賺進 3500 萬版稅。我個人翻譯有近 20 本心理成長、文學藝術、商業激勵等領域書籍，包含知見心理學代表作《會痛的不是愛》《發現內在的鑽石》《成功者的 8 個特質》《我揍走了你的乳酪》和《深夜加油站遇見蘇格拉底》續作《生命如此富有》等，部分為買斷式，部分為版稅制，最暢銷且長銷的作品，也為我創造了數十萬的被動收入。

你已經了解掙錢與賺錢的不同、主動收入和被動收入的區別以及不同販售時間的方式，你的財富腦已經具備越來越多的成功思維了，接下來如何鞏固這些思維呢？

你需要認識 NLP（神經語言程序學）思維理解層次，這是以知名人類學家格雷戈里・貝特森（Gregory Bateson）提出的意識理論為依據，再由與我合作多年的老師羅伯特・迪爾茨（Robert Dilts）所整理出來的。

![](img/c2747cd0c5bf820d125459594a169642_107_0.png)

這套理論讓我們認知到「自己是如何理解一件事情」的。當你對一件事情的理解層次不同，就會形成不同的反應和做法。當理解層次越低，我們就越會成為環境的受害者，而理解層次越高，就越容易得到解決問題的力量。

我們透過這個模型，可以清晰地看見「人是怎麼製造出自己的貧窮」。

|  | 貧窮腦 | 思考模式 |
|---|---|---|
| 環境 | 我貧窮是因為景氣不好、老闆太小氣、同事太蠢、客戶太無知…… | 以負面角度看待環境，一切問題都怪罪外部因素。 |
| 行為 | 我貧窮是因為我不夠努力、太懶散、沒有花時間學習理財…… | 質疑自己的行動，將失敗歸諸於行動。 |
| 能力 | 我貧窮是因為我不夠聰明、情商低不會處關係、沒有商業天賦…… | 判斷自己缺乏解決問題的能力。 |
| 信念、規條、價值觀 | 我貧窮是因為我本來就不看重錢，錢不是最重要的…… | 被負面信念所限制。 |
| 身份 | 我貧窮是因為我就是一個無足輕重的無名小卒…… | 認為自己微不足道，毫無力量。 |
| 精神 | 我貧窮是因為我的生命就如草芥，毫無意義，對世界也毫無影響…… | 認為自己與世界是分裂的，不相干的。 |

- 貧窮腦的六個層次 -

環境、行為與能力稱為低三層，是多數人可以意識到的層次，價值觀、身份、精神，屬於接近潛意識的高三層，需要悉心留意或是教練帶領才能夠覺察。通常低層次的問題，提高一個層次思考就能輕易解決。

我們想要扭轉貧窮腦的模式轉為財富腦，也是這樣一層層地改變，越上層的改變越難，但影響力也越大。

許多生命的核心關鍵問題，如財富、幸福、快樂，都需要極大的力量才能真正推動改變，這時候若只停留在低層思維層次，就會十分混亂、無力。

真正重要的生命議題，需要從上至下改變思維層次，以下我們依然以財富舉例，展現將貧窮腦思維翻轉為財富腦思維的變化。

|   | 財富腦 | 思考模式 |
|---|---|---|
| 精神 | 我希望自己的富足能夠讓世界更好。 | 利他思維，跳脫自利，思考自己給世界的貢獻。 |
| 身份 | 我是一個富足的人，是掌握自己生命的創造者！ | 賦予自己有力量的正向身份。 |
| 信念、規條、價值觀 | 我相信世界是美好的，金錢是實現精彩人生的工具。 | 建立有力量的信念。 |
| 能力 | 我具備終身學習的能力，可以不斷成長。 | 培養專業與整體的能力。 |
| 行為 | 我選擇每天學習理財知識、充實自我。 | 採取大量正向行動。 |
| 環境 | 我現在的環境充滿機會與資源。 | 以正面角度看待環境。 |

- 財富腦的六個層次 -

通過這兩個表格，你是否更清晰看見，自己在哪些時候發揮了財富腦思維、哪些時候又落入了貧窮腦思維？

帶著這套幫助無數人成功的思考體系，你再來理解下面的財富四象限概念，就能比其他人更快速掌握關鍵點了，也更能看到自己想進入什麼身份。

## 財富四象限

財富四象限是財商領域經典的一課，其中最廣為人知的是《富爸爸，窮爸爸》作者羅伯特・清崎所提出的 ESBI 財富四象限理論。

我過去與羅伯特老師一同進行亞洲巡迴財商課時，目擊這個理論衝擊台下數萬名聽眾，如果你聽過這個理論，我們可以做一個複習和升維，如果你沒聽過，那就準備好來一個認知大升級囉！

| | |
| 為別人工 作\領薪水\60%\僱員 E | 建立系統為你\工作賺錢\5%\B 企業老闆 |
| 專業人士 S | I 投資者 |
| 為自己工作\做一天賺一天\30% | 讓錢為你工作\越賺越多\5% |
- 財富四象限 -

我們可以看到這幅圖用十字隔出了四個象限，分別代表四種不同的財富維度，左上角的英文字母是 E，它的意思是 Employee 僱員，左下角是 S，代表 Self-employed 專業人士或是小生意主，右上角的 B 是 Business owner 企業主，而右下角的 I 代表 Investor 投資者。

任何人的一生都可能經歷這四種不同的財富維度，它們也可能會重疊存在。它們不代表人的高低優劣，而是呈現出這四種身份帶來不同的思維方式。

先從左邊的兩個象限說起，這兩種身份是以掙錢思維主導的。

世界上 80% 的人一輩子都會待在 E 象限裡面，過著受僱者的生活。

不管是朝九晚五還是 996②，他完成崗位職責，然後老闆支付他薪水。在這個象限裡的好處是穩定、安全、就算天塌下來也不會砸死你，因為有老闆頂著，但同時你的收入也是有天花板的。

當然如果你夠優秀、夠資深，得老闆信任，老闆可能會願意分股票

②內地用語，代表早上九點工作到晚上九點，一週工作六天。

給你，多數是期權性質，辭職後可能就會失效。有些創始團隊高管則有機會得到永久股份，那就是從卓越的 E 象限成為 I 象限（股東）的例子。僱員的身份並沒有不好，每個崗位都有自己創造的價值，同時每個人想要的生活方式不同。有些人喜歡安定跟平穩，有一份穩定收入的工作支撐自己想過的生活，這也是很棒的。

S 象限可以理解為專業人士，或是小生意主。

例如在律師事務所上班的律師、在診所工作的醫師，或是做小生意的小老闆。他們賺取金錢的能力通常比僱員高，因為他們具備不可替代的專業能力。

例如你是接案能力特別強的律師，你協助一個企業併購案，賺了一大筆儲金，這筆收入是不是比其他僱員多得多？但你還是得付出大量的時間和精力，靠自己本尊掙錢，做一天有一天的收入。

如果我們想要進入到賺錢的領域，不再只是靠雙手掙錢，那麼我們就要培養右邊象限的思維。

右上角的象限是 B 象限，代表企業主和老闆。

全世界只有 5% 的人可以進入到 B 象限，其中包含中小企業主和大型企業主。當企業還沒有自動化時，通常老闆還是必須天天去公司，一週沒去公司可能就會出亂子，這時候老闆可能是比 S 象限更累的。

有些經營餐館的企業主，就是一群疲憊的老闆。我有位朋友家族經營一間蘭州肥腸麵店，生意興隆、天天爆滿，早期從洗肥腸的方法、調料的秘方，到餐館的營收會計，都需要老闆親力親為，老闆出去度假就會開不了店。後來培養出親信、建立了固定流程，老闆們才被釋放出來。一幫熱愛肥腸麵的朋友們一直鼓吹他們家建立連鎖系統，覺得一定會爆紅，成為玩轉被動收入的企業主。

要進入 B 象限並不容易，雖然成功後有巨大的獲益，但中途也有巨大的風險。要從個人單打獨鬥的思維，轉為老闆運作員工與資金的思維，隨時想著「如何讓公司沒有我也能運作良好」，這樣才能真正享受作為企業家賺取被動收入的快樂。

最後是右下角的 I 象限，代表投資者，讓錢為你賺錢。

例如你找到了一個好的投資項目，不管是股票、基金、債券或是一間新創企業，當你學會讓錢為你賺錢，你就進入了 I 象限 10。

但是從開始學投資到獲利，需要一個漫長的過程。很多人承受不了投資的「學習過程」，只能半途而廢。其實凡事會就簡單、不會就很難，更精確一點來說是學過就會、沒學過就不會。

不管是走路、開車、游泳，或者是賺錢、創業、投資都是如此，沒有天生的專業投資者，就算父母再牛，孩子出生也要重新學走路，投資也是一樣。

任何產業裡，都可能有 ESBI 象限的不同位置。例如娛樂業，有些藝人專注於接拍作品，成為行情要價越來越高的 S 象限專業人士，而有些藝人除了演戲工作，還涉足投資各式各樣的產業，那就是往 B、I 象限發展了。

同樣都是醫生，若是受聘於醫院，就是在 E 象限，若是自己出來開診所，每天都要看診排班，就在 S 象限，若是投資醫院，建立醫療團隊，開始有自由的時間，就是 B 象限，若是投資新的醫療技術和設備，就是 I 象限。

用一句順口溜來總結 ESBI 象限的精髓就是：
E 象限，我是僱員，我為別人工作。
S 象限，我是專業人士，我為自己工作。
B 象限，我是企業家，別人為我工作。
I 象限，我是投資者，錢為我工作。

⑩書中的定義是擁有 100 萬美金的投資資金，才能被稱為「專業投資人」。

大部分的人都是從左邊的 E、S 象限出發，再往右邊的 B、I 象限邁進的，而福布斯排行榜名人，也多半在右邊。

不過往的工作與事業經驗中，你是否經歷過 ESBI 不同的象限？在不同的象限中，收入是如何？自己的心態是如何？

| 象限 | E 僱員 | S 專業人士 | B 企業家 | I 投資者 |
| --- | --- | --- | --- | --- |
| 人數比例 | 80% | 18% | 1% | 1% |
| 收入比例 | 1% | 20% | 79% |  |
| 收入方式 | 掙錢（主動收入） |  | 賺錢（被動收入） |  |
| 核心關鍵 | 確保穩定 | 提升專業 | 建立系統 | 操作槓桿 |
| 晉級需求 | 良好學歷教育 崗位技能 | 行銷力 表達力 業務力 疑導力 執行力 | 財商力 管理力 統籌力 整合力 戰略力 抗壓力 | 財商力 自控力 趨勢觀察力 |
- 四象限比較 -

這四個象限會帶來不同的人生風景與學習，而財富腦是進入 B、I 象限必不可少的修煉。我們又該怎麼 bist 呢？

《富爸爸，窮爸爸》作者羅伯特清崎的推薦公式是：

成為（BE）→去做（DO）→真正擁有（HAVE）

也就是先進入 B、I 象限的思維狀態，接著採取相對應的行動，最後自然享受成果。

這與我們上一段所談到的 NLP 思維理解層次不謀而合，從高三層的精神、身份、信念出發，再帶動低三層的能力、行為和環境，才是最高效的。

下次再面臨事業或財務上的選擇時，問問自己：

如果是僱員會怎麼想、怎麼做？
如果是專業人士會怎麼想、怎麼做？
如果是企業主會怎麼想、怎麼做？
如果是投資者會怎麼想、怎麼做？

## 金錢自由公式

努力修練自己成為有錢人，是為了能夠享受金錢帶來的自由生活。
為什麼有錢人可以躺在沙灘上曬太陽，同時收入源源不絕？因為他已經擁有財富自由（financial freedom），這四個在財商領域閃閃發亮的字是什麼意思呢？怎樣才算是達到財富自由呢？

你不需要家財萬貫才能財富自由，它的公式是：當被動收入大於所需支出時，你就達到了財富自由。

被動收入與支出，是財富自由公式的兩大檢視重點：一方面要建立被動收入，二方面我們要評估自己的生活需要多少支出。

> 美國財經作家川特哈姆（Trent Hamm）說：「良好的預算始於真實地了解你的支出和收入，財務獨立的一個重要部分是，弄清楚如何在你的能力範圍內生活。」

不管你有沒有記賬的習慣，你都知道自己每個月的固定花費大約是多少，包含房租（房貸）、水電、稅費、通訊費等基本開銷，加上其他生活支出，總結成一個概略的數字。

在統計支出的過程中，你可以為自己設定三檔標準，分別加以預估。

第一檔是基礎生活支出，也就是每個月一定得支出的費用，包含最基本的房租或貸款、食物、交通、電話費等等，這些支出僅僅是維持你的基本生活。

第二檔是理想生活支出，除了必須的開支外，增加了學習、娛樂、休閒、慈善等非必要支出，節慶送禮也屬於這個層次，加上這些開支之後，你的支出可能至少增加 30%，甚至更多，但卻能換來更舒適的生活品質。

第三檔則是優渥生活支出，每個支出環節都進行升級，增加更多的高端旅行、奢侈品消費，並且購買更多輛車，有的做市區代步、有的上山越野，再加上一台露營野餐車。你的每月優渥生活支出可能是基礎生活支出的五倍、甚至十倍、百倍乃至於無上限，讓你能夠享受富豪般的生活。
