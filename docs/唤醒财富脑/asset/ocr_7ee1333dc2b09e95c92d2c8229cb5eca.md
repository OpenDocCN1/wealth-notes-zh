# 本章小結

# 未來必備技能：投資

+   1、 有錢人與窮人的第五個區別：面對未來的方式不同。\n2、 投資是致富的必備技能。想要學會投資要保持兩個習慣：學習和實踐。

# 世界第八大奇跡：複利

+   1、 世界的第八大奇跡：複利。了解的人賺錢，不了解的人被賺錢。\n2、 複利三原則：\n第一：本金。起始資金決定了收益與利潤的增長。\n第二：時間以及頻次。滾動複利的頻次越多，持續的時間越長，滾出的利息就越多。\n第三：利率。就是產生利益的效率，效率越高，收益越好。

# 資本三要素：如何發揮錢的效應？

成為投資人，把資金變成資本的三要素：

+   第一個是金錢的本身。\n第二個是時間，投資需要時間去放大價值。\n第三個是智慧，也就是有錢人的腦袋。

# 平穩的情緒，才是投資的最大本錢

+   1、 成為頂尖投資者的兩大關鍵：杜絕情緒、理性決策。\n2、 要關注現金流大過於淨資產，因為缺乏現金流，就容易落入情緒風險。\n3、 情緒高漲時做的決策，往往是錯誤、賠錢的。
