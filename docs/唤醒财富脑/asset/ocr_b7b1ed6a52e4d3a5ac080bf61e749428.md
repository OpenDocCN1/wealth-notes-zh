# 你是窮人？還是有錢人？

在成長領域中，自我認知是很重要的，這關乎一個人對於自己所在的位置和定位是否清晰，也是影響他成長效率的最大因素。

舉個例子來說，一個人如果在大海裡浮沉，卻一直想要百米衝刺，那他肯定很挫敗，連手腳都施展不開，他得先看清楚自己的處境「啊，我現在陷在海浪裡」，至少要先想辦法上岸才能去思考百米衝刺的事情。相反來說，有些人已經在岸上了卻老覺得「不行，我快淹死了」，就像明明手頭有餘裕，卻老是說「我太窮了沒錢投資」，這也是一種認知謬誤。

這些偏差的自我認知都會造成內耗的感受，進而成為你的財富阻礙（Wealth Barrier），過高的財富阻礙指數，就是錯誤的自我認知造成的。

有個自我認知偏差的例子叫做「捧殺」，就是俗稱的大頭症。

不管是企業高管、歌星、演員甚至是講師，這些需要光環效應的職業崗位，都特別忌諱大頭症。在這個流量稀缺的時代，「名聲」和「影響力」往往無法僅靠一人成就，需要動用公司和團隊力量才能建立，但如果站在第一線的明星以為一切都是靠自己的實力，這種錯誤認知就是工作和商業上很不成熟的表現。簡單來說，就是「錯把平台當能力」，這會變成職涯發展的一大絆腳石。

在財富這個領域裡，也有許多的認知偏差。例如很少人認為「我已經太有錢了，需要少賺一點」，大部分的人都覺得錢不夠，不夠富有，甚至覺得自己很窮，但這是真的嗎？

到底什麼叫窮，什麼叫富？對於貧富的定義不明，可能讓人淪落到欲望和恐懼的無限迴路中，難以自拔。
