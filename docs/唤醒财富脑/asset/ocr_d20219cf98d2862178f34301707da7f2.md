# 推薦序 9 讓財富腦「助你好運」

七年前，我寫了一本從正向心理學角度探討運氣的書，叫《助你好運》。當時我連同出版社辦了一場「30 天好運研修營」，邀請各界有志於探索心理成長的人士參加，將書中的理念實踐在生活中並做觀察，芳誼也是其中一位參與者。這些年來，芳誼不但多次為國際大師們進行口譯，獲得了他們一手的知識精華，也善用她的才華，啟發更多人發掘潛能，為自己創造更富有的內在與外在。如今她將這些心得和經驗編寫成系統性的知識，讓每個人都能夠創造更好的生活，這也是在為社會創造更多的好運與善的源頭。

我很喜歡這本書的切入角度：透過測驗和問題了解自己對財富的深層觀念，並透過公式檢視目前的財務狀況。這不只是心法，也是很好的財務整理法。想學習投資理財的人，可以用這本書建立良好的基礎。恭喜芳誼，不但實現了自己的夢想，也以分享為初心，協助眾人實現自我成長。這也是我在書和課程中傳遞的理念，有相互照見之處，私心希望不只是巧合！

劉軒（Xuan Liu）
知名作家／心理學導師
