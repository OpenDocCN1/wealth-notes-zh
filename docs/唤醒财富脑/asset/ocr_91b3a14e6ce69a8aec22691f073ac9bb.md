一大利鍵，故說「轉念即轉運」。並不是說聖人就永遠沒有負能量或是負向狀態，而是聖人、開悟者可以更快速地調整自己。這也是為什麼有「修行人不可算命」的說法，其實是說修行人即使算了命，也很可能算不准，因為每一次修正念頭，命運的軌道就有機會改變，而修行人經常在覺察與修正自己。

有一位弟子問他的師父說：「師父你已經開悟了，你是不是再也不會感受到恐懼、害怕、憤怒了？這些是我們還沒有開悟的俗人才會有的情緒對嗎？」師父一笑回答說：「傻孩子，開悟者也還是人啊！我們依然有七情六慾，也偶爾會有恐懼、不安、焦慮、不信任等等，只是頻率會比一般人少許多，同時我們可以更快速地調整自己」。所以開悟並不是從此剷除七情六慾，而是獲得更快速覺知和調整的能力。

一般人也許會覺得大師好像離我們很遙遠，但是事實上人人皆有佛性，就是內在的圓滿自性，俗話來說就是內在的智慧。

內在智慧與宗教無關，而是內在真正的潛能，它不屬於任何一個宗教，而是屬於每一個人的天賦潛能。

我們的意識具備從 0 ～ 1000 的能量層級潛能，就像是種子一般存在於每個人的內在，只是看我們更關注哪一顆種子、選擇讓哪一顆種子發芽，給予哪一顆種子茁壯的能量。開悟的人只是有更多的高能量種子發了芽。

# 我們內在的兩頭狼

美國的印第安人部落有一對祖孫，爺爺跟孫子說，我們每個人的內在都有兩頭狼：好狼跟壞狼，以能量層級來說的話，好狼的能量在 200 以上，充滿了大愛、勇氣與智慧。而壞狼的能量在 200 以下，穿梭於恐懼、攻擊、憤怒與質疑。

孫子問：「爺爺，這兩頭狼誰會獲勝呢？誰會主宰我們的命運呢？」爺爺說：「那要看你關注哪頭狼，你就餵養了牠，更大的那頭狼主宰你。」
