# 如何創造高效的學習

如同所有頂級電子產品公司都在不斷升級他們的產品系統，終身的學習與成長，是確保我們這一 生財富正向積累的關鍵。

可惜的是，大部分人的學習熱情都消耗在制式教育的壓搾之中，特別極端的就像公視電視劇《你的孩子不是你的孩子》裡描繪的，年輕的靈魂被單一的考試標準碾壓、甚至粉碎。情況好一點的孩子則是努力撐過考高中、考大學的時期，但是從此學習的興趣已經被考試破壞殆盡，對書本、學習產生極度反感，進大學就是放飛自我「由你玩四年」。我們公司很多剛進來的 90 後、00 後員工都笑說，自己這輩子的知識頂峰就在考完大學的那一天。

十幾年的義務教育洗禮，其實並沒有教會我們「如何學習」，甚至還摧毀了許多人的學習欲望。正因為許多人的學習習慣止於大學階段，於是掌握了成長秘訣的人，就能成為財富之路上的終極贏家。

我大學英國文學史課堂的閱讀清單有一本書叫做《如何閱讀》（How to Read），那時候覺得特別逗趣，人家問你在閱讀什麼？我說我在閱讀《如何閱讀》。後來才知道這叫做後設觀點（Meta Perspective），就是做一件事不只看表面，而是能夠抽離到另一個更高的角度去看待同一件事，藉以產生更寬、更高的視野，有助於在這件事情上達到更好的效果。就像孔子說登泰山而小天下，拔高高度，看得更清楚。

既然確認了學習是致富路上必不可少的技能，今天我們借用美國教育學家艾德格戴爾（Edgar Dale）的著作所啟發的學習金字塔理論（Cone of Experience），探討什麼樣的方式才能發揮最好的學習效果？美國緬因州的國家訓練實驗室研究發現，如果光是聽老師講述，學生在兩周後記得的內容只會剩百分之五。究竟如何才能提升學習效果呢？他們通過金字塔的概念來闡述，以下是方便運用的簡化版本。
