# 限制性信念的根源

+   1. 我無法獲得大量金錢，因為我不夠好，能力不夠強（不足感）
2. 我無法讓金錢滾滾而來，因為我不是唯利是圖的人（清高感）
3. 我能獲得一定數額的金錢，但更大的財富需要靠攀附關係才能獲得（清高感）
4. 君子愛財，取之有道，有些錢我不想賺（清高感）
5. 如果需要拍馬屁、做舔狗，我寧願賺辛苦一點的錢（清高感）
6. 我無法很輕鬆就賺到很多錢（辛苦感）
7. 錢很難掙（辛苦感）
8. 如果我很有錢，我可能會變得孤單（討好感）
9. 金錢是邪惡的，所以我不想要它（清高感）
10. 我應該把別人的需要放在自我的需要之前，否則是很自私的（討好感）
11. 我應該避免賺取太多的金錢，因為這會帶來矛盾與痛苦（辛苦感）
12. 不一定只有金錢才能創造美好的生活（清高感）
13. 賺更多錢，可能要犧牲我的自由、甚至是關係和健康（辛苦感）
14. 我不擅長理財（不足感）
15. 如果我賺了很多錢，可能會被物欲所控制、反而失去一切（清高感）
16. 依照我的現有條件，很難成功（不足感）
17. 錢買不到幸福，所以不需要太看重金錢（清高感）
18. 如果賺很多錢，過程中可能會得罪、牽負很多人（討好感）
19. 再多錢也無法買到內心真正的平安（清高感）
20. 追求利益會導致關係失調、家庭失和（討好感）
21. 錢很難管理（不足感）
22. 因為我是女人，社會允許我的成就是有限的（不足感）
23. 因為我是男人，很多錢不得不花（虛榮感）
