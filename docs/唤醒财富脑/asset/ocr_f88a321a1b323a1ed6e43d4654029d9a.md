# 推薦語

在我人生 32 歲時，我還是個負債百萬，碰到金融海嘯，人生不知何去何從的窮光蛋。但真的很神奇，透過學習提升自己的財商，並把財商跟房地產投資、房地產事業結合，不到 3 年的時間，我就跳脫富爸爸說的老鼠賽跑的上班族生活，在外圈過著時間自由、財務自由的日子，至今已超過 10 年的時間。之所以能快速達到這樣的境界，我覺得房地產是個工具，但最關鍵的關鍵因子，還是一顆有錢人的腦袋，也就是芳誼在本書中所說的「財富腦」。芳誼是我們這％群頻繁出國學習的同學中，受到世界級財商大師功力加持最深的，相信只要你好好閱讀這本書，你也可以打開你的財富腦，加速改變你的人生！

Jerry
JR 購屋理財資訊網創始人
《百萬部落客教你如何月入百萬》作者

在看我來，芳誼這位小時候曾經被懷疑是水腦症、其實只是腦袋大了點的小女孩，果真是一位既有內涵又有能力的漂亮女生。書中諸多的金句中，我最喜歡的一句話是「你做一件事的態度，就是你做所有事的態度」，這也是我對芳誼的基本認知。誠如芳誼在書中所言，關於財富的三大選擇，時時刻刻都在影響著我們的財富命運，可謂是醍醐灌頂式的提醒（在此賣關子給各位看倌自行去挖寶）。芳誼的寫作由淺入深、邏輯清楚且舉證諸多案例，讓人在閱讀中覺得人生充滿了無限的愛與希望，能夠在積極的信念中產生力量。非常貼心的是，每個章節末還加上了「本章重點小結」，讓我對作者的細膩更加欣賞。

陳延宏
《財務策略個案分析》作者
IIC 科技大學商業管理學院教授兼院長
