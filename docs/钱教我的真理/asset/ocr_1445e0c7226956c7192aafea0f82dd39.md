# 錢在你眼裡，「只是一張紙」？還是「朋友」？

錢是有「意志」的。

譬如像拋棄式刮鬍刀，只要你用得仔細，用完之後還讚美一下：「了不起，刮得好乾淨唷。」這樣一來，刮鬍刀的壽命就能延長好幾倍呢。

相同的，如果你經常對錢表達感謝，錢也會願意為了你「多做點事」。

但也有人認為：「錢只不過是一張紙，數字哪有什麼意志？」我想這種人大概只把錢看成是「一張紙」或「一個「數字」吧。
