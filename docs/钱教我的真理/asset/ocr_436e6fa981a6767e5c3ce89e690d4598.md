# ### 懶人祈求上天，勤者感謝上天

我們在上天的面前，有人祈求，有人感謝。

勤勞者向老天爺表達謝意，懶惰者則向老天爺表露期盼。向上天祈求並不是壞事，但只知嘴裡嚷著：「老天爺，求求您！」自己卻一點也不努力，這種做法既不能培養「智慧與耐力」，對祈求者來說也沒有任何好處，所以老天爺是不會幫助這種人的。

接下來要說的，只是我個人的想法，我覺得日本的社長當中，女性少於男性的原因，是因為女性有機會「嫁入豪門」，所以女人都比較不肯努力。
