# 最好是上天也讚許的「基本功」

有些企業老闆開發出優秀商品，或把企業經營得有聲有色，因而深獲大眾敬佩，或許也有很多人打從心底讚賞他們：「好棒啊！」但我在前面也已經說過，這種人，大部分都已在前世或前世好幾代，累積了無數辛勤與努力，才會有今天的成就。

所以，各位當中如果有人想要變成富翁，就必須先從「基本功」練起。而這
類基本鍛鍊，最好就練「上天也讚許的基本功」。

換句話說，也就是運用你的「智慧與耐力」來學習賺錢。

只要你擁有卓越的智慧與耐力，賺錢的機會總是源源而來。有人經營企業遭遇失敗，那都是因為還沒有具備必要的「智慧與耐力」。

所以我建議大家先學習如何練好基本功。
