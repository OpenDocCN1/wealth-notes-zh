


# 敬一丹与电视新闻语态

**小懒判断** 适合做内容、当主播或研究媒体表达的人，不适合想看敬一丹生平八卦的人。最值得关注的语速数据是从每分钟160字涨到320字，还有“改革总从边缘开始”的规律：早间时段、地方台、民生新闻先松绑，主播中心制的新媒体只是把这条规律又走了一遍。坑在于把敬一丹风格当主流，她那种“隐痛”式表达在当年恰恰是少数派。

9月13日，央视著名主持人敬一丹在北京去世，享年71岁。

敬一丹1955年生于哈尔滨，1988年进入中央电视台工作到退休，官方评价是“深耕新闻一线三十余载，以沉稳、知性、亲和而富有洞察力的风格深入人心”。

敬一丹的离世，是中国电视新闻黄金时代走向谢幕的标志之一。不少回忆文章提及她特有的温和而坚定的主持风格。她的声音和形象让1990年代的电视舆论监督，在尖锐之余多了温度。

本期会员通讯，我们通过分析敬一丹及其他知名新闻主持人的台风，回顾中国电视新闻的播报语态的变迁。为了避免话题发散，我们只讨论与新闻播报、新闻评论直接相关的语态变化——同在央视新闻评论部的崔永元及类似的电视名嘴不做讨论。

## “念稿机器”也有创新点

文革前的播音风格，以中央人民广播电台资深播音员夏青、齐越为代表，可谓爱憎分明、坚定豪迈。文革期间，播音风格基本就是电影院里《新闻简报》式的，高亢激昂的战斗檄文。

2009年，《中国周刊》在罗京去世后采访中国播音学学科奠基人张颂。他提到，1981年薛飞、杜宪进入《新闻联播》之后，开始探索与前辈不同的播报方式。薛飞他们把前辈的播音称为“新华体”，认为其速度较慢，总感觉很观众有很远的距离。

薛飞、杜宪和之后进入《新闻联播》的张宏民、罗京、卢静等人一道，谋求播音上的突破。他们把“观众同志们”的问候语变成了“观众朋友们”。1984年，卢静第一个尝试微笑播音。《新闻联播》播音员们逐渐形成了字正腔圆、沉稳大方的播音新风格。尽管这种风格在当时作为创新广受欢迎，但时间一久就显得死板。

1989年之后，《新闻联播》的主持人发生了变动。邢质斌、李瑞英、李修平、罗京、张宏民、王宁最终稳定下来，轮流出现在主播台上，被戏称为“老三对”；直到2007年，海霞、郭志坚、李梓萌、康辉、欧阳夏丹、郎永淳等才陆续加入。

张颂总结，1950-60年代，播音的速度是每分钟160-180字，到1980年代就变成了每分钟220-240字，1990年代以后再次提速，变成了每分钟280字。而到2012年，《新闻联播》中主播们的语速已经达到了320字/分钟，基本上这已经是保持风度、仪态前提下的最大值了。“如果是现在的观众回过头去看50年前的新闻节目，可能会觉得跟放慢镜头一样。”

1994年，很多人说《新闻联播》的播音员只会照稿念。张颂希望罗京写一篇文章反驳，罗京回答，“这用不着写文章，让他来念一个试试就行了。”

张颂是众多《新闻联播》播音员的导师，“每当有人不屑‘《新闻联播》播音员只是一台念稿的机器’，张颂总为他的学生鸣不平”。他始终强调：“新闻播音员不是一群没出息、一味照稿念的传声筒。同样一段话，我有多种表达感情的方式，仔细听绝对能揣测出、感受到其中内涵。他们全是在自己理解下，用敏锐的思维反应把握政策分寸，发出自己的声音。”

只不过，“念稿机器”的批评并非空穴来风：播音员依照写好的稿件照本宣读，与后来那种要参与选题、采访、编辑、串联，甚

至为整档节目负责的“主持人”，确乎是两种职能。

## 从播音员到主持人

李梓萌曾说，“如今，播音员与主持人之间的界线已经不分明了，直播量的增加要求播音员必须具备新闻主持人的直播能力”。从“播音员”到“主持人”的转变不可能发生在一夜之间。正好，敬一丹本人就完整经历了这个转变过程。在她职业的起点，她是“照本宣科”的播音员；在她退休时，她以自己鲜明的主持风格被人们记住。

2004年，她在《99个问号：敬一丹漫谈主持人》一书中说：

“我觉得，主持人的出现就是为了让电台、电视台像一个人，尽量实现人和人的交流。而以前，是一个机构对受众的宣传。听听原来的中央人民广播电台和中央电视台的节目，那是一个‘人’吗？那声音全是规范的，一个样，不是专业的人听不出区别来。”

“这是不能脱离时代的，不能想像主持人会出现在中国的六十年代和七十年代，根本没有可能。六、七十年代哪能‘我’啊？在那个时代背景之下，‘我’都消失了。媒体的一切改变都离不开环境。中国广播电视才走到了这一步，才有了主持人。它真的是时代发展的产物，也是尊重传播规律的产物。”

敬一丹的职业起点是1980年代初，在黑龙江人民广播电台做播音员。她在今年5月30日的一场毕业典礼上发言说：

“因为过去我做过最传统意义的播音员，照本宣科、按部就班成了我的惯性，也成了我正常的状态。我经常感觉，我是认真的，但是被动的。”

但转向不再“照本宣科”其实并不容易。有一次她要提笔给听众回信，却一时不知如何下笔。她回忆说：

“我第一次在质疑我的专业。我在学会了字正腔圆地做一个转述者的同时，失去了独立的思考和个性化的表达。我们那时候经常说要‘理解稿件’，理解编辑记者的意图，我认识的世界是间接的。我的所有创造都局限在把文字变为有声语言。我不否认这也是一种创造，但这种创造相对来说是狭窄和消极的。”

这以后，她却仍然不知该怎么做。不久，她就听到在遥远的中央人民广播电台，出现了对台湾广播《空中之友》里的徐曼。“很快，国内的同行就意识到，我们能对台湾的听众这么讲话，为什么就不能对我们大陆的听众这么讲话呢？慢慢地，在中国的广播电视界，就出现了主持人。”

她回忆说，比较早的主持人是《话说运河》《话说长江》的虹云、陈铎，以及《为您服务》的沈力。

“在这之前，从来没有这样的交流出现。他们以那么一种方式，不是转述的形式，而是近距离、活生生、个性化的方式和观众交流。这个变化是很本质的。”

主持人火了以后，地方台就开始学习央视，也推出自己的主持人。最初第一批主持人，多半是有播音背景、当过播音员的。“所以一直到現在，人們還習慣把播音和主持放在一塊說。播音員和主持人有相同的东西，但更应该看到他们的区别。主持人不光是体制上采用了采、编、播合一的方式，还有个人的心态，表达方式，给受众的感觉都是不一样的，他更个性化。”

敬一丹说，“我是在播音的背景下走向主持人的，是先研究别的主持人，然后自己才成为主持人的。这样一条路，使得我能一边实践，一边琢磨。可实践、可琢磨的还真不少。”

此后，她考入中传前身北京广播学院研究生，毕业后留校任教。不久后，敬一丹在一个会议上见到了一群市场经济早期的开创者，希望把他们的故事写成报道。

“这一天，我感受到了心动。这个心动让我清楚地知道，我内心是什么在如此强烈地吸引着我——这就是陌生、新鲜、记录和传播。我要当记者。我要从记者出发，做一个采编播合一的主持人。”

## 敬一丹的主持风格

此后，她在央视二套的《经济半小时》工作了好几年。1993年5月10日，《一丹话题》开播，是“央视第一个以主持人名字命名的言论性节目”，从选题、采访、编辑、制作到播出，除摄像外全由敬一丹操办。

此时敬一丹“进入了舒适区”，直到1994年4月1日《焦点访谈》开播。敬一丹说，接到节目组邀请后，“我立刻就心动了。立刻！是什么吸引我？就是《焦点访谈》旗帜上的四个字：舆论监督。”她停掉了以自己命名的节目，加入了《焦点访谈》。

时任新闻评论部主任孙玉胜表态，“尽管我们是做舆论监督的，但是我们的位置要摆得非常正，我们不能以在野党的这种位置来看待监督出来的问题，向政府发难……而是要本着一种建设者的思维，抱着解决问题的态度帮助政府来工作，绝不是添乱。”

然而《焦点访谈》的性质决定了它不得不直面尖锐的社会矛盾，整体播报也给人“刺痛感”。回顾来看，将“建设者思维”贯彻到最彻底的，其实就是敬一丹。“在《焦点访谈》这样一个充满冲击力的节目中，敬一丹的‘温文尔雅’显得有些格格不入。”她的同事们在《焦点访谈红皮书》中写道。

白岩松在《痛并快乐着》里写：“她的心很软，即使是批评性的报道，她也是商量性的口吻，而在采访需要提一些尖锐性问题时，敬大姐总是狠不下心来，这使得敬大姐在我们这个经常流露出‘尖酸刻薄’的团队中多少显得有点与众不同。”

比如，一家出版社把地图印错了。她知道最直截了当的问法应该是：“你知道不知道地图印错会引发怎样连锁的后果？”可面对那位年轻的编辑，她怕这样一问，事情会显得太重。于是，她一开口就成了：“你过去印过地图吗？”类似这样的例子有很多，面对采访对象，她实在做不到“哪疼往哪戳”。

《焦点访谈红皮书》说：“有一种主持人能给人以‘刺痛感’，因为舆论监督节目本来就不是让社会所有人都感觉舒服的，是要让它保持‘感觉’，不能麻木，这‘感觉’里当然包括痛感；但另一种主持人，让人产生一种‘隐痛’，不是那种尖锐的痛感。敬一丹属于那种在比较平和的状态下，善于表达‘隐痛’的主持人，她可以把一些锋芒毕露的话语处理得很合理，很注意语调的把握，她对观众说话的声调，像是对朋友说话一样，这是她一直追求的一种交流感。”

在节目组里，方宏进的风格也类似敬一丹。他说：“作为一名《焦点访谈》的主持人，你要以理服人，不能天天声色俱厉地拍桌子，那只是一种宣泄，缺少让人回味的东西。”

# 语态的变革从边缘开始

《焦点访谈》以及《一丹话题》等并不是央视最早的舆论监督栏目。1980年7月12日，《观察与思考》开播时，不仅是全国第一个电视评论类栏目，而且在普遍没有主持人姓名的时代，第一个放上了“赵忠祥”的名字。

1988年，节目改名《观察思考》并规范化播出，同时全国各地同类节目纷纷出现。方宏进正是因为在北京电视台主持《18分钟经济与社会》栏目被《观察思考》节目组相中，一年后跳槽到中央台的。到1993年，《观察思考》和《今日世界》栏目划归新成立的新闻评论部后停播，人员转向《东方时空》和《焦点访谈》。“焦点时刻”和《焦点访谈》是《观察思考》的直接继承人。

笔者曾在2020年1月赵忠祥去世时，写过纪念文章《赵忠祥的时代角色》，并且认为“赵忠祥是中国最早一批电视记者的杰出代表”。作为《观察思考》的主持人，赵忠祥展现了与他主持《动物世界》或春晚时截然不同的，一种庄重冷峻的风格，为节目注入了权威感与沉稳感。在面对复杂的社会问题时，他表现出一种客观、冷静的审视姿态。

1993年5月1日，早间节目《东方时空》在央视一套开播，标志着中国电视历史上新-轮改革的开启。时任新闻评论部主任的孙玉胜在《十年——从改变电视的语态开始》中写道：“作为自始至终的参与者，我认为……成功的深层原因更在于《东方时空》实验了一种新的电视理念——重新检讨我们与观众的关系，重新认识电视的‘家用媒体’属性及其特有的传播规律。甚至可以进一步直白地说：始于1993年的电视新闻改革在理念上是从实验与电视观众新的‘说话方式’，也就是新的电视叙述方式开始的。比如，叙述的态度应该是真诚和平和的；叙述的内容应该是观众关心和真实的；叙述的技巧应该是有过程和有悬念的；叙述的效果应该是具有真实感和吸引力的……”

这段话充分概括了1993年以来的电视新闻改革，在语态表达上的主要成果。这次改革让电视节目“转变了政令传达者和知识教育者的姿态”。

敬一丹的温润风格，其实并不是这段时间语态改革的主流。大众更熟悉的是白岩松的风格。“白岩松的激情和锐气给人一种感染，新闻评论员的特征在他身上特别鲜明：敏感、独到、深刻、参与感、播讲欲、不传播毋宁死！……他似乎永远在发现着什么，身上有股锐气。”

到王志主持《面对面》时候就更为如此。网友评价王志的“尖锐”主持风格说，“它是一种态度，但是它更是一种手段……只有从反面，用排除法把所有的疑问都解决之后，我才敢相信这个天是蓝的”。

之后，电视新闻的语态在民生新闻中继续下沉，同时接力棒从央视传到了地方台。

2000年底，周播手语新闻节目《时事纵横》改版扩容，更名为《本周》。贺红梅是这档栏目的标志性主持人。她有点“拉家常”的播报方式，让节目更加接地气。策划节目时，编导们认为，让“旧闻”保持鲜度最有效的办法，就是给它注入浓浓的人情味，通过发掘富有情感的内涵，让“旧闻”重新获得生命力。2001年4月，日本首次审查通过了歪曲历史、美化侵略的中学历史教科书。在做这个话题时，贺红梅没有简单重复外交部发言，而是根据节目的特点，设计了这样的开头：“我们都知道，孩子是最天真的，大人说什么，他们就信什么。即使大人说谎，孩子们也会信以为真。当然，这是很可怕的。然而，最近的日本，就发生了一起大人说谎骗孩子的事……”

经过逐年改版，这个栏目后来变成了日播的《共同关注》，主播朱广权的“段子式”播报走红。

2002年元旦，江苏电视台推出《南京零距离》，捧红了主持人孟非。人民日报海外版采访当时的制片人（注：原文未署名，推测为相关制片人）说，“孟非做过记者，他采访时间话比较到位，心态也比较好。主持人在生活中怎么与人相处，很重要。他是盛气凌人还是平易近人，结果会很不一样。孟非他生活里就比较低调，比较真实，并且能在电视上还原、表现这种真实。”他此后因《非诚勿扰》在2012年成为第一位非央视的金鹰奖最佳电视节目主持人获得者。

读报类新闻栏目迎来了一个小高峰，全国各地都有效仿。2003年，CCTV-2的《第一时间》开播，马斌的“读报”板块成了它最有特色的内容。马斌2008年受访时说：“说白了就是说点人话呀，观众就是衣食父母……中国看电视的，基本上都是最朴素的老百姓，你必须知道他们在想什么，你得用他们的话来表达一些事情。”

学界后来把这总结为“播”与“说”的分野。在“播”新闻的字正腔圆之外，“说”新闻则是主持人把稿件二次创作，“用自己个性化的语言‘说’出来，让观众感到轻松、亲切、自然”。

另一个拥有同样风格的节目类型是地方台的民生新闻，笔者曾在548期会员通讯《中国特色的电视“民生新闻”》中有过详细描述。

从上面可以看出，新闻语态放低姿态，体现亲和力和感染力的变革，更容易发生在边缘的，限制较小的，能创新，有容错空间的地方。不论是当年新闻改革时选择“没什么人注意的”早间时段，主持人中心制让节目自由度更高，还是地方台由于覆盖面有限，有空间播放本地较为尖锐的社会议题等等，都体现了这个规律。

# 起到 anchor 作用的人

近十余年，电视以及广播、报纸等传统媒体渠道，以及门户网站的管控比以往有所收紧，加速了传统的新闻网站向“今日头条”式的算法推荐和自媒体的过渡。技术进步后，自媒体走向视频化。限制相对较小的新媒体，天生就是以主播为中心来组织账号运营的，因此表达风格很快进入了高速进化阶段。

大屏一侧，新闻节目形态日趋保守和倒退。《新闻联播》2013年的特约评论员、现场直播连线球赛等创新都归于昙花一现。央视新闻频道“地球出水”十余年不变，除新闻直播间外的特色栏目大部分被取消。

2020年新闻频道高清播出时，《新闻联播》甚至为了安全播出，不惜把背景大屏幕上遮蔽上，换成了喷绘的背景板，沿用至今。

《焦点访谈》也由站立播报回归坐姿。

而新闻改革之后的节目，在电视媒介衰退的背景下后继乏力：《每周质量报告》在三鹿奶粉案后，因播发过吹捧三鹿的报道而失势。有人对比《焦点访谈》10年前后的节目名称，感慨其中难见舆论监督报道的踪影。《经济半小时》也没法再“关注公众利益”，批评性报道不得不新开一个栏目《财经调查》继续做。

此时的电视台并非弃疗，而是将希望寄托在了监管较为宽松的小屏一侧。比如，2019年7月，《新闻联播》在线下“转变语态”，推出竖屏短视频评论栏目《主播说联播》，让联播组的播音员“结合当天节目中的重大新闻和热点新闻，用通俗易懂、年轻化的语言表达”。领导人外访的随行记者会拍幕后、拍行李箱、自拍等，剪成“大国外交最前线”Vlog在微博、抖音、B站同步推出。

电视新闻主播影响力的下降是全球性问题，在电视业最发达的北美也如此。但是，北美新闻业为这种主持人留下了一个专有名词：News Anchor。它也指接力赛里跑最后一棒、为全队稳住成绩的那个人。四面八方记者和编辑采集的内容，最后汇总到主播台，借由 Anchor 之口对外传播。新闻主播要控场、主导节目，有时自行编辑和串联整档节目，并为节目完全负责。他决定了节目的风格与基调，像最后一棒那样稳住全局。

在写给敬一丹的悼文中，中国传媒大学的周逵写道，“她是国民倾听者，也是中国电视史上极少数真正意义上的 Anchorwoman（女主播）。她不是把声音抬得最高的人，是把船稳住的人。”

他说：“不管媒体多么的分众化，多么依赖数据、推送、算法等等，我们对于复杂社会的认知需要一个锚点，否则所有的讨论最后都变成两极化的互撕，永远不会有一个共识的空间。所以我觉得我们怀念敬一丹，不仅仅是因为她的人格魅力，是她在公共舆论场里头能起到一个 anchor 的作用。”
