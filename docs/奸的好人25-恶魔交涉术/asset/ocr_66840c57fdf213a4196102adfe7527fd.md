# 4、运用不同的说法给听者完全不同的感受

「给我过来！」这句话经常会在道上的兄弟间听到，或是类似这种对话：
「听说XX最近很神气！」
「什么！叫那个浑小子给我过来！」
大概就是类似这种情况。那么，为什么要用「给我过来」呢？这是因为这样的说法，可以同时向内、向外夸示自己的优越性。
另外，「乘虚而入」也是道上兄弟常说的话。
「XX在OO街上收保护费，一副自己很伟大的样子。」
「什么，那个臭小子！居然敢乘虚而入！」
换句话说，即是要给对方一点颜色瞧瞧的意思。
然而，当双方在同一场合的对峙时，究竟谁比较占上风，旁观者其实很难分得清楚。也就是说，同一事件会出现人云亦云的「谣言」。
