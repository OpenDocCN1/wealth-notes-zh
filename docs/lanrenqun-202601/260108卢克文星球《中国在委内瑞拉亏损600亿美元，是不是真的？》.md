

# 中国在委内瑞拉亏损 600 亿美元，是不是真的？

整理：公众号懒人搜索，懒人专属群精选

马杜罗被绑架后，一个老话题开始在中文互联网兴起：中国到底在委内瑞拉亏了多少钱？

有的自媒体声称，中国对委内瑞拉投放的上千亿美元贷款已经打了水漂；也有人断言，所谓的数百亿美元投资早已化为泡影。

透过这些跳动的文字，我仿佛发现，对某些人而言，中国亏钱，似乎比他们自己赚钱还高兴。

那么，中国在委内瑞拉，到底亏了多少钱？

## 01

如果用搜索引擎去查询“中国对委内瑞拉的债务”，很容易被各种数字晃花了眼：有说高达千亿美元的，也有说几百亿的。

实际上，根据威廉与玛丽学院下属研究机构 AidData 的研究，委内瑞拉目前仍欠中国的债务规模大约在170亿美元左右。

而且委内瑞拉的偿还能力，极为可靠。

要理解这个问题，必须先了解中委债务形成的背景。中委之间真正成规模的经济合作，主要始于2009年前后。

当时的国际环境是，2008年金融危机，让国际油价从140美元/桶的历史高点，一路下跌至70美元左右。中国国内的主流判断是：虽然油价暴跌，但不排除未来会涨，所以要抓住机会，和主要产油国签订长期结算协议，对于控制风险最有效。

在这个背景下，2009年，中国向委内瑞拉提供了约80亿美元贷款，次年又追加了约270亿美元。

这些资金并非无偿援助。

根据协议，委内瑞拉需要以大约50美元/桶的价格，每天向中国供应至少10万桶原油作为还款基础，但委内瑞拉石油对华出口，实际远超这个数字。

这个价格明显低于国际市场价格，看起来委内瑞拉亏麻了，它能答应？

首先委内瑞拉的原油品质非常不行：多为重质油，沥青质和硫含量极高。

这就导致其杂质多、炼化难度大。在国际市场上，这类原油只能打折出售。

为消化这类原油，中国山东的部分地炼企业还专门花费巨资对炼化装置进行了升级改造，以适应委内瑞拉原油的加工需求。

其次，马杜罗的前辈查韦斯在油气领域全面推进国有化，直接跟美国资本爆了，双方的官司打到今天都没停歇。如果不是2008年金融危机，削弱了美国的国力，委内瑞拉早就挨打了。

种种原因，使得中国当时跟它的协议虽然价格不高，却是委内瑞拉无法拒绝的。

而在协议签署后，从2009年到2014年全球石油价格大幅反弹，委内瑞拉的财政与还款能力随之明显改善。在这一阶段，中国从低定价原油协议中获利颇丰。

更重要的是，尽管委内瑞拉原油并不适合生产汽油，但正因为其沥青质含量极高，反而非常适合用于生产道路沥青。而那一时期，正好是中国基础设施建设的高峰阶段，对沥青的需求极为旺盛，使得委内瑞拉重油在中国市场上获得了价值。

这也是为什么美国绑架马杜罗之后，上海的沥青期货价格迎来了一波上涨。因为委内瑞拉石油供应的稳定，对于中国沥青价格至关重要。

但这一良性循环并未持续太久。2014年起，在欧佩克与俄罗斯爆发产能战，国际油价再度暴跌后，委内瑞拉经济立刻就完蛋了，中国紧急提供了约100亿美元的贷款，用于维系其基本财政运转，同样以石油偿还。

到2016年前后，中国对委内瑞拉的累计贷款规模大约在600亿美元左右。这一数字，正是互联网上所谓“中国亏损600亿美元”的主要来源。而所谓“亏损1000亿美元”，实际上是将不同年份的贷款额度、重复统计项目简单叠加后的结果，而且没有考虑已偿还份额，是非常不严谨的。

2016年后，中国基本停止了对委内瑞拉的资金援助，中委关系进入存量债务消化期。期间，中委再次签署协议，规定每日对华输送石油，必须超过33万桶/日。

经过九年多的“石油实物偿还”，截止目前，委内瑞拉对华欠款规模大约还剩170亿到190亿美元，仅占委内瑞拉外债的八分之一到十分之一。也就是说，在委内瑞拉的外债结构中，中国并不是最大的债权方，甚至连“最危险”的那一档都算不上。

看到这里，很多人会产生疑问：

难道委内瑞拉这几年，只是在还中国的钱？

事实确实如此，原因也非常简单。其他债权人要求的是美元还款，而委内瑞拉财政崩溃，拿不出美元。

手上唯一值钱的东西，就是地下的重油。中国可以接受石油抵债，其他债权人不接受。

这就是为什么中国的债务是有保障的。

## 02

在2018年委内瑞拉发生主权债务违约之后，其政府债券价格一路暴跌。各大债主纷纷抛售，导致面值100美元的委内瑞拉国债，市场成交价一度仅剩6.5美元，几乎被视为垃圾中的垃圾。

然而，局势在2025年10月出现明显转折。特朗普公开证实，已授权中央情报局在委内瑞拉开展秘密行动之后，委内瑞拉政府债券价格迅速反弹，短时间内上涨超过100%，从此前的10.26美元跃升至19.73美元。

随后，在1月3日宣布抓捕马杜罗的消息传出后，委内瑞拉国债价格进一步上涨至30.18美元。

简单计算，如果在10月购入委内瑞拉政府债券，短短三个月，账面回报率就可达到约300%。

这一轮债券上涨的逻辑并不复杂。资本的本质是逐利的，逐利的前提，是安全感。只有当资本认为自身利益具备现实保障时，才会重新进入高风险市场。

美国动手，让资本市场觉得，自己的利益有特朗普撑腰，有保障。

从这个角度看，美国对于委内瑞拉的侵略不但没有摧毁委内瑞拉的偿还能力，反而使得其重新获得美国资本的青睐，信用风险预期与基本面同步改善，其债券价格从票面价值的6.5%反弹至约30%，意味着市场对其违约担忧显著下降。

只能说，太幽默了。

美方的军事行动，并没有让持有委内瑞拉债券的中国遭受经济损失，反而抬升了中方手中委内瑞拉债券的市场价值。

看到这里，往往会有人提出质疑：美军都已经到门口了，委内瑞拉凭什么还要优先偿还中国的债务？

必须指出一个更加冷酷、也更关键的现实问题。

美国本就是全球主要石油出口国，对外石油出口规模早已超过委内瑞拉。在自身石油长期供给过剩的背景下，美国能源企业没有动力，大规模消化委内瑞拉原油。

委内瑞拉原油品质极差，属于超重质原油。除墨西哥湾沿岸少数几座专门改造过的炼油厂外，美国本土几乎没有炼厂具备长期处理委内瑞拉原油的能力。

这决定了，美国即便掌控委内瑞拉，也无法通过自己吃下石油来完成利益闭环，只能将其卖出去。

根据数据显示，2025年11月，委内瑞拉石油出口量约为92.1万桶/日，其中约80%——也就是74.6万桶/日，将流向中国市场。

而反过来看，委内瑞拉仅占中国石油进口总量的约4%。换句话说，中国对委内瑞拉极其重要，而委内瑞拉对中国则并非不可替代。

如果美国想要债务重组或榨取价值，必须把委内瑞拉的石油卖出去。而在现实条件下，能够大规模消化委内瑞拉石油的买家，只有中国。

因此，所有围绕委内瑞拉的债务重组方案，都绕不开中国市场。只要中国的债权得不到基本保障，任何债权人都得不到保障。

## 03

中国的发展模式是建立在超大规模工业体系之上。这种体系决定了，中国对于全球原材料市场的控制。我买你的石油，你的石油就是黑金，我不买你的石油，你的石油就是地上的一滩烂泥。

无论委内瑞拉政权掌握在马杜罗集团手中，还是由反对派接管，他们最终都绕不开一个极其朴素的问题——石油到底卖给谁。

对于委内瑞拉这类资源型国家，中国市场本就极为重要。

这个问题并不取决于意识形态，也不取决于外交口号，而是取决于产业结构、炼化能力和长期需求。

只要不像利比亚那样长期内战，将生产设施彻底打爆，中国的资产损失就不会放大。

这也是美国今天的问题，如果美国还有工业，他自然可以赢家通吃，但是在长期去工业化之后，哪怕取得如此巨大的胜利，美国也需要向中国让步。

就像稀土行业，中国掌握的，并非稀土原材料，而是产业链，美国本身不缺稀土，但没有加工能力，才会被我们卡脖子。

只要委内瑞拉的石油，最终仍然卖给中国，中国的债权、安全与利益，就始终处在一个可控区间内。
