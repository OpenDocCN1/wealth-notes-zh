

# 美国为啥暂缓对伊朗动手?

260120 猫哥
整理：公众号懒人搜索，懒人专属群精选
懒人微信：lazyhelper1

![](img/a5ffae14135a2ab9fab11d2fc65caa43_0_0.png)

从北京时间1月15号6:15伊朗宣布关闭领空开始，全球吃瓜群众就倒吸一口凉气，睁大眼睛盯着美以接下来会有什么大动作？

是对伊朗再来一次大规模空袭，还是复制委内瑞拉的斩首行动？

结果，没想到的是，川普刚把刀架在伊朗脖子上，居然又收回去了。

先复盘几个重要节点：
- 北京时间15日11:15左右，也就是伊朗宣布关闭领空5小时后，伊朗又宣布重新开放领空。
- 傍晚19:00左右，中伊外长通话。
- 到了晚间，消息确认，美军打击伊朗的桥头堡卡塔尔空军基地降低警戒级别。
- 最后在北京时间16号早上，川普正式宣布暂缓对伊朗发动军事打击。

那么？为什么川普临阵会来个猛踩刹车呢？

个人判断，最核心的原因，是美国的军事打击计划流产了。

我们要清楚的是，本次军事打击伊朗的计划，实际上就是想趁伊朗通胀内乱之际，煽风点火，大兵压境威胁军事打击，然后复制抓捕马杜罗的斩首行动，快速给伊朗来个改朝换代。

不过这个计划，有个前提，那就是伊朗得乱，得大乱才行。

而结果呢？

这场席卷伊朗全国的内乱，半个月就被扑灭了。就在伊朗关闭领空前1天，伊朗方面就宣布已经平息内乱，完全掌控了国内局势。

所以，事情到这，还玩个登儿啊？

军事打击计划的前置条件已经发生变化，自然后续动作就要调整。

川普是个商人，不是宝剑出鞘必见血的战争狂人。

大家一定要清晰地认识到，美国现在根本就打不起大仗。

它的打击选项只有3个：经济封锁、空袭和斩首行动。

对伊朗的经济封锁，已经无以复加，能打的牌太少，最多就是我们看到的，把制裁的大棒伸向第三方。

而空袭呢？

它又做不到量大管饱，只能执行定点空袭。

毕竟舰艇飞机全球调动，那是烧石油，但空袭依托的是导弹，上游稀土还被我们卡着脖子，一梭子放完，后续补充多少，产能是否能即时跟进，都需要打个问号。

去年5月，美以搞了12天空袭伊朗就草草结束，其中一个重要原因，就是以色列导弹库存低于警戒线，后续补给跟不上，只能见好就收。

而且大家是否见过，仅仅只通过空袭，敲掉一些重要设施，就能把一个政权拿下的案例吗？

其次，川普现在的重心是格陵兰岛和委内瑞拉石油这2个优先级方向。

在格陵兰岛方面，现在面临欧洲的压力正在增加。虽然德、法等国像过家家式的派出军事人员到格陵兰岛，总人数一个教室都坐不满，看似象征意义。但实际上代表的是一种政治上的表态，如果川普真的用动军事力量去夺取格陵兰岛，那么与欧洲的关系将出现重大裂痕，后续走向就变得不可控。

而在国内方面，石油巨头并不鸟川普的投资诉求，搞得川普有点心烦意乱。

所以，如果中东一时半会儿被伊朗牵制住，那会影响全盘计划。

至于林肯号航母还要一周时间抵达中东，以色列防务体系还需要升级等原因导致暂缓，我认为都不是核心原因。5月份美以空袭伊朗，周边军事准备比这次更充分，也就12天了事。

说穿了，川普本轮威胁军事打击伊朗，完全就是一次“偷鸡”行为，既然伊朗已经收拾完国内局面，那就失去偷鸡的意义，自然而然，局势就会降温。

再说伊朗方面：这次伊朗能够死里逃生，有2个核心因素：
- 其一，伊朗能够迅速扑灭国内骚乱。当然也证明，伊朗军政的基本盘还是稳定。
- 其二，伊朗警告周边国家还是起到了作用。伊朗目前公开信息是手握2000枚导弹，如果往阿联酋、卡塔尔、沙特的美军基地砸下去，来个鱼死网破，大家都还是心虚。

这点，在去年5月美以联手空袭伊朗，伊朗是没有明目张胆地发出类似警告信息的，这次估计看来是真急了。

那么，在扛过这轮危机后，伊朗接下来该怎么办呢？

说3个观点：
- 第一，短期伊朗现在还不能掉以轻心，要防止美国搞以退为进的把戏，突然攻其不备来个斩首行动。毕竟有马杜罗这个成功案例在前，眼下最好的动作就是复制粘贴，成本低，见效快。
- 第二，伊朗要把矛头锁定对准以色列。
这次伊朗威胁警告周边国家，给接下来对抗美以提供了一个新思路。那就是把力量集中，砸向美国攻其必救的以色列。

试想，伊朗要打美国，太远打不着。面对美军的空袭，又毫无办法。唯一的优势就是家里导弹无人机还不少，而且自己可以生产。

说实话，威胁警告周边国家，只是博弈的一种考量，真动起手来，难道不担心这些国家同仇敌忾吗？

所以，最好的办法就是把导弹无人机对准以色列。

这么说吧，以色列的防空体系再强悍，也受不了来自伊朗的几轮饱和式攻击，在这点上，前期战果已经证明，只要上量，还是能够突破以色列的多层防空体系。

以色列战略纵深太小，2000枚导弹来个饱和式攻击，外加无人机，我觉得以色列基本也就残血了。

实际上，这才是伊朗手上最大对美以的威胁，内塔也并不是完全没有感觉得到这点，后面就看能不能用好这张牌。
- 第三，归根结底，还是要解决国内经济与民生问题。
这次伊朗被逼入绝境，起因就是国内通胀导致，才让CIA、摩萨德有机可乘，如果不解决国内经济问题，这个雷永远会悬在头上，随时可能再爆。

而要解决经济问题，现在唯一的选择就是向我们彻底靠拢，放弃不切实际的亲美想法。

对我们而言，虽然伊朗和委内瑞拉都有石油，但情况不一样。

委内瑞拉太远了，我们够不着，而且它的地缘政治影响远远没有伊朗重要。

伊朗地处亚欧大陆节点位置，在地理上很重要，牵扯的地缘利益非常复杂。不仅涉及中东，还影响里海、中亚、巴基斯坦等。

所以，哪怕伊朗有些小心思，但我们处于整体战略考虑，也不可能坐视它轻易就被美以颠覆。

所以，只要伊朗迷途知返，不再犹豫，积极选择与我们合作，我们还是会拉上一把。

只不过，现在问题的关键是，伊朗在经此一遭后，内部会不会统一思想？

2021年，我们就和伊朗签署了涉及4000亿美元的中伊投资协议，计划在25年内向伊朗投资4000亿美元，其中约2800亿用于石油和天然气领域，1200亿用于基础设施等项目，如港口、铁路、通信技术、安全合作等。这是伊朗摆脱经济困局的一剂良药，但可惜的是，之前被伊朗国内的各方利益阻挠，给生生搅浑了，这里包括革命卫队、教士群体等。

接下来，要挽救伊朗国内经济民生，解决它的财政困局，就只有切实履行这份协议一条路可走。

对于伊朗而言，它就是救命稻草。只不过，也需要伊朗国内垄断势力愿意把利益让渡出来才行，毕竟我们不是慈善家。

综上所述，伊朗当下的危局，说穿了完全是自己作出来的结果。

安全上放弃了自己小兄弟，坐视抵抗之弧崩盘，经济上长期在中美之间犹豫不定，这才酿成今日之祸。

虽然现在喘了口气，但前途仍然很堪忧。哈梅内伊年龄太大了，他现在还在，能压得住场面。如果身后事交代不清楚，仍然没有解决国内经济民生问题，那未来发生更大的内乱是大概率。

接下来就看伊朗内部能不能有壮士断腕的魄力和动力了。趁现在，痛定思痛，果断做出决断，否则，当下这一幕，未来随时会再发生。
