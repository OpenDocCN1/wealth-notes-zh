

# 牢A是怎么安全回国的？他的贡献到底有多大？

2024年1月17日，斯奎奇大王（牢A）现身直播间，证实了他回国的消息，直播间瞬间涌入了20万人。他到底遭遇了什么样的危险？又是怎么回国的呢？

关于牢A到底是怎么回来的，这几天各种传闻甚嚣尘上。有人脑补成了好莱坞大片，什么龙组接送、战狼护航、大使馆临时办护照，甚至还有说是中国加拿大达成秘密协议，牢A是蹭加拿大总理访华专机回国的。这些说法，完全不靠谱。巧了，我刚好有一点内幕消息。牢A的回国，并不是在1月13日《纽约时报》点名牢A之后，而是在此之前。也就是说，在《纽约时报》文章发表之前，牢A已经跑路了，所谓14日回国，纯属烟幕弹。因为牢A提前预埋的报警器开始报警了。

说实话，虽然牢A揭露了美国的斩杀线，但美国政府一开始还真没把牢A当回事，他们听不懂中文，也不屑于去理解“斩杀线”“长生种”“白羽人”这种中国亚文化。真正对牢A动杀心的，是那些“高华”群体。

这些高华大都是过去40年间因为各种原因跑出去的。但是呢？这些丧家之犬没法真正融入美国，中国又回不去，这帮人除了一部分能吃美国狗粮之外，剩下的大多数人，都是在干各种移民中介和留学中介的生意，利用信息差来赚中国人的钱。为了增加潜在客户，这些人过去十几年在中国网上兴风作浪，拼命夸赞美国，诋毁抹黑中国，通过各种方式忽悠中国人卖资产、撸网贷之后润美，然后乖乖把钱给他们。

牢A的视频，就像一把尖刀，精准地挑破了这层精心编织的滤镜。润美的中国人为啥润？投奔民主都是扯淡的，本质上还是想改变命运、阶级跃升。但如果美国遍地斩杀线，去了之后看个病就被斩杀，那谁还愿意润？牢A这不是在直播，是在砸那帮移民中介的饭碗。断人财路，如杀人父母，你说这些高华能不恨他么？

早在去年12月份，就有高华在有组织地人肉开盒他了。不得不说，牢A还是很警觉的，早在直播之前，就预设了4个假名字假手机号假地址，如果这些信息被开盒，那就能起到报警器的作用。本来吧，牢A的想法是，这样就算这些假信息被开盒，他也是安全的，事实上，高华们开出的信息都是假的，虽然牢A的假地址收到了子弹邮件，但不会给牢A造成危险。但是到了1月份，形势急转直下，牢A的真信息也被开盒了，包括姓名、地址等等。还好，真信息混合在假信息之中，高华也搞不清到底哪些是真的。这些高华虽然有点势力，但说白了也只是一群乌合之众，没有执法权，更没有调动美国国家机器的能力，他们只能靠私家侦探和华人圈子慢慢去核实，而这也给了牢A最宝贵的窗口期。

牢A喜欢交朋友，在润人圈也认识人，得知自己的真实信息被开盒之后，马上就意识到自己危险了。就在这个时候，发生了一件大事，某大官媒发了一篇关于斩杀线的文章。这是一个极其强烈的政治信号，这不仅仅是认可，更是一种态度。要知道，西方资本主义对意识形态的敏感度，远远超过我们。当一个社会主义国家的留学生，用一套逻辑严密的理论去解构美国社会的顽疾，还获得了中国官方的认可时，在那帮美国政客眼中，到底会认为这只是一个普通留学生的吐槽？还是来自东方的意识形态进攻呢？不用我说了吧？所以，牢A的斩杀线理论，必然导致美国意识形态机器的剧烈反弹，也必然危及牢A的安全。这一下子，牢A就危险了。

FBI上门还好，起码还能走走司法程序。但如果使阴招，那可就危险了。毕竟美国人是有前科的。不少读者应该还记得2020年的时候，华人女作家“纽约蓝蓝”写了个《疫情中的纽约人》日记，展现美国拉胯的抗疫措施，然后呢？2020年3月27日，纽约蓝蓝突然就遭遇了车祸，不幸去世。为了不重蹈纽约蓝蓝的覆辙，牢A当机立断，跑路。

至于牢A是不是被国内特工护送回国的，我负责任地告诉大家：绝对不是。中美关系如此微妙，直接派人在美境内执行任务，一旦暴露就是严重的外交事故。我们国家行事，向来是低调安全，绝不会授人以柄。真正给牢A回国提供帮助的，是一位国内退役军人朋友，帮牢A策划了整个回国的流程。包括用他人身份寄送行李（防止高华察觉）、变换IP（制造还在美国的假象）、释放假信息烟雾弹等等，都是这位朋友和牢A一起策划的，整个流程既严密细致又合规合法。甚至连机票，都是出发前一天订的，为此多花了上千美元。当然，这个流程中最关键的，还是牢A去机场的路程。

为啥？因为牢A真实信息被开盒之后，在牢A家周围，也有不明人士盯梢了，牢A也不确定自己的航班信息有没有被开盒。如果去机场的路上被绑架，那就麻烦了，安保必不可少。为此，牢A的朋友帮他雇佣了美国一家PMC公司（私人安保）护送他去机场。不得不说，这就是“资本主义优越性”，只要给钱，别的都无所谓。至于牢A给美国形象制造了多大打击，PMC不管。

这中间还发生了一个极度惊险的插曲。在接牢A的时候，一开始牢A设定接头地址是假的，但还没等保镖抵达假地址，就有人冒充保镖要接牢A了，还好牢A并不在假地址，只有一个朋友，最后假保镖因答不上接头暗号而失败。如果牢A上了假保镖的车，后果不堪设想。这也充分说明，牢A真的已经被有组织地针对了，他的处境非常危险。为了避免在出境的时候被找茬扣下，牢A在朋友的提醒下，含泪删除了手机里所有的小视频，这也导致牢A的“小故事”彻底变得死无对证。还好一路有惊无险，牢A总算坐上了一天只有一班的西雅图直飞上海航班，顺利回国。

回国两天后，美国那边才反应过来，《纽约时报》和《经济学人》几乎是前后脚刊登了关于“斩杀线”理论的深度报道。这是中国亚文化第一次以如此具备攻击性的姿态，被摆上了美国统治阶级的案头。《纽约时报》这篇文章也是个高华写的，名叫袁莉，原是新华社记者，后来叛逃美国，成为长期活跃在反华舆论一线的马前卒，和NPR的冯哲芸、华尔街日报的邓超、纽约时报的肖慕漪一起，并称四大反华女记者。

在文章中，袁莉把牢A称为“中国宣传机器的一员”，是带着抹黑美国的任务而来的间谍。袁莉写这篇文章，就是想把事情闹大，让美国官方出手干掉牢A，借刀杀人。美国的动作也算快，报道刊发第二天，就有不明身份人员去牢A的公寓敲门了（牢A的室友证实了）。但房子里早已人去楼空。这个时间差，让牢A在这场生与死的竞速中赢了半个身位，在最后关头逃出生天。

## 二

牢A回来了，虽然没拿到学位，但毫无疑问，他已经不需要学位来证明自己。为啥？因为他干了一件前无古人的事情——以一个普通个人的身份，代表社会主义阵营，向资本主义阵营发起了一次史诗级的意识形态反攻。过去几十年，社会主义阵营在国际舆论场上一直处于被动挨打的局面。西方构建了一套完美的二元对立话语体系：社会主义 = 贫穷落后。资本主义 = 自由繁荣。这套逻辑像思想钢印一样，深深打在一代全世界人的脑海里，当中就包括很多中国人。但是呢？牢A出现了。

牢A这家伙啊，虽然是个00后，但堪称人文社科领域的天才，既能深刻洞悉美国社会的分裂隔离和淘汰机制，又能拥有通俗有力的表达能力，持续高强度直播输出，用充满细节又符合逻辑的故事，把美国的真实一面展现给全体中国人。牢A以一人之力，超过了中国社科领域无数专家教授，在过去几十年对美国形象打击之和。如果谁不服气的话，请看一看，同时登上《求是》《纽约时报》《经济学人》的成就，谁能做到？

为啥过去的社科专家做不到呢？很简单，他们搞研究的出发点，是用来扬名谋利评职称的，他们会用晦涩的语句总结出一套套看起来高大上的理论，凸显自己的专业性和严谨性，只要领导不明觉厉就行，而不在乎老百姓看不看得懂。现在呢？牢A把目光转向了人民，他没有用生硬的说教，而是用一个个鲜活的、甚至带着血腥味的案例，给资本主义重新贴上了标签：不把人当人、社会达尔文主义、系统性剥削。讲故事的过程中，还穿插了插科打诨的小故事，在群众的喜闻乐见之中，把美国的底裤扒了下来。

这是自从厨房辩论后，社会主义阵营对资本主义阵营最漂亮、最深刻、最具有穿透力的一次反击。当年，尼克松和赫鲁晓夫那场著名的“厨房辩论”，美国人用洗碗机、彩色电视机和琳琅满目的消费品，确立了资本主义生活方式的绝对优越性。而现在呢？牢A告诉全世界，美国，是一个没有兜底机制的社会，更是一个将无利可图的国民视为“负资产”并进行物理清除的庞大机器。如果说以前的意识形态斗争是比“谁过得更好”，那么牢A提出的“斩杀线”理论，则是在灵魂拷问：“到底什么社会制度真正把人当人？”当这个理论开始引起美国普通人的共鸣，当人们开始思考为什么看不起病就得死、为什么流浪汉会消失时，它就已经动摇了资本主义制度合法性的根基。这才是让美国统治阶级真正感到恐惧的地方，这哪是什么抽象直播啊，分明是认知战。

某种程度上说，《纽约时报》那篇文章，就是美国意识形态机器触发了报警。如果牢A不跑，接下来的事情，用脚趾头想想都知道，要么牢A中枪“自杀”，要么被抓，然后被逼在电视镜头前痛哭流涕，公开承认一切都是编造的谎言。还好，跑得足够及时。

站在中美博弈的角度，牢A这次算是凯旋归来，立下大功。
- 第一，牢A可能直接影响了美国从中国吸血。众所周知，美国经济的很大一部分活力，来自于全球吸血，其中中国富裕阶层和中产阶级的资本外流占据了相当比例。而这些人之所以愿意变卖北上广深的房产去美国，是因为他们心中有一个虚幻的“美国梦”。牢A的视频，对这种心理预期产生了毁灭性的打击。他让那些原本打算卖房润美的人，不得不停下来重新审视：我去了美国，会不会就是视频里那个睡大街的？我会不会因为叫一次救护车就破产？这不仅仅是舆论战，这已经上升到金融战的层面了。
- 第二，牢A改变了中国人。牢A本身就是年轻人，他的粉丝也多是00后、90后这一代人，牢A的直播，让他们对资本主义的本质有了极其深刻、甚至可以说是透视级的理解，这是一种集体性的认知觉醒。这些人，迟早会有人走上中国的政治舞台。当这群读着“斩杀线”理论长大的人开始主导中美博弈时，他们的认知逻辑将是完全不同的，决策思路也会有深刻改变。这种改变，其战略价值无法估量。

牢A回来了，但这并不是故事的终点，而是新篇章的起点。牢A他天生就是意识形态战神，是卓越的辩经大师，甚至社科版本的钱学森。让他去当医生是资源的极大浪费。在未来的舆论战线上，我们需要更多像牢A这样的人。他们懂西方，但不媚西方；他们有逻辑，更有立场；他们能深入敌后的街头巷尾，也能站在理论的高地上高屋建瓴。

牢A的安全归来，标志着中美在认知领域的攻守之势，已经发生了根本性的逆转，也标志着美国投入无数的人力和美元，在新闻界、法律界、教育界、经济学界培育无数的间谍打造的认知铁幕，彻底破产。当然，这些人肯定会反扑，牢A回国之后不意味着安全，一定会遭遇各种栽赃、污蔑和抹黑，未来牢A出现什么丑闻和纠纷，一点也不奇怪。对于牢A来说，他的战斗，才刚刚开始。
