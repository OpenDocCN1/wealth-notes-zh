

# 印度正式介入缅北

260109 猫哥

整理：公众号懒人搜索，懒人专属群精选懒人微信：lazyhelper1

![](img/324b0a20d7c64b7aa9757d8196eb9ff6_0_0.png)

前段时间，《硅谷时报》披露了一则重磅消息：印度和缅北的克钦武装，签订了秘密协议，用武器换稀土，印度正式介入缅北。

这对中国而言，是一个严峻挑战。那么，这份秘密协议到底怎么回事？

《硅谷时报》不是大媒体，印度官方和克钦军官方也对报道一概否认。

一开始，我觉得是假消息。但深入了解后发现，早在2025年9月，《路透社》便报道过，印度有意和克钦邦签订一份“稀土供应”协议。

除了《路透社》，一些缅甸主流媒体，比如《缅甸时报》、《伊洛瓦底新闻网》也进行了报道，“缅甸商务部”的官网对消息进行了转载。

2024年末，印度官方还曾组织一个考察团，前往克钦军控制区考察。

2025年9月，印度官方收集了一些缅北的稀土样本，进行分析和试验。

有大媒体和缅甸官方机构背书，印度官方还进行过考察和样本收集，这份秘密协议，大概率是存在的。

协议的内容，主要有两项。

- 第一，是稀土供应。

中国限制稀土出口后，印度急于寻找新的稀土来源，而缅甸稀土资源丰富。2024年，缅甸稀土产量3.1万吨，是全球第三大稀土生产国。

这3.1万吨稀土，几乎全部产自缅北，绝大部分在克钦军控制的八莫县和奇贝县，稀土也是克钦军的重要财源，双方一拍即合。

印度获得稀土，克钦军拿到银子。印度的银子，对克钦军很重要。

特朗普上台后，削减了对“缅甸民族团结政府”（也就是反对派）的援助，导致缅军战局逆转。本来战局对政府军极端不利。

来自美国的援助减少后，政府军不断收复失地。克钦军想稳住阵脚，得开辟新财源，和印度签订稀土供应协议，就锁住了一个长期客户。

开过公司的人，都知道锁定一个长期客户，对现金流的帮助有多大。

为了运输稀土，双方计划修建两条公路，连通克钦军控制区和印度东北部，一条从克钦军总部所在地“拉咱”，到印度米佐拉姆邦；另一条，从奇贝到印度那加兰邦。

- 第二，是军事援助。

克钦军不傻，知道在如今的世界局势下，自己手中的稀土是一个大筹码。只换一点银子，太不值了，要尽可能把稀土这个筹码最大化利用。

克钦军缺装备，缺一切与战争相关的后勤物资。

在克钦军的要求下，印度同意，向克钦军提供武器装备以及后勤物资。当然，为了避免刺激缅甸政府，大概率只提供轻武器，不太可能提供重武器。

印度的武器不是白给作为交换，克钦军要帮助印度打击分离主义组织，也就是印度东北部的武装分子，这些组织在面临打击时，经常跑到缅甸，令印度政府十分头疼。

克钦军如果把他们“绑送”给印度政府，他们逃跑的难度就大大增加了。同时，克钦军还得在领土问题上“让步”。

缅甸和印度存在领土争端，有一些争议地区，理论上属于克钦军“声索范围”。

印度要求，克钦军对争议地区“保持沉默”。

这份秘密协议，对中国好坏参半。

一直以来，中方担心“缅甸政府”走向我们的对立面，导致西南出海口泡汤。

“同盟军”攻势猛烈时，我们选择摁住同盟军，让他们把腊戌城区（不包括腊戌郊区）交回给缅甸政府，就是担心这一幕出现。

军政府输得太多，急眼了，说不定会主动引入印度、美国等境外势力。

别忘了，在缅甸若开邦，租借当地港口的国家，可不止我们一个，印度也租借了一个。缅甸试图利用印度，平衡中国影响力的心思很明显。

美国和缅甸关系不佳，怎么引入美国势力？

其实，从2025年下半年开始，特朗普已经和军政府改善了关系，解除了一部分制裁。还在外交上，事实承认了敏昂莱的地位。

这么做的原因，还是稀土，特朗普想获得缅甸的稀土，他不在乎意识形态，所以，我们也是没办法。

现在，印度把手伸向缅北，和克钦军签订秘密协议，无疑会严重得罪缅甸政府。缅甸商务部网站和主流媒体转载这个消息，就是官方在表达不满。

军政府近期忙于选举（缅甸正在举行全国大选，军政府毕竟是政变上台，需要走个程序，让自己变得合法），明面上不会和印度撕破脸。

但长远来看，缅甸和印度的关系，很难和谐了，这对我们倒是个好消息。

从坏的方面说，印度体量庞大，它介入缅甸局势，将导致局势变得复杂。

比如，以前缅北的各种停火谈判，都是中国主持，印度介入后，会不会稀释中国影响力？

以前缅北的各支武装，包括克钦军，对于中国的制裁没有太大抵抗能力。中国把关口封几天，限制物资进入缅北，就能让民地武变得艰难。

印度介入后，民地武们的底气会不会变得充足？毕竟有些东西，就算中国不给，印度也有。

原本一道“公安局通缉令”，就能迫使民地武们交出电诈分子，印度伸手进来后，就不那么好说了。

又比如得到印度的银子后，克钦军会不会壮大，发育得比现在更强？

克钦人信奉美国新教（浸信会），二战时期便与美国深度合作，不管它对我们态度如何，骨子里终究是美系势力。

克钦军壮大，缅北战乱就会继续，中缅合作的各种项目难免被打断。

著名的“密松水电站”项目，就曾被克钦军搅黄。和其他武装追求自治不同，克钦军追求独立，假设克钦独立，我们又多了一个邻国。

原本规划中的“印度洋出海口”，只需经过一个国家，克钦独立后变成了两个，谈判难度大增。因此，克钦军的壮大不符合我们利益。

除了克钦军，印度有没有可能和其他武装合作？成事虽然不足，但要败事，绝对有余。缅北这谭水本就浑浊，印度这么一搅，更浑了。

往后，缅甸局势的博弈只会更胶着，西南出海口一事，怕是要多受几分变数了。
