# 若想推銷自己
就別嫌其煩地露臉

假如住在市區裡的集合住宅裡，不認得其他居民的臉並不稀奇。儘管如此，萬一碰上緊急狀況，最好多少認識一下鄰居也是事實。

就心理學而言，見面的次數與親密度成正比。雖非「遠親不如近鄰」，但即使有血緣關係，不見面當然也會疏遠。因此，商場上有想接近的對象時，只須多多露臉。當然若是推銷的話，對方可能會挖苦地說：「哎呀，你又來啦。」但比起不露臉的競爭對手，確實在對方心中留下印象。

不過，假如對方是異性，即便是公事也會持有戒心，最好稍微節制一點。這項心理法則中，也有愈常見到討厭的對象會更加討厭這種完全相反的模式，若發覺對方感到困擾，趕緊告退才是明智之舉。
