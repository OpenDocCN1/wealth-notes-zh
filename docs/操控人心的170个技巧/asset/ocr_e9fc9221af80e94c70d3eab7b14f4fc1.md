# 總是想表達什麼的人
真正的心思剛好相反

![](bbox=[0.14, 0.13, 0.68, 0.41])

個性陰沉的人在年前表現得很開朗是當事人的願望所致，對話也有相同的情形。「我們夫妻圓滿，也受到孩子敬愛……」明明沒問這些事，卻極力表達家庭幸福美滿的人，實際上很有可能受到疏遠，感覺寂寞。

因為如果真的家庭美滿，沒必要口口聲聲說有多幸福。

另外，嘴上老是說「工作忙到沒時間睡覺！」的人，實際上沒有很忙，只是想展現努力工作的樣子給人看。

從翻言語輕重的觀察對方，就能窺見出乎意料的真心話。
