# 總是笑盈盈聽人說話
是因為不想惹對方生氣

![](bbox=[0.74, 0.03, 0.9, 0.14])

總是笑容滿面，善意聆聽對方說話的人，通常個性老實溫和。可是，其中也有個性原非如此，基於強迫觀念才無意識地露出笑容。

譬如歇斯底里的父母養育出的孩子，在成長過程中總是討好父母，免得惹他們生氣。另外，學生時代曾被霸凌的人也會自然地察言觀色，即使長大成人也不會改變，無法自拔。

換言之，總是滿臉堆笑，是不想惹惱對方的防衛本錢。所以，當他面對不用露出笑容的對象時，就會變得很冷淡。
