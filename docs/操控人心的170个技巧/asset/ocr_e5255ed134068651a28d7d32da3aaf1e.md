# 幾個人

在餐廳用餐時，觀察一下誰在何時點了什麼？因為從如何點餐，能瞭解這個人對周遭的適應性。

適應性最高的人，會配合大家點的餐點中最多的那一项。因為覺得：「只有自已點不一樣的餐點太突兀了。『所以等其他人都點了最後才點餐。這種人適應性雖高卻缺乏決斷力，也不會清楚表達意見。

另一方面，不管旁人點什麼，就只點自己想吃的東西的人，適應性較低。這種人我行我素，一旦決定就不改變自己的意見，在團體中經常是不受歡迎的人
