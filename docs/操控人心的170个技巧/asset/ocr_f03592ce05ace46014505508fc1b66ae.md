# 表現很誇張的人
是自以为是的獨善家

運動賽事實況轉播時，你是否聽過播報員感動落淚，驚呼連連呢？乍看之下真是充滿人情味的熱血男兒，但多數情況表現得太過火，播報的內容也沒什麼，大多太過誇張，脫離現實。

換句話說，只不過是被當下的氣氛感染，而繼續
**控制自己的情緇**

而且由於陶醉於自己的表現，沒有餘力觀察周遭的反應。這也是**自以為是，以自我為第一優先的人**。情緒容易被感染，熱情高昇的確有用的價值，但最好記住，這樣的人能否打從心底信任要打上個問號。
