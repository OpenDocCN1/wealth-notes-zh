# 立刻道歉的人心裡輕視對方

![](bbox=[0.73, 0.05, 0.86, 0.14])

知道失敗的那一瞬間能夠迅速道歉的人，在旁人眼中的評價也不錯。然而仔細一想，很顯然這並非深思熟慮後的謝罪。換言之，通常只是反射性地說出「對不起」。總之先賠罪，可以緩和對方的怒氣，也不會降低他人對自己的評價。能夠以此合理的思考行動，可說是非常厲害的人。而且，他背地里輕視對方，也頗有自信：「跟這個人認真爭論也沒有意義」。和老實的態度相反，內心覺得：「是啊，道歉就好了吧？我也是很忙的。」盡是無禮的想法。如果你以為他是老實的青年，可能是個天大的誤會。輕易的賠罪可千萬大意不得。
