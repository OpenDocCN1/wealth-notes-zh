# 愈懦弱的人愈會頂撞人

當場頂撞別人，異常有著攻擊性的人，乍看之下很剛強，不過本質上通常是懦弱的人。這正是懦弱的內核會動。

受到一點批評就無法忍受：「你才糟糕咧！」歇斯底里地叫咄逼人，絲毫不給予反駁的餘地。所以做出如此過度的攻擊性反應，是因為想掩飾自己懦弱的防線本能所致。

相反地，真正強悍的人氣度恢宏，受到一點批評不會動搖。不會為了小事一一頂撞對方，所以不久後他高尚的人格就會受人欽佩。
