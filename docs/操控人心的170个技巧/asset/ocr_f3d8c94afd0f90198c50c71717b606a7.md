# 瞧操心的人也會閉嘴

瞎操心的人在自己的迷惘消除前通常會不斷質問對方。
譬如有個利用知名飯店與航空公司的廉價旅遊行程。怎麼看都是個划算的方案，簡直是撿到寶。

可是，「為什麼這麼便宜……？為了找出原因，不安的人會不斷質問負責人：『為什麼這麼便宜？』、『料理的等級真的跟圖片相同嗎？』、『飛機安全嗎？』
不過即便說明了原因，『真的嗎？』他仍會投以懷疑的眼光。若想讓這種人放心，只須面帶微笑簡單講一句：

「大家都這麼說。」
縱使明知社會上有各種意見，但我們還是很容易認為自己的想法正確，那些持有不同意見的人則被當成「怪人」。

所以，**當知道大家與自己有同樣的疑惑時，當下便會放心。**只要說這句話就能讓瞎操心的人閉嘴。
