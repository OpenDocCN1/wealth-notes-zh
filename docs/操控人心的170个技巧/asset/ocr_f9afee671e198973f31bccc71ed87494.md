# 頑固得超乎常識的人
脫去「束縛」後變成人來瘋

![](bbox=[0.02, 0.0, 0.13, 0.06])

趁著聚會的興頭去唱卡拉OK續攤，入座後一問：「誰要唱第１個？」卻有一股見外的氣

氛。

這時你遞上麥克風說：「你唱、你唱。」也絕對會有人拒絕：「不不，你先請。」邊說邊

用手把麥克風推回來。

這種人絕非不擅於唱歌。反而是抓緊麥克風熱情演唱的人。

不過，「別人勸誘你做什麼时要客氣一下。」這種「傳統父母的教誨」深深扎根，

**認爲不顧別人，爭先恐後是非常失禮的事**。其實很想開口唱歌，也絕不會說：

「好，我要唱！」只能靜靜等待麥克風輪到自己手上。

碰上這種認真的人，就先為他脫去束縛吧。大家唱得興高采烈，牢牢緊閉的人類快樂泉

源的「**本我**」就會探出頭來，使氣氛更歡樂喔。
