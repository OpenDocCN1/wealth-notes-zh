# 奉承女強人

「身為女性的魅力」

比一般男性員工腦筋更靈光，輕描淡寫地迴避大叔們低級的笑話，任何人都另眼相看的女強人若是直屬主管，對一無是處的下屬而言肯定是難以接近的對象。

面對這樣的主管，很多人想要拉近距離時，總是對她積極工作的模樣稱讚：「真了不起！」

但是，假裝佩服她的工作態度並不管用。這種事當事人可是「清二楚」。

與其如此，奉承能幹的女主管「身為女性的魅力」才是最佳手段。

例如讚許她做的美甲：「連指頭都保養周到呢！」或者說：「那個手提包很適合妳喔！」

不妨大肆稱讚看起來最花錢的部分。

女人自己最中意的部分受到稱讚沒有不心花怒放的。能做到這一點，她會覺得你是一個能注意细微之處的下屬而特别关照喔。
