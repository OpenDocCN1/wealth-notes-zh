# 以「不用做」來推動
沒幹勁的人

對於沒什麼幹勁的下屬，很多人覺得激勵鞭策才是上策，這可就錯了。對於沒幹勁的人，採取放任的態度才是正確作法。

譬如醫師勸告「少喝點酒」反而會很想喝，人類存在一種心理，愈是被禁止的事情就愈想從事。換言之，要順勢利用這種心理。

對沒有幹勁的人說：「這份工作你可以不用做。」或「既很辛苦，你可以退出這個企劃。」刻意把他撇開。

他可能會手足無措奮發振作喔。
