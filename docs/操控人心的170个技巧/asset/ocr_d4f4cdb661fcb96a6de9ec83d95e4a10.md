# 想讓對方接受不利條件，得逐漸提高要求的層級

在想讓對方說出「Yes」的場面中，說服方式須費點工夫。有個方法是，首先提出容易接受的小小要求取得瞭解，然後逐漸提高難度。

譬如讓對方答應購買某項商品後，再逐一迫加手續費、運費或是選項。或許做法有點奸詐，這可是稱為「低飛球技巧」的一種說服術。人類的心理是一旦瞭解後，面對不利於自己的條件也難以拒絕。

任何人都有喜歡一貫性行動的傾向。推翻一度答應的事違反一貫性，而且感覺也不好。因此就會接受不利條件。

這種傾向愈認真的人愈強烈，不妨先推測對方的個性再試試這個方法。

附帶一提，在揭示不利條件時，可以採取「我忽然想到」或「差點忘了」的態度。要是企圖昭然若揭，只會招來反感。
