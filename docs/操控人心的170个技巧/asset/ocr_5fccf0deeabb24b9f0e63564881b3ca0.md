# 陪對方抱怨
贏取信任

正如「能言善道者亦善於聆聽」，傾聽別人說話是溝通的基本。不過頻頻點頭稱是只能算是「無害的人」。因此，若想獲得更高一級的評價，之後的對應將是重點所在。

比如說顧客忽然提起：「最近因為孩子的教育問題和老婆起爭執……」那就和他一起抱怨老婆吧。

這個時候先別插嘴，靜靜聆聽。要是他繼續說道：「我老婆堅持讓孩子去補習，但我覺得應該培養運動興趣，讓孩子開心地成長。」「此時，要先肯定對方的意見：「我懂。讀書並不是「切啊。」

如此他會覺得，你不僅聽他抱怨，而且又懂他的心思，這份欣慰將昇華成對你的信賴。

最後假如你也表現出同樣的煩惱：「其實我家也是……」就更完美了。對方會覺得你是有著相同苦惱的夥伴，對你的信賴肯定更勝以往。
