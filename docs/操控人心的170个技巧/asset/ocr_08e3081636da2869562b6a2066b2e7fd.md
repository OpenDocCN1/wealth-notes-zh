# 利用限定的標題
激發購買欲

信步所至的餐廳因客滿而無法入座，偶然經過的店家某種甜點掛出「本日已售完」的牌子碰上這種情形，你是否無論如何也想去那間餐廳，或吃吃看那道甜點呢？

其實，稀有或難以入手的东西更有魅力，能激發欲望。這正是所謂無理要求的心理。

假如想刺激顧客的購買意願，不妨利用「只有現在才能入手」、「限定○○個」、「已售完。等待進貨」等隱藏的標題。這些標題藏有讓原本並不感興趣的商品，變成很想要的
