# 坐不住是「想走人」的信號

儘管嘴上說：「時間還好。」屁股卻扭個不停，上半身也頻頻左右搖晃，就是這個人想離開的證據。

身體左右搖晃，當然是為了移動體重，想回家卻走不了的人會心神不定地頻繁地動來動去。如果目光一直飄向房間入口，肯定是這麼回事。

即便坐著，雙腳卻逐漸朝向入口，嚴重時明明正在談話，屁股卻已經離開座椅了。

若是看到這個「信號」，就別再長篇大論，趕快放對方走吧。

若不這麼做，對方就會認定「來找這個人真是受夠了」，之後無論有沒有時間，他一來就會發出想離開的信號。
