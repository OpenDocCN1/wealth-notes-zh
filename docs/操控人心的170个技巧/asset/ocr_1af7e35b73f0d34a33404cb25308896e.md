# 把下屬叫到自己辦公桌前的主管是想讓對方服從

職場上與主管合不合得來十分令人在意，就算主管也未必是有修養的人。雖然也得看對象，搶先一步對應才能建立圓滿的關係。譬如向下屬下达指示時，「喂！過來一下。」故意把人叫到自己辦公桌前的主管最好謹慎應對。

自己不動卻對下屬頗指氣使的主管，是想向旁人表現自己處於上位。不僅如此，若是大聲說出指示讓旁人聽到，這種傾向更爲顯著。

這種主管簡言之就是權威型，誤以爲能隨心所欲使喚下屬。通常內心是膽小鬼，但在懦弱的另一面，這種人也會滿不在乎地利用立場干擾人事。

如果想要出人頭地，就算麻煩最好還是乖乖站到他的前面。
