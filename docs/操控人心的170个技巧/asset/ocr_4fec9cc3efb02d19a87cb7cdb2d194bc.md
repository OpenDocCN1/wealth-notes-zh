# 若想讓對方如己所願
不妨刻意否定

一般而言與其否定，使用肯定的表達方式能讓事情順利進行。儘管確實如此，但刻意使用否定的表達方式也能控制對方的心情。

「告訴我，若直截了當地追問，一般人反而會口風緊閉，但假如說：『你不想講也沒關係。』對方反而會吞吞吐地開口。

這是美國心理學家欽巴洛命名為『耶魯效應』的逆轉現象。換言之，試著否定自己所希望的事，結果就能如己所願。另外，在否定後加一句：『除非你想～』效果更是加倍。
