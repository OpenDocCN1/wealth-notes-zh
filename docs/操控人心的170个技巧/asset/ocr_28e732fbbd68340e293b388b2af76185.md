# 老 是 說 「應 該 」 的 人

# 最 愛 正 確 言 論

正確言論至上主義者的口頭禪就是「應該了」這一詞。

具體而言「不應該對社長說的」、「那時應該拒絕啊」或「你應該先聯絡啊」等說法，

「應該」這一詞有一種讓自己的價值觀帶有正義的魔法。

可是，無論這些說法是正確的或沒有切中要害，對聽者而言只不過是一指責」。要是太過分，最好先發制人提早對應。

方法非常簡單，做好該做的事別讓他有機會說「應該」。

比如說「社會人士應該服襲裝整齊」，就跟著照做。做到令人無法反駁的地步，讓對方閉嘴即可。

反覆如此自然會令人刮目相看，他將會時時注意你。如此，接下來就由你發表意見了。

「該做的事都做了，還有不滿嗎？」以這樣的態度，光明正大 地提出要求：「下一件工作請交給我。」或「這個週末我要休假。」
