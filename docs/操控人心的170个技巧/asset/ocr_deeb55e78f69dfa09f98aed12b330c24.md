# 說「這是為了你」的人
想要回報

有人老是嘴上說：「這是為了你。」或「我是為你好。」或許當事人是出於好心，可是聽者只會覺得厭惡。

這也難怪，因為強迫的態度與言詞不僅無法說服對方，反而大多適得其反。

這種將自己的意思強加於人的極有自信，總認為自己是對的。

因此，**對於自己的建議要求精神上的回報**，假如不聽勸告事情不順時，他就會得意洋洋地說：「所以我就說了嘛。」

面對這種人應回答：「謝謝。」「是啊。」接下來當耳邊風就行了。總之老實地聽話對方就會滿足。

順帶一提，最好別跟這種人深交。別接受對方個人的勸誘，保持一定的距離吧。
