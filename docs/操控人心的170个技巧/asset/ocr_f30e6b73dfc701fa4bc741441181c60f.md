# 和狂工作時

# 調查他的興趣

對自己與別人在工作上很嚴格的人，當一起共事時工作順利倒還好，一旦狀況那可不得了。因為個性認真頑固，他可能冷言冷語：「我沒辦法和你一起工作！」導致工作毫無進展。

此時，縱使你試圖修復關係向前搭話：「哎呀！最近過得如何？」他可能只會冷冷地回：「幹麼？」如此陷入僵局時該怎麼辦呢？

這時應先調查對方。這種人太多對於某個領域「總是忍不住發表意見」。例如在運動與興趣等領域，擁有堪稱行家的本領與見識。就是他的驕傲領域。

瞭解這點後，就若無其事地把話題帶到他的「拿手本領」。如此，他肯定會如同專業解說員般開始長篇大論。

趁他擡開的心扉尚未關閉前，再提起工作的问题吧。
