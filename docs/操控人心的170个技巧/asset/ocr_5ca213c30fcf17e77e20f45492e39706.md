# 老是提起當年勇
是因為想逃避現實

―我年輕時可是吃足了苦頭。―絮絮叨叨地聊起當年的主管令人頭疼。不少人一定心想：「我聽過幾遍了……」然後置若罔聞。

以前的辛勞與豐功偉業很顯然是三種現實逃避，當事人也十分清楚。儘管如此仍忍不住

談當年，正是**對現在的自己缺乏自信**。

大談以前的功勞，是因為想藉由談論過去的成就讓現在的自己好過一點。另外，無法不

聊過去的辛苦，是想藉由比較過去的自己，來肯定現狀的心理表徵。

的確，這種聽過幾百遍的內容令人討厭，但仔細一想，聊一聊就能恢復自信倒也是個好方法。

雖然稱不上「不聽老人言，吃虧在眼前」，不過別嫌囉嗦，偶爾正襟危坐地傾聽或許也不錯。
