# 拜託麻煩事時
請選秋高氣爽的日子

有些事情明知困難，也必須拜託別人。例如拜託靚靚的好友在婚禮上演說，或是明知休假有預定行程，卻得請同事假日代班。

這種時候就算合掌連聲拜託，對方也有可能不睬。

其實，在緊要關頭向人拜託時天氣非常重要。陰雨綿綿會令人憂鬱，萬里晴空則使人心情爽快，人的心情會被天氣大幅左右。

因此若想要對方接受請求，不妨選擇大晴天。並且最好是溼度低，秋高氣爽晴朗好天氣。好天氣會讓人心情放鬆，平時不會接受的請求也會傾口答應。

對方允諾後就如願以償了。之後就算他後悔為何會接受而想要辭退時，也別忘了提醒他說到做到。
