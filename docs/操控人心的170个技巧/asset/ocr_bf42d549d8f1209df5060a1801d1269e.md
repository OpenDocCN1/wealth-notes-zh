# 從抱怨或稱讚看情緒結所在

和同事飲酒聚會時，工作的話題愈聊愈起勁並不稀奇。平日謹慎不聊八卦的人，黃湯下肚就忍不住批評主管與同事。

假如這時他忽然說：「我很討厭那種吝嗇的男人。」無意中脫口而出的抱怨絕不能漏掉。因為這種發言藏有當事人**也沒發覺的真心話**。

人在談論討厭的人時，投射出自己本身討厭的部分是常見的模式的。這正是所謂的**癮頭**。

口口聲聲說討厭「吝嗇的男人」，當事人極有可能個性十分吝嗇。

反之喜歡的類型，舉出的人必定具有自己缺乏的特質。比如他說：「我喜歡舉止優雅的人」，可見當事人缺乏這種要素，這正是他所憧憬的地方。

當然兩種說法與當事人的情緒並非毫無關係。在想讓人大吃一驚的場面中或許能派上用場，記住不會有損失喔。
