# 受到質問便支吾其詞
就是想隱瞞什麼的證據

有些人受到質問時並不直接回答，而是岔開話題。他並非無法理解問題，而是

# 回答的理由。

例如你問：「資料製作還順利嗎？」
「嗯，另一件快完成了，算是還好。對了，這是前幾天您詢問的報告書……」如此不清楚
回答「順利與否」卻轉換話題時，十之八九並不順利。
先支吾其詞，之後再設法挽回。即使當事人自認巧妙地岔開了話題，這樣含糊其辭卻容易被看穿。
然而，立刻追問並不見得會有好結果。總之先放過一馬，若能挽回就不用追究。
重點是看穿「有所隱瞞」時，就得當心注意。
