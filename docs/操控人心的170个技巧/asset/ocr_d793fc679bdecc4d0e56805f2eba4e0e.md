# 藉由誇張的動作

# 取得對話的優勢

在你身邊是否有人講話時的反應非常誇張呢？

「這麼大隻的狗對著我吠！」邊說邊將兩手大大地張開；「車站前開了一家新店」邊說邊刻意指著那個方向，總之肢體動作都很過度的人。

有些人覺得這真的很煩，但以溝通技能的意義而言卻很優秀。因為比起全無動作的人，這種人說話時傳達給對方的訊息量多得驚人。

譬如以言語表現「5公分的厚度」，和用拇指與食指表示「大約這樣的厚度」，何者簡單易懂必定一目瞭然吧？

換言之，傳遞訊息時動作是必需的，一旦營造出氣氛，對方即使不願意也會被話題拉走，還能取得對話的優勢。

即使情況略顯不利，想氣勢說服對方時將有絕佳的效果。非常值得一試喔。
