# 巧妙利用點頭

# 引誘對方說出「Yes」

善於傾聽的人通常是邊點頭邊熱情地聆聽。「嗯，嗯。」因為他聽話時身體向前傾，自然人滔滔不絕說得更起勁。

如此，自然對對方懷好感，當自己說完換對方開口時，自己也是充滿善意地聆聽。

若巧妙利用這種「點頭」的特點，就能輕易引導對方說出Yes。

換言之，點頭肯定對方的話：「是啊。」、「正是如此。」對方對你也會表現出肯定的態度。這時你可以不經意地切入正題：「下次活動我想用這個提案。你覺得如何？」

重點是聽對方回答時也要熱情地點頭。眼前的對象並不想破壞難得的友好氣氛，即使對方心裡不快，「是啊，我覺得這提案不錯。」他也很有可能回答Yes。
