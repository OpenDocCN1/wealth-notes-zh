# 藉由「反問」迴避麻煩的客訴者

在餐廳裡只不過因為上錯菜就大聲咆哮：「叫店長出來！」稍微受到無禮的對待就怒吼：「你以為我是誰啊！」這些投訴的客人平時就是內心不滿。若遇到這種咄咄逼人的麻煩人物，就採取「反問調行動（Dis pacing）」對應。

假如他威嚇：「你要怎麼解決！此時鞠躬賠罪就是同調。但你不可如此，反而要冷靜地詢問：「那麼您希望我們怎麼做？請具體地說明。」「

如此一來，也許對方會回答：「你連這種事都不知道嗎！這時你依然淡淡地回答：「非常抱歉，我不知道。請您具體地說明。」

表現出如此冷靜的態度，對方也會判斷，此時若要求實質的賠償，可能會吃上恐嚇罪的官司。

重複一再「反問」，再強硬的客訴者也只會擱下狠話離開。
