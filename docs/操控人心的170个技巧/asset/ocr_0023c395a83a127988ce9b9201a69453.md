# 觀察指頭
便可判斷對方是否在說謊

![](bbox=[0.78, 0.05, 0.85, 0.18])

態度與語氣非常有自信，但仔細一瞧手指卻動個不停。尤其若是說大話的人有這種動作，你是否會有種奇妙的感覺？

無論嘴上講得多從容，手指的動作能表達內心。其實他的內心正在與不安奮戰。

譬如在說明新商品與新服務時，如果手指不停地敲桌子，或是輕輕地搓雙手手指，可能被指穿了說謊。
假如被拆穿了該怎麼辦？被指出錯誤時該如何敷衍……？心中的一抹不安使指頭產生無意識的動作。

尤其一段說明結束後，一邊詢問：「您覺得如何？」一邊動手指想必非常可疑。這時候保險起见應「提高警覺」。
