# 憑感覺說話的人
都是靠聯想

在任何事都理性思考的人眼中，憑感覺說話的人可以說是很難相處的對象。

憑感覺行動的人在對話中經常使用擬聲語和擬態語。

例如：

+   - 「蒐集資料手腳要恰怡。」
- 「時間結束前得衝了。」
- 「她今天很閃呢。」

另外，對小事連呼「好棒」，陳述情況時用「感覺不錯」等曖昧的表現也是同樣的人。

這種人的共通點是，談話會隨著心情逐漸脫軌。而且，脫軌倒是還好，說話反反覆覆才麻煩。

原因就是思考的「聯想遊戲化」。
