# 如果最後的場面成功
就能一舉提高好感度

+   『評價：★★★
『效果：★★
『易懂度：★★

總算順利約到中意的女孩子。

可是，預約的時髦餐廳口味比起評價差了一點，好像不合她的口味而有損她的心情。

即便如此也不用因期待落空而沮喪。有一條祕計能在當天挽回局面。

人類有種稱為**「親近效應」**的心理，無關於之前的過程，最後的印象能影響之後的判斷。

像這個例子，在約會的最後帶她去珍藏的夜景景點，說幾句能打動芳心的話即可。

如此一來，比起白天在她心裡留下洶湧的記憶，眺望美麗夜景，被追求的記憶將更加強烈。

當然也會提高對你的好感度。

**結局美滿就饒大歡喜。**在擬定約會計畫時，比起挑選共進午餐的餐廳，最後絕不能

草草收尾才是鐵則。
