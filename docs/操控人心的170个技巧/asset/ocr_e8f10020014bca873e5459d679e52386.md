# 要撒魚餌給上鉤的魚時 須看清時機

一「耐性」  ◎  ★  二「效果」  ◎  ★★  三「意念」  ◎  ★

——在到手前投入金錢與感情，用盡一切手段，一旦得手後突然就不再花費賣工夫。若是絕不

放過獵物的獵人，通常不會撒魚餌給釣到的魚。

可是，應算是用魚餌釣到才發展關係，沒了魚餌兩人的關係就會惡化，這可是明若觀火的事實。

不過，要是給了過多的魚餌，遲早也會不再感激。

要馴服用物質衡量愛情的對象，請先重設為沒有任何禮物的狀態。如此對方的不滿高漲，在爆發前再次注入金錢與愛情。

一旦陷入空腹狀態，就運一片仙貝也能滿足心靈。陷入精神上的飢餓狀態後，此時的禮物會異常甘美。

> 重點是撒餌時要看清時機。
