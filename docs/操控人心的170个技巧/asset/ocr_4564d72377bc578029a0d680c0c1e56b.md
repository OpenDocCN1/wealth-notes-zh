# 只須加上「還是」就能誘導對方

拿皮鞋去修理時，要是店員問：「只要修理嗎？還是順便擦一下皮鞋？」之前明明不打算擦皮鞋，此時是可能會覺得反正都來了也順便擦一下好了？

這正是「還是」這個繫續詞驚人的效果。即使起初沒這個打算，一聽到：「是Ａ嗎？還是Ｂ？」不知為何就覺得必須選擇接在「還是」後面的Ｂ。所以不想加班的時候，不妨說：「這件工作要加班完成嗎？還是…………」如此主管腦中會擅自補上一句：「還是可以下班了？」於是最會回答：「你可以下班了。」
