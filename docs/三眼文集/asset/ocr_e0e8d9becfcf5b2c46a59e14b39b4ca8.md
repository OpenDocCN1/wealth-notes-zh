+   - 创业培训；

# 2、收智商税主要灌四个猛药：

# 猛药一：一定要玩“暴富”；

智商越低越没钱，越想暴富，一打一个准！

> 巴菲特：“大家好，我回报率平均才几个点。”

# 猛药二：一定要制造紧张气氛，加强紧迫感；

“你马上就要错过了”让小白兔的内心慌慌的；

# 猛药三：一定要制造“神话”立标杆，“捡钱”越简单越好！

让小白兔内心上觉得自己不去“捡”这份钱，简直丧尽天良，小心脏一跳一跳的；

# 猛药四：一定要把简单的东西复杂化。

去理发店理发，本来五分钟能解决的事，非要修修剪剪半个小时，收费便“有理有据”。
