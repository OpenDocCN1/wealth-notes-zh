# #经济增长的本质是分工的进步

社会怎么能创造更多财富？
那就是分工，分工越细，生产效率自然越高，同样的劳动付出，劳动生产力自然更大。

比如制造一把锄子，一个人去制造可能要花费1个月的时间，因为既要对木材加工造出锄子把手，又要炼树铁、翻模等造出锄子头，如果再往原材料上游看，甚至要去开采铁矿，可能工期就是以年来计算了。

当分工出现的时候，这一把锄子的效率就高了，从开采铁矿到伐木，再到炼铁、木材加工、翻模、镰敲打磨等都分工开来，n个人一起造一把锄子，同样的时间，每个人同样的劳动付出，所带来的产能（所造锄子数量）就会有大幅提高。
