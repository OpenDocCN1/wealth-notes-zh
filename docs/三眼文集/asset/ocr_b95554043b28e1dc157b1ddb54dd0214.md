# 客观的信息

所以很多人 дальнейшего继续认知提升的问题上更进一步：
“三眼老师，有什么政治经济学书籍推荐吗？”
答案是：几乎没有！

很简单，人性都是要隐藏意图，几乎没有人会告诉你真相，隐藏都来不及，尤其是有关联的人。

比如你的朋友跟你讲话，每一句话都是隐藏的，100%，不可能把真实的东西告诉你，而且要尽量隐藏掉。

只有那些跟你毫无关联的人，才有可能对你讲一些真话。

所以人提升认知最普遍的方法就是跟着“古人”学习，因为没有丝毫关联；
