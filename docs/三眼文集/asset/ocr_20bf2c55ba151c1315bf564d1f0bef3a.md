# 简化与复杂

开悟需要简化；
迷惑即为复杂。

简化属守，属明，属盾；
复杂属攻，属暗，属矛。

知识的妙处在于变化，
即可简化，亦可复杂。

简化，使人得到真相；
复杂，使人得到幻象。

助人，须教人简化之道，简化使人开悟；
捕食，须给人平添复杂，复杂使人迷惑。

世间幻象奇多，真相稀少。

众人多皆沉迷于幻象不能自拔，被捕食却喜乐非常。

可暗可明，可明可阳，
可真可假，源自心性。

# 有所求与无所求

有所求即为自我；
无所求即为忘我。

人有所求时，必被牵制，而受反制，
捕食者变成被捕者而至困兽犹斗；

人无所求时，能慧眼识明，
洞悉世事万局，破除攻守之道。
