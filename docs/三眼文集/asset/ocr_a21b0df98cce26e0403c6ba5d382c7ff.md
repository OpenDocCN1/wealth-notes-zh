# 现代化

# 三改

大组织有三改，股改汇改和土改，都是搞活经济的大利器，区别就在于利器能不能扳得动，太沉的容易闪到腰。股改改的是大户人家的利益，自然不容易动，老股民自然懂；汇改改的是国际大组织规则融合，列强都是硬货，更不容易扳得动；土改，可以！
