# 穿越的和尚

所以，佛道的那么多文字，都在研究“人的思想运作模式”。

科学，只是“运作模式”的一个展现方式而已。

模式研究明白了，看人类社会方方面面才能看透。

把1千年前某个脑子极大开光的和尚或道士，拉到现代社会，人家照样会很牛逼，因为明白“玩人基本功”。

+   1、你为啥在这里锤东西，谁定义你锤东西的；
2、他们是怎么定义你锤东西的。
