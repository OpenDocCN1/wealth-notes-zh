# 1、攻击你城市发展极度不均衡！

社会学角度看，世界发展史就是一部乡村逐步城市化的历史，经济学角度看，就是一部人口集中资源协同演进史，人口与资源向城市聚集中没毛病！

但！这里面有个度的问题，也就是发展均衡与否的问题。

中国是一个经济发展极为不平衡的国家，沿海地区人均GDP达到10万元左右，中等发达国家国家收入水平，而内陆地区大部分城市人均GDP只有两万元左右。
