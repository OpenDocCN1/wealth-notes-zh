# 不gong是常态

财富就那么多，分配的过程一定充满不gong，社会生产力越高，财富创造的越多，资本的力量越大，分配就越不gong平。

一个组织经历了原始资本积累阶段后，资本就会趋向于集中化，马克思说资本来到世间是 shit 胎的，就是因为资本发展到一定体量后就会形成左右分配的力量，让分配的掠夺本质发挥的更充分。

所以先富带后富只能是一个美好的想象。

而且这世界本来就没有什么“合理”可言，无论是穷鬼还是富豪，无论何种分配方式，二者都会觉得不合理，每个人都只站在自身的角度看待问题。

所以集体的组成是通过博弈，而在博弈之上就是权力，任何组织形态的分配都源自于权力的干预。

神州几十年前人与人的差距没那么大，他家有5个鸡蛋，你家有1个，这就算<|message|> 巨大差距了，而高速发展至今，差距是你家有100个鸡蛋，他家可能有100亿个。

马爸爸单凭自身的劳动回报不可能拥有那么多财富，而除了这些看得见的明星外，社会每一个角落无不充满分配和lue夺。
