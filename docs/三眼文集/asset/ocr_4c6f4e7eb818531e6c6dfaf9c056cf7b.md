# 啥叫提振内需？

就是想办法让中下层分配的钱更多，从而让整个盘面流转起来。

如果转不动，富人的N套房子没人接盘，资本家生产的产品没人购买，中下层还没有余粮消费，所有人都 Erwin ，都没有财富增长。

富人与穷人是共生关系，不是对立关系，这一点要记牢。

![](bbox=[0.42, 0.75, 0.57, 0.8])

# 什么是阶层流动？什么是逆袭？

就是每当经济循环转不动了，要搞“重新分配”了，那么主力分配群体就会大概率发生阶层跃升，跟得上就叫逆袭，跟不上就是落队。

分配之门打开的地方，就是逆袭之道！
