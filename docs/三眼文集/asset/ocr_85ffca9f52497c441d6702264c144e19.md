# 宽广与狭隘

人性性的宽广与狭隘只存乎己，而不在外象。

看似投明者不一定就宽广；
看似投暗者不一定就狭隘。

正如道德可以救人的工具，也可是牵制人的武器；
只因攻守皆有所求，捕食者与被捕者皆为所求而活。

正确与错误以己为准则，于外为工具而已。

是非善恶皆有界限，界限愈广，是非善恶愈互相转化，扩至宇宙无非善恶。

# 长短反正

利器有长短，事物有反正。

长短相互克制，
正反相互转化；
生出形、势、情。

得与失即为形；
进与退即为势；
攻守即为现象<|message|>度势。

形势之较量关键在于心性，在于心志，更在于心力。
