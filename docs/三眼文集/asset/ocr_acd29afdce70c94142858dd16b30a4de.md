# 人的痛苦源于结构不足

这就造成一个事实结果：
人的结构越大却越简单，越小就越复杂。
因为越大越接近本源认知，结构越小，你所依存的更高层级的结构就越多，自然变得愈加复杂。
人思想的痛苦就来源于此，在一个小空间里挣扎不得释放。
无论是人的心理、精神、还是依存于外界的生存发展行为。
也就是说，人的痛苦=人结构的不足。

# 认知的界限

所以诸位读到此处应该就会明白，人由于结构的大小，人的认知有一个界限，与人讲话和沟通，想办法让对方明白，这是一个极大的学问，因为你要通过对方认知界限里所能感知的事物去阐述逻辑，才可被对方接受。
人自说自画很简单，但与人沟通却很难。
