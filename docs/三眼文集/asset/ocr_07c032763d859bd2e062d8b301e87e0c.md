# 破解了人就破解了规则

在破解规则上，本质就是如何“破解人”。

在上一篇文章讲过，想要了解一个人就要看清其“边界”。

对于上面的勤奋少年，“边界”就在他嘴里的公司规则上，这就好比观察现如今的中产阶级，他们从小就被锁在一个个“边界”里，锁定在一个个“游戏规则”里，养成 了“良好习惯”。

讲到这，再延伸一下，什么叫“规则的层次”。

定“游戏规则”是 有层次的，层次越高规则越简单，层次越低规则越复杂。

从大到小，规则像俄罗斯套娃。

所谓大道至简。

层次越低，规则越趋向“动物本能”层，人们追求温饱，对人生的渴求只限于临时的快感和生存本能的需要；

层次越高，规则越向“佛道”迈进，人会追求超然于现实的东西，寻找存在的本质。
