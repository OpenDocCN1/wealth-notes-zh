# 经济增长就是财富增长，财富增长就是财富可循环。

无论是你想买房赚钱，还是想创业赚钱，还是依附于某位老板打工赚钱，如果你觉得钱难赚了，那只有一个原因：就是你那个市场交易转起来很费劲了，转不动了，交易少了，当然赚钱费劲！

经济危机本质就是：左手一堆东西，右手买不动。

这个右手，就是百姓！
