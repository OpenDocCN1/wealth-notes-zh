# 陈昌文解读《论语》：

臧武仲这个人以智慧著称，他在鲁国做大夫，得罪了权臣孟孙氏，于是设法逃回了自 己的封地防。

这个防地，是鲁国国君封给他的，于是他写了一封信给国君，大意是，我 是有罪的，但罪不至于死，我这个封地，我还要，您把这个封地封给我的 后代，我自己会离开鲁国。这是据地自守的意思，您给我个面子，封地给我 后代，我离开鲁国，如果不您给我面子，休怪我铤而走险了。表面看起来很 谦虚、卑谦，实际上在要挟君主，所以，孔子说，虽然说起来不是要挟君主， 但是我不相信啊。

这里有个做人问题，有些人就是聪明，有才干，但是他们也容易拿着自 己的聪明、才干跟人谈条件，谈筹码。跟您合作的时候，虽然也能好好合作， 但是，他总是要摆一个富，如果您要不跟我合作了，我手里可是有您的罪证， 我有能力把您摘掉，我知道您的一些什么秘密，我搞破坏也还是行的。这种 人在现实社会中，是有一些。

我当年招聘了一个程序员，后来由于一些缘故辞退了他，他就利用自己 的技术，锁定了我们的源代码，也让我们开不了服务器，要挟要满足他一些 过分的要求，否则我们不要正常工作了。

有这种思维的人，即便是再聪明、再厉害，总是会踩到坑的。这属于做 人没有诚意，任何人知道他有这个心思，都不愿意跟他合作。这种人只为自己， 不会顾全大局，喜欢要挟事主。

这臧武仲的封地，本来就是国君封给他的，国君要要回去，就要回去， 要继续封给他的后代，就封，他不应该据地求封。这个行为跟后来的韩信据 守齐地，要求封假齐王是一个道理。韩信打下了齐地，派使者对刘邦说，您 现在封我 一个假齐王，我好镇守齐地，大家才服气我，结果惹得刘邦破口大骂，
