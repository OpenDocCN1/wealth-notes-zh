# 18、闷声发大财，不要大张旗鼓地找自己打不过的对手打

原文

> 鲁人为长府。闵子骞曰：“仍旧贯，如之何？何必改作？”子曰：“夫人不言，言必有中。”

陈昌文解读《论语》：

鲁国人要改建长府，把这个长府修建得更好些。闵子骞说，就照原来的样子吧。原来的样子如何？为什么非要改建？孔子说，闵子骞这个人话很少，但是一说话，就说对了，说到点子上了。

鲁昭公这个人，想要修建长府。鲁昭公被季氏三家权臣欺负，心里不爽，就修建长府，打算大张旗鼓的政变，或者说要攻打季氏等权臣。闵子骞是微言大义，您不要那么大张旗鼓的，您就跟什么都没变一样，为什么要大张旗鼓的改建长府呢？这样让大家都知道您要干什么了。您实力也并没有那么强大，您能干得成？还不如一切照旧。

一切照旧有两个意思，打不过别人，就别打，您仍然当您的君王。权臣再厉害，也是权臣，他现在也不能把您怎么样。如果您非要大张旗鼓的搞季氏，对方狗急跳墙，可能适得其反。二是，您即便是想攻打别人，也要偷偷行事，不要大张旗鼓，别人都准备好了呢？您还打什么呢？要攻其不备。

孔子说，闵子骞这个人，平常不说话，一说话，就说透彻了本质，说到核心点了。
