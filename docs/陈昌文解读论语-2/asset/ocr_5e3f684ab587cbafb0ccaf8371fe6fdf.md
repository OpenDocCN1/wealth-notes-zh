# # 27、听到了就去干

# ## 原文

冉有问：“闻斯行诸？”子曰：“闻斯行之。”

# ## 陈昌文解读《论语》：

冉有问，听到了就去行动吗？孔子说，听到了就去行动。冉求这个人性
格懦弱、畏畏缩缩，做事本来就慢，喜欢想。

社会上大部分人都这个毛病，思考的很多，行动很少。于是冉求问孔子，
是不是听到了就行动，这种人呢，可能还想得到到一个回复，多想想。要是孔
子回复他，多想想，他就会一直想，一直少于行动。孔子根据冉求的具体性
格特征，给他的答复是，立刻行动。

其实一个人的行动力是不是强，自己清楚；一个人是不是优柔寡断，自
己想想，也清楚。如果您是一个行动很少，天天老是思想，喜欢听课，喜欢看
到别人是不是有新观点，喜欢问东问西，但是没有什么具体结果、成就的人，
说明您就是一个优柔寡断、没什么行动力的人。这种人，就要立刻行动。

成功来源于不断地行动，不断地干活，而不是只是在那里想，在那里学习。
行动多了，很多经验您就有了，很多技巧您也就学会了。实践出真知。您天天都想，
而不行动，您想的其实与真实的世界是有很大出入的。
