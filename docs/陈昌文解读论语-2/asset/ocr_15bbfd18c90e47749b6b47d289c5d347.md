# 陈昌文解读《论语》：

孔子说，如果所有人都讨厌他，您也别把他直接否定了，要考察具体情况，了解事情真相。如果人人都喜欢他，您也别跟着喜欢他，也要具体考察他做了什么事情，他是个什么样的人。

人一定要有反思的能力，要了解事情真相的能力，不能被人糊弄了。不要听到别人说，就以为是真的。所有人都说这个人坏，都讨厌他，也可能是他做了一件大好事、长远的好事，但是现在普通人的智力水平理解不了，就可能说他坏。

还有一种人，他就是清廉为民，这种人，谁跟他说什么，请他通融帮忙，他都不帮，结果呢，周围的权贵都恨他，天天宣传他的恶，您听到的，就是这个人如何如何坏，其实，他是真好。

所以，我们要考察实际情况，去看一看他的真实思想、行为。眼见为实，耳听为虚，当然眼见的时候，我们也要思考我们看到的是不是别人故意让我们看到的。现代互联网社会，视频、音频、图文发达，传播速度快，有很多人故意误导大众的判断力，我们不要听风就是雨，那么快的就否定，或者肯定一个人。

每个人都说他好，也要考察具体的情况、具体的人，不要就跟着说他好。有一种人，专门欺名盗誉，专门做些要大家说好听的事情，然后大量宣传，摄取名誉；有一种人，坏事做绝，但是，他给关键宣传人物好处，这些关键的人物就天天宣传他的好，导致所有人被蒙在鼓里，觉得他好。

孔子这句话，讲的就是不要人云亦云，要以事实做为依据，要有自己的判断力。有些人天生就具有煽动大众的能力，做正事不行，搞欺骗一把好手，我们要防止这些人的招数搞乱我们的头脑。总之，无论是都说一个人好，还
