# 知礼。

知道礼貌，知道礼仪，知道规矩，知道规律。万事万物都是有规矩的，都是有规律的，都是有一套法则的。按照法则去做，按照礼仪去做，按照规矩去做，您在这个社会上才能立起来，大家才能认可您，您横冲直闯，乱整，没有人认可您，没有人把您当回事，大家也不给您机会。

礼仪，就是我们每个人都要理解这个社会的规则、人与人之间的规则、组织与组织之间的规则、事物与事物之间的规则，所有人按规矩办事。比如，**尊重重道、孝敬父母都是礼，您必须得这样做，还要教育所有人这样做。如果大家不这样做了，抱歉，这个社会就乱套了。** 如果您不这样做，您就会被人喊讨，您说您怎么可能立得起来。这套上有些**人**敬师灭祖，想通过**教**师灭祖发财，这些都是愚蠢的事情，最终，他就立不起来了。

# 知言。

通过别人讲话，知道别人是什么人。通过自己的言语，体会到自己是什么人。人若有偏私、坏心肠，您注意听他的言论，您就能听出来。人若骝话连篇、谎话连篇，您注意听，您也就知道他的内心世界。人不仅仅要善于倾听别人的言论，也要善于识别自己的言论。看看我们这颗心是不是变了，是不是藏着祸心、私心，都能从言语中发现。

一个人坑了您，您被坑过后，才反应过来，其实您与他交往的过程中，您就应该能体会到他言论中释放出来的正邪信息。一个人喜欢您，您也能从他言论中体会出来。正人君子、邪恶之徒，嘴里有阴谋诡计、善恶忠奸，您去仔细听，您就会发现，您其实能听出来。那些说从言语中不能判断一个人的，都是些不认真、不仔细去听的。
