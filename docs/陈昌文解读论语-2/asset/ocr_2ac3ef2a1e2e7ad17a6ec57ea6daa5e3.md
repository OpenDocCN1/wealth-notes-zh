# 接下来在讲音乐。

音乐、艺术、娱乐，代表一个社会的风气，这是要重视的，不能让您随便创作，随便播放。很多人觉得不自由，想干啥艺术、娱乐、音乐都行，这绝对不可以，这会导致社会风气转变。所以，一个明智的君主，一定会管理好一个社会的音乐、风气。

孔子希望用韶乐。这是尧舜禹当中舜的音乐，和平中正，尽善尽美，一片祥和。人听什么音乐，就会被调到什么境界。人听悲伤的音乐，就会调到悲伤之中；听愤恨的音乐，就会进入愤恨之中；听仇恨的音乐，就会进入仇恨之中；听快乐的音乐，就会进入到快乐之中。

音乐过分，人就会过分。所以，有智慧的人，会选择性的听能听的音乐。不能听、不应该听的声音，坚决不听。

最后一件事，放郑声，远佞人。为什么？因为郑声淫，佞人殆。

什么叫做淫？过分就叫做淫。淫就是放纵，不是指男女之事。生活中的方方面面都可能淫，天天听音乐不做事，听得过了，也是淫。死了人了，唱唱哀乐是可以的，但是淫了，悲伤得伤人了，就不应该。快乐可以，快乐得过分了，发狂了，就不应该。爱可以，爱得过分子，就会强行控制对方，控制不了，就生气怨恨，复仇心理，就是淫。

任何事都应该恰到好处，也就是中庸思想。而不应该过分，这郑声就是过分了，所以叫做淫，所以要去除，不听郑声。

# 那为什么要远佞人呢？

佞人，就是有才智，巧舌如簧，搬弄是非，还能谄媚、讨好、巴结人的人。为什么这一条要提出来？大家会发现，当君子的，周围好像都有这么一个人，或者一群佞人，巧舌如簧，巴结上司的能力太过强大。这上司好像离不得他，以至于祸国殃民，还要把这样的人带在身边，直到把自己害得身死国灭也离
