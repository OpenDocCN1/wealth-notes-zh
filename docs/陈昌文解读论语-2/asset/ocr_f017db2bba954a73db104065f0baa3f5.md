# 7、听反对意见，有助于自己成长

# 原文

子曰：“回也，非助我者也，于吾言无所不说。”

陈昌文解读《论语》：

孔子说，颜回这个人，对我没什么帮助，为什么呢？因为我说什么，他都高兴、快乐。

当然，孔子是非常喜欢颜回这个徒弟的。但是当一个人您说什么，他都赞同，都听得懂，而且高兴的时候，您就没有新的观点、新的刺激，您就会永远认为自己是对的，也不思考了。所以，有时候，我们还是需要一些反对意见，需要一些人跟着我们抬杠，当然，这是对于大多数普通领导者都需要的。不过，对于孔子、颜回这个级别的圣人，他们自然知道什么是对错的。

孔子说这句话，其实也是进一步表扬颜回，说这人领悟能力强，我说的什么都懂，能举一反三，闻一知十。颜回是公认的可以接孔子道统的人，可惜，死得早。

这里有两点需要大家注意，对于普通人，我们确实需要经常听到反对意见，好反思自己，多思考，更接近真理。对于智慧高出您很多倍的人，他们本身是具有判断力，知道对错、善恶的。这时候，您就不要去跟高人抬杠了，有些人因为听别人说要反对意见，结果自己不学无术，狗屁不通，也敢去跟比自己智慧高出数倍的人抬杠，这种人就是典型的杠精、无知。

孔子说颜回不反对自己，什么都听得懂，也暗含表扬、欣赏的意思。
