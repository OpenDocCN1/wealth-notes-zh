# 25、人到四十，需要您的道德修炼到一定的地步，业绩有结果

原文

> 子曰：“年四十而见恶焉，其终已也。”

陈昌文解读《论语》：

孔子说，如果您到了四十岁，还让人厌恶，您这辈子也就这样了。这是什么意思？就是说一个人到了四十岁，文治武功，应该基本定型了。人的道德文章，应该基本就那样了。

对于大多数人来讲，这就是您人生的第一个总结了。

您的人格修炼、道德修炼、事业修炼应该到了一定的程度了，起码有让人称道、承认的地方，让人佩服的地方。如果您到了四十岁，混了四十年，还一无是处，道德、人格、事业都没什么结果，没什么业绩让人称道，养活自己都困难，还到处蹭饭吃，德行人格有亏欠，让人生厌，您这辈子就算完了。

别以为自己还年轻，人是有大限的，您不早日努力，早日去成就自己，年纪大了，您什么也没有，您基本就废了。人的年纪大了，心力就跟不上了，体力也跟不上了。而且谁也只想要功名成就的人合作，跟有前途的人合作，您说您都四十岁了，什么都拿不出来，谁跟您合作啊？所以，年轻人要早日努力，早日修炼自己的人格、道德，以及业绩，不要等到年纪大了，变成一个让人讨厌的人。没人愿意见到您，也没人愿意跟您合作。四十岁，就是要业绩的时候了，这个黄金年纪，您拿什么交卷呢？您拿什么开启您下一段美丽的人生？
