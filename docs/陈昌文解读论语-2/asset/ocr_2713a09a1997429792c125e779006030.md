# 33、坏人应该打击，好人应该嘉奖

# 原文

或曰：“以德报怨，何如？”子曰：“何以报德？以直报怨，以德报德。”

# 陈昌文解读《论语》：

有人问孔子，用德来回报怨，怎么样呢？孔子说，用德来回报怨，那么又用什么来回报德呢？以直心来回报怨，以德来回报德。

这句话，是给很多圣母讲的。

很多人，被一些莫名其妙的言论洗的脑子已经出了问题，分不清社会的好坏，搞不清楚自己该用什么方式对应不同的人。好的行为，就应该受到嘉奖；坏的行为，就应该受到惩罚，这是天理，赏罚分明，这样，社会才能正常运行。

一个坏人，干了坏事，如果您用德去回报他，您是在显示您的高尚呢？还是搞乱这个价值体系？让后面的人不知道应该是学您用德行回报他呢？还是惩罚他？如果有人惩罚这些搞破坏的人，您是不是还要圣母心的让别人去原谅他？让受害者大度一点点呢？

坏人，干了坏事，就应该受到对应的处罚。这个社会上有有些人确实不应该受到良好的教育，因为他们不配，一切都是成本的，包括智力教育、德行教育，我们也不应该分配好的资源去给那些做坏事的坏人。

一个人有德行，做了很多好事，我们才对他进行道德回报，给他更多优质的教育资源，以及智力资源、社会资源支持他，让他发展得更好，这是他应该获得的。
