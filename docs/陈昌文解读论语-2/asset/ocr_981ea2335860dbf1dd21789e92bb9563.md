# 陈昌文解读《论语》：

孔子说，臧文仲是占着当当的位置不做事吗？知道柳下惠是贤能之才，却不举荐柳下惠与自己同朝为官。

臧文仲素有贤名，是个能干的人，但是孔子在这里痛骂臧文仲，原因就是不举荐柳下惠，知道柳下惠贤能，不举荐柳下惠跟自己同朝为官。

这种现象，到处都是，这是一个人的格局问题，甚至是嫉贤妒能问题。人总是想表现自己，而不想让别人出风头。即便是别人真正的贤能，怕别人抢了自己的风头，抢了自己的位置。其实，您举荐的人越多，您提拔的厉害的人越多，您的势能就会越强大。即便是别人嘴上不说，心里也知道；即便是很多人都不承认您举荐了他们，帮助他们，但是当您举荐、推选的呢能非常多的时候，有那么几个人才说是您的功劳，在任何一个组织里，您就奠定了您的江湖地位。即便是您什么都不用做，您已经是隐形的大佬了，这是从功利角度来讲。如果有机会，您一定要多提拔、举荐您知道的贤能的人给组织，让这些贤能的人发挥他们的能力。

为什么要让这些贤能的人发挥他们的能力呢？因为市场是无限的，并非有限。有才能的人，一定会创造出对应的业绩，这样，整个组织就会更优秀，力量更大，其实您的市场就更大了。自己一个人干，与举荐一个优秀的人干，或者举荐一群优秀的人干，效果是完全不一样的。

很多人以为只要自己能吃饱饭就行，别管其他人，但是您在一个组织中，组织发展好了，对您的命运也是正面加持，所以，于公于私，您都应该举荐人才，让组织发展得更好、更强大。不培养人才，会导致后继无人，会导致自己被固化在一个位置上，自己也不能前进。

可以这样说，一个管理者最重要的任务，并非业绩，而是不断地为组织
