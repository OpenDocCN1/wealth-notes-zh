# 陈昌文解读《论语》：

季康子又来问孔子，盗贼很多啊，国内不得安宁，这个怎么办妮？孔子说，您如果不贪婪，不盗窃别人的，就算您赏给别人，别人也不要。

这话什么意思？儒家思想的一切思想，都是找自己的问题，而不是怪罪别人。这盗贼怎么来的，不就是您自己弄出来的吗，您横征暴敛，不知廉耻，不懂礼法，才导致天下盗贼四起，才导致大家不知道廉耻，到处偷盗，抢劫。倘若您治国有方，礼义廉耻都知道，您不想要的东西，就算赏赐给别人，别人也不会要。这还是上行下效的问题。

我们很多人都喜欢怪罪下属，怪罪跟随者，觉得是大家的事情没做好，是团队不行，是粉丝不行，其实主要是自己不行，一将无能累死三军，一切错误都是自己的。倘若自己行了，自己搞对了，则下面的人都行了。

所以，还是修身齐家治国平天下，先修好自己的德行，道德行为都合乎礼仪，则天下自然平定，哪里还需要管理，需要纠正呢？人们总是不想管理自己，想管理别人，这本末倒置，累死您也做不到。一个人能管好自己，把自己的问题都纠正了，则您的世界，就是理想的世界了。

# 22、改变自己，才能改变周围的环境

# 原文

季康子问政于孔子曰：“如杀无道，以就有道，何如？”孔子对曰：“子为政，焉用杀？子欲善而民善矣。君子之德风，小人之德草，草上之风，必偃。”
