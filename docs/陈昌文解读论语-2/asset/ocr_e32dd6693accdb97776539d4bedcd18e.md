# 愿意改进？

就说您在组织里，您可以帮助很多人，您真的发自内心地去帮助了吗？就说现在做视频、做直播的人，做讲师的人，您是不是每天都在改进自己的错误，在想自己哪里没做到位呢？

很多人觉得非常奇怪，蘧伯玉为什么改错不能改呢？他们以为自己有错，知道了就能改，这是大错特错。有的是惯性，有的就是不改，有一种天然的惯性。人只需要去除现在身上的毛病，不断地找毛病改正就行了。人并不需要到处拜师学艺，并不需要不断地学习新东西让自己优秀。

就这一点，改掉昨天的错误，向这个方向去做，这个人就会非常优秀。

比如在谈恋爱的过程中，您的对象明明做错了有些事，比如欺骗您，您明明知道不应该跟欺骗您的人在一起，结果，您又容忍了，这就会导致您更大的损失。这就是不能改错酿成的苦果。

再比如，在做项目的过程中，您知道该去搞营销，做流量，但是您昨天不做，今天又不做。您的广告也没做好，您昨天不做，今天又不做，导致错误不断地累积，结果您的人生只有消耗，而毫无成效。

人们都知道自己有很多错，人们不优秀是因为自己并不愿意改正，而非学少了，也并非拜老师拜少了。

我见到很多人蝇营狗苟、忙忙碌碌，总在学，总在拜老师，其实啊，任何一门学问，一个老师讲的道理，都足够您学一辈子了，别贪多。先想想自己能改掉哪些错，每天都改一点，优秀一点。您真这样做，不出三天，您就会发现自己有明显的变化。

蘧伯玉的贤能，就在于自己时时刻刻琢磨着改错且实践了。
