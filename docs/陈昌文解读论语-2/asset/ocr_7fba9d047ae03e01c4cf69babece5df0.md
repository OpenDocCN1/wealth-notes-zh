# 4、无为而治的前提是管理好自己，然后知人善用

原文
子曰：“无为而治者，其舜也与？夫何为哉？恭己正南面而已矣。”

# 陈昌盛解读《论语》：

孔子说，能做到无为而治的，只有舜吧？他是怎么做的呢？恭恭敬敬的南面而坐而已。

这就是政治的最高境界，也就是管理的最高境界。您啥也不用管，天下就治理好了，但是真的啥也不用管吗？不是。管理好自己，恭恭敬敬的，把这个做到极致。

又谈到管理学的核心问题，中国古人讲，修身、齐家、治国、平天下，这个恭恭敬敬，就是第一步。修身，德鲁克讲管理的本质就是管理自己。

您自己特别恭敬有礼，自己管理好了自己，您作为大家的表率，大家自然跟着您学了，这就是上面的人有道，下面的人就不令而行，不下命令，大家自动运转。如果您无道呢？您就算下命令，大家也不遵从，或者是表面答应您，背地里也不执行。所以，管理的核心，是管理好自己，做好表率，然后您的跟随者有样学样，您的组织就管理好了。

您真想做到无为而治，您不做事，就一定要周围的能人里帮您做事。别人凭什么帮您？就是感召于您的道德。您有道德，大家就跟着您干，把事情干好；您无道德，大家当然不跟您干。您德行高，才能聚集能人异士帮您，否则，您聚集不了人才，则是没人帮您，您还得亲力亲为。所以，无为而治的条件是，您能管理好自己，您具有道德，您能聚集优秀的人才来帮您。
