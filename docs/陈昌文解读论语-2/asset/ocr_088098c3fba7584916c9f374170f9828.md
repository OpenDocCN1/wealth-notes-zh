# 陈昌文解读《论语》：

孔子说，智慧是够的，但是仁德不够，您虽然得到了，还是会失去。也就是仅仅凭借智慧得到，您是守不住的，还要有仁德。当您的智慧够了，仁德也能守得住事业，但是您这个人没有庄重、威仪来统领下属，则下属看您成天嘻嘻哈哈的，会对您不敬。智慧也够了，仁德也能守得住事业，人也有庄重、威仪，这下该可以做好管理者了吧？还是不行，必须衣食住行、言谈举止，以礼相待同僚或者下属，否则，未善也，不能达到完美。

这一段是讲一个人的管理能力。

想要有管理能力，必须要有智力、智慧，这个是您获取管理的位置、做好一件事的基本能力。如果您连起码的智慧都没有，您什么也干不好，则您取不得位置，取不得成就。

智慧从什么地方来？就是通过不断地学习实践来的。

有了智慧，还必须有仁德。您取了天下，并没有仁德，大家会瞧不起您，会觉得您这个人不行。甚至觉得您Y就是个坏人，这种人就是守不住天下，只能打天下。商纣王就是一个智慧很高，但没有仁德的人，所以，他就算得到了天下，也会失去。任何一个组织都是如此，您有取天下的本事，这个靠智慧就能完成，但能不能守住天下，要靠仁德。

我们有了仁德，就万事大吉了吗？并非如此。我们还要有庄重的威仪。什么叫庄重的威仪？首先，您不能一天嘻嘻哈哈，没个正行，天夭说笑话，讲些荤段子。您的言语、行为让人觉得尊重您或不尊重您都差不多，根本就不用尊重您，您就是这么一个玩意儿。
