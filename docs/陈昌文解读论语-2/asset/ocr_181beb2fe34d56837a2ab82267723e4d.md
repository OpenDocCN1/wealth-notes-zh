# 陈昌文解读《论语》：

这一段，是颜渊问如何治理一个诸侯国，但孔子回答的是如何治理天下。历史上有人说，这是颜渊谦虚的问，表面问的是如何治理诸侯国，一个小国、小邦，实际上，问的也是如何治理天下，也就是辅佐周天子应该怎么干。孔子也明白颜渊的心意，所以，直接回答的就是如何治理天下。

首先是日历，采用夏历，每一代新君喜欢改换历法，总要跟前朝不一样，弄的历法混乱，不适合农民伯伯依据历法种地，收获了。而夏历就是我们中国最优秀的阴历，农民伯伯只要采用夏历来播种，施肥，收获就行了，就是最标准的历法。这个历法在我们农村上，现在还用着呢。

孔子的意思是想要周天子恢复夏历。

其次是殷朝的车，也就是车马的标准，要订立一个够用、适用的车马标准，不能宣传奢侈浪费之风，朴实够用就行。为什么要选择殷朝的车马标准？因为殷朝时期，大家用的就是木头做车前的模木，其他朝代奢侈浪费之风盛行，有的用玉，有的用黄金，有的用象牙，有的用皮革，一个比一个奢侈，一个比一个浪费，产生了不必要的攀比。

我个人也有一个感受，没学儒家思想之前，我本来也比较朴素，但是看到很多人住很大的房子，坐豪华车子，我自己也想拥有。然后呢，我甚至连家里不用的灯，也开着，灯火通明，浪费电。后来随着儒家思想学习的深入，我不去的地方，就把灯关了，我甚至还因为浪费而感到自豪，批评父母关掉了不必要的灯，其实这是非常愚昧无知的。家里的灯，也在消耗自己的精气神，实属浪费，我们要戒除这种攀比之风。节约力量，养精蓄锐，以做正事。

再次，穿周朝祭祀用的礼服装束，也就是穿着方面，用周朝的建筑，不奢侈，但华美程度也够了。不轻视礼仪，也不过分。这就是周朝服装。
