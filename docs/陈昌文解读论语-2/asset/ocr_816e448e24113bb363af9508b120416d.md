# 23、学习是为了让自己去实践，
并非在別人面前炫耀

# 原文

子曰：
“古之学者为己，今之学者为人。”

# 陈昌文解读《论语》：

孔子说，古代的人、以前的人，学习是为了自己；现在的人、当今的人，学习是为了别人。

这句话非常有意思。就是说啊，以前的人知道学习是为了自己，学以润身，学到头脑里，去执行，从身体上去改变，去干。现在的人呢，学习不为自己，不执行，不干，就是为了装自己有学问，为了表演，徒事讲说。学习只在口耳之间，耳朵听到，嘴巴讲出去炫耀，至于这个东西有没有用，自己行动不行动，懂与不懂？自己压根不关心，把学习当成了表演，为了骗掌声、鲜花、奖金而已。

这就是为什么很多人天天都在听课、学习，什么都懂了，还是生活得一塌糊涂的原因，因为这些本质上都是小人，只在口耳之间学习，并不会把学到的东西拿去实践，您一说道理，他马上跳起来反驳，我都懂，我明白，但是，又有什么用啊？这些人没思考能力，无行动能力。

就说营销这件事，您必须去做推广，去准备内容，去渠道里干活，上传您准备好的文案、视频、素材，您需要长期的去跟客户建立关系，日复一日的去重复这些动作。而小人呢，他不做这些工作，他以为听一个4p营销理论课，他就会营销了。听说过，跟去干活，完全是两码事。
