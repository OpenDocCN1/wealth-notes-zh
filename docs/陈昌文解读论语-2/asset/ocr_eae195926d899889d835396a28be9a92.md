# 39、只跟志同道合的人一起做事，找不到，就一个人做

原文
子曰：“道不同，不相为谋。”

陈昌文解读《论语》：

孔子说，大家的志向、思维、谋划的方式、价值观、原则、判断能力不一样，就不要在一起谋划事情。

我们看一个人，首先看一个人的道，跟我们一样不一样，要是这个人的道跟我们不一样，就完全没有必要在一起做事，后果就是浪费时间，损失金钱。

不谋道的人往往谋利，所思所想都是利的事情，这会导致他们的算计方式、做事方式不一样。如果您是一个谋道的人，跟一个谋利的人在一起做事，您以为您会实现您的志向，结果这个谋利的人会不断地从您身上算计金钱，这就很没意义。

我们做事情，一开始就只能跟志同道合的人一起做。如果不是志同道合的人、只为钱的人，这个事情百分百做到后面会扯皮，也做不起来。没经验的人，会进入谋利思维，其实最后是利也没有，道也没有。有经验的人，眼光精准，一眼就能看出这个事情是合乎道的，还是合乎利的。一直跟您谈利益的人，谈谋利的人，大概率都会把您引导偏，引导偏了过后，他谋了您的利就不负责了。或者您做着做着醒悟了，就不做了，但是在这个过程中，就
