# 17、君主做事要永远不疲倦

原文

子张问政。子曰：“居之无倦，行之以忠。”

陈昌文解读《论语》：

子张问孔子，如何搞政治，如何搞治理，如何当领导？当君主？

孔子说，居之无倦。

什么是居之无倦，就是我坐在这个位置上，勤勤恳恳，日日精进，什么事情都做到位，做好，不疲倦，不偷懒。这几个字，看似简单，但能做到的，寥寥无几，能做到的，都是厉害角色。大多数人，对自己的工作、分内之事，都做不好，都是偷懒的，都是敷衍了事的。即便是开始的时候做得好，过不了多久，就不想干了。善始者实繁，克终者盖寡。

所以我们会发现一个现象，做一个项目，开始的时候，大家都很积极，用不了几个月，这个项目就开始冷淡了，大家就不做了，又开始寻找下一个项目，这样周而复始的循环，然后一辈子没成就。

就连能拥有三分钟热度的人，也都算社会上的佼佼者了。大部分人连开始，都开始不了，就放弃了，何来长期的在一个位置上，还能把这个事情做好。这样的人，时间久了，就能把对应的技能练习到炉火纯青。

其实，这也是日日不勤之功的另一个说法。骐骥一跃，不能十步；驽马十驾，功在不舍。您能长期在一个位置上，且态度极好的把该做的事情做好。则，您一定会有成就。

做讲师，写文章，搞营销工作，都是如此，您能不疲倦吗？日日都去做，难。
