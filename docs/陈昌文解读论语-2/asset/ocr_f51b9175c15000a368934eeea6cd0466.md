# 14、高标准要求自己，低标准要求别人，
怨恨就远离了

原文
子曰：“躬自厚而薄责于人，则远怨矣。”

陈昌文解读《论语》：

孔子说，要重重的责备自己，严格要求自己，对别人要宽容、温和、缓和一点，则怨恨离您就远了啊。

人为什么有怨恨？大概是觉得别人对不起自己，别人答应自己的事情没做到。别人骗了自己，自己付出的没得到回报。人啊，总是拿着放大镜去看别人的缺点。对自己的缺点，倒是不在乎，不改正，容易原谅自己，这样，我们的怨恨就多了。我们要做的是对自己严格要求，对自己高标准，对其他人没什么要求或者低要求，过得去就行了。这样，您才能常怀感恩之心。

人在要求自己的时候，就是修身，会变得越来越聪明。比如，您用的员工不好用，老是误事，这个时候，您要想的是您的识人、辨人能力是不是有问题？您是不是用错了人，还是规章制度有问题，而不是去责备员工无能。要求自己，很容易改变，而且会永久性的解决问题；要求别人，什么也改变不了，并且大概可能会让别人怨恨您，众叛亲离，导致事情越来越难办。

比如，我们合伙做生意，您的合作伙伴开始答应帮您承担一部分启动资金，过一段时间又变卦了，您怨恨他不？您不用怨恨，您要想，您为什么跟这个人合伙了，他帮您一点一点。您还要想，您为什么这么缺钱，您的现金为什么不能支撑，还需要他帮您？这就是高标准要求自己。您还要想，即便是他什么也不用帮您，您也能搞定，这就是对他人零要求，您就不怨恨他了。
