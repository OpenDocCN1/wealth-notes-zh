# 不戒视成谓之暴。

不监视，不监督，不考察，只想要结果，要成绩，这就是暴。管理者必须在工作过程中去看大家做得怎么样了，去监视，去指导，给大家找方法，找策略，想办法，而不是时间到了就问大家要成绩，没有成绩，就辱骂，或者惩罚。这样的管理者叫做暴。

管理，是有监督、带领、辅导、给策略、给方法的责任的，否则当什么管理呢？

# 慢令致期谓之贼。

下命令的时候拖拖拉拉，看到要到期了，马上下命令，马上要结果，没有结果就要惩罚人，这种人叫做贼人，是民贼，故意找事，故意坑人。作为管理者、老板，您不干涉，您得体察民情。一个事情要有准备工作，有过程，要摸索，还得体谅大家犯错，必须是有时间成本的。管理者必须早做打算，有全面的管理经验。没有早做准备的智慧，只知道要结果，给大家带去巨大的时间压力、紧张情绪，这样的人就是贼。
