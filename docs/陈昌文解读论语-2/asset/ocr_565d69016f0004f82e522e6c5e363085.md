# 11、有原则，有底线，知行合一，表里如一，做真君子，不做小人

原文

> 子曰：“色厉而内荏，譬诸小人，其犹穿窬（yú）之盗也与！”

陈昌文解读《论语》：

孔子说，外表严厉，内心软弱，就如同很多类型小人的一种。什么小人呢？就是在别人墙上打个洞或者找个洞钻进去，偷东西的小偷一样。

色厉内荏是一种病，这种病必须治疗好，否则对人对事的伤害非常大。我们这个人啊，要有原则，外部必须刚强、威严，内心也要如此。必须坚持原则，在任何情况下，遇到任何人、任何事都必须坚持原则，否则，就会被人占了便宜，找了漏洞。一个人为什么会被占了便宜，找了漏洞？就是不坚持原则、左右摇摆、自我矮化、迎合错误，导致更大的损失。

我们在任何时候，都要高标准、严要求自己，自己内心是怎么想的，外表就这么表现。表里不一，表面的一个东西，想去欺骗别人，内心的一个东西又很软弱，很害怕，是反面的。这种人就是想糊弄别人，最终把自己给糊弄了，丢失了金钱、时间、精力，还矮化了自己的人格，非常划不来。

真正的君子，表里如一，知行合一，百分百有规矩、有原则、有讲究。是什么样的道理，就说什么样的道理。不想骗别人，也不想糊弄自己。一般色厉内荏的人，都是想欺骗别人，蒙混过关，结果呢，往往自己被骗够了。不要欺骗别人，也不要相信别人，自己去找真理，根据真理来做事。特别是有团队的情况下，团队里的成员人多了，都能看到真理，这时候我们要发挥
