# 3、孔子批评子路无德

原文

> 子曰：“由！知德者鲜矣。”

陈昌文解读《论语》：

孔子说，仲由，就是子路，知道道德的人很少啊。这句话是直接对子路讲的，相当于否定子路，批评子路，当头棒喝。

子路这个人跟着老师学习，也很认真，听了就去做，但是暴躁气、易怒，还经常顶撞老师。不过跟老师关系也是最好之一，孔子也很爱护子路这个学生，所以，才直接批评、呵斥他，不要以为您子路学到了道德，没几个人能懂这个道德。说白了，大家都缺道德。

人啊，一定要认为自己缺德，而且要对照自己的心，来看看自己缺什么道德。而不是盯着别人道德不道德。

人总会觉得别人对不起自己，都是别人的错，抱怨别人，而不想让别人对自己好过，有恩于自己，反倒是几句话就开始记仇。这是人不道德的地方。

比如，孔子对子路很上心，但是子路经常顶撞老师，多次怒气冲冲说些阴阳怪气的话，当然我们并非说子路这个人不好，子路当然是个好人，但不妨碍他缺德啊。

前面刚讲过子路，一不顺心，就找老师抱怨，君子也会穷吗？意思就是老师，您天天讲君子君子的，现在好了，我们倒霉了，君子也会穷吗？这句话问的，一点心性水平也没了。
