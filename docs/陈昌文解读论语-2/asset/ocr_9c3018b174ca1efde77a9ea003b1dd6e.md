# 1、政治不过是带头痛劳动，让大家跟着一直干活，而不要闲着

原文

子路问政。子曰：“先之，劳之。”请益。曰：“无倦。”

陈昌文解读《论语》：

我认识一个商人，这个人已经很有钱了，但还是每天很勤奋，不休息。他经常给我一个道理：人这个东西，无事生非，饱暖思淫欲，饥寒起盗心。只要不做正事，就一起生出邪念，会去搞些让自己后悔的事情。现在想想他的话，再读这句《论语》，有所印证。

子路问孔子，如何治理政治。

孔子说，您要把好带头作用，使劲干活。带头的如果于干活，没有榜样的作用，后面的人都不干活了。

劳之，不能只是您自己干活，您必须让大家跟着干活、劳动。人唯有劳动，才能生出善心，才能生出智慧，才知道物力维艰，知道什么是锄禾日当午，汗滴禾下土，谁知盘中餐，粒粒皆辛苦，才知道一碗一饭是怎么来的。否则，这个人于干活，只要钱，就会贪得无厌，认为您应该给他，认为他自己很了不起，很高傲。

整个组织的所有人，都必须劳动，勤奋的劳动，带头劳动，带着大家一起劳动，这就是政治。

所有伟大的企业、伟大的组织，都是这个模式。
