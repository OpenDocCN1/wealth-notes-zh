# 2、不为利禄所动，坚持正确的价值观

# 原文

> 柳下惠为士师，三黜。人曰：“子未可以去乎？”曰：“直道而事人，焉往而不三黜？枉道而事人，何必去父母之邦？”

陈昌文解读《论语》：

柳下惠做法官，就是判案的官员，这种官员，当然权力非常大，当然里面的利益也会非常大。三次被罢黜，就是三次被上司开下课，不让他当官了。当然可以看到柳下惠也是三次被启用，证明他有价值啊，才启用他。

有人就说啊，您这么有本事，有能力，又正直，去哪个国家不当官？何必非赖在这里受辱呢？经常被罢黜。这明明不是您的错，您都是对的，都是按照道义进行判案啊。柳下惠说，我直来直去，案子该怎么判，就怎么判，当然会得罪很多人，比如得罪上司等的利益群体，当然会被罢黜三次，但这就是我当官的意义所在啊。假如我贪赃枉法，上司让怎么判，我就怎么判，我这官当当的好好的，何必离开自己的国家去其他国家当官？意思是，我这种人，即便是去了别的国家，一样会被罢黜啊。但是我有我的用处，你们要启用我的时候，自然会来启用我，但我只会秉公执法。

柳下惠是真正的君子，我们在这一段里要学习的就是这种做人的格调，比如我们对待客户，我们讲清楚了，您要用我，我就是这样做。我的价值观是什么，我的态度是什么，我怎么对您，受不了，您就开除我，我就不给您
