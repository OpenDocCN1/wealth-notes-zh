# 15、要求自己，而不是要求别人

原文

齐景公问政于孔子。孔子对曰：“君君，臣臣，父父，子子。”公曰：“善哉！信如君不君，臣不臣，父不父，子不子，虽有粟，吾得而食诸？”

陈昌文解读《论语》：

齐景公问孔子，怎么治理国家，孔子说，君王要像君王的样子，臣子要像臣子的样子，父亲要有当父亲的样子，儿子要有当儿子的样子。

这话啥意思？就是您做什么要爱一行，要专一行，要成为一个行业专家，一个职业专家，不要弄得四不像。

这让我想起了我大学同学的一句话，十几年过去了，我依然记忆犹新，他说：“我不敢说我是一个人，我起码要活得像一个人。”

这个像一个人，就把责任、义务、付出等人性光辉面给激发出来了。您在这个位置上，您起码要像那么回事吧？不要太过分。犹如，您家里来了宾客，您总得要打招呼的，总得要笑脸相迎的，您如果不闻不问，那么您可能就会被人笑话是傻瓜了。

同样，当一个君主，他有君主的义务、责任与付出。当臣子也是，不是让您白领俸禄的，食君之禄，担君之忧。当父亲的，要给儿子做好榜样。您干坏事，您的儿子也跟着学，就算不跟着学，也知道自己父亲不是个好东西。当儿子呢，要孝敬父母，有个做儿子的样子。就这些简单的道理，做到了，这个政治也就做好了。
