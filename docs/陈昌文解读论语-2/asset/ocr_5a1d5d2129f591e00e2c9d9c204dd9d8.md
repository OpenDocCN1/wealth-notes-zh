# 16、表达自己的情绪要看场合，思后果，发乎情，止乎礼

原文

曾子曰：“吾闻诸夫子，人未有自致者也，必也亲丧乎。”

陈昌文解读《论语》：

曾子说，我听老师说过，人啊，不能自由自在的把感情表达到极致。如果有⋯的话，也是在亲人去世的时候吧，这个时候没人管您，您也不用在意谁，表达丧痛是应该的。

人这种动物，平常的时候，总是要遮遮掩掩的，跟谁交流，总是要照顾场面的，要看人下菜碟。您面对比您大的官员，您不能说骂就骂骂。您面对团队，您不能撒泼打滚。您心里不高兴，也得故作镇静，或者就算您发表情绪，您也得控制着点。

在人类历史上的一些特殊时期，甚至说错话，都会导致杀头之罪，所以，更不能随意表达情绪。那些控制不了自己情绪、随意表达、不计后果的人，本质都是蠢，智力没有进化。情绪控制能力差的人，命运一般般都差。

我们要发泄自己的情绪，自由自在地表达，得看场合，得看后果，得有分寸。如果您实在要表达情绪，您可以找一个没人的地方，没有后果的地方，去表达。当然，亲人去世，表达伤痛，那是可以自由自在地发挥的。

人不是带着面具生活，而是不得不带着面具，我们尽可能真诚一点，但也得考虑后果。
