# 40、如何管理好跟随者

原文

子曰：“上好礼，则民易使也。”

陈昌文解读《论语》：

孔子说，上面的人好礼仪，则跟随者、民众就好管理了，好使用了。

这可是千古难题，每一个领导者、老板、皇帝，都想要人民听话，好管理。

我说啥，就是啥，我想干啥，大家都支持，劲往一处使。若是能达到这个境界，每个老板、领导者脸上不乐开了花吗？

孔子给的解决方案就是好礼。所以我们就专门讲讲什么是好礼。好礼了，大家都听您的了。

+   1、对人要礼貌。

见到谁，都要以礼待之。也就是领导者要热情，不要冷冰冰的。冷冰冰的，大家看您不顺眼，怎么还可能听您的？一个冰块是没办法种庄稼的，一个冰冷的人也难有良好的人际关系，一个冰冷的领导者也难以有真心的跟随者。

尊重您的跟随者，他们才愿意被您使用。若您不尊重您的跟随者，他们就会觉得跟着您是委曲求全，要是其他地方有一个更好的待遇，他早就跑了。还有的是被迫在您这里领取薪水，学习点什么，随时随地都想取而代之或者另起炉灶。

您让大家觉得自己的尊严受到了伤害，就离离心离德了，您用起来，大家就表面答应您，实际上根本不去做，更有甚者，表面上也不恭敬您了。

+   2、领导者自己要以身作则。
