# 11、表面功夫就是实际功夫

# 原文

棘子成曰：“君子质而已矣，何以文为？”子贡曰：“惜乎，夫子之说君子也！驷不及舌。文犹质也，质犹文也。虎豹之鞟，犹犬羊之鞟。”

# 陈昌文解读《论语》：

棘子成这个人，是卫国大夫，所以，后面子贡称他为夫子。

他说啊，君子注重内涵就行了，有本事就行了，内心里有东西就行了。何以文为？为什么要做表面功夫呢？为什么要在意表面形式呢？为什么要用表面来美化呢？为什么要仪式礼仪呢？

子贡说，可惜啊，实在遗憾，夫子您说的君子，当然是说错了。说错话了，四匹马也拉不回来，所以不懂不要乱说啊。话这个东西说错了，就收不回来了啊。

表面功夫，就是本质啊，一个人连表面功夫都做不好，证明他实际功夫也做不好啊。本质是什么？本质就是表面功夫啊。

这两句话非常哲学，非常矛盾又统一。这个世界上，看似有很多事情，实际上，都是一件事。没有结果的人，证明过程就是错的，没有过程的人也不会有结果。所以，一个人说他很努力，过程都对了，结果不对，这是自欺欺人，乱说话，骗人。一个人结果对了，他说他过程错了，是歪打正着，这也是乱说，或者谦虚。

道理就是本质，本质就是道理。
