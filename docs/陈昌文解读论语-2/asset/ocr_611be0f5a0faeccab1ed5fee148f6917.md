# 26、言过其实是耻辱，要讲事实

# 原文

子曰：“君子耻其言而过其行。”

# 陈昌文解读《论语》：

言过其行，说话超过了自己的行为，就是说大话，说漂亮话，说了话，行为跟不上。孔子说，君子以自己说的话，行为跟不上为耻辱。

人为什么会说话，行为跟不上呢？主要是张开嘴，在形式上，比迈开腿，比干活要容易得多。人为什么喜欢说大话？因为说大话，可以诓骗利益，可以表现自己高明，可以欺骗别人。说漂亮话，人人都爱听，大家不喜欢听实话，所以很多人就不说实话了，经常言过其实。这是因为利益驱使，需要让别人相信自己。

说大话、漂亮话，言过其实有什么坏处呢？就是长此以往，您欺骗了别人一次、二次，第三次，别人可能就不相信您了，您就失去了公信力，您可能又会去找另一批人说大话，说漂亮话。结果就是您变成了一个骗子，事情并没有发展。

那么，人到底应该怎么样呢？就是实事求是，是什么就说什么，绝对不言过其实，这样啊，您看起来走得慢，好像没什么人欣赏您，您自己也很孤单，但是您可能吸引到聪明的、智慧的人，这些人本来就是少数人。

就说做营销这件事吧，很多营销人员都喜欢说大话，说谎话，说漂亮话，先把钱诓骗进来再说，其实他不知道，这样做后果很严重，客户会不满意，会闹事，会举报，各种各样的麻烦接踵而至。
