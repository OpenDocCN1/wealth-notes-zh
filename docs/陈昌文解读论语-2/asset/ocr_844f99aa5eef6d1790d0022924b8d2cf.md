# 3、为什么启用新人难

原文

齐景公待孔子曰：“若季氏，则吾不能；以季孟之间待之。”曰：“吾老矣，不能用也。”孔子行。

陈昌文解读《论语》：

齐景公想用孔子治理齐国，还想封地给他，在考虑孔子的待遇问题。像鲁国国君对待季氏那样，礼遇太隆重，齐景公做不到；象孟氏那样对待孔子，好像礼遇又轻了点。于是，齐景公对待孔子的待遇想确定到比孟氏高一点，但比季氏低一点这个待遇。

在鲁国，季氏是上卿，是最为尊贵的人。孟氏是下卿，当然也非常尊贵。想要确定对孔子的待遇就是季孟之间。但是呢，齐景公年纪大了，心力不足，这群臣看见齐景公想要用孔子，当然不愿意啊，反对的人非常多，还有人想要谋害孔子。于是，最后齐景公说，我老了，不能用您了啊。于是孔子就离开了齐景公。
