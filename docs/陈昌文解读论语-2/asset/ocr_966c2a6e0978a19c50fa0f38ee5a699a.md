# 25、只管做好自己的事情

原文

> 子曰： “不在其位，不谋其政。” 曾子曰： “君子思不出其位。”

陈昌文解读《论语》：

孔子说，您不在那个位置上，就不要去谋划那个位置上的政治、管理等各项事务。

人应该管的永远是自己，您自己有很多事情，您的衣食住行、言行举止、您的事业、您的项目，您都做好了吗？您为什么要去关心别人的事情？别人的事情，别人操心就行了，您又没吃那口饭，为什么要去管别人的事情？

不在别人的位置上，您是不知道别人到底在干啥的，您也不知道别人获得了什么信息，有什么经验。您去管理、关心、出主意，往往都是脱离实际的，不仅仅闹笑话，还会给别人添乱，还招人讨厌。

人的精力是有限的，天天想别人的事情，别人又不听自己的，那就是徒劳。您要真有本事，把自己当下应该做的事情做好，自己手里的事情做好，等您做好了，别人看到您确实有本事，自然来请教您，这个时候，您也只能说自己懂的，有实践经验的事情给人参考，而不是一顿乱吹。不懂的，也洋洋得意的瞎忽悠。

人总喜欢瞎吹，吹那些自己管理不了的大事，世界大事，比如中东局势、宇宙大事，因为吹这些东西，说说对错，无所谓的，没人找您麻烦。而真正掂量自己的能力，您今天工作做好了吗？有成绩吗？您买了房子吗？存款多少啊？孝敬父母吗？这些东西是身体力行，马上就能做的，这就要命了，所以大家往往避而不谈这些自己能身体力行的事情。您当老板的，您把员工
