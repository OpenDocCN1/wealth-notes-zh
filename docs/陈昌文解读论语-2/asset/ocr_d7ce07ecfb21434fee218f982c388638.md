# 28、人行干啥都行，人不干干啥都不行，
人才是组织发展的关键

原文

子曰：“人能弘道，非道弘人。”

陈昌文解读《论语》：

孔子说，人能够使道弘大，发扬光大，使这个道理彰显天下。道并不能使人弘大，发扬光大，彰显于天下。

这句话，就是现在很多人说的，听了那么多道理，还是过不好这一生的答案、解释。

这句话到底是什么意思？就是您牛B，您才能把道弘扬天下，才知道老祖宗说的是对的；您有慧根，又有执行力，您就知道四书五经，孔夫子、老子、庄子、孟子，这些人是圣人，讲的是真道理，您得做嘛。

具备智慧，具备执行力，手脚并用，您就是了不起的人，您就弘扬了道。您干啥都能成，您就是英雄人物。相反，您这个人不行，光听道理有什么用呢？天天听别人讲书，听别人讲道理，您也不干活啊？您还是睡睡觉、玩游戏、发呆、啥也不干，也不思考，就想变成圣人？英雄？获取天下权利、财富？您这是在做梦。道不会弘扬您的。

所以说，天地人三才，人最重要。能人最重要，圣人先知最重要。要是没有能人、圣人先知，社会都不会发展，一帮草包，或者说一帮普通人，现在可能还在原始人社会。社会能出现一个圣人、一个厉害的人，那是全社会
