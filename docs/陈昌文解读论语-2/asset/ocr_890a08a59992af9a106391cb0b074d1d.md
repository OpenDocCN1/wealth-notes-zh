# 陆昌文解读《论语》：

子贡问孔子，君子有厌恶的人吗？孔子说，有厌恶的人。

孔子在这里列举了四种厌恶的人。

第一种人，称人之恶，天天说人坏话，到处攻击别人的缺陷，这些人从来不反思自己，也不关心自己的事业，就是说人坏话。别人坏是别人的事情，跟您无关，您做好您自己的事情就行了。而且吧，就算别人坏能影响到您，您也只能改变您自己，说人坏话干啥？坏了自己的人品，天天盯着别人，心思都在别人身上没必要。

就算这个坏人在挖坑了，您也改变不了什么，您要做的，只是从现在开始，做好自己的项目，赚自己的钱，不断地提升自己，否则，您想做什么呢？继续说人坏话？从情感上来讲，您说人坏话，还把自己心情搞坏了；从道德上来讲，天天说人坏话，自己也会道德败坏；从理智利益上来讲，完全没必要，说人坏话，自己得不到什么好处。

所以别说人坏话，关注自己的事情，做好自己的项目，赚钱、修心要紧。

第二种人，在下位，说上位坏话。自己不如别人，或者在别人手下做事，注意，无论您如何搞，永远都有上位。上上下下是每个人陷入的局，无论您干啥，您都有上位。请认清这个现实。除非您是天王老子，您就是天下第一，所有人都是您的下位，想想，可能吗？

好了，认清了这个局，我们再来谈这句话。您跟着人干事，给人干事，您就别说人坏话，上位有错，直接纠正，直接讲明白，希望他改正，整个局面更好，您就更好。为什么要说上位坏话？特别是背后使坏的人，就是人品大大的坏了，这完全没必要。

古代有很多奸臣，就是这样的蠢人，看似聪明，背后说坏话，干坏事，结果把上位给搞死了。他以为上位搞死了对他有什么好处？没有什么好处，他也会死。他就是理解不了，真心帮助上位，整个局面好了，自己就会更好。
