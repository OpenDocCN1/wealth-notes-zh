# 34、如何知道一个人的终极梦想

# 原文

子路、曾皙、冉有、公西华侍坐。子曰： “以吾一日长乎尔，毋吾以也。居则曰：‘不吾知也。’ 如或知尔，则何以哉？”

陈昌文解读《论语》：

子路、曾皙、冉有、公西华陪着老师坐着。孔子的教学方式，就是大家在一起坐着，聊天，各表达各的观点，孔子加以点评。孔子说，我比大家年长一日，这是谦虚的说法，孔子比大家年长很多，至少不是一日，说一日，是说我比大家年长，但也年长不了多少。

毋吾以也。不要觉得我年长，就不好意思说啊，畅所欲言，想说啥，就说啥，有什么才华都展现出来吧。

居则曰：‘不吾知也。’ 如或知尔，则何以哉？经常在家里说，我就是没人知道啊，我就是没人了解啊，没有伯乐啊，那么现在，假如有伯乐，您被人了解了，有人提携您，您打算干点啥？有什么本事呢？

首先讲一讲孔子的教学方法，是大家坐在一起相互辩论、讨论，孔子给以点评，这种教学方法很容易让一个人主动思考。当然也对老师的要求比较高，老师的本事不是足够大，容易镇不住场子。孔子当然也比较谦虚，说我就比大家年长一天，大家随便说。这个是我们要学到的，就算您满腹经纶，也要谦虚一点。
