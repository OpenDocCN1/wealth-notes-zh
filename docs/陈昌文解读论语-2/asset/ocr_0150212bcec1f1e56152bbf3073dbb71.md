别人答应您的事情不去做，没做到，或者打了折扣，那么对自己的高标准要求，就是您有没有备用方案，您为什么不去亲自去做？如何补救？对别人的要求就是，他愿意做是情分，不愿意做就算了。

如果有人辱骂您，想想自己哪里做错了，以后避免这种事情。想想，别人骂您是他人自己的素质问题，不要要求每个人都喜欢您，完全没必要。别人骗了自己，要想想自己为什么智力这么低，被骗，为什么自己听了骗子的话？要理解，骗子本来就生活在这个世界上，虽然是不道德的，甚至违法的，但他就是存在。

如果自己对一个人付出了，没有回报。就想想自己付出的方式、眼光、程序是不是错了。付出犹如投资，说明自己的投资能力有问题，要继续修炼。别人不回报您是正常的，这就是人性啊。回报您了，您才要感到惊喜呢。对自己严格要求，高标准的要求，会让自己迅速进步，理解到这个社会的本质。对别人没要求，或低要求，不责备别人，也没人怨恨您了，您也不用陷入这些没必要的争斗中。

# 15、要运用所有人的智慧去完成一件事

# 原文

子曰：“不曰‘如之何，如之何’者，吾未如之何也已矣。”

# 陈昌文解读《论语》：

孔子说，遇到事情，不说怎么办呢？“怎么办啊”的人，我也不知道应该拿他怎么办了。
