# 8、一个人要修炼好的三招

原文

孔子曰：“不知命，无以为君子也；不知礼，无以立也；不知言，无以知人也。”

陈昌文解读《论语》：

这是《论语》的最后一段。这句话也是对孔子的总结，也算是对《论语》的总结，大家学了这么久，给大家总结一下，这做人最重要的是什么。

知命。

俗话说，安身立命，您干点啥？靠什么生活、生存、养活自己、养活妻儿老小，这就是您的命。您从事什么职业，做什么工作，这就是您的命。搞清楚自己要干啥，能干到什么程度，这就是您的未来。您来这个社会、这个世界的使命是什么，按照这个方向一直去做。完成自己的使命，这就叫做知命。

当您知道您具体要干什么的时候，社会上的一些诱惑，您就能看明白了，哪些该做，哪些不该做，您就懂了。

人有人的命，组织有组织的命，国家有国家的命。您的命，是在组织中、国家中。您的命，要顺应这个时代。您活得得有价值。历史有历史的大命运，您要为这个大命运做贡献。如果您跟着历史的大命运对着干，您的小命大概也不好过，甚至会给这性命。

知道自己的命，就要认命，很多人以为认命就是绝望、不奋斗了、妥协、懒惰、失败了，其实不是。认命是我们必须认真的做好我们能做的事情，当您真正认真做好我们能做的事情的时候，您慢慢会发现，上天会安排更重要
