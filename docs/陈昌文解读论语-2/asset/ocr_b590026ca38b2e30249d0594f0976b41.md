# 41、领导力的核心是敬

# 原文

子路问君子。子曰：“修己以敬。”曰：“如斯而已乎？”曰：“修己以安人。”曰：“如斯而已乎？”曰：“修己以安百姓。修己以安百姓，尧舜其犹病诸！”

# 陈昌文解读《论语》：

子路问如何当君子，当领导。孔子说，修己以敬。就是一个敬字，做到了，就能当好领导。

什么是敬？这个学问可大了。敬父母、师长、百姓、下属。敬天爱人，把事情做好，也是敬。做什么都有恭敬之心。比如，您尊敬父母，不顶撞、谩骂殴打父母，孝敬父母。比如，您真正发自内心的尊重老师。有些人是假尊敬老师，老师说两句，他心里就犯嘀咕，瞧不起老师了，或许学几天就会觉得超过老师了。可以跟老师分庭抗礼、另起炉灶等，这都是没有敬，没有敬的人学不到什么真东西，也没有耐心。再比如，敬下属，有人跟随您，您是把他们当成奴隶？还是当成朋友？还是当成师长？您是不是把别人当人看了，这就是敬的区别。

敬事，一件事，您是不是很认真的去做，还是敷衍了事？具有恭敬之心，重视、诚恳、真诚、认真、不马虎、不敷衍、不二心、不低毁、不嘀咕别人、不抱怨，无什么不满意之心，这就是敬。

大家对照一下自己的为人处世，是不是做到了敬，这个字是用来修养自己的。修养好了自己，您就是一个君子、一个合格的领导了。

孔子话音刚落，子路不假思索，马上问了一句，就这样吗？您讲完了？
