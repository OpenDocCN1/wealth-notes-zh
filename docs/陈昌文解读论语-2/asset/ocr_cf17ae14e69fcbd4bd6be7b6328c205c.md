# 陈昌文解读《论语》：

子张问孔子如何才能做到仁。孔子说，能做到以下五点，就是仁了。那么请问是哪五点呢？

孔子说，第一是恭。

说话永远是恭恭敬敬的，做人做事永远都是恭恭敬敬的，对谁都有礼数，都礼貌，无论是陌生人，还是老熟人，都是恭恭敬敬的。

我们这个人啊，见到陌生人，有时候觉得跟自己无关，于是不恭敬，怠慢了别人。有些人就会记恨在心里，等到别人发达了，或者某个时机，别人可能就会报复您了。人还有一个毛病，即便是做到恭恭敬敬的，但是熟悉了，成了老朋友、老相识了，可能就放松了，觉得可以调侃别人，给别人取外号啊，就开始没有恭敬之心了，因为觉得熟悉了嘛。但是您觉得您跟别人可以开玩笑、熟悉了，别人可不这样认为。所以，我们恭敬是要一直恭敬，永远恭敬下去。而不是我想恭敬的时候，就恭敬一下，不想恭敬，就不恭敬。要一直不变。比如我们讲的尊师重道，我们要永远的尊师重道，时时刻刻都要尊师重道，而不是今天情绪来了，就不尊师重道了，明天想起来我做得不对，又开始尊师重道，不断地反复。这当然就不是恭。

恭敬别人，既让别人舒服，又保护自己。恭敬事情，能理解做事有难度，要做好不容易，这样，才有做好的可能。而傲慢，往往得罪人，事情也做不好。您恭敬别人，别人就恭敬您，您才不会受到侮辱。

第二是宽。

首先要讲的是严于律己，宽以待人。宽，不是对自己讲的，是对待别人的，如果您对自己很宽容，犯错了随时随地地原谅，无所谓，那么您就会继续犯错。那么我们为什么要对人宽容呢？因为您严苛了过后，别人就掩盖错误，找借口，让您发现不了真实原因，您要鼓励别人讲出真相，您去解决事情，
