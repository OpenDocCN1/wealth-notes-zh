# 20、做事要讲究适度，不过分，也不差火候

# 原文

子贡问：“师与商也孰贤？”子曰：“师也过，商也不及。”曰：“然
则师愈与？”子曰：“过犹不及。”

# 陈昌文解读《论语》：

师是子张，商是子夏。子贡问孔子，子张与子夏谁更贤德啊？孔子说，
子张有点过分了，子夏呢，又差点火候。子贡就说，那么是子张更贤德了？
意思是，过了总是比不及好吧。孔子说，过分了和不足是不一样的。子张这个人，
学习刻苦努力，什么都想跟圣人一样，简直学习到走火入魔的地步。而子夏
这个人呢，做什么事情，都缺点火候，得过且过。

学习刻苦努力当然好，但过分了，就会出现很多问题，一是身体搞坏了，
忽略了其他问题。二是不能持续，因为人始终是会累的。要恰到好处。这就
是中庸之道。而不及呢？学什么都差得不多就行了，蒙混过关，容易让人堕入
平庸，虽然比大部分人好点，但是也很难有什么顶尖的成就。

所以，一个高明的人，是张弛有度，该睡觉睡觉，该工作工作。绝对不是
一曝十寒，也不是得过且过。比如，我们很多人创业，开始的时候激情满满，
没日没夜地奋斗，干了3个月，没出成绩，就绝望了，就放弃了，我这么努力，
还不成功？这些人，往往都是忽略了事物的规律，只会感动自己。

还有一种人创业呢，他还以为他在打工，慢悠悠的，朝九晚五，结果储备
的资金用光了，还没搞到业务，就破产了。
