# # 30、 有些人问问题就是设置陷阱

# ## 原文

> 季子然问：“仲由、冉求可谓大臣与？”

# ## 陈昌文解读《论语》：

季子然是权臣季氏子弟。季氏有不臣之心，随时准备造反，也笼络了很多人才。

孔子的弟子，仲由，就是子路，冉求，也在季氏家里做事，当臣子。

季子然想，既然您的两个得意弟子都在我们家里做家臣，我就问您这两个徒弟怎么样？您表扬您的徒弟好，也就是表扬我们家了。

这个问题非常刁钻毒辣，看似平静，实际上是想给自己脸上贴金。

孔子是圣人，当然不会着了了他的道。圣人当然是明察秋毫的，知道每一个问题都有背后的语境，都有背后的原因，不能直接回答，要考虑清楚了，给予正确的答案。

在我们这个世界上，有很多人问问题，其实只是要一个自己想要的答案，而不是想要一个正确答案。当然孔圣人要给的是真理性的答案，而不是您想要什么答案，就给您什么答案。
