# 4、只交往有益处的朋友

原文

> 孔子曰：“益者三友，损者三友。友直，友谅，友多闻，益矣。友便辟，友善柔，友便佞，损矣。”

陈昌文解读《论语》：

孔子说，有三种朋友对自己有好处，有三种朋友对自己有坏处。

跟正直的、向我直言的人做朋友；跟诚实、实在的人做朋友；跟见多识广的人做朋友，是有好处的。

跟徒有其表、虚荣的人做朋友；跟说话谄媚、讨好、奉承之人做朋友；跟巧舌如簧、夸夸其谈，但无真本事的人做朋友，有害。
