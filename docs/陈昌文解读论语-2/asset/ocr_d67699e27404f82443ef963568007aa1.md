# 孔子说，言忠信。

先说忠，您答应别人的事情，要做到，否则别答应；您帮助别人，要尽心尽力地帮助，不能敷衍了事。比如您有下属，您也要忠诚下属，什么是忠诚下属？就是让下属成就，让下属赚钱，让下属安身立命。

很多人一讲忠，就以为是要求别人忠诚于自己，这是愚蠢的行为。别人没有义务忠诚您，而是您要忠诚于您周围的人、您的下属与上司。当您设身处地、一心一意帮助他们，真心实意提升他们的收入，让他们身心健康的时候，他们自然就会喜欢您，依赖您。您要么事业飞黄腾达，要么就免于祸患了。

然后再讲这个“信”字，人不能言而无信，人无信不立，您说话颠三倒四，经常骗人，谁能跟您交往呢？谁能跟您合作呢？人说的每一句话，都必须是实话、真话，您说话才有力量。您说假话、谎言，即便是能欺骗一时，也欺骗不了长久，会给您招祸。所以我经常对人讲，一个人只能讲真话，因为讲假话会给自己招祸。

行笃敬。

行为要笃，什么是笃？笃实、老实、忠厚，就是笃。憨厚老实，不要心眼，不是当面一套，背后一套，要说到做到，做不到的，不说。靠谱，别人就对您放心，交代给您的事情就能成，不能成的也不交代给您。

您是一个靠谱的人，别人都愿意跟您合作，有机会也愿意提携您，您也不是坑蒙拐骗之人。这样，就算有人告您的恶状，都没人相信，因为大家都

敬，有敬意，对什么都敬，敬天地鬼神，敬人，敬事，尊师重道，尊敬父母，尊敬工作人员、下属、合作伙伴。
