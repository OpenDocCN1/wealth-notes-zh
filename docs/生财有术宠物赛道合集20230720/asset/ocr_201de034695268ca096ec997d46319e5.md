# 二、宠物赛道情况

宠物赛道大致可以细分为：萌宠、吃播、科普。

# （1）萌宠 难度：5 星

+   1. 必备条件：宠物有特色或号主有较强的包装能力
2. 其他条件：会讲故事、会拍摄剪辑
3. 优点：流量大，出大 V 概率高
4. 缺点：泛粉多，用户画像不够精准，报价较低，无法批量复制
