# 2、视频号小游戏任务资格怎么开通？

第一步：进机构，现在机构账号才有限向官方提交账号资格开白权限。

第二步：发作品涨粉，100粉丝之后可以填写报名表。

机构每周都会给官方提交名单，再由官方筛选账号开白，现在开白的比例每周都在40% 左右，所以当周没有拿到资格同学，稳定更新优质作品，下周继续提报就行了。

如果在这个等待的过程中心态就崩了，那说明你不适合做小游戏。

第三步：拿到资格之后去发作品带链接开始变现。

# 3、如何起号

这个其实很简单，视频号的新号是有7天左右的保护期的。

利用好这几天可以快速的起号，抖音上游戏类爆款很多，在视频号上没有发过的作品，可以直接去水印发到视频号，大概率还是会爆。
