# 7、抖音的作品如何做“毫无保留的借鉴”? 

这个其实很简单，去水印-换背景-加贴纸-换字幕-加音效-滤镜-特效-实拍画中画滤色处理后透明度3左右-加边框。

去水印的软件可以直接微信小程序搜。

这些如果看不懂的话就是剪映的基础操作不过关，建议打开剪映里面很多基础教程。

做好短视频拍剪是基本要求，必须要会。
