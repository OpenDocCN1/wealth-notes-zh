# 威利斯-奥佛兰汽车

美国人向来以精明的买家著称。他们会出于本能地从商业的角度来看待自己要购买的产品。他们时刻想着事实和数字，而不是时尚和梦幻。当他们要做一个重要的购买决定时，他们会通过理性的判断，而不是心血来潮或漂亮的图片来作出选择。

这恰恰就是奥弗兰汽车比市场上其他同类汽车销量高的原因。

要弄清楚为什么奥弗兰汽车是世界上同等价格下，质量最好的汽车，并不需要很好的商业头脑。首先，大家都知道，生产 5000 辆汽车的单位成本，肯定要比生产 20000 辆汽车的单位成本高出很多。生产任何东西都是如此。一个制造商每年生产 5000 辆汽车，而他的竞争对手同期生产 20000 辆。我们必须承认，汽车工厂的生产成本中，非生产性劳动力成本，至少和生产性劳动力成本一样高。非生产性劳动力成本包括，领班、主管、簿记员、书记员、办公室人员，以及其他监督真正生产产品的劳动力的人员成本。

假设，一个工厂的非生产性劳动成本，和日常开销费用每年为 1000000 美元，该工厂的汽车产量为 5000 辆。那么，平均每辆汽车的这 2 种生产成本加起来就是 200 美元。但如果这家工厂汽车产量为 20000 辆汽，那么每辆车的成本就只有 50 美元。

所有人都知道，买 1 吨煤的成本，要比买几千吨煤的成本高。同理，其他所有商品也是如此。不论是钢铁、皮革、车轮，还是头发装饰、轮胎、温泉等等。因此，生产 20000 辆汽车的厂家，比生产 5000 辆车的厂家的售价低，因为他购买原材料的成本有优势。

任何可以生产 20000 辆汽车的工厂，一定配有豪华自动设备，以及其他省力、省钱的设备，而这些设备对只能生产 5000 辆汽车的工厂来说，就太昂贵了。所有零部件都必须精确，否则，大批量生产是无法实现的。
