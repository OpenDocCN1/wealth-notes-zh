棕榈就是秘密所在！它不仅仅是一块香皂。棕榈让它与众不同！它能带给你比任何你之前用过的香皂都多的滋养！它能为你带来充满活力，健康的肌肤。它除了清洁肌肤之外，还有舒缓、滋养、美白的功效。它能让每个使用者充满魅力。

# 东方最优质的产品

我们花了 36 年的时间，不断地努力完善一个从东方人那里得到的秘方——棕榈和橄榄油的科学融合。这才造就了棕榈非凡的品质。东方美人在过去的许多年中，一直使用棕榈和橄榄油滋养和保护他们的肌肤。我们通过棕榈向大家展示了，橄榄油和棕榈油是如何完美地融合在一款纯香皂之中的。它不仅可以清洁肌肤，还可以滋养和保护肌肤。因此，棕榈能带给肌肤其他香皂无法带来的功效——而且，这两种油单独使用，也无法发挥这种效果。

# 纯香皂

我们不使用任何人工色素。棕榈中橄榄油使它呈现出了淡淡的绿色色调。棕榈不含任何其他杂质。它含游离碱。所以，可以保护皮肤的天然油脂，使皮肤柔软光滑。

# 在硬水中也能产生丰富泡沫

你一直想要一款不论在硬水，还是在软水中，都能产生柔和，丰富的泡沫的香皂。那么，棕榈香皂就是你的最佳选择。
