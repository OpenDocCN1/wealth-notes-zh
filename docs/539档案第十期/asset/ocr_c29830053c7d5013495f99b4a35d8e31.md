# 如何洗掉黑头

来自：克莱尔·赫夫曼

纽约——知名皮肤科医生今天给一些有皮肤问题的男女，以及青少年展示了，如何用他完善的疗法，在10分钟内清洁油性皮肤，收缩粗大毛孔。之后，他又演示了如何洗掉黑头和白头粉刺，以及青春痘。

当着观众的面，这位医生选择了一个36岁的女性，典型的油性皮肤。她鼻子周围有黑头，毛孔粗大，而且还有肉眼可见的白头粉刺。医生给她的脸上涂了一层油膏。很快，这层油膏凝固，变成了像薄膜塑料似的面膜。接下来，他给这位女士的脸上喷了一些水，并递给她一块普通毛巾，让她洗掉脸上的油膏。让她惊异万分的是，毛巾上不仅有擦下来的肮脏的东西……而且，还有一些多年来一直破坏着她的美丽的黑头。

我们难以置信地盯着毛巾，医生的助理转过身对我们说：“你们刚才看到的现象，就像是一个奇迹。然而，刚刚这位女士做的事情，你在家里也可以轻松完成。但是，要想弄清这个配方对皮肤的清洁作用，首先你必须抛弃一些大多数人都不存在的对皮肤问题的错误认识。”
