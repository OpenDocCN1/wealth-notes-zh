# 亚历山大报告（正常售价 95 美元）…………16 美元

这是我第一次主动进行特价销售，不准备赚一分钱。为什么我要以史无前例的超低成本价向你销售呢？

因为它对我来说有很好的商业意义。请看：

我的客户一年平均向我购买 3 次。每个客户每个订单的平均价格为 50 美元。

如果我这次以非常划算的价格向他们销售时事通讯，比如，我平常售价 225 美元的通讯，卖给他们只要 17 美元——或者我平常售价 39 美元的报告，卖给他们只要 8 美元……那么，每位购买过我的产品的人，是不是肯定会感激我给他们的优惠呢？

他们下一年是不是会向我购买更多的出版物呢？

我想，如果我现在给他们极大的优惠，他们下一年肯定会购买更多。

那么，让 80000 个客户满意，我需要多少成本？我只要利用我正常售价带来的利润所需缴纳的所得税——我每赚 1 美元，要向税务局缴纳 50 美分的企业所得税——把售价降低到成本价即可。

# 我的想法是

这样，我既不用向税务局缴纳所得税——同时还能让我的 80000 个忠诚的客户感到满意。

# 下一年

下一年，我计划做一个更好的方案（让我能更好的避开所有企业所得税）。我敢保证，下一年你会回来向我购买更多。

# 所以，我大胆地

我把本应该是税务局得到的钱，交到了我客户的手里。
