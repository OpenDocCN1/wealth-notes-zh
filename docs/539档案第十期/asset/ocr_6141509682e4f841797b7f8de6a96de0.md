# 秘密是什么？
水下声波震动！

为什么这个看起来像蝴蝶的鱼饵，能疯狂地吸引鱼儿上钩——即使普通诱饵，天然诱饵只能钓到很少，甚至无法钓到鱼？原因很简单——

因为这种诱饵可以发出独特的潺潺的，悦耳的冒泡声——在水下每分钟能发出 200 多次声波振动——我相信，这对鱼儿来说是无法抗拒的！

是的！我相信这种声波脉冲是每个渔夫梦寐以求的！我研究过海洋生物学家有关鱼儿在水中相互之间发出的声音的报告！我看到过鱼群仿佛被催眠似的，跟着一艘船的螺旋桨游动！

我一直相信，如果我能捕捉到这些潺潺的，悦耳的冒泡声，以及水下的震动频率——听起来像呼唤鱼儿一样——并把这种声音放进“震动鱼饵”中，它就能捕到多的令人惊讶的鱼，即使旁边的普通鱼饵很少，甚至没有捕到鱼！即使在普通鱼饵很难捕到鱼的水域，也是如此！
