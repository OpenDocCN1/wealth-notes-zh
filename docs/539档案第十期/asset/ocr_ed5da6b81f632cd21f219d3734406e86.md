# 46、第三者推荐销售信

亲爱的朋友：

今天我给你的是一个内心特别喜欢的提议。确切的说，是我的钱包特别喜欢的。

因为我将向你展示的东西，帮我赚了很多钱。我相信它也可以为你赚很多钱。我内心十分确定，所以，我敢给你一个明确的保证：

如果你尝试这个赚钱公式的机会，你将赚到至少5000美元的额外利润—如果没有这个公式，你永远也可能赚不到的5000美元，否则，你不用花一分钱！

那么，这个公式到底是什么呢？我将告诉你。

过去的几年中，我很幸运地能和一位出色的文案撰稿人鲍勃·瑟琳一起工作。鲍勃曾经撰写过很多强大，带来高利润的文案。

他的点子和文案，仅帮助我的一个项目，就让我的利润增加了917%。你没有看错。百分之九百一十七！

他的文案还为其他很多公司创造了显著的业绩。

不管怎样，我发现鲍勃·瑟琳有一个只给自己客户提供的大师水平文案撰写课程。我自己学完了那套课程，现在我将直接把它提供给你：他的简单，循序渐进的“能量公式”将向任何人展示如何快速成为一个一流的文案撰稿人。一个可以不断写出让销量疯狂飙升的文案的撰稿人。

你有没有投放过一个广告，或一封销售信，你本来非常确定它能带来巨大的反应率，但却失败的很彻底？如果是这样，你就应该知道真正强大的文案的重要性。在这里，我不会详细说明课程内容。相反，我附上了一封鲍勃·瑟琳写给客户的信。它会告诉你如何迅速增加你的销量和利润，这些信息，你在其他地方根本无法看到。
