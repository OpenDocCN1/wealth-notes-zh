# 奇怪的新声音吸引了无数着魔般的鱼！

来自：莱曼·沃尔顿，
共同发明人保罗，一位钓鱼爱好者说道

想想！我新发明的震动诱饵，可以发出潺潺的，悦耳的冒泡声，听起来就像你沿着水面飞掠而过！它在水下每分钟可以发送200次振动！和任何淡水鱼之前听到过的声音都不同。

它的这种奇怪的形状，奇怪的声音，以及奇怪的震动——在某个夏日，它第一次捕鱼的时候——就已经吸引了鱼儿疯狂的攻击，它们似乎都要蹦出水面了。其中有，鳟鱼、鲈鱼、大梭鱼、碧古鱼、狗鱼等等，它在1小时里，钓到了120条鱼，而旁边的鱼饵，几乎很少甚至没有捕到鱼！原因是——

# 大丰收！1小时，抓住120条鱼！

是的！想象一下1941年8月20日，一个炎热的夏日！你坐在伊利诺斯州，香蒲湖畔。前面是一个美丽的池塘——90乘60英尺宽！钓鱼的人尝试着用人造鱼饵，苍蝇，天然诱饵引鱼上钩！但是，这是一个没有钓鱼限制的鳟鱼鱼塘，你们却只能偶尔钓到一条鱼。看起来，今天又要白白浪费了。

然后，你的3个铁杆朋友决定和我一起去试试运气！我们并排坐在湖边开始钓鱼。离我们不远，有一个和我们完全不同的诱饵——一个奇怪的金属小怪物，像子弹，又像蝴蝶飘荡在水中！

# 即使有经验的渔夫也吃惊地看着！

几乎在瞬间，安静的水沸腾了！第1条鱼立刻上钩了，引起了人们的欢呼！然后是第2条，第3、第4、第6、第7、第8条鱼，一条接一条地上钩了！闪闪发光的水面上泛起了美丽的彩虹——每分钟上钩的鱼不少于1条！
