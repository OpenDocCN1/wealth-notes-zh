# 有些地方已经售罄——
还有一些地方，也只剩下几辆

如果你想购买哈德森，那么你必须抓紧行动。超过 100 家哈德森汽车经销商手里的订单，已经达到了我们目前在指定时间内能交付的量。

有些经销商的订单已经超过了他们的分配额度，为了保护自己额外的订单，他们不得不加价向其他汽车经销商购买。我们工厂现在每天平均的新订单，已经超过了我们的生产能力。

所以，你可以看到，我不是在诱惑你购买哈德森，更多的是提醒你，如果你今年想购买一辆高级汽车，请立刻做决定。

因为就目前哈德森的需求量来说，很多人都不得不等到夏末才能提到新车了。

但在一些地方仍有可能买到尚未售出的哈德森。有几个经销商预见哈德森的需求量肯定会很大，所以，提前下了大量订单。如果你所在区域，有这么一个有远见的经销商，那么你非常幸运。在其他地方，估计你没有办法买到本季的哈德森。通过研究这辆高级汽车，尽管你可能短期内无法买到。但是，你至少可以确定下一辆汽车要买什么样的。
