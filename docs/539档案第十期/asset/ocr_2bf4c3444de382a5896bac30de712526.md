泰德·约翰逊

亲爱的泰德：

我写信是想告诉你一个很大的潜在利润投资机会，我想你一定会感兴趣。

我正在向一个精准市场投放一款信息产品。这款产品我已经研究了数月，非常有潜力。

这个市场有140000名专业人员，平均年收入超过70000美元。像许多专业人士一样，这个群体对他们的产品和服务的营销做的却非常差。所以，我开发了一款产品，教他们如何更加成功地销售自己的产品和服务，售价约600美元。

通常，在目标市场中，你会得到5%—10%的反应率。按最低的5%算，年销售额将达到4200000美元。

```
140000 X0.05 = 7000
```

```
7000 X 600美元 = 4200000美元
```

记住，这些数字还只是前端销售额。通过后端，我们还能销售各种各样的附加产品和服务。

我想为这个项目筹集125000美元。最低投资额为10000美元起步。报酬将根据最后的收入而定。下面是报酬的设定方法：

+   1. 你的初始投资资金将全额偿还。此外，你每年会得到初始投资额度60%的回报。
