# 史无前例，超低价特别报告

尊贵的朋友：

我的企业在 1984 年这一年，发展的特别好。事实上，我的企业所得税比去年上升了 2.5 倍。如果我们今年赚的再多一点，所得税的问题会更严重——我需要向税务局缴纳更多的钱。

# 我的问题就在于此

你看，我不想解雇我的员工。在今年结束之前，我还要卖出很多时事通讯——以及我之前承诺的 5000 个不同的行情报告。

# 总结起来，很简单

我必须开发更多的业务——不仅为了支付员工工资，也为了实现我对出版商的承诺。但是，如果我通过它赚到利润的话，我的所得税问题会更严重。所以，我做了一个大胆的决定——我想其他任何人都不敢这么做。

我决定以成本价向你提供时事通讯和特别报告。所得收入只要够支付出版商，还有其他必须的订单处理成本即可——此外，不多收一分钱。

（这么算下来，时事通讯只要 13-25 美元——它们的通常售价是 77-250 美元——报告只要 10 美元，甚至更少，是通常售价的 85-90% 。）

换句话说，我是在零利润为你提供时事通讯和报告。你只要承担我把它送到你手中所需的成本。
