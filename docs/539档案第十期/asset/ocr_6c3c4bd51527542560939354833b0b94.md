# 关于作者

泰勒 G.希克斯，通过他在书中提到的方法，给自己和别人创造了很多财富。如今，他有好几个自动收入。之所以说“自动”，是因为他每周只要花不到 2 天的时间监管这些业务的运行——他有充足的时间去旅游，娱乐，做自己喜欢做的事情！

更神奇的是，他开始寻找这些财富之时，他没有任何人脉，没有任何钱，他的父亲在他 14 岁时就去世了。如今，他是许多有抱负的财富创造者的个人顾问。他还会出席一些公司的商业计划制定会议，咨询费为 1 小时 50 美元。

在他的职业生涯中，希克斯先生投资过的业务有酒店，公寓房，出租房地产，划船，航运，出版，娱乐，股票，印刷，工程和剧院等等，都赚了大钱。他目前拥有几个重要的服务行业，还撰写了 3 本畅销书：《如何利用业余时间，创建第二份收入》、《通向财富的捷径秘密》、《如何以极少的钱开启自己的事业，并实现年入 100000 美元》。
