# 萧何藏书

沛公刘邦攻克秦国都咸阳后，诸将争相抢夺金帛财物，吵闹时有发生。萧何则对金帛财物连看也不看一眼，而把无人问津的秦丞相、御史的律令、图书等小心翼翼地收藏了起来。后来刘邦洞悉天下的险关要塞、户籍、豪强富户 的财产及百姓的疾苦等方面的情况，主要得益于萧何收藏的秦律令、图书。

# 卓氏求远

因夜奔司马相如而传为千古佳话的卓文君是大富豪卓王孙的女儿。卓王孙的祖先是赵国人，靠冶铁为业，成为天下有名的富豪。秦国灭亡赵国后，下令把富豪迁徙到蜀地。卓氏夫妻也在其中，推着小车艰难地走着。其他富豪因手头存有少许钱财，便争相贿赂负责押送的官吏，请求迁徙到比较近的地方居住。于是，他们在一个叫葭萌的地方安顿了下来。唯有卓氏对妻子说：“葭萌土地贫瘠，百姓贫穷，在这里居住不会有所做为。我听说峨山之 下，沃野千里，物产丰富，从未发生过灾荒，并且交通方便，是经商的好地方。”因此，他们主动请求到最偏远的临邛落户。到了临邛后，他们广置田产，经营商业，还开发了铁矿。不久，卓氏就成了天下屈指可数的大富豪。卓氏的见识，确实有过人之处啊。
