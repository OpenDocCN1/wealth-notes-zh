# # 弱 敌 术

战争的 目的是取胜，而削弱敌方势力，改变力量对比，进而消灭敌方，无疑是事半功倍的策略。弱敌术不拘一格，具有隐蔽的特点。使用此术，一旦被敌方识破，不仅不能奏效，反倒打草惊蛇，对己方不利。因而高明的决策者，务必要做到含而不露，使敌方无法察觉。宁越归尸罪齐，可说是弱敌术的升华。当然，弱敌术不仅用在军事上，在名利角逐中，都有可能派上用场。

# ## 文 种 伤 农

勾践回到越国后，朝思暮想，打算灭吴复仇，大夫文种建议伤害吴国农业。因为当时农业是立国之本，农业垮了，国家也就完了。恰逢那年越国大旱，向吴国求援，吴国送来了大批粮食。第二年，越国大丰收，吴国的收成却不好。越国借口还粮，文种带人把煮过的粮食运到了吴国。吴国人见越国的粮食颗粒饱满，便纷纷留作下一年的种子。第二年种下去后，没有发芽，造成绝收，因而闹了大饥荒，国力削弱，为越国灭吴创造了有利条件。
