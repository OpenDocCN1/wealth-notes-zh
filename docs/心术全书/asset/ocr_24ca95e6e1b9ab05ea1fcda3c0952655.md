# 邹忌间田忌

战国时，齐相国邹忌和将军田忌怎么也合不来。邹忌为此十分苦恼，因为没有什理由，随意排斥战功赫赫的将军并非易事。有个部下看出了他的心思，说：“您可建议让田忌率军进攻魏国。如果胜了，说明您决策有方，功劳少不了有您一份；如果败了，就要追究将军的责任，他会名声扫 地。您看如何？”邹忌依计而行。田忌受命出战，在孙膑的协助下，连战连胜，捷报频传。田忌由此声名大振，邹忌反倒被人淡忘了。

一计不成，邹忌又派自己的部下假造成田忌的部下执行第二套方案。不久，国都临淄大街上的一个算命先生向国君告发，说有一个自称是田忌将军部下的人，去找过他，说：“我家主人连战连胜，名扬天下，理应为王，你给算算是吉是凶。”这些话很快传到了田忌耳朵里，他深知自己处境危险，难以辩解。为了保全性命，就逃到楚国去了。

邹忌在胜局已定的情况下还不放心，又采取了第三步行 动。在一般人想来，大概是向楚王说一些中伤的话。可是邹 忌恰恰相反，极力赞扬田忌。他得知楚国大臣杜赫很得楚王 宠信，就送上下厚礼，请杜赫对楚王说：“齐相邹忌一直担心 逃来的田忌会率楚军攻齐，由此他对楚国怀有敌意。这样一 来，楚国就危险了。不如封给田忌一部分土地，让他解甲归 田，以表明我们没有进攻齐国的意图。如此邹忌的戒心就会 消除，与我们友好相处，田忌也会对大王的容留和封地感恩 不尽。”楚王采纳了杜赫的建议，在江南选了一片地封给了 田忌。
