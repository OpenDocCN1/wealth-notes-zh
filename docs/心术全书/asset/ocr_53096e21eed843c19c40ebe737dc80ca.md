# 胆识术

要想做成大事就必须有胆量，而胆量则受见识的制约。譬如一个人，知道水能淹死人，便不下水；知道火能烧死人，因而不到火中去。不下水，不进火，并不说明没胆量，而是见识不允许。如果自信水火不伤身，又有什么必要害怕呢？见识贮藏在头脑之中，像君王一样发号施令；胆量就像臣子，唯命是从。胆量不足的人，要用见识来强化；胆量有余，则要靠见识来抑制。见识可以产生出胆量，胆量却不能产生出见识。遇事英明果断，处理得体，便是有见识的表现。自觉见识不足，就应注意向聪明人学习。随着见识的增长，胆量也就增大了。

# 完璧归赵

秦昭王听说赵王得到和氏璧，十分眼馋，很想弄到手，就写了一封信给赵王，要求用十五座城池换玉璧。这可让赵王犯了难，给吧，怕秦王不守信用，白白丢了玉璧；不给吧，又怕惹恼秦王。正在犹豫之际，有个叫蔺贤的宦官向赵王推荐了自己的门客蔺相如。赵王立即召见了他，问：“先生能上秦国办这事吗？”相如说：“假如没有合适的人，我愿意带着玉璧前往。请大王放心，如果十五座城交给赵国，玉璧就交给秦国；不然的话，我一定把玉璧完好地带回来。”
