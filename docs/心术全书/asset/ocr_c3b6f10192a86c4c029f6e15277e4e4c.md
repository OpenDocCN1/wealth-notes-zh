# 烧 井 栏

文彦博在成都任职时，常在雪夜大宴宾客，饮至深夜不散。士卒在风雪中守卫了半夜，饥寒交迫，愤怒异常，诅咒饮酒的官员们不体恤下属的冷暖。为了发泄，他们故意拆掉井栏，点燃烤火。有个军校跑来报告，宾客们听了腿都吓酥了，不知该怎么办好。只见文彦博不慌不忙地说：“天的确很冷，拆井栏烧，算得了什么事？”他神色自若，饮酒如故。那些憋足了劲准备闹事的士卒，因找不到闹事的理由，一个个全像漏了气的气球，无精打采地散去了。第二天，文彦博才追问烧井栏的事。很快查出了鼓动的人，把他狠狠地打了一顿板子，驱逐出官府。

# 驿 舍 火

宋英宗时，苏颂担任度支判官。一次，他陪同契丹使者回国，住宿在恩州。半夜时分，驿站客舍着起了大火。手下人请他出外避火，苏颂不同意；当地的士兵想入内救火，苏颂还是不同意，只是传令守卫驿站的士卒把火扑灭。原来这场大火是有人故意放的，目的是想以此诬陷契丹使者制造事端，并试图让不明真相的当地士兵趁救火之机杀死契丹使者，进而达到离间宋朝和契丹关系的目的。由于苏颂看出了有人制造事端的险恶用心，因而既不让手下人出去，又不让受煽动的士兵进入，使制造事端的人无懈可击，从而保证了契丹使者的安全，维护了宋朝和契丹的友好关系。
