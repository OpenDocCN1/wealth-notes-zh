# 明察术

心术之所以神奇，是因其建立在明察的基础之上。孟子赞颂舜帝“明察并举”，是说既要目光敏锐，明辨是非；又要观察入微，洞悉事理。目光不敏锐，就不能观察入微；不能洞悉事理，就显示不出贤明。太阳当空，任何缝隙都会显现出来。这么说，难道社会上再没有黑暗，再没有不白之冤了吗？实际远非如此，但只要执法者能够明察，人们也就没有遗憾了。

# 还剑
