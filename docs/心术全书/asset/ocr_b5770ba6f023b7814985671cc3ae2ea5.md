# 李 及 观 书

曹玮在秦州任职多年，因年老多病，多次向皇帝呈交奏章，请求朝廷派人接替自己。宋真宗问宰相王旦说：“由谁来接替曹玮合适呢？”王旦考虑再三，推荐了李及，宋真宗也表示同意。众人则觉得李及虽然小心谨慎，办事公道，并有一定的政绩，但他缺乏威武果断的气魄，恐怕难以胜任守卫和管理边境的职务。老臣韩亿也有这种看法，就对王旦说了。王旦听后笑了笑，什么话也没说。

李及到了秦州，秦州的将领和官吏见来了个文弱书生，都有些轻视他。一天，有个禁军士卒大白天在集市上强抢民女的银钗首饰，被捕吏当场抓获，押送到官府。李及正在看书，听完报告后，命人把禁军士卒押上来。略加审讯，禁军士卒就认了罪。李及干脆超越其它管理手续，把禁军士卒立即斩首。接着，他又看书如故，好像根本没发生过什么事情，将吏们无不惊叹佩服。

不久，李及处事果断的消息传到了京师。老臣韩亿听说了，又去拜访王旦。把他听到的原原本本地对王旦说了一遍，还极力称赞王旦知人善任。王旦平静地说：“禁军士卒光天化日之下当强盗，边帅就地处斩，是很平常的事，没有什么可值得大惊小怪的。我让李及代替曹玮，并不是出于这方面的考虑。试想曹玮管理秦州已达七年之久，西羌人对他都佩服气。两国和睦相处，没有发生什么事端。可以说，曹玮已经把边境上的事安排的稳稳妥妥的了。如果派他人接替曹玮，必然会自以为聪明，轻易地改变了曹玮的治理措施。这样一来，曹玮多年来开创的局面就付之东流了。之所以派李
