# 选 才 术

在一个群体内，如何选用人才，能否举贤任能，决策者起着至关重要的作用。决策者不但要有主见，而且要有正确的主见。看一个人，不能只听他个人讲得如何，也不能只听周围的一些人说他怎样，而应听其言，观其行。这样才能明是非，辨真伪，得出鉴别人才的正确结论。决策者要善识关于人才的褒贬之言，特别是对于自己身边人的议论，更要明察公断。否则，就会是非颠倒，贤愚莫辨。

# 魏文侯拜师

魏国有一个叫段干木的人，很有名望，隐居在一条偏僻的小巷里，不肯出来做官。魏文侯想向他请教治理国家的方法。有一天，他坐着车亲自到段干木家拜访。不料段干木听到文侯的车马声响，赶忙翻墙头跑了。魏文侯无奈，只好转身回去了。以后又接连去了几次，段干木都不肯相见。但魏文侯并不灰心，每次乘车路过他家门口时，都要站起身，扶着马车上的栏杆，伫立观望，以示敬意。车夫很不以为然，说：“段干木不识抬举，对这样的人您还理他干什么？”魏文侯说：“话可不能这么说，段干木品德高尚，学识渊博，我不能不尊重他啊！”
