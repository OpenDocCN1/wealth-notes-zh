# 统御术

作为一个领导者所应重视的，并不是下属工作的成果，而是要懂得统御部下的技巧。在世间所有的艺术中，再没有比领导者的统御艺术更复杂、更捉摸不定的了。统御术主要包括以下内容：考核下属是否言行合一；有过必罚，以示威严；有功必赏，以服人心；注意每个人的言论，切忌信口开河；善用计谋；故意试一试对方；以陷阱试探对方。成功的统御术的标志是：下属将事业上的成功与发展，视为自己的事业而倍加关心，并且没有被束缚、受制约的感觉。

# 管仲献策藏粮

齐国粮食大丰收，粮食价格大幅度下跌。齐桓公怕粮食流向其他国家，想让百姓把粮食贮藏起来，问管仲有什么好办法。管仲说：“刚才我在街上见有两家修了新粮仓，主公可把这两家的主人请来当官，用璧玉作聘礼。”齐桓公照办了。消息传开后，齐国家家兴修粮仓，丰收的粮食全都贮藏了起来。
