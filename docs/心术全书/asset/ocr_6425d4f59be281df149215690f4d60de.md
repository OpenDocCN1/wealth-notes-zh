# 张咏劝植桑

张咏担任崇阳县令时，见百姓大多以种植茶叶为业，生活富裕，就说：“种茶利润丰厚，朝廷早晚 会实行茶叶专卖，不如及早改种桑树。”于是下令拔茶植桑，茶农虽然想不通，但由于张咏平素有令必行，很有威望，都忍痛拔掉茶树，改种桑树。种桑养蚕，抽丝织绢，收入与茶叶相近。几年后，朝廷果然实行茶叶专卖，其他县的茶民都失了业，怨声载道。唯有崇阳县早已改种桑树，百姓生活未受影响。百姓感激张咏，纷纷出钱出物，修建了一座庙纪念他。

# 王 琼 出 贤

王守仁是一个很有才干的人，曾任兵部主事。由于得罪了权贵，一直倍受压抑，没有施展才能的机会，被贬谪到江西任闲职。兵部尚书王琼对王守仁很了解，一直想找机会重用他。福州三卫军人发动叛乱的消息传来，王琼趁机推荐王守仁率军平叛。有人说：“叛乱规模并不大，何必要调王守仁去呢？”原来王琼已经预料到宸濠将要谋反，才故意把王守仁从江西调到福州，为日后平叛做准备。可又不便明讲，就含糊地说：“福州平叛的确没必要调动王守仁，我不过是让朝廷重用他，以备将来出现大的变故时，他能够从容应付。”于是，他发出檄文，派遣王守仁到福州平叛。不久，宸濠果然发动叛乱，江西守臣全被诱捕处死，只有王守仁因在外平叛而幸免于难。由于他手中握有朝廷的平叛敕令，便立即兴兵讨伐宸濠。
