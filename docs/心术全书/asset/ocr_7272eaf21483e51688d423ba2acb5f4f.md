# **宓子不害世风**

孔子的学生宓子任亶父县令时，正赶上齐军入侵鲁国，亶父是必经之地。听说齐军快到了，亶父一些有名望的人向宓子请求说：“地里的麦子已经熟了，请您下令让百姓随便收割吧。无论是不是他种的，可他毕竟是亶父百姓，总比留在地里让齐军抢去好。”一连请求了几次，宓子坚决不同意。

几天后，齐军打了过来，把麦子抢掠一空。季孙氏知道后大发脾气，派人去责骂宓子。宓子不以为然地说：“今年收不到麦子，明年可以再种。如果有人不劳而获，他们就会盼望敌军再次入侵。一年收不到麦子，对亶父的影响是不大的。但如果让人们有了侥幸之心，世风就会变坏。由此而带来的危害，恐怕几代人都难以消除。”

# **董安于远虑**
