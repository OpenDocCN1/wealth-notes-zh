# # 蜜中鼠屎

三国时期，吴国幼主孙亮出游西苑，正值吃黄梅的季节。他就派了一个黄门到仓库去取蜜淹渍的梅子。黄门取回后，孙亮发现蜜中竟然有鼠屎。他很生气，询问黄门是怎么回事。黄门说从仓库中取来时就是这样。孙亮又把管理仓库的官吏传召来，让他说明情况。那官吏则说从未发现蜜中有鼠屎。孙亮说：“这好办，把鼠屎剖开看看就知道了。”他命人把鼠屎剖开，见里面是干燥的，就说：“鼠屎如果早在蜜中，应该里外都是湿的。而这些鼠屎却是外湿内干，说明是刚刚放进去的，肯定是黄门想陷害栽赃！”黄门无奈，只好伏地请罪。
