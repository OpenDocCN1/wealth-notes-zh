# 张良计调项羽

项羽兵围荥阳，因城里兵力空虚，韩信大军又一时调不回来，形势对汉军十分不利。楚军捉来汉军大将王陵的母亲，项羽便派使者去见王陵，声言他如果不来投降，就杀了他的母亲。

张良乘机派了一个人到楚营求见王陵的母亲。王陵的母亲为了不使儿子为难，就当着汉军使者的面自杀了。项羽对使者说：“你回去告诉刘邦和王陵，让他们赶快投降，否则别说我不客气！”使者走到项羽跟前，小声说：“我是叔孙通，汉王有眼无珠，对我不加重用。我可以劝说王陵来安葬他的母亲，至于去留，还不是随大王您的便？”项羽问：“城里有多少兵马粮草，刘邦为何还不投降？”使者说：“城里的汉军有二十余万，粮草还算充足。按理论刘邦早该出战，可他别有所图。他想把您拖在荥阳，暗地里派韩信去进攻大王的的都城彭城。等拿下彭城后，再移师荥阳，里应外合，歼灭大王的军队。”项羽有些被说动了，又问：“你打算与王陵什么时候来？”使者说：“找到机会马上就来，不过大王可得注意彭城那边的动静啊。”使者走后，项羽一面抽调主力部队去防守彭城，一面等待王陵和叔孙通来降。其实那个使者根本就不是叔孙通，而是张良为了调回项羽，有意让使者诈称叔孙通。
