# 李 林 甫 离 间 李 适 之

唐玄宗时，宰相李 林甫 和李适之同任相职。一天，李林甫对李适之说：“华山发现了大金矿，开采后可以增加国库收入，可是皇上并不知此事。”过了几天，李适之把华山发现金矿的事对唐玄宗说了。唐玄宗又问李林甫知不知道这件事，他说：“臣下早就知道了，只是因为华山是皇上本命王气所在，不宜开凿，所以我考虑再三，始终没敢向陛下提起这件事。”唐玄宗听了，觉得李林甫更尊重自己，便疏远了李适之。
