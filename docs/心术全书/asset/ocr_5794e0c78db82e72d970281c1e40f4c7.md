# 郭子仪交军权

郭子仪兵败邺城，损兵十万，遭到了宦官鱼朝恩的排挤。唐肃宗听信谗言，决定召回郭子仪，改派李光弼接管兵权。郭子仪素来爱兵如了，在军队中拥有极高的威望。将士们听说了郭子仪回京的消息，全都哭泣着拦住道路，请求中使让他留下。郭子仪深知君命不可违，再说自己不回京师，会招来更多的谗言。但他又怕士卒知道真相后发生哗变，便借口为中使送行，轻装离军，对阻拦他的将士说：“你们搞错了，我怎么会走呢？我这不过是为中使送行。”将士们信以为真，立即让开了一条路，郭子仪趁势上马，飞驰而去。当天傍晚，李光弼率五百人接管了军队，军心安定了下来。

# 种世衡运庙梁

种世衡任漕池知县时，打算修葺城外一座古庙。庙的主梁又粗又长，无法运上山。种世衡就让县里的几个衙役剪断头发，装扮成武术师，并放口风说要在山上举行大比武。人们听说后，蜂涌上山观看。种世衡说：“大家去把庙梁抬上山，然后看武术表演。”众人欣然下山，齐心协力，把主梁抬上了山。种世衡的做法近于欺骗，他应该让众人看到真正的武术表演，否则会失信于民。
