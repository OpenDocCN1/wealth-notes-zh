# 吃素救宋濂

朱元璋当了皇帝后，为了巩固自己的地位，经常杀戮功臣。一天，他因一点小事恼怒宋濂，顿生杀心。马皇后得知后，开始吃素。见朱元璋不解，她说：“听说要杀朱先生，妻不能救他，只好用吃素的的方式为他到阴间祈祷。”朱元璋顿悟前非，派人赦免了宋濂。

# 刘延清谏乾隆

乾隆年间，西域刚刚平定，户部奏闻各地府库大多空缺无物。清高宗大怒，想撤免一大批州县官员，用专门从事满汉文翻译的笔帖式官员取而代之，便派人把刘延清召来，询问他对这个问题的看法。高宗说：“朕已思考了三天，您觉得怎么办才好？”刘延清低下头，默言不语。高宗等得不耐烦了，厉声斥责他。刘延清慢慢地说：“皇上圣明，尚且思考了三天，我人老头昏，怎么敢随便说出看法？请允许我回去好好想想。”第二天，刘延清上朝对高宗说：“州县官员是直接管理百姓的，应该让身为百姓的人担任。”于是，高宗取消了原来的计划。
