# 狄青占卜

狄青在征讨侬智高时，大军行至桂林之南，他下令停止行进，说：“胜负没有把握，应该算一算。”说着，他像变戏法似的，从身上掏出了一百个铜钱，做出十分虔诚的样子，与神约定说：“如果这次出师大获全胜，钱抛下后，全都正面朝上。”左右幕僚怕他占卜不尽人意，影响士气，纷纷劝他不要抛钱。狄青不听，坚持要抛。儿万名将士屏住气息，等待着占卜的结果。只见狄青的手猛然一扬，一百个铜钱散落到了地上。神了！钱的正面全都朝上。全军将士欢声雷动，声震环宇。狄青面带微笑，命左右把铜钱原封不动地钉在地上，用青纱盖住，并亲自打上封结，然后高声宣布：“等我们凯旋时，再来祭祀天神，致以谢意。”由于士气高涨，狄青很快消灭了叛军，平定了邕州。班师还朝时，经过占卜处，全军隆重地祭祀了天神。祭祀完毕，狄青亲自拿起铜钱给将士们看，却原来钱的两面是相同的。由于桂林一带山高林密，地势险要，来自中原的将士到了此地情绪不稳。于是，狄青借神鼓舞士气，坚定了将士们的必胜信心。
