# 颜真卿杀叛将

安禄山发动叛乱，攻陷东都洛阳，斩杀了唐将李愔等人。随后，派段子光带上李愔等人的首级，送到河北道示众。平原太守颜真卿想严惩叛将段子光，故意对诸将说：“李愔等人我全认识，段子光送来的全不对，是来欺骗我们。”说着，不容分辨，命手下人杀死了段子光，埋葬了李愔等人的首级。

# 赵匡胤送客索钱

赵匡胤杯酒释兵权后，石守信等执掌重兵的人都得到了封地。过了几年，赵匡胤又担忧他们手上钱太多易生他念，就在京师每人赐给一块土地，让他们修建府第，结果每人花费了数万金。府第落成后，赵匡胤为大家设宴庆贺，见石守信等人快要喝醉了，便宣告他们的子弟搀扶着回去，并亲自送他们出殿。在大殿门前，赵匡胤说：“你们的父亲都是忠臣啊，他们今日答应每人上交朝廷十万缗钱”。石守信等人酒醒后，都问是怎么回来的，是否在皇帝面前失态，子弟们就把赵匡胤的话学说了一遍。石守信等人虽记不清醉后说过这些话，可既然皇帝这么说，只能认为说过。于是，纷纷倾缴上交了钱。
