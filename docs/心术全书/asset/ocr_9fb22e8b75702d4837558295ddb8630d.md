# 敬 走 婢 女

有个叫陈石渠的人，年近四十岁了，还没有儿子。他有 心纳房妾，只因夫人李氏十分嫉妒而不敢明说。姨母可怜他 没有后代，就送给了他一个婢女。陈石渠把婢女带回去后， 不敢说要约为妾，只说是姨母送的婢女，准备以后慢慢想办法。李氏弄明白了事情的原委后并不声张，对婢 女 十分 谦 卑。一大早，她就起来替婢女准备好洗脸水。一日三餐也全 由她一人操办，绝不让婢女伸手。到了晚上，她又为婢女铺 好被褥。过分的恭敬，使得婢女局促不安。不久，婢女就主 动请求回到陈石渠姨母家里去了。
