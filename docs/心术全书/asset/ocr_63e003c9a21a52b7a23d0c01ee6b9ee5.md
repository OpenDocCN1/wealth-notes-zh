# 敷衍术

为人处世，得体为宜。有些事需要认真去做，有些事则可敷衍了事。对于信口乱说的人，最好不动声色，胡乱回答，使其无懈可击。怒极之人，往往言不由衷，负气行事。此时，你千万不要坚持反对意见，否则，只能会弄巧成拙。不妨表面上顺从他的意见，而在具体执行时则大打折扣。如果完全照办，只能造成对谁都不利的结局。

# 虚问虚答

齐景公对晏婴说：“东海里边，有古铜色水流。在这红色的水域里面，有枣树，只开花，不结果，是怎么回事？”晏婴说：“从前，秦缪公乘龙船巡视天下，用黄布包裹着蒸枣。龙舟泛游到东海，秦缪公抛弃裹枣的黄布，使那黄布染红了海水，所以海水呈古铜色。又因枣被蒸过，所以种植后只开花，不结果。”景公不高兴地说：“我随意发问，你为什么对我乱治一气？”晏婴说：“对于胡乱发问的人，最好的办法是胡乱回答他。”
