# 白 起 祠

唐代贞元年间，咸阳人流传着秦代名将白起显灵，请求为国家保卫边陲的话，并流传着白起预言正月吐蕃将要大规模入侵的消息。不久，吐蕃果然袭扰边境。由于唐军早有准备，将士拼死力战，吐蕃军被击溃。这一来唐德宗相信了白起显灵的事，准备在京师修建白起祠，追封他为司徒。李泌劝谏说："臣听说国家将要兴盛，就听从民声，顺从民意。如今边境将帅奋勇杀敌，凯旋而归，陛下却要褒赏白起。臣以为这样会涣散军心，导致边防解体。况且在京城修建庙宇，举行盛大的祭祀活动，势必要影响全国，导致巫风盛行。我听说在邮那地方早就建有白起祠，何不命有关人员修整一番？这样做不会产生太大影响，白起即便真能显灵，也未必不满意。"唐德宗听取了他的意见。

# 崔群不奉诏

崔群主持翰林院事务，唐宪宗赞赏他理事正直果断，下诏让学士们有事不必奏明皇上，可直接对崔群说，由他归纳后呈报皇上。崔群见诏，马上叫见唐宪宗，说：“翰林学士要奏明的事，都是有据而发。如果不直接向皇上奏明，以后负责翰林院的人万一是搞阴谋诡计的，那么学士们有利国计民生的主张，就无法向皇上奏明了。”遂不奉诏。
