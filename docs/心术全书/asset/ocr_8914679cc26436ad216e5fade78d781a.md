# 挟 制 术

挟制术是依靠势力或抓住对方弱点，强迫对方服从的技巧，多用在下列情况中：一是以君王之命号令天下，凭借君王的威望，达到民望从，雄杰服，在政治上占据优势的目的；二是处境困难时，用武力挟制对方头面人物，强迫他服从己方的意愿；三是抓住对方的短处，使之不敢加害于己。挟制术是一种非常手段，使用时要审时度势，迅速制服对方。切忌随意滥用，反受制于人。

# 郑庄公假托王命

春秋时，周天子虽然已经失去了往日的权威，但仍具有极大的号召力。郑庄公打算征伐宋国，可是宋国爵位高，论地盘也比郑国大，必须以周天子的名义，再取得诸侯的支持，才有成功的可能。于是，他带上祭足去朝见周天子，以便制造受命伐宋的假象。谁知他到了周王室，却受到了周天子的冷遇。原来周天子和郑庄公早有矛盾，郑庄公曾指使手下人抢劫过周王室的庄稼，周天子对此事一直耿耿于怀。见郑庄公来朝见，周天子想乘机羞辱他一番，便不阴不阳地说：“今年的庄稼我可以自己留着吃了吧？”郑庄公嘴上虽然不说，心里却挺不痛快。周天子也不设宴招待他，反倒派人送来十车谷子，想成心气气他。
