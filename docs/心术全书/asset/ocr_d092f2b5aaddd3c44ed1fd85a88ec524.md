# 察 奸 术

在世界万物中，人是最为复杂、神秘的生命有机体。人的复杂性与神秘性不仅在于其心理状态与行为方式的捉摸不定，更表现在人还具有故意掩盖这些心理与行为的高超能力。作恶的人往往借用这种能力掩饰罪恶，以求蒙混过关。要想揭去伪装，必须洞悉做恶人的内心秘密，具有深刻、准确和巧妙的判断力。这种判断力主要得力于五种行为模式：闻其言而知其人的言语判断；观其行而知其性的行为判断；捕捉眼神和面部表情信息的神情判断；服饰判断；显示个性的嗜好判断。

# 老太太引出杀人犯

唐太宗贞观年间，衡州板桥店老板张迪的妻子回娘家去了，店里住进了卫三、杨真等三位客商。三人因有急事，次日凌晨就上路了。可他们做梦也没想到，那天夜里有人用卫三的刀杀害了张迪，而后把刀插回了刀鞘。天亮以后，店里的人发现老板被杀，就去追赶卫三等三人。追上后，发现卫三的刀上沾有血迹，便把他们扭送到了官府。酷刑之下，三人忍受不过，违心地认了罪。
