# 战 栗

南朝梁代人萧琛，字希瑜，自幼聪慧过人，才辩出众。一次，梁武帝大会宾客，因一时高兴，抓起一枚红枣扔到萧琛身上。萧琛下意识地抓起一枚栗子抛了过去，可巧打在梁武帝脸上。众宾客见状都很害怕，谁也不敢出声。萧琛却轻松自如地说：“陛下投给臣下一颗赤子，臣下自然敢在陛下面前战栗了。”他巧妙地把红枣比作赤心，又用“战栗”谐音“战慄”。众宾客全被萧琛的“解释”逗乐了，梁武帝也从挨臣子打的窘态中解脱了出来。

# 好生陛下大德

武则天召徐有功进殿，斥责他说：“我听说你判案经常出错，这是为什么呢？”徐有功说：“我的微小过失，陛下便能明察，这正显示出陛下过人的才智啊！”武则天听了很受用。
