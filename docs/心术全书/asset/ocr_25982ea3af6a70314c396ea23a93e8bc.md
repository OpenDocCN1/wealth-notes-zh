# 石 显 固 宠

汉元帝时，石显任中书令，专权朝政。怕有人在汉元帝面前说自己的坏话，他经常故作忠诚，并且想用一件事来打动皇帝，使之不再对自己有什么疑心。一天，汉元帝派石显到各官府中征集财物，他趁机说：“我怕一大早宫门不开，影响公务，请皇上诏令把守宫门的官员，到时候能为我开门。”汉元帝答应了。石显便有意半夜时分进宫，并声称奉了皇上的诏令。把守宫门的官员不敢怠慢，开门放他进去。

第二天，果然有人上书，告发石显假传诏令，半夜时分擅自进宫，行踪诡秘，请求查办。汉元帝看了上书，笑着拿给石显看。石显装做受了很大的委屈，哭泣着说：“由于陛下过分看重我这个无能之辈，一些人恼恨嫉妒，时常想陷害我。”从此，汉元帝对他言听计从，宠信尤加，没有谁敢说坏话了。

# 王 莽 退 选

西汉末年，王莽为了进一步控制朝政，决定给年仅十二岁的汉平帝刘衍娶亲，以便让自己的女儿当皇后。于是，太皇太后王政君下了一道命令，要全国名门世家的适龄少女向有司报名。王莽看了名单，觉得不仅人数众多，而且王氏家族的女子占去了一半，自己的女儿能否入选没有把握。为此，他采取了以退为进的策略，推说自己没有特殊才能，女儿也没有出众的容貌，故而请求王政君允许自己的女儿退出竞选。王政君没看透他的用心，就批准了。这一来惊动了王莽的亲信心腹，他们纷纷进言，认为非王莽女不足以立为皇
