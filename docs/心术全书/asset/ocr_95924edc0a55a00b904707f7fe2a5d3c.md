# 保 身 术

古话说，害人之心不可有，防人之心不可无。世上总有一些居心叵测的人，时时觊觎可乘之机，无事生非，损人利己。善于保身的人，能够明辨是非，精以应对，使之无可乘之机。尤其是身处逆境，亦能苦撑下去，既看到自己的劣势，又看到自己的优势，用理智来分析所处的现实，继续朝着既定目标迈进，变不利为有利，避免自身受到伤害。

# 芮 伯 献 马

周厉王派芮伯讨伐玦国，大获全胜。芮伯在战利品中发现了一匹好马，准备献给周厉王。芮季劝告说：“你应该把马丢掉。我听说周厉王是个贪得无厌的人，他的欲望是无法满足的，并且爱听信谗言。你献上一匹好马，他会认为你得了许多匹好马。别的大臣也会乘机向你索取财物，你如果不能满足他们的要求，他们就会说你的坏话，这样你就很危险了。”芮伯不听，把马献给了周厉王。几天后，周厉王的宠臣荣夷公派人向芮伯索取财物，遭到了芮伯的拒绝。荣夷公怀恨在心，对周厉王说：“芮伯征讨玦国，得到了数不清的财产，可他全都据为己有了。”周厉王听了很生气，就把芮伯赶走了。
