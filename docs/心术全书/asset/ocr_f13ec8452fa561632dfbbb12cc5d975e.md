# # 察 色 术

观察人有各种角度，有的从人际关系中观察，有的在成败的关键时刻观察，有的在生活细节上观察，最直接、最有效的方式莫过于察言观色。人的面孔往往是心灵的窗口，那怕是极微小的变化，都有可能负载着心灵的信息。因而善于观察的人都有敏锐的眼力，能在对方转瞬即逝的脸部表情中，捕捉到内心世界的隐密。察言观色的能力是可以培养的，只要你注意锻炼自己的观察能力，就可以探测到对方心灵的秘密。
