# 荆花杀人

单县有一对农民夫妇感情融洽，过着甜美的生活。一天，丈夫在地里干活。中午时分，妻子送去了可口的饭菜，不料丈夫吃完饭，竟暴死在田间。公公觉得儿子死得奇怪，认为是儿媳妇有外心，所以毒死了儿子，便告到官府。官府把儿媳妇抓去，她因受不了皮肉之苦，屈打成招，被关进死囚牢，等到秋后处决。

许襄毅当时在山东任职，到单县巡察时，翻阅了待决死囚的卷宗。翻阅到这一案件时，他仔细地看了半天，自言自语地说：“夫妇相守，白头偕老，是人们的最高追求。下毒杀人，是各种诡计中最隐秘的，哪有乘送饭的机会毒死丈夫的道理？肯定事出有因。”于是，他重新提审了女子，详细地询问那天送饭的情况。女子说：“那天送的是鱼汤和米饭，丈夫吃得很高兴，不料吃完就死了。”许襄毅问：“送饭时路上有些什么？”女子说：“路两旁有一片荆树林，正开着荆花，除此之外没有别的。”许襄毅点点头，似乎悟出了什么。他派人买鱼做饭，放入荆花，让狗和猪吃，结果都毒死了。女子
