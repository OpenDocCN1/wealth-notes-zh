# 江东桥之战

陈友谅攻陷太平之后，占据了长江上游，就派人约张士诚一同进攻建康。有的人劝朱元璋亲自率军迎击，朱元璋说：

“敌军一旦知道我率大军出城，就会用少许部队牵制我，而派出大军顺流直下建康，半天时间就可到达。到那时，我率领步兵和骑兵从百里之外赶回来迎敌，正犯了兵家大忌。”

于是，朱元璋找来康茂才商量说：“两股敌军合在一起，那就很难对付了。如果先击败陈友谅，张士诚那边也就闻风丧胆。你能迅速地把陈友谅的军队引出来吗？”康茂才说：“我家有个守门老汉，以前曾服侍过陈友谅。让他去说，陈友谅必定上钩。”就让那看门老汉带上一封信，乘小船来到陈友谅军中，许诺在陈友谅进攻时，康茂才担任内应。陈友谅果然深信不疑，十分高兴，问康茂才在什么地方接应。看门老汉说：“他正在防守江东桥。”陈友谅问：“江东桥是什么桥？”答：“是一座木桥。”陈友谅更加放心了，赏给看门老汉一顿饭，叮嘱说：“我不久就到，到了以后喊‘老康’为信号。”

看门老汉回来后报告了情况，朱元璋说：“他快要钻进我的圈套里面了。”便立即派人拆掉原来的木桥，改建了一座铁石桥。这样，陈友谅的大船就无法撞开大桥逃走了。又派冯胜和常遇春率领三万精兵，埋伏在石灰山侧，徐达等驻守在南门外，杨璟驻守大胜港，张德胜、朱虎率水师驻守卢龙山，命令旗手们把黄色旗帜隐伏在山的右边，把红色旗帜隐伏在左边，并告诫说：“敌军来到举红旗，听到鼓声举黄旗。黄旗一举，万军齐发。”
