# 相君之背

楚汉战争时，刘邦逐渐占了上风。刘邦的军队，又主要掌握在韩信手中。齐人蒯通看出了这一点，想用奇特的方法感悟韩信，劝他背叛刘邦，独自争夺天下，就说：“我学过相术，能预知一个人的前途未来。”韩信问：“你怎样看相呢？”蒯通说：“人的贵贱看骨相，忧喜形于色，成败在于决断。用此法相人，万无一失。”韩信说：“好，请您给我看一看。”蒯通说：“不能让别人听见。”韩信便屏退左右，屋里只剩下他们两人。蒯通说：“相您的脸，不过封侯，而且潜藏着危机；相您的背，贵不可言。”“背”是双关语，表面上指后背，实际上指背叛自立。

# 自备绵绳

桓道恭是桓玄的族人，在桓玄处任贼曹参军。他性格耿直，敢说敢为。桓玄经常虐待下属，致使不少人痛恨他。桓道恭在跟随桓玄打猎时，腰间经常扎一根细绵绳。桓玄不解地问：“你为什么要扎根绳呢？”桓道恭说：“您在打猎时动不动就捆绑人，说不定哪天我也要犯在您的手下。见您捆人用的绳很粗糙，我怕手受不了，就准备了一根柔软的绵绳，留着在您捆我时用。”桓玄听了顿有所悟，从此不再随意虐待下属了。
