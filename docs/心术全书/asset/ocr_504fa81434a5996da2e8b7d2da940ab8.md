# 心 力 术

智慧是心力赖以产生的土壤，而心力则是智慧的妙化。没有智慧而去大谈心力，如同演木偶戏，虽然千变万化，只不过是供人嬉笑罢了。没有心力而去谈智慧，正如同车夫和船工，自以为技术高超，一但遇险就会束手无策，不翻车沉船才怪呢。值得注意的是，心力不是一成不变的，它灵活多样，变化无穷。心力的出神入化，可以说是智慧得以充分发挥的标志。

# 卓文君卖酒

司马相如琴挑临邛富人卓王孙寡女卓文君，两人私奔回成都。可家里什么也没有，无法维持生活。两人合计了一番，又返回了临邛。卖掉车马首饰，在卓府对面租了房间，夫妻俩开店卖酒。卓文君在外边卖，司马相如在里边做杂务。卓王孙本来就不同意这门亲事，十分生气。见他俩在大门对面开酒店，这火就更大了，命人关上大门，改走侧门。可这毕竟不是长久之计，经人多方劝说，他分给卓文君一百个奴仆，一百万钱。司马相如和卓文君达到了目的，高高兴兴地回成都去了。
