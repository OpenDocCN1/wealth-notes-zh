# 狄青设馔

宋朝时，陕西有个豪士叫刘易，喜爱谈论兵法，仗义疏财，并熟悉边情，因而很受魏公韩琦的敬重。他爱吃苦马菜，一顿吃不着就又喊又骂。一次，刘易随狄青出守边塞。因当地没有苦马菜，狄青就派人到内地买了许多，刘易别提有多高兴了。可是没高兴上几天，他就受不了了。原来狄青私下里命厨师撤掉其它菜肴，每餐只上苦马菜一种。时间一长。刘易无法忍受，主动提出不再吃苦马菜，改食别的菜肴。
