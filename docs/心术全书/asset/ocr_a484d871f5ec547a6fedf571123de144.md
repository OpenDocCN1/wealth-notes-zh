# 远 虑 术

俗话说，人无远虑，必有近忧。人在生理上并无大的差别，出生时的智力，也是大致相同的。为什么有的人能够三年早知道，而有的人却事到临头举止失措呢？原因就在于有的人居安思危，防患于未然；有的人则鼠目寸光，看不清事物发展的规律。人人都有求福避祸的愿望，殊不知福祸是可以相互转化的。要想立足不败，在成功时要头脑冷静，察觉到潜伏着的失败因素；失利时要从容自如，把握住转败为胜的契机。

# 请 封 寝 邱

孙叔敖病重时，告诫他的儿子说：“大王多次要封给我土地，都被我回绝了。我死后，大王肯定会封给你土地。你在受封时，千万不要接受好的土地。在楚国和越国之间，有个叫寝邱的地方，那里不仅土地贫瘠，而且地名也令人厌恶。楚国人或越国人都很迷信，谁也不会去争夺那地方。能够长期拥有的，只有那个地方啊。”孙叔敖死后，楚王果然要把肥美的土地封给他的儿子。他的儿子坚辞不受，请求封给寝邱土地。楚王答应了。自此，孙叔敖的子孙一直生活在寝邱。国家虽几经变故，却从未有人打过寝邱的主意。
