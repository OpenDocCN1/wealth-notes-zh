# 万二听诗散财

明代洪武初年，嘉定安亭有个叫万二的人，是元朝的遗民。他家资巨万，是郡内数一数二的大富豪。一天，有个人从京师回来，万二向他打听在京师的所见所闻。那人说：“别的都没什么，只是说皇上最近作了一首诗，诗中说：‘百僚未起朕先起，百僚已睡朕未睡。不如江南富足翁，日高丈五犹披被。’”万二听后叹了口气，说：“已经出现预兆了。”众人谁也不明白他说的是什么意思，因而都没在意。万二就把家产委托给几个能干的管家经营，自己则带上妻子儿女泛游湖湘，过着悠闲的生活。不到两年，江南富豪大多被朝廷抄家，没收了财产。万二的家业不仅没受影响，反而因经营有方，越来越兴旺。

# 和珅猜中文题

顺天乡试，《四书》文题必须钦定。出题前，由内阁进呈《四书》一部，待皇帝命完题，再拿回来。乾隆乙酉乡试，阉宣捧着《四书》送还内阁时，和珅有意搭话，探问清高宗命题的情形。阉宣说高宗在批阅第一本至后半部分时，忽然笑了起来。随即挥毫疾书，拟定了文题。和珅嘴上不说，心里已经猜出文题是“或乞醯焉”一章。盖因“乞醯”二字中能拆出“乙酉”二字。和珅为人聪明绝顶，他见清高宗喜欢搞文字游戏，便用拆字的方式，猜中了文题，而后悄悄地告诉了门生。由于早有准备，那年乡试他的门生全都高中。
