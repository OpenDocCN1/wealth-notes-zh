# 段秀实以柔克刚

段秀实由白孝德推荐当了泾州太守。当时郭子仪任副元帅，镇守蒲州。他的儿子郭晞任检校尚书，兼任行营节度使，驻守邠州。邠州的一些恶少因郭晞治军不严，便混入军中。他们光天化日之下抢夺民财，经常打伤人，甚至殴打孕妇，导致流产。白孝德对此恶行虽说很气愤，可又不敢说什么。段秀实从泾州赶来，诉说了军人的暴行，并请求担任专管军人犯罪的都虞候。白孝德正无计可施，马上同意了他的请求。

说也凑巧，段秀实就任都虞侯的当天，就有十七个军卒到市场上抢酒，还刺伤了卖酒的老头，打碎了酿酒器皿。段秀实果断地命令手下人把这些军卒抓起来，立即处死，用长矛挑着脑袋，游街示众。消息传到军营，军卒都红了眼，大吵大嚷着披上铠甲，手执兵刃，准备冲出军营厮杀。

段秀实解下佩刀，选了个年老行动不便的人牵着马，径直向郭晞的军营走来。军卒见他来了，一个个怒气冲冲地围了上来。段秀实一边往里走，一边大笑着说：“杀我这么个老头子何必要披挂一番？我不是顶着脑袋给你们送来了嘛。”军卒们听了他的话，全都愣住了。

过了一会儿，郭晞出来了，段秀实当着众人的面责备他说：“副元帅的功劳充塞天地之间，可如今您却听任军卒肆意妄为。边境地区一旦闹出乱子，这责任由谁负呢？我想不仅您逃脱不了，恐怕连副元帅也罪责难逃。如今邠州的恶少纷纷混入军中，残害百姓，罪恶多端。人们都说您仗着副元帅的势力不管束军卒。这样一来，你们郭家的功名还能够保
