# 秦王间废信陵君

秦王对魏公子的威名深以为患，于是派人带上一万斤黄金到魏国，收买晋鄙的门客，让他们在魏王面前诽谤信陵君说：“公子在国外已经十几年了，他现在又回到魏国做了大将，各诸侯国都听从他的指挥。如今在诸侯们的心中，只知道有信陵君，不知道还有大王您，还都准备拥戴他为王。”与此同时，秦国又接二连三地派出使者进行另一方面的活动，到魏国见信陵君，假意庆贺并询问他是否已经立为魏王。魏王天天听到这些消息，信以为真，就派人取代了信陵君的职业。信陵君知道自己是 因为诽谤而被解除职务，就借口有病不再上朝，与门人宾客终日饮酒，沉湎于女色。四年后，就抑郁而死。秦王得知信陵君已死，便派大将蒙骜进攻魏国，攻克了十二座城池，设置了东郡。以后，秦国不断地吞食并吞魏国领土，十八年后活捉了魏王，攻陷了魏国的都城大梁。

# 秦军巧用离间计

秦国派出大军进攻赵国，赵国名将廉颇坚守城池，使秦军陷于被动。于是，秦军派出奸细，散布谣言说：“秦军并不怕廉颇，怕的是赵奢的儿子赵括。”赵王果真中计，将廉颇撤换，改派赵括担任统帅。秦国得知这一消息后，就偷偷改换白起为统帅，并向全军将士传令，如果有谁将这一消息泄露出去，立即斩首示众。这是因为，如果赵括知道秦军换了白起任统帅的话，必定坚守城池，不敢发动进攻。
