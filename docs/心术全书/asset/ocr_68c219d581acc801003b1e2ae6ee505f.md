# 焚

券

孟尝君是战国时以养士闻名的四公子之一。一日，他问众门客，谁会计算利息，准备派到薛地收债。冯煖说：“我可以。”孟尝君就为他准备好了车马，载着债券前往薛地。临行时，冯煖问：“收完债，打算让我买点什么回来？”孟君尝说：“你觉得我缺什么，就买什么吧。”

冯煖到了薛地，把借债人全都召集来。公布完借贷帐日后，便假传孟尝君的指令，把借贷全部免除，连利息也全部免收。并当着大家的面，把债券全都烧毁。薛地的民众欢欣鼓舞，感激得涕泪交流，齐声高呼万岁。

此后，冯煖驾车以最快的速度返回。孟尝君对他这么快返回大惑不解，连忙穿衣戴帽，召见冯煖。一见面，孟尝君就急不可待地问：“债都收完了吗？”冯煖说：“收完了。”孟尝君接着问：“那么你给我买回什么来了呢？”冯煖说：“您让我买缺少的东西，我私下里考虑，您宫中装满了珍宝，马圈里养满了膘肥体壮的大马，内室里美女成群结队。您家中缺少的只有义，我便替您买回来了。”孟尝君越听越糊涂，问：“您替我买了什么义呢？”冯煖说：“您的封地只有薛地那么一块地方，却不爱护那里的百姓，只知放债收租，弄得百姓无法生活。我已假传您的命令，用您的名义，把借贷全部赏赐给了薛地的百姓，把债券全都焚毁了。那里的百姓对您感恩戴德，高呼万岁。这就是我为您买回的义啊！”孟尝君听了很不高兴，冷冷地说：“先生算了吧。”
