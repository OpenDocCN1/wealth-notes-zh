# 模糊术

无论说话办事，都应力求明白，这是勿庸置疑的。但在有些环境下不可能或根本无法说明白、做明白，这就需要采用模糊术了。模糊术主要用在三种环境中，一是有些情况不便弄明白，因而故意采用模棱两可的方式，以便留有回旋余地；二是有些话题无法说明白，如“病好些了”之类；三是有意识地增强说话办事的技巧，故意采用模糊术。

# 首鼠两端

窦婴是汉景帝的母亲窦太后的堂侄，受封为魏其侯。田蚡是汉武帝的亲舅舅。田蚡续娶时，窦婴带着名将灌夫一同去贺喜。宴会上，田蚡等人对灌夫很不礼貌，导致灌夫大骂灌贤。田蚡乘机下令把他逮捕，并把他的家属也全都拘留，准备灭族。窦婴倾向灌夫，同田蚡一直吵到汉武帝那里。汉武帝没办法，就叫大臣们发表意见。大臣们对两大皇族哪边也不敢得罪，谁也不开口。御史大夫韩安国吞吞吐吐地说：
“窦婴说，灌夫平时有功无过，酒后失言，不应当陷于重罪，这话是对的。田蚡说，灌夫胡作非为，危及国家，这话也不错。究竟怎么处理，还是凭陛下圣明裁定。”
