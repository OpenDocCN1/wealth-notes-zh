# 屠 桦 石 顾 全 秀 才

屠桦石任浙中督学 时，执法严明，学风大盛。可是当地有些人专门搜寻士子们的过失，屠桦石决心煞一煞这种歪风。有个秀才到妓院嫖娼，保甲得知后，不待天亮，就闯入妓院，把那个秀才和妓女一起捉到官府。到了官府，保甲大呼大叫，说士子嫖妓宿娼，应予严惩。屠桦石正在内室翻阅文书，佯做不知。保甲吵嚷了一会儿，见没人理他，就跪在地上，膝行到内室。屠桦石见他进来了，向侍立身旁的衙役使了个眼色，衙役心领神会，从后门溜出，到大堂上把秀才放走了。保甲并不知道，还在喋喋不休地叙说秀才的秽行。屠桦石装作很气愤的样子，昂首来到大堂上，厉声问：“秀才在哪儿？”保甲见秀才没了，不禁大吃一惊，哑口无言。屠桦石喝道：“大胆刁民，竟敢耍弄本官。来人哪，把这个刁徒重打三十大板，戴上枷板示众！”说完，又让人把妓女赶出大堂。保甲不明自地挨了三十大板，神情沮丧地走出官府，对人说：“奇怪啦，难道我刚才捉来的是个鬼吗？”众士子对这个平日专门欺负读书人的恶霸，早就恨得咬牙切齿。听他这么一说，一齐朝他脸上吐唾沫。保甲羞愧无比，灰溜溜地走了。当地人见屠桦石连这样一个贪酒爱色的秀才都加以保护，再没人敢欺负读书人了。那个嫖妓的秀才对屠桦石更是感激
