# 智 困 术

在社交中，由于主观的或客观的、人为的或意外的诸方面的原因，常会使己方出现困境。如能迅速改变策略，使对方受到困扰，就可以变被动为主动。困扰对方，首先要抓住时机。一般说来，宜早不宜迟。至于早到什么时候最恰当。只有根据具体情况来确定，才能取得最佳效果；其次要注意交际对象。对不同的对象，采取不同的方式；其三是要顺应变动的心境特点。否则，不仅不能困扰对方，还可能使己方陷入困境。此外，还要有渊博的知识，丰富的阅历，镇定的气度，敏捷的反应。这样，就可以应付自如了。
