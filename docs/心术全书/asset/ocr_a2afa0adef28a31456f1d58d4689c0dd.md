# 庄辛论幸臣

楚顷襄王在郢都失守逃到城阳后，庄辛告诫他不要贪图眼前享受，以免招致严重的后患。他说：“我听到有句俗话说：‘见兔而顾犬，未为晚也；亡羊而补牢，未为迟也。’我还听说，从前商汤和周武王依靠百里大的地方兴盛起来；夏桀和商纣虽拥有整个天下，最后却灭亡了。现在楚国的领土虽然很小了，但总算起来，还有几千里土地，岂止是百里吗？”

“大王难道没有看见那蜻蜓吗？它有六只脚，四个翅膀，飞翔在天空中，低头啄取蚊、蛇一类飞虫，把它们吃掉；抬头接住甜美的露水，把它喝下，自以为没有祸患，不和别人争什么。可是没想到那五尺高的小孩子正调好糖浆，涂在丝绳上，在四仞高的地方粘住自己，掉下来让螳蛸和蚂蚁吃了。”
