# 祖逖厚结胡眷

祖逖很爱自己的下属，谦恭地对待贤士，虽然是疏淡之交或者卑奴贱仆，也都施予恩惠，以礼相待。因此黄河以南的土地陆续都收归晋朝所有。河岸上的小城中有些住户原来已经让子弟在胡人那边做事，祖逖不追究而听任他们分别归属于胡或归属于晋，并经常派部下的巡逻军队假装包围抢掠这些人家，以此表明他们没有归依晋朝，免遭胡人的怀疑和迫害。城中的各位主事人对此感恩戴德，每当胡人有什么密谋或动向，就立即悄悄报告给祖逖。祖逖先后攻克了许多地方，都是这些人提供的情报。

# 唐太宗贬李勣

唐太宗晚年时，为给太子安排一个忠心不二的辅佐大臣，有意把太子詹事李勣贬谪到边远荒凉地区，并且对太子说：“你对别人没有恩德，别人就不会拼死为你效力。我将李勣贬谪到边远地区，是为了日后让你重用他。你在即位后，可委托他担任仆射。出于报恩，他会拼死为你效力，这样我就放心了。”太子即位后，按照唐太宗的安排，很快就提升李勣任尚书右仆射。
