# 许允妻捉襟

三国魏人许允的妻子容貌丑陋，可是有德有才。结婚那天，刚刚举行完婚礼，许允就因为妻子其貌不扬，赌气跑了出去。客人桓范好不容易找到了他，连劝加拽，把他弄回了新房。过了一会儿，桓范起身走了，许允也起身要走。妻子一把抓住他的衣襟，许允生气地说：“妇有四德，你有多少？”妻子说：“德言容工这四德，我只缺容，别的都不差。请问士有百行，你又有多少呢？”许允说：“一样不缺。”妻子说：“士有百行，以德为首。你重色不重德，怎么能说什么都不欠缺呢？”许允无言以对，面有愧色，由此开始敬重妻子。

# 孩童问倒博士

北齐永安简平王高浚八岁时，跟随博士卢景裕读书。一天，他问卢景裕说：“祭神如神在，到底有没有神？”卢景裕说：“有。”高浚又问：“有神，说祭神就行了，还要说‘如神在’干什么？”卢景裕回答不上来。

# 高 定 问 父

高定七岁时读《尚书》中的《汤誓》篇时，问父亲说：“臣子为什么要伐君呢？”父亲说：“商汤征伐夏桀，是应合天命，顺从人心的举动，不能说是以臣伐君。”高定又问：“商汤说：‘你们只要辅助我，奉行上天的命令讨伐夏国，我就要大大地赏赐你们。假如你们不听我的话，我就要惩罚你们，让你们当奴隶，决不宽恕。’他的话能说是顺从民心吗？”
