# 先 轸 败 楚

春秋时，晋文公率晋、宋、秦、齐四国军队五万多人，七百乘战车，在卫国的城濮拉开战幕，准备与楚军决一雌雄。

决战前夕，晋军中军统帅先轸命下军给战马蒙上虎皮，冲去楚军较弱的右军。楚右军的战马全吓得瘫倒在地，士兵纷纷逃跑，就这么被轻易击溃了。接着，晋上军竖起两面大旗，假充中军，装出退兵的样子。晋下军则用车拉着树枝，尘土飞扬，假装败逃。楚左军见晋军撤退，连忙驱马追击。先轸见楚军中计，指挥中军冲杀过去，将楚军拦腰斩断。狐毛、狐偃则指挥上军，夹攻楚左军，结果晋军取得了重大胜利。
