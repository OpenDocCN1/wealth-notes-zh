# 子罕夺权

战国时，宋相国子罕善于玩弄权谋，深得宋公的赏识。一次，子罕对宋公说：“国家治理得怎么样，主要在于能否恩威并举。自古以来，加官晋爵，奖赏赐予，这都是人们所盼望得到的，请您实行这些措施，国人定会对您感恩戴德。而行刑处罚这一类显示威严的事，是人人不愿接受的，请把这些事交由我负责，让我来承担不好的名声。”宋公听了乐得合不拢嘴。说：“好事全归我，让人怨恨的事全归你，这样国人全都会拥护我，我将成为天下最得人心的人了。”然而他想错了，子罕执掌了生死大权以后，国人都来巴结。子罕趁机培植了大批死党，很快控制了宋国，杀死了宋公。
