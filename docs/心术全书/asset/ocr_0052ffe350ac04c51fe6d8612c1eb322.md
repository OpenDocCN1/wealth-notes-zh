# 公孙消邀宠

秦国王族中有一个叫公孙消的，虽屡次出征，建立了不少功勋，却久久不得升迁。原来掌握朝政大权的宣太后对他有成见。宣太后是秦王的生母，得不到她的欢心，升迁是无望的。公孙消早就看出了这一点，便千方百计地设法消除宣太后对自己的厌恶。尽管他献殷勤，并没能消除宣太后的成见。一个名叫献则的策士为公孙消出谋说：“宣太后的亲弟弟华阳君在东周任职，仕途很不得意。太后为此事忧心忡忡，可是由于是自己的亲弟弟又难以开口。现在你以秦王族的身份对东周施加压力，使其任华阳君为相。这样，太后的偏见自然就消除了，你也就可以得到升迁了。”公孙消照此行事，宣太后果然改变了对他的看法。要想使对方真正从内心欢欣，不在于赠送多少物品或曲意逢迎，重要的是了解对方的情感和需求，进而有的放矢地打动对方。
