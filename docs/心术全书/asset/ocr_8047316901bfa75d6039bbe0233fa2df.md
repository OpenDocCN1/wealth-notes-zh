# 李左车说韩信

楚汉战争时，韩信一挙打败赵王歇，活抓了赵国著名的谋士李左车。韩信亲自为李左车解去绳子，很恭敬地对待他。李左车很受感动，就投降了汉军。接着，韩信向李左车请教下一步攻打燕、齐的军事行动计划。李左车首先分析当时的形势说： “将军您俘虏魏王，活捉夏说。一个早上击溃赵军二十万人，杀掉残余，活捉赵王，已经名闻海内，威震诸侯。但是，您的军队经过多次战斗，已经疲劳不堪，如果现在去攻打燕国，万一不能速战速决，时间拖久了，既攻不下燕，又使齐国做好了充分准备。这样，你的弱点就暴露出来了，想取胜也就不可能了。目前的办法，只有按甲休兵，暂吋不动。然后找机会派使者到燕国去劝降，燕国慑于您的军威，不敢不听从。只要燕国一投降，剩下齐国就容易解决了。”韩信采用了这一建议，派人到燕国说明利害关系，燕国果然投降了。过了一段时间，韩信远袭齐国，击溃齐军二十万人，齐王率残部逃窜。
