# 守信术

守信是为人处世的基本条件。自己不能胜任的事，勿轻易地答应，既经许诺，就必须兑现诺言。无信之人，已谈不上人格。信的基本定义是真诚。无信之人，经常会对自己的轻诺寡信，找来一大堆借口，时间长了自然会失去他人的信任。要想保持自己完美的形象，说话办事应深思熟虑，谨慎行事，切忌轻许诺言，以维持圆满的人际关系。

# 晋文公守信

晋文公率军攻打原国之前，和大夫们约定，十天之内无论攻下攻不下。都要撤兵回国。转眼间十天过去了，原国没能被攻下。探子送来情报，说原国已经精疲力竭，如再有三天时间，就大功告成。将士们也都劝晋文公继续攻打，不要丢掉即将到手的胜利。晋文公说：“我和大夫们约定十天为期限。如果不撤兵，就是自食其言。我怎么可以为一个原国，丧失了信用呢？”他说到做到，按照约定时间撤军回国了。原国君臣听说后很受感动，说：“对这样信守诺言的人，我们还有什么可怀疑的呢？我们归顺晋国，得到他们的保护不是更好吗？”于是，原国派出使臣，主动归顺了晋国。这一消息不胫而走，卫国人听说了，也主动归顺了晋国。
