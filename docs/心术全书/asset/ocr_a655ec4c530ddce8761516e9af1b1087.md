篷，欲杀匈奴士兵。匈奴使者被当场杀死，其他随从的士兵不是被杀死，就是被烧死。还有个别的逃之夭夭，不知去向。班超一行返回住处时，天刚刚泛起了鱼肚白。

第二天，班超把鄯善王请到住处，让他看匈奴使者的人头。鄯善王又惊又喜，慌忙趴在地下，磕着着头说：“愿意服从汉天子。”

# # 班超斩巫师

从鄯善国回来后，班超又一次被派往西域，首先到了于阗国。国王广德对班超的态度很冷淡。于阗国迷信巫师，巫师受匈奴利用，反对结交汉朝，就说：“你为什么要去结交汉朝？汉朝使者的那匹马，神很喜欢，为什么不牵来祭神？”于阗王就派人向班超请求把那匹马送给他。班超知道是巫师在捣鬼，不露声色地说：“可以，不过要让巫师亲自来取。”那巫师得意洋洋地来牵马，班超并不答话，挥刀把他拦腰砍断。然后提着巫师的头去见于阗王，对他说：“你结交汉朝，有享不尽的荣华富贵，可要是勾结匈奴，这人头就是榜样。何去何从，你可要三思啊！你为什么不象鄯善王那样，把儿子送到汉朝去呢？”于阗王瞧见了人头，又经班超大胆地一说，心里早软了下来，连忙说：“我愿意归顺汉朝。”

# # 龚 逯 平 盗

汉宣帝时，渤海左右郡发生了严重的饥荒，饥民们蜂起闹事。郡守无策，只好挂印辞官。汉宣帝着意选拔能治乱的人，丞相和御史一致举荐龚遂，宣帝就任命他担任了渤海太守。
