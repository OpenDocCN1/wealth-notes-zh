# 厚待书生

元代人廉希贤任中书平章时，江南大官僚刘整带着丰厚的礼物前来拜谒。廉希贤傲慢地坐着，连眼皮都懒得抬一下。刘整行过谒见礼之后，廉希贤也不让坐，让他站着说话。刘整讨了个没趣，灰溜溜地离开了廉府。

说也凑巧，刘整刚走，门人通报有个书生求见。廉希贤立即起身，到大门口亲自把书生迎进客厅。那书生衣衫褴褛，带着新写的诗卷，请廉希贤品评。廉希贤认真地读了一遍，就同书生讨论起作诗的技巧。又由作诗谈到经史，进而谈到治国安邦之道。两人越谈越投机，大有相见恨晚之感。

书生走后，弟弟廉希贡不解地问：“刘整本是江南显官，现今又在我朝廷任要职，您对他冷淡无礼。书生不过是一个穷酸文人，您却对他彬彬有礼，这是为什么呢？”廉希贤语重心长地说：“国家重臣的举手投足，都会对天下产生很大影响。刘整虽说是显官，其实不过是一个卖国求荣的无耻小人。书生有什么过错，我为什么不能尊重他呢？如今元朝刚刚建立，我如果领头不尊重文人，恐怕天下就不会有人读书了。”
