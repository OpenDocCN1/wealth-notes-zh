# 主父偃削地

西汉初期，诸侯势力很大。他们占有众多的城池，不服从朝廷，造成了四分五裂的局面。汉景帝曾采用晁错的计策，逐步削掉诸侯王的封地，从而导致了七国叛乱，被削掉的地又重新回到了诸侯王手中。汉武帝登基后，有两个诸侯王先后上书，请求把土地分封给子弟。汉武帝本打算拒绝，中大夫主父偃抓住这个机会，献计说：“古时候的诸侯，封地不过一百里，力量不大，容易控制。现在的诸侯，有的拥有几十座城，地方一千多里。势力大而蛮横，一不称心就会联合起来对付朝廷。要是打算把他们的土地削去一部分，他们就会造反，从前晁错不就因此而丧了命吗？再说诸侯王的子弟少则几个，多则几十个，可除了嫡子继承外，别的子弟连一尺的封地也得不到。要是皇上下令让诸侯把自己的封地分封给所有的子弟，不但大家都高兴，感激皇上的恩德，更重要的是封地一分散，势力也就分散了。这样无形中就把诸侯王的封地削了。” 汉武帝采纳了他的意见，允许各国诸侯王把封地转封给自己的子弟。这么一来，大国变成了小国，诸侯王的封地化整为零，朝廷就容易管束他们了。
