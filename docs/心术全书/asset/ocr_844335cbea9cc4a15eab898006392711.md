# 厮养卒救赵王

赵王武臣派遣韩广到燕国，燕国人就拥立韩广为燕王。赵王想得到燕国的一些城池，就与张耳、陈余率兵越过赵国边境，进入燕国。

赵国的侵略行径，遭到了燕军的坚决抵抗。一天，赵王外出被燕军抓获。燕军主将下令把赵王关押起来，并提出割让赵国领土的一半给燕国，才放回赵王。张耳和陈余先后派出十多个使者前往燕军求情，都是一到燕国，就被杀害了。
