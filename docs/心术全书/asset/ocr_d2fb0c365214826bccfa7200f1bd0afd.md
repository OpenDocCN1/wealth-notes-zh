# # 王安石查匿名信

王安石任开封知府时，接连接到匿名信，告发一些人想谋反，牵涉百余人，皇帝诏令他尽快查处。王安石仔细地看了所有的匿名信，发现文法、字体等均出自一人之手。尤其是最后一封信，在谋反的名单中又加进了三个人，其中有个姓薛的。他脸上露出一丝轻蔑的笑，说：“明白怎么回事了。”他派人找来那个姓薛的，问：“你近来与谁闹过纠纷吗？”姓薛的说：“按说没同谁闹过矛盾，不过有个士子曾拿着他写的文章让我推荐当官，遭到了拒绝，悻悻而去，看样子挺恼火。”王安石派捕吏把那个人拘捕到官，经审问，他供认了写匿名信诬陷他人的犯罪事实，被处死了。
