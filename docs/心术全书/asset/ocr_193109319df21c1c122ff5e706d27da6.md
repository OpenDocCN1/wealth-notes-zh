# 免 祸 术

《史记》中说：“智者避危于无形。”世上总有一些居心险恶的人，寻找时机陷害他人。要想立足社会，不仅需要谋深计远，还需要居安思危，防患于未然，时刻保持清醒的头脑，准备应付可能发生的危险和困难。当然，任何灾祸都是难以预料的。遇到突如其来的灾祸，当事人如果手忙脚乱，六神无主，必然会陷入被动。在这种情况下，应该保持清醒的头脑，从容镇静地找出免祸的方法。有的人远见卓识，能预测灾祸的发生，从而及早加以防范，这便是更高层次的免祸技巧了。

# 解 衣 自 免
