
# 曹操设伏

公元198年，曹操率军攻打张绣。当他得知袁绍准备偷袭许都的消息，连忙撤兵回返，张绣乘机率众追击。荆州刘表也趁火打劫，凭险固守，截断了曹军的归路。曹军前后受敌，形势危急。曹操毫不惊慌，利用月色掩护，佯装撤退，暗中设伏。张绣以为曹军仓惶而逃，毫无顾忌地追赶，进入了埋伏圈，被曹军打得大败。

# 诈出不降人

三国时，吴军统帅吕蒙引诱西蜀守将糜芳出城投降后，准备率军入城。谋士虞翻说：“如今死心塌地降吴的，只有糜芳一人是可信的。对于城中的其他将领，怎么能轻易相信呢？应该马上派人进城，拿到城门钥匙，以便控制全城。”吕蒙认为他的话有道理，准备亲自入城，虞翻又说：“不可以，万一城中设有伏兵，我们就要大难临头了。”于是虞翻派糜芳回城，并教他说：“你回到城里可以这么说：‘我侥幸逃离了吴军，回到城里，想和诸位同心守城，抗击吴军。谁能破敌，我甘愿让他担任守城主将。”他回去后说了这些话，果然有不少将领愿意拼死守城。化装进城的虞翻当场把这些将领抓起来处死了，然后迎接吕蒙大军入城。

# 设灯歼敌

齐朝将领鲁康祚率军攻魏，两军隔着淮河安营扎寨。魏国长史傅永想，南人爱夜间袭营，行动时定会在淮河中放置火炬，用以指示涉水的位置。傍晚时分，他把魏军分为两部分，埋伏在军营两侧。又派人带上油灯，放置到深水处，叮嘱说：“见到敌军点燃灯火，你们也马上点燃。”夜半时分，鲁康祚果然率军涉水劫营，在两路伏兵的夹击下，溃退到淮河边。见淮河中亮着许多油灯，难辨真假，纷纷走了过去，被淹死的人不计其数。

# 元孟辞行

公元四九四年，北魏将领元孟率十万人马包围了南齐的南郑，攻了两个多月未能攻下，准备撤兵。可又怕城中守军乘势追击，就让老弱病残和部分主力部队先撤，自己亲率部分人马断后。为了麻痹敌军，元孟特意写了一封信，派人给南郑守将肖懿送去，通报撤军消息，向他“辞行”。肖懿看了信嘴一撇，说：“想骗我出城，亏你想得出！”传令城中守军，任何人不得出城，违者立斩不贷。过了一天一夜，发现北魏阵地上死一般寂静，见不到一个魏军的身影，肖懿这才知道了计。急忙下令追击，无奈为时已晚。

# 李渊骄李密

隋恭帝义宁元年五月，太原留守李渊起兵割据。当时，活动在河南一带的李密瓦岗军声势浩大，李渊便写信与他联系。李密自恃兵强马壮，想当盟主，复信要李渊亲自到河内会盟。李渊认为此时如和李密决裂，无异是为自己增添敌手，不如用卑微的言辞，使他骄傲自大，去牵制隋军主力。自己则乘机西取关中，据险养威，坐收渔人之利。于是复信李密，说自己年过五十，没有争夺天下的大志，只求李密夺取天下后，看在同姓的份上，给一饭碗吃，也就心满意足了。李密见信后洋洋自得，对部下说：“连李渊都拥戴我，天下不属我又属谁呢？”从此放松了警惕。事实证明，李渊的这着棋很高明，隋军主力受到一心要当皇帝的李密的牵制，李渊得以顺利地占领了隋军兵力薄弱的关中地区。出乎意料的是，还没等李渊出兵，李密就被王世充打败了。公元618年，李密带着两万余残兵败将到关中投降了李渊。

# 裴行俭伏兵保粮

调露元年，大总管裴行俭奉命征讨突厥。连续几次运送的军粮，全被突厥军队半路劫持去了。裴行俭决心打通粮道，就伪装了三百辆粮车，每辆车内埋伏着五名壮士，让老弱兵卒赶车，又派出精兵尾随而行。途中，突厥军队果然来抢夺粮车，赶车的兵卒一哄而散。突厥兵抢到粮车，趾高气扬地赶到水草肥美的地方，解鞍牧马，倒地休息，有几个突厥兵到车中取粮，埋伏的壮士一齐杀出，尾随的精兵也赶到了，合力全歼了毫无防备的突厥抢粮军队。从此，唐军粮道畅通无阻。

# 种世衡计除二将

元昊有两个心腹大将，号称野利王和天都王。二人阴险歹毒，对边境构成了很大的危险。野利王曾遣使说，只要种世衡送给他三个漂亮姑娘，他就投降。种世衡知道他在耍手段，决定用离间计，借元昊之手除掉他。于是，种世衡把使者留了下来，假意答应了野利王的要求。

紫山寺有个叫法崧的和尚，为人忠诚坚定，可以大用。种世衡就用官职引诱他出山，安排在自己门下。法崧因讨贼立了大功，被帅府授予三班阶职，任指挥使。种世衡又替他置办家产，居室骑从一应俱全。法崧酗酒狎博，无所不为。种世衡不仅不怪罪，反而对他越来越好，法崧感恩不尽。一天，种世衡突然发怒说：“我待你如同亲生儿子，你却串通反贼，该当何罪？”说着，命人对他严刑拷打。一连几十天，情景惨不忍睹。法崧毫无怨言，平静地说：“我光明磊落，问心无愧。您听信奸人之言，即便杀了我，又有什么可说的呢？”

过了半年，种世衡觉得法崧能经得起考验，下令去掉枷锁，让他沐浴干净，然后召入内室，抚摸着他的后背道歉说：“你并没什么过错，我不过是要考验考验你。我想派你使用离间计，受的苦要超过这一次，你能保证不泄露吗？”法崧哭着接受了任务。

种世衡给野利王写了一封信，用蜡油封好，缝在法崧的衲衣中间，并告诫说：“这封信不到生死关头绝不可泄漏。你如果轻易泄露了，就是忘恩负义，坏了我的大事。”随后又画了一幅乌龟红枣图，让法崧带上交给野利王。

法崧到了野利王那里，呈上图画。野利王估计有密信，就向他索要。法崧故意瞅着左右，回答说没有。野利王就给元昊写了封信，报告了这件事。元昊就把法崧和野利王召到数百里以外的地方，诘问法崧把密信藏到什么地方了，法崧坚持说没有。元昊命毒打法崧，几次昏死过去，可他始终不招认。

过了几天，元昊单独召见法崧，说：“你再不说实话，今天就砍掉你的脑！”见他还是不说，元昊下令拉出去斩首，行至宫门口，法崧大叫：“我白白死去，完不成将军的事了，有负将军啊！”行刑的人反复追问，法崧才从衬衣中取出密信。

过了一会儿，元昊命人安排法崧到宿舍中歇息。同时派出心腹之人，假作野利王的使者，去见种世衡。种世衡估计是元昊派来的，为了验证一下，他没有立刻接见，只是对属官说：“安排使者到宿舍中休息吧。”然后派人去慰问使者，同他谈到元昊驻守的兴州一带的情况时，使者说得很详细；可是谈到野利王驻守处的情况时，使者显得很陌生。正巧活捉了几个元昊手下的兵卒，种世衡让他们从墙缝里偷看使者，认定使者是元昊手下的人，还可以叫出姓名。种世衡这才接见使者，馈赠甚多。他估计使者回去后，法崧就该回来了，而野利王则是死在临头。事情的发展，正像他预料的那样。

杀了野利王以后，种世衡在边境上设了个祭坛，在木板上刻写了祭文，说野利王和天都王同心相结，有意为大宋朝效力。不想野利王过早捐躯，因而设坛悼念。他亲自点火烧纸，样子显得很虔诚。见有一队敌军巡逻兵冲了过来，种世衡就把纸钱和木筒一起投入火中，匆匆离开了。木筒没有烧毁，敌军巡逻兵带回去交给了元昊，他立即处死了天都王。两名大将死后，元昊如失左右手。他渐渐悟出中了种世衡的离间计，心情沮丧，追悔莫及。

# 乘虚术

同强敌对抗时，为了消磨其士气，减少自身损失，一定要设法分散对方力量，或松懈其意志，才有可能乘虚而入，达到消灭敌人的目的。此术方法很多，或制造谣言，混淆视听，使对方产生疑惑，迷惑其意志；或故布疑阵，分散对方力量，削弱其防卫，而对己方的企图和行动则要绝对保密。一旦时机成熟，抓住对方弱点，打他一个措手不及，取得最后胜利。

# 围魏救赵

公元前353年，魏惠王派庞涓带兵去攻打赵国，包围了赵国的都城邯郸。赵国的国君急得没办法，派人到齐国去求救。齐威王答应出兵，打算拜孙膑做大将。孙膑不肯，说：“我这个残疾人如果当了大将，人家该笑话齐国没人了。”于是改拜田忌为大将，拜孙膑为军师，让他坐在兵车里出谋划策。路上，孙膑对田忌说：“赵国不是庞涓的对手，不等我们赶到邯郸，那地方早就叫魏军攻下来了。不如传出话去，就说我们去的攻打襄陵。襄陵是魏国重镇，庞涓听到消息，一定要回来援救。那时候，我们再在半路上打他，准打胜仗。”田忌认为是个好主意，就在魏军回来必定要经过的一个叫桂陵的地方，把军队埋伏下来。

果然，庞涓一听齐军来攻打襄陵，慌了神，说：“如果襄陵一丢，国都也就危险了。”他赶忙从邯郸撤兵，去援救襄陵。这下，正好钻进了齐军布下的包围圈。当庞涓看到齐军战旗上写着个斗大的“孙”字时，不由得大吃一惊：“原来这个瘸子还活着，我上他的当了！”说罢，率领残兵败将，拼死杀出重围，狼狈地逃了回去。

# 暗渡陈仓

公元206年4月，项羽封刘邦为汉王。张良送刘邦到了褒中，临别时说道：“此去尽是栈道，请大王走一段烧毁一段。”听说烧毁栈道，刘邦大吃一惊，问：“你难道让我永远当汉中王？”张良笑道：“不！这样做是为了让项羽放心，不加戒备；也让别的诸侯不能侵扰。”刘邦这才心领神会，与张良依依告别。项羽得知刘邦烧了栈道，果然放松了对他的警惕，放心大胆地去讨伐其他不从命的诸侯去了。

军队训练多日，刘邦制定了东征的策略。他先派出几百士兵，去修复栈道。章邯得知消息，不免震惊，却又认为只派出几百名士兵，短期内实难以完成修复栈道的浩大工程，因而放下心来。刘邦在派兵修复栈道的同时，偕同韩信统率大军，沿着古时小路，以迅雷不及掩耳之势，直扑陈仓。在不到一个月的时间里，便夺取了三秦地方，不仅扩大了地盘，兵力也日益加强，准备东出与项羽较量。

# 击一而得二

汉光武帝建武五年，张蓝占据西安，拥有两万精兵。他的哥哥张步纠集各郡军队，约有一万人，盘踞在临淄，两城相距四十余里。耿弇奉命攻打二城，就在二城之间扎下了营。经过细心观察，他发现西安城虽小，却很坚固；临淄地虽比较大，但容易攻取，便有意放出口风，说将在五天之后攻打西安。张蓝听说后，日夜戒备。到了攻城的日子，耿弇让士兵半夜开饭。拂晓，突然对临淄城发起攻击。仅仅用了半天时间，就攻破了临淄城。张蓝吓破了胆，竟率部弃城而逃。

事后，诸将问：“主将本说进攻西安，却突然进攻临淄，一举占领两城，这其中有什么秘诀吗？”耿弇说：“张蓝听说我要进攻西安，定会严加防守，而临淄根本就没想到会遭受进攻，被我打个措手不及，所以很快破城。攻克临淄，西安孤立无援，自然就会丧失固守的信心。这就是所说的击一而得二啊。如果先去攻打西安，因兵精城坚，早有防范，不仅会给我军造成重大伤亡，而且一时难以攻下，腹背还要受到临淄的牵制。我军深入敌区孤军作战，缺乏粮草，利在速战。如果十天半月不能取胜，我们的外境就很困难了。”诸将听了啧啧称叹。

# 围城打援

东汉初年，张步据守齐地，他的部将费邑的弟弟费敢占据巨里城。耿弇移师巨里城下，声言要填塞护城河攻城，并赶制攻城器械。逃回的战俘把这一消息报告了费邑，他果然上当，带领三万精兵赶来增援。半路上中了耿弇的埋伏，费邑死于乱军之中，援军溃散。巨里城眼见孤立无援，叛军弃城而逃。

# 避实就虚

东汉初年，岑彭率军三万征讨秦丰。秦丰与部将蔡宏拒岑彭于邓城，使他数月无法前进。一天夜里，岑彭调动军队，并传令说，明天拂晓向西进击山都，还有意放松了对战俘的看管。有些战俘逃回后，把岑彭调兵攻打山都的消息报告了秦丰。他急忙抽调主力部队去守卫山都，岑彭却带领大军突袭黎邱，夺取了秦丰的粮草。秦丰见上了当，急忙赶回救援，半路上中了岑彭的埋伏，被打得大败。

# 司马懿避敌攻城

公元238年，魏将司马懿进攻占据辽东的公孙渊。公孙渊在辽隧一带修筑营垒固守。司马懿分析了形势，留下小部分军队牵制敌军，调动大部分以直捣公孙渊的老巢襄平。有人表示不理解，司马懿说：“公孙渊知道我军远道而来，粮草不足，利在速战。因而他利用己方粮草充足的优势，有意采用拖延战术，想陷我方于被动。襄平很空虚，一旦攻破，公孙渊就没了依托，人心必定大乱。他为了稳住军心，会救援襄平。我们乘机与之决战，不就可以获胜了吗？”局势的发展，果真如司马懿预料的那样。

# 宇文泰破骑兵

南北朝时，西魏宇文泰进攻东魏。东魏派高昂、宝泰、高欢各自率军抵挡，并在河上架起三座浮桥，摆出要渡河决战的架势。宇文泰屯兵广阳，对诸将说：“敌军表面上做出要全面进攻的样子，其实是想牵制我军，掩护宝泰渡河西进。高欢自起兵以来，每次都用作宝泰作先锋，屡战屡胜。然而翳兵必败，如趁此机会袭击他，定会出奇制胜。”有人认为这是冒险，不如分兵抵御。宇文泰力排众议，放风说要坚守陇右，暗中却率军东出，直指宝泰驻守的潼关。等宝泰得到消息，大军已至跟前。宝泰匆忙应战，结果全军溃败，他本人也自杀身亡。

# 奇策克长安

李渊兴兵反隋，调集主力部队进攻河东。隋军守将屈突通凭险固守，李渊屡攻不下。李世民献计说，如果绕过河东，乘虚入关，可一举夺取天下。而一味进攻河东，不仅会使军队遭受重大损失，还会使得关中隋军从容备战，更难对付。李渊采纳了他的建议，除留少数军队伴攻河外，亲率大军以迅雷不及掩耳之势入关，很快攻克长安，夺取了关中地。屈突通见大势已去，就投降了。

# 李靖用死间

颉利兵败求和，唐太宗派鸿卢卿唐俭慰问安抚。颉利口称投降，实际上是为了保存实力，以图东山再起。李靖出谋说：“颉利虽然打了败仗，但依然拥有十余万军队。如果逃回漠北就很难对付了。我方已派人去安抚，他们必定放松警惕。要是派出一万人偷袭，可擒获颉利，不必顾及唐俭的安危。”唐太宗依计连夜出兵，彻底击溃了敌军。

# 狄青智取昆仑关

宋仁宗皇佑年间，智侬高发功叛乱，朝廷派狄青征讨。

听说朝廷大军到了，地方驻军将领陈曙，想冒险邀功，结果被打得大败，狼狈逃回。狄青按军法从事，把陈曙等三十一名将士全部斩首，并下令任何人不许和敌军私自交战。接着，他又下令修筑营寨，囤积粮食。叛军首领得知这一消息，以为官军不会很快出战，因而放松了警惕。不料次日凌晨，狄青突然下令进军，在昆仑关下扎下大营。那天正是元宵节，狄青宣布全军过节，扬言说第一夜招待高级将领，第二夜招待中下级将领，第三夜犒赏全军将士。第一夜尽欢而散，第二夜招待中下级将士时，酒至半酣，狄青起身说：“本人身体欠佳，去去就来。”过了一会儿，他又传出话，说病情不见好转，请副将孙冯代行酒令。众人又吃又喝，玩得很痛快。及至深夜，众人见主将不来，谁也不敢擅自离开。

天刚蒙蒙亮，探马传报：“元帅已攻破昆仑关，请诸位上关用早点。”众人听了，无不惊讶，怀疑是谣言。经查证无误，众人欢呼着拥上关去。原来狄青故意声张连夜设宴，是为了麻痹叛军首领。那天晚上，叛军首领以为没事，也在设宴犒赏部下。再加上天气恶劣，风雨交加，也使得叛军放松了警惕。狄青出其不意，率领部分精兵悍将，偷袭敌营，一举夺取了叛军赖以凭借的昆仑关。

# 朱棣夺船

燕王朱棣率军抵达淮河北岸，与南军盛庸的部队隔河对峙。南军由骑兵、步兵和水军组成，拥有几千艘战船，成为阻挡燕军南进的最大障碍。燕王打算夺取这批战船，为以后渡江做准备。于是，他下令在淮河北岸制造船只，编造竹筏，好像立即就要强渡淮河。然而，他暗中却命部将邱福，朱能等人率精兵西行二十余里，乘小船偷偷地渡过淮河，绕到南军背后，发动突然袭击。南军大乱，四散而逃。盛庸在慌乱间，吓得连马都上不去，跳上一只小船狼狈而逃。就这样，南军的几千艘战船，轻易地落入北军手中。

# 王守仁平叛

王守仁因兵部尚书王琼推荐而受到重用，在他奉命讨伐福州三卫军人叛乱的途中，传来了江西宁王朱宸濠叛乱的消息。他果断地下令停止进军，率军调头回到临安，打算以此根据地，讨伐朱宸濠。他一面向朝廷报告消息，一面联络四方军队，充实粮草。面对朱宸濠嚣张的气焰，王守仁认为，兵家之道，急着攻击敌军主力或有重兵防守的地方，都算不上得计。所以，官军做出据守不战的架式。朱宸濠以为官军胆怯，就会放心大胆地去攻占别的地方。官军乘机尾随其后，攻取叛军的老巢南昌。朱宸濠得知南昌失守，定会拼死救援。此时出其不意，半路伏击，就可大获全胜。

果不出所料，朱宸濠听说王守仁坚守不出，就下令进攻鄱阳。并打算顺江直下，一举夺取南京。兵过安庆，安庆知府张文锦命军士鼓噪大骂叛军。宸濠大怒，命停止进军，全力攻打安庆。

王守仁探得消息，说：“时机到了！”立即率军向南昌挺进。有人对这一做法表示异议，认为应该先去救援安庆。王守仁说：“估计安庆还可以抵挡一阵子，我们只要攻下南昌，叛军定来争夺，安庆之围就不救自解了。”

南昌的留守叛军人数不多，且多是老弱兵卒。见官军来到，纷纷倒戈，大开城门，官军很快占领了全城。宸濠兵围安庆，久攻不下。正在焦虑之际，传来了南昌失守的消息，朱宸濠匆忙率军回救。半路上中了王守仁的埋伏，叛军全线崩溃，朱宸濠本人也当了俘虏。

# 待劳术

以逸待劳是说在敌我双方决战中，一方依靠有利地形，处于从容休整，丰衣足食的安逸地位，作好战斗准备，养精蓄锐，等待长途跋涉来进行决战，弄得疲惫不堪的另一方。从而达到掌握主动，战胜敌人的目的。以逸待劳需要有忍耐力，而忍耐力来自坚强的意志和理智的思维。有效地使用待劳术，牢牢地控制战争的主动权，把握局势的发展变化。

# 以逸待劳

春秋时期，晋、楚争霸，两国都想控制处于中间的小国郑国。郑国无奈，只好在两强之间摇摆。晋悼公对郑国反复无常的做法非常恼怒，决定一举征服郑国。重臣荀莹听说后，急忙上朝求见悼公，说：“郑国之所以不能死心塌地地降晋，是由于有楚国的压力。晋国要想降服郑国，必须先制服楚国。”悼公说：“楚国力量很强，怎样才能制服呢？”荀莹说：“计策倒是有一个，就是以逸待劳计。”悼公问：“此计如何用？”荀莹回答说：“军队不可以频繁调动，是因为怕造成军队疲惫不堪，进而丧失战斗力；常要诸侯出兵援助，他们就会心怀不满。国内军队疲惫，国外诸侯怨恨，这种局面是保持不了多久的。要想拖垮敌军，应把我军分成三部分，轮流作战，有劳有逸。楚军进攻我军就退却，楚军退却我军就进攻。楚军远道而来，求战不能，求和不得，疲于奔命。时间长了，楚国就会民困兵乏，无力对外作战了。这样，晋国就可以达到长期控制郑国的目的了。”晋悼公依计而行，果然拖垮了楚国，控制了郑国。

# 奇策胜楚

吴王阖闾即位后，对伍子胥说：“我早就想攻楚，又怕冒死打败楚国后，功劳被别人夺了去。现在我已经即位，是实现这一夙愿的时候了。您觉得怎样才能取胜呢？”伍子胥说：“楚国当权的人多而乖戾，没有谁能承担起国家的重任。我们可派一部分军队挑战，引诱楚军倾巢而动。等楚军出动，我军就退回；楚军退回，我军就出击。等到楚军疲劳已极之时，我军找准时机，全线出击，就可大获全胜。”阖闾采纳了这一计策，果然打败了楚国。

# 李牧守边

李牧是赵国良将，驻守雁门抗击匈奴。他把当地税收用作军费，时常犒劳将士，严格训练军卒的骑射技术，还经常派密探了解敌情。他告诫全军说：“一旦发现匈奴进犯，立即收兵回城。谁要是擅自出战，无论胜败，定斩不饶。”

几年过去了，匈奴认为李牧胆小怕事，赵军将士也有同感。赵王的多次责备，也未能使他改变策略，赵王一怒之下撤了他的职，改派他人代替。新将领上任后，遇有匈奴骚扰抢掠就领兵出战。不到一年时间就有多次失利，造成重大损失，边民无法种田放牧。
