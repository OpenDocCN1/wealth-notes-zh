# 用 神 术

假借神意来服务于自己的目的，是权谋的重要手段之一。真正信神的中国人并不多，大多数人其量是宁信其有，不信其无。人们虽对神并不那么虔诚，但又有完全不信会对自已产生危害的禁忌。出于保险起见，还是小心翼翼地遵从清规。假借神意的人正是利用这一弱点，震慑对方心理，从而达到目的。
