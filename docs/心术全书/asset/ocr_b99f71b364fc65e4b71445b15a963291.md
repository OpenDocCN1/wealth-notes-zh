# 刘琦大败金军

公元1140年，刘琦率军三万多人坚守颍昌城，抵挡金军南侵。为了造成敌军的疑惧，他下令大开城门。金军果然怀疑有伏兵，不敢攻城，只在远处放箭。由于刘琦早有安排，宋军在城上放箭，射杀大批金军，宋军则伤亡甚少。当金军被迫后撤时，刘琦率军追击，致使金兵大多淹死在颍河里。

金军纠集残部，准备再次发动进攻。刘琦决定先发制人，派大将阆充率领五百人，趁着雷雨黑夜突袭敌营，使金军蒙受重大伤亡，又退兵三十里。第二天夜里，刘琦趁着雷雨交加的机会，派出突击队，潜入敌营。每人除带有武器外，还带有一个竹哨。闪电闪时，突击队员一齐吹哨，砍杀敌军；雷电过后，伏地不动。金军黑暗中搞不清是怎么回事，整夜自相残杀，乱成一团。天亮后，金军便远远地退到了老婆湾。

金兀术听到金军接连失利的消息十分恼怒，亲率十几万大军来助战。刘琦派出两名勇士，对金兀术说刘琦不过是个只知贪图享乐的纨绔子弟，根本就不会打仗。金兀术深信不疑，因而产生了轻敌心理。为了消磨金军的锐气，刘琦派人把金军引诱到撒毒的地区。致使不少金军将士中毒，战斗力直线下降。在交战时，刘琦采用了敌疲我打的战术。上午固守，下午在金军疲惫之时，先派几百人从西门杀出，吸引金军的注意力。然后突然派出几千名精锐将士，从南门杀出。金军大败，狼狈逃窜。刘琦乘胜追击，歼灭了数万金军。
