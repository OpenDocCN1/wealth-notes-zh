# 饰贤术

古话说，“得道多助，失道寡助”。“得人心者得天下，失人心者失天下”。为了获得人们的支持，历代统治者无不重视拢络人心的工作。说到底，统御术的核心是如何拢络人心。拢络人心，有个统治者自身形象的问题。自身形象的贤明，是拢络人心的起码道德准则。以贤明的面目出现，无论是被社会道德所肯定的所谓“服人心”，抑或被视认为不义行为的“收买人心”，都会取得民众的支持。饰贤术带有鲜明的伦理色彩，其心理动机可以出自于善的判断，也可能出自于恶的判断。如果说“服人心”属于“阳谋”，那么，“收买人心”就属于“阴谋”了。

# 诽谤孟尝君

孟尝君对门客夏侯章待遇很高，给他四五百人的伙食费，可是夏侯章反倒经常在背后诽谤孟尝君。有人对孟尝君说了，他说：“我常有事要请教夏侯公，不要责怪他。”燠青把这话转告了夏侯章，他说：“我没什么功劳，孟尝君却给我很高的荣誉和待遇。对我这么好，我反倒诽谤他，这样一来孟尝君就成了宽厚待人的仁人君子，我则成了忘恩负义的无耻小人。我这是用自己的人格和声誉为他效劳啊，你还要我说什么呢？
