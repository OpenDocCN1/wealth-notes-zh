# 行 骗 术

世上每个人都有追求物质利益与本能享受的需求，行骗者正是及时为人们提供这种满足，并因对方贪图小利而得手。很明显，行骗术包括物质、生理和社会权力三种形态。物质行骗包括金钱、物品、饮食等形式；色欲行骗主要利用生理本能的满足来使对方上钩；权力行骗的主要形式是封官许愿，这对那些权力欲强烈的人最为有效。其中，女色较多地被当作行骗工具，为某个行骗者服务。行骗术是人们在道义上大加谴责而在实际生活中又极易上当的技巧。因此，谙熟行骗术是预防上当受骗的最好方法。

# 张仪破盟

战国时，齐国和楚国结成联盟，共同对付秦国，形势对秦国很不利。于是，秦相国张仪去见楚怀王，说：“秦国十分愿意同楚国保持友好关系，但很痛恨齐国。可是楚国与齐国结盟，这就使秦国无法同楚国友好了。大王如果同齐国断交，我可以让秦王割让给您六百里土地。这样您既结好了秦国，又相对削弱了齐国，还可得到六百里土地。有这么多好处，您何乐而不为呢？”楚怀王利欲薰心，就立即与齐国断绝了关系，并派人跟张仪到秦国接收土地。
