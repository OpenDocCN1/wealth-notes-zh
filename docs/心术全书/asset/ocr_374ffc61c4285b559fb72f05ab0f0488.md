# 雄 辩 术

心术不是言语，语智不等于心术。夸夸其谈的人有言辞穷尽之时，伶牙俐齿的人也有凡夫俗子。两人舌战，有理的人必定取胜。如果双方均有一定的道理，那么能言善辩的人就要占上风。有时一言九鼎，三寸不烂之舌胜过千军万马；有时轻松的谈笑，可以使剑拔弩张的纠纷冰释。一个人的语言如果没有魅力，就很难出人头地。有的人一言显示出智慧，从而功成名就。心术是人的内部世界的核心，语言则是心术的外在形式。《诗经》上说：“惟其有之，是以似之。”大概说的就是这种现象吧。

# 孟子驳倒淳于髡

淳于髡是有名的舌辩之士，一次他问孟子说：“男女授受不亲，这是礼制所规定的吗？”孟子应声答道：“当然是礼制规定的。”淳于髡又问：“假如一个人的嫂嫂掉在水里，做小叔的看见了，能不能用手去拉呢？”孟子说：“嫂嫂掉在水里而不去拉，那简直变成了没有人性的豺狼了。男女授受不亲，这是正常的礼制。嫂嫂掉在水里用手去拉，不过是临时的变通办法。”淳于髡问：“现在天下人都非常痛苦，和掉在水里一样。可您不去援救他们，这是为什么呢？”孟子说：“天下人都受苦，只有用‘道’才可救他们出苦海。
