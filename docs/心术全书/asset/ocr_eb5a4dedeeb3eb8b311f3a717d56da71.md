# 宋汝霖上书免牛黄

宋徽宗政和初年，宋汝霖任掖县县令。当时户部命提举司购买牛黄，供应京城药局制药用。誓急如星火，提举司给各州县下达交牛黄的数量。违期不交，官吏免职，百姓治罪，因而各州县百姓竞相杀牛，寻找牛黄。宋汝霖却下令不许百姓宰杀耕牛，并且上书说：“遇到灾年，牛染病后方可生出牛黄，如今五谷丰登，耕牛头头膘肥体壮，因而无牛黄可采。”提举司看了上书无法反驳，便下令掖县免交牛黄。全县百姓奔走相告，感激县令救了全县的耕牛。

# 薛长孺平叛

薛长孺担任汉州通判时，一部分戍卒关闭军营，杀人放火，并准备冲击官府，杀害知州。面对戍卒的嚣张气焰，知州等人都一筹莫展。薛长孺毫不畏惧，只身闯进军营，传谕全体士卒说：“你们都是上有父母，下有妻子儿女的人，为什么要干这种灭族的事情呢？听我的口令，不愿谋反的站到左边。”那些原本受胁迫的士卒，纷纷站了过去。只有八个策划谋反的见大势已去，夺门而出，逃散到邻近的属县中去了。薛长孺立即下达通缉令，很快捉获了八个反卒。
