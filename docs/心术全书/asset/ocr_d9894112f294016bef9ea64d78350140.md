# 唐代宗教女

升平公主是唐代宗的女儿，嫁给郭子仪的儿子郭暧为妻，两人经常拌嘴。一天，两人又吵了起来，郭暧说：“你不就是仗着父亲是天子吗？我还不稀罕呢。”升平公主更加生气了，大哭大闹一番，就回宫去了。唐代宗耐心地听女儿说完，责备她说：“郭暧的话不能说没有道理，因为天下并不是我们李家私有的啊。”接着安慰了一番，劝她赶快回婆家。这时，郭子仪拥起郭暧，带着来请罪。唐代宗对郭子仪说：“俗话说得好，不痴不聋，不能当老公。小儿女闺房内的事，让他们自己处理好了，我们就不要过问了。”于是，郭子仪把郭暧带回了家，喝令把他狠打一顿。此时升平公主怒火已消，见丈夫挨打，十分心痛，哭着替郭暧求情。从此，他们二人不再吵闹，恩爱日深。
