# 孙膑装疯

孙膑看清了庞涓的真面目后，心想，我受了他的害，怎么能把兵书再传给他呢？又一想，如果不写，庞涓就会立即把我杀死。他想来想去，终于想出了个好主意。当天晚上，孙膑就“疯”了。仆人送饭来，他瞪着眼大叫：“你为什么拿毒药来害我？”说着把饭菜都推翻在地上，又把写好的竹简往火里扔，嘟嘟嘭嘭地叫骂不止。庞涓听说，急忙赶了过来，只见孙膑蓬头垢面，趴在地上，一会儿哭，一会儿笑，朝着他直磕头，嘴里喊着“鬼谷先生救命”。庞涓怕他装疯，让人把他拖到猪圈里。孙膑在粪堆上倒头便睡，醒了后捡起猪粪就往嘴里塞。庞涓这才认为他是真的疯了，就不再理他。后来齐国设法把他从魏国救了出来，带到齐国。

# 余氏夺宠
