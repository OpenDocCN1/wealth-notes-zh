# 张丑脱身

张丑因为人质的事到燕国去交涉，燕王想杀死他。他听到消息后，连夜逃走了。快到边境时，燕国的边将捉住了他。张丑毫不惊慌，从容地说：“你知道燕王为什么要杀我吗？是因为有人说我有颗宝珠，燕王很想得到它。现在这颗宝珠已经丢失在路上了，你要是把我送回去，我就说宝珠被你抢了去，吞到肚子里去了。这样燕王不仅要抓你，还要剖开你的肚子。”边将吓得直打冷战，赶忙放走了张丑。

# 保留政敌

战国时，韩国相国公叔与韩王的爱子几瑟矛盾很深。经过一番争斗，几瑟失算，逃亡到了国外。公叔仍不肯罢休，打算派刺客去暗杀几瑟，有个门客劝他说：“请您不要这么做。您现在之所以受到太子俈婴的敬重，是因为几瑟还活着。几瑟存在一天，太子就担忧一天，也就不得不依靠您。如果几瑟被杀死，没有人和太子争位，他就不会再敬重您了。”公叔认为门客说得有道理，遂取消了刺杀几瑟的计划。
