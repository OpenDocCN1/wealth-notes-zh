# 李世民击溃强敌

秦王李世民兵至高堰，薛仁杲派宗罗喉抵抗，李世民高筑营垒，坚守不出。诸将纷纷请战，他说：“我军刚打了败仗，士气低落。敌军则因打了胜仗，有轻敌情绪。目前应等待时机，到敌方骄傲散漫而我方群情振奋时，可一举歼灭敌军。”于是传令全军：“谁敢再说出战，立即斩首！”

两军僵持了六十余天，薛仁杲军队的粮食吃光了，有不少兵卒跑过来投降。李世民见时机成熟，派出部分军队在浅水原引诱敌军出战。宗罗喉早就等不及了，立即派出全部精锐部队应战，相持了几天，李世民估计敌军已经疲惫不堪，对众将说：“可以出战了。”派庞玉在浅水原南面布下战阵。宗罗喉像输红了眼的赌徒，指挥全军大举进攻。就在庞玉几乎招架不住的时候，李世民亲率主力部队从浅水原北面发起强攻。敌军措手不及，顿时大乱，纷纷溃逃。李世民带领骑兵穷追不舍，窦轨拽住他的马，劝他不要追击，以免中了敌军的埋伏。李世民说：“势如破竹，机不可失。”下令继续追击，迅速包围了宗罗喉驻守的城池。敌军见大势已去，纷纷出城投降。薛仁杲无奈，也出城投降了。

这一仗投降精兵上万人，众将都来祝贺，有人问：“大王一战而胜，立即舍弃步兵，仅靠骑兵，又无攻城器械，竟直通城下。谁都觉得无法破城，您却一举攻克，这是什么原因呢？”李世民说：“宗罗喉属下都是陇外骁将悍卒，只有出其不意才可战胜他们，所以战斗中斩杀和俘虏的人不多。如果不抓紧进攻，败军聚集到城中，薛仁杲稳定住军心，那就很难对付了。我急速猛攻，败军大多溃逃陇外，城里就空
