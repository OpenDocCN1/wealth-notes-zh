# 明镝散军妓

明镝在并州任职时，军营中有些妓女常年居住。他想把妓女赶走，又怕招致军卒的不满。凑巧的是，因争风吃醋，几个愤怒的军卒打死了一个妓女。捕支把那几个军卒捉拿来，并陈述了杀人的缘由。明镝故作心不在焉地说：“谁也没请她们来，出了事与官府有什么关系？”说完，竟把那几个杀人的军卒无罪释放了。妓女们听说后人人自危，纷纷逃走了。

# 叶南岩息讼

叶南岩任蒲州刺史时，有一伙打群架的人抬着一个被打成重伤的人来告状。他见那人生命垂危，忙拿出自己家的刀疮药，亲自捣成碎末，给那人敷上，治疗完毕，叶南岩又安排两个下属照顾受伤人，嘱咐说：“要好好照料，不要让伤者受风。他如果死了，我拿你俩是问。”随后，把受伤者的家属全都赶了出去，不准他们接近受伤者。

经过周密地调查，叶南岩查出了打人主谋，把他关进监狱，释放了其他人。有个好友不理解叶南岩的做法，他解释说：“俗话说，骂人无好口，打人没好手。受伤者如得不到急救，就会因失血过多而死亡。他一死，问题就严重了。不仅他的妻子要守寡，儿女成孤儿，而且打死人的人要偿命，他的妻子也要守寡，儿女也要成孤儿。其他参与打斗的人，也要判刑入狱。这么一来，就会有许多家无法正常生活。如果受伤人治好了，变成了一桩无足轻重的打架斗殴案。想
