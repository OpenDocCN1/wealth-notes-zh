# 田苓一语中的

赵国和魏国联合进攻华阳，韩国向秦国告急。接连派了许多使臣，可秦国就是不同意派兵。田苓愿为使臣，去请求秦国发兵，相国韩辰答应了。他来到秦国，径直拜见秦相穰侯。穰侯态度傲慢，不屑一顾地问：“韩国形势很危急吧？您来有何高见呢？”田苓说：“韩国没什么危急的形势。”穰侯生气地说：“你这话是什么意思，韩国形势不危急，接二连三地派使者求救兵干什么？”田苓说：“韩国形势若是危急，把国土割给赵魏两国就可以了，还有什么必要向秦国讨救兵呢？”穰侯说：“您不用见大王了，我决定立即派兵援救韩国。”几天后，秦国援军打败了赵魏联军，解了华阳之围。

# 慎子保国

楚襄王当太子时，在齐国做人质。楚怀王死了以后，太子向齐王辞行，齐王说：“你把东边的国土送给我五百里，就放你回去。否则，你是回不去的。”太子一时拿不定主意，说：“请允许我去问问太傅。”找到太傅慎子后，慎子说：“献地是为了保身，你舍不得奉献自己喜爱的国土，耽误了给死去的父亲送葬，那是不义的。我觉得应该答应齐王。”于是，太子去见齐王，说同意献地。

太子因而得以回国即位，齐国使者也随之之前来索要土地。太子又找慎子商量，慎子说：“您可在明天上朝时，让各位大臣都献计献策。”太子照办了，臣子们各抒己见，意见不统一。
