# **李世民识人**

唐太宗李世民对群臣说：“国家的灭亡，大多是由奸臣谄媚奉承酿成的。”于是有人上书，要求清除奸佞之臣。李世民问裴矩说：“怎么样才能识别出奸臣呢？”裴矩说：“他日陛下和众大臣议事时，可以假装发怒。那些直言不讳，据理力争的是忠臣；因惧怕陛下的威严而曲意奉承的人就是奸臣。”李世民摇摇头，说：“这样做不合适。按理说，国君就像水流的源头，人臣就像水流。哪有弄脏了水源，却要水流清洁的道理？身为一国之君，使用狡诈的计策去窥视别人的内心，又怎么可以指责人臣曲意奉承呢？历代的帝王，大多为自己能要点小小的权术而沾沾自喜，我却替他们脸红。”

后来，李世民发现有些大臣收受贿赂，就暗中派人送礼，想以此查出收受贿赂的人。结果司门吏接受了一匹绢，李世民动了怒，打算处以极刑。裴矩表示反对，进谏说：“做为朝廷命官，收受贿赂，贪赃枉法，的确可以处以极刑。可是您故意行贿，并以此为依据加以惩罚，属于陷人于法，本身就是违法行为。”李世民由衷地点了点头，高兴地对群臣说：“只有像裴矩这样敢于纠正君王错误的人，才称得上是忠臣啊！”
