# 复仇术

复仇是一种重要心态，它激励人们为达到目的，不惜付出高昂的代价，乃至献出生命。适当地把握时机，是能否成功的关键。时机来到，随意妄行，不仅不能复仇，而且会打草惊蛇，甚至会受到仇敌的进一步伤害。聪明的复仇者，在良机尚未到来之时，隐藏起真正的目的，等待时机的到来。一旦时机成熟，如下山之虎，似离弦之箭，迅猛出击，报仇雪恨。

# 吕母替子报仇

王莽当政时，郡郡郡海曲县有个吕母，她的儿子当县吏，因为犯了点儿小罪，竟被县宰杀了。吕母越想越恨，决心替儿子复仇。吕母家很有钱，她就酿造了许多醇酒，又买了不少刀剑衣服。年轻人来买酒，她总是多给，少收或者不收钱。衣服破的人来了，她就给换上新衣服，也不论价收钱。几年后，吕母的钱财用光了，不少年轻人赶来还钱。吕母哭着说：“我之所以对大家好，并不是为了求别的，是因为县宰无辜杀了我的儿子。诸位肯哀怜我吗？”年轻人听了都很气愤，表示愿意帮助吕母报仇。消息传开后，附近的人纷纷赶来报名。仅仅几天时间，就召集了几千人。吕母自称将军，率众攻破海曲县，活捉了县宰，历数他的罪行。其他官
