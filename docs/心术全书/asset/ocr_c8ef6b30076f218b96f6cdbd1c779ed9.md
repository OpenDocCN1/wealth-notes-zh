# 杨云才换砖模

杨云才担任荆州同知时，朝廷拨款整修拓宽城墙，经费已经确定。可是御史台却忽然发来公文，要求城墙比原设计高出二尺左右。主管建城的官员和郡守合计，打算增加经费。可是郡里一时又拿不出，大家正在着急，杨云才说：“我有办法了，用不着增加一文钱。”第二天，他乘马来到砖场，命砖场老板取来砖模检验。砖场老板连忙献上，杨云才故作认真地看了一会儿，突然发怒道：“这砖模不合尺寸！”说着命人砸碎了原有的砖模，然后拿出自己随身带来的，交给砖场老板，说：“就使用这样的砖模！”砖场的人看了新带来的砖模，都莫名其妙，因为实在看不出与原有的砖模有什么不同。实际上，杨云才带来的砖模比正常砖模厚出二分左右，凭眼睛打量是根本看不出的。可是每层砖厚出二分，城墙的高度会累积增加二尺左右，正合御史台的要求。
