# 李衡妻保夫

三国时期，丹阳太守李衡为人直率，多次顶撞冒犯邵那王。妻子虽然多次相劝，可他就是不听。那那王即位后，李衡才害了怕，不知如何是好。妻子说：“郡那王平素就追求好的名声，现在正想借着即位的时机，让天下人都知道他的美德。因此，他目前不可能因一点儿私怨杀人。你应该主动穿上囚徒穿的衣服，请求他把你关进监狱，再上表逐一列举自己的过失，要求接受严厉的惩罚。这样做不仅会得到宽恕，兴许还会有别的收获。”李衡照办了，郡那王果然下诏说：“丹阳太守李衡，因自己过去有一些小过失自责入狱，痛心悔过。事情既然过去了，没必要再追究。李衡知错能改，实属难能可贵，依旧官任丹阳太守。”
