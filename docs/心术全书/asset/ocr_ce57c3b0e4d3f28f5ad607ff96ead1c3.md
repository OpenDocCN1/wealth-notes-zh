# 有天无日头处

明代成化年间，嘉善知县林某随意打死了一家十三口人。侣钟巡按浙江时，准备加以严惩。林某得知消息，出重金贿赂镇守浙江的宦官李文，求他说情。李文便派人请侣钟赴宴。侣钟明白李文的用心，就预先替优人编了个滑稽戏。宴会上，一个优人装扮成官员在赏雪，并让吏卒把雪狮子放到阴冷处，留待日后观赏。官员问：“放在何处好呢？”吏卒说：“山阴怎么样？”官员摇摇头。吏卒又说：“江阴可以吧？”官员还是摇头。吏卒想了想，说：“山阴、江阴都不行，那就不知该放在何处了。”官员说：“只有嘉善县合适。”吏卒说：“嘉善县无阴，恐怕放不住。”官员说：“谁说嘉善县无阴？林知县打死一家十三口人，至今逍遥法外，难道不是有天无日的地方吗？”一座皆惊。李文见侣钟态度坚决，不敢开口求情。
