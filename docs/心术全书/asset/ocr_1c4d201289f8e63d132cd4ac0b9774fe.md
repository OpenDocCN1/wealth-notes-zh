# 察 伪 术

人的内心是最难考察的。人们相貌不同，经历各异，有的表面上温良而实际上内心诡诈，有的外表恭敬而内心在搞欺骗，有的人貌似勇敢实际上很怯懦，有的好像尽力实际上并不忠诚。人心并非无法探究，有七种方式可以考察出对方的内心世界：一是在事非面前观其志，二是与之交谈，进而发现可疑点，三是同他谋划事物，观察其态度，四是借祸患灾难，考察其是否勇敢，五是同他饮酒，考察其心性，六是用财产考察他是否廉洁，七是让他做一件事，考察其是否守信用。

# 箕不疑识伪
