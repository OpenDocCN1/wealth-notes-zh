# 请吃笋烧肉

有个姓姚的江南人在某县担任知县，政绩斐然。有个远方来的道士，声称能预知未来事，受迷惑的人很多。知县听说了，派仆人拿着请帖，假托太夫人有病，请他到县衙来。道士听说知县请自己，别提有多高兴了。到了县衙前，知县亲自出迎，那道士更加飘飘然。落座后寒暄了几句，知县突然问：“你知道我请你来干什么吗？”道士说：“太夫人身体不适，我早就知道了。”知县说：“请你来没别的事，想请你吃一顿笋烧肉。”说完，喝令衙吏把道士拽下去，打了四百竹板。知县又问：“你知道本知县还打不打你？”道士哀求说：“青天大老爷开恩，不能再打了。”知县声高喝道：“又说错了，再打四百。”打完，知县拍案厉声说：“你既然自称预知未来事，怎么不知今天要挨打？你妖言惑众，罪该万死。念你初来本县，就不深究了。你要马上离开本县，不准再回来。”判决完，让衙吏把他哄了出去。
