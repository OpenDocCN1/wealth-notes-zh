# 假 手 术

所谓假手术，指的是借刀杀人。比喻自己不出面，用别人之口去陷害他人，或借别人之手除掉对手。由于法律的制约，环境的限制，随意陷害或杀害对手，会将自己置于不利境地，因而使用假手术是再合适不过的了。“杀人莫见血，见血非英雄”，说的就是这个道理。

# 郑桓公灭邻

春秋时期，郑桓公打算进攻邻国，先派人了解了邻国的良臣勇将，记下了他们的名字。然后派人潜入邻国，送上厚礼，并把邻国的良田指定分给他们。接着在邻国城外设立祭坛，把记有这些人名姓的名册埋在地里，以鸡血和猪血浇祭，仿佛盟誓过一般。邻君得知后，以为这些人要造反投敌，就把他们全都杀掉了。郑桓公趁机兴兵进攻，很快就灭亡了邻国。
