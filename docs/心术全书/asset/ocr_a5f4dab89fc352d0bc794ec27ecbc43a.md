# 钓 鱼

元朝英宗至治年间，江西铅山一带造伪钞成风，主犯是当地土豪昊友文，他们把伪钞散发到江苏、安徽、河北等地，为害很大。

昊友文奸诈狡猾，心狠手辣，靠印伪钞发了大财。他还暗中指使手下党羽四五十人混进官府当差，作为地探。如有人告他的状，党羽会立即通风报信，告状人用不了几天就会被暗杀，因而没有人敢告状。昊友文还先后霸占他人妻女十一人为妾，民愤极大。

至治二年，福州罗源人林兴祖到铅山任知州。他对昊友文的劣迹早有所闻，下决心要除掉这一大害，又苦于找不到罪证。就设下放长线钓大鱼之计，四处张贴布告，严禁制造伪钞，并悬赏告发制造伪钞的人。布告贴出几天后，林兴祖又暗中布置一人到官府揭发，却又判他是假的，把他赶了出去，因此昊友文也就没有加害于他。百姓见有人告发昊友文没有遭到暗害。胆子也就大了一些。

一天，有个人抓住了两个制造伪钞的人，扭送到官府。这两个人又说是昊友文叫他们干的，林兴祖就把他俩关押起来。昊友文自恃有财有势，就出重金贿赂林兴祖，要求释放这两名罪犯。林兴祖既已抓了罪证，一方面严辞拒绝了贿赂，一方面将昊友文扣了起来，收监候审。

消息传出，立刻哄动了四方街邻，一时间有上百人来揭发昊友文的罪行。林兴祖将昊友文及其同党逐ー依法论罪，除了大害。
