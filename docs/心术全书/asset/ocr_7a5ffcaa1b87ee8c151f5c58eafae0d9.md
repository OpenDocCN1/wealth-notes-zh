# 遗剑杀文种

文种接到范蠢劝其出走的信，一时拿不定主意，就托病不上朝。勾践知道文种的才干远在众人之上，决心除掉他，免得日后生出祸患，便亲临寓所去“探病”。进屋后，勾践解下佩剑，说：“你有七个好计策，我用了四个就灭亡了吴国，剩下了三个。可是万一吴国的祖宗找我报仇怎么办？寿梦、僚、阖闾他们都挺厉害，你得替我想法儿对付他们才行。”文种听得糊里糊涂，刚要问个明白，勾践已站起身，故意把宝剑落下走了。文种取过宝剑，只见上面刻有“属镂”二字，原来是吴王夫差赐伍子胥死的那把剑。他回想了一下勾践说的话，什么都明白了，悲哀地说：“悔不该不听范蠢的劝告！”接着仰天大笑，说：“百世之后，后人定当拿我与伍子胥相比，虽死犹荣。”说完刎颈自杀了。

# 长沙王讨封

西汉时，各地诸侯王云集京朝朝见皇帝。汉景帝设宴款待，并让诸侯王跳舞祝寿。大家都跳得很开心，只有长沙王跳得别别扭扭，像是放不开手脚，惹得大家阵阵发笑。汉景帝觉得奇怪，问他怎么了，长沙王说：“国小地窄，不足回旋！”汉景帝明白了他的用意，就把武陵、零陵、桂阳三处加封给了他。
