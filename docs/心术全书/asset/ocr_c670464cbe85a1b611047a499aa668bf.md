# 王阳明审案

明朝时，盗贼首领王和尚被抓获，供出了同伙多应享和多邦罕。他俩被捕后，已经表示悔罪。可是多应享的母亲突然写了封信给官府，为儿子申冤，还让王和尚作证。王阳明想，肯定是王和尚接受了多应享家的财物，才答应替他开脱罪责。为了弄清这件事的来龙去脉，王阳明专门在后堂设了案桌，把一名衙役藏在桌围中。布置停当，他下令把三个盗贼带上堂进行复审。按照预先的安排，刚开始审案，一名衙役急匆匆地跑进来，说宾馆来了客人。王阳明便起身走了出去，屋里只剩下三个盗贼。过了一会儿，王阳明回来了，桌围中的衙役钻了出来，说：“大人刚才出去时，王和尚对其他两人说：‘你们暂且咬紧牙关，忍受点皮肉之苦，等我想办法为你俩开脱。’”三个盗贼见阴谋败露，赶忙叩头认罪，从实招来。
