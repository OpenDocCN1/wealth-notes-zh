# 曹操不征辽东

官渡一战，曹军大获全胜。袁绍的两个儿子袁尚和袁熙率领几千人马逃往辽东，投奔了辽东太守公孙康。公孙康身为汉朝太守，却自恃辽东地处偏远，不服朝廷管辖。等到曹军大破乌桓后，有人劝说曹操趁机征伐辽东，认为这样不仅可以收服公孙康，还可以清除袁氏兄弟这一隐患。曹操说：“征伐大可不必，二袁的脑袋，公孙康很快就会给我送来。我何必要出兵征讨，闹得民不聊生呢？”众人都才明白这话是什么意思，但见曹操主意已定，谁也不好再说什么。转眼到了九月，曹操率军从柳城回来，正赶上公孙康遣使送来了袁氏兄弟的首级。众人依然搞不清曹操用的是什么计谋，曹操笑着说：“公孙康早就痛恨并惧怕袁氏兄弟，我军如果急于进攻，他们就会合起来对付我们。缓一段时间出兵，他们就会自相残杀。因此，我料定公孙康必杀二袁无疑。”
