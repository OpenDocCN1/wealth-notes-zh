军民。

有一次，吴将陈尚和潘景侵犯晋地，被晋军追击打死。羊祜说，他们以身殉职，精神可嘉，便下令厚加殡敛。两人的家属来迎丧，羊祜以礼相待。晋军俘虏了两个东吴的孩子，羊祜说：“他们的家人一定很着急，还是宽大为怀，放他们回去和家人团聚吧！”孩子的家长感激羊祜大恩，后来带领所属家族投降了晋军。

吴将邓香带兵骚扰，烧杀抢掠，被晋军捉到，捆绑着来见羊祜。邓香吓得脸色灰白，认为一定要被砍头。不料羊祜只责备了几句就把他放了。邓香感恩不尽，也带部属投奔了羊祜。

有时羊祜会集部众在江、河一带打猎，严禁超越晋地。有的猎物如果先被吴人射伤，逃过边境，被晋军得到，羊祜就派士兵送回去。像这样的事一传十，十传百，东吴的将士和百姓对羊祜都心悦诚服。他们称羊祜为羊公，不再直呼他的名字了。

陆抗知道羊祜这一手很厉害，比刀枪更能征服人心。他也以同样的方式对付羊祜，派人送去美酒。羊祜当着使者的面，毫不迟疑，捧起就喝。有一次陆抗病了，羊祜派人送去了药，使者说：“这药是羊公亲自调制的秘方，准备自己服用的。听说将军身体欠佳，特地送来。”陆抗的僚属苦苦恳求陆抗不要吃，他说：“羊祜岂是用毒药害人的将军？”说着一口气喝了下去。这一下两人的名声传开了，边境暂且平安无事。

羊祜一面以仁德对东吴军民施加影响，一面认真积蓄力量，做好伐吴准备。后来晋军一举灭吴，其中羊祜的功绩是不可磨灭的。
