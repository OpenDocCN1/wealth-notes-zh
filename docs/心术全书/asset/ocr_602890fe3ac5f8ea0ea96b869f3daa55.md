# ## 齐军救韩

魏国攻打韩国,韩国向齐国求救。齐王拿不定主意,同大臣商量何时出兵合适。张䌹说:“应尽快出兵,如果去晚了,韩国抵挡不住,就会投降魏国,那对齐国可就不利了。”

陈臣思说:“我看现在还不到出兵的时候,因为韩魏两军都还没到精疲力竭的程度,现在就出兵,不是让齐军代替韩军承受魏军的打击吗?我们可以马上与韩国结成军事同盟,严密观察战场形势的变化。等到魏军疲惫不堪时,我们不仅可以轻易取胜,而且能得到更多的利益。”齐王听取了陈臣思意见,打发韩国使者回了国。韩国又接连打了五次败仗,再次向齐国求救。齐王这才派出大军,在马陵大败魏军。自此,魏国和韩国因两败俱伤,都衰落下去了。
