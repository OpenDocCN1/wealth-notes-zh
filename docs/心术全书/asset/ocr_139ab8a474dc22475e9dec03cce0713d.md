# 刘瑾专权有术

大宦官刘瑾想专权，就为明武宗准备了各种珍宝古玩。等明武宗看得入迷时，他就取出各衙门的奏章请武宗处理。明武宗正在兴头上，不耐烦地说：“我用你是干什么的？为什么要拿这些事来使我心烦呢？赶快拿到一边去。”一连这么做了几次，以后事情不论大小，只随刘瑾裁决，不必再申报皇帝了。
