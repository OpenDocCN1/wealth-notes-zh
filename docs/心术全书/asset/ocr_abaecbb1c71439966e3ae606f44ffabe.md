# 范尧夫治恶僧

范尧夫任陕府帅时，属下的一个知县因事入村，到了一座佛寺稍事休息。吃完饭，在廊庑间散步，看见一间僧房很雅致清洁，寂静无人，桌上摆着一瓢酒。知县一时高兴，提笔在僧房窗纸上写了一首诗：“尔非慧远我非陶，何事窗间酒一瓢？僧野避人聊自醉，卧看风竹影萧萧。”头一句用的是东晋大诗人陶渊明和僧慧远交往的典故，由于二人本不相识，所以连用两个“非”字，反其意而用之。据诗意看，知县并未沾酒，然而却“沾包”了。原来这和尚的俗家，以前曾到县衙打官司，因理屈被判了罪。由此和尚憎恨知县，这一瓢酒就是用来陷害他的。

知县走后，和尚把窗纸上的诗割下来，贴在状纸上作物证，投状子到范尧夫处诬告知县，说：“和尚我有施主某某，昨日带着酒来到我房中，正赶上我不在屋。不料知县走了进来，施主赶快躲避起来。知县把酒喝了倒没什么，可是把几只银杯也顺手牵羊拿走了。那几只银杯是施主的，让我拿什么还他。大人只要追问一下施主和县衙小吏就明白了。”
