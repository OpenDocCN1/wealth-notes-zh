# 崔巨伦作歪诗

北魏人崔巨伦曾担任殷州别将。殷州被叛军攻占后，叛军首领葛荣听说他有才能和名望，打算起用他。崔巨伦决心逃跑，不在叛军内任职。端午节那天，葛荣会集百官，让崔巨伦当众赋诗。崔巨伦故意思索了很大一会儿，吟诗道：“五月五日时，天气已大热。狗便呀（张口）欲死，牛复吐舌头。”听了他的诗，众人差点笑闪了腰。自此葛荣很轻视他，再也不提让他做官的事了。

不久，崔巨伦交结了儿个志士，一起南逃。一天晚上，他们路遇叛军巡逻队，其他几个人不由紧张了起来，崔巨伦小声鼓励大家说：“宁可向南一寸死，决不向北一尺生。”他大模大样地迎若巡逻队走了上去，欺骗他们说：“我们是奉命去执行特殊使命的。”说着，掏出一张纸，递给巡逻队头目，说：“这是手谕。”趁巡逻队头目在火把下查看时，崔巨伦手起刀落，把巡逻队头目杀了。其他人见头目被杀，一齐抱头逃窜。崔巨伦一行终于摆脱了叛军的控制。
