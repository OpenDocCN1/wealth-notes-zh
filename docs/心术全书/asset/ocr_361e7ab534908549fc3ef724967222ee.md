# 半夜捉蛙

马光祖在处州任职时，下令禁止捕捉青蛙，违者治罪。有个农民将一个大瓜掏出瓜瓤，里面装满青蛙，外面用瓜皮盖上，与其它瓜混放在一起。不料进城时被发现，押送到了官府。马光祖仔细打量着那只瓜，觉得很难发现破绽，不禁发生了怀疑，问：“这些青蛙是什么时间捉的？”农民回答说：“半夜。”问：“有人知道吗？”答：“只有我妻子知道。”马光祖怀疑农民的妻子有外遇，有意陷害，就把她传讯到官府。经审问，她果然与人通奸。原来奸夫想通过陷害农民，达到长期霸占其妻的目的，便唆使她教丈夫用空瓜藏青蛙入城。奸夫又预先告诉守城的兵卒说有人用空瓜运青蛙进城，所以农民被抓住了。查明了情况，马光祖严惩了这一对狗男女。
