# 李世民愧贪

将军长孙顺德接受了别人送给他的几匹绢，事发后，唐太宗李世民当众赏赐给他几十匹绢。大理寺少卿胡演进谏说：“长孙顺德收贿赂理应严惩，可陛下却赏赐给他许多绢，这不是助长他的贪心吗？”李世民说：“不！如果他还有一点廉耻之心，得到我赐给他的绢，感受到的耻辱应超过刑罚。如果感受不到耻辱，说明他不过是个连禽兽都不如的人，即使杀了他，又有什么用呢？”有些时候，从侧面使对方反省过失，比正面直接指责，会收到更好的效果。
