# 朱棣装疯夺位

洪武三十一年闰五月，明太祖病死，因太子朱标先于太祖七年死去，由皇太孙朱允炆即位，改年号为建文，是为建文帝。齐泰被任命为兵部尚书，黄子澄担任了太常卿。太祖初建明朝时，曾将自己的儿子分封到全国各地，宗室诸王的势力都有所膨胀，其中又以北方数王的势力较大。他们设置官署，拥有甲兵，位尊权重，对皇权形成严重的威胁，尤其是封在元朝故都燕京的燕王朱棣势力最强。

因此，朱允炆即位后，就同齐泰、黄子澄商量削藩。齐泰主张先削燕王，认为只要将他削掉，其他诸王会不削自服。黄子澄则认为应先削其他诸王，去掉燕王的羽翼，这样一来，他势孤力单，成不了大气候。朱允炆同意了后者，开始对其他诸王下手。与此同时，又改任工部侍郎张昖为北平布政使、都指挥谢贵、张信掌北平都司事，并且屯兵北平附近，从内外两方面钳制燕王。

燕王看透了朱允炆的意图，想先发制人，起兵发难，可又觉得时机不成熟。因而暂时忍耐，秘密训练军队，准备起事。他见形势不利，就假称得了癫狂病，在街市上奔走喊叫，抢夺人家的酒食，说话颠三倒四；有时仰面朝天躺在大路上睡觉，终日不醒。张昖和谢贵知道后，便借口入宫探病，想看个究竟。时值盛夏，只见燕王穿着皮袄，守着火炉，还一劲儿地喊冷。二人认定燕王真有病，防备稍为放松。但葛诚密报燕王根本没病，朱允炆下密诏让张信提拿燕王。张信因平素深受燕王的知遇之恩，反倒同他一起对付朝廷。不久，燕王诱杀了张昖、谢贵，宣布起兵清君侧。
