
# 吴汉临变不惊

吴汉担任大司马时，有敌寇夜袭军营，将士们一片恐慌，吴汉却坦然地躺在床上，像什么事也没发生一样。将士们听说吴汉躺着不动，都安定了下来，回到各自的营帐中去了。军心稳定后，吴汉亲自挑选了一部分精兵迎击敌寇，敌寇狼狈逃窜。

# 张辽杀反卒

三国时，张辽接受曹操的命令，率军驻扎在长社。一天夜里，军中有几个想谋反的人点燃大火，闹得人心惶惶。张辽对左右亲兵说：“谁也不要动，这肯定不是全军谋反，而是别有用心的人制造事端，扰乱军心。”接着又传令全军说：“不反的人安然就坐。”军令下达后，不知所措的将士们纷纷坐了下来。张辽抓住时机，亲自率领十几个亲兵在军营中寻找，很快搜出了谋反首要分子，就地处死了。

# 保持平衡

濡须战争时，孙权与曹操僵持了一个多月。一日，孙权乘坐大船偷看曹军的布防情况，被哨兵发现，报告了曹操。曹操大怒，下令万箭齐发，箭如飞蝗般地射到了船弦上。由于中箭太多，竟使得大船开始倾斜。孙权从容不迫，下令调转船头，让船的另一边受箭。过了一会儿，这一边也射满了箭，船身又平稳了。

# 文聘退吴军

三国时，魏将文聘驻守石阳，孙权亲率五万大军来攻。当时正值雨季，洪水冲毁了不少处城墙和栅栏，无法守城。文聘决定用空城计退敌，下令城中任何人不许走动。自己则躺在床上不起身，用以安定军心。孙权果然不敢攻城，认为附近必有伏兵，便撤兵而去。

# 失匕

刘备在未得势时处处小心，不显露自己的胸怀。一次，曹操宴请他，席间两人谈论天下人物。曹操说：“现在天下的英雄，只有您和我两人。像袁绍那样的人是不足称道的。”刘备正在进食，一听这话，惊得筷子掉在了地上。这时，外面风雨交加，响起一阵震耳欲聋的炸雷。刘备为了掩饰自己举动的失常，忙说：“圣人说：‘雷急风狂时，人会吓得不知所措。’这话真有几分道理啊。刚才的炸雷，吓得我连筷子都掉在地上了。”

# 谢安镇静鼓士气

东晋时，苻坚率前秦军准备一举灭亡东晋政权。东晋宰相谢安，派侄子谢玄为主将，迎击前秦军。由于兵力相差悬殊，将士们心存畏惧，有不少人开了小差。在这种情况下，谢安保持着若无其事的悠闲神态，即使谢玄亲自来请示迎敌方案，他也只是说：“一切准备就绪，不必担心。”

谢玄坐立不安，又派人去请示。谢安却大摆宴席，下棋取乐，好像根本不把战争当作一回事。实际上他对战争并没有肯定获胜的把握，只不过想以此消除谢玄的不安心理。在谢安的影响下，谢玄镇静了下来，他审时度势，出奇兵击溃了前秦大军，夺得了淝水之战的胜利。有趣的是，当捷报传来时，谢安只是随便地扫了一眼，就又下起了围棋。宾客问：“到底发生了什么事？”谢安淡淡地说：“没什么，只不过是小儿辈大败敌军罢了。”嘴上虽这么说，可他下完棋回屋时，再也抑制不住内心的激动，过门槛时竟把木屐折断了。

# 李世民自制

李世民是中国历史上不多见的明君，他说：“君主依赖国家，国家依赖国民。君主搜刮国民的血汗来供自己挥霍享乐，就如同割自己身上的肉充饥一样。肚子虽然填饱了，人却死了。君主如果富了，国家就会贫穷乃至灭亡。世上的人常常忧虑盗贼，其实真正的盗贼是那些身为君臣却挥霍无度的人。有的人主张治国采用严刑峻法，我看不如去掉奢侈腐化的风气。只有节省开支，减轻徭役赋税，百姓生活富足了，国家也就安定了。”李世民不仅是这么说的，而且也是这么做的。因而在其统治时期，我国出现了“贞观之治”的盛世。

# 官印失而复得

唐宪宗时，裴度被封为晋国公，任中书令。一日，手下人突然报告说官印丢失了。裴度一点儿也不慌乱，和颜悦色地告诉下属不要声张。当天晚上，他设宴与众人畅饮。半夜时分，手下人附耳告诉他说官印又回来了。裴度什么也没说，依旧饮酒不止，直到尽兴方才罢宴。有人问丢失了官印为何不着急，他说：“官印肯定是让掌管案牍的官吏私自拿去干不正当的事去了。我如果追得紧，他们就可能把官印销毁或投入水中，那就再也无法找到了。我有意延缓一下处理，是料想他们用完后，会悄悄地送回来。”

# 军营夜火

王驟任益州知府时，有几个戌卒夜间在军营里放起大火，想以此制造混乱。王驟得知消息后，马上派兵把军营围了个水泄不通，并且传令说：“不想谋反的人，举起双手出来，没任何事。”于是，众戌卒都走出了军营，制造事端的戌卒也夹杂在其中。见戌卒都出来了，王驟让知晓闹事详情的军校把制造事端的戌卒指了出来，共计十来个人，王驟当即把他们处死了。军营很快恢复了正常，好像什么事都没发生过。

# 李及观书

曹玮在秦州任职多年，因年老多病，多次向皇帝呈交奏章，请求朝廷派人接替自己。宋真宗问宰相王旦说：“由谁来接替曹玮合适呢？”王旦考虑再三，推荐了李及，宋真宗也表示同意。众人则觉得李及虽然小心谨慎，办事公道，并有一定的政绩，但他缺乏威武果断的气魄，恐怕难以胜任守卫和管理边境的职务。老臣韩亿也有这种看法，就对王旦说了。王旦听后笑了笑，什么话也没说。

李及到了秦州，秦州的将领和官吏见来了个文弱书生，都有些轻视他。一天，有个禁军士卒大白天在集市上强抢民女的银钗首饰，被捕吏当场抓获，押送到官府。李及正在看书，听完报告后，命人把禁军士卒押上来。略加审讯，禁军士卒就认了罪。李及干脆超越其它管理手续，把禁军士卒立即斩首。接着，他又看书如故，好像根本没发生过什么事情，将吏们无不惊叹佩服。

不久，李及处事果断的消息传到了京师。老臣韩亿听说了，又去拜访王旦。把他听到的原原本本地对王旦说了一遍，还极力称赞王旦知人善任。王旦平静地说：“禁军士卒光天化日之下当强盗，边帅就地处斩，是很平常的事，没有什么可值得大惊小怪的。我让李及代替曹玮，并不是出于这方面的考虑。试想曹玮管理秦州已达七年之久，西羌人对他都佩服至极。两国和睦相处，没有发生什么事端。可以说，曹玮已经把边境上的事安排的稳稳妥妥的了。如果派他人接替曹玮，必然会自以为聪明，轻易地改变了曹玮的治理措施。这样一来，曹玮多年来开创的局面就付之东流了。之所以派李及去，是因为他老成持重，必定会谨守曹玮的管理方式，如此而已。”韩亿越发佩服王旦的见识和气度。

# 烧井栏

文彦博在成都任职时，常在雪夜大宴宾客，饮至深夜不散。士卒在风雪中守卫了半夜，饥寒交迫，愤怒异常，诅咒饮酒的官员们不体恤下属的冷暖。为了发泄，他们故意拆掉井栏，点燃烤火。有个军校跑来报告，宾客们听了腿都吓酥了，不知该怎么办好。只见文彦博不慌不忙地说：“天的确很冷，拆井栏烧，算得了什么事？”他神色自若，饮酒如故。那些憋足了劲准备闹事的士卒，因找不到闹事的理由，一个个全像漏了气的气球，无精打采地散去了。第二天，文彦博才追问烧井栏的事。很快查出了鼓动的人，把他狠狠地打了一顿板子，驱逐出官府。

# 驿舍火

宋英宗时，苏颂担任度支判官。一次，他陪同契丹使者回国，住宿在恩州。半夜时分，驿站客舍着起了大火。手下人请他出外避火，苏颂不同意；当地的士兵想入内救火，苏颂还是不同意，只是传令守卫驿站的士卒把火扑灭。原来这场大火是有人故意放的，目的是想以此诬陷契丹使者制造事端，并试图让不明真相的当地士兵趁救火之机杀死契丹使者，进而达到离间宋朝和契丹关系的目的。由于苏颂看出了有人制造事端的险恶用心，因而既不让手下人出去，又不让受煽动的士兵进入，使制造事端的人无懈可击，从而保证了契丹使者的安全，维护了宋朝和契丹的友好关系。

# 草场火

宋代，杜纮在郓州任职时，有人在城门旁边贴出了一张大纸，上面写着妖魔将要降临郓州等一些话，郓州的百姓见了都很害怕。不久，官府的草场大白天着了大火，而这也正是大纸上写的“妖魔”要做的一件事。郓州的百姓更害怕了，以至有不少人关门闭户，打算到外地避一段时间。有个手下人请求杜纮在全城进行大搜捕，捉出装神弄鬼的人。杜纮笑着说：“这正是奸人所希望的，我如果下令大搜捕，就会加剧全城的混乱，奸人正好趁火打劫。我怎么会落入他的圈套呢？我不上当，奸人反倒会无计可施。”不久，捕吏终于查出了那个企图闹事的人。那人是个强盗，准备搞乱民心，混水摸鱼。不料聪明反被聪明误，财没发成，倒把自己送上了断头台。

# 军械库失火

李允则正设宴款待军队将领，有人报告军械库起火了。他不动声色，依然饮酒行令。大火扑灭后，他马上派人秘密到瀛州调运军械。没用上十天时间，军械运回，补足了因大火而短缺的部分，几乎没有人知道这件事。不久，李允则饮酒不救火的事传到了朝廷，枢密院请求宋真宗免去他的官职，并追究刑事责任。宋真宗说：“这事肯定有原因。”于是，把李允则召到朝廷，请问不救火的原因，他说：“军械库历来禁火，看守极严。那天宴会刚开始就着起大火，肯定是有人故意放的。我如果去指挥救火，有可能落入坏人的圈套，发生不测。”宋真宗认为他说得有理，决定免于追究。

# 狄青留涅

狄青出身下层士兵，后来跻身于显贵阶层，成为威震一时的名将。在他未发迹时，曾因犯罪遭受了脸上刺字、涂墨的涅刑。当他做了枢密副使后，脸上涅痕犹存。皇帝觉得朝廷大臣脸上有涅痕不体面，劝他用药除掉。狄青指着自己的脸说：“陛下不问门第，因功提拔重用臣下，我感恩不尽。我留下这块涅痕，正是用来劝勉将士用的，让他们知道，只要为国立功，任何人都会有出头之日的。因此，臣下不敢奉命。”打这以后，皇帝更加器重他了。

# 海瑞讨官印

明朝人海瑞到江南赈济灾民时，上元县令办事不利，受到了海瑞的斥责。谁知他不仅不后悔过，反而怀恨在心，偷走了海瑞的官印。海瑞算来算去，认定官印是被上元县令偷去了。如果当面讨要，他说死也不会承认。实在逼急了，还有被销毁的危险。要是不声张，他做贼心虚，必定会借故上门观察动静。

果不出所料，第二天上元县令便若无其事地来拜访海瑞。海瑞安排妥当后，才笑容可掬地出来迎接。二人刚刚坐定，没上上几句话，仆人气喘吁吁地跑进来报告说宿舍起火了。海瑞佯装惊恐，捧起装官印的匣子，猛地塞给上元县令，说：“这是大印，请暂且代为保管。”说着，扭头跑出去“指挥”救火去了。上元县令明知印匣子是空的，可又不敢说破，只好带上回去了。火很快救灭了，上元县令不敢交回空印匣，就把官印放进去，交还了海瑞。

# 尤翁忍辱

明朝时，苏州有个姓尤的老翁，经营了一家当铺，生意一直很兴隆。一年年底，尤翁听见前厅里有人吵架，就赶忙跑了过去，见是一位邻居和当铺的伙计在吵。尤翁问是怎么回事，伙计说：“这人前些日子拿了几件衣服来典当，今天却空手来讨还，还张口就骂人。”伙计这边说着，那人还在不停地骂，态度十分蛮横。尤翁想了想，满面笑容地走到那人跟前，好言好语地说：“嗨，咱们都是邻居，我有过错还希望你多加包涵。马上要过年了，又没什么大不了的事，你就别生气了。”说着回头让伙计把那人典当的东西拿来，打开一看，共有四五件衣服。尤翁拿起一件棉衣说：“这是过冬必不可少的衣服，你拿回去。”又拿起一件新一些的长袍说：“拜年时当然要穿件新的，这件你也拿回去。至于其他衣服，你眼下用不着，先放在这里怎么样？”那人拿了那件衣服，面带羞愧，一声不响地走了。当晚，那人突然死在另一家里，害得那家为此打了一年官司，几乎倾家荡产。后来才搞清，那人负债太多，无力偿还。他知道尤翁家很有钱，索性提前服了毒药，准备用死来敲一笔大钱。由于尤翁处理得法，才使他无话可说，死在了另一家。当有人问尤翁：“您难道预知邻人的诡计，才如此容忍吗？”尤翁说：“那怎么可能呢？我只是觉得一个人如果过分蛮横无礼，那他一定有所依仗。遇到这种情况，如果不加忍耐，就会酿成大祸。”

# 保身术

古话说，害人之心不可有，防人之心不可无。世上总有一些居心叵测的人，时时觊觎可乘之机，无事生非，损人利己。善于保身的人，能够明辨是非，精以应对，使之无可乘之机。尤其是身处逆境，亦能苦撑下去，既看到自己的劣势，又看到自己的优势，用理智来分析所处的现实，继续朝着既定目标迈进，变不利为有利，避免自身受到伤害。

# 芮伯献马

周厉王派芮伯讨伐玦国，大获全胜。芮伯在战利品中发现了一匹好马，准备献给周厉王。芮季劝告说：“你应该把马丢掉。我听说周厉王是个贪得无厌的人，他的欲望是无法满足的，并且爱听信谗言。你献上一匹好马，他会认为你得了许多匹好马。别的大臣也会乘机向你索取财物，你如果不能满足他们的要求，他们就会说你的坏话，这样你就很危险了。”芮伯不听，把马献给了周厉王。几天后，周厉王的宠臣荣夷公派人向芮伯索取财物，遭到了芮伯的拒绝。荣夷公怀恨在心，对周厉王说：“芮伯征讨玦国，得到了数不清的财产，可他全都据为己有了。”周厉王听了很生气，就把芮伯赶走了。

# 魏犟求生

晋文公重耳流亡时，受到了曹国国君的奚落。大夫僖负羁想私结重耳，就派人给他送去酒肉。后来重耳当了晋国国君，率军攻破曹国。为了报恩，他下令任何人不许动僖负羁的财产，违者死罪。

晋军将领魏犝和颠颉自恃功高，对重耳的命令很不服气，夜深人静时，二人潜入僖负羁家放起大火，魏犝因躲避不及，被砸成重伤。晋文公知道后很生气，准备把他俩处死。赵衰说：“主公执法从严的做法是对的，不过魏犝是晋军中最勇猛善战的将领，杀了实在可惜。我看杀了主使放火的颠颉就可以了。”重耳说：“魏犝虽然勇猛，可是已经受了重伤，看来好不了了，就按照军令杀掉算了。”赵衰说：“这样好不好，让我先去瞧瞧。要是他真的不行了，就照主公的话办；如果身体尚可，就留他一条命，让他立功赎罪。”重耳同意了。

再说魏犝胸部受了重伤，浑身上下烧得没一块好肉，有气无力地躺在床上呻吟着。听说赵衰来探望，这个冲锋陷阵的硬汉子竟然猜出了对方的来意，连忙命左右用布条裹紧他的胸脯，强支病体，亲自出来迎接。赵衰见了，不由得一愣，忙问：“听说将军身受重伤，怎么起来了呢？主公很惦念你，特意派我来看看。你快回去养伤吧。”魏犝说：“主公打发人来看我，我怎么敢失礼呢？我知道自己犯的是死罪，万一能免予一死，将拿这死里逃生的身子报答主公和您的大恩大德。”说着，故意蹦跳了几下，赵衰赶忙劝住，说：“快别这么着，我替你向主公求情就是了。”回去后，赵衰如实作了汇报，重耳免除了魏犝的死罪。

# 范蠡激流勇退

越国灭吴后，勾践在贺台上大摆宴席，庆祝胜利。席间，觥筹交错，群情欢腾，但勾践却神态反常，面无喜色。范蠡叹了口气，说：“大王不想归功臣下，有功的大臣就要面临危险了。大王的为人，只可共苦，不可同甘啊！”于是，他找了个借口出去，带上西施泛舟而去。勾践怕他变了心，连忙叫文种去接管了他的军队，然后派人各处去找。寻找的人在太湖边找到了范蠡的外衣和一封信，勾践以为他杀了西施，接着又自杀了，这才放下心。不久，范蠡托人偷偷送给好友文种一封信，要他赶快脱身。文种正犹豫不决时，就被越王赐死了。

# 景鲤自救

公元前287年，楚王派景鲤出使秦国。有人对秦王说：“景鲤是楚王最喜爱的大臣，大王应把他拘禁起来，用他换取楚国的土地；如果楚王不答应，我们就杀掉景鲤，再与才能不如他的人打交道。这可是一举两得的计谋。”于是，秦王拘禁了景鲤。景鲤弄清了事情的原委，让人传话给秦王说：“我觉得大王将被天下人所轻视，并且土地也不可能得到。来贵国之前，我就听说齐魏等国打算割让土地献给大王。他们之所以这样，是因为秦国与楚国是兄弟之邦。如今大王拘禁我，无疑昭示天下秦楚邦交已经破裂。这样一来，齐魏怎么会敬重孤立无援的秦国呢？当楚国得知秦国处境孤立后，不仅不会割让土地，还要联合其他诸侯国图谋秦国，秦国不就很危险了吗？所以还是把我放了为妙。”秦王认为他说得有道理，就把他释放了。

# 陈平杜绝谗言

燕王卢绾谋反的消息传来，刘邦派樊哙统率大军前往讨伐。樊哙刚走，就有人揭发他和吕后串通一气，图谋不轨。刘邦把陈平和周勃叫进来，说：“樊哙与吕后结成死党，巴不得我快死。你俩这就到燕国去，见到樊哙，就地处决。”他怕两人不敢杀樊哙，又吩咐陈平一定要带回樊哙的脑袋，他要亲自过目，并且要派周勃接替樊哙征讨卢绾。

二人启程后，陈平对周勃说：“樊哙是皇上的连襟，功劳又大。这会儿皇上发了脾气要杀他，万一反悔了，那该怎么办？再说皇上病危，咱们斩了吕后的妹夫，将来她能放过咱们吗？”周勃说：“可也不能不执行诏令，把他放了吗？”陈平说：“放是不能放，不如把他装入囚车，押回长安，让皇上自己处理好了。”周勃觉得是个好办法。

二人到了军队驻地，登坛宣读诏命。周勃统率军队，继续讨伐卢绾；陈平则把樊哙装入囚车，押送回京。途中，传来了刘邦驾崩的消息。陈平害怕吕后和吕须发怒，派人火速赶赴京城报告消息。回到京城后，陈平显得十分悲伤，有意向吕后把逮捕樊哙的事哭诉了一遍。吕后觉得他处理得很得体，就说：“你一路劳累，早点回去休息吧。”陈平害怕吕须趁机向吕后进谗言，就坚决要求留下来守灵，流着泪眼说：“我受了先帝的大恩，理应效犬马之劳。现在太子刚刚即位，宫里正需要人，就让我留下当个卫士吧。一来可以报效先帝的大恩，二来可直接替您和皇上效力。”吕后听得甜滋滋的，当即拜他为郎中令。从此，陈平深得吕后信任，吕须等人的谗言也就行不通了。

# 刘睦避祸

东汉时，北海王刘睦礼贤下士，很受皇帝器重。一次，刘睦派使者进京问候皇帝，问：“你到了京师，皇上问起我来，你怎么说？”使臣说：“我就说您忠顺孝顺，慈仁善良，敬重贤人。”不料刘睦连连摇头，说：“这么说不行。你要说我的小时候聪明伶俐，好学进取，可自从继承王位以来，终日沉溺于声色犬马之中，不问政事，不思进取。只有这么说，皇上才不会怀疑我。”

# 韦忠保身

晋惠帝是有名的白痴，昏庸无能，朝政被贾后把持。平阳人韦忠，博学多才，很有名气。尚书仆射裴顾就把他推荐给张华，张华便派人请他当官。韦忠却借口有病，委婉地回绝了。有个朋友问他为什么不去当官，韦忠说：“张华和裴顾这两个人为人轻浮，我不愿同他们玉石俱焚。”原来张华和裴顾依附贾后，引起许多人的不满。不久，就爆发了八王之乱，张华和裴顾及他们举荐的人，全被赵王伦杀害了。

# 王戎失足

西晋时，齐王见各路兵马从东西两面夹攻都城，忙召集文武百官商讨对策。尚书令王戎说：“来的军队很多，不可阻挡，不如让出大权回封土去，还可谋求平安。”东海王司马越附合王戎的意见，齐王微微地点了点头。

突然，齐王的心腹猛将葛旄呼地站起来吼道：“河间王这混帐东西叛乱，应该立即发兵征讨，为什么惊慌失措？汉魏以来几百年，朝中掌权的王侯打退堂鼓的，有几个保住脑袋、保住宗族的？凡主张要齐王交权返国的人，应该立即抓起来杀头！”

葛旄的大嗓门儿把百官都吓呆了。王戎全身冷汗直冒，看看齐王的脸色变了，露出杀气来，东海王也垂下了脑袋，心里一想，虽然东海王赞成自己，但他是皇亲，别人不敢叫他难堪，十有八成要拿自己开刀。不禁急中生智，赶忙说：“刚才服用了寒食散，药性发作，要上厕所。”随即装出老态龙钟的样子，故意失足跌进粪坑，满身又臭又脏地爬了出来。齐王和百官捂着鼻子大笑不止，本来杀气腾腾的气氛又缓和了下来。王戎狼狈地回了家，总算逃避了一场可能发生的杀身之祸。

# 酒中隐身

齐王专权后，任用了一些名士来作幕僚，连东吴地方远近闻名的张翰和顾荣也被请来了。他们起初对齐王寄托了很大希望，当见齐王恣意妄为，滥杀无辜，就灰心丧气了。张翰整日沉醉在酒里，别人对他说：“你不想好好干点事，在青史上留名吗？”他说：“死后留好名声，不如现在多喝一杯酒。”过了几天，他对顾荣说：“天下乱纷纷，何时能了结，我原是山中隐士，何必到这千里迢迢的外乡来贪图富贵，你善自保重吧！”找了个机会，他不声不响地溜走了。
