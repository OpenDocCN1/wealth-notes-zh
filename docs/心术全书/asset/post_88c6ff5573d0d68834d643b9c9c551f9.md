
# 女人头哪去了

有个安徽富商看上了一小户人家的妻子，就不惜出重金给她的丈夫，让他同意并劝说妻子改嫁。妻子开始不同意，在丈夫的威逼下勉强同意了。当天晚上，丈夫置办酒席宴请富商。估计富商快要到了，丈夫主动避了出去，让妻子出面招待。不料就在丈夫避出，富商到来这段间隙中，那女子被杀害了。富商来到，发现女子被杀，脑袋失踪，吓得不知所措。

丈夫回来后，以为富商杀害了妻子，告发到官。富商被传讯到官，说：“要我说喜欢这个女人，那完全属实。她即便不同意，我也会慢慢想办法，何必耍杀人呢？”官府听富商说得在理，就让他协助破案。有个老人对富商说：“这附近一直有个叫夜僧，从出事那天晚上起，再没听到他的声音，我觉得可疑。”富商就招募了几个人寻找叫夜僧的下落，很快在邻郡发现了他。富商派了个人穿上被杀女子的衣服，在树林中等着。当叫夜僧路过时，那人学着女人腔喊：“和尚，快还我头！”叫夜僧吓得浑身乱颤，说：“头挂在你们家左边第三户邻居的铺架上，……”还没等说完，埋伏的人一拥而上，把他捆了个结实。叫夜僧自知失语，隐瞒不了，便从实招供。原来那天晚上叫夜僧偶然路过女子家门前，见大门开着，想乘机进去偷点东西。进屋后发现有年轻貌美的女子坐在床边哭泣，顿生歹念。他强奸不成，不由得恼羞成怒，就把女子杀了。然后割下脑袋，挂在左边第三家邻居的铺架上。

官府立即把挂人头的那家主人传来，问发没发现一颗女人头，他说：“发现了，由于害怕招来灾祸，又移挂到左邻门口的树上。”又传讯来左邻主人，他说：“人头确实有，因怕惹麻烦，就埋在园子里了。”官府马上派人去挖，先挖出了一副男性头骨，再往下挖，才挖出了被杀女子的头骨。官府质问男性头骨是怎么回事。左邻主人招供说，他在十年前杀了仇人，把头埋在园子里。一起拖了十年未能侦破的凶杀案，就这么顺便破了案。于是，官府把叫夜僧和左邻主人同时处决了。

# 假秀才现形

临海县令设宴招待新秀才，有个年轻女子迷上了一个风度潇洒的，不禁流露出了爱慕之情。一个摆地摊的老太太看出了女子的心思，说：“那秀才是我家邻居，不仅人长得美，心眼也好。姑娘若有心，我让他晚上来找你。”女子含羞地点了点头。这老太太还真守信用，回去就对秀才说了，劝他晚上去和女子幽会。谁知秀才是个正人君子，坚决不去。老太太有个儿子是市井无赖，终日寻花问柳，不务正业。他了解到这一情况后，不由得喜上心来，特意修饰了一番，晚上假扮秀才潜入女子房中。黑暗中女子真假莫辨，把他当成了意中人。

过了些日子，女子家来了客，她搬到母亲房中暂住，房间里住了一对来客夫妻。夜里，女子房中闪进一个人，把来客夫妻双双杀死后溜走了。

案子报到官府，县令开始以为女子家图财害命，当发现客人的物品一件不少，不由得犯了合计。他想了一阵，突然问：“这间房子以前谁住？”女子的父亲说：“是小女的房间。”县令拍案而起，喝道：“把她给我抓起来！”把女子抓到官府，县令先以酷刑威胁她，而后问：“小女子，快快从实招来，你的奸夫是谁？”女子说：“是某秀才。”紧接着把秀才抓到官府，他申辩说：“邻居老太太的确让我去幽会过，被我拒绝了。我敢指天起誓，从未进过女子家门。”县令转过身问女子：“秀才身上有什么标记吗？”女子说：“他胳膊上有一块黑痣。”当场让秀才露出胳膊，根本没有黑痣。县令想了想，又问：“那老太太有几个儿子？”秀才说：“有，与我年龄相仿。”县令马上派人抓来老太太的儿子，发现他胳膊上有块黑痣。县令长出一口气，说：“杀人凶手总算找到了。”随即动用大刑，老太太的儿子供认了杀人事实。原来那天夜里他溜进女子房间，见床上有两个人，以为女子又和别的男人睡上了，不禁火冒三丈，动手杀人。案子审理完毕，老太太的儿子被处决，秀才则无罪释放。

# 包公推理破案

广东揭阳县内发生了一起人命案，县令朱一明询问前来报案的两男一女。其中一个长得眉清目秀的青年男子首先开口说：“小人姓周名义，三天前，我与赵信约定乘船工张潮的船到外地买布，不料过了约定时间。赵信没来，我就让张潮去找。”没等周义说完，另一个男子插话说：“小人就是张潮，周义让我去找赵信，我在赵家门外连叫了三声赵家娘子，赵氏才不紧不慢地打开门，说赵信天没亮就走了。”那女的就是赵信的妻子，在一旁抽泣不止。朱一明想，这定是少年风流的周义，伙同年轻美貌的赵妻谋害了赵信。于是，他下令对二人施以重刑。二人忍受不过，屈打成招。

刚巧，包公巡察来到揭阳县，读罢案卷，深感蹊跷，决定重新审理。审理时，把张潮也找来了。包公先让周义和赵妻说了发案的情况，接着又让张潮讲。张潮又把那天的话复述了一遍。包公听后，惊堂木一拍，厉声喝道：“大胆刁民，图财害命，快快从实招来！”张潮无奈，只好从实交待了杀人夺财的经过。原来那天早上，赵信带着五百两银子在周义之前来到船上。张潮顿生歹念，用石头砸死了赵信，又在尸体上绑上石块，沉入水底。周义来到后，他谎称没见到赵信，还亲自上门去找。那么包公是如何判断出张潮是杀人凶手的呢？他根据张潮去找赵信时，在赵家门外不喊赵信，却直接喊赵家娘子。由此推断出张潮一定事先知道赵信不在家，不然怎么会直接喊赵家娘子呢？

# 烧猪断案

句章县令张举一日出巡，突然有人拦住马头，跪在地上说：“小人吕良，向大人报告，我哥哥吕策被人放火烧死了。”张举急忙率领衙吏赶到现场，围着焦尸踱了两圈，说：“把死者的嘴掰开。”衙吏使劲掰开焦尸的嘴，张举弯身细看了一会儿，见死者嘴里很干净，便起身问吕良说：“你哥哥死的时候有谁在场？”吕良说：“我嫂子始终在家。失火后，她来不及救出哥哥，只身跑了出来。”张举听了，考虑了一会儿，对吕良的嫂子说：“你这奸妇，竟敢杀人，还不从实招来！”吕良的嫂子连声喊冤，张举冷笑着说：“我要你当场认罪。”说完，命人捉来两头猪，打死一头，然后一同扔进火里。待烧死后，张举分别让人把猪嘴撬开给众人看。只见先打死的那只，嘴里没有草灰；活着烧死的那只，满嘴草灰。张举又问：“这回你该招了吧？”吕良的嫂子绝望地说：“我招认，是我害死了丈夫。”原来，吕良的嫂子叫刘美翠，她见丈夫久病不愈，又见吕良年轻貌美，便想害死丈夫，然后嫁给吕良。她背着吕良烧死丈夫后，又放火制造了假现场。

# 头上痕迹

齐也强与一个素不相识的小和尚路遇，问：“小师傅，你这是到哪里去呀？”小和尚说：“去江宁化缘。”齐也强想，种田实在太苦了，不如出家当和尚。干脆杀了他，冒充和尚去化缘，那该多悠闲自在啊。于是，他趁小和尚不注意，抽出柴刀，把小和尚砍死了。然后拿了小和尚的度牒，剃光了头，冒充起和尚来。齐也强一路化缘，不知不觉来到了江宁，向县令张咏递上了度牒。张咏看了度牒，刚要签发，目光在齐也强的脑袋上停住了，便问：“你出家几年了？”齐也强回答：“整整十年。”张咏听了大喝一声：“好你个杀人犯，竟自投罗网来了。来人！把他抓起来。”齐也强被捆了个结实，押进了死牢。原来张咏早已接到报案，说有一个小和尚被人杀死在路边。张咏检查度牒时，并没发现可疑之处，却发现齐也强头上有扎毛巾的痕迹。和尚是从来不扎毛巾的，张咏据此认出了杀人犯。

# 黄盏斋杯酒破疑案

清道光年间，黄益斋任江西宁州牧。当地有个富绅举止粗鲁，言辞鄙陋，家里虽然有许多名画古玩，可是摆得乱糟糟，根本不像文人雅士的摆设。黄益斋犯了合计，估摸者十有八九是个强盗，决心弄个水落石出，就换上便服到富绅家附近了解情况，见有个年轻貌美的妇人抱着孩子站在大门口，面色憔悴，忧愁不堪。他故意用乡人的土话问：“嫂子好像有什么心事？”妇人听了，吓得脸色灰白。黄益斋又说：“我会看面相，觉得你的来历很奇怪。你愿意说给我听听吗？”妇人朝屋里看了看，泪流满面，几乎痛哭失声。黄益斋说：“千万不要多说话，坏了事。我这就走，你多保重。”

次日，黄益斋大宴宾客，富绅也应邀前往。他把富绅单独叫到一个房间，问“某幅对联写得很好，下面落款的某君，与你是什么交情”，又问“你的书架上某书是旧版，得之不易，里面的藏书小印，是你什么人”等一些问题。富绅支支吾吾，回答不上来。黄益斋喝令把他抓起来，又派人用小轿把妇人接到官府。一经询问，她就讲出了实情：“我的父兄都是广东籍官员，请假探亲途中经过鄱阳湖遇上强盗，家人全被杀，霸占我为妻，已经整整十八年了。这富绅就是当年杀我全家的强盗。”妇人为了给父兄报仇，多年来忍辱偷生。如今有了出头之日，便当堂摔死了怀中的幼子。黄益斋杯酒破多年谜案，一时传为佳话。

# 老太太引出杀人犯

唐太宗贞观年间，衡州板桥店老板张迪的妻子回娘家去了，店里住进了卫三、杨真等三位客商。三人因有急事，次日凌晨就上路了。可他们做梦也没想到，那天夜里有人用卫三的刀杀害了张迪，而后把刀插回了刀鞘。天亮以后，店里的人发现老板被杀，就去追赶卫三等三人。追上后，发现卫三的刀上沾有血迹，便把他们扭送到了官府。酷刑之下，三人忍受不过，违心地认了罪。

唐太宗了解到案子的审理经过，觉得有可疑之处，命御史蒋恒重新审理。他接案后，把店里所有人传讯到官府。又借口人数不足，留下一个年逾八旬的老太太，把其他人放了回去。傍着晚时分，老太太放了回去。接便派狱典你跟一踪，告诫说：“老太太回去后肯定有人向她探听情况，你要记住这个人的相貌。”老太太回去后，果然有人向她问这问那。连三天，老太太每日被传讯到官府，到天黑才放回去，那个人每天都探听案子的情况。蒋恒下令抓起那个人把问，他交待了与张迪的妻子通奸，并合谋杀害张迪的事实。案子查清后，立即上奏唐太宗。唐太宗很高兴，赏赐给蒋恒二百匹绸缎，还提升他当了侍御史。

# 诈审断牛

唐朝新乡人王恭，父母相继去世，给他留下了两间房屋和六头母牛的家产。王恭当兵时，把六头母牛交由舅舅李珽看管。一晃五年过去了，王恭退役回到家乡，听邻居说那六头母牛又生了三十头小牛。当他到舅舅家要牛时，舅舅却说：“你的六头母牛已经死了两头，只剩四头了。”王恭说：“可我听说还有三十头小牛啊。”李珽说：“这都是别人胡说，根本没有的事。”王恭越想越气，就告到了县里。县令裴子云听完诉讼，把王恭留在县衙，派人传讯李珽。李珽刚到，裴子云厉声喝道：“有人告你偷了三十头牛，快快招供，免得皮肉受苦。”李珽说：“大人明察，那三十头牛是外甥王恭的母牛生的，不是偷的。”裴子云见说出实情，就说：“既然是外甥的，那就还给他吧，免得有人说三道四。”李珽无奈，只好把牛如数还给了外甥。王恭送给舅舅五头牛，做为五年辛苦的酬谢。

# 小吏查凶手

向敏中是宋代人。在西京做官时，有个和尚因天色已晚，到一户有钱人家借宿。那家主人不同意，和尚就寄宿在他家的车棚中。半夜时分，和尚偶然抬头，发现有个强盗挟着个女子，带着一个大包袱，从墙上逃了出去。和尚想，我要借宿主人不同意，如今他家丢了女人和物品，我免不了要担嫌疑，不如及早离开，免生是非。由于路径不熟，他一脚踏空，掉进了一口枯井里。谁知那逃出的妇人已经被强盗杀害，早就扔到井里了。

第二天清早，主人发现了井中的和尚和被杀的女人，急忙报告了官府。和尚被捉拿到官，酷刑之下，不得已屈招。说自己引诱那家女人出逃，因害怕有人追上，就把女人杀死扔到井里，自己则因天黑失足落入井中，赃物放在井旁，不知被什么人拿走了。依据和尚的“供词”，县里很快结了案，上报府里。府里也认为案子审理得清楚得当，唯独向敏中因赃物下落不明而产生了怀疑，便单独提审和尚，了解到了真情。随后派出一名小吏，外出秘密访查真正的杀人凶手。

一天，小吏在村店吃饭时，开店的老太太见他是官府的人，就问：“和尚的案子处理得怎么样了？”小吏骗她说：“昨天被拷打死了。”老太太又问：“既然这样，如果抓到真正的凶手又该如何处理呢？”小吏说：“案子一旦了结，不管判得对与不对，再也不能变更了。即使发现了真正的凶手，也不再过问。”老太太说：“这样看来我说话也无妨了。那个女人实际上是我们村的某人杀的。”说着，还指了指那家的房子。小吏马上来到某人家，乘其不备，把他捉获归案。经过审问，那人招认了偷盗杀人的罪行，还在他家搜出了赃物。至此，和尚才得以出狱。

# 摸钟

宋朝人陈襄任蒲城县令期间，有家富户丢失了许多财物，告发到官。捕吏抓获了几个小偷，不料他们互相包庇，无法弄清谁是真正的盗贼。陈襄苦苦思索，终于想出了一个好办法，对小偷们说：“城南庙里的大钟可以辨认盗贼。犯了案的人摸，会发出声响；没犯案的人摸，没有声响。”他先派衙役把小偷押到庙附近，然后亲自率领僚属到庙里祈祷了一番，暗中让人把大钟涂上墨，用黑布把四周遮住，让小偷轮流去摸。摸完后，发现有个小偷手上没有墨。经过审讯，财物果然是他偷的。陈襄巧妙地利用盗贼怕出声响不敢摸钟的心理破了案。

# 元绎识奸

宋朝人元绎当过江宁推官，后升任上元县令。一天早上，有个披头散发的女人拽着一个男人来到大堂上，说他杀害了自己的丈夫。原来昨晚这个男人同女子的丈夫饮酒，酒醉后打了起来，女子的丈夫回家扑到床上就睡了。半夜时分，他被人砍断腿，因流血过多而死，于是就发生了前边的节。元绛听了申诉，把那个男人收监，对女人说：“你回去处理丈夫的丧事吧，那男人已经服罪，不久就要处决。”

女人走后，元绛立即派了个慎重可靠的小吏跟踪。只见那女人路上遇到一个和尚，两人互递眼色，窃笑不止，还偷偷说了一会话。小吏连忙回去报告，元绛下令把女子和和尚抓起来。经审问，二人供认早已勾搭成奸，合谋杀人，并蓄意栽赃陷害他人。事后有人问元绛是怎么对那女人产生怀疑的，他说：“有两点令人生疑，一是她哭丈夫，可并不悲哀；二是丈夫半夜被砍断腿，肯定要溅出不少血，可她身上却没有血迹。”

# 王安石查匿名信

王安石任开封知府时，接连接到匿名信，告发一些人想谋反，牵涉百余人，皇帝诏令他尽快查处。王安石仔细地看了所有的匿名信，发现文法、字体等均出自一人之手。尤其是最后一封信，在谋反的名单中又加进了三个人，其中有个姓薛的。他脸上露出一丝轻蔑的笑，说：“明白怎么回事了。”他派人找来那个姓薛的，问：“你近来与谁闹过纠纷吗？”姓薛的说：“按说没同谁闹过矛盾，不过有个士子曾拿着他写的文章让我推荐当官，遭到了拒绝，悻悻而去，看样子挺恼火。”王安石派捕吏把那个人拘捕到官，经审问，他供认了写匿名信诬陷他人的犯罪事实，被处死了。

# 黑风败北

宋朝时，临城县令商父办案很有名，处理了不少棘手的案件。一次，他派人抓住了大盗黑风。黑风自知做恶多端，难免一死，想在死前洽一洽县令商父。他发现监狱看守秦鬼心术不正，就说：“我想在死前，送给你一笔财产，不知你想不想要？”秦鬼忙问：“你送我什么财产？”黑风说：“你要得到财产容易，但要给我列出城里几户首富的名单。”秦鬼问：“你要名单干什么？”黑风说：“你把名单给我，我就说他们是窝主。等县令把他们抓到监狱，这些肥得流油的家伙到了你的手心里，哪个敢不乖乖地给你送礼？”秦鬼乐坏了，当即提供了城中八个最有名的富户的名字。

几天后，商父审理黑风，当问到窝主时，他就把那八个“窝主”供了出来。案子审得过于顺利，反倒使商父犯了疑。他派人把那八个“窝主”抓来，让他们整齐地跪在地上，又把黑风提上堂，问：“窝主都抓来了，你看一下抓没抓错？”黑风随便看了一眼，就回答说：“都对。”商父指着其中一人问：“那我问问你，他叫什么名字？”这一下黑风可傻了眼，干瞪眼说不出来。又问了几个，他全答不上来。商父说：“好了，不要再演戏了。是谁给你提供的名单？”黑风只好如实招认了。于是，商父放回了八个富户，把秦鬼重打四十大板，逐出县衙，黑风则斩首示众。

# 鞭打石头

有个人坐在路旁的石头上休息，不知不觉地睡着了。醒来后，发现钱袋子里的一干线被人偷走了。县令杨武接到报案，派人把石头运到大堂上。声言石头偷钱，要审讯它。并说审讯时，官民可以随便观看。人们听说杨县令审石头，都觉得好奇，纷纷前来观看。杨武暗中派出捕吏，观察在县衙外面窥视大堂的人，要求一经发现，立即逮捕。捕吏果然抓到了一个鬼鬼祟祟、欲进又止的人。经审问，他承认了钱是自己偷的。杨武鞭打石头，虽近乎天方夜谭，但他料定偷钱的人既觉得奇怪，又心怀恐惧，肯定会来，来了又不敢贸然进去。他正是利用这一心理，发现并抓获了偷钱的人。

# 铁佛说话之谜

魏州冠氏县有座华林僧院，院内有尊一丈多高的铁佛。寺内和尚突然放出风，说铁佛显灵，能够说话。和尚们还在寺外大肆张扬，铁佛的名气越来越大，远近的官吏豪富、乡绅学子乃至平民百姓纷至沓来，捐款敬佛。皇帝听说后，命尚谦查清此事。张骆毛遂自荐，愿协助尚谦调查，皇帝也同意了。他们来到冠氏县，与地方官密谋了一番，命华林僧院所有和尚都到某地做佛事。趁此机会，张骆秘密来到僧院，进入僧房，发现有条暗道直通铁佛空心处。他让尚谦站在铁佛前，自己沿暗道进入铁佛，厉声斥责和尚们捣鬼的把戏。尚谦弄清了铁佛说话的真情，把和尚全都拘捕收监，把几个带头制造事端的和尚押送京师，经皇帝核准，依法处决了。

# 寡妇告儿子

李杰任河南尹时，有个寡妇告发儿子不孝，请求治罪。李杰觉得事出有因，就故意问寡妇说：“儿女不孝，罪在不赦。你就这么一个儿子，难道想看着他死吗？”寡妇说：“他是自作自受，我不后悔。”李杰说：“既然这样，你到市场上买口棺材，等着收尸就行了。”寡妇上市场时，李杰派差役暗中监视。只见离开衙门不远，从小胡同里闪出一个道士，和寡妇嘀咕了几句。李杰得报，下令把道士抓来。经过审讯，道士供认与寡妇已经勾搭了三年多，碍于她的儿子，两人不能随心所欲，想借官府之手除掉。情况查明后，李杰处死了道士，就用寡妇刚买来的那口棺材装殓了他。

# 钱藻审京军

钱藻领兵驻守密云时，有两个京军在通州抢掠百姓财产，被地方官吏当场抓获，可他们大吵大闹，拒不认罪。地方官无奈，就把他俩交由钱藻处理。他俩自恃是京军，连钱藻也不放在眼里。钱藻毫不生气，示意把甲带下去，单独审讯乙。他声色俱厉地审了一会儿，又提笔写了一阵子，好像是记录口供。然后喝令乙退下，把甲带上来。钱藻举起刚刚写的那张纸，说：“刚才乙把事情的经过都交待清楚了，都是你一手策划的，与他没什么关系。因此，乙应当无罪释放，你却应当处死。”甲根本想不到钱藻是在欺骗他，愤愤地说：“这事本来都是乙出谋干的，怎么全推到了我头上呢？”于是，他把抢掠的经过如实说了一遍。等他说完后，又传乙上堂对证，这样就把案情弄清楚了，两个京军被依法治了罪。

# 诱贼自首

京师有家外族客商开办的商店，被一伙盗贼洗劫一空，郡县的官吏查访了很长时间，没有发现任何线索。经过调查，柳庆了解到客商家附近住有许多不三不四的人，估计是他们当中的一些人干的。他就秘密派人以盗贼的口气写了几封匿名信，贴在官府大门上，大意说，我等偷盗之后，心里既怕又悔，想自首又怕官府不予免罪，希望官府尽快表态
