# 离 间 术

如果敌方上下亲密无间，情同手足，就要设法在其内部制造矛盾加以离间，使之离心离德，互相猜忌，在严重的内耗中分崩离析。运用离间术，最有效的手段莫过于使用间谍。

# 张仪中伤樗里子

樗里子是秦王的同父异母弟，被封为将军，而且一度担任相国。他不仅后台硬，而且谋略超人。张仪想中伤他，就派他作出使楚国的特使。由于张仪施展手段，秦国占领了楚国两座城，两国关系便紧张了起来，樗里子此行的目的就是缓和矛盾而去的。

樗里子到楚国不久，楚王的特使就回访了秦国，说：“我们大王很敬重樗里子，想让他在中国当相国，请务必答应。”原来这是张仪幕后策划的，他在派樗里子到楚国的同时，秘密派人劝楚王向秦王要求留下樗里子。楚王的使者来到后，张仪对秦王说：“听说樗里子出使楚国后，把国家大事抛在脑后，却请求楚王答应他留下。现在楚王的特使来了，说明确有其事。我真担心秦国已经被出卖给楚国了。”秦王听了大怒。消息很快传到樗里子耳朵里，他害怕回秦国遭暗算，就逃到别的国家去了。历来君主们最担心的，是有人取代自
