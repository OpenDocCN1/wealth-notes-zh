# 小吏查凶手

向敏中是宋代人。在西京做官时，有个和尚因天色已晚，到一户有钱人家借宿。那家主人不同意，和尚就寄宿在他家的车棚中。半夜时分，和尚偶然抬头，发现有个强盗挟着个女子，带着一个大包袱，从墙上逃了出去。和尚想，我要借宿主人不同意，如今他家丢了女人和物品，我免不了要担嫌疑，不如及早离开，免生是非。由于路径不熟，他一脚踏空，掉进了一口枯井里。谁知那逃出的妇人已经被强盗杀害，早就扔到井里了。

第二天清早，主人发现了井中的和尚和被杀的女人，急忙报告了官府。和尚被捉拿到官，酷刑之下，不得已屈招。说自己引诱那家女人出逃，因害怕有人追上，就把女人杀死扔到井里，自己则因天黑失足落入井中，赃物放在井旁，不知被什么人拿走了。依据和尚的“供词”，县里很快结了案，上报府里。府里也认为案子审理得清楚得当，唯独向敏中因赃物下落不明而产生了怀疑，便单独提审和尚，了解到了真情。随后派出一名小吏，外出秘密访查真正的杀人凶手。
