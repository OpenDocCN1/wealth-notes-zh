# 商鞅取信

秦孝公决定推行商鞅的新法令，授予他推行新法令的大权，叫他抓紧把新法令制定出来。新法令制定出来后，商鞅怕老百姓不相信，推行不开，就想了个办法。他叫人在都城的南门竖了一根三丈来长的木头，旁边贴了张告示，说：“谁能把这根木头扛到北门去，赏赐十金。”不大一会儿，木头周围就围满了人。大伙儿心里直犯嘀咕，这根木头并不重，扛几里地也不是什么难事，怎么给这么多赏赐呢？或许是什么圈套吧，结果谁也不去扛。商鞅见没有人扛，又把奖赏提高到五十金。这么一来，人们更疑惑了，都猜不透商鞅的葫芦里到底卖的是什么药。有个粗汉子拨开人群，笑嘻嘻地说：“我来试试。”说着，扛起木头就走。许多看热闹的人出于好奇，一直跟到北门。只见商鞅已经在那里等着，对大汉说：“好，你能够执行法令，应得奖赏！”随后就把早已准备好的五十金赏给了他。这件事很快传开了，大家都说：“商鞅说话算数，说到做到，对他的命令可要执行啊！”
