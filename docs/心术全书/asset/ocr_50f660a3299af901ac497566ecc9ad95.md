# 怒斩皇甫文

高峻起兵叛乱，据守高平，汉军久久不能攻下。于是，光武帝刘秀派寇恂带着诏书前往招安。高峻得到消息，派军师皇甫文为使前来谈判。谈判过程中，皇甫文语气强硬，态度傲慢。寇恂大怒，喝令把他捆起来，斩首示众。众将怕惹出祸端，都苦苦相劝。寇恂一概不听，当即处死了皇甫文，然后把随同皇甫文一起来的副使放了回去，并让他传话给高峻：“皇甫文蛮横无礼，我已经把他杀了。你愿意投降，我保你平安无事；如不想投降，你可以固守。”高惊恐万分，当天就打开城门，投降了朝廷。众将纷纷向寇恂表示祝贺，可还是弄不明白为什么杀了皇甫文，高峻反倒会投降。寇恂说：“道理很简单，皇甫文是高峻的智囊，高峻对他言听计众。我见他态度蛮横，料想他不会投降。如果让他活着回去，继续出谋划策，只能造成更大的麻烦。把他杀了，高峻不仅没了出谋划策的人，而且会受到震慑，自然会投降。
