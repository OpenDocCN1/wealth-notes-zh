# 解纷术

人际间经常产生纠纷, 处理得当, 可以息事宁人; 处理不当, 则有可能刀兵相向。解纷术是以适当的手段、从容的对答来排解纠纷的一种技巧。主要有四种方式: 一是容许当事人宣泄不满的情绪, 这往往是化解纠纷的有效方法; 二是假如当事人明显错了, 你能够用一种保全他的面子的“圆滑”策略来对待, 纠纷将被排解; 三是针对当事人的错误, 进行针锋相对的批评, 可以促使其猛醒, 尽早认识并改正错误; 四是有些问题需要采取折衷的解决办法, 有一些妥协精神。综上, 排解纠纷没有固定的模式, 重要的是弄清产生纠纷的原因, 才能妥善地予以解决。那种以不变应万变的方式是万万不行的。
