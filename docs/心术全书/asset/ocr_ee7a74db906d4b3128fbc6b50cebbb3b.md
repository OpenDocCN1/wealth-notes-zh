# 尤翁忍辱

明朝时，苏州有个姓尤的老翁，经营了一家当铺，生意一直很兴隆。一年年底，尤翁听见前厅里有人吵架，就赶忙跑了过去，见是一位邻居和当铺的伙计在吵。尤翁问是怎么回事，伙计说：“这人前些日子拿了几件衣服来典当，今天却空手来讨还，还张口就骂人。”伙计这边说着，那人还在不停地骂，态度十分蛮横。尤翁想了想，满面笑容地走到那人跟前，好言好语地说：“嗨，咱们都是邻居，我有过错还希望你多加包涵。马上要过年了，又没什么大不了的事，你就别生气了。”说着回头让伙计把那人典当的东西拿来，打开一看，共有四五件衣服。尤翁拿起一件棉衣说：“这是过冬必不可少的衣服，你拿回去。”又拿起一件新一些的长袍说：“拜年时当然要穿件新的，这件你也拿回去。至于其他衣服，你眼下用不着，先放在这里怎么样？”那人拿了那件衣服，面带羞愧，一声不响地走了。当晚，那人突然死在另一家里，害得那家为此打了一年官司，几乎倾家荡产。后来才搞清，那人负债太多，无力偿还。他知道尤翁家很有钱，索性提前服了毒药，准备用死来敲一笔大钱。由于尤翁处理得法，才使他无话可说，死在了另一家。当有人问尤翁：“您难道预知邻人的诡计，才如此容忍吗？”尤翁说：“那怎么可能呢？我只是觉得一个人如果过分蛮横无礼，那他一定有所依仗。遇到这种情况，如果不加忍耐，就会酿成大祸。”
