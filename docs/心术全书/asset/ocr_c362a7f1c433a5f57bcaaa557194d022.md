# 智斩冯弧

隋朝时，泉县有个叫冯弧的，横行乡里，无故打死了人。知县魏复接到报案，把冯弧判了死刑，呈报吏部批准。不料，吏部侍郎是冯弧的姐夫，不予批准，让魏复从轻处理，还答应保举他升官。魏复很生气，几天后依然呈报死刑，结果又被退回。魏复心生一计，第三次上报时，故意将“冯弧”写成“冯瓜”，吏部侍郎没细看案卷的内容，就大笔一挥同意处斩。批文回来后，魏复立即把“冯瓜”添加几笔，又变成了“冯弧”，并马上把他处决了。

# 郑氏惩治色狼

唐代滕王荒淫无耻，属下官员的妻妾，凡是长得漂亮一些的，没有不被他污辱的。每次污辱官员的妻子，他总是谎称王妃传唤，骗入宫内。只要一入宫，定是难逃魔掌。任典签官职的崔简刚刚结婚，妻子郑氏年轻貌美，是出名的美人儿。

滕王听说后，不由得心摇目荡，不能抑制，又故伎重演，声言王妃召郑氏进宫。这可难坏了崔简，不让妻子去吧，又惧怕滕王的淫威；让妻子去吧，又怕妻子被污辱。他
