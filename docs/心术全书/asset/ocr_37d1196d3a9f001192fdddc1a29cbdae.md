# 头 上 痕 迹

齐也强与一个素不相识的小和尚路遇，问：“小师傅，你这是到哪里去呀？”小和尚说：“去江宁化缘。”齐也强想，种田实在太苦了，不如出家当和尚。干脆杀了他，冒充和尚去化缘，那该多悠闲自在啊。于是，他趁小和尚不注意，抽出柴刀，把小和尚砍死了。然后拿了小和尚的度牒，剃光了头，冒充起和尚来。齐也强一路化缘，不知不觉来到了江宁，向县令张咏递上了度牒。张咏看了度牒，刚要签发，目光在齐也强的脑袋上停住了，便问：“你出家几年了？”齐也强回答：“整整十年。”张咏听了大喝一声：“好你个杀人犯，竟自投罗网来了。来人！把他抓起来。”齐也强被捆了个结实，押进了死牢。原来张咏早已接到报案，说有一个小和尚被人杀死在路边。张咏检查度牒时，并没发现可疑之处，却发现齐也强头上有扎毛巾的痕迹。和尚是从来不扎毛巾的，张咏据此认出了杀人犯。
