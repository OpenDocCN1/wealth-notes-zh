# 巧取民心

秦王朝苛政日甚一日，百姓生活在水深火热之中。各地豪杰蜂起反秦，共推楚怀王为义帝。可是过了不久，势力最大的项羽就杀掉了义帝。汉王刘邦兵至洛阳新城时，三老董公进见，对刘邦说：“出兵如果没什么理由，那就一事无成。所以说，要攻打对方，必须先找出攻打他的理由。如果天下人都知道对方是贼寇，就可以把他制服了。本来天下各路诸侯共推楚怀王为义帝，项羽却冒天下之大不韪，弑杀了他，这就激起了天下的仇恨。大王要想同项羽争夺天下，首先应取得民心。在出兵之前，应当让三军全穿素服，并告谕天下各路诸侯，征讨弑杀义帝的盗贼。这样，您就会赢得天下人的支持。”刘邦采纳了他的建议，为义帝举行了隆重的发丧仪式，士兵全都身着缟素，并传谕各路诸侯说：“寡人将要悉发关中的军队，收回被贼寇占据的地方。愿同各路诸侯一起讨伐逆贼项羽，为义帝报丧。”他的号召，很快得到了各路诸侯的响应。
