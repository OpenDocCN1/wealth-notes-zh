# 晏婴弃车

齐国人有个奇特的癖好，喜欢驾着车互相撞击车轴取乐，结果每天都要撞坏不少车轴。齐君曾下令禁止，结果收效不大。晏婴想改变这一习俗，他特意准备了新车良马，去参加撞击车轴活动。活动结束后，晏婴跳下车，说：“车轴被撞击过的车，乘坐是很不吉利的，会给人带来灾难。乘坐这样的车去祭祀，连天神和祖先都要发怒。”说完，把车抛弃在路旁就走了。从此，撞击车轴的活动绝迹了。

# 丝绸涨价

东晋丞相王导善于处理军国大事。刚刚南渡时，府库空虚，仅有几千匹丝绸。为了筹措朝廷办公费用，王导和其他大臣一道，每人做了件丝绸单衣穿在身上。一时间丝绸单衣成为最流行的服装，人们争相抢购，导致丝绸大涨价，每匹丝绸竟能卖一两银子。王导乘机把府库中的丝绸拿出卖掉，为朝廷筹集了一笔经费。
