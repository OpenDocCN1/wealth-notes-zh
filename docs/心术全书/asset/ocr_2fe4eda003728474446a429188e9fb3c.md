# 高子业巧断杀人案

高子业初到代州任职时，有个叫江棒秀才想霸占邻人的房屋，因而发生了纠纷。他偷偷杀死了江孜等二人，藏起二人的尸首，想找机会诬陷邻人。邻人很机警，发现了江棒的动机后，自知惹不起他，便忍气吞声，把房子全让给了江棒。江棒得到房子自然高兴异常，就把江孜等埋在自己的卧室里。

几年后，江棒的兄长千户江榇因口角误杀了妻子。江棒就挑动江榇妻子的娘家人到官府告发江榇，他自己也借机诬陷兄长杀死了江孜等。江榇被抓到官府，因拷打致死。由于江榇没有后人，他的官爵由弟弟继承。继承的人只能有一个，于是江棒又同弟弟江槃发生了争执，官司打到了监司台。监司台决定让高子业重新审理江孜等人被杀案。

在大堂上，高子业问江棒说：“你知道江孜等人的尸体被埋在什么地方了吗？”江棒故作从容地说：“江榇把他们杀害后就埋到自己房间里去了，至于具体埋在哪儿，我也说不上来。”他聪明反被聪明误，无意中透露出死者埋在房间里。机警的高子业发现了这一重要线索，又突然问：“江孜等因什么事被杀？”江棒毫无思想准备，脱口说：“是因同我争房子。”高子业接着问：“江榇与你住在一起吗？”江棒说：“不住在一起。”高子业厉声喝道：“江榇为了替你争房子而谋杀族人，又埋在自己房间里，哪有这样的道理？”随即问捕吏说：“到江棒的房间里搜查过没有？”捕吏说：“还没去。”高子业立即派捕吏去搜查，结果挖出了两个被害人的遗骨。江棒无奈，只好低头认罪。
