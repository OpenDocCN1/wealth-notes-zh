# **曹 睿 感 父**

曹丕跟随父亲曹操平定河北时，纳袁熙的妻子甄氏为妻。他即位之后，便立甄氏为后。甄氏为曹丕生了个儿子，取名为曹睿。不久，郭贵妃得宠，曹丕便杀了甄氏，立郭贵妃为后。郭贵妃没有儿子，年幼的曹睿便给她做了儿子。曹睿聪明伶俐，小心侍奉郭后。郭后对曹睿不存芥蒂，母子二人关系倒也和睦。然而曹丕却因为杀了甄氏的缘故，恐曹睿忌恨，始终没有立他为嗣。一次，曹睿跟随曹丕外出打猎，遇见了母子两只鹿，曹丕射死了母鹿，命曹睿射死小鹿。曹睿哭着说：“陛下已经射死了母鹿，孩儿不忍心再杀死它的孩子。”曹丕听了，动情地说：“我儿子真是一个仁人，天下有主了。”遂决定立曹睿为嗣。曹睿后来当了皇帝，是为魏明帝。

# **杨 广 夺 宠**

隋文帝晚年，太子杨勇失宠，他的兄弟晋王杨广听说后，打算谋取太子职位。首先，他针对杨勇多内宠引起皇宫内外议论这一点，极力显示自己对女色不感兴趣。他虽然也合法地拥有众多姬妾，但只和正式配偶萧妃居处。其次，凡有人前去拜访他，无论贵贱，他必定亲自和萧妃迎送，招待周到。所以，一时间连宫中执役的下人也无不称赞他仁孝。他还专门收拾了一个房间，陈设朴素，服役的宫女又老又丑，并把故意弄坏的乐器放在角落里，不让人掸去灰尘，表示这类东西他是从来不碰的。文帝和皇后来看他，他就在这间屋子里和他们相见。由此他的宠爱与日俱增，终于在杨勇废黜后，被正式立为太子。他后来当上了皇帝，是为隋炀帝。
