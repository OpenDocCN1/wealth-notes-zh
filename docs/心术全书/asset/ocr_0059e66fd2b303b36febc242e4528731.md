# 避嫌术

人生处世，难免会遇到种种猜忌。有的来自亲友，有的来自同事，有的甚至来自素不相识的人，其中尤以上司的最难对付。与其等到嫌疑临身再去为自己辩解，不如防患于未然，主动避免嫌疑。俗话说，脚正不怕鞋歪。在一般的交际中，只要心胸大度，光明磊落，就不会招致嫌疑。朋友相处，不宜交往过密。过密的交往最易产生嫌疑，导致反目成仇。世界上没有哪个上司愿意看到下属的威望或才能胜过自己。你如果自信在威望或才能方面不亚于你的上司，不妨给自己抹点“黑”，出点“丑”，就可消除上司的嫌疑了。
