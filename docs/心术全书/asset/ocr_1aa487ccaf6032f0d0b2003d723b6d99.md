# 孟子辩服孔距心

孟子到了齐国边境的平陆，对当地的邑宰孔距心说：“如果你的战士一天三次失职，你开除他吗？”孔距心爽快地说：“哼！用不了三天，我就除他的名了。”孟子说：“可你自己失职的地方就很多，比方说遇到灾荒年份，你的百姓流离失所，饿死的很多。”孔距心迟疑了一下，说：“这个嘛，我是心有余而力不足，无法免除天灾。”孟子说：“譬如说现在有一个替别人放牧牛羊，那么为牛羊找到肥美的草场和充足的水源是他的天职。如果连这一点都做不到，那是把牛羊退迁给主人呢？还是看着牛羊一个个死掉呢？”孔距心憋红了脸，过了好大一会儿才说：“我认识到自己的过失了。”

# 鲁仲连义不帝秦

秦国军队围攻赵国都城邯郸。魏安釐王派遣辛垣衍从小路潜入邯郸，想让赵国尊秦国为帝。齐国谋士鲁仲连恰巧在赵国游历，平原君介绍他去见辛垣衍。

鲁仲连见到辛垣衍后却不言语。辛垣衍说：“我观察这个城里的人，都是对平原君有所求的。看您的样子不像这样，为什么不早日离开呢？”鲁仲连说：“秦国是一个废弃礼义、崇尚战功的国家。用欺诈的手段役使士兵，用对待俘虏的办法役使他的百姓。如果让秦王称帝，顺利地统一了天下，那么我只好跳入东海自杀了，我不忍心做他的百姓！
