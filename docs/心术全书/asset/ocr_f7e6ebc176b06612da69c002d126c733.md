# 程明道治恶民

沿河一带有几十个不务正业的恶民，专以抢掠船民的钱财为业。每年岁末，还要烧毁十余只不合他们心意的渔船，以此恐吓船民。程明道上任不久，就抓获了一个恶民。经过审讯，他供出了几十个同伙。程明道把这些人传讯到官府，赦免了他们过去的罪恶，让他们分开居住，以行船为业，并负责举报坑害船民的人。自此，再没出现过抢掠船民钱财和烧船的事。程明道命恶民当船民，亲自尝一尝行船的艰辛，促使其痛改前非。
