# 汉武帝防干政

汉武帝原先所立的太子刘据，因巫蛊案身亡，剩下年长一点的儿子中，如燕王刘旦、广陵王刘胥，都因庸庸碌碌，多有过失，不得欢心。惟有钩弋夫人所生的幼子刘弗陵，深得武帝喜爱。为了防止钩弋夫人日后因儿子年幼干预朝政，在确立刘弗陵为太子之前，汉武帝命钩弋夫人自杀。

钩弋夫人摘下簪子和耳环，趴在地上一个劲儿磕头。汉武帝吩咐把她带出去，钩弋夫人并不说话，两只眼睛直瞅着汉武帝，那可怜劲儿就别提了。汉武帝实在没有勇气再看下去，就闭上眼睛，催促说： “快走，快走！反正你得死！”钩弋夫人就这么被逼死了。

事后，有不少大臣对这件事表示不理解，汉武帝说：“自古以来，国家混乱大多是由主少母壮造成的。幼主继位，权柄落入母亲手中，于是骄横跋扈，淫乱自恣，没有人能制止，你们难道忘了吕后的事了吗？所以欲立幼子，不得不预先除掉其母，免生后患。”

这一做法到了北魏时，竟至被定为制度。凡是被立为太子的，他的母亲不论有无过失，都必须杀。
