# 恩结术

当对方完全是因自身原因而导致错误的时候，你不加以惩罚或报复，他就会对你产生强烈的感恩心理，从而顺从你。反之急于报复、惩罚对方，虽然有害于对方，于己也无益。为了达到恩结的目的，甚至可以给对方创造或提供一个犯错误的机会，然后加以利用。至于运用父罚子赦、夫错妻改的方式笼络人心，手段则更高明一筹。高欢、李世民都算得上这方面的行家。
