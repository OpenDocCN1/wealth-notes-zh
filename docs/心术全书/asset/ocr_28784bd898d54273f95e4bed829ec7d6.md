# 反语术

反语就是说反话，或反话正说，或正话反说，有表里两层意思。表面一层是谈话本身所固有的，骨子里的一层是这个特定的上下文所赋予的，说话人的真正意图正是骨子里的这层意思。反语的表里两层意思，永远是正好相反的。反语可使交谈的双方，直接从正语和反语中形成比较，往往会收到比仅仅说正语更强烈的语言效果。反语多用于讽刺，所以运用时，必须让人明白这是正话反说。
