回廉颇的念头。

# 臭鱼惑众

公元前210年夏，秦始皇出巡时得了重病，死在沙丘。随行的赵高和李斯慌了手脚，慌忙商量对策。李斯说：“沙丘离咸阳还有一千六百多里，半路上皇上突然晏驾，要是消息传出去，可能引起混乱。不如暂时保密，回到京城再说。”于是，他们就把秦始皇的尸体安放在车里，关严车门车窗，放下帷子，外面的人什么也看不见。除了胡亥、赵高、李斯及几个内侍外，别的人全不知道秦始皇已经死了。文武百官照常乘车在上朝，每天的饮食也像往日一样由内侍端到车里去。由于天气炎热，不久尸体腐烂，散发出刺鼻的臭味。李斯就命令人弄来一些鱼放在车上，用以迷惑人。这样，直到把秦始皇的尸体运抵咸阳，他死亡的消息一直没有走露。

# 指鹿为马

赵高窃取了秦朝大权以后，怕有的朝臣不服气。一天，他牵着一只鹿来到大殿上，对秦二世说：“我得到了一匹好马，特地牵来献给陛下。”秦二世认得是鹿，笑着说：“丞相可真会开玩笑，这分明是一只鹿，怎么会是马呢？”赵高装做很不高兴地说：“这是我费了好大气力才得到的一匹好马，怎么能是鹿呢？陛下可问问各位大臣，这到底是马还是鹿？”不少大臣怕得罪赵高，违心地说：“不错，是一匹好马呀！”有些不肯违心说假话却又胆小的人，使劲低着头，一言不发。只有几个大胆正直的大臣说：“是鹿，不是马。”赵高暗中记下了这几个大臣的名字，几天后，就找了个借
