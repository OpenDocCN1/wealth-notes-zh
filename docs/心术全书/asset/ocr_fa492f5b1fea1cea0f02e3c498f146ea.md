# 侯渊取蓟城

魏尔朱荣派大都督侯渊带领数量极少的军队去讨伐韩楼，有人主张增加一些军队，尔朱荣说：“侯渊擅长随机应变，让他多带人，未必用得上。”

侯渊出发后，一路大造声势，深入到敌后活动。在距离蓟城一百余里的地方遇上了敌军，侯渊设下埋伏，等敌军走过，突然从身后发起进攻，敌军被一举击溃，俘虏了五千多人。侯渊什么也没说，让把马匹和武器还给俘虏，放他们回城。部将都认为不可以，苦苦相劝，侯渊说：“我们兵少，不能强攻力战，只有出奇兵，施用离间计，才能攻克蓟城。”估计俘虏全都入了城，侯渊夜里带领骑兵来到城下，喊叫开门。韩楼果然上当，以为放回的人是内应，要开门献城，急忙上马夺门而逃，被侯渊追上活捉了。侯渊没费一刀一枪，占领了蓟城。

# 王镇恶背水制胜

秦将姚丕守卫渭桥，阻挡晋军的进攻。王镇恶率军逆水而上，乘坐蒙着牛皮的战船，划船的人都隐蔽在船舱内。秦军只见船进，不见有人划船，以为对方有神帮助，惊恐万分。到了渭桥附近，王镇恶暗中命人解开缆绳，战船全都随水漂走了。看着大家焦虑不解的样子，王镇恶说：“这里是长安北门，离家万里，战船及衣服粮食，都已经随水漂走。我们进攻获胜，则功名俱有；一旦失败，死无葬身之地。”说着，他奋勇当先，冲杀在前。众将士也不敢怠慢，人人以一当十，势不可挡，打败了姚丕守军。
