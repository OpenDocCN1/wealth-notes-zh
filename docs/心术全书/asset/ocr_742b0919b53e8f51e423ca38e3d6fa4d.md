后。王莽又不失时机地“劝说”众人，弄得进言的人越来越多，结果王莽的女儿被立为皇后。

# # 翟酺争尚书

东汉时，因尚书缺额，皇帝下诏让六百石以上的官员参加考试，择优选拔。翟酺准备应试，估计能同自己形成竞争的对手是太史懿。于是，他借故去拜访。寒暄过后，他就坐着什么也不说了，眼中闪着泪花。太史懿感到奇怪，问他怎么了。翟酺有意作出欲言又止的样子，犹豫了好半天才说：

“我最近看了占卜书，感觉有人将因才智过人遭到中官的杀害。看你的面相，与书里说的很像，所以我心里很难过。”

太史懿听了既感激，又害怕，就称病不参加考试。结果翟酺考试位居第一，官拜尚书。

# # 曹操“中风”

曹操少年时游手好闲，不务正业，叔父多次向他的父亲告状，要求对他严加管教。一天，曹操正在大路上玩，见叔父走来了，就故意躺倒在地，做出口歪眼斜的样子。叔父见了，以为曹操中了风，急忙去告诉了他的父亲。他父亲听说后，急忙跑来看究竟发生了什么事，却见曹操正谈笑风生地同小伙伴玩耍，好像什么也没发生一样。父亲不解地问：

“你叔父刚才还说你中风了，怎么这么快就好了？”曹操眼皮翻了翻，说：“哼！我哪有什么中风的事？叔父看不上我，总是说些难听的话骂我。”父亲听了，还真有点生了叔父的气。自此，叔父再告曹操的状，父亲也不相信了。
