# 王猛赦免徐成

十六国时，前秦大将王猛督军10万攻打燕国，在潞州一带与燕人相持。为了探知燕军的虚实，王猛派将军徐成前去侦察，约定中午时分返回。可是，徐成直到黄昏才返回。王猛大怒，要处斩徐成。徐成的上司邓羌不同意，求情说：“大敌当前，斩将会影响战斗力，不如让他戴罪立功。”王猛说：“不杀徐成，军法不容。”邓羌又说：“徐成是我的部将，我愿与他一同死战赎罪。”王猛还是不应允。邓羌愤怒已极，回营后号令军士进攻王猛。王猛见形势危急，便说：“邓羌有义有勇。”派人通报邓羌，说已经赦免了徐成。过了一会儿，邓羌到了大营谢罪。王猛拉着他的手说：“我是用这件事来试试将军，让你的下属更敬重你。大敌当前，我怎么会滥杀大将呢？”一场即将发生的兵乱就这样平息了。
