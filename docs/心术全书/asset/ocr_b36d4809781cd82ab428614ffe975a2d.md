# 淳于髡善察

梁惠王连续两次接见淳于髡，他一句话也不说。梁惠王很奇怪，责问那个引荐淳于髡的宾客。宾客又去追问淳于髡，他说：“我第一次见大王，大王心不在焉，其心在于奔驰；第二次见大王，他的心思在音色，所以我没说话。”宾客一一回报，惠王惊讶地说：“淳于髡真是圣人啊！头一次有人献上了一匹好马，寡人尚未骑试，他就来了；后一次是有人献来一名歌者，我正想听演唱，他又来了。寡人两次虽然都是单独接见，可是所关心的，的确是其他的事。”

# 臧孙子的忧虑

齐国派出大军进攻宋国，宋国马上派臧孙子为使节，到楚国求援，楚王当即高兴地答应了。在回宋国的路上，臧孙子一直愁眉不展。车夫觉得奇怪，问他说：“楚王痛快地答应派兵援救宋国，您却面无喜色，这是为什么呢？”臧孙子说：“楚王痛快地答应派兵，这正是我所忧虑的啊。齐国是一个大国，宋国是一个小国，楚国为救一个小国而得罪一个大国，自然要冒很大的风险。他应该拒绝或勉强答应才合乎常理。可他却十分痛快地答应了，这其中恐怕有诈。他大概是想乘宋齐交兵之际，坐收渔人之利。”果不出所料，齐军侵入宋境，接连攻下了五座城，可楚国并未派出一兵一卒前来援救。
