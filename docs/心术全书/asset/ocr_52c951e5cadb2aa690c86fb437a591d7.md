# 人决不食之

有个僧人以善辩著称，一次他对众人说：“儒学虽属正统，但不如佛学广博。如僧人大多能读儒家书籍，儒家学者却不能读佛家典籍。我们明朝兼通儒学和佛学的儒家学者，只有宋景濂一个人罢了。”张倬斥责他说：“譬如饮食，人可以吃的，狗也可以吃。狗所吃的东西，人是决不能吃的。”僧人默然无语。

# 佛笑

清代初年，梁相国和他的儿子都是朝廷高官，权势显赫。高宗南巡时，梁相国的儿子已被免官，可是有人告发他横行乡里，胡作非为。高宗听了很生气，游大佛寺时，梁相国赶来迎驾。高宗正在气头上，走到山门前，满面怒容地指着弥勒佛问：“佛朝我笑，是什么意思？”梁相国急忙上前一步，说：“佛见了佛，自然要笑。”高宗回过身来，冷笑了一声，说：“那为什么也朝着你笑呢？”梁相国连忙摘下帽子，说：“佛笑奴才不成佛耳。”

# 碰到了屈原

清代大学者纪晓岚机智过人。一次，乾隆想难难他，便问：“爱卿，忠孝怎么解释？”纪晓岚不假思索，脱口而出：“君要臣死，臣不得不死，为忠。”还没等他说完，乾隆插话说：“好，我现在就让你去死。”纪晓岚一愣，随即说：“臣下遵旨！”乾隆问：“你打算怎么死？”纪晓岚说：“跳河。”乾隆说：“那就快去吧。”纪晓岚果真走了
