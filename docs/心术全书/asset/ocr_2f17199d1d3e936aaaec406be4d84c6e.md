书《春秋》的规定，对尊贵的人是 不能施加刑罚的。何况是战马受惊，不是您存心违法，我看就不必议罪了。”曹操沉思了一会儿，说：“既然主簿不敢议罪，我就自己执行法令吧！”说罢，抽剑割下一绺头发，扔在地上，说：“大 军不能没统帅，姑且割发代首吧。”消息传开，全军上下无不感叹，再没人敢违犯军令了。

# 华歆救人

华歆和王郎一道乘船避难，有个人苦苦哀求，想搭乘他们的船。华歆不同意，王郎说：“所幸船里还有空余的地方，就带上他吧。”华歆也只好同意了。船开动不久，一伙盗贼顺岸追来，口口声声让搭乘的人下船。王郎吓得直打哆嗦，想把搭乘的人送上岸去，交给盗贼。华歆说：“这个人要搭乘时，我就怀疑他会招来麻烦，因而不同意。既然已经答应人家搭乘，怎么可以半路上抛开不管呢？”遂让船继续行走，那个搭乘的人得救了。

# 荀晞杀堂弟

荀晞能文能武，平时当文牍堆积如山时他才去处理，边看边批，快得像流水一般，奸诈欺骗的勾当很难瞒过他。荀晞治军极严，他的堂弟要在他手下当将官，他挺为 难地说：“我执法如山，万一你今后冒犯军纪，那时后悔就来不及了。”婶婶坚持要他任用，荀晞没办法，只得任命堂弟为督护。不久，堂弟犯法当斩，婶婶吓得魂不附体，披头散发地去求情。荀晞坚决不答应，依法处斩了堂弟。然后换上素服去祭吊，边哭边说：“兄弟啊，杀你的是兖州刺史，哭你的是你哥哥荀晞。”荀晞这么治理军队，使得军纪严明，将士作战勇敢，屡屡打胜仗。
