# 不宜言外事

宋代人王叔文早年侍奉太子，经常与太子等人谈论政事。一次，当谈到宫市骚扰百姓，在社会上产生了极坏的影响时，太子激愤地说：“我想劝谏皇上，取消宫市。”众人齐声称赞太子体恤民生，太子也有些飘飘然。然而他发现平日最敬重的王叔文默然无语，不免有些奇怪。众人退出后，太子单独留下了王叔文，问：“你为什么不说话？”王叔文说：“太子的职责是照料好皇上的衣食住行，按时请安，不宜谈其他事。再说皇上已经在位很久了，朝廷的每一件事几乎都是由他决定的。您贸然要求取消宫市，皇上如果怀疑您是为了收买人心，篡权夺位，您又作何解释呢？”太子听罢，吓出了一身冷汗，双手抓住王叔文衣服，哭着说：“不是先生指教，我怎么会想到这一层？”从此，太子更加敬重王叔文了。

# 爱珠复宠

沈爱珠嫁给许季臣后，你恩我爱，感情融洽。可是过了一段时间，许季臣看上了妓女王墨兰，并娶回家作了妾。从此，许季臣把全部心思放到了王墨兰身上，对沈爱珠十分冷淡。沈爱珠什么也不说，换上破衣服，弄得蓬头垢面。这样一来，许季臣更讨厌她了。过了一段时间，沈爱珠突然换上华丽的衣服，浓妆艳抹，光采照人。许季臣简直惊呆了，甚至有些不相信她就是自己的妻子。于是，他与沈爱珠重修旧好，疏远了王墨兰。沈爱珠巧用求新心理，又一次赢得了丈夫的爱。
