# 杯酒释兵权

赵匡胤发动陈桥兵变，当上了皇帝。一天，他问赵普说：“自从唐代末年以来，仅仅几十年的时间，帝王竟至十次易姓，政局动荡，战争不息，这是什么原因呢？”赵普说：“藩镇势力太大，君弱臣强，自然政局不稳。要想长治久安，就得削弱藩镇，收回过重的兵权。货币粮食由朝廷统一调配，军队由皇上直接指挥，天下就太平了。”还没等他说完，赵匡胤就摆摆手，说：“卿不必说了，我知道该怎么办了。”
