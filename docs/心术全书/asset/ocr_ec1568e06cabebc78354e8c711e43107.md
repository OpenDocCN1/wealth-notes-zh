滋滋的，当即拜他为郎中令。从此，陈平深得吕后信任，吕须等人的谗言也就行不通了。

# 刘 睦 避 祸

东汉时，北海王刘睦礼贤下士，很受皇帝器重。一次，刘睦派使者进京问候皇帝，问：“你到了京师，皇上问起我来，你怎么说？”使臣说：“我就说您忠顺孝顺，慈仁善良，敬重贤人。”不料刘睦连连摇头，说：“这么说不行。你要说我的小时候聪明伶俐，好学进取，可自从继承王位以来，终日沉溺于声色犬马之中，不问政事，不思进取。只有这么说，皇上才不会怀疑我。”

# 韦 忠 保 身

晋惠帝是有名的白痴，昏庸无能，朝政被贾后把持。平阳人韦忠，博学多才，很有名气。尚书仆射裴顾就把他推荐给张华，张华便派人请他当官。韦忠却借口有病，委婉地回绝了。有个朋友问他为什么不去当官，韦忠说：“张华和裴顾这两个人为人轻浮，我不愿同他们玉石俱焚。”原来张华和裴顾依附贾后，引起许多人的不满。不久，就爆发了八王之乱，张华和裴顾及他们举荐的人，全被赵王伦杀害了。

# 王 戎 失 足

西晋时，齐王见各路兵马从东西两面夹攻都城，忙召集文武百官商讨对策。尚书令王戎说：“来的军队很多，不可阻挡，不如让出大权回封土去，还可谋求平安。”东海王司马越附合王戎的意见，齐王微微地点了点头。
