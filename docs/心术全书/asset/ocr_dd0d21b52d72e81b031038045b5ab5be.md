# 许 而 不 与

宋太祖曾答应授予张融司徒长史官职，可过了很长时间也没任命。一日上朝时，张融故意骑了一匹瘦马。太祖好奇地问： “爱卿的马这么瘦，每天给吃多少粮？”张融说：“一石。”又问：“吃一石粮怎么会这么瘦呢？”回答说：“只说不给。”太祖明白了他的用意，很快就让他当了司徒长吏。

# 使 者 问 询

狄青屡建奇功，官至枢密使。他自恃功高，对同僚颇为傲慢。给将士们发放物品时，动辄就说：“记住，这是狄家爷爷赏赐的。”他的话使得许多同僚不满。当时文潞公执掌朝政，便有意在边境地区设立三镇，派狄青担任镇节。狄青当然不愿意去，就对皇帝说：“我没什么功劳而被委派担任镇节，没有什么罪过而被派往边境地区，请陛下三思。”皇帝觉得他说得在理，一时无话可说。等他回去后，皇帝就把这些话对文潞公学说了一遍，并说狄青是忠臣，对他不要乱加猜疑。文潞公说：“太祖皇上难道就不是周世宗的忠臣吗？然而他得了军心，所以才有了陈桥兵变，黄袍加身的事。”皇帝听了默然无语。

狄青并不知道皇帝的态度发生了变化，又到中书省为自己不担任镇节辩解。文潞公直视着他说：“没有别的事，只是朝廷怀疑你。”狄青听了不由得打了个冷战，只好听命出任镇节。
