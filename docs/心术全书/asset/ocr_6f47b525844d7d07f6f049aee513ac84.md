# 韦孝宽预察

皇帝下诏免去尉迟迥相州总管职务，派韦孝宽去接替他，并任命小司徒叱列长文担任相州刺史。韦孝宽让叱列长文先走几天，自己随后赶到。当韦孝宽行至朝歌时，尉迟迥派大都督贺兰贵，带着他的亲笔信，赶来问候韦孝宽。韦孝宽读了信，觉得不对劲，就有意与贺兰贵交谈起来。通过交谈，他怀疑尉迟迥要谋反。于是以有病为托辞，在驿站住下观察动静，并派人到相州以求医买药为名，秘密探听消息。几天后，先行的叱列长文逃了回来，带来了相州谋反的消息。韦孝宽弄明白了情况，便打马回返。他下令拆毁沿途所有的桥梁，并把驿站的马全都牵走，还吩咐驿站的管理人员说：“尉迟大人要来了，你们要多准备酒菜迎接。”几天后，尉迟迥果然派出几百名骑兵追赶韦孝宽。追兵们一路上因贪吃驿站的酒肉，再加上桥梁被毁，没有替换的马匹，所以未能追上。
