率部协助筑城，并想趁机改编王忠嗣的军队。王忠嗣看透了
他的用心，就率部提前到达。借口没见到安禄山，接着就率
部返回了。

# 依照圣旨办了

南唐升元年间，金陵着了一场大火。左衙使周业正在朋
友家饮酒，喝得烂醉。有人把这件事报告了烈祖李升，李升
对施仁望说：“你率领十名卫士到着火的地方，如果周业正
指挥救火，算他没事。如不是这样，立即斩首报来。”施仁
望出宫后马上派人去告诉周业，对他说明了情况，周业听了很
害怕，急忙穿上女子服装，去找施仁望谢罪，施仁望就把他藏
了起来。大火熄灭后，施仁望去拜见李升，说：“火灾没造
成多大损失，对周业也依照圣旨办了。”他有意味使用模糊语
言，既顾全了君主的面子，又为解救周业留有回旋的余地。
听他这么一说，李升忙问：“你把他杀了吗？”施仁望说：
“周业的父亲周本正在前线拒敌，臣不敢匆忙奉诏杀周业。”
李升这才松了一口气，说：“不是你差点坏了大事！”从此，
他倍加器重施仁望。

# 丁皂保敷衍皇帝

清太祖努尔哈赤的胞弟恭王突然病死，努尔哈赤悲痛异
常，责问恭王府的总管和长史为什么不及早报告病情。二人
说这是恭王的吩咐，他怕兄长为自己有病而悲痛，便不许任
何人向努尔哈赤透露病情。努尔哈赤听了，更加悲伤，也越
想越气，就召来内府郎中丁皂保，命他去打死恭王府的总管
和长史。
