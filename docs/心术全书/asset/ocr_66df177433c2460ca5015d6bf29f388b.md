# 用谎术

人人都爱听真话，讨厌假话。但在有些情况下，说真话反而收不到好的效果，甚至把事情弄糟。当此之时，针对人们的心理，耍一点儿滑头，说几句谎话，往往可以收到奇效。用谎不宜过多，更要有好的机会。谎言使用得恰当，以后即便暴露，也会得到人们的谅解，不至于对用谎人的声望造成损害。至于居心叵测的谎言，是不属于这一范畴之内的。

# 陈轸移祸

公元前317年，秦国在脩鱼战胜了韩国，韩国打算割让给秦国一些城池，以此作为条件与秦国议和。楚王得知秦韩即将和好的消息，意识到秦军可能转而攻楚，便采用陈轸的计谋，告示全国将发兵救韩，命令部队开到通往韩国的道路上，并遣使对韩王说：“楚国虽然力量不强，但已出动了所有的兵力来援助贵国，希望贵国不要被秦国吓倒，我国宁可冒亡国的危险来捍卫贵国。”韩王高兴万分，便不顾公仲的竭力反对，决定解除与秦国的城下之盟。秦王得 greatly 大怒，率军猛攻韩国。韩王盼望着楚军前来援救，可一直到秦军打到岸门还未见到楚国的一兵一卒。韩王这才知道了楚国的当，后悔莫及。韩王被迫以儿子做人质跟秦订立了和约。
