# 预测术

人的预测能力是社会性的，是在社会生活中培养和训练出来的。人们掌握了知识，逐渐认清了事物发展的规律，就有可能对未来有所预测，发现未来的某些轨迹。在预测术中，想象担负着创造性的任务，以最大的可能构思未来的远景，并形象地展示出来。预测不能靠闭门造车，必须以必要的信息情报为基础。捕捉信息中有价值的部分，加以分析和利用，就可以对未来做出有效的预测。

# 智过改姓

赵襄子的大臣张孟谈拜见智伯出来，在军营门口遇上了智过。等他走远，智过急忙入见智伯，说：“魏桓子和韩康子可能要变心，您应该加强戒备才是。”智伯说：“你这话有根据吗？”智过说：“我刚才遇见张孟谈，见他神情矜持，态度高傲。因而我猜想赵襄子和韩、魏两家大概已经有意合作。”智伯哈哈大笑，摇着头说：“我已经同韩、魏两家定妥了，一旦灭赵，土地由三家平分。他们不可能欺骗我。”

见智伯不听劝告，智过又去拜访魏桓子和韩康子，观察他们的动向。回来后，对智伯说：“魏桓子和韩康子神色不对劲，很可能会背叛您，不如趁早除掉，以绝后患。”智伯
