# 邓艾捷足先登

邓艾与郭淮两军会合，共同抵御姜维。姜维见无隙可乘，下令撤军。郭淮想乘机西进，击溃与蜀汉政权交好的西羌。邓艾说：“敌军并没有走远，随时可以返回。不如兵分两路，以防意外变化。”于是，郭淮去攻打西羌，邓艾驻扎在白水的北面。

三天后，姜维派廖化在白水南岸扎营，做出与邓艾决战的样子。邓艾对众将说：“蜀军返回，我们处于劣势，按道理应该渡河决战。可是他们不修建浮桥，说明姜维是想用部分蜀军拖住我们，另有所谋。我估计他是向东偷袭洮城去了。”洮城在白北岸，离邓艾驻扎地有六十余里。邓艾连夜率军抄小路赶到洮城，作好迎战准备。刚刚安排好，姜维就赶到了洮城对岸，准备渡河。见曹军早有防范，只好放弃了袭击洮城的计划。

# 石勒破晋军

西晋大将王浚派遣五万多人进攻襄国，守将石勒因守军数量太少，十分焦急。他采纳了部将张宾等人的建议，在城墙上挖了二十余个暂不挖透的洞，里面布下伏兵。趁晋军还未列好战阵之际，石勒亲自击鼓，城头上的将士一齐摇旗呐喊，吸引晋军的注意力，暗中却传令伏兵出去。刹那间，城墙上开了二十余个洞，伏兵以迅雷不及掩耳之势杀人敌阵。晋军措手不及，全军溃退。石勒乘胜追击，打得晋军丧魂落魄。
