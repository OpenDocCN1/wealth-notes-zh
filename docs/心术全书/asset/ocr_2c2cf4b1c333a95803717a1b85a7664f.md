就进谗言，影响自己的计划，决心先发制人。

赴任那天，王敦设宴为他饯行。席间，温峤起身敬酒。来到钱凤跟前时，没等对方举杯，温峤就装出醉酒的样子，一把拽下了钱凤的帩缨扔在地上，并说：“你钱凤算什么东西，竟敢不喝我的酒。”弄得钱凤狼狈不堪，王敦以为他真的喝醉了，劝钱凤不要介意。在向王敦告别时，温峤涕泪交流，接连返回几次。在王敦的催促下，才屡屡叩首地上了路。温峤走后，钱凤果然对王敦说温峤不可信。王敦却不以为然地责怪钱凤小家子气，报复温峤的酒后失礼。这样，温峤得以顺利地到达建康，把王敦的叛逆阴谋报告了晋明帝。后来温峤和庾亮等人一起，平定了王敦发动的叛乱。

# # 口吐虾蟆

唐朝时，有个妇女随丈夫到南中时，因误食过一条虫子，从此心疑得病，多次治疗全然无效。于是请了一位京城名医看病。医生问过病因，对病人的姨母说：“等会儿我给病人吃药，呕吐时你用盆盂接着，接完后即刻端出去倒了，就说吐出的秽物中有一只虾蟆，已跳到水沟里去了，并千万要让病人相信这话。”病人的姨母照办了，妇女的病果然好了。
