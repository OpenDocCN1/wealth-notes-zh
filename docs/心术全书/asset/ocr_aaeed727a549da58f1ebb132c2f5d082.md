# 韩信赐官

韩信未发迹时很穷，一次在大街上行走，有个少年拦住了他，说：“你背着长剑，个子长得也不小，好像有两下子，其实是个窝囊废。你要是有种，就杀死我；如果不敢，从我的胯下爬过去好了。”韩信思索了一会儿，从胯下钻了过去，惹得满街围观的人哄笑不止。

后来，韩信帮助刘邦打下天下，被封为王。衣锦还乡之时，特意找来那个少年，任命他担任楚中尉，还夸他勇敢。手下人对韩信以德报怨的做法表示不理解，他说：“当时我完全可以杀死这个人，但杀人要偿命，我满腹的文韬武略不就付之东流了吗？哪里还有今日封王的事？”手下人问：“您不杀他就够宽容的了，为什么还要任命他当官呢？”韩信说：“我这是做给天下人看的。连凌辱我的人都能得官，其他与我有矛盾的人就更没必要对我心存疑虑了。”

# 丙吉容人

汉宣帝时，丙吉任宰相。他的车夫爱喝酒，酒醉后很放肆。一次，他赶车随丙吉外出，竟在酒醉后吐了满车厢。管家知道后，把车夫大骂了一顿，并准备辞掉他。丙吉说：“如果因酒醉被赶走，哪里还会收留他呢？他不过弄脏了我的车，用水洗去算了。”于是，仍然留车夫赶车。
