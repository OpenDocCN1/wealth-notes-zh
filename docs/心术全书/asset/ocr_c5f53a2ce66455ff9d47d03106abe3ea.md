# 二 难术

论辩时，论辩的一方提出一个断定两种可能性的解决办法。再由这两种可能推断出两种结果，使得对方选用任何一种解决办法都有困难，从而进入左右为难的困境。所以说，二难术在论辩和思维中有着很重要的作用，是进行严密论证和驳斥对方的强有力的工具。

# 不 死 之 药

楚国一位弓箭手见有人向楚王进献不死之药，问：“这药人可以吃吗？”那人回答说：“可以。”弓箭手听了，一把夺过药吞了下去。献药的人报告了楚王，楚王大怒，下令杀掉弓箭手。弓箭手说：“是献药的人说可以吃呀！”献药人说：“我是说这药人可以吃。”弓箭手又说：“正因为人可以吃，所以我就吃了。”楚王更生气了，喊道：“吃了我 的不死之药，还敢狡辩，快把他杀了！”弓箭手说：“大王，这药是假的，您吃了也没用，我吃了又有什么不对呢？”楚王问：“你怎么知道是假的？”弓箭手说：“既然说是不死之药，人吃了就可以不死。如今我刚刚吃完，您就要杀我。可见这是死药，不是不死之药。”楚王被折服了，当即释放了他。
