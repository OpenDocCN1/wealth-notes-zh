# 不可不察

智伯想灭亡卫国，就送给卫国国君四百匹骏马和一块白璧，用以迷惑对方。卫君收到礼物后高兴异常，设宴庆贺。宴会上，文武大臣都向卫君表示祝贺，唯有南文子显得很忧愁。卫君问：“我们同大国发展友好关系，你却是一副忧愁的样子，这是为何呢？”南文子说：“没有什么功劳接受赏赐，没出什么力就接受别人的礼物，这都是不应该的。如今对方送上门来，不能不弄清对方的意图是什么。四百匹骏马外加一块白璧，这是小国向大国纳贡的规模。而现在大国反过来送给小国，您不能不慎重对待。”卫君认为他说得很有道理，就秘密传令边境军队密切注意智伯的动向。几天后，智伯果然派兵偷袭卫国。由于卫国军队早有准备，及时发现了智伯的企图。智伯叹口气说：“卫国有能人啊，预先看出了我的计谋。”说完，下令撤兵回国。
