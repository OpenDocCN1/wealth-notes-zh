# 教子术

把孩子教育好，几乎是所有家长的企盼。探寻伟人的成功之路，你会惊奇地发现，差不多所有伟人都得益于良好的家庭教育。教育子女，首先要动之以情，即从情感上打动他，使其言行发生预定的转变。人是感情动物，只有情感，才是打开心灵大门的金钥匙。由于动情法的效果往往比较短暂，而且带有盲目性，因而不要忽略晓之以理的教育方法。说理法是从理智上征服孩子，迫使其有一个深刻反省的认识过程，因而效果是稳定而长久的。高明的家长，多并用二法，使孩子在爱的氛围中，领悟到为人处世的哲理。
