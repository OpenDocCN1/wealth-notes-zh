# 望梅止渴

东汉末年，曹操率军远征张绣。路途中，天气炎热，没有水源，将士们渴得嗓子直冒烟，一个个无精打采。曹操怕影响士气，用马鞭子指着前方，说：“快走啊，前面有一片梅树林，树上结满了青梅，又甜又酸，好吃极了！”将士们听了，满嘴直流口水，个个精神焕发，行军速度明显加快了。不久，部队就到了有水的地方。

# 孙坚装病杀张咨

孙坚出兵讨伐董卓，行至南阳时，已经招集了数万人的军队。他派人送信到南阳，让太守张咨提供军粮。张咨不屑一顾地说：“他孙坚也不过是个两千石的官儿，同我职位一样，哪有资格让我出粮！”于是拒绝了提供军粮的要求。孙坚又想当面和他谈一谈，也被拒绝了。孙坚想，我刚刚起兵，就遇到阻力，不给点颜色瞧瞧，怎么能确立威严？就装做得了急病，危在旦夕。全军上下，人人恐慌。有的去请巫医，有的求山川神灵保佑。孙坚秘密派遣心腹去见张咨，说等孙坚死后，军队听从他的指挥。张咨一听乐得眼睛都睁不开了。为了在孙坚死后能顺理成章地接收兵权，他率领五百军卒，抬着酒肉，前来看望孙坚，犒劳军队，想以此收买人心。孙坚把张咨请进军营，卧床接待他。过了一会儿，孙坚又设酒宴招待张咨。酒酣之际，孙坚递了个眼色，长沙主簿报告说：“南阳一带的行军道路没有修好，军队使用的物资也没给准备。太守张咨阻拦义军，使义军不能按时讨贼，请按军法处置。”张咨大惊失色，起身想逃走。这时伏兵四
