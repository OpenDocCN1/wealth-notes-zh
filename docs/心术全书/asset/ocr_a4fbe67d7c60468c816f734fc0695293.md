# 高仁厚定军心

高仁厚攻打杨师立时，一天夜里，杨师立派部将郑君雄率精兵突袭城北副使寨。副使杨茂言不能抵御，弃寨而逃。其他营寨的将士见副使逃走了，也纷纷效尤，弃寨逃命。郑君雄如入无人之境，左冲右突，渐渐逼近中军大营。高仁厚下令大开营门，点起火把，照得通亮，亲自率领将士埋伏在两侧。叛军见营门大开，怕中埋伏，急忙撤退。高仁厚大吼一声，伏兵齐起，追杀叛军。叛军狼狈逃窜，有几十个人当了俘虏。

叛军败走后，高仁厚考虑到各营寨逃命的将士太多，不能全杀，就密召孔目官张诏来耳语了一番，派他去对各营寨的将士说：“你们要赶快把逃跑的人追回来，告诉他们不必害怕，主帅根本就不知道谁跑谁没跑，也不想追查。”张诏一向很有威望，将士们都听信了他的话，天亮以前纷纷返回了营寨。唯有杨茂言已经逃到张挞，好不容易才把他追回。高仁厚听到各营寨漏鼓开始正常报恩，高兴地说：“总算都回来了。”

第二天早上，高仁厚把全体将领招集到中军大营，处斩了杨茂言，对其他弃营的人一概不问，并把俘虏的几十个叛军也释放了。郑君雄听回来的人谈了情况，害怕地说：“高仁厚军法严明，不可战胜啊！”不久，他杀死了杨师立，率部投诚了高仁厚。
