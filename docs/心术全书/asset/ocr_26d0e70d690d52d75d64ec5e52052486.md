# 王孙贾母劝子

战国时期，燕军在乐毅的指挥下，会同赵、楚、韩、魏等国联合进攻齐国。齐军大败，齐湣王下落不明，大夫王孙贾垂头丧气地回了家。母亲对他说：“你早出晚归，我倚在门口等你；晚出不归，我靠在窗口等你。你侍奉君王，却不知君王的去处，还回家干什么？”王孙贾听到很不好意思，来到闹市中，大喊道：“愿意跟我复兴齐国的露出左胳膊！”当时响应的就有三百多人。王孙贾率众杀死了楚国的战将涫齿，拜齐湣王的儿子为王，终于复兴了齐国。

# 唐太宗处理家务事

薛万彻与丹阳公主结为夫妻，感情很好。一天，唐太宗与家人闲谈时，无意中说了“薛骾马像个乡巴佬”的话，不想传到了丹阳公主耳朵里。她为自己嫁给薛万彻而羞愧，竟一连几个月不与丈夫见面。有人把这件事告诉了唐太宗，他忍俊不禁。于是，专门为这对小夫妻摆下酒宴，席间唐太宗提议行酒令赌输赢，并解下各自的佩刀当赌物。唐太宗假装失败，把佩刀输给了薛万彻，还夸奖他头脑机灵，丹阳公主在一旁高兴得直想笑。酒宴过后，薛万彻正准备上马，丹阳公主当着唐太宗的面，撒着娇把丈夫拽到了自己车上，两人亲亲热热地回宫去了。
