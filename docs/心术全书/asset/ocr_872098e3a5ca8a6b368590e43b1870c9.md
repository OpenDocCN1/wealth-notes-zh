# 吴复明察秋毫

溧水人陈德外出临清当长工，妻子林氏在家靠纺织养家糊口。日子久了，林氏经不住左邻张奴的诱惑，遂勾搭成奸，打得火热。三年后，陈德积蓄了几十两银子，用小包装着回家。在离家十五里的地方，天已经黑了下来，下起淅淅沥沥的小雨。陈德害怕连夜路碰上盗贼，银子被抢走，就把小包藏到水心桥第三个桥墩的洞穴里，空手回到了家。林氏正和张奴鬼混，听见丈夫的敲门声，把张奴藏到了床底下，夫妻相见少不了问寒问暖一番，陈德说了藏银子的经过，就上床歇息了。
