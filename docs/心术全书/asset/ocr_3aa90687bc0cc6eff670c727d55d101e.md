# 暗 示 术

有时，某些事情不便直接说明，就把真实的意图，通过一些动作、姿态或间接的语言流露给对方，这就是暗示术。一个人仅仅善于使用暗示术还不够，还要善于捕捉对方发出的暗示信号。只有具备敏锐的判断力，才能够洞悉暗示信号的丰富内涵。中国人向来讲求含而不露，暗示术是大有用场的。有效地掌握并使用暗示术，做为暗示的一方，既能把意思流露给对方，又不至于因对方有可能出现的不满而受窘，做为被暗示的一方，既可明白对方的意思，又可保全面子，不摔身价。

# 优孟衣冠

春秋时，楚国有个叫孙叔敖的宰相。他一生为官清廉，家中没有什么财产。临死时，他对儿子说：“我死了以后，你可能很穷。生活不下去时，你可以去找优孟。就说你是孙叔敖的儿子，求他帮忙。”

优孟是当时楚国著名的优伶，一次孙叔敖的儿子碰上了他，说：“我是孙叔敖的儿子，现在以卖柴为生，实在生活不下去了。我父亲临死时，特意嘱咐我生活不下去时找您。”优孟说：“好吧，你不要走远，免得以后找你时找不到。”为了劝谏楚王，优孟开始练习孙叔敖的言谈举止。过了一年
