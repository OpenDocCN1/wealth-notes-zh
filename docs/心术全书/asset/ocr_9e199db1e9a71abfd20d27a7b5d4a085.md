# 李元轨不杀余党

唐代霍王李元轨任定州刺史时，突厥侵扰边境，李嘉运等人充当内应。他们的丑行败露后，引起了唐高宗的震怒，诏令李元轨把李嘉运及其同谋全部斩首。李元轨想，强敌当前，人心浮动，如果牵涉太多的人，容易造成恐慌，如同逼迫人们去谋反。于是，他下令只处斩首恶李嘉运，对其他人一律赦免不问。事后，李元轨给唐高宗写了份奏章，说自己违反了诏令，请求治罪。唐高宗看了奏章很高兴，说：“对那道诏令，朕早就后悔了。不是霍王审时度势，定州恐怕早就丕归大唐管辖了。”

# 赵葵定军心

赵方任荆湖制置使时，一次战斗后，赏赐立功的将士。由于赏赐的物品很少，将士们怨声载道，有酿成大乱的危险。赵方的儿子赵葵年仅十二三岁，发现了这一动向后，急忙登台大喊道：“大家不要着忙，刚才的赏赐是朝廷给的。由于路途太远，不可能有很多。本制置使另为大家准备了丰厚的奖赏，包管大家高兴！”听了他的话，谁也不再说什么，军心安定了下来。
