# 语 激 术

怒因刺激而生，勇气也从胆边生，许多事业凭一怒而成，也有无数坏事起于一怒之差。在有些情况下，正面开导和说服教育，已经不能收到理想的效果。如果采用反面的刺激性语言，甚至令人不堪忍受的羞辱性的语言，则可达到预期目的。语激术一般有两种形式：一是明激法，即直接贬低、刺激对方；二是暗激法，即赞扬他人，间接贬低对方，从而激起对方压倒他人的决心。使用语激术要把握好分寸，不痛不痒不行，过于尖刻也会使人反感。

# 孙林父激将

春秋时，殖绰本是齐国将领，因齐庄公派他帮助晋国叛臣栾盈伐晋，栾盈兵败后，他投奔了卫献公。卫献公被逐复位后，派殖绰去讨伐政敌孙林父，孙林父便派孙鼈、雍鉏二将引兵应战。二将早知殖绰骁勇异常，不免感到害怕，不愿领命。孙林父看出他们怯战，责骂说：“恶鬼尚有些胆量，你们做人为人却胆小如鼠。一个殖绰就把你们吓得要死要活，要是遇上强敌，你们大概会自杀吧？有骨气就去杀敌，没骨气不要来见我。”二将听了，羞愧交加，愤怒应战。他们使用诱敌之计，把殖绰引进了埋伏圈。孙鼈令伏兵一齐放箭，殖绰被射死了。
