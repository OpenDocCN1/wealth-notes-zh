# # 归 心 术

成大事者，必须得到众人的拥戴和服从，而要做到这一点，最重要的是本人的行为足以使众人折服。要取得人心，不仅要施惠于民、取信于民，而且对众人的情感、欲望，也只能因势利导，不可强行造物。在政局不移，战争僵持等关键时刻，人心向背便成了决定的因素。当此之时，深谋远虑的人往往一方面从容镇静地安抚民心，赢得支持，另一方面使用离间等计谋，瓦解敌方人心。

# ## 重用仇敌安人心

晋文公重耳当上国君后，晋怀公旧臣吕省、卻芮等人企图焚烧宫室。阴谋被粉碎后，吕省、卻芮被处死，可是他们的党徒很多，惶惶不可终日，害怕灾难降临到自己头上，便相互串连，制造谣言，寻衅闹事。晋文公正为此犯愁，有个名叫头须的小吏求见。头须本是晋文公的仇敌，他出谋说：“全国的人都知道我是您的仇敌，您如果肯任用我，人们就会说您不念旧恶，宽宏大量，人心也就安定了。”晋文公采纳了他的建议，便托言巡城，让头须给自己驾车。吕省、卻芮的党徒见头须也受到了晋文公的重用，全都放了心。不久，谣言就平息了，晋国安定了下来。
