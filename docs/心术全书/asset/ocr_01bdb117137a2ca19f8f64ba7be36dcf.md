# 刘绘巧治相思病

南朝宋时，刘绘的妹妹是鄱阳王的妃子，两人感情很深。鄱阳王被宋明帝杀害后，刘绘的妹妹悲痛欲绝。刘绘怕妹妹相思丧命，就请画师画了一幅画，画的是鄱阳王搂抱着宠姬情意缠绵地照镜子的情景。然后暗中派人把画送给妹妹看，她原以为鄱阳王也像自己一样专心爱自己，看了画如同咽下一只苍蝇，气得直往画上吐唾沫，大骂道：“这样的薄情人死了活该。”刘绘就这样治好了妹妹的相思病。

# 隋炀帝的宫殿

一次，苏世长在披香殿上侍宴。酒兴正浓时，他突然问：“这座宫殿是隋炀帝修建的吧，不然为什么这么华丽呢？”唐高祖生气地说：“卿表面上是直谏，实际上内心狡诈。谁不知道这宫殿是我修建的，为什么要说是隋炀帝建的？”苏世长说：“我实在不知道，只觉得宫殿过于豪华，不是节俭的帝王所应修建的。过去我在陕西武功时，有幸做您的从属。当时您的住处，仅仅能遮避风雨，但您觉得很满足。由于隋炀帝奢侈，老百姓受不了他暴虐的政令，天命才转归有道的君主，陛下因此获得了天下。可现在您的宫殿又超过了隋炀帝的，要想不重蹈他的旧辙，怎么能办得到呢？”
