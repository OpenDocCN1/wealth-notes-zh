# 蔺相如止奔

蔺相如是宦者缪贤的舍人。有一次，缪贤得罪了赵王，想逃到燕国去，让蔺相如帮他拿主意。蔺相如问：“你怎么知道燕国可以收留你呢？”缪贤说：“我曾经跟随大王与燕王在边境上相会，燕王私下里握着我的手，说：‘希望我们能成为知心朋友。’因为这个，我才决定到燕国去。”蔺相如听了摆摆手，说：“使不得呀！那是因为赵强燕弱，您又受到赵王的宠信，燕王想通过结交您，进而亲近赵王。现在您因得罪了赵王而逃到燕国去，燕王本来就惧怕赵王，又怎么敢收留您呢？弄不好还会把您抓起来，遣送回赵国。依我看，您不如向赵王负荆请罪，或许可以得到赵王的宽恕。”缪贤按他说的做了，赵王果然免了治罪。

# 曹操坐收渔利

建安八年，曹操进攻袁绍残部袁谭和袁尚。二人被打败，逃回邺城。谋士郭嘉对曹操说：“二袁各有党羽，互不服气。袁绍活着时，既想按常例立长子袁谭为继承人，又喜爱幼子袁尚，至死犹豫不决。我军如急于进攻，二袁会同心协力抵抗。倒不如暂时罢兵，让他们自相残杀。等他们的力量削弱后，可一举消灭。”曹操依计而行。撤军不久，二袁就爆发了内战。袁谭被打败，反而向曹操求救。曹操趁机出兵，很快打败了二袁。
