# 反间术

“间”是间谍，“反间”就是设法把敌人的间谍为我所用。运用反间术的主要手段是，遇有敌方间谍来刺探情报，可用重金收买，使之叛离敌方；或诈痴装憨，故意提供假情报，使敌方上当。

# 陈平离间范增

楚汉相争，项羽派出十万大军，扬言要夺取重镇荥阳。刘邦急得坐卧不安。陈平安慰他说：“项羽手下不过范增、钟离昧等几个人算是人才，其余的都庸庸碌碌不足称道。项羽为人猜忌，容易听信谣言。只要大王舍得钱，我就有办法对付他们。”于是，刘邦交给陈平许多黄金。陈平挑选了几名心腹，叫他们打扮成楚兵，混到楚营里去了。过了几天，楚营里就三三两两地议论开了。有的说：“范增和钟离昧有这么大的功劳，可什么好处也没得着。”有的说：“要是他们在汉营里，恐怕早就封王了。”这些议论传到项羽的耳朵里，他不免起了疑心，就不再跟钟离昧商量军机大事了。可是对于范增，他还是信任的。
