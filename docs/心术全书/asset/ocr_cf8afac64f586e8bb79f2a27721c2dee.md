# 避实就虚

东汉初年，岑彭率军三万征讨秦丰。秦丰与部将蔡宏拒岑彭于邓城，使他数月无法前进。一天夜里，岑彭调动军队，并传令说，明天拂晓向西进击山都，还有意放松了对战俘的看管。有些战俘逃回后，把岑彭调兵攻打山都的消息报告了秦丰。他急忙抽调主力部队去守卫山都，岑彭却带领大军突袭黎邱，夺取了秦丰的粮草。秦丰见上了当，急忙赶回救援，半路上中了岑彭的埋伏，被打得大败。

# 司马懿避敌攻城

公元238年，魏将司马懿进攻占据辽东的公孙渊。公孙渊在辽隧一带修筑营垒固守。司马懿分析了形势，留下小部分军队牵制敌军，调动大部分以直捣公孙渊的老巢襄平。有人表示不理解，司马懿说：“公孙渊知道我军远道而来，粮草不足，利在速战。因而他利用己方粮草充足的优势，有意采用拖延战术，想陷我方于被动。襄平很空虚，一旦攻破，公孙渊就没了依托，人心必定大乱。他为了稳住军心，会救援襄平。我们乘机与之决战，不就可以获胜了吗？”局势的发展，果真如司马懿预料的那样。
