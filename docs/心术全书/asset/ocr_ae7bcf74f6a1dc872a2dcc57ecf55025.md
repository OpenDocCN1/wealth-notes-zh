# 郑武公灭胡

春秋时，郑武公打算灭亡胡国。由于胡国的力量比较强，一时难以得手，郑武公就把女儿嫁给了胡国国君，以此使胡国放松对郑国的警惕。过了一段时间，郑武公问群臣说：“我想对外用兵，可以征伐谁呢？”大夫关其思说：“可以征伐胡国。”郑武公勃然大怒，说：“郑国与胡国情同手足，你却要征伐它，是何道理？”说完命武士把关其思杀了。胡国国君听说后，以为郑国同胡国友善，不再戒备。郑武公乘机率军突袭，一举灭亡了胡国。
