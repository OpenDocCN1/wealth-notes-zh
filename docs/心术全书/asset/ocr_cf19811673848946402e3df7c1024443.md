# 应 变 术

应变术是指在客观条件发生变化的情况下，做出恰当得体、有理有利的反映，进而维护自己的利益、地位和威信。迅速的适应能力要求立即进入角色，对客观事物的变化快速做出反应，而不是晕头转向，不知所措。现代社会中每个人都经常变换位置，意想不到的情况随时可能发生。因此，应变术是立足不败的法宝。

# 弦高犒师

春秋时期，秦国派兵偷袭郑国。秦军到了滑国境内，离郑国已经不远了。郑国有个商人叫弦高，正要到洛阳去做买卖，半路上碰见了一个从秦国来的老乡，了解到了秦军的动向。他急中生智，拿出四张熟牛皮，外加十二头牛，假托郑国使者慰劳秦军，并且说：“我叫弦高，我们国君听说大军将要到来，派我犒劳你们。”他一面应付秦军，一面派人到郑国去报告。秦军主帅果然上了当，以为偷袭计划已经暴露，郑国早有准备，就下令撤兵回国。
