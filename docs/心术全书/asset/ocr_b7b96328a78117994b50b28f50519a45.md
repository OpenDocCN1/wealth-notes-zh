# 不 疑 术

一旦获得了人才，就应充分信任，放手使用。人才获得信任，会把聪明才智发挥到最佳水平，创造出奇迹。用人不疑的前提是知人，用人者要有主见和洞察力。人才被怀疑，多与用人者无主见和轻信有关。
