# 朱仙镇书生

金兵在朱仙镇被岳飞打败，金兀术想放弃宋朝故都汴梁，撤兵回北国。有个书生拦住马头，说：“太子千万不要撤走，岳飞快被免职了，您有什么可忧虑的呢？”金兀术生气地吼道：“闪开！一派书生之见。岳飞反用五百轻骑，就打败了我十万大军。再说汴梁百姓都盼望他来，我怎么能守得住呢？”书生并没有被吓住，又说：“太子说得很对，可您却忽略了另一面。自古以来哪有朝中奸臣专权，将领在外建功立业的？岳飞连兵权都保不住，拿什么收复汴梁？”金兀术顿悟，取消了撤军计划。不久，岳飞果然被宋王朝害死了。那书生则因劝说有功，受到了金兀术的重用。

# 王晋溪料敌寇自退

明代嘉靖初年，异族作乱陕西，骚扰军事重镇花马池。花马池守将火速上表，请求朝廷派兵救援。朝廷召集九卿会议，军事总管王宪决定立即发兵，众人表示同意。只有冢宰王晋溪表示反对，说：“朝廷不必派兵，我自有办法。”他随即上书皇帝，说：“花马池是我在边防任职期间的重点规划处，驻有重兵，防守严密，敌军不可能轻易攻占。敌寇骚扰，不过是想掠夺财物。花马池的兵马完全可以防守，敌寇攻不下，很快就会撤走。朝廷如派军远征，一路疲劳，到了那里也不见得派上用场。而且沿途打扰百姓，影响国家安定。如未等兵到敌寇早已退走，那更是徒劳无益。所以，我觉得还是不要派兵为好。”王宪不听，派两个将军率六千兵卒去救援。没等走到半路，敌寇就撤走了。
