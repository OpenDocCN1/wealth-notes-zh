# 魏斯守信

一天，魏斯和管理山林川泽的虞人相约，正午时分到郊外去打猎。不巧那天下了大雨，十分寒冷。从上午开始，魏斯就同群臣一起饮酒，气氛融洽。估计快到中午了，魏斯命令撤去宴席，要到城郊去。群臣都说：“天正下大雨，根本无法打猎，何必白跑一趟呢？”魏斯说：“我已经和虞人约好，即使不能打猎，也应该去践约。”国人听说后，感叹道：“国君这么守信用，我们怎能不尽力为他做事呢？”从此，魏国令行禁止，迅速强大了起来。
