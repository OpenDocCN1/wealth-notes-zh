# 你怎么知道好吃

隋文帝时，崔宏度任太仆卿。他曾告诫下属，说话要忠诚老实。有一天，他独自一人吃鳖肉，忽然问身旁的侍者说：“你说今天的鳖肉好吃吗？”侍者下意识地附合说：“好吃。”崔弘度一听火了，说：“你没吃，怎么会知道好吃呢？”命左右把侍者打了一顿板子。当时长安流传着的一首谚语说：“宁饮三斗醋，不见崔宏度；宁茹三年艾，不逢屈突盖。”二人都是有名的酷吏。

# 反对谄媚

唐太宗站在一棵大树下，故意赞叹道：“这棵树可真美啊。”宇文士及也附着大加赞美。唐太宗勃然大怒，说：“魏征经常劝我要疏远那些专事谄媚的人，我怀疑你是这样的人，看来怀疑对了。”宇文士及连忙叩头谢罪，说：“在朝廷上，官员们经常当面指出陛下的过失，同您争论，闹得您很难堪。现在我有幸在您身边，又不涉及国家大事，再不顺从您，虽贵为天子，您又有什么乐趣呢？”唐太宗怒气顿消。他反对谄媚，却又不知不觉地接受了奉承。
