# # 舒芬迁坟

古人迷信，以为把死去的长辈葬在风水宝地，后代人就可以升官发财。明代人舒芬的父亲相中一块好地，请风水先生来看。风水先生说：“这块地能出状元，不过要在四代之后。”舒芬的父亲很沮丧，叹口气说：“我是看不到了。”舒芬年仅数岁，童声童气地说：“父亲不必忧虑，果真像风水先生说的那样，那就请您把前三世祖先的遗骨迁到这里，我就可以高中了。”父亲按他说的做了，舒芬在正德年间，果然考中了状元。当然，这并不见得与祖坟有什么关系，但他迁坟的想法却充分显示出过人的才智，也许这才是他考中状元的真正原因。

# ## 岳钟琪用盗

岳钟琪跟随大将军年羹尧讨伐青海时，一天夜里，有个盗贼潜入军营偷他的坐骑，被当场捉住。岳钟琪上下打量了他一番，问：“你到底是来行刺，还是偷盗？”盗贼毫不含糊，回答说：“盗马。”又问：“是白天进来的，还是夜间进来的？”答：“刚刚翻墙进来。”岳钟琪想，军营戒备森严，他既然能进来，也算是个人才。于是停止审讯，命人摆上酒菜，和盗贼喝起酒来。他自己用一个大杯，让盗贼用小杯。喝完酒，岳钟琪合衣而卧，鼾声大作。盗贼见他对自己如此器重，很受感动，决心留在帐下效力。
