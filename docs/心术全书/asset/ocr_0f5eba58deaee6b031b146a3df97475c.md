# 吕蒙正装聋

宋代人吕蒙正豁达大度、善于处理矛盾，很得皇帝信任。当他刚入朝做官时，有个朝士指着他说：“这样的人配当参政吗？”吕蒙正头不抬，眼不睁，一走而过。他的手下人都愤愤不平，要弄清那个朝士的姓名。吕蒙正赶紧制止，说：“一旦知道了他的姓名，我就会一辈子也忘不了，这有什么好处呢？还是不知为好。”由于他宽宏大气，赢得了朝臣们的普遍尊敬。

# 写假信得官

南宋时，有个人模仿秦桧的笔迹，以他的名义写了一封信，带着去拜访扬州太守。扬州太守识破是一封假信，就把那个人连同假信，一起送到了秦桧处。秦桧看了假信，不仅没发火，还让那人当了官。有人不理解为什么要这么做，秦桧说：“这个人敢以我的名义写信，可见不是一般人物。如果不用官职把他束缚住，他就会到外国任职，对宋朝不利。”

# 郭进雅量

郭进任山西巡检时，有个军校到朝廷告发他。经查实，告发的事纯属望风捕影。宋太祖大怒，下令把军校押回山西，交由郭进发落。正赶上北汉国入侵，郭进便对军校说：“你敢随意告发我，说明你还有点胆量。现在我给你个立功赎罪的机会，如能打退敌军，我将把你推荐给朝廷；否则，就自己想法死掉，免得弄脏了我的剑。”那军校在战场上奋勇杀敌，大败后汉军。郭进不负前言，推荐军校当了官。
