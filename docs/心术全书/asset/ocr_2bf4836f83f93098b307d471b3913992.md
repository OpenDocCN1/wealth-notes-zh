# 崔思竞明察内奸

有人告发崔思竞和堂兄崔宣谋反，武则天派御史张行发调查审理。告密人为了制造口实，预先把崔宣的妾诱骗到自己家藏了起来，然后声称崔宣谋反被妾察觉，他就杀人灭口，把尸体扔到洛河里去了。

经过调查，张行发找不出任何谋反的证据。武则天大发脾气，命重新调查，结果还是一无所获。武则天气地说：
“崔宣杀妾之事如属实，那么谋反的事就昭然若揭了。如果找不到妾，崔宣如何表明自己无罪？你自己怎能保住清白的名声？”张行发出话里有话，十分害怕，催促崔思竞赶快找到崔宣的妾。

为了尽快找到崔宣的妾，崔思竞不惜花费重金，招募寻找的人。几天过去了，还是找不到。在此期间，崔思竞发现了一桩怪事，即他与崔宣谋划的事，告密人很快就知道得一清二楚。他估计有内奸，就故意对崔宣的妻子说：“妾是找不到了，不如舍出二百匹绸缎，雇个刺客杀死告密人，免得他再告状。”

次日凌晨，崔思竞隐藏在告密人的大门旁观察动静。过了一会儿，只见崔宣家的一个食客鬼鬼祟祟地来了。他买通看门人，溜进去报信。当天，告密人就公开张扬，说崔家要雇刺客杀他。
