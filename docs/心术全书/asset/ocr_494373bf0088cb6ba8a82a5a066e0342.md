# 自 控 术

无论是感情、思想、行动、言语等，都可以透露出一个人的某种特征。肤浅的人往往喜形于色，智力高的人则对事物的变化了如指掌，不为表面现象所左右。明智的人心胸豁达，眼界开阔，心中风云翻滾，面上静如湖水。养成从容镇定的气质并非易事，尤其在失利或危机面前，如果不能自己，就注定要失败。善于自控的人，内心虽然并不平静，但决不流露出来。沉稳的风度会给对方造成压力，为自己增强信心。

# 公子小白装死

齐襄公没有儿子，只有两个异母兄弟。一个是公子纠，母亲是鲁国人；一个是公子小白，母亲是卫国人。有一天，管仲对鲍叔牙说：“依我看，将来继位当国君的，不是公子纠就是公子小白，我和你每人辅佐一个吧。”鲍叔牙同意了管仲的主张。从此，管仲当了公子纠的老师，鲍叔牙做了公子小白的老师。

齐襄公十分残暴昏庸，常常找碴儿责骂大臣。管仲、鲍叔牙知道他不会有好结果，找了个机会，一个带着公子纠躲到鲁国，一个带着公子小白躲到莒国去了。

周庄王十二年，公孙无知杀死了齐襄公，夺了君位。不
