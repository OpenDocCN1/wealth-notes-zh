# 钱藻审京军

钱藻领兵驻守密云时，有两个京军在通州抢掠百姓财产，被地方官吏当场抓获，可他们大吵大闹，拒不认罪。地方官无奈，就把他俩交由钱藻处理。他俩自恃是京军，连钱藻也不放在眼里。钱藻毫不生气，示意把甲带下去，单独审讯乙。他声色俱厉地审了一会儿，又提笔写了一阵子，好像是记录口供。然后喝令乙退下，把甲带上来。钱藻举起刚刚写的那张纸，说：“刚才乙把事情的经过都交待清楚了，都是你一手策划的，与他没什么关系。因此，乙应当无罪释放，你却应当处死。”甲根本想不到钱藻是在欺骗他，愤愤地说：“这事本来都是乙出谋干的，怎么全推到了我头上呢？”于是，他把抢掠的经过如实说了一遍。等他说完后，又传乙上堂对证，这样就把案情弄清楚了，两个京军被依法治了罪。

# 诱贼自首
