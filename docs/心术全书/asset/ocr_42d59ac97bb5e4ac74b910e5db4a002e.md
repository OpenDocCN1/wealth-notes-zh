# 孙坚退海盗

孙坚十七岁时，跟随父亲乘船来到钱塘，正遇上一伙海盗，在岸上吵吵嚷嚷地分赃。过往的人员、船只，见海盗在那里，都离得远远的，不敢通行。孙坚看了一会儿，对父亲说：“这伙海盗没什么了不起，看我去对付他们。”父亲还没来得及阻拦，孙坚已经操起一把刀上了岸，他扬起手臂比比划划，像是指挥人马围歼海盗。海盗们望见了，以为大队官军来围捕他们，连忙丢下财物，四散逃命。孙坚紧追不舍，斩杀了一个海盗，把首级交给了官府。
