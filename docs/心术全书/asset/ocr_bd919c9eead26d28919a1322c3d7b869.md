# 安顿继迁母

李继迁起兵骚扰西部边境，宋太宗打算处死他的母亲。
宰相吕端听说后，连忙去拜谒宋太宗，说：“从前项羽要煮死刘邦的父亲，想以此挟制刘邦。刘邦不仅不服，反倒希望分一碗肉汤喝。这说明举大事的人，是顾不上亲人的，更何况李继迁这样的谋反之人。陛下杀了他的老母，只会加深仇恨，坚定他的反叛决心。”宋太宗问：“依你该怎么办？”吕端说：“我觉得应该把李继迁的母亲安置到延州，并派人照料好她的生活。这样一来，李继迁即便不投降，至少可以拴住他的心。”宋太宗拍着吕端的后背说：“不是你提醒，几乎误了大事。”于是，把李继迁的母亲安置到延州生活。不久，李继迁病死，他的儿子率部投降了宋朝。

# 王守仁要挟宦官

王守仁在平定宸濠发动的叛乱中立了大功，有些宦官却处心积虑地想陷害他，他深感忧虑。恰好，有两个宦官来到浙江，王守仁便在镇海楼设宴招待他们。饮酒至半量，王守仁打发走仆人，撤掉上楼的梯子，拿出一箱信件给两个宦官看，原来都是他俩勾结宸濠谋反的信件。两个宦官看了，吓得脸色灰白，跪倒在地上。王守仁扶起他们，又把信件全都还给了他俩，感动得他俩涕泪交流。后来朝中有人说王守仁的坏话，多亏了两个宦官从中斡旋，才免遭灾难。
