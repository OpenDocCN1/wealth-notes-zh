# 种世衡赠侍妾

北宋初年的一天晚上，镇守边关的统帅种世衡请胡人最强大的部落首领苏慕恩一同饮酒，并叫出侍妾作陪。趁种世衡出去的机会，苏慕恩调戏侍妾，被种世衡发现了。苏慕恩面带愧色，连忙起身请罪。种世衡却笑着问：“你真喜欢她吗？”便将侍妾送给了他。自此，每当有胡人部落闹事，种世衡便派苏慕恩去讨伐，每次都大败而归。

# 真情动间谍

北宋时期，边境士卒抓住了一名间谍。李允则亲自为他松了绑，并热情地招待他。间谍很受感动，据实招认自己是契丹国王派来的，还交出了他刺探到的宋军部署及粮草分布等情报。李允则认真地看了一遍，说：“你的情报不准，误差很大。”说着，命军吏把实际情况提供给间谍。间谍请求把情报用印章封好，李允则也同意了，还为他准备了充足的回返费用，然后就放他走了。几天后，那个间谍又返了回来，不仅原封不动地交回了李允则提供的真实情报，还把契丹的兵力部署等情报，提供给了李允则。
