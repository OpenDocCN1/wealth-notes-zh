# ## 付尸一观

唐代匡城人刘玄佐镇守汴地时，因受到别有用心的人的挑唆，想处死翟行恭，没有人敢劝谏。处士郑涉擅长官辞，他毅然去见刘玄佐，说：“听说翟行恭马上就要被处死了，我请求在处死他之后，把尸体借给我看一看。”刘玄佐大惑不解，说：“尸体有什么可看的？”郑涉说：“我听说屈死的人的脸色与正常人的不同，因平生没有见过，所以想借来看一看。”刘玄佐感悟到了自己的错误，赦免了翟行恭。
