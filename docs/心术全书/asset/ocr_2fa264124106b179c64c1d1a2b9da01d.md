# 李允设计筑城

北宋和辽国缔结了澶渊之盟后，雄州地处边境，却没有城墙，难以防范辽国的侵忧。北宋有意筑城，却又怕辽国以此为借口，诉诸武力。担任雄州防务的李允想了一个办法，命人用白银铸造了一个大香炉，放在北郊的一座寺院里，有意不派人看守。几天后，大香炉不见了。李允则大张旗鼓地寻找，闹得满城风雨，还放出口风说，寺院因没城墙保护，经常丢东西。接着，下令全城的军民突击修城。仅仅用了十余天，城墙就修好了。眼见雄州筑起了城墙，辽国虽老大不高兴，却找不出指责北宋的口实。
