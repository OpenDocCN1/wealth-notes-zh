文种辞别吴王回越国去了。

等到吴国和齐国交战时，子贡又 到了 晋国，对晋定公说： “吴国正与齐国打仗。要是吴国打了胜仗，准会跟晋国争夺霸主地位，您不可不防啊！ ”晋定公听了子贡的话，果真准备了起来。等到子贡回到鲁国时，吴国已经把齐国打败了。子贡凭着一张嘴，保全了鲁国。

# # 奉承话换国君

晋国被秦国打败，晋惠公当了俘虏。 阴饴甥到秦国交涉，请求释放晋惠公，秦穆公傲慢地问： “国君没了，晋国乱套了吧？ ”阴饴甥故意叹了一口气，说： “唉，真让您说对了。现在晋国分成两大派，各持一端，互不相让。一派是军人，认为国君被俘是晋国的奇耻大辱，便加紧训练，准备复仇。另一派是文官，认为惠公被俘是他自己的错，他们正忙着收税，为的是献给秦国，还说： ‘秦国是最讲信义的国度，只要惠公获释，晋国定要为秦国拼死效力。’ ”秦穆公又问： “两派对惠公能否获释是怎么看的呢？ ” 阴饴甥说： “军人不抱什么希望，文官则认为秦国重仁义，讲感情，会原谅晋国的过失，放回惠公。如今晋国已被打败，秦国成为霸主，施恩布德是易事。不知大王是像军人预料的那样呢，还是像文官所希望的那样？ ” ——番奉承话，说得秦穆公飘飘然，他赶忙说： “秦国历来讲仁义，这次请惠公来，是同他商谈国事，怎么会扣留呢？ ”话虽这么说，他还是逼着晋国交割了当初许下的河外五座城，又叫晋太子圉到秦国作人质，才释放了惠公。
