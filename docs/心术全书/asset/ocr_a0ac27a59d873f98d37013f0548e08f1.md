# # 毒 鸡 伤 人

苏州有一对夫妇相亲相爱，小日子过得很美满。丈夫外出经商时，妻子在家养了几只鸡，想待辛苦在外的丈夫回来，给他补补身子。丈夫一去就是几年，总算盼回来了。妻子马上杀了一只鸡，做给丈夫吃。见丈夫吃得津津有味，妻子的心都要醉了。不料丈夫刚放下饭碗，就倒地气绝。邻人怀疑女子在丈夫外出经商时有了奸夫，合谋害死了丈夫，就报了案。经过审讯，姚太守觉得不像是谋杀，怀疑老鸡有毒，就派人把其余几只老鸡全都抓来杀死，让几个待决囚犯吃，果然毒死了两人，案子就此了结。原来鸡经常吃蜈蚣一类毒虫，吃地多了，身上便蓄积了大量毒素。所以，讲究养生之道的人从不吃老鸡，并且夏天一般不吃鸡。

# # 张老者的遗嘱

张老者是有名的富户，只有一个独生女儿，便招了个上门女婿。几年后，他的妾生了个儿子，取名一飞。儿子四岁时，张老者病逝了。他在临终时对女婿说：“妾生的儿子不能继承家业，你只要能使活他们母子，使之不至于死在荒郊野外，就是积阴德了。”说着，拿出一张遗嘱，上面写着：“张一非吾子也家财尽与吾婿外人不得争夺。”女婿看了很高兴，自信家产归属自己了。

十多年后，张一飞长大，到官府申诉，要求分一份家产，女婿就把遗嘱呈交上去，官员见写着“张一非吾子也，家财尽与吾婿，外人不得争夺”，就不再过问了。
