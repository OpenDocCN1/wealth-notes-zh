# 华佗治病

某郡守请华佗治病，他诊视一番，叹了口气，什么也没说就走了。郡守虽然很生气，可为了治病，又派人送去了一份厚礼。华佗收下了礼物，可十多天过去了，他不但不来治病，反倒派人送来一封信，上面写着“无耻太守，枉活人间”八个字。郡守气得大咳一声，吐出一滩黑血。原来华佗诊察发现郡守胸中淤血，只有设法吐出，才能治好病。可要想吐出，单靠吃药是不解决问题的，于是采用了怒激的方式。华佗听说郡守吐了血，把礼物退了回去，还对郡守讲了治病的方式。郡守的病很快就好了。
