# # 装 憨 术

所谓装憨，意指在形势不明朗的情况下，表面上装疯卖傻，掩盖着真实的动机，避免引起对手的警觉。谋生于智，成于密，败于露。宁可装作糊涂暂不行动，不可假充聪明轻举妄动。暗中筹划而不露形迹，如同雷电在冬季蓄而未发。装憨术的突出特点是以退为进，后发制人。

# ## 醉得忘了日子

殷纣王不分昼夜地设酒宴，连日期都忘了。他问左右大臣，谁都说不知道。于是殷纣王派人去问王族中堪称贤人的箕子。箕子对身边的侍从说：“作为一国之君，日期都不知道，看来世道要变了。别人都说忘了日子，如果我说知道，便会对我起戒心，那我可就危险了。”见到殷纣王派来的人，他说：“我也醉得忘了日子。”

# ## 阮籍借醉避难

阮籍，字嗣宗，陈留尉氏人。他早年喜好诗书，有经国济世之志。但处于魏晋易代之际，在统治阶级内部的残酷斗争中，不仅抱负无法施展，自身的安全也没有保障。于是转而崇尚老庄思想，对现实采取了消极反抗的态度。他终日饮酒昏酣，发言玄远，说话从不评价别人的优劣得失。司马昭
