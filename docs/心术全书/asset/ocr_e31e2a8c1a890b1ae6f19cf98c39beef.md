# 曹彬拒赠

后周派阁门使曹彬去赏赐给吴越王一批兵器。为了避免接受馈赠，交接完毕，曹彬马上下令开船回返。吴越王果然准备了馈赠品，见曹彬走了，立即派出快船，带着馈赠品追了上来。曹彬叹了口气，说：“我再不接受，就有沽名钓誉之嫌了。”于是接受了全部馈赠品。回到后国，他派人把馈赠品送到朝廷。周世宗诏命曹彬接受馈赠，他在接受下来后，又转手分给了亲朋好友，自己一点也不留。

# 张齐贤分家产

北宋时，皇帝的亲戚中有兄弟二人均分财产，分家单过。可两人都觉得对方的财产比自己多，时常到朝廷上去闹。由于他们是皇帝的亲戚，所以没有人敢说什 么。张齐贤对皇帝说：“这不是台府所能解决的问题，请允许让我来解决。”皇帝答应了。张齐贤坐在相府里，把兄弟俩找来，问：“你们是不是都觉得别人的财产多，自己的财产少呢？”兄弟俩齐声说：“是的。”张齐贤记录下他们说的话，并让他们签名画押。然后派出两名官吏，把哥哥家的人全部领到弟弟家去，把弟弟家的人全都领到了哥哥家，双方任何人不许动原来的那一份家产。财产交换后，兄弟俩谁也无话可说。第二天，张齐贤把处理结果奏明了皇帝，皇帝说：“我早就猜想非你处理不好这件事。”
