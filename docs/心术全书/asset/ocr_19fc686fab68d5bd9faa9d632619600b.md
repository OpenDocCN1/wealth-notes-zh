# 乱敌术

搞乱敌军，是夺取胜利的最有利条件。乱生于内，形于外。设谋乱敌，方式多种多样，其中易服乱军和诈俘乱敌是卓有成效的手段。军服是军队的外在标志，易服混入敌军，使之真假难辨，发生混乱。将帅是军队的核心，诈称俘虏了敌军将帅，也会使敌军不战自溃。乱敌的手段要新奇而突然，以免被敌军识破。乱敌仅仅可以创造出取胜的机遇，不失时机地乘乱歼敌，才是乱敌的最终目的。

# 厨师败华氏

华氏发动叛乱，宋公亲自去征讨，在鸿口把他打败了。可华氏并不死心，纠集残部要同宋公决一死战。宋公怒不可遏，要发动攻击，厨师濮说：“我是一个无足轻重的小人，让我带兵进攻吧。”宋公答应了，濮高声对将士说：“忠于宋公的人跟我冲吧！”宋军将士群情激昂，跟着他冲向敌阵。双方刚刚接战，濮用衣服包起一个人头，举过头顶，喊道：“华氏已经被我杀了！”叛军顿时乱了营，不战自溃，宋军取得了胜利。
