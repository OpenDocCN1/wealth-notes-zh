# 朱士彦免祸

孙嘉淦任翰林检讨时，上书清世宗雍正皇帝，直言不讳地讲了三件事：一是请求皇上亲近骨肉同胞；二要停止过重的捐税；三要停止连年不断地对青海西藏用兵。这引起了雍正的不满，打算惩治他一番，问朱士彦说：“你看该怎么处理为妥？”朱士彦说：“他的言辞的确太直率，很不得体。可他是个人，用心是好的，只是方式不讲究。我倒挺佩服他的胆量。”雍正听了，怒火顿消，大笑着说：“朕也服气他的胆量啊。”遂召孙嘉淦上朝，封他为国子监司业，再升为吏部侍郎。你想救助得罪了他人的人，不妨在得罪人的面前批评他的方法，而赞赏他的心性，使人觉得他是正直的，从而免去对他的怨恨。
