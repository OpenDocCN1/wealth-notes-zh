# 活捉公子印

秦孝公派卫鞅伐魏，魏国派公子印抵抗。两军对峙了一些日子，卫鞅派人送信给公子印，说：“你我以前是好朋友，现在却相持于战场。我实在不忍心残杀，不如你到这边来，我们商谈一下，订立盟约，和平共处。”公子印不知是计，竟欣然前往。卫鞅设宴款待公子印，两人谈笑风生。酒至半酣，卫鞅猛地翻了脸，早已埋伏下的武士一拥而上，把公子印捆了个结结实实。紧接着秦军发起进攻，大败魏军，占领了魏国大片国土。
