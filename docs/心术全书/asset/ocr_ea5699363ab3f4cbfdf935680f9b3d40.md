# 火上浇油

汉景帝立薄氏为皇后，因她没有儿子，打算改立已经生了三个儿子的栗姬为皇后，就先立栗姬的长子为皇太子。谁都看得出，只要薄皇后一废，栗姬就是皇后了。长公主有个女儿，打算许配给太子。栗姬却认为景帝的美人是长公主推荐的，夺了她的宠，因此恼恨长公主，拒绝了这门亲事。于是，长公主把女儿许配给了王美人的儿子刘彻，形势开始变得对栗姬不利。可她不仅未加戒备，反倒更加骄横了。有一次，汉景帝身体欠佳，心中烦闷，故意问栗姬说：“我百年之后，请你照顾好所有的王子，行不行？”栗姬听了，很不高兴，没好气地说：“你拿我当保姆啊！”汉景帝动了气，长公主乘机说：“栗姬心胸狭窄，她要是做了皇后，恐怕又要把人当猪了。”汉景帝听了，不由打了个冷战，便不打算立栗姬为皇后了。王美人得知景帝正在气头上，就故意派礼官催促景帝立栗姬为皇后。礼官奏请景帝说：“子以母贵，母以子贵。如今太子生母无封号，这是不合适的，应速立栗姬为皇后。”景帝气得两眼冒火，差点杀了礼官，随即下令废太子为临江王。栗姬越想越气，不久就因气害病而死。后来，景帝立王美人为皇后，立她的儿子刘彻为太子。
