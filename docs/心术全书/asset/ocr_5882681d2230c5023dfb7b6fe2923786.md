# 草 场 火

宋代，杜纮在郓州任职时，有人在城门旁边贴出了一张大纸，上面写着妖魔将要降临郓州等一些话，郓州的百姓见了都很害怕。不久，官府的草场大白天着了大火，而这也正是大纸上写的“妖魔”要做的一件事。郓州的百姓更害怕了，以至有不少人关门闭户，打算到外地避一段时间。有个手下人请求杜纮在全城进行大搜捕，捉出装神弄鬼的人。杜纮笑着说：“这正是奸人所希望的，我如果下令大搜捕，就会加剧全城的混乱，奸人正好趁火打劫。我怎么会落入他的圈套呢？我不上当，奸人反倒会无计可施。”不久，捕吏终于查出了那个企图闹事的人。那人是个强盗，准备搞乱民心，混水摸鱼。不料聪明反被聪明误，财没发成，倒把自己送上了断头台。

# 军械库失火

李允则正设宴款待军队将领，有人报告军械库起火了。他不动声色，依然饮酒行令。大火扑灭后，他马上派人秘密到瀛州调运军械。没用上十天时间，军械运回，补足了因大火而短缺的部分，几乎没有人知道这件事。不久，李允则饮酒不救火的事传到了朝廷，枢密院请求宋真宗免去他的官职，并追究刑事责任。宋真宗说：“这事肯定有原因。”于是，把李允则召到朝廷，请问不救火的原因，他说：“军械库历来禁火，看守极严。那天宴会刚开始就着起大火，肯定是有人故意放的。我如果去指挥救火，有可能落入坏人的圈套，发生不测。”宋真宗认为他说得有理，决定免于追究。
