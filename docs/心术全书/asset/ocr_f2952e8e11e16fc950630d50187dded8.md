# 苏代免征

楚军伐韩，形势十分危急。韩国便向东周征调兵丁和粮食、兵器等物品。当时东周已很衰微，周王为此焦虑不安，问苏代该怎么办。苏代说：“这没什么可愁的，我让韩国收回征调令，再把高都城送给您不就得了。”周王说：“若能如此，我情愿把国家交由你治理。”

于是，苏代去见韩国相国公仲侈，对他说：“您不知道楚国昭应说了些什么吗？他劝楚王说：‘韩国已经府库空虚，不出一个月，就要乖乖投降。’楚王听了将信将疑，可您在这紧要关头却向东周征调兵士和军需品，这不是自己把弱点暴露给楚人了吗？楚国一旦得知，必然会增派大军，全力进攻，那么，韩国恐怕维持不了多久了。”公仲侈说：“可我已经派使者到东周索取去了，这该怎么办呢？”苏代说：“您可以停止征调，再把高都城送给东周，以此显示韩国的强大国力。”公仲侈听了很不是味，说：“我停止征调就已经够意思了，怎么可以再送城给东周呢？”苏代说：“您如果将高都送给东周，东周就会同韩国结成同盟，共同对付楚国。您牺牲一个小小的高都，却能够拢络住东周，这好处可就大了。”公仲侈被说服了，不仅停止了征调，还把高都送给了东周。楚国听说后，认为韩国势力很强大，又得到东周的支持，很难取得胜利，就撤军回国去了。
