
# 统御术

作为一个领导者所应重视的，并不是下属工作的成果，而是要懂得统御部下的技巧。在世间所有的艺术中，再没有比领导者的统御艺术更复杂、更捉摸不定的了。统御术主要包括以下内容：考核下属是否言行合一；有过必罚，以示威严；有功必赏，以服人心；注意每个人的言论，切忌信口开河；善用计谋；故意试一试对方；以陷阱试探对方。成功的统御术的标志是：下属将事业上的成功与发展，视为自己的事业而倍加关心，并且没有被束缚、受制约的感觉。

# 管仲献策藏粮

齐国粮食大丰收，粮食价格大幅度下跌。齐桓公怕粮食流向其他国家，想让百姓把粮食贮藏起来，问管仲有什么好办法。管仲说：“刚才我在街上见有两家修了新粮仓，主公可把这两家的主人请来当官，用璧玉作聘礼。”齐桓公照办了。消息传开后，齐国家家兴修粮仓，丰收的粮食全都贮藏了起来。

# 田穰苴执法如山

晋国联络燕国进攻齐国，形势十分危急。齐景公急忙召见田穰苴，拜他为大将，命其率领五百辆兵车，抵抗晋燕联军。田穰苴说：“希望能够派一个您最信任并且地位尊贵的大臣来做监军。”齐景公同意了，任命庄贾为监军。

田穰苴与庄贾见了面，分手时约定，庄贾在第二天中午时分准时到达军营。庄贾是齐景公的宠臣，地位显赫，根本不把田穰苴放在眼里。第二天天黑时，他才来到了军营。田穰苴问：“监军为什么刚到？”庄贾大大咧咧地说：“来了个客人，多喝了几杯酒，来晚了一步。军队出发吧。”田穰苴严肃地说：“您知道吗？一个做将军的，从接到出征的命令那一刻起，就忘自己的家；到军中有了约束，就忘了自己的亲戚；手持鼓槌，就忘了自身的安危。说什么来了客人呢？”庄贾见田穰苴十分认真，心里很不高兴，正想发作，只听田穰苴喊道：“军法官在哪里？”军法官赶快走了过来。田穰苴问：“过时不到，按军法该当何罪？”军法官说：“当斩。”庄贾一听“斩”字，吓了一跳，赶紧叫手下人跑去向齐景公求救。可是，还没等求救的人回来，田穰苴已经下令把庄贾斩了。三军将士大为震动。

齐景公听说田穰苴要处死庄贾，急忙派使者拿着符节去赦免庄贾。使者认为自己是奉了国君的命令，就驾着车飞也似地冲进了军营，高喊：“刀下留人，国君赦免了监军！”田穰苴喝住使者，说：“将在军中，国君的命令有所不受！”随后又问军法官：“对乱闯军营的人，应当怎么处理？”军法官说：“当斩！”使者听了，吓得面无人色。田穰苴说：“国君派来的使者是不能杀的，但军法如山，不能不执行。”说着他下令斩了使者的随从，砍了使者所乘车厢外的立木，杀了左边驾车的那匹马，以此代替使者受刑，向三军显示威严。

三天后，田穰苴下令进攻敌军。全军将士见田穰苴执法如山、不畏权贵，又爱护士卒，和大家同甘共苦，都深深受到感动。齐军上下一心，争着要杀敌立功。没多久，便把几年来失去的土地，全都收复了。

# 孙武操练女兵

孙武本来是齐国人，由于避难到了吴国。他带着自己所著的兵书，想要求见吴王，施展自己的抱负。阖闾想要伐楚，正需要孙武这样的人才，就说：“你的兵书我读过了，能不能当面试一试，用来操练女兵呢？”孙武说：“好吧。”于是阖闾便把宫女都叫了出来，大约有180多人，交给孙武指挥。

孙武把她们分为两队，让阖闾最宠幸的两个宫女分别担任两队的队长，命令所有的宫女都拿一只戟。孙武问：“你们知道自己的心、后背、左手、右手吗？”宫女们齐声回答：“知道。”孙武说：“好！现在我命令你们向前，你们就看心所对的方向；命令你们向左，就看左手对的方向；向右也是一样；命令向后，你们就转过身去。大家能做到吗？”众宫女应声说：“能！”孙武便下令操练，并三令五申，不听号令的，要受军法处置。随后击鼓传令向右，宫女们何曾受过这种约束？听到号令，七扭八歪，乱哄哄地笑个不停。孙武说：“号令说得不清楚，动作讲得不明白，所以你们操练得不好。这不能怪你们，是我的责任。”说完又把规定的号令反复讲了几遍，然后击鼓传令向左。宫女们照旧乱七八糟，又是一阵大笑。孙武说：“先前，没有把号令讲清楚，你们也不熟练，这是我的责任。现在号令既然已经交待清楚了，你们却不按照号令去做，这就是你们的责任了。依照军法，应该处罚队长。”说完就要将两个队长斩首。吴王阖阊从台上看到孙武要斩两个得宠的宫女，连忙派人传令，说：“我已经知道将军是善于用兵的了。但是这两个美人可万万斩不得！没有她们的陪伴，我吃不香睡不宁啊！”孙武说：“我已经接受了大王的任命，当了主将。将在军，自有治军权。”就下令斩了两个队长，又指派两个宫女做队长，重新击鼓操练。这一吓，宫女们不敢说笑了，一个一个认真地操练起来。

训练完毕，孙武派人报告吴王说：“女兵已经操练好了，大王可以亲临视察。随便大王下什么命令，她们都能服从。”吴王正在为失去两个美女难受呢，就搪塞说：“将军去休息吧，我不想再观看了。”孙武听了，叹口气说：“唉，看来大王只是喜欢看我的兵书，并不想让我施展才能啊！”阖阊这才认识到自己错了，就任命孙武为将军。后来吴国向西攻破强大的楚国，进入郢都；北面威胁齐国、晋国，称霸诸侯，孙武是做出了重大贡献的。

# 齐威王赏罚分明

邹忌讽谏齐威王，让臣民提意见。可他觉得光是让人来提意见还不够，还得明察是非，才能做到心中有数。一次，他向朝廷的大臣们了解地方官吏的情况，不少大臣都夸阿城县令好，说即墨县令不好。邹忌把这一情况告诉了齐威王，请威王暗地里派人调查。不久，调查的人回来了，把实际情况向齐威王作了报告。威王就下令召阿城和即墨的两位县令入朝。他事先让人在朝堂的一边摆好黄金绸缎，在另一边架起大锅，烧了一锅开水，然后把朝臣全都召集来。大臣们猜想，这次阿城令必定得赏，即墨令肯定倒霉。只见威王先把即墨令召上来，对他说：“自从你到即墨做官，就不断有人向我说你的坏话。我派人去考察，发现你那里庄稼长得好，百姓生活安定，官吏忠于职守，这些都是你的功劳啊！可是因为你不肯给朝中的大臣送礼，所以不少人说你的坏话。现在我把这些黄金绸缎赏给你，另外封给你一万户的俸禄！”然后，齐威王又把阿城县令召上来，指着他说道：“从他做了阿城令，天天有人夸你。可我派人去调查，却发现你那里庄稼荒芜，百姓缺吃少穿。赵国骚扰边境，你充耳不闻。只知道贿赂朝中大臣，让他们替你说好话。各地的县令都像你一样，那我齐国早就完了。来人哪，把他处死！”话音刚落，卫兵们一拥而上，把阿城令扔到了开水锅里。接着，齐威王又煮了几个贪婪枉法、罪大恶极的大臣。

# 左氏换刑徒

卫国有个刑徒逃到了魏国，卫国想用五十金把刑徒赎回，魏王不答应。卫君又想以割让左氏为条件，换回刑徒。左有大臣说：“用一座城去换一个刑徒，太没必要了。”卫君说：“在国家治与乱的问题上，不存在大与小。法律不能确立权威，刑罚不能得以实施，我就是拥有十个左氏又有什么用处？确立法律的威严，有罪必受惩罚，我即便失掉十个左氏也没什么可惜的。”

# 遭而勿失

西汉时，曹参代替萧何做了相国，什么也不变动，很少过问政事，让官吏们一切按照前相国的章程办理，自己则终日饮酒。有几个大臣见新相国不管事，很替他着急，有人甚至当面对他说明。可是他们一到那儿，曹参就请他们喝酒，直到喝醉才算完事。要是有人在他面前提起军国大事，他就让先喝酒，然后想办法岔开话题，弄得别人无法再开口。

汉惠帝知道了后，心里很不安。他召来曹参的儿子——中大夫曹密，说：“你回家的时候，替朕问问你父亲，国家大事全靠相国主持，他却终日饮酒，这是为什么呢？”曹密回到家，照汉惠帝的话问曹参。曹参一听就火了，把儿子连打带骂赶出了家门。

曹密受了责打，别提有多窝火了。他垂头丧气地回到宫里，向汉惠帝说了因劝说挨打的经过。汉惠帝更加纳闷了。第二天，他趁曹参一个人在他跟前，问：“相国为何责打曹密？他问的话是我的意思，是我叫他去劝相国的。”曹参马上摘去帽子，趴在地上，连连叩首，承认错误。汉惠帝让他起来，说：“相国有什么话，就照直说吧。”曹参问：“请问皇上，您跟先帝相比，谁更英明？”汉惠帝说：“这还用说，我拿什么跟先帝相比呢？”曹参又问：“我跟萧相国比较，皇上觉得谁更贤明？”汉惠帝微微一笑，说：“好像您不如萧相国。”曹参说：“是啊，皇上看得太对了。皇上不如先帝，我又不如萧相国。那么，先帝和萧相国平定了天下，制定了规章，如今只要继承下去就可以了，难道还能超过他们吗？”汉惠帝听后，心里虽说不上满意，却也挑不出他的话有什么过错，就说：“我明白了，请您别往心里去。”

# 李世民识人

唐太宗李世民对群臣说：“国家的灭亡，大多是由奸臣谄媚奉承酿成的。”于是有人上书，要求清除奸佞之臣。李世民问裴矩说：“怎么样才能识别出奸臣呢？”裴矩说：“他日陛下和众大臣议事时，可以假装发怒。那些直言不讳，据理力争的是忠臣；因惧怕陛下的威严而曲意奉承的人就是奸臣。”李世民摇摇头，说：“这样做不合适。按理说，国君就像水流的源头，人臣就像水流。哪有弄脏了水源，却要水流清洁的道理？身为一国之君，使用狡诈的计策去窥视别人的内心，又怎么可以指责人臣曲意奉承呢？历代的帝王，大多为自己能要点小小的权术而沾沾自喜，我却替他们脸红。”

后来，李世民发现有些大臣收受贿赂，就暗中派人送礼，想以此查出收受贿赂的人。结果司门吏接受了一匹绢，李世民动了怒，打算处以极刑。裴矩表示反对，进谏说：“做为朝廷命官，收受贿赂，贪赃枉法，的确可以处以极刑。可是您故意行贿，并以此为依据加以惩罚，属于陷人于法，本身就是违法行为。”李世民由衷地点了点头，高兴地对群臣说：“只有像裴矩这样敢于纠正君王错误的人，才称得上是忠臣啊！”

# 李世民训臣

尉迟敬德性情暴躁，依仗着自己功劳大而盛气凌人，弄得同僚都对他不满，有的人甚至告发他想谋反。一次，李世民问他是否有谋反的心思，尉迟敬德委屈地说：“我跟陛下讨伐四方，身经百战，历尽磨难，留下了这条老命。现在享受富贵，怎么会想谋反呢？”说着把衣服脱下来扔到地上，露出累累伤痕，感动得李世民热泪盈眶。李世民好言好语地安慰了他一番，可他的脾气丝毫未改。一次宴会上，尉迟敬德因和同座的人争论谁是长者，一时性起，打瞎了任城王李道宗一只眼睛。李世民见他如此放肆，怒容满面地离开了宴席。事后，李世民训斥尉迟敬德说：“朕要和你同享富贵，你却居功自傲，放纵自身。我要提醒你，不要忘了古时韩信和彭越是因何被杀的。他们的死，可不是汉高祖的罪过啊！”尉迟敬德受到很大震动，从此不再放纵自己了。

# 李世民愧贪

将军长孙顺德接受了别人送给他的几匹绢，事发后，唐太宗李世民当众赏赐给他几十匹绢。大理寺少卿胡演进谏说：“长孙顺德收贿赂理应严惩，可陛下却赏赐给他许多绢，这不是助长他的贪心吗？”李世民说：“不！如果他还有一点廉耻之心，得到我赐给他的绢，感受到的耻辱应超过刑罚。如果感受不到耻辱，说明他不过是个连禽兽都不如的人，即使杀了他，又有什么用呢？”有些时候，从侧面使对方反省过失，比正面直接指责，会收到更好的效果。

# 武则天惩治杜肃

唐中宗时，武后执掌权柄。有一年，江淮发生旱灾，饿死了许多人。为了恢复生产，朝廷明令禁止杀生。张德年龄已经很大了，可一直没有儿子，他为此忧心忡忡。兴许老天有眼，他喜得贵子，那高兴劲儿就甭提了，便杀了一只羊，宴请同僚以示庆贺。被请的人中有个叫杜肃的，他饱餐一顿，擦了擦流油的嘴，乘人不注意揣起一块羊肉，并以此为据上表告发张德违反禁令，擅自杀生，请朝廷治罪。

上朝时，武后问张德从哪弄到的羊肉。张德不敢隐瞒，如实说了，并叩首请罪。武后说：“朝廷严令禁止杀生，你违反禁令，当然不对，可你更不对的是不加选择地乱请客。”说着拿出杜肃的奏表让群臣看。杜肃十分尴尬，恨不得变成只老鼠钻进洞里。

# 勿徇己见

张咏多年担任益州知府，恩威并用，声名卓著。他离任后，有人提议由任中正出任益州知府，可也有人表示反对。皇帝拿不定主意，问宰相王旦觉得派谁合适。王旦说：“益州治理得很好，非任中正去不能维持这种好的局面。”皇帝这才任命任中正担任益州知府。

临行前，任中正专程去拜见张咏，请教为政良策。张咏说：“国家制定有法律，依法办事就行了。可是有人把自己的见解看得比法律更高明，因而舍弃法律采用自己的见解，往往把事情办糟。所以说，为政最重要的是依法办事，克服主观意志对法律的干扰。”任中正听取了张咏的意见，果然把益州治理得井井有条。

# 守信术

守信是为人处世的基本条件。自己不能胜任的事，勿轻易地答应，既经许诺，就必须兑现诺言。无信之人，已谈不上人格。信的基本定义是真诚。无信之人，经常会对自己的轻诺寡信，找来一大堆借口，时间长了自然会失去他人的信任。要想保持自己完美的形象，说话办事应深思熟虑，谨慎行事，切忌轻许诺言，以维持圆满的人际关系。

# 晋文公守信

晋文公率军攻打原国之前，和大夫们约定，十天之内无论攻下攻不下，都要撤兵回国。转眼间十天过去了，原国没能被攻下。探子送来情报，说原国已经精疲力竭，如再有三天时间，就大功告成。将士们也都劝晋文公继续攻打，不要丢掉即将到手的胜利。晋文公说：“我和大夫们约定十天为期限。如果不撤兵，就是自食其言。我怎么可以为一个原国，丧失了信用呢？”他说到做到，按照约定时间撤军回国了。原国君臣听说后很受感动，说：“对这样信守诺言的人，我们还有什么可怀疑的呢？我们归顺晋国，得到他们的保护不是更好吗？”于是，原国派出使臣，主动归顺了晋国。这一消息不胫而走，卫国人听说了，也主动归顺了晋国。

# 商鞅取信

秦孝公决定推行商鞅的新法令，授予他推行新法令的大权，叫他抓紧把新法令制定出来。新法令制定出来后，商鞅怕老百姓不相信，推行不开，就想了个办法。他叫人在都城的南门竖了一根三丈来长的木头，旁边贴了张告示，说：“谁能把这根木头扛到北门去，赏赐十金。”不大一会儿，木头周围就围满了人。大伙儿心里直犯嘀咕，这根木头并不重，扛几里地也不是什么难事，怎么给这么多赏赐呢？或许是什么圈套吧，结果谁也不去扛。商鞅见没有人扛，又把奖赏提高到五十金。这么一来，人们更疑惑了，都猜不透商鞅的葫芦里到底卖的是什么药。有个粗汉子拨开人群，笑嘻嘻地说：“我来试试。”说着，扛起木头就走。许多看热闹的人出于好奇，一直跟到北门。只见商鞅已经在那里等着，对大汉说：“好，你能够执行法令，应得奖赏！”随后就把早已准备好的五十金赏给了他。这件事很快传开了，大家都说：“商鞅说话算数，说到做到，对他的命令可要执行啊！”

# 吴起夺哨卡

战国初年，名将吴起出任魏国的西河防区长官。在边境上，有一个秦国的哨卡危及魏国农民的正常耕种，但对这样一个小小的哨卡又不值得兴师动众。于是，吴起就设法利用当地民众来拆掉它。一天，他在官府门口放了一根车辕，宣称谁能让它搬到城门门口，赏给田地和房屋。老百姓不知真假，无人应承。其中有个人出于好奇，把车辕扛到了城门，结果真的得到了赏赐。众人为之一惊，惋惜自己失去了发财的良机。第二天，吴起又放出二担谷子，说谁能运到城门口，也能得到与第一天相同的赏赐。这次，人们为了争着挑谷子，闹得不可开交。吴起见时机成熟，便在第三天发布了进攻哨卡的命令，说谁能第一个冲进去，不仅给田给房子，还有官当。结果老百姓蜂拥而上，很快夺取了哨卡。

# 魏斯守信

一天，魏斯和管理山林川泽的虞人相约，正午时分到郊外去打猎。不巧那天下了大雨，十分寒冷。从上午开始，魏斯就同群臣一起饮酒，气氛融洽。估计快到中午了，魏斯命令撤去宴席，要到城郊去。群臣都说：“天正下大雨，根本无法打猎，何必白跑一趟呢？”魏斯说：“我已经和虞人约好，即使不能打猎，也应该去践约。”国人听说后，感叹道：“国君这么守信用，我们怎能不尽力为他做事呢？”从此，魏国令行禁止，迅速强大了起来。

# 曹操削发

曹操严令士兵保护庄稼，不准践踏禾苗，要是有人违犯，就要依据军法判罪。有一次，曹操带兵出征，队伍正迅速向前行进。突然扑刺刺一声，从麦田里飞出来一只斑鸠，从曹操的坐骑头上掠过。战马受惊，嘶叫着窜进了麦田。等曹操用力勒住缰绳停下来，已经踩倒了一大片麦子。曹操赶紧下马，对管理法令文书的主簿说：“我的马踩坏了麦子，违犯禁令，请按军法议罪。”主簿说：“您是一军的主帅，不能议罪。”曹操说：“我制定了法令，自己却违犯，不治罪怎能服众？”主簿又说：“法令是对一般将士用的，按照古书《春秋》的规定，对尊贵的人是不能施加刑罚的。何况是战马受惊，不是您存心违法，我看就不必议罪了。”曹操沉思了一会儿，说：“既然主簿不敢议罪，我就自己执行法令吧！”说罢，抽剑割下一绺头发，扔在地上，说：“大军不能没统帅，姑且割发代首吧。”消息传开，全军上下无不感叹，再没人敢违犯军令了。

# 华歆救人

华歆和王郎一道乘船避难，有个人苦苦哀求，想搭乘他们的船。华歆不同意，王郎说：“所幸船里还有空余的地方，就带上他吧。”华歆也只好同意了。船开动不久，一伙盗贼顺岸追来，口口声声让搭乘的人下船。王郎吓得直打哆嗦，想把搭乘的人送上岸去，交给盗贼。华歆说：“这个人要搭乘时，我就怀疑他会招来麻烦，因而不同意。既然已经答应人家搭乘，怎么可以半路上抛开不管呢？”遂让船继续行走，那个搭乘的人得救了。

# 荀晞杀堂弟

荀晞能文能武，平时当文牍堆积如山时他才去处理，边看边批，快得像流水一般，奸诈欺骗的勾当很难瞒过他。荀晞治军极严，他的堂弟要在他手下当将官，他挺为难地说：“我执法如山，万一你今后冒犯军纪，那时后悔就来不及了。”婶婶坚持要他任用，荀晞没办法，只得任命堂弟为督护。不久，堂弟犯法当斩，婶婶吓得魂不附体，披头散发地去求情。荀晞坚决不答应，依法处斩了堂弟。然后换上素服去祭吊，边哭边说：“兄弟啊，杀你的是兖州刺史，哭你的是你哥哥荀晞。”荀晞这么治理军队，使得军纪严明，将士作战勇敢，屡屡打胜仗。

# 弃小术

在社会交际中，似乎每个人都懂得舍小求大的道理，但实际上有许多人却背道而驰，其根本原因就是没有理顺大利和小利，长远利益和眼前利益的关系。大的利益和小的利益有时不可兼得，甚至是互为矛盾的。放弃小利，对有些当事人来说，并非那么轻而易举。要想做到这一点，需要有坚强的忍让精神，不忍则不能放弃小利。小利的获得，往往意味着大利的失去。当你津津有味地享受一叶之乐时，是否想到失去了泰山之美呢？

# 齐桓公选才

宁戚是卫国农。一天，他在牛车下吃饭，敲着牛角唱歌。齐桓公见了，觉得他是个难得的人才，决定委以重任。群臣说：“卫国距离齐国并不远，可以派人前去了解一下。他如果确实有德有才，再提拔也不算晚啊。”齐桓公说：“这正是我最怕的。人们往往在提拔重用人时，总是担心他有些小过错，有时甚至因小失大。正因为这样，使不少杰出的人才被埋没了。”于是，提拔宁戚担任了上卿。

# 荀息借道

春秋时，虢国和虞国结成了军事同盟，对晋国威胁很大。晋献公同荀息谋划说：“我想攻打虞国，又怕虢国救援；想攻打虢国，则怕虞国救援，该怎么办才好呢？”荀息说：“虞公很贪婪，特别喜欢珍宝。您能把自己最好的马车和白璧送给虞公，他因贪小利，定会有求必应。您趁机提出借道去征伐虢国，等灭亡了虢国后，撤军时顺便就可灭亡虞国。”晋献公按荀息的计策办了，果然先后灭亡了虢国和虞国。

# 孙臆赛马

孙臆随齐国使者来到齐国后，住在田忌家里。田忌多次同齐国宗室子弟下赌注赛马，结果赢少输多。孙臆经过现场观察，发现他们的比赛用马相差不多，都分为上中下三个等级，就对田忌说：“您尽管下大注，我肯定让你赢大钱。”田忌相信了他的话，就下了很大的赌注。将要比赛时，孙臆悄悄地对田忌说：“您今天比赛，要把马的出场次序颠倒一下。用您的下等马，对付对方的上等马；用您的中等马，对付对方的下等马；用您的上等马，对付对方的中等马。”田忌依计而行。比赛结果，田忌以三局两胜取得胜利，赢了两千金。

# 智伯计灭仇由国

春秋时期，智伯想灭亡仇由国，但道路崎岖，车马无法通行。如果派人修路，那就要暴露真实意图。智伯心生一计，派使者去见仇由国王，说晋国要送给仇由国一口大钟。仇由国王听了很高兴，不顾群臣反对，马上派人来晋国运钟。当发现山路狭窄不能运送时，仇由国王就调集大量民工拓宽道路。大钟刚刚运到，智伯就统率大军尾随而至，发动突然袭击，灭亡了仇由国。
