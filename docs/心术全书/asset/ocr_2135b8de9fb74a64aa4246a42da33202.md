# ## 羊皮换国相

秦穆公派公子𫇆求婚于晋，想娶晋献公的长女为夫人，献公答应了。由于百里奚不愿在晋当官，献公就派他当女儿的陪臣。他对这种羞辱不堪忍受，就在半路上逃走了。他逃到楚国的宛城，以养牛为生。再说秦穆公见晋国的陪臣中有百里奚的名字，却没有这个人，感到奇怪。公子𫇆奏道：“他是从前虞国的大臣，半路上逃走了。”穆公又问公孙枝说：“你从晋国来，知道百里奚是什么样的人吗？”公孙枝是晋国奇士，刚随公子𫇆到秦，穆公就封他大夫。他说：“此人很有才能，可惜生不逢时。”当穆公了解到百里奚在南海放牛后，又问公孙枝说：“我用重金请求楚君，他能把百里奚给我吗？”公孙枝说：“这样百里奚就来不成了。”“为什么呢？”穆公不解地问。公孙枝说：“他在楚国放牛，说明楚君还不知道他的才能。若以重金去求，楚王定会留下自用，不肯给了。不如说他是逃跑的陪臣，用贱金赎回来。”穆公认为有理，就派出使者去见楚君，献上五张羊皮，说要赎逃臣百里奚回去加以罪责。楚君不愿得罪秦国，派人把百里奚关进囚车交给使者。海边的人以为他此去会被杀害，抱着他痛哭。百里奚反倒笑着说：“秦君哪里会在乎一个陪臣呢？他向楚王要我，是想用我啊！”果然，百里奚到秦国后当上了左庶
