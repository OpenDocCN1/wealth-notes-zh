# 陈五戳穿骗术

京城里的平民百姓大多迷信巫婆。有个叫陈五的武人讨
厌家人信奉巫婆，可又没办法说服他们。一天，他嘴里含着
个青李子，腮边鼓出一块，骗家里人说长了毒疮，疼痛不
堪，还故意卧床不起，水米不搭牙。他的妻子十分忧愁，便
派人找来女巫看病。女巫煞有介事地说：“他长了疔疮，性
命难保。因为他平日不敬神，所以神不会保佑他。”家人一
齐恳求，巫婆这才答应给陈五看病。陈五假装呻吟不止，疼
痛难忍，对家人说：“快请神师进屋来救我，不然我就没命
了。”巫婆进屋后，信口雌黄地说了一通。陈五从容地坐了
起来，从口中慢慢地吐出青李子让大家看，然后猛然下床，
揪住巫婆痛打一顿，赶出门外。自此家人不再信奉巫婆了。
