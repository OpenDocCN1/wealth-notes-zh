# 陆逊佯攻退兵

嘉禾五年，孙权北征，派陆逊和诸葛瑾分兵攻打襄阳。陆逊派亲信韩廙给孙权送信，报告进军的情况。由于情况有变，孙权提前撤军回国。韩廙在回返途中被曹军抓获，孙权给陆逊的亲笔复信也落入了曹军之手。

消息传来，诸葛瑾很害怕，对陆逊说：“主公已经撤军，曹军又捉住了韩廙，了解了我军的底细。再说汉河水位下降，不利水军行动。因此，我军应当火速回撤。”陆逊好像根本就未听到，依旧督促手下人种植蔬菜，自己则与将领们下棋射箭。

诸葛瑾想，陆逊足智多谋，肯定有自己的打算，便秘密来到他的营帐探问。陆逊说：“曹军得知主公撤军，便会调集所有的军队攻击我们。现在他们已经占领了有利地形，开始布阵。我们如果溃逃，那只能是自取灭亡。目前的当务之急是稳定军心，然后再巧施计谋，安全回撤。”两人又密谋了一番，便分头行动。诸葛瑾率领水军，陆逊指挥陆上兵马，一齐向襄阳进发。襄阳守军已经离城赶来参加围歼吴军，见吴军水陆并进夹攻，急忙退守城中。陆逊从容地列好阵势，虚张声势一番，然后全军上船回撤。曹军历来惧怕陆逊，弄不清他要干什么，眼巴巴地看着吴军越走越远，始终没有人敢去追赶。
