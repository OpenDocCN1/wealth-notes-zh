# 张晋除逆子

大司农张晋在刑部任职时，遇到过一件棘手的案子。有个人因经营有术而暴发，成了附近有 名的富户，可是他的父亲却依然过着贫穷的生活。一天晚上，与儿子分居的父亲实在穷得没办法，就挖开墙壁，进入儿子的房间偷窃财物。儿子发现有人偷东西，黑暗中捅了一刀。点上蜡烛后，才发现死的是自己的父亲。告发到官后，官吏们各执己见，议论纷纷。有的说儿子杀死父亲，天理不容，理应处死。有的则认为儿子是为了阻挡强盗，保护财产，杀死父亲属于误伤，不宜判死刑。由于达不成共识，便把此案呈送刑部裁决。张晋详细地看了案情，挥笔批道：“杀死强盗可以宽恕，不孝应当处死。儿子家里有的是钱，父亲却因贫困去偷盗，这不孝真是太明显了。”遂把儿子按不孝罪处以死刑。

# 严惩媚神的人

黄震在广德任通判时，发现广德有种恶俗，不少人把自己捆绑起来，带上枷板，自我拷打一番，然后到庙中求神恕罪。一天，黄震见有个士兵带枷来到庙里，就把他召到跟前，让他坦白自己的罪恶。那士兵不解地说：“我并没有什么罪过，只是想请神明消灾。”
