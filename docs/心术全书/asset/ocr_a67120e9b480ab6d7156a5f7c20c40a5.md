# 释 疑 术

一个人遭受对方的怀疑，单靠苦口婆心地去解释，往往难以奏效。如果主动出击，暂时认同对方的怀疑，然后加以引伸，得出荒谬的结论，便可使对方认识到怀疑错了，自己就可以从被怀疑的困境中解脱出来。司马懿装病，采用的就是主动去疑的方式，使对方误认为他已将将就末，不足以在政治上构成威胁，才得以隐藏起真实的动机，免遭外来促害，抓住机会，制服了对手。
