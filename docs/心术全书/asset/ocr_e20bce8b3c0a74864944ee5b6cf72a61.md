# 破谜术

俗话说，魔高一尺，道高一丈。善于制造谜案的犯罪分子，无疑是高明的；而能够侦破谜案的执法者，则更胜一筹。人的心理状态不能直接观察到，要从诸种活动的中介里来分析判断。人的言语、行为、神情、服饰、兴趣等社会行为模式，往往直接反映着他的真实心理状态。但对于制造谜案的犯罪分子来说，这些模式仅仅是“心理假象”的呈现。不善于观察分析，就无法侦破谜案。侦破谜案的方式是多种多样的，其中抓住疑点，顺藤摸瓜，运用合理的推理，使案情大白是最常见的手段。
