# 决 断 术

决断术的特征是先下手为强，与一般行为相比，有以下几个显著特点：决策与行动的敏捷性；行动具有魄力；坚决果断，给人印象深刻；先发制人；控制对手；出其不意。在不给对手以思考的余地这一点上，决断术有着奇效。若是让对手得以仔细思考，你就难以制胜。只有快速决策，迅猛出击，从气势上、心理上压垮对手，才能出奇制胜。

# 槌击玉连环

秦王派人到齐国，送给齐襄王田法章的王后太史氏一个玉连环，并且说：“听说齐国人很有智慧，能解开这个玉连环吗？”太史氏看出了秦王取笑自己的用心，什么也没说，取过一把槌子，将玉连环砸了个粉碎，然后对使者说：“已经解开了。”
