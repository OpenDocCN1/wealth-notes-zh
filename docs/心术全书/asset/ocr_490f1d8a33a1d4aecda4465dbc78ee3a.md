# 委  恶  术

委恶术是一种嫁祸于人，想方设法使对手陷于不仁不义的技巧。既然对方不仁不义，那么与之相对的己方就变得“大仁大义”了，这就是使用委恶术的奥妙。委恶术的形式主要有以下几种：一是对于还处在同盟者阶段的潜在对手，或与自己有矛盾而尚未公开化的对手，放任和诱导他作恶。等到时机成熟时，即举起“正义”大旗进行讨伐；二是寻找借口，制造事端，饰以大义，明其为贼，作为自己进攻对方的理由；三是罗织罪名，剪除异己。

# 复仇的圈套

吴起来到楚国后，当上了楚相。他对内变法图强，对外夺关斩将，深得楚悼王的信任，但却触犯了楚国贵族的利益。他们串通一气，决心除掉吴起。恰值楚悼王死去，贵族们乘机作乱。他们挥动兵器，准备杀死吴起。吴起眼见无处逃生，便猛扑到楚悼王身上，死死抱住，再也不肯松手。疯狂的贵族们连射带砍，杀死了吴起，楚悼王的尸体也被弄得不堪入目。吴起在临死时毫不慌乱，引诱贵族们毁坏楚悼王的尸体，使他们犯下了诛灭九族的大罪。不久，楚太子继位，在埋葬了楚悼王后，便将参与杀害吴起的七十多家贵族灭了族。
