# ### 破水柜

毕再遇同敌军交战时，处于上游的敌军突然顺流施放水柜。将士们抵挡不住，打了败仗。当天晚上，毕再遇命军士捆扎了数千个草人，外面套上衣服，绑上旗帜和兵器，立在船头上。次日凌晨，毕再遇击鼓进军。敌军弄不清对方来了多少人马，急忙把水柜全放了出去。眼见水柜全都顺流漂走，才知道上了当，叫苦不迭。毕再遇趁机插响战鼓，指挥将士猛攻上去，大败敌军。

# ### 毕再遇借箭

开禧年间，毕再遇被敌军包围了，箭也快用光了。他命人在城墙上撑开青色盖蓬，来回走动。围城的金兵以为主将巡城，一齐朝青色盖蓬放箭。射在盖蓬上、城楼上和落在城中的箭，多达二十多万枝。
