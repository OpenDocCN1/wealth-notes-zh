# 马绊筋

左宗棠身高体胖，一次饭后，拍着肚子说：“将军不亏肚子，肚子也对得起将军。”而后环顾左右，问下属们说：“你们说我肚子里装了些什么？”有的说：“满腹文章。”有的说：“满腹经纶。”也有的说：“胸中有十万甲兵。”还有的说：“腹中包罗万象。”左宗棠连连摇头，说：“不对，不对。”忽然，有个小校站出来大声说：“将军之腹，满贮马绊筋耳。”左宗棠拍案大叫：“说得对，说得对！”当场提拔小校当了军官。原来左宗棠是湖南人，他家乡的人把牛吃的草叫做马绊筋。他喜欢牛负重致远的性格，曾说自己是牵牛星转世。聪明的小校注意到了他的这一心理，因而说出了他的心坎上。
