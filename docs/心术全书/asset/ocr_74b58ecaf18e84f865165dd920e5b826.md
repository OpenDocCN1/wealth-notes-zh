# # 挫 锐 术

锐气可以助人致胜，也可以使人变得不知所以。在战场上，高明的指挥者总是在蓄养己方锐气的同时，消磨对方的锐气，曹刘长勺胜齐，就是一个挫锐致胜的成功范例。在日常生活中，也会遇到不从事实际工作，不知他人难处，爱口出狂言，指责他人的人。对付这种人，最好的办法是纵其意而行之。待他吃尽苦头，就乖乖服输了。

# ## 王 翦 灭 楚

战国末年，秦王派王翦率六十万大军进攻楚国，楚国也调集全国军队抵抗。楚国因面临着亡国的危险，群情激昂，士气高涨。王翦分析了这一形势，决定坚守不战，拖垮楚军。任凭楚军挑战叫骂，他一概置之不理。与此同时，王翦一面加紧督运粮草，一面强化军队训练，养精蓄锐。两军对峙了一年，楚军主将项燕见军队已是锐气殆尽，怕陷于被动，下令向后撤退一段距离，以便重新布防。王翦乘楚军后撤混乱之机，突然发动进攻，楚军被击溃。项燕见大势已去，拔剑自杀了。一年后，秦军灭亡了强大的楚国。
