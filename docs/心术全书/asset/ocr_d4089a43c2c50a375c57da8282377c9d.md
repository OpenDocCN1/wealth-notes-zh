我了。我屡屡索要房屋田园，表面上是给子孙后代准备家业，实际上是想让秦王认为我心里只想着享乐和子孙，不至于怀疑我有别的野心。

# 门客劝萧何

黥布反叛，刘邦亲自率军征剿。他多次遣使到关中，问萧何在干些什么。萧何对使者说：“皇上在外征剿，我在内安抚百姓，尽所有的力量帮助皇上讨伐叛军。我现在的做法，和皇上征讨陈豨时是一样的啊。”听他这么说，有个门客找了个机会，悄悄对他说：“您快要遭受灭族的灾祸了。您位至相国，功劳天下第一，从十多年前开始，一直深得民心。皇上屡屡遣使来问，是怕您威望太高，影响关中，波及全国。您为什么不多买些土地，使自己的名声受到损害呢？”萧何采用了门客的计谋，强行低价买了不少民田民房，闹得百姓怨声载道。刘邦凯旋时，不少百姓拦路投诉萧何霸占民财，他心里比吃蜜还要甜。

# 鲍生劝萧何

刘邦任用萧何主持关中事物。在楚汉战争处于僵持状态时，刘邦多次派使者到关中慰问萧何。萧何很高兴，鲍生却说：“大王在外风餐露宿，反倒数次派使者慰问，这是对您不放心啊！要想打消大王的疑虑，最好的办法是把您能参军打仗的子弟，全送到军队中去。”萧何采纳了鲍生的建议，刘邦果然没再派使者慰问。
