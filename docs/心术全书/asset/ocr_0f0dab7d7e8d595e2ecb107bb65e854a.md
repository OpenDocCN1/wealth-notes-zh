# 苏轼杀悍卒

苏轼任密州通判时，当地出现了一伙强盗。安抚使派遣三班使臣，率领悍卒数十人前来捕捉。悍卒自恃靠山硬，借口搜捕强盗，大肆骚扰百姓，闹得满城风雨。他们甚至用朝廷禁物诬陷平民，强抢民财，及至争斗杀人。被杀者的家属写好诉状，到官府诉冤。苏轼想，悍卒正在城内逞凶，处理不慎容易引起哗变，造成更大的麻烦。于是，他故意把诉状扔到一边，连看也不看一眼，说：“这是不可能的事！”悍卒们听说了，以为官府不会管他们，更加肆无忌惮。苏轼秘密派人查出了杀人的悍卒，果断地处决了。这一举动，既平定了民愤，又使别的悍卒无隙可乘。

# 王敬则治小偷

王敬则担任吴兴太守时，盗贼猖獗，百姓叫苦不迭，他决心煞住偷盗之风。一日，捕吏抓住了一个小偷。王敬则就把小偷的亲属全都传来，当着他们的面，把小偷狠狠地抽了，几十鞭子。而后让小偷带上写有“窃贼”字样的牌子，每日洒扫大街。过了一段时间，王敬则传出话，让小偷另交待一个小偷替他扫大街。小偷们唯恐被认出，全都逃到外地去了，吴兴境内百姓生活安定了下来。
