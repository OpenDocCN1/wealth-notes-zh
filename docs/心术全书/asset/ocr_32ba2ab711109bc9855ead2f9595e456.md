# 安 敢 不 贺

唐太宗下朝回宫，生气地说：“我非杀了这乡巴佬不可。”文德皇后关切地问：“是谁触犯了陛下？”唐太宗说：“除了魏征还会有谁？朝廷上每次争论问题，他总是使我下不来台。”皇后听了急忙退下，换上朝见皇帝的礼服，庄严地站在院子里。唐太宗吃惊地问：“皇后这是怎么了？”皇后说：“我听说皇上圣明，臣子尽忠。现在魏征敢犯颜直谏，忠心可嘉，可只有皇上圣明他才敢这么做啊。我身在后宮，怎么敢不祝贺呢？”
