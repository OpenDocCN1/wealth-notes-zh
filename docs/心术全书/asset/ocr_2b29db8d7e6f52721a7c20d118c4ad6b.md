# 陶侃砺志

陶侃遭受王敦的诬陷，贬任广州刺史。日子一久，他自觉身体发胖，命下属运来一百块大砖放在书房。从此，他天不亮就起床，把砖搬出，黄昏时再搬进书房。开始每次搬五块，便觉得腰酸背痛。经过长期锻炼，一次搬十块也不觉累。就这样，陶侃不论阴晴雨雪，还是酷暑严冬，天天如此，使体魄健壮如初。后来，王敦发动叛乱，陶侃复任荆州刺史。晋成帝咸和三年，年高七十的沙场老将陶侃受命为征西大将军，挂帅出征，一举平定了苏峻、祖约叛军。
