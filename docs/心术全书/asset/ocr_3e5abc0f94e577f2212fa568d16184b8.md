# # 摸钟

宋朝人陈襄任蒲城县令期间，有家富户丢失了许多财物，告发到官。捕吏抓获了几个小偷，不料他们互相包庇，无法弄清谁是真正的盗贼。陈襄苦苦思索，终于想出了一个好办法，对小偷们说：“城南庙里的大钟可以辨认盗贼。犯了案的人摸，会发出声响；没犯案的人摸，没有声响。”他先派衙役把小偷押到庙附近，然后亲自率领僚属到庙里祈祷了一番，暗中让人把大钟涂上墨，用黑布把四周遮住，让小偷轮流去摸。摸完后，发现有个小偷手上没有墨。经过审讯，财物果然是他偷的。陈襄巧妙地利用盗贼怕出声响不敢摸钟的心理破了案。
