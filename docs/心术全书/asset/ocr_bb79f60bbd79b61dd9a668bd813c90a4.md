# 女人头哪去了

有个安徽富商看上了一小户人家的妻子，就不惜出重金给她的丈夫，让他同意并劝说妻子改嫁。妻子开始不同意，在丈夫的威逼下勉强同意了。当天晚上，丈夫置办酒席宴请富商。估计富商快要到了，丈夫主动避了出去，让妻子出面招待。不料就在丈夫避出，富商到来这段间隙中，那女子被杀害了。富商来到，发现女子被杀，脑袋失踪，吓得不知所措。

丈夫回来后，以为富商杀害了妻子，告发到官。富商被传讯到官，说：“要我说喜欢这个女人，那完全属实。她即便不同意，我也会慢慢想办法，何必耍杀人呢？”官府听富商说得在理，就让他协助破案。有个老人对富商说：“这附近一直有个叫夜僧，从出事那天晚上起，再没听到他的声音，我觉得可疑。”富商就招募了几个人寻找叫夜僧的下落，很快在邻郡发现了他。富商派了个人穿上被杀女子的衣服，在树林中等着。当叫夜僧路过时，那人学着女人腔喊：“和尚，快还我头！”叫夜僧吓得浑身乱颤，说：“头挂在你们家左边第三户邻居的铺架上，……”还没等说完，埋伏的人一拥而上，把他捆了个结实。叫夜僧自知失语，隐瞒不了，便从实招供。原来那天晚上叫夜僧偶然路过女子家门前，见大门开着，想乘机进去偷点东西。进屋后发现有年轻貌美的女子坐在床边哭泣，顿生歹念。他强奸不成，不由得恼羞成怒，就把女子杀了。然后割下脑袋，挂在左边第三家邻居的铺架上。
