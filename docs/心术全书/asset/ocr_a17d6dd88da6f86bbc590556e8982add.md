# 吓唬妇女干什么

赵匡胤任后周殿前都点检，将要率军北伐时，京师纷纷传言军队要立赵匡胤当天子。赵匡胤听到传言后，对家人说：“外面议论纷纷，都说我要当天子，该怎么办才好呢？”他的姐姐正在厨房，顺手操起一根箸面杖追打赵匡胤，边打边说：“男子汉遇到大事应该胸有成竹，当机立断，跑回家来吓唬妇女干什么？”她的话分明是鼓励赵匡胤当皇帝。匡胤悟出了姐姐的意思，点点头出去了。不久，他就发动陈桥兵变，黄袍加身，当了皇帝。
