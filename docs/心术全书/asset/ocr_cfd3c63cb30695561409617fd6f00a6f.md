# 弃小术

在社会交际中，似乎每个人都懂得舍小求大的道理，但实际上有许多人却背道而驰，其根本原因就是没有理顺大利和小利，长远利益和眼前利益的关系。大的利益和小的利益有时不可兼得，甚至是互为矛盾的。放弃小利，对有些当事人来说，并非那么轻而易举。要想做到这一点，需要有坚强的忍让精神，不忍则不能放弃小利。小利的获得，往往意味着大利的失去。当你津津有味地享受一叶之乐时，是否想到失去了泰山之美呢？

# 齐桓公选才

宁戚是卫国农。一天，他在牛车下吃饭，敲着牛角唱歌。齐桓公见了，觉得他是个难得的人才，决定委以重任。群臣说：“卫国距离齐国并不远，可以派人前去了解一下。他如果确实有德有才，再提拔也不算晚啊。”齐桓公说：“这正是我最怕的。人们往往在提拔重用人时，总是担心他有些小过错，有时甚至因小失大。正因为这样，使不少杰出的人才被埋没了。”于是，提拔宁戚担任了上卿。
