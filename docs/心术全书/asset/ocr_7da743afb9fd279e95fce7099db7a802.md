# 骊姬逼死申生

骊姬打算害死太子申生，改立自己的儿子奚齐为太子。她首先让晋献公的宠臣荀息做奚齐的师傅，晋献公愉快地答应了。而后，他又对晋献公说：“主公已经上了年纪，我的孩子岁数还小，以后我们母子就得依靠太子了。请主公让太子进宫来，说我要见见他。”晋献公就派人到曲沃召申生进宫。申生回来后，骊姬让他陪自己逛花园，他只得从命。

当天晚上，骊姬又哭又闹，说申生调戏了她，并让晋献公自己看个明白。第二天，骊姬事先把晋献公安排在花园附近的一座小阁楼上，自己就在头发上抹了蜂蜜。等申生来到花园，她说：“这些蜜蜂真讨厌，老在我头上打转儿，请太子帮我轰一轰。”申生只好从命，为骊姬驱赶蜜蜂。晋献公远远望去，真以为申生抱住了骊姬的脑袋，气得发了疯，当天就要处死申生。骊姬反倒苦苦相劝，说：“太子是我请进宫来的，要是为这件事杀了他，别人准会以为是我害了他。这次就饶了他吧，以后改正就是了。”晋献公在骊姬的劝说下，强压怒火，打发申生回曲沃去了。

过了一段时间，申生将祭祀祖父母的酒肉献给晋献公。正巧晋献公外出打猎去了，酒肉便由骊姬接受了下来，并暗中放进了毒药。几天后，晋献公打猎回来了，见到申生献来的酒肉，心里很高兴，要亲自尝一尝。骊姬慌忙出面制止，说酒肉是从外边来的，不能轻易吃，要先试一试有没有毒。就将肉切下一块扔给狗，狗咽下后立即倒地死了。又把酒倒给一个宫女喝，没喝上几口就断了气。晋献公大怒，调集重兵去讨伐申生。
