# # 种世衡计除二将

元昊有两个心腹大将，号称野利王和天都王。二人阴险歹毒，对边境构成了很大的危险。野利王曾遣使说，只要种世衡送给他三个漂亮姑娘，他就投降。种世衡知道他在耍手段，决定用离间计，借元昊之手除掉他。于是，种世衡把使者留了下来，假意答应了野利王的要求。

紫山寺有个叫法崧的和尚，为人忠诚坚定，可以大用。种世衡就用官职引诱他出山，安排在自己门下。法崧因讨贼立了大功，被帅府授予三班阶职，任指挥使。种世衡又替他置办家产，居室骑从一应俱全。法崧酗酒狎博，无所不为。种世衡不仅不怪罪，反而对他越来越好，法崧感恩不尽。一天，种世衡突然发怒说：“我待你如同亲生儿子，你却串通反贼，该当何罪？”说着，命人对他严刑拷打。一连几十天，情景惨不忍睹。法崧毫无怨言，平静地说：“我光明磊落，问心无愧。您听信奸人之言，即便杀了我，又有什么可说的呢？”

过了半年，种世衡觉得法崧能经得起考验，下令去掉枷锁，让他沐浴干净，然后召入内室，抚摸着他的后背道歉说：“你并没什么过错，我不过是要考验考验你。我想派你使用离间计，受的苦要超过这一次，你能保证不泄露吗？”法崧哭着接受了任务。

种世衡给野利王写了一封信，用蜡油封好，缝在法崧的衲衣中间，并告诫说：“这封信不到生死关头绝不可泄漏。你如果轻易泄露了，就是忘恩负义，坏了我的大事。”
