# 陈平杜绝谗言

燕王卢绾谋反的消息传来，刘邦派樊哙统率大军前往讨伐。樊哙刚走，就有人揭发他和吕后串通一气，图谋不轨。刘邦把陈平和周勃叫进来，说：“樊哙与吕后结成死党，巴不得我快死。你俩这就到燕国去，见到樊哙，就地处决。”他怕两人不敢杀樊哙，又吩咐陈平一定要带回樊哙的脑袋，他要亲自过目，并且要派周勃接替樊哙征讨卢绾。

二人启程后，陈平对周勃说：“樊哙是皇上的连襟，功劳又大。这会儿皇上发了脾气要杀他，万一反悔了，那该怎 么办？再说皇上病危，咱们斩了吕后的妹夫，将来她能放过 咱们吗？”周勃说：“可也不能不执行诏令，把他放了吗？”陈平说：“放是不能放，不如把他装入囚车，押回长安，让 皇上自己处理好了。”周勃觉得是个好办法。

二人到了军队驻地，登坛宣读诏命。周勃统率军队，继 续讨伐卢绾；陈平则把樊哙装入囚车，押送回京。途中，传 来了刘邦驾崩的消息。陈平害怕吕后和吕须发怒，派人火速 赶赴京城报告消息。回到京城后，陈平显得十分悲伤，有意 向吕后把逮捕樊哙的事哭诉了一遍。吕后觉得他处理得很得 体，就说：“你一路劳累，早点回去休息吧。”陈平害怕吕 须趁机向吕后进谗言，就坚决要求留下来守灵，流着泪眼 说：“我受了先帝的大恩，理应效犬马之劳。现在太子刚刚 即位，宫里正需要人，就让我留下当个卫士吧。一来可以报 效先帝的大恩，二来可直接替您和皇上效力。”吕后听得甜
