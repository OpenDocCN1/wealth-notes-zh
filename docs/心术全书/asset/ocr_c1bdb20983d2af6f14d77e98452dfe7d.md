# 间谍传军威

北宋人王德用任定州总管时，为了防止契丹侵扰边境，严格训练士卒。一年后，定州的士卒都变得技艺熟练，军纪严明。一天，有个契丹人混进城中刺探情报，将士们纷纷要求把他抓起来杀掉。王德用说：“大可不必，我正要借用他的嘴，来宣扬我们的军威，让契丹不敢侵扰我们。”于是，他下令举行公开的阅兵典礼。将士们严明的纪律与高超的技艺，赢得了百姓的交口称赞。契丹间谍也混在人群中观看了阅兵典礼，看完后回去对契丹首领说：“宋军训练有素，是很难战胜的啊。”契丹首领听了很害怕，忙遣使向宋朝求和。事后，有人问王德用为什么要这么做，他说：“仗打得再漂亮，总要有一些损失。不战而能使敌人屈服，这才是高明的做法啊。”

# 薛弼妙计胜杨幺

杨幺占据洞庭湖，陆耕水战，气势浩大。他乘坐的楼船长 达十余丈，官军只能仰视，无法靠近攻打。岳飞打算也建造同样的大船，与杨幺的楼船抗衡。湖南运判薛弼对岳飞说：“如果要建造大船，那需要很长时间才能建成。况且敌 方的长处，我方可想方设法避开。现在天旱，河水下降，可 以出重金悬赏杨幺的脑袋，而不同他交战。并派兵截断江 河，使河流干涸，让楼船无法行驶。这样，杨幺的失败就指 日可待了。”岳飞采用此计，仅用了八天时间，就全歼了杨 幺叛军。
