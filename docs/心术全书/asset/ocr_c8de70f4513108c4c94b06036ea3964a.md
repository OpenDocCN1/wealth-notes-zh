# # 自荐术

自荐术是指自我了解，对自己有合理评估，对前程充满自信的基础上，创造一定的条件，自我推荐，从而提高知名度的技巧。知名度高，可以拓宽交际面，获得更多的朋友。一般说来，人皆慕名而来，知人而交。知名度高，意味着有较多的人知道你，较多的人愿意和你交往，从而增加成功的机会。中国人是以谦逊含蓄著称于世的，因而自荐不仅要选择善于识别人才的用人者，更重要的是讲求自荐技巧，切忌不识时务，言过其实。名不副实的自荐，只能会降低自己的人格。
