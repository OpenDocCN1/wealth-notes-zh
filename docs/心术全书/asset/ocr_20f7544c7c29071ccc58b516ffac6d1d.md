# ## 天地万物

王阳明认为如果没有灵明，天地万物便不复存在。有个门生表示怀疑，说：“天地万物，自古就有，怎么能说没有人的灵明，就不存在了呢？”王阳明说：“人死了，他的精灵就散了，他心中所认识到的天地万物还能存在吗？”他运用诡辩的方式，把门生说的客观存在的“天地万物”，偷换成了心中所认识到的天地万物。人死了，自然没有任何知觉了，但这和客观存在的天地万物并不是一回事。

# ## 胸中像个圣人

王阳明说：“每个人的胸中都有个圣人，只是由于人们自信心不足，渐渐埋没了。”接着对于中说：“你胸中原是有个圣人的，”于中急忙推辞道：“不敢当，不敢当。”王阳明说：“这是你自身有的，为什么要不承认？”于中依旧摇头。王阳明说：“众人胸中都有个圣人，何况你于中呢，为何要谦虚呢？这是没必要的。”于是，于中笑着承认了自己是圣人。王阳明采用循环论证的方式，把于中搞得晕头转向，竟稀里糊涂地承认自己是圣人了。
