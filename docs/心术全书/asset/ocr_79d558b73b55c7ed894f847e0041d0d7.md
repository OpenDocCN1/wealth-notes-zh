# 年夔尧问师

年夔尧七岁时，父亲请来一位塾师教他读书。上课的第一天，塾师就教他《三字经》。刚学了两句，他就问塾师说：“‘人之初，性本善’，这两句是什么意思？”塾师说：“是说人刚刚降生人间，他的本性是善良的；所有的坏人，都是后来学坏的。”年夔尧说：“我觉得不是这样。刚刚降生的人都坏，必须有人教导，才能渐渐地改掉毛病变成好人。如果不是这样，我父亲何必请您来教我呢？”塾师无言以对。

过了些日子，学习《千字文》时，年夔尧又问道：“‘天地玄黄’，怎么理解？”塾师说：“天玄色，地黄色。”年夔尧接着问：“地当然是黄色，可天有时是青色，有时是苍色，在下雨时又变成灰色，从来没有过玄色啊？”塾师再次被问住了。

# 戴震问倒塾师

戴震，字东原，幼年时在私塾读书。学习《大学章句》的“右经”章时，他问塾师说：“曾子怎么知道这是孔子的话，并加以叙述？门人又怎么知道是曾子之意而记载下来的？”塾师说：“这是朱熹说的。”问：“朱熹是什么时代人？”答：“南宋。”问：“曾子是什么时代人？”答：“东周。”戴震想了想，又问：“东周与南宋相差多少年？”塾师说：“约两千年。”戴震接着问：“时代相距如此遥远，朱熹怎么会知道？”塾师被问倒了。
