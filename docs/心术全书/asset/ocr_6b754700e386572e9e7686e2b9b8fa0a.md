# 洛 水 石

武则天当皇帝后喜欢祥瑞，所以经常有人献样祥瑞木，以此谋求官爵。李昭德当宰相不久，有人捧着一块白底中间有赤纹的石头进献，说是在洛水中得到的。武则天问：“它与别的石头有什么不同？”那人回答：“这石头的心是红的。”李昭德在一旁怒斥道：“这块石头心是红的，难道其他石头都是要造反的吗？”武则天和左右大臣都忍俊不禁，那人灰溜溜地退了出去。
