# 赵生诘难曹知府

明代初年，某地有个知府姓曹，自称是三国时魏王曹操 的后裔，并以此自夸。一日，当地来了个有名的戏班子，演 出《捉放曹》，曹知府也前往观看。扮演曹操的赵生，演技 高超，把曹操奸诈阴险的嘴脸表现得淋漓尽致。台下曹知府 自己觉得的祖先被侮辱，心里窝了老大的火，可又不便发 作。回府后，立即派公差去抓赵生治罪。赵生不解，公差便 如实相告。赵生听了微微一笑，从容地随公差走进官府。坐 在堂上的曹知府见赵生昂首而立，不禁拍案大怒说：“大胆 刁民，见了本府如何不跪？”赵生眼睛一瞪，说：“大胆府 官，见了曹丞相，怎不降阶迎接？”曹知府气得脸色铁青， 说：“你不过是个戏子，怎敢自称曹丞相？”赵生冷冷一 笑，说：“大人既然知道我是演戏的，那又为何当真呢？” 曹知府哑口无言，只好放走了赵生。
