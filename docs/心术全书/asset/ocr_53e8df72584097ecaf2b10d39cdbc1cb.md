# 不战术

强者通过武力而获得胜利，但这并不是真正完美的胜利，真正完美的胜利是不战而胜。正如姜子牙所说，最强大的军队，是使士兵不受伤害的军队。“不战而屈人之兵”，孙武子认为这是指导战争时应当追求的最佳结果。当然，不战是指没有战场上刀剑光影的厮杀，并不是说没有施计用谋、攻心夺志的决斗。恰恰相反，“不战而屈人之兵”，正是依赖于斗智实现的。

# 四面楚歌

楚军被围困在垓下，兵少粮尽，汉军及诸侯的军队包围了数重。夜间，随着微风，从四面八方传来了楚歌声。项羽愣了半天，颓丧地说：“难道刘邦已经打下西楚了吗？不然汉营中怎么会有这么多楚人呢？”项羽只知道刘邦的士兵大多是关中人，韩信 的士兵大多是齐、赵、燕等地的人，压根儿就没想到英布的九江兵临近楚地，大多会唱楚歌。张良便利用他们，教会了汉军。他估计楚军人心一乱，必然会大批地逃亡，便下令任何人不许阻拦逃亡的楚军将士。

楚歌传到了楚营，将士们听到家乡的歌声，勾起了思乡之情。他们眼看着内无粮草，外无救兵，谁愿意坐以待毙呢？开始还是三三两地开小差，到后来干脆整批整批地
