# ## 仲孙涍欲擒故纵

鲁庄公晚年，他的同父异母哥哥庆父为了夺取政权，杀害了国君，引起民愤。庆父又收买刺客杀死了公子般，立年仅八岁的闵公当国君，实权操纵在他自己手中，鲁闵公是齐桓公的外甥，请求齐国帮助自己。齐桓公了解了鲁国的情况后，打算派兵除掉庆父。大夫仲孙涍说：“现在庆父的嘴脸没有被世人完全看清，我们马上就出兵，会招致世人的反对，对齐国的声誉有损害。不如暂且等一等，待庆父再做恶时，齐国就可名正言顺地派兵诛杀他了。”齐桓公听从了他的建议，未对鲁国用兵。庆父见无人干涉，索性派刺客暗杀了闵公。这下子激发了鲁国臣民的愤怒，包围了庆父的住宅。齐桓公趁势派出军队，除掉了庆父，立公子申为国君。
