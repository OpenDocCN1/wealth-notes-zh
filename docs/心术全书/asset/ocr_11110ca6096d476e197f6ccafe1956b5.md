# 干红猫

南宋时，临安北门外西巷，有个卖熟肉的老头名叫孙三，他每次外出时，总要反复告诫妻子说：“好好照管好我的猫，这种猫整个都城内没有第二只，千万不要让人看见。要是有人偷走了它，那可就了去我的命了。我年老无子，这猫就像是我的儿子一样啊！”他天天这么说，可附近的人却从未有人见过他的猫是什么样的，好奇心驱使人们经常在孙三大门前徘徊，以求一饱眼福。一天，孙三的猫忽然拽着绳索跑到大门口，他的妻子急忙跑出来，把猫拖了回去。众人总算看见了，只见那猫全身火红，没有一根杂毛。见到的人又惊讶又羡慕。
