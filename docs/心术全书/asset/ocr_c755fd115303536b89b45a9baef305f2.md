# 替罪术

任何人处世都难以做到事事一帆风顺，在遇到挫折，可能产生严重后果时，可以推出-二个相关人物来抵罪，以消除危机，维护当事者的完美形象。特别是在高层的争权夺位的斗争中，往往险象环生。一旦谋划失手，谋划者就会有生命危险。在这种情况下，推出若干“替罪羊”来抵罪，就十分必要了。

# 弟弟饿死以后

西汉初年，淮南王刘长因谋反被捕，判了死刑。汉文帝为了显示宽容，改死罪为流放罪。在被流放途中，刘长绝食而死。由于他乘坐的车有很大的隐秘性，所以在他绝食期间竟没有一个人发现。行进到雍县时，县令壮着胆子启封验看，才发现刘长早已死了。汉文帝得知后，怕背上杀弟的罪名，就把雍县以前沿途的县令全都处死，罪名是由于他们不启封送食物问候，才导致刘长饿死。

# 曹操借头

公元198年，袁术发兵攻陈，曹操亲率大军援救。袁术闻知后，下令坚守不战，几个月过去了，双方还是处于对峙状态。由于曹军远离后方，时间一长，军粮发生了问题。
