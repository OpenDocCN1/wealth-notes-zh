# 析疑术

说谎人的口如同恶浪排空，奸邪人的心肠如同得了绝症。他们可以撒下弥天大谎，如同笼罩天际的毒雾，但明察秋毫，剖疑解难，就会茅塞顿开。如同太阳当空，妖魔鬼怪只好望而却步，逃窜隐匿。奸邪之人的把戏看似灵异，其实并不难戳穿。只要击中要害，顷刻间便可水消雪释。西门豹水淹女巫，林俊火烧活佛，都是大快人心之举。

# 西门豹治邺

西门豹来到邺城上任，只见田地荒芜，人烟稀少。父老们个个愁眉苦脸，唉声叹气地说：“都是为了给河伯娶媳妇才闹到这步田地啊！”西门豹听了莫名其妙，问：“河伯娶媳妇是怎么回事？”父老们便一五一十地告诉了他。

原来，邺城有一条大河，叫做漳河。每逢夏天，山洪暴发，河水经常泛滥成灾。当地有一个迷信传说，说主管漳河的水神河伯，每年都要娶一位漂亮姑娘，如果按时挑出姑娘嫁给他，他就保佑风调雨顺，五谷丰登，不然的话，他就会发脾气，兴风作浪，冲毁房屋，淹没庄稼。为了得到河伯的保佑，每到春天，巫婆就挨家挑选姑娘。看见哪个穷苦人长的姑娘长得漂亮，就让她做“河伯夫人”。然后选一个日子，把姑娘放在用芦苇编成的小船上，让水漂走。过不了多久，就没了踪影。
