# 谢安镇静鼓士气

东晋时，苻坚率前秦军准备一举灭亡东晋政权。东晋宰相谢安，派侄子谢玄为主将，迎击前秦军。由于兵力相差悬殊，将士们心存畏惧，有不少人开了小差。在这种情况下，谢安保持着若无其事的悠闲神态，即使谢玄亲自来请示迎敌方案，他也只是说：“一切准备就绪，不必担心。”

谢玄坐立不安，又派人去请示。谢安却大摆宴席，下棋取乐，好像根本不把战争当作一回事。实际上他对战争并没有肯定获胜的把握，只不过想以此消除谢玄的不安心理。在谢安的影响下，谢玄镇静了下来，他审时度势，出奇兵击溃了前秦大军，夺得了淝水之战的胜利。有趣的是，当捷报传来时，谢安只是随便地扫了一眼，就又下起了围棋。宾客问：“到底发生了什么事？”谢安淡淡地说：“没什么，只不过是小儿辈大败敌军罢了。”嘴上虽这么说，可他下完棋回屋时，再也抑制不住内心的激动，过门槛时竟把木屐折断了。
