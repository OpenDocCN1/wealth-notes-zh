# 韬 晦 术

韬和晦二字，均含有隐藏、遮掩之意。韬晦术是指在特定的形势下，把自己真实的意图隐藏起来，以摆脱困境，化险为夷，并寻机东山再起，重振雄风。当然，作为隐蔽自己真实意图的韬晦之计，还有个装得像不像，能不能使对方深信不疑的问题。使用韬晦术，自然不仅仅是为了求生，更重要的是为最后消灭对方而积蓄力量。

# 勾 践 复 国

吴王夫差一举打败了越军，越国面临着亡国的危险。越国君臣为了保住国家，留大夫文种留守国内，国君勾践带着妻子和大夫范蠡到吴国做人质。他们到了吴国后，把带来的美女和宝物分送给夫差和其他大臣。大臣们都很满意，只有伍子胥存有戒心。吴王罚勾践君臣住到阖闾坟墓旁的石屋里，专管放养马匹，还经常派人去观察他们的言行。他们穿的是破衣滥衫，吃的是糟糠野菜。勾践看马喂草，范蠡打草砍柴，勾践夫人洗衣做饭。个个安分守己，毫无怨言。夫差认为穷苦的生活已经消磨了他们的斗志，便不再提防。

三年过去了，夫差反觉得勾践君臣挺可怜，又经伯嚭讲情，便想放他们回国。由于伍子胥的反对，夫差才打消了这一念头。偏巧夫差病了，范蠡建议勾践去探病，并且乘机表
