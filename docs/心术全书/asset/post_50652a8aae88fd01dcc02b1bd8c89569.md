
# 何必冠到

战国时有个叫王登的县令，向赵襄子推荐了一个人，赵襄子连面也没见，就任命那个人当了中大夫。有人劝谏说：“您连见都没见过，为什么要急于任命呢？”赵襄子说：“提拔王登时，我对他十分了解。对于他推荐的人，我何必一定要自己见面了解呢？”

# 用人不计小过

楚汉战争时，魏无知把陈平推荐给刘邦，刘邦重用了他。周勃和灌婴等人表示反对，说：“陈平这个人外表长得仪表堂堂，其实心地不好。他在家时，同嫂子勾勾搭搭。出外后，先到魏国做事，接着到楚，不得已又归汉。到了汉军后，听说还收受贿赂。对这么一个心术不正的人，希望大王明察。”

刘邦找来魏无知，问他为什么推荐陈平。魏无知说：“我推荐的是能力，大王问的是德行。如今只讲求德行的人，对汉军有什么用呢？楚汉战争正在节骨眼儿上，大王需要的是有杰出才能的人。只要对国家有大用，勾搭嫂子，收受点儿贿赂又算得上什么大事呢？”

刘邦又找来陈平，责备他说：“你先事魏，再事楚，又归汉，反反复复，能不让人怀疑吗？”陈平说：“我为魏王做事，他不能用我的计谋。至于为楚做事，项王只知任用亲戚，对别人既不相信，也不重用，我当然要离开他。归附汉王您，是由于您能重用有才能的人。由于我刚到汉军，没有积蓄，不接受馈赠就无法生活。大王愿意用我，我就为大王效力；如果不能 用，我赤身而来，赤身而去。请大王把我收的赠金收归府库，放我走好了。”刘邦听了不仅没再责怪陈平，还给予重赏，任命他为护军都尉。从此，不再有人对陈平挑三拣四了。

# 范仲淹举才

范仲淹任用人不拘一格，如由他起用的孙威便德才兼备，为世人称道。他担任军队统帅时，选用的幕僚，大多是被贬谪的朝廷命官。这些人往往在他的幕府呆不上多长时间，就重新被朝廷起用。有人问他为什么要这么做，范仲淹说：“人既有才能，又没什么过错，这当然是再好不过的，朝廷自然应该委以重任。但那些确有可用之才，又不慎遭到非议的人，如果不给他创造机会，使其显露才华，为国家做一番事业的话，那么，他的才华就会被埋没，从而变为毫无用处的废人。这难道不是极大的损失吗？”范仲淹正是采用这种方法，为国家选拔了不少治世之才。

# 知微术

智者可以在微渺之中预见灾祸的苗头，能独自察觉得吉祥的兆头，善于触发灵机以挽救败局。知微可使人把握住契机。机遇可以降临到每一个人的身上，洞悉知微术，就能把握机遇，获得成功。反之，只能丧失转瞬即失的机遇，悔恨终生。

# 头脑清醒的伯宗娶

春秋时，晋国的大夫伯宗退朝后，眉开眼笑地回到了家。妻子问：“您面带喜色，这是为何呢？”伯宗说：“我今天上朝时，大家都夸我说话办事的才智像阳处父。”妻子说：“阳处父华而不实，会说话而没有智谋，因此灾祸临身。众人说你像他，你有什么可高兴的呢？”伯宗又说：“那就请各位大夫来饮酒，我和他们说话，你亲耳听听吧。”妻子同意了。饮酒时，伯宗又夸夸其谈，众人都称赞他口才好。客人们走后，妻子对伯宗说：“诸位大夫的确不如您，然而人们是不能长期容忍别人比自己强的，所以灾难肯定会降落到你头上。你应该赶快去找一个能够保护咱们的儿子州犁的人。”伯宗听从了妻子的话，把儿子托付给毕阳。后来，大夫们果然陷害伯宗，毕阳就带着州犁逃到楚国，避免了一场灾难。

# 郓成子预知卫国乱

春秋时，郓成子受鲁君之命出使晋国。途经卫国时，卫国右宰谷臣设宴招待他。虽然宴会厅里陈列着乐器，可并没有乐工演奏乐曲。酒酣之际，谷臣馈赠给郓成子一块玉璧。

郓成子完成了使命，归国时却不去拜访谷臣。随从说：“来的时候，谷臣盛宴招待您，可返回时您却不去拜访，这恐怕不合礼仪吧？”郓成子说：“你说的我何尝没想到。上次谷臣设宴，目的是想结交我。陈列着乐器不演奏，是暗示他他有难言之忧。酒后送我玉璧，是一旦发生变故，托我保护他的家族的意思。我料想卫国可能要出大事。”果不出所料，郓成子离开卫国还不到三十里，宁喜发动政变，谷臣被乱军所杀。

得知这一消息后，郓成子当即返回卫国，把谷臣的亲属接到鲁国，不仅安排了住处，还拿出自己的俸禄供养他们生活。等谷臣的儿子长大成人后，郓成子把玉璧还给了他。

# 公孙鞅自料不死

公叔痤病危时，魏惠王亲自前来探视，问：“先生百年之后，国家大事如何安排？”公叔痤说：“我这里有一个叫公孙鞅的人，才智不凡，可把军国大事交给他管理。大王如果觉得不合适，就把他杀掉。免得别的国家重用了 他，对魏国不利。”魏惠王不以为然，嘴上不说，心里却觉得公叔痤已经糊涂了。

惠王走后，公孙鞅来看望公叔痤。公叔痤就把对惠王说的话向他说了一遍。不久，公叔痤死了。魏惠王没有起用公孙鞅，公孙鞅也没有准备逃走的心思。有人知道公叔痤对惠王说的话，劝公孙鞅赶快离开魏国。公孙鞅却毫不在意，专心办理公叔痤的丧事。当别人问他为什么不怕死时，公孙鞅不屑一顾地笑着说：“惠王既然不听从公叔痤的话重用我，又怎么会听信他的话杀害我呢？”后来，公孙鞅到了秦国，受到秦王的重用。他变法图强，使秦国很快强大起来，为灭亡六国打下了坚实的基础。由于他被秦王封在叫商的地方，因而又称为商鞅。

# 任安的预见

秦康公下令修建高台，三年未能完工。突然间，社会上风传楚国将要兴兵伐齐。任安听说后，急忙去拜见秦康公，说：“一个国家，如果出现严重饥荒，或者百姓过于劳累，那很容易招致别国的来犯。您修建高台已经三年了，楚国在这种情况下声言要进攻齐国，恐怕他们的真实意图是要进攻秦国。我们应当多加提防才是。”秦康公认为他的话很有道理，就加强了东南部边境的防守。楚国果然打算进攻秦国，见秦国有准备了，就放弃了原来的打算。不久，楚国将要攻齐的传言就销声匿迹了。

# 老毋扫坟

汉朝人严延年任河南太守时，动辄杀人，外号叫“屠伯”。母亲从东海郡来看他，正赶上他判决杀人。母亲感到吃惊，便住在都亭客舍，不肯进儿子的门，责备他说：“天道神明，决不可随意杀人。我可不愿在年老时，看见自己的儿子上断头台。我这就回东海清扫墓地。”随后，不顾严延年的苦苦相劝，径直回东海去了。过了不到一年，严延年就获罪被杀。东海一带的人，都说严延年的老母见识过人。

# 夏侯玄识司马氏

三国时，魏中书令李丰见司马懿权倾朝野，准备让夏侯玄取代他。司马懿看出了李丰的用心，就把他杀了，并把夏侯玄关进了监狱。因夏侯玄名声很大，关了一段时间就放出来了。为了躲避司马氏的陷害，夏侯玄出狱后很少与人交往，也不再写文章。司马懿死后，许允对他说：“这回你该没什么忧虑了吧？”夏侯玄苦笑着说：“恰恰相反。司马懿还能顾全名声，不会对我轻易下手。至于他的两个儿子司马师和司马昭，是不可能容下我的。”果然，没过多久夏侯玄就被杀害了。

# 冰城

北魏别将司马楚之督运军粮，柔然想袭击他。一天，侍从报告说一头驴的耳朵被人割掉了。司马楚之说：“这肯定是敌军奸细到我们军营里侦察虚实，割下驴耳朵做为凭证，回去报信去了。过不了多久敌军就会来袭击我们，应该赶快准备战斗。”于是下令把粮草集中起来，用柳树枝条编成城的骨架，然后浇上水。水很快结成了冰，成为一座冰城。冰城修好不久，柔然的军队就赶到了。冰城既坚固又很滑，柔然攻不进去，只好撤走了。

# 万二听诗散财

明代洪武初年，嘉定安亭有个叫万二的人，是元朝的遗民。他家资巨万，是郡内数一数二的大富豪。一天，有个人从京师回来，万二向他打听在京师的所见所闻。那人说：“别的都没什么，只是说皇上最近作了一首诗，诗中说：‘百僚未起朕先起，百僚已睡朕未睡。不如江南富足翁，日高丈五犹披被。’”万二听后叹了口气，说：“已经出现预兆了。”众人谁也不明白他说的是什么意思，因而都没在意。万二就把家产委托给几个能干的管家经营，自己则带上妻子儿女泛游湖湘，过着悠闲的生活。不到两年，江南富豪大多被朝廷抄家，没收了财产。万二的家业不仅没受影响，反而因经营有方，越来越兴旺。

# 和珅猜中文题

顺天乡试，《四书》文题必须钦定。出题前，由内阁进呈《四书》一部，待皇帝命完题，再拿回来。乾隆乙酉乡试，阉宣捧着《四书》送还内阁时，和珅有意搭话，探问清高宗命题的情形。阉宣说高宗在批阅第一本至后半部分时，忽然笑了起来。随即挥毫疾书，拟定了文题。和珅嘴上不说，心里已经猜出文题是“或乞醯焉”一章。盖因“乞醯”二字中能拆出“乙酉”二字。和珅为人聪明绝顶，他见清高宗喜欢搞文字游戏，便用拆字的方式，猜中了文题，而后悄悄地告诉了门生。由于早有准备，那年乡试他的门生全都高中。

# 心力术

智慧是心力赖以产生的土壤，而心力则是智慧的妙化。没有智慧而去大谈心力，如同演木偶戏，虽然千变万化，只不过是供人嬉笑罢了。没有心力而去谈智慧，正如同车夫和船工，自以为技术高超，一但遇险就会束手无策，不翻车沉船才怪呢。值得注意的是，心力不是一成不变的，它灵活多样，变化无穷。心力的出神入化，可以说是智慧得以充分发挥的标志。

# 卓文君卖酒

司马相如琴挑临邛富人卓王孙寡女卓文君，两人私奔回成都。可家里什么也没有，无法维持生活。两人合计了一番，又返回了临邛。卖掉车马首饰，在卓府对面租了房间，夫妻俩开店卖酒。卓文君在外边卖，司马相如在里边做杂务。卓王孙本来就不同意这门亲事，十分生气。见他俩在大门对面开酒店，这火就更大了，命人关上大门，改走侧门。可这毕竟不是长久之计，经人多方劝说，他分给卓文君一百个奴仆，一百万钱。司马相如和卓文君达到了目的，高高兴兴地回成都去了。

# 望梅止渴

东汉末年，曹操率军远征张绣。路途中，天气炎热，没有水源，将士们渴得嗓子直冒烟，一个个无精打采。曹操怕影响士气，用马鞭子指着前方，说：“快走啊，前面有一片梅树林，树上结满了青梅，又甜又酸，好吃极了！”将士们听了，满嘴直流口水，个个精神焕发，行军速度明显加快了。不久，部队就到了有水的地方。

# 孙坚装病杀张咨

孙坚出兵讨伐董卓，行至南阳时，已经招集了数万人的军队。他派人送信到南阳，让太守张咨提供军粮。张咨不屑一顾地说：“他孙坚也不过是个两千石的官儿，同我职位一样，哪有资格让我出粮！”于是拒绝了提供军粮的要求。孙坚又想当面和他谈一谈，也被拒绝了。孙坚想，我刚刚起兵，就遇到阻力，不给点颜色瞧瞧，怎么能确立威严？就装做得了急病，危在旦夕。全军上下，人人恐慌。有的去请巫医，有的求山川神灵保佑。孙坚秘密派遣心腹去见张咨，说等孙坚死后，军队听从他的指挥。张咨一听乐得眼睛都睁不开了。为了在孙坚死后能顺理成章地接收兵权，他率领五百军卒，抬着酒肉，前来看望孙坚，犒劳军队，想以此收买人心。孙坚把张咨请进军营，卧床接待他。过了一会儿，孙坚又设酒宴招待张咨。酒酣之际，孙坚递了个眼色，长沙主簿报告说：“南阳一带的行军道路没有修好，军队使用的物资也没给准备。太守张咨阻拦义军，使义军不能按时讨贼，请按军法处置。”张咨大惊失色，起身想逃走。这时伏兵四起，把他抓住绑了起来。孙坚宣布了张咨的罪行，就把他斩首了。听说太守被杀，南阳郡官民无不震惊。孙坚军队所到之处，有求必应。有的郡县甚至提前准备好粮食，等待着孙坚率军到来。

# 自首

后周时，雍州有几户胡族人家被一伙强盗洗劫了。胡族人家报案到县衙、郡府，官府查不出，他们的左邻右舍都被诬为嫌疑犯和通匪犯，关押了起来。雍州别驾柳庆不赞成这样做，主动请求接受此案的审理工作，郡府同意了。

柳庆授意文书写了一封匿名信，誊写了数份张贴在衙门口。信上说：“我们参与抢劫的同伙，人员复杂，各有各的想法。日后难免要泄露出去，那时罪就大了。现在我等都想自首，但怕受到官府的惩罚。如果官府能不惩罚自首的人，我们就来自首。”

第二天，柳庆又以官府名义贴出了一张通告，晓示自首者可以免罪；不自首而被捕获者，严惩不贷。

几天后，广陵人王欣的家奴，自缚来州衙报案，并供出同伙多人。没几天就把犯罪分子全部抓获归案，被拘禁的乡邻才得以获释。

# 张易先发制人

张易在颍州做通判时，刺史宋匡业经常借酒耍狠，动辄打人，有时甚至借酒杀人。可因为他是刺史，没有谁敢说什 么。一次，张易去参加宴会，得知宋匡业也参加，就故意事先喝得有几分醉意。到了宴会上，张易找了个宋匡业的小过失，借故大发脾气。他摔碎酒杯，掀翻桌子，厉声责骂宋匡业借酒耍疯。宋匡业很害怕，只是说：“您喝醉酒使性，真是厉害啊。”张易并不算完，骂骂咧咧地走了出去。从此，宋匡业因畏惧张易，再也不敢耍酒疯了。

# 令狐楚降粮价

兖州久旱不雨，富豪乘机囤积粮食，造成粮价大幅度上涨。恰在这时，令狐楚被派往兖州任职。他向前来迎接的官吏和乡绅了解了以前的粮价是多少、州内有多少粮仓、仓内有多少存粮等问题，然后弯起手指算了一会儿，当着众人的面，自言自语地说：“从前米价是这么多，仓里有这么多米，拿出定价出售，粮价就会大幅度下降。”迎接的人“偷听”到这一消息，急忙告诉了城中的富豪。富豪们怕粮价下跌吃亏，争相开仓售粮，粮价很快趋于平稳。

# 大国的气度

南唐主派人送给宋朝宰相赵普五万两白银。赵普觉得不好处理，就把此事告诉了宋太祖赵匡胤。赵匡胤说：“这不能不收，但要写一封信表示答谢。同时，还要少许贿赂一下他们派来的使者。”赵普辞行时，赵匡胤又说：“做为大国的气度，不能自行削弱，应当使小国感到捉摸不透。”及至南唐主的弟弟李从善出使宋朝时，除了正常的赏赐之外，又秘密送给他五万两白银，数额与送给赵普的相同。南唐君臣对赵匡胤的做法无不震惊，叹服他的大国气度。

# 吴柔胜辩诬

宋代人吴柔胜出仕蔡州知州时，因盗贼猖獗，他就让百姓建立了保伍联防的组织。不久，盗贼便纷纷被捉获，百姓安居乐业。一年春天，不少蔡州百姓聚集在确山做佛事，有个别有用的人到京师告状，说蔡州有伙强盗占据确山，并列出了十个“贼首”的名单。皇帝便派得宠的宦官赶往蔡州，督促捉拿。宦官到了蔡州，就急不可耐地催促吴柔胜出兵。吴柔胜说：“您是想借用军队显示威严呢，还是想捉拿盗贼呢？”宦官说：“当然是想捉拿盗贼。”吴柔胜说：“我管理蔡州，虽然算不上机敏，也不至于对境内有上千人聚集闹事而充耳不闻。如今派兵前往，是逼着百姓谋反。确山上的确有不少人，不过他们是些聚集在一起做佛事的老百姓，目的是想赚些钱财。想让他们中的哪一个来，不过是百手之劳。”于是，他每天陪同宦官饮酒，不再提这件事。举密派那十个被点名捉拿的“贼首”主动赶到京师向皇帝说秘了实情。皇帝这才感悟到有人故意栽赃陷害，就把那个诬明的人治了重罪。

# 墨水吓退元俨

宋真宗因病卧床不起，八大王元俨素有威名，借口问病，在宫中住了下来，居心叵测。宰相李迪忧虑不安，可又不能公开赶他走。一天，李迪见翰林司用金盂端着热水去送给元俨饮用，就故意用笔甩进一些墨汁。然后让翰林司送去，什么也不要说。元俨见水不干净，怀疑有人下毒谋害，赶忙离开了宫禁。

# 韦孝宽预察

皇帝下诏免去尉迟迥相州总管职务，派韦孝宽去接替他，并任命小司徒叱列长文担任相州刺史。韦孝宽让叱列长文先走几天，自己随后赶到。当韦孝宽行至朝歌时，尉迟迥派大都督贺兰贵，带着他的亲笔信，赶来问候韦孝宽。韦孝宽读了信，觉得不对劲，就有意与贺兰贵交谈起来。通过交谈，他怀疑尉迟迥要谋反。于是以有病为托辞，在驿站住下观察动静，并派人到相州以求医买药为名，秘密探听消息。几天后，先行的叱列长文逃了回来，带来了相州谋反的消息。韦孝宽弄明白了情况，便打马回返。他下令拆毁沿途所有的桥梁，并把驿站的马全都牵走，还吩咐驿站的管理人员说：“尉迟大人要来了，你们要多准备酒菜迎接。”几天后，尉迟迥果然派出几百名骑兵追赶韦孝宽。追兵们一路上因贪吃驿站的酒肉，再加上桥梁被毁，没有替换的马匹，所以未能追上。

# 朱丹溪救农民

元朝时，义乌名医朱丹溪一次出诊，见一个无赖抡起扁担向农民的后背打去。农民惨叫一声，倒在地上。当无赖再次抡起扁担时，朱丹溪飞步上前挡住扁担，朝农民后背踢了一脚，对无赖说：“您就高抬贵手，别跟他一般见识了。”无赖见占了便宜，扬长而去。围观的人议论纷纷，倒在地上的农民也站起身责骂朱丹溪。朱丹溪笑盈盈地说：“先不要骂，我问你，刚才倒地时是不是下肢麻木？”农民点点头。又问：“现在呢？”农民说：“不麻木了。”朱丹溪这才说出了原委：“刚才的一扁担，致使你腰椎移位。如不及时复位，有可能造成瘫痪。我踢你一脚，实际上是为你复位。”农民这才恍然大悟，跪在地上，答谢神医。

# 王守仁写绝命词

王守仁因上疏营救御史戴铣，触怒了大宦官刘瑾。受过廷杖后，被贬谪到贵州任龙场驿。王守仁素知刘瑾心毒手辣，就换上便服，日夜兼程前往。过江时他作了《吊屈原文》表明心志，接着又写了首绝命词。然后让下属传出话，说他已投江身亡。绝命词传到京师，刘瑾看了还是不解心头之恨，打算派遣刺客在小道上刺杀王守仁。及至听到了王守仁投江身亡的传言，才停止了刺杀行动。王守仁用的计谋与公子小白是一样的啊！

# 仇钺装病破敌

明代正德五年安化王寅镛谋反，任游击职务的仇钺身陷叛军之中。京师不少人传言仇钺已经从贼谋反，兴武营守备保勋为外应。李文正说：“我敢断言，仇钺决不会从贼叛乱。至于保勋，是因为他同寅镛是儿女亲家，所以有人怀疑。朝廷如果信以为真，那么众多与反贼有亲朋故交关系的人，谁还敢投奔朝廷？”于是荐举保勋担任参将，仇钺担任副职，责成他俩共同讨贼。保勋接到任命，感激朝廷的知遇之恩，奋力作战。仇钺则佯装有病卧床不起，秘密串通一些对谋反不满的人做内应，等候保勋大军到来。他还派人劝谋反将领何锦说，应该马上出兵守卫渡口，以防保勋大军决堤灌城。何锦果然中了调虎离山计，率领精锐部队守卫渡口去了，城里只剩下另一贼将周昂守城。仇钺又传出话，说病情恶化，危在旦夕。周昂听说后赶来探病，仇钺趁其不备，一铁锤把他打死在病榻边。接着，仇钺起床更衣，披甲仗剑，骑马出门。他振臂一呼，串通好的人齐声响应。他们迅速攻占城门，生擒宣镛，平定了叛乱。

# 决断术

决断术的特征是先下手为强，与一般行为相比，有以下几个显著特点：决策与行动的敏捷性；行动具有魄力；坚决果断，给人印象深刻；先发制人；控制对手；出其不意。在不给对手以思考的余地这一点上，决断术有着奇效。若是让对手得以仔细思考，你就难以制胜。只有快速决策，迅猛出击，从气势上、心理上压垮对手，才能出奇制胜。

# 槌击玉连环

秦王派人到齐国，送给齐襄王田法章的王后太史氏一个玉连环，并且说：“听说齐国人很有智慧，能解开这个玉连环吗？”太史氏看出了秦王取笑自己的用心，什么也没说，取过一把槌子，将玉连环砸了个粉碎，然后对使者说：“已经解开了。”

# 当机立断的杨敞妻

西汉时，曾一度立昌邑王刘贺当皇帝。因他贪淫好色，大将军霍光和张安世商量，打算废掉刘贺，另立（匈）询当皇帝。商量好后，二人大司农田延年去通报杨敞，听取他的意见。杨敞见事关重大，又惊又怕，不知道说什么好。田延年见他汗流浃背，借口出去更衣，让他清醒清醒。杨敞的妻子见状心里很着急，从东厢房里跑过来，对他说：“这是关系国家安危的大事，如今大将军考虑已定，派大司农来通报你。你如果不马上表示赞成，同意大将军的安排，而是犹豫不决，恐怕要先被灭族啊！”杨敞如梦初醒，等田延年更衣回来，立即表示了赞成的态度。

# 司马懿平叛

魏明帝太和元年，魏国新城太守孟达准备谋反。司马懿得到密报，心想如要奏明魏明帝，然后平叛，往返需一个多月，而军中粮食仅可维持一个月左右。再说叛军经过一个月的准备，又加上粮草充足，将很难对付。于是，司马懿在未接到进军命令的情况下，率军秘密出击，昼夜兼程，仅用了八天时间，就赶到了叛军占据的上庸城下。叛军由于准备不足，城墙未固，在占优势的魏军的强攻下，军心动摇。孟达的外甥邓贤和部将李辅等人开门出降，魏军冲进城去，杀死孟达，消灭了叛军。

# 玄武门事变
