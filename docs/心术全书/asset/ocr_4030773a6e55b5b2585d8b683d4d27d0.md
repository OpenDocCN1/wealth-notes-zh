# 陈平劝萧何

吕后采用萧何的计策诛杀了韩信，刘邦便派使者拜萧何为相国，加封五千户食邑，并派一名都尉率领五百名士卒做他的侍卫。同僚们知道后，纷纷前来祝贺，陈平却说：“我看灾祸不远了。皇上在外奔波，而让您守卫京城，既无风吹日晒之苦，又没被流石飞箭夺去生命的危险。他反倒对您大加封赏，增加您的卫队，这可不是好兆头。皇上心里想的是，韩信能谋反，你萧何也不那么可信。要想平安无事，你应该把皇上的封赏让出，侍卫退回，还要把家产拿出资助军队。”萧何照他说的做了，刘邦果然很高兴。

# 卫青避嫌

大将军卫青出兵定襄，部将苏健、赵信率先头部队三千余骑兵与匈奴大军遭遇。激战了一天，终因寡不敌众，三千兵所剩无几。赵信见大势已去，就投降了匈奴。苏健拼死冲出重围，单枪匹马回到大营。议郎周霸说：“大将军自出骑兵，还未曾杀败将。现在苏健抛弃士卒，擅自逃归，正可斩首示众，以明军威。”随军长史说：“我看不能这样。苏健数千兵马，遭遇匈奴数万军队。苦战一天，将士都不敢有二心。兵败后侥幸逃回的人就斩首，那么以后兵败，谁还敢回来？只好去投降敌军了。军队有这种想法，怎么能作战呢？”卫青说：“我忠心报国，不怕军队没有威严。周霸劝我斩首部将，我觉得当臣子的不应这么想。对于苏健，我既不敢断然处死，又不敢随意赦免。把他押送到京师，由皇上去裁决吧。”于是，用囚车把苏健押送到京师，汉武帝果然赦免
