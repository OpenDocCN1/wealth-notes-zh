# 曹操‘梦’中杀人

曹操曾说：“在我睡觉时，任何人不要靠近我。我有梦中杀人的毛病，杀了人自己也不知道。”下属们对这些话深信不疑，一见曹操睡了，都离得远远的，谁也不敢靠近。一天，曹操假装睡觉，故意把被子蹬到了地上。有个得宠的人怕他着凉，悄悄地上前给他盖被子。不料曹操翻身跃起，挥刀杀死了那个人，然后回到床上，继续“睡觉”。一觉“醒”来，他故作不知，问：“是谁杀了我的侍从？”从此，在他睡觉时，再没人敢到跟前了。

# 李林甫暗算严挺之

严挺之为人正直，遭到李林甫的忌恨，被贬官为绛州刺史。过了一段时间，唐玄宗对李林甫说：“严挺之现在什么地方？这个人可以重用。”李林甫当时支吾着没说什么，下朝后马上找来严挺之的弟弟严损之，说皇上很惦念他的哥哥，不如趁此机会奏称严挺之中了风，请求皇上准予回京治病。皇上一高兴，兴许把他留任京官。严损之马上派人送消息给严挺之。严挺之听信了李林甫的话，向玄宗递交奏章，请求回京治病。李林甫趁机对玄宗说：“严挺之年事已高，又得了风疾，应任命他担任闲职，以便养病。”玄宗照他说的做了，任命严挺之担任了詹事官。
