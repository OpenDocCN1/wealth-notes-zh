# 惩 恶 术

惩治恶人是件大快人心的好事，可并非易事，需要掌握较高的技巧。恶人作恶，无论他装扮得多么道貌岸然，总会留有破绽。破绽大体呈现两种形态：一种是作恶时留有明显的漏洞，一眼就能看出作恶者的丑恶面目；二是虽无大的纰漏，但通过认真地观察分析，还是可以察觉到作恶者的险恶用心。要识别并惩罚作恶者，除了要了解其根底与真"相"外，还应具备从作恶者的言行中直接或间接发现破绽的能力，以便掌握主动，严惩恶人。

# 侮 辱 宦 官

西汉人爰盎为人正直而识大体，宦官赵谈自恃深得皇帝的宠爱，时常想陷害爰盎，他为此忧心忡忡。哥哥对他说："你如果能当众侮辱赵谈一次，以后即便讨厌你，也不敢再说什么，皇上也不会再听信。"一天，爰盎见皇帝打算让赵谈陪同，乘车到东宫去，就跪在车前对皇帝说："我听说能与天子共同乘车的人，都是天下的英雄豪杰。当今我们大汉朝就算没人才，陛下也不应同一个被阉割了的人坐在一起。"皇帝听了大笑，把赵谈赶下车去。从此，赵谈再也要不起来威风了。
