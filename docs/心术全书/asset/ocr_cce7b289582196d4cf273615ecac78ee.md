# 冯当世难倒王安石

冯当世很器重王定国，王安石却极力压制他。一天，冯当世向宋神宗举荐王定国时，王安石说：“王定国还是一个不懂事的孩子，怎么可委以重任呢？”冯当世大怒，吼道：“王定国是戊子年生的，怎么能是个孩子呢？”原来宋神宗也是戊子年生，冯当世故意强调戊子年生，意在你王安石既然说戊子年生的王定国是无知的孩子，那不就等于说宋神宗也是个无知的孩子吗？难怪王安石听了冯当世的话，吓了一跳。默默地退了出去。

# 徐达佯醉破敌

朱元璋打败陈友谅后，调兵东下，派徐达去进攻泰州。泰州守将史彦忠见兵势浩大，不敢出战，一面请求救兵，一面据城固守。徐达兵临城下后，每日派人叫骂挑战，史彦忠始终坚守不出。徐达无奈，命在城南七里处扎下大营。双方僵持了一段时间，春节即将来临。徐达传令，全军将士在军营里欢度春节，从除夕之夜开始，全军解甲弃兵，饮酒作乐。敌军探子报知史彦忠，他大笑着说：“徐达枉称大将，土包子性难改，这么闹下去，军队还有什么斗志？我何必再等援军，自己就可以消灭他们。”话虽这么说，他还是不放心，派儿子史义去探听虚实，诈称要献城投降。
