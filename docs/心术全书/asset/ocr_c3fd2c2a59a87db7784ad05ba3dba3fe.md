# 徐氏报夫仇

吴国孙权的弟弟孙翊担任丹阳太守时，妫览任都督督兵，戴员任部丞，他们关系十分密切。部将边洪等人一向恼恨孙翊，一次趁他送客，边洪从身后一刀杀死了他，然后逃进了深山。孙翊的妻子徐氏重金招募人去追捕。捉到边洪后，就把他杀了。妫览见孙翊已死，便进入军府，霸占了孙翊的所有侍妾和奴仆，进而还想霸占徐氏。徐氏怕拒绝遭到毒手，就骗妫览说：“请你耐心等几天，等过了月末最后一天，脱掉丧服，我就依从你。”妫览见她说得恳切，就答应了。徐氏悄悄派人找到孙翊的心腹部将孙高和傅婴，向他们诉说了孙翊一家的不幸。孙高和傅婴听得痛哭流涕，发誓要替孙翊报仇。月底那天，徐氏祭祀完毕，便脱去丧服，薰香沐浴，换上华丽的服装。还命人布置了新房，挂上崭新的帏帐。她佯装高兴，时不时地还开怀大笑。妫览在隐蔽处窥探了许久，不禁心花怒放，打消了疑虑。徐氏命孙高和傅婴换上便装，与奴仆婢女混杂在一起，站在大门内外列队恭候，然后派人去请妫览。妫览早就急不可耐了，连忙跟了进来。徐氏见他进了大门，从屋里出来拜迎。妫览正要还礼，徐氏双眉倒立，大喝一声，孙高和傅婴同时跳出，手起刀落。可怜妫览还未从美梦中醒来，就已做了刀下鬼。与此同时，门外的其他兵士杀死了戴员等人。徐氏见大仇已报，便重新披麻戴
