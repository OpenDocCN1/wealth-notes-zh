# 谁是纵火犯

南朝梁长沙宣武王死了，将要出葬时，东府仓库着起大火，损失惨重。府中一时议论纷纷，不少人要求严惩管理仓库的官员。有些平时有矛盾的人，想趁机打击对方。一时间闹得人心惶惶。御史中丞乐蔼说：“从前晋朝的兵器库着了火，张华认为是仓库中存放的油犸过多，引起自燃。现在要紧的是检查一下仓库里有没有积灰，如果有，就说明是自燃，不是管理仓库的官员的过错。”在清理着火现场时，果然发现了积灰。

# 御史明辨诬告信

唐朝初年，李靖任歧州刺史。有人密告他要谋反，唐高祖李渊派御史前往调查。御史看了密告信，认定是诬告，但不说破，定要告密人一同到歧州调查。过了几个驿站，御史突然做出吃惊的样子，愤怒地鞭打随行的典吏。然后陪着笑脸对告密人说，典吏一时粗心，没带密告信，请他重新写一封。告密人只好重新写了一封。御史把两封密告信对照着看，发现出入很大，便返回京城，报告了李渊。李渊大吃一惊，下令审讯告密人。他承认了诬告的事实，被处死了。
