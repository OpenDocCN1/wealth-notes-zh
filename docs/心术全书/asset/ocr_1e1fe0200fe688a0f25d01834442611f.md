# 张说的女儿求官

唐朝宰相张说的女儿嫁给了姓卢的人。一次，他回家替公公求求官，张说听了一句话也没说，只是指了指垫床腿的小石龟。女儿听了很高兴，回家对丈夫说：“公公得了詹事官职了！”詹事的职责是掌管宫中皇后和太子的家事。不久，她的公公果然当了詹事官。
