# 辞例外赏赐

宋英宗即位后，为了拢络人心，遍赐大臣礼物。枢密使富弼领完了自己应得的一份，宋英宗又派小黄门给他送去一份。小黄门说：“这是皇上的例外赏赐，请您接受。”富弼说：“大臣如果接受例外赏赐，那么皇上例外行事又该如何制止呢？”遂拒绝接受。

# 吕夷简虑远

宋真宗的妃子李氏，是宋仁宗的生母。她的儿子被太后夺去做了自己的儿子，与杨太妃合养。李氏为了儿子的安全，忍辱偷生，与宫女住在一起，过着同一般人没什么两样的生活。由于人们害怕太后，没有人敢提及此事，所以，宋仁宗虽一天天长大了，却始终不知自己的生母是李氏。

李氏病危时，才从顺容进位到宸妃。她死了以后，太后想以宫人的礼仪治理丧事。宰相吕夷简上奏说：“丧礼理应 从厚。”太后不理，领着宋仁宗回到内殿。过了一会儿，她独自回到帘下，询问吕夷简为什么要这样，他说：“臣下是 待罪宰相，事情不分内外，都应当过问。”太后动了气， 说：“你难道想要离间我们母子吗？”吕夷简说：“太后如 不以赵家为念，我就不好再说什么了；如果还能为大宋前途 着想，那还是从厚治丧才显得稳妥。”太后猛然醒悟，同意 以一品夫人的规格治丧。吕夷简又对皇宫都知罗崇勋说： “应当给宸妃穿上皇太后的衣服，入殓时以水银充实棺椁。 你要是不这么做，日后可不要说我没吩咐。”罗崇勋不知如 何是好，连忙报告了太后，太后也表示同意。
