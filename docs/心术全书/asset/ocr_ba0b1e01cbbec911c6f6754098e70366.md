# 后记

心术是智慧妙化的结晶，伴随着人类社会实践和思维的发展而发展。一部漫长的人类社会史，也是一部心术的创造史和实践史，无时无刻不闪烁着智慧的灵光。心术是调控人际关系最重要的技巧，社会竞争，说到底是心术之争，人们无不梦寐以求自己拥有深谋远虑的本领。

绵绵几千年，不知有多少圣贤哲人试图设计出人类生存智慧与处世哲学的理想模式，然而最终都陷入困惑之中。历览汗牛充栋的典籍，大都板着冰冷的面孔，喋喋不休地讲：“怎人做人”，具体地指点人们“遇事应该这样”的却如凤毛麟角。书上讲的是仁义，而处世需要的是心术。两者实在难以统一，难怪在中国读书与交际能力往往不成正比。《心术全书》正是为消除这一戛弄人生的怪圈而做的尝试，旨在为懦夫增勇，警懒汉发奋，促愚夫茅塞顿开，助智者如虎添翼。

参加本书撰写工作的还有：舒芳、李岩、艾春光、伊琳、周斌、焦野萍、包涵、田梦。
