# 自 残 术

自残逆人之常情，行自我伤害之举，是以血和泪为代价，达到取信于人的目的。有的假装自己内部有矛盾，打入敌方内部；有的为了陷害他人，不惜自我折磨；有的为了保全自家性命，摆脱险境，装疯卖傻。综观种种，要紧的是取得对方的信任，才有成功的可能。万一被对方识破，反倒弄巧成拙，甚至白白送了性命。

# 要离刺杀庆忌

庆忌为了给父亲姬僚报仇，逃往艾城，招纳死士，结连邻国，想寻找机会进攻吴国。吴王阖闾为此食不甘味，忧心忡忡，伍子胥向他推荐了一名叫要离的壮士。要离宁可牺牲自己，也决心帮助吴王除掉庆忌。三人商定后，阖闾使苦肉计，找借口砍掉要离的右臂，囚系狱中。伍子胥则偷偷派人将他放走，阖闾又将要离的妻子儿女全部杀死。

要离逃出吴境后，一路上讲述自己的冤仇，去投奔庆忌。庆忌开始不愿接纳，派人到吴国打听了一番，得知要离全家确实被杀，才不再有怀疑，让他当了自己的部下。要离对庆忌说，伍子胥和阖闾不和，自己被关押时，就是伍子胥将他放走的，并说伍子胥愿意做庆忌复国的内应，帮助除掉阖闾，同时鼓励庆忌尽快伐吴。庆忌信以为真，就整顿军
