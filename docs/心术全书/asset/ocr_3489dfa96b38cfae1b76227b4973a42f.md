# 吴郡卒撒酒疯

苏峻发动了武装叛乱，当时庾冰任吴郡太守。见叛军声势浩大，郡吏和兵卒各奔东西，一哄而散。只有一个郡卒没跑，他找来一条小船，让庾冰藏在里面，上面堆积了些柴草。几天后，小船划到了钱塘江边。此时，苏峻重金悬赏捉拿庾冰，各地搜查很严。郡卒把船划到柴草市场，告诫庾冰不要动，自己拿着船桨上岸去了。过了一会儿，只见他喝得大醉，挥舞着船桨向小船走来，一边走一边说：“不就是找庾太守吗？就在我船上，没错！”庾冰在船上听得一清二楚，吓得浑身直冒冷汗，一动也不敢动。捕吏开始以为郡卒说的是真话，急忙聚拢来要搜船。及至看见是条小船，便认为郡卒是说醉话，不再有什么怀疑。郡卒故作跌跌撞撞地回到船上，把船划到江对面，庾冰终于脱离了险境。
