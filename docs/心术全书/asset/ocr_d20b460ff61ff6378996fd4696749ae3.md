# 官印失而复得

唐宪宗时，裴度被封为晋国公，任中书令。一日，手下人突然报告说官印丢失了。裴度一点儿也不慌乱，和颜悦色地告诉下属不要声张。当天晚上，他设宴与众人畅饮。半夜时分，手下人附耳告诉他说官印又回来了。裴度什么也没说，依旧饮酒不止，直到尽兴方才罢宴。有人问丢失了官印为何不着急，他说：“官印肯定是让掌管案牍的官吏私自拿去干不正当的事去了。我如果追得紧，他们就可能把官印销毁或投入水中，那就再也无法找到了。我有意延缓一下处理，是料想他们用完后，会悄悄地送回来。”

# 军营夜火

王驟任益州知府时，有几个戌卒夜间在军营里放起大火，想以此制造混乱。王驟得知消息后，马上派兵把军营围了个水泄不通，并且传令说：“不想谋反的人，举起双手出来，没任何事。”于是，众戌卒都走出了军营，制造事端的戌卒也夹杂在其中。见戌卒都出来了，王驟让知晓闹事详情的军校把制造事端的戌卒指了出来，共计十来个人，王驟当即把他们处死了。军营很快恢复了正常，好像什么事都没发生过。
