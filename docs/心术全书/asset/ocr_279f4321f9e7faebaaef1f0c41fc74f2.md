# # 智留七宝鞭

有人密报王敦要谋反，晋明帝换上便服，亲自到军营中观察了解。离开时，有个军官认出了他，慌忙报告了王敦。王敦正在睡午觉，听说晋明帝前来探营，又急又怕，派出五个人骑马追赶。晋明帝发现有追兵，闪进一家杂货店，对卖货的老太太说：“我这把鞭子叫七宝鞭，价值连城，现在送给你。追兵来到后，你就说我过去半天了，并且把鞭子拿给他们看。”说完，便骑马飞驰而去。不一会儿，追兵赶到了，问老太太见没见着一个骑马的人。老太太说：“早就过去了。”说着，把七宝鞭拿给他们看。追兵你传我，我传你，都爱不释手，逗留了很长时间才上路追赶，晋明帝早就返回宫中 了。

# # 敢向尊前不尽心

五代时的小诗人李升，很早就失去了父母，孤苦伶仃，到处流浪。后来被徐温收为养子，改名叫徐知诰。

他知道养子的地位是没有保障的，随时都有被抛弃的可能，正像一盏小油灯的灯火随时可能被突如其来的风吹灭一样。于是他借《咏灯》为题，把自己埋藏在心底的忧郁和愿望，委婉曲折地表达了出来：“一点分明值万金，开时惟怕冷风侵。主人若肯勤挑拨，敢向尊前不尽心。”意思是说小小的灯火虽然能放出光亮，但它太弱了。主人如果经常添油剔蕊，那么小小的灯定会为主人放出全部的光。徐温看了这首诗，为李升的才华折服，给他提供了优越的学习条件和生
