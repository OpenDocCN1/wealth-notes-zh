# 魏文侯信任乐羊

魏文侯准备攻打中山国，翟璜推荐乐羊做大将，说他足智多谋，善于带兵。可也有人反对，说：“乐羊的儿子乐舒在中山国当官，只怕他痛爱儿子，不能尽力。”翟璜说：“乐羊可是一个忠心报国的人。乐舒曾经替中山国君请乐羊去做官，乐羊认为中山国君荒淫无道，不但自己没去，还劝儿子离开。可见他是很有见地的。”文侯把乐羊找来，问他说：“我打算派你率军进攻中山国，可你儿子在那里当官，你该怎么办？”乐羊说：“大丈夫为国家建功立业，攻不下中山，甘受处罚。”魏文侯就派他为大将去攻打中山。一连几仗，中山兵大败。魏兵长驱直入，一直打到中山国的都城，围得水泄不通。中山国君十分害怕，一面加紧防守，一面逼着乐舒劝说乐羊停止攻城。乐舒无奈，只好出面劝说。乐羊见儿子在城楼上大叫，请求见自己，就出来把儿子骂了一顿，要他劝中山国君赶快投降。乐舒请求乐羊暂时停止攻城，等他回去和国君商量。乐羊同意了，给他一个月的限期。一个月过去了，中山国又要求缓期一个月。这样三次，乐羊也没有攻城。原来他考虑到中山都城很坚固，硬攻伤亡太大。不如采取围而不攻的办法，来收买民心，等待时机成熟攻城。这时，魏国一些嫉妒乐羊的人跟魏文侯说起了坏话：“乐羊开始攻打中山时，势不可挡。可儿子一句话，他就三个月不动一兵一卒。要是不把他召回，弄不好魏军要断送在他的手里。”诽谤乐羊的话不断传到魏文侯的耳朵里，他问翟璜怎么看。翟璜说：“乐羊这个人很可靠，主公不要怀疑。”于
