# 讼师咬耳朵

浙中有个人很不孝，一次殴打七十多岁的老父亲，竟至打掉了牙齿。父亲伤心极了，拣起牙齿，到官府去告状，官府准备严惩逆子。逆子得知消息后吓坏了，慌忙去向一位专门包揽打官司的讼师请教，并答应送给讼师一百两银子。只见讼师头摇得像拨浪鼓，连连说：“大难事，大难事！”逆子又许诺再加些银子，请求讼师一定要帮忙。讼师勉强答应了，让逆子在他家住下，慢慢想办法。第二天，讼师突然高声对逆子说：“有办法了！”招手让逆子来到自己跟前，做出要耳语的样子。逆子连忙贴耳相就。讼师并没什么话，却一口咬掉了逆子的半个耳朵，弄得逆子满身血污。逆子又惊又怕，杀猪般地嚎叫起来。讼师示意他不要喊，说：“不要叫，这是你逃脱罪责的好办法。你赶快把咬下的半个耳朵收藏起来，等官府审讯时再拿出来。”到了官府，官员质问逆子为什么殴打父亲，逆子竟矢口否认。官员命人把他父亲被打掉的牙齿拿给他看，逆子竟不慌不忙地拿出了半个耳朵为自己辩白，反告父亲咬掉自己的耳朵。官员认为逆子不可能咬下自己的耳朵，而由于老人的牙齿不坚固，在咬掉儿子耳朵的同时，牙齿脱落也不是不可能的事。这样，官员认定这是一起普通的家庭纠纷，逆子终于逃脱了刑事惩罚。
