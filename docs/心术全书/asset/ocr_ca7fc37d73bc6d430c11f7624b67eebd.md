# 田筒的心计

司马喜任中山国相，中山君的宠妾阴筒经常找他的别扭。司马喜觉得自己处境危机，就让田筒帮忙想个万全之策。田筒说，“赵国的使臣到中山国时，您偷偷地告诉使臣，说中山君的宠妾阴筒有倾城倾国的相貌。赵王听说后，肯定会向中山君索取阴筒。中山君如果同意把阴筒送去，那中山国就没人跟您过不去了。假如中山君不同意把阴筒送给赵王，您可乘机劝说立阴筒为嫡妻。这样，阴筒会对您感恩戴德，绝不会再跟您过不去。”司马喜照办了，赵王果然遣使索要阴筒。中山君不同意，司马喜说：“您不同意，赵王肯定会大怒，并因此出兵，那中山国可就危险了。您不如把阴筒立为嫡妻，这样赵王就无法索要了。”中山君便把阴筒立为嫡妻。从此，阴筒把司马喜视为知己。
