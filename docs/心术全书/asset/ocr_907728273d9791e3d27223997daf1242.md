# 陈轸论郤恶

春秋时，楚国的左尹郤恶叛逃到秦国，极力说楚王的坏话。秦王听了很受用，打算任命他为五大夫。陈轸劝告秦王说：“我的家乡有一个改嫁的女人，经常对后夫说前夫的坏话，后夫听了很受用。不久，这个女人再次改嫁，又时常对第三个丈夫说第二个丈夫的坏话。一次，第三个丈夫对第二个丈夫说了有关他的坏话。第二个丈夫笑着说：‘以前她对我说的，也是这些话。’现在郤恶刚刚离开楚国，就不断地说楚王的坏话。有朝一日他再到了别的国家，大概就要说您了。”秦王遂打消了任用郤恶的念头。
