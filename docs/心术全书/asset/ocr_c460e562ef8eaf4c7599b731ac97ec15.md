# 银子被谁偷去了

柳庆任雍州别驾时，有个富商携带着二十斤银子，寄居在京师。他出入谨慎，住的房间终日上锁，钥匙从不离身。可是没过多久，在房间门和锁都没有发生任何变化的情况下，银子却不翼而飞。郡县的官吏都认为是被店主人偷去了，便把他抓到官府，严刑拷打。店主人忍受不过，遂屈打成招。柳庆对此案的审理持怀疑态度，他找来了富商，问：“你经常把钥匙放在什么地方？”富商说：“带在身上。”又问：“这期间你与谁同宿过？”答：“没与谁同宿过。”问：“那么，与谁饮过酒吗？”答：“前些日子曾和一个沙门饮过酒。因喝得多，酒醉后睡了一觉。”柳庆说：“对了，这个沙门才是真正的盗贼啊！”他马上派出捕吏去捉拿，沙门已经带上偷的银子逃之夭夭了。于是发出通缉令，命各地严加查访。不久，沙门被抓获了，富商的银子如数追回。
