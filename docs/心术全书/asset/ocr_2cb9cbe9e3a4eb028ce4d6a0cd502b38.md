# 旁敲侧击救魏尚

魏尚担任云中太守时，一次打败匈奴，杀死了许多匈奴士兵。由于一时疏忽，在向朝廷报功时，多报了六个首级。汉文帝知道后动了怒，以冒功请赏为名，撤了魏尚的职。大臣们都替魏尚鸣不平，但见汉文帝态度坚决，谁也不敢再说什么。

一天，汉文帝问冯唐是什么地方人，冯唐说是赵地人。文帝一听来了兴致，说：“赵地出良将啊！像廉颇、李牧这样的人如果为我所用，我还用得着担忧匈奴骚扰吗？”冯唐见替魏尚开脱的时机到来，就说：“话是这么说，可是陛下即便有像廉颇、李牧那样的良将，也未必能用啊。”汉文帝觉得有些刺耳，问：“你这话是什么意思？”冯唐说：“古代帝王将要出征时，总是说：‘我管朝廷内的事，将军在外遇事可以自决。’军队内论功行赏，本是将军的职责。李牧在赵国做将军时，全部支配使用了所在地的税收，赵王听之任之，不加干涉。因此，李牧才得以发挥出全部才智，使赵国强大起来。而在当今，魏尚任云中太守，用所在地的税收供养将士，因而匈奴惧怕，不敢进犯。可是陛下却仅仅因六个首级的失误，将他下狱治罪，罢了他的官爵。由此看来，陛下即便有像廉颇、李牧那样的将才，也不会任用他们。”文帝听了，认识到了自己的过错，马上免了魏尚的罪，让他官复原职。
