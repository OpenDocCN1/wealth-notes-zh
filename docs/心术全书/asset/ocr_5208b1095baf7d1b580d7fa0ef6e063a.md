# 移 接 术

所谓移接术，是指为了达到目的不惜无中生有，凭空制造矛盾，瞒天过海，移花接木，使既成的事实发生变化。只要对自己有利，可“屈尊”，可“高攀”，无所不用其极。此术的特点就是在最公开的场合，实现最隐秘的目的，依据的是最公开的也就是最隐秘的法则。

# 李园妹得楚

楚考烈王没有儿子，赵国人李园想把妹妹进献给他，又怕不得宠。李园就设法当了执掌楚国实权的春申君的舍人，设法取得信任，把妹妹献给了春申君。不久，李园妹有了身孕，兄妹俩合计了一番，想出了一个移花接木的计策。于是，李园妹找了个机会，劝说春申君。她说：“大王对您的宠信，就是亲兄弟也比不了。可是大王没有儿子，死后势必由他的兄弟当王。他的兄弟当王后，必定要启用自己的亲信，您又怎么可能保住如今的显赫地位呢？再说您得势这么久了，说不上在什么地方早已把他们得罪了，这样您不就更危险了吗？如今我已有了身孕，由于您宠幸我的时间不长，因而没有什么人知道。您要是把我献给大王，他必定喜欢我。如果运气好，我生个男孩，那么就是您的儿子当王了，楚国的各种赏赐您都会得到。”春申君被她调动了心，就把她献
