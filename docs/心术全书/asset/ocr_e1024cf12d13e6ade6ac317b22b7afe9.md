# 王越布疑云

威宁伯王越率领千余人，陪同保国公朱永巡视边境地区，不幸与敌军遭遇。见敌军人多势众，兵力相差悬殊，朱永想赶快逃走，王越坚决不同意。他从容地把千余人布好阵，原地固守。敌军见此情景，摸不透是怎么回事，不敢发动进攻。夜里，王越命骑兵全都下马，衔枚而行，谁也不许回头张望。他亲自带领一部分骁勇将士在后面保卫。沿着山后的小路走了五十多里，安全地回到了城中，敌军竟没有察觉。事后，王越对朱永说：“强敌当前，我们要 是撤退，敌军会趁势掩杀过来，我们谁也别想活着回去。我原地布阵，是用以迷惑敌军。趁着夜色，有次序地悄悄撤退，是防止被敌军发现。”

# 邓愈退强敌

公元1357年，朱元璋命邓愈守徽州，胡大海南下攻打江西婺源。邓愈到达徽州不久，元朝大将鄂勒哲突然率兵十万从杭州扑来，妄图重新夺回徽州。当时徽州的守军不多，城墙也没有修复好。再加上胡大海已分兵南下，援军短期无法到达。面对危急的局势，邓愈从容不迫。他先安定人心，鼓舞将士作好打硬仗的准备，然后下令大开城门。元军兵临城下，见情况反常，疑窦顿生，急忙退走了，徽州城得以保全。
