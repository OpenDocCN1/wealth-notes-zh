# ## 铁佛说话之谜

魏州冠氏县有座华林僧院，院内有尊一丈多高的铁佛。寺内和尚突然放出风，说铁佛显灵，能够说话。和尚们还在寺外大肆张扬，铁佛的名气越来越大，远近的官吏豪富、乡绅学子乃至平民百姓纷至沓来，捐款敬佛。皇帝听说后，命尚谦查清此事。张骆毛遂自荐，愿协助尚谦调查，皇帝也同意了。他们来到冠氏县，与地方官密谋了一番，命华林僧院所有和尚都到某地做佛事。趁此机会，张骆秘密来到僧院，进入僧房，发现有条暗道直通铁佛空心处。他让尚谦站在铁佛前，自己沿暗道进入铁佛，厉声斥责和尚们捣鬼的把戏。尚谦弄清了铁佛说话的真情，把和尚全都拘捕收监，把几个带头制造事端的和尚押送京师，经皇帝核准，依法处决了。
