# 戚贤火烧萧总管

戚贤刚担任归安县令时，县内有座萧总管祠，信奉的人特别多，装饰越来越华丽，香火也日甚一日。戚贤想制止这种劳民伤财的祭祀活动，就传谕全县百姓说：“天久不雨，若祈祷萧总管能下雨，那是再好不过的；如果不能下雨，就要拆掉萧总管祠。”随即派人把萧总管的木像从祠中抬到桥上。善男信女们祈祷了三天，结果滴雨未落。戚贤就下令把木像扔到河里。过了几天，戚贤乘船时，那木像突然自水中跃出，跳入船舱。侍卫们见了都恐惧异常，失声喊道：“萧总管来了，萧总管来了！”戚贤不慌不忙地笑了笑说：“看来我把它扔到水里失策了，应该烧掉才是。”说着命人扔到岸边点火焚烧起来。戚贤向四周看了看，见岸上有座庙宇，似乎悟出了什么。他把一个特别聪明的侍卫叫到跟前，小声嘱咐说：“你赶快换上百姓服装，隐藏在庙宇旁边。等那个水中做怪的人出来，把他抓来见我。”不多时，那个侍卫果然抓到了潜伏在水下的人。
