# 反 还 术

反还是反驳和揭露中经常使用的一种方法，即“以其人之道，还治其人之身”，用对方所讲的道理和所用的方法，回敬给对方。使对方进退维谷，陷入窘境，以达到反驳和揭露的目的。喜欢诡辩的人擅长用荒唐的逻辑来骗人，反还术正是对付诡辩者的有效方法。

# 小 时 了 了

孔融十岁那年，跟随父亲来到洛邑。当时李元礼担任司隶校尉，名气很大，到他家去的除了亲朋好友，就是社会名流。孔融想拜访李元礼，一天，他径直来到李家门外，对看门人说：“请通报你家主人，就说亲戚来了。”看门人听罢，急忙通报，随即毕恭毕敬地把孔融迎进了大门。孔融大模大样地走进会客厅，李元礼怎么也想不起来他是什么亲戚。过了一会儿，李元礼终于忍耐不住了，便问道：“请问您与我是什么亲戚？”孔融不紧不慢地说：“从前我的祖先孔子，曾向您的祖先老子李耳问过礼，这就有了师生之谊。所以说我们两家是世亲啊。”听了孔融的回答，在场的人无不称赞他聪明过人。
