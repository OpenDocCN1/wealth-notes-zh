# 游 说 术

人人都会说话，效果却大相径庭。说话的魅力在于征服听话人的心理。任何有一定的动机，说服对方时，若能抓住他的心理，替他拨拨算盘，晓以利害，定能少费口舌，收到预期的说服效果。只有了解对方心理活动的脉络，了解对方的兴趣、爱好、志向和抱负，才能因势利导，对症下药。假如不了解对方或知之甚少，那么游说非但不能奏效，反倒有可能把事情办糟。
