# 争 宠 术

要争宠，除了靠自己固有的品质外，有时还必须要一些手腕，而投其所好是最易见效的。投其所好固然有效，但逢迎的痕迹太明显，一旦不成功，便再难有出头的日子。因而大凡争宠的人，一般不采用这种方式，而是在如何显示贤明才能上下功夫。

# 安陵君结楚王

江乙对楚王的宠臣安陵君说： “您身居高位，却没有办法和楚王结成至交，我替您担忧。”安陵君说：“那该怎么办呢？”江乙说：“您要求求为大王殉难，这样就能成为大王的至交。”过了三年，安陵君还是没讲。江乙不耐烦了，说：“我的计谋您如果不用，那我以后再也不见您了。”安陵君说：“您的计谋很好，只是还没找到合适的机会用。”一次，楚王到云梦打猎。有头野牛横冲过来，楚王拈弓搭箭，一箭射死了它。众人齐声欢呼，楚王手举弓箭，仰天大笑着说：“今天真快活啊！我万岁千秋之后，还能有这样的快乐吗？”安陵君泪流满面地走上前，说：“大王对我恩重如山，情深似海。大王如不嫌弃，我甘愿在您万岁千秋之后，跟随奔赴黄泉，变为褥草为您挡住蝼蚁。只有这样，我的心才能得到安宁。”楚王听了十分高兴，从此以他为至交。如
