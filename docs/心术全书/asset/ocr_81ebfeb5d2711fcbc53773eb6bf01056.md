# 约法三章

刘邦攻进了咸阳，将士们乱纷纷地争着冲进仓库，抢夺金银珠宝。刘邦走进秦二世的住处，打算享受一阵子。樊哙劝告他不听，张良又劝他说：“正由于秦朝暴虐、奢侈，二世荒淫无道，您才能来这儿。您要想得天下，就得朴素、节俭。”刘邦下了好大决心，才离开皇宫，到灞上驻扎。然后招集各县的名流豪杰，同他们约法三章，安定民心。百姓知道后，都打心眼里感激刘邦，争先恐后地带上酒肉粮食来慰问将士。刘邦好言好语地劝他们把东西带回去，说：“粮仓里有的是粮食，百姓就不要费心了。”百姓更加高兴了，都盼望着刘邦永远不离开。

# 成都王不辅政

除掉司马伦后，齐王和成都王都因功劳大，共同辅政。成都王的亲信卢志对成都王说：“大王现在和齐王共同辅政，但自古以来两雄不可并立，我劝大王不如回封邺城去，让齐王独个儿在朝中执政。这样，天下的人心都会向着你。”成都王觉得卢志说得有道理，就去对晋惠帝说：“三王起兵，都是齐王带头发难的功劳，理应把朝政都交给他。我母亲病重，请允许我回去侍候。”晋惠帝从来就没有什么主意，是个点头皇帝，别人怎么说他都同意。

成都王又写了一封辞行的信给齐王，随即带领随从启程回邺城。齐王见信，赶紧飞马追赶，在洛阳东北的七里涧追上了。成都王只是两眼泪汪汪，诉说母亲的疾病，别的事只字不提。其实齐王巴不得一人专权，并不想留他。两人客客
