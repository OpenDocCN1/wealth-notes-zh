# 廉范增炬

公元73年，匈奴大举入侵云中。云中太守廉范奉命抵抗，可是兵力太少。下属提议请救兵，廉范不同意，他想出了一条增炬惑敌的妙计。谁都知道，火炬通常只能点燃一头。廉范独出心裁，制造出十字形火炬。夜半时分，廉范让士卒每人手持一个十字形火炬，用手握住一端，其余三端点燃。远远望去，廉范军队的数目顿时“增加”了三倍。匈奴军见廉范军营火光骤增，以为汉朝援军到了，十分恐惧。天刚亮，就急忙拔寨撤退。廉范乘机率军追赶，斩杀匈奴一千多人。

# 虞诩增灶

东汉末年，几千羌人把虞诩截在陈仓峓谷。虞诩被迫停下来，声言向朝廷请救兵，等救兵来到再发动进攻。羌人听说后，就趁救兵还没来到，分散到邻近各县去抢夺财物。虞诩见羌人分散，乘机进军，昼夜兼程，每天行进一百多里。每次休息做饭时，便命令士兵各作两灶，逐日加倍增加。羌人以为虞诩请来了救兵，不敢发动进攻。于是，虞诩率军突破封锁，把羌人打得大败。虞诩声言等救兵到了再走，是为了分散敌军；日夜急行军，是给羌人造成时间和空间上的被动；加倍修灶，是为了迷惑羌人，使他们误以为援兵已经赶到。
