# 张咏除妖

张咏任成都知府时，民间流传有个白头老妖，经常出没成都，每次都要吃不少人的谣言。百姓忧心忡忡，纷纷到外地避难。张咏命下属到闹市观察，发现有大谈此事的，立即逮捕。第二天，下属就抓来一个人。张咏马上下令把他处死，还贴出了安民告示。有人问这样做的目的，张咏说：“谣言惑众，灾祸来临。妖怪之形，出自谣言之声。制止谣言，在于果断处理，仅靠口头禁止是难于奏效的。”
