# 秦桧请客

程厚与秦桧关系十分密切，在他担任中舍官职时，一日，秦桧邀请他到府上做客。他如约前往，被引入一间大房子中。房子很空，只有一张书案，上面放着一个用高级丝绸包裹着的册子。程厚闲得无聊，便打开观看，见册子里工工整整地抄写着—篇题为《圣人以日星为纪》的赋，结尾处题有“学士类贡进士秦垠呈”的字样，文章写得词采华丽。程厚无事可干，便一页又一页地诵读这精赋，无意中几乎要背诵下来了。在他诵读期间，隔一会儿便有人送来可口的酒菜，还有人进来问候致敬。奇怪的是，直到天色已晚，只是不见秦桧的踪影。程厚无奈，只好满腹狐疑地起身告辞。数日后，朝廷公布了贡举的消息，并宣告程厚入院命题判卷。他这才明白了秦桧的用意，就以秦垠的那篇赋命题。结果不难猜测，秦垠在这次考试中位居第一名。
