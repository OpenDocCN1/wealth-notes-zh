# 顾鼎臣讲学

明世宗朱厚熜忌讳很多，动不动就杀人。嘉靖初年，讲官顾鼎臣讲《孟子· 戚丘蒙章》，当讲到“二十八年后，尧死了”时，群臣吓得大气不敢出。原来朱厚熜平日常自比尧舜，说尧死了，有影射他的嫌疑。只听顾鼎臣不紧不慢地补充说：“这一年，尧帝已经一百二十岁了。”大家这才松了一口气。

# 老头子

一日，清高宗漫步到翰林院，大学士纪昀正与同僚闲谈。时值盛夏，纪昀因身体肥胖怕热，亦裸着上身。听说皇上来了，怕失礼受责，急忙藏到夹壁中去。清高宗其实早已发现，故意不露声色地坐了下来。过了一会儿，纪昀听都没动静，以为皇帝已经走了，便从夹壁中走了出来，边走边问：“老头子走了没有？”众人都肃立在那里，吓得不敢出声。纪昀一抬头，猛然发现高宗端坐在上面。他自知语失，连忙跪下。高宗说：“你叫我老头子，要是讲出道理来，我不罚你。”纪昀应声答道：“皇上万寿无疆，所以称为‘老’；为天下人臣之首，这就是‘头’；是真命天子，则可称为‘子’，这合起来就是‘老头子’。”高宗听了，连连点头称善，纪
