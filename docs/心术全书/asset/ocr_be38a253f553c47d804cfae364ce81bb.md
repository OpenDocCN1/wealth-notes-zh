# 居大不易

白居易刚去参加科举时，还没有什么名声。一天，他带

上自己的得意诗卷去拜访大诗人顾况。顾况见他的名片上写

着：“白居易”三字，就开玩笑说：“长安百物贵，居大不

易。”当他读到诗歌《赋得古原草送别》中“野火烧不尽，

春风吹又生”的诗句时，不禁赞许地说：“能写出这样的佳

句，居天下有什么困难？老夫前言是开玩笑罢了。”

# 杜邮之赐

宋世祖曾赏赐给谢中书一把宝剑，谢中书为友人鲁爽送

行时，又把宝剑转赠给了他。后来，鲁爽因涉嫌谋反被杀。一

次宴会上，宋世祖向谢中书问起那把剑的情况，谢中书说：

“早在送别鲁爽时，私下里替陛下做了杜邮之赐。”杜邮是

古代地名，在今陕西咸阳市。战国时秦昭王逼武安君白起离

开咸阳，当白起走到离咸阳仅十里的杜邮时，秦王又派使者

送去一把剑，让他自裁，白起遂引颈自杀。谢中书巧妙地借

用这个典故，使自己摆脱了窘境。
