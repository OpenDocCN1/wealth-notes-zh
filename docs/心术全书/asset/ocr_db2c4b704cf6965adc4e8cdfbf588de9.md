# # 董崇避嫌

东汉光武帝刘秀北伐燕、代后，由于太守寇恂治理有方，这一带迅速繁荣起来，为刘秀军提供了大批军粮。于是，刘秀接连几次派人犒赏慰问，寇恂也十分得意。茂陵人董崇告诫寇恂说：“皇帝刚即位，四方尚未安定。您管理大郡，内得人心，外破强敌，肯定会招致别人的嫉妒。从前萧何镇守关中时，汉高祖也曾几次犒劳慰问，实际上是对他起了疑心。为此，萧何把儿子、兄弟都派到高祖军中，您应以前人为鉴。”寇恂觉得有理，向刘秀请求跟随出征。刘秀说：“河内还没安定，你不能离开。”寇恂就派侄子、外甥到刘秀军中。刘秀果然很满意，不再派人犒赏慰问了。
