# 灵感术

战争是诸种因素的竞赛，其间最精彩莫过于斗智斗谋。正确的谋略可转劣为优，化险为夷。正所谓用兵在智，胜战在谋，“运用之妙，存乎一心”。战争是活的，情况是千变万化的。智谋没有固定的模式，它是靠灵感来捕捉和运用，而严谨的从容态度，丰富的实践技巧，精深的军事修养，灵变的指挥技巧，则是瞬间爆发用兵灵感的源泉。

# 袁绍智赚公孙瓒

东汉建安四年，袁绍包围了幽州城。幽州刺史公孙瓒派儿子到黑山求援，并准备等援军来到后，里应外合，共同对付袁绍。时过多日，袁绍攻城越来越紧。公孙瓒见救兵迟迟不至，又派人去给讨救兵的儿子送信，让他请援军快来，还约定以举火为内外策应的暗号。不料，这封信落入袁绍手中，他决定将计就计，按信中所约定的方式举火。公孙瓒果然上当，以为援军到了，遂出城作战，闯进了袁绍设置的埋伏圈，拼死得脱，伤亡惨重。袁绍指挥军队继续攻城，终于攻克幽州，全歼了公孙瓒的部队。
