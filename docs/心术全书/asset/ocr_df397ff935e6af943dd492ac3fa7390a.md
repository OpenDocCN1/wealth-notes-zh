# 驭言术

一毁一誉，往往是衡量一个人的标准。因而，如何驾驭舆论，利用舆论，是立足社会的一项重要内容。纵观古今，有不少人因不愿及舆论的制约，大至国破家亡，小至身首分离。对统治者来说，虽然自身也要受舆论的制约，但由于其本身的影响力，可以在某种程度上驾驭舆论，这无疑为体现其意志提供了有利条件。当然，只有顺应民心，以身作则，才会达到预期的目的。反之，只能会适得其反。

# 禁穿紫衣

齐桓公喜欢穿紫衣服，一时成了社会风气，齐国人都穿上了紫衣服。齐桓公觉得很不舒服，让管仲想办法。管仲和他咬了一阵耳朵，齐桓公连连点头。第二天上朝时，齐桓公已经换穿上了别种颜色的衣服。有几个大臣依然穿着紫衣服上朝，齐桓公做出厌恶的样子，说：“你们几个离我远点，我最讨厌紫衣服的气味。”几天过后，齐国就没有穿紫色衣服的人了。
