# ## 用灯花烧过的信

东魏大将段臻占据宜阳一带，指使他的下属扬州刺史牛道恒煽动边民闹事。韦孝宽觉得事态严重，就密派间谍人员找来牛道恒的书信，让擅长摹仿的人照着练习，很快伪造了一封牛道恒写给韦孝宽的“亲笔信”，信中谈了悔过归顺的打算。还故意用灯花在信纸上烧了两个洞，表明信是夜间写的。信伪造好以后，派人送到段臻那里。段臻看了信后，果然开始怀疑牛道恒。二人从此离心离德，相继被韦孝宽擒获。

# ## 王猛离间慕容垂

前燕车骑大将军慕容垂带领儿子慕容令、慕容楷及部下投奔前秦，苻坚很高兴，答应灭掉前燕后把燕地封给慕容垂。苻坚的下属王猛认为慕容垂不会甘居人下，不如及早除掉，以绝后患，遭到了苻坚的拒绝。不久，苻坚派王猛率军征讨前燕，他请求让慕容令随军前往，苻坚答应了。军队出发后，王猛私下里去向慕容垂告别，并请求他送自己一件纪念品。慕容垂不知是计，就把自己的佩刀送给了他。行军途中，王猛派一个心腹拿着佩刀对慕容令说：“前秦对我们不信任，我们还是回前燕去吧。您的父亲已经动身，他让我来告诉您，让我也赶快动身。”说着，把慕容垂的佩刀递给了慕容令。他见到父亲的佩刀，不容不信，便带上旧部，逃回前燕去了。王猛也不追赶，马上派人送信给苻坚。慕容垂听说后，也吓得匆忙出逃。他虽然被苻坚追回来了，可再也得
