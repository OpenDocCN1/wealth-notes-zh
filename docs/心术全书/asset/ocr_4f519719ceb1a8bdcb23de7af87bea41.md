# 思 辩 术

一切事物只用明暗二字就可以概括，水不清澈就会腐 臭，镜不明就会模糊生诱，人思辨不明就像坠入云雾之中。 有的人思辨像蜡烛，光映咫尺；有的人思辨像太阳，光照八 极；还有的人根本不懂思辨，处世如同在漆黑的夜晚，盲人 骑着瞎马临近深渊，实在太危险了！可见，人与人思辨的差 距是很大的。愚人还未反应过来，智者早已了如指掌；愚人还 在幻想，智者已有了坚定的信念。思辨术可使人明察秋毫， 趋利避害，稳操胜券。
