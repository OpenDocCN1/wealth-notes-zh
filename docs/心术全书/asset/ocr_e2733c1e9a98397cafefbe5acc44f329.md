# 诡 道 术

两军相争，离不开诡道。曹操说过：“兵无常形，以诡诈为道。”走路取其平坦，用兵不怕诡诈。实实虚虚，使敌人疑神疑鬼。彼暗我明，敌军就会无所适从；机智灵变，敌军就会惊慌失措。使用诡道，成功的战例不胜枚举。只要战争不消失，诡道术就不会失去其魅力。

# 晋文公攻曹

晋文公率军攻打曹国，曹国城门大开，诈称投降。晋文公派人去受降，刚入城就被伏兵杀了。曹国还把受降人的尸体吊在城墙上，想以此瓦解晋军斗志。晋文公就带人来到曹君的祖坟，做出要掘墓的样子。曹君害怕了，请求以归还受降人尸体为条件，换取祖坟不受破坏。晋文公答应了，趁曹人抬着棺材出城时，晋国伏兵一拥而上。由于城门被棺材堵塞，怎么也关不上。大队晋军乘机攻进城，活捉了曹共工。
