# 深谋远虑的李夫人

李夫人深得汉武帝的宠爱。在她病重时，汉武帝亲自来探望，李夫人却用被子蒙上头，说：“妾久病在床，形貌毁坏，不可以面见皇上。我只希望把儿子哀王和我的兄弟托付给陛下，求皇上多加关照。”汉武帝说：“夫人久病不假，可现在就把儿子和兄弟嘱托给我，不是太早了吗？”李夫人说：“作为一个女人，形貌不整，未经梳洗打扮，是不能见君王和父亲的。因而我现在不敢面见皇上。”汉武帝渴望见她一面，就说：“夫人如让我见一面，我将赏赐千金，封你的兄弟为高官。”李夫人说：“封赏全在皇上一句话，不在于见不见一面。”汉武帝反复恳求，李夫人干脆回身向里，连声叹气，不再说话。汉武帝无奈，满脸不高兴地回去了。

汉武帝一走，李夫人的姊妹齐声责备她说：“你不过是个贵人，连皇上见一面的要求都不答应，还说什么嘱托兄弟呢？”李夫人长叹了一口气，说：“凡以色事人的人，色衰而爱减。宠爱没有了，情分也就断绝了。皇上之所以眷恋我，是因为想着我从前的容貌。如今我的容貌已毁，皇上见了只能害怕而厌恶，会从心底里抛弃我，怎么还肯追念过去的恩爱而重用我的兄弟呢？我不见皇上，正是想把兄弟长远地托付给他啊。”不久，李夫人离开了人世。汉武帝一直思念着她，把她的兄弟全封为高官。
