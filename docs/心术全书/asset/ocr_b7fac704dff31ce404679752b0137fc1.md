# 公 关 术

人怎样才能立足社会，怎样才能博得别人的喜爱，怎样才能有效地和他人打交道，这些都需要人际交往的技巧，公关术正是调控人际关系的艺术。简单地说，公关是指一个组织机构与社会公众，以及各界的关系协调。公共关系虽然近年来才为我国引进、利用，但其作为一种活动，在我国早就出现了。如战国时期的纵横家们，代表着某一集团的利益游说、出使各国，创造了不少公共关系方面的成功范例。
