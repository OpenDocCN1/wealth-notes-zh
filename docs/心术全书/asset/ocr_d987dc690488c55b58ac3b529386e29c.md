# 文彦博查案

一次对外用兵时，因监军黄德和拥兵观望，致使主将刘平战死。事后黄德和为了推卸责任，竟诬告刘平通敌。还用金带贿赂刘平的奴仆，让他作伪证。随后把刘平一家二百余口抓进监狱，准备灭族。皇帝觉得刘平谋反案证据不足，派御史文彦博到河中一带作进一步的调查。

经过多方查证，终于了解到了事情的真相。黄德和及其同党害怕阴谋败露，就另派一名御史去接替文彦博查案。文彦博拒绝交案，对新派的御史说：“朝廷怕案子查不清，才派你来接替。可是现在人赃俱在，案情大白，没必要再查下去了。案子的处理或许不尽人意，但一切责任由我来负，你就不要过问了。”后派的御史只好回朝廷交差。不久，文彦博奏明皇帝，处死了黄德和及刘平的奴仆。
