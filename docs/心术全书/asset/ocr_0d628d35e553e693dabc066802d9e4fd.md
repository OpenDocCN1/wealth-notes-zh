# 吴质巧施掉包计

杨修谋划立曹植为太子，曹丕很忧虑，让吴质藏在竹笼中，乘车到自己的行宫商讨对策。不料被杨修发现，马上报告了曹操。曹丕十分害怕，问吴质该怎么办。吴质说：“这没什么，明天把竹笼里装上丝绸拉进宫就可以了。”曹丕依计而行，曹操见拉的是丝绸，不仅不再怀疑曹丕，反倒认为杨修心术不正。

# 曹丕邀宠

曹植素有文才，深得曹操的喜爱，也有立他为太子的念头。为此，次子曹丕感到十分忧虑。一次，曹操将要率军远征，曹植写了一篇大赋，称颂父亲的功德，并当众诵读，声情并茂，赢得了曹操和大臣们的阵阵喝采。曹丕来送行时，什么话也不说，只是泪流满面，伏地而拜，表示出对父亲出入沙场的担忧。曹操很受感动。相比之下，他觉得曹植华而不实，曹丕则骨肉情深，心地坦诚，终于下决心立曹丕为太子。
