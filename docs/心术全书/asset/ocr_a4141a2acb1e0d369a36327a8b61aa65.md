# # 惩罚武举人

清朝人许治任华亭知县时，有个武举人把一个农民扭送到县衙，说农民挑粪弄脏了他的衣服，要求严办。许治了解武举人的为人，平素依仗着有钱有势，飞扬跋扈，决定趁机治治他。于是，许治煞有介事地训斥了农民几句，又罚他给武举人磕一百个头。当磕到八十多个时，许治忽然说：“快停下，我这脑袋让你们给气糊涂了，还没问举人是文的还是武的？”武举人回答：“是武举。”许治叹了一口气，说：“全错了，给文举人应磕一百下，给武举磕五十下就够了。已经磕过数了，你得还回去。”武举人坚决不磕，许治大怒，喝令差役把他摁倒，给农民磕了头。武举人满面羞愧，狼狈地离开了官府。
