# 巧 答 术

巧妙地回答对方的提问，是社交活动的重要技巧。有些人为了某种目的，经常提出一些难以解答的怪题、难题，将对方的军。一般说来，巧答的奥妙在于避开直接问啥答啥的套数。面对难题、怪题，如果直接回答，无论怎么说，都会让人抓住把柄。而从别的角度回答，就能出奇制胜，巧夺天工。巧答的妙诀在于，首先要认真分析对方发问的用意和动机，然后拿出巧妙的答案。巧答是分析、发现、联想、表述等能力的综合体现。

# 第五伦谈私心

第五伦为人正直，奉公守节，汉章帝时被任命为司空。有人问他有没有私心，第五伦说：“以前曾有人要送我一匹千里马，我虽然拒绝了，可直到位至三公，依然没能忘记这件事。哥哥的儿子有病，我一晚上去探望了十次，回来后就睡着了。我自己的儿子有了病，虽然没起身去看他，却一夜没合眼。如此看来，我还是有私心啊！”
