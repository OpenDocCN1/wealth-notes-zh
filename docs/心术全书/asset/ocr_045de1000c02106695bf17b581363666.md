# 周金息众怒

周金在宣州任职时，总督冯侍郎待人苛刻，众人都很恨他。一天，众将领到冯侍郎处请求发放军粮，他不仅不同意，还要鞭打众人。将领们忍无可忍，闹哄哄地包围了帅府，要与冯侍郎拼个你死我活。

当时周金正染病在床，官员们跑来向他哭诉了将领们闹事的情况。周金从容不迫地说：“有我在，你们用不着担心。”他强支病体，穿上便服，站到院子里，派人把几个总官找来，佯装怒不可遏，大骂道：“都是你们几个贪得无厌，盘剥将士，不然，将士们怎么会不自重自爱呢？”说着，还要用鞭子抽打他们，被下属苦苦劝住了。

将领们听说周金不怪罪他们，怒气顿消。他们一齐赶来，跪在周金面前，替把总官们求情说：“把总官们没有什么过错，事情是由于总管军队的人贪财，不体恤我们这些军人造成的。周金就向他们讲述了随意闹事的害处，说得众将领心服口服，齐声说：“是您救了我们的命。”于是，将领们马上解除了对帅府的包围。
