# 揣摩术

揣摩术是指从对方的表情和态度中，揣摩臆测对方心理的技巧。在生活和事业上，应时刻注意揣摩你的对手。对手可能是敌人，也可能是朋友；可能很熟悉，也可能素不相识。无论你与他是友好相处，还是激烈竞争，充分认识和了解对手，都是非常必要的。揣摩对手，主要把握以下方面：弄清对手的性格；了解对手的感觉；摸清对手的情感线；发现对手的思维规律；衡量对手的智慧能力；发现对手的潜意识；发现对手的内心冲突和矛盾。此外，还要考虑到对手所处的实际环境。自己则要不不动声色，以静制动，使对手无懈可击。
