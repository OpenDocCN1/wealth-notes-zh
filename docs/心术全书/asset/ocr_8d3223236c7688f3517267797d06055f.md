# 囚刀破案

刘宗龟镇守海南时，有个富商的儿子正当少年，风流倜傥。一日傍晚，他把船停泊在江边，见一豪富人家门口站着个漂亮女子，就挑逗说：“记住，今天晚上我来陪你。”女子微微一笑，算是答应了。

到了晚上，女子果然开着门等少年。不料未等少年赶到，有个小偷先摸进了屋，准备行窃。女子黑暗中看不清，以为情人来了，扑了上去。这可吓坏了小偷，以为有人捉拿他，顺手捅了一刀。女子倒地身亡，小偷见出了人命，扔下刀跑了。少年进屋后，踩了地上的血，滑倒在地。他伸手一摸，正摸到女子的尸体，吓得三魂出窍，一溜烟逃回船上，连夜离岸而去。

第二天，豪富家发现女子被杀，顺着血迹追到岸边，一打听才知道昨晚停泊了一条船，不知去向。豪富家马上报了案，官府派出快船，追上少年乘坐的船，把他捉拿回官府。虽经反复审讯，用尽各种刑具，少年只承认引诱过女子，不承认杀人，刘宗龟仔细地观察杀人刀，发现是屠夫使用的，不像是少年的物品，决定进一步调查。他传令说，最近要举行一次大演习，并犒赏将士，要求全城从事屠宰、烹饪的人某日到球场集合。到了约定日期，屠夫和厨师都来了。刘宗龟借口天色已晚，让他们留下刀具，明天再来。第二天清早，屠夫和厨师又来了，纷纷来取刀具，刘宗龟早有安排，把杀人刀混入其中，并随意撇下了一把刀。众人取回了刀，只有一个屠夫东瞅瞅，西看看，在找自己的刀。刘宗龟指着剩下的那把杀人刀问：“你怎么不拿？”屠夫摇摇头，说：“这不
