# 冒顿射父

西汉初年，匈奴头曼单于的儿子冒顿想杀父自立。为了达到这一目的，他每日同部下一同练习骑射，并规定说：“凡是我射的目标，你们都要放箭，违命者立斩不贷。”一天，冒顿突然向自己平日最喜爱的坐骑射了一箭，部-down们不敢怠慢，一齐放箭，射死了那匹马。几天后，冒顿猛然向自己的妻子射了一箭，部-down们犹豫了一下，马上想起了军令，便一齐射冒顿的妻子，满身的箭使她变得像只刺猬。见时机成熟，冒顿决定杀掉父亲。一次打猎时，他冷不防向父亲头曼放了一箭，部-down们毫不犹豫，引弓放箭，射死了头曼。头曼死后，冒顿当上了匈奴王。

# 曹操“心动”

曹操对人说：“别人要是想加害于我，我的心就会动起来，因而能预先知道。”为了证实这些话，曹操对一个他极为宠信的近臣说：“你可以秘密带上一把刀来到我的身边，我就会说心动起来，喝令你抓起来，并对你用刑。你只要什么也不说，我保你不会有任何事。事后，我会重重地赏你。”那近臣照办了，曹操喝令把他抓起来，推出去斩首。近臣因对曹操的话深信不疑，因而一点儿也不害怕，被处斩了。可悲的是，他至死也不相信自己会真的被杀死。自此以后，曹操手下的人都相信他确有遇危心动的功能，想谋害他的人，也就不敢下手了。
