
# 李牧之死
秦王嬴政为了统一天下，在公元前二二九年，派大将王翦和桓齮率军攻打赵国。桓齮一战攻下平阴，消灭了十多万赵国军队。赵王十分惊慌，急忙调派李牧和司马尚抵抗秦军。李牧足智多谋，巧设埋伏，一仗击溃秦军，桓齮也死于乱军之中。王翦见秦军失利，决定使用反间计。他派人给赵王的宠臣郭开送去了许多财物，同时散布谣言，说李牧与秦军私下里往来密切，打算取代赵王。郭开干脆当着赵王的面制造谣言。说：“李牧心怀犹豫，不进攻秦军，是由于他早就打算降秦，秦王把封赏给他的土地和财物都准备好了。”赵王信以为真，就派人把李牧杀了，还撤了司马尚的职。王翦见离间计成功，率军长驱直入，一举灭亡了赵国。

# 甘茂中伤公孙衍
秦王很器重公孙衍，一次私下里对他说：“我想让你担任相国的职务。”不料，这话被相国甘茂的心腹听到了，马上报告了甘茂。于是，甘茂求见秦王，说：“大王就要得到大有作为的相国了，请接受我的祝贺。”秦王一怔，暗想：这话我只对公孙衍说过，他怎么会知道呢？可是嘴上却说：“相国想到哪去了，我既然把国家交给你了，怎么还会去选别人呢？”甘茂干脆一针见血地说：“大王不是要让公孙衍当相国吗？”见甘茂不客气地捅漏了，秦王反倒镇静了下来，反问道：“那你是怎么知道的呢？”甘茂想，我要是如实说出心腹之人听到的，那是很不利的。他索性一不作，二不休，装做很随便地说：“这是公孙衍亲口对我说的呀！”秦王顿时语塞，无言以对，心里恨透了公孙衍。几天后，秦王就找了个借口，把公孙衍流放 了。

# 白登解围
韩王姬信勾结匈奴冒顿造反，汉高祖刘邦御驾亲征，中了冒顿的诱兵之计，被困在白登。虽然谋臣猛将不少，但孤军被困，外无援兵，内乏粮草，形势十分危急。被围的第四天，陈平看见山下有一男一女骑着马来回调动匈奴军队，感到奇怪，一打听，才知道那女的是冒顿单于的阏氏。他猛然间想出了一个好办法，打算从冒顿的阏氏身上打开缺口。他把主意对刘邦说了，刘邦连连点头，催他赶快行动。第二天一大早，陈平打发一个使者带着金银珠宝和一幅图画去见阏氏。使者一路行贿，买通匈奴兵卒，让他们带自己悄悄地去拜见阏氏。

使者见到阏氏，献上礼物，并且说：“这些都是中原皇帝特意送给您的。中原皇帝情愿同匈奴大王结好，请您多帮忙。”阏氏见了丰厚的礼物，别提有多高兴了。她打开那幅图画，见上面画着一个美貌绝伦的女子，不由得皱起了眉头，说：“这幅画拿来干什么？”使者说：“中原皇帝怕大王不答应，不肯退兵，准备把中原头号美人献上。这是她的画像，先请大王过过目。”阏氏摇摇头，说：“这用不着，拿回去吧。”阏氏当天晚上就劝冒顿送给中原皇帝一个人情，将来好多索取些财物，冒顿答应了。第二天清早，冒顿下令解围，放走了刘邦一行。陈平巧妙地利用了阏氏的嫉妒心理，使刘邦转危为安。

# 离间奸党
西汉宣帝时期，赵广汉出任颍川太守。当地的豪门大族互为婚姻，串通一气，社会风气很坏。赵广汉想改变这一局面，就在豪门中物色了一个可以利用的人，假意审讯了一番，并根据他的口供定了罪。然后赵广汉把他交待的涉及其他豪门的话泄露了出去，使豪门之间互相怨恨。赵广汉还让下属做了个检举箱，每当收到检举信，就去掉写信人的真实姓名，假托是豪门子弟写的。不久，豪门家家怨恨，奸党离散，社会风气大为改观。

# 离间二凶
董卓死后，他的死党李榷和郭汜作乱，攻下长安，杀死王允，控制了献帝，把持着朝政。他俩关系密切，太尉杨彪和司马朱雠觉得，如不将他俩离间开，那就很难对付。他们听说郭汜的妻子嫉妒心极强，便决定在她身上打开缺口，就派人散布流言，说郭汜与李榷的妻子关系暧昧。不久，这话传进了郭汜妻子的耳朵里。自此，她说什么也不让郭汜晚间出门，连李榷邀请郭汜饮酒，她也不让去。李榷见郭汜不来，就派人把酒肉送去。郭妻见了，就在酒肉中下了毒，然后派人送给郭汜。郭汜刚要吃，她连忙劝止，先把饭菜给狗吃了一些，结果狗被药死了。郭汜见了大惊失色，认为李榷想暗害他。过了几天，李榷请郭汜吃饭，谁知回家后肚子就疼了起来，郭妻给他灌了些粪便，一番呕吐之后，肚子才不疼了。这更使得郭汜痛恨李榷，便准备先发制人。他调动军队，打算围攻李榷。李榷听到消息后，忙率军应战。至此，两人彻底决裂。

# 曹操离间联军
三国时，曹操率军征伐占据关中的韩遂马超联军。由于曹操与韩遂的父亲是同年孝廉，因而两军相遇时，曹操故意不许军队进攻，亲自上前和韩遂交谈，说的都是一些京都旧事。韩遂回去后，马超打听他们说了些什么，韩遂说谈的都是些琐细小事，这便引起了马超的疑心。过了几天，曹操给韩遂写了封亲笔信，信中有许多地方涂抹得很乱。当韩遂把信件拿给马超看时，马超认为信是被韩遂涂抹的，更加重了对他的疑心。于是关中诸将互相猜疑，离心离德。曹操乘机各个击破，终于平定了关中。

# 斛律明月蒙冤
齐相国斛律明月足智多谋，办事干练。韦孝宽想除掉他，就让参军曲岩作了一首歌谣：“百升飞上天，明月照长安。”“百升”就是“斛”。不久，又作了一首歌谣：“高巨不摧自崩，斛树不扶自竖。”两首歌谣都暗示斛律明月将要夺位篡权，韦孝宽派出间谍，到北齐广为散布。当时北齐的另一达官显要祖孝征与斛律明月有矛盾，听到后又加工润色一番，上奏给齐王，斛律明月被不明不白地处死了。

# 用灯花烧过的信
东魏大将段臻占据宜阳一带，指使他的下属扬州刺史牛道恒煽动边民闹事。韦孝宽觉得事态严重，就密派间谍人员找来牛道恒的书信，让擅长摹仿的人照着练习，很快伪造了一封牛道恒写给韦孝宽的“亲笔信”，信中谈了悔过归顺的打算。还故意用灯花在信纸上烧了两个洞，表明信是夜间写的。信伪造好以后，派人送到段臻那里。段臻看了信后，果然开始怀疑牛道恒。二人从此离心离德，相继被韦孝宽擒获。

# 王猛离间慕容垂
前燕车骑大将军慕容垂带领儿子慕容令、慕容楷及部下投奔前秦，苻坚很高兴，答应灭掉前燕后把燕地封给慕容垂。苻坚的下属王猛认为慕容垂不会甘居人下，不如及早除掉，以绝后患，遭到了苻坚的拒绝。不久，苻坚派王猛率军征讨前燕，他请求让慕容令随军前往，苻坚答应了。军队出发后，王猛私下里去向慕容垂告别，并请求他送自己一件纪念品。慕容垂不知是计，就把自己的佩刀送给了他。行军途中，王猛派一个心腹拿着佩刀对慕容令说：“前秦对我们不信任，我们还是回前燕去吧。您的父亲已经动身，他让我来告诉您，让我也赶快动身。”说着，把慕容垂的佩刀递给了慕容令。他见到父亲的佩刀，不容不信，便带上旧部，逃回前燕去了。王猛也不追赶，马上派人送信给苻坚。慕容垂听说后，也吓得匆忙出逃。他虽然被苻坚追回来了，可也再也得不到苻坚的信任。慕容令则被前燕流放到偏远荒凉的地方去了。

# 李林甫离间李适之
唐玄宗时，宰相李林甫和李适之同任相职。一天，李林甫对李适之说：“华山发现了大金矿，开采后可以增加国库收入，可是皇上并不知此事。”过了几天，李适之把华山发现金矿的事对唐玄宗说了。唐玄宗又问李林甫知不知道这件事，他说：“臣下早就知道了，只是因为华山是皇上本命王气所在，不宜开凿，所以我考虑再三，始终没敢向陛下提起这件事。”唐玄宗听了，觉得李林甫更尊重自己，便疏远了李适之。

# 高力士一语怒玄宗
毛仲很得唐玄宗的宠信，因瞧不起宦官，所以高力士等人对他十分恼恨。一次，毛仲的妻子生了个儿子，玄宗派高力士前往赐酒馔金帛，并授予新生儿五品官衔。高力士回来后，玄宗问：“毛仲高兴吗？”高力士说：“毛仲抱着儿子让我看，还说‘我儿子难道就当不了三品吗？’”玄宗听了大怒，说：“此贼竟敢用小儿怨恨我！”高力士趁机进了不少谗言。不久，玄宗将毛仲贬官瀼州，行至永州时又被赐死。

# 王钦若离间寇准
澶渊之战后，宋真宗因寇准劳苦功高而特别器重，这便招来了王钦若的嫉妒。一天，寇准因有事先退了朝，真宗久久地目送他出去。王钦若却不阴不阳地说：“陛下如此敬重寇准，是不是认为是匡扶社稷之臣呢？”宋真宗点了点头。王钦若又说：“澶渊一战，陛下不以为是羞耻的事，反倒觉得十分荣耀，并由此敬重寇准，这难道应该吗？”宋真宗睁大了眼睛，问：“爱卿此话怎讲？”王钦若说：“《春秋》认为，城下之盟，是莫大的耻辱。然而陛下作为万邦之主，寇准竟让您与胡虏订盟于城下，难道还有比这更耻辱的事吗？”宋真宗听了，顿时拉下了脸，变得不高兴起来。王钦若见他的话已经奏效，便继续进谗说：“陛下知道赌博吗？赌徒在山穷水尽之时，常常不惜一切孤注一掷。寇准实际就是把陛下当成了‘孤注’，臣下心里至今还替陛下捏着一把汗。”宋真宗听信了他的谗言，开始痛恨寇准。不久，就罢免了寇准的宰相职务，降为刑部尚书，到陕州任职。

# 岳飞施计废刘豫
岳飞得知刘豫同金人勾结，而金兀术又很讨厌他，就决定离间他们。恰好军中抓到一个金兀术派来的间谍，岳飞假装认错了人，责备他说：“你不是我派到刘豫那里去的密探张斌吗？为什么要背叛我？我以前派你到齐，约定让刘豫把四太子金兀术引诱来，你却一去不返。我又另外派人联系这件事，刘豫已答应今年冬天以联合进攻长江为由，把四太子骗到清河，并说派你给我送信。你却拿着信至今不送来，耽误了我的大事，该当何罪？”间谍怕暴露了真实身分被处死，就顺水推舟，承认自己是“张斌”，请求岳飞给他一次立功补过的机会。岳飞便写了一封信，约刘豫合谋诛杀金兀术，并且对间谍说：“我暂且饶了你，给你一个带罪立功的机会。你再去一趟齐国，同刘豫定好举兵起事的日期。”

说完让人把信用蜡汁封好，割开间谍的大腿，把信夹在大腿肌肉中缝合，还反复告诫他不得泄密。间谍回去后把信交给了金兀术。金兀术见信吃惊不小，火速派人把信送给金主看。金主大怒，当即废了刘豫。

# 反间术
“间”是间谍，“反间”就是设法把敌人的间谍为我所用。运用反间术的主要手段是，遇有敌方间谍来刺探情报，可用重金收买，使之叛离敌方；或诈痴装憨，故意提供假情报，使敌方上当。

# 陈平离间范增
楚汉相争，项羽派出十万大军，扬言要夺取重镇荥阳。刘邦急得坐卧不安。陈平安慰他说：“项羽手下不过范增、钟离昧等几个人算是人才，其余的都庸庸碌碌不足称道。项羽为人猜忌，容易听信谣言。只要大王舍得钱，我就有办法对付他们。”于是，刘邦交给陈平许多黄金。陈平挑选了几名心腹，叫他们打扮成楚兵，混到楚营里去了。过了几天，楚营里就三三两两地议论开了。有的说：“范增和钟离昧有这么大的功劳，可什么好处也没得着。”有的说：“要是他们在汉营里，恐怕早就封王了。”这些议论传到项羽的耳朵里，他不免起了疑心，就不再跟钟离昧商量军机大事了。可是对于范增，他还是信任的。

又过了些日子，项羽派使者来到汉军。陈平把使者领到宾馆，摆上丰盛的宴席，并亲自作陪。他故意问使者说：“近来范亚父贵体如何？有没有他的亲笔来信？”使者不解地问：“我是项王派来的，怎么会有范亚父的亲笔信？”陈平听了连说误会，离席而去。不一会儿，来人把原来的上等酒席撤了下去。又过了好半天，才见一两个人把粗劣的食物端了上来。使者别提有多窝火了，回去后把所见所闻一五一十地对项羽说了一篇，更加重了项羽的疑心，对范增也不再信任了。范增看出项羽冷落自己，又难过又愤怒地说：“天下大事已经定了，愿大王好自为之，请允许我回家养老去吧。”项羽巴不得他快走，就爽快地答应了他的要求。范增一路走，一路叹气，还没到彭城，就毒疮大发，死于途中。失去了范增等人的辅助，项羽变得越来越被动了。

# 高明的泄密
东汉时，秦丰自封为楚黎王，与汉朝对抗，光武帝刘秀派岑彭前往征讨。秦丰也不甘示弱，电兵邓县，阻挡岑彭的进攻。几个月过去了，岑彭依旧无法取胜。一天，他突然声言改变战略，要进攻山都。军队出发前夕，岑彭给俘虏训话，让他们去留自便。俘虏们很高兴，有的留在了汉军中，有的弃甲归田，也有的又回到秦丰那里，并带回了岑彭将要进攻山都的“情报”。秦丰深信不疑，马上亲率重兵去镇守山都。不料岑彭根本就没去山都，而是率军直捣秦丰的老巢。秦丰见上了当，连忙回兵救援。结果半路上又中了岑彭的埋伏，全军覆没。

# 张飞打伏兵
刘备占据徐州后，曹操派王忠、刘岱分两路前来攻打，刘备则派关羽和张飞分两路迎击。关羽与王忠接战不久，就把他活捉了。刘岱听说后，便屯兵坚守，任凭张飞如何叫骂，只是不出战。

张飞便整天在营中饮酒，常常喝得酩酊大醉。一天，他借着酒劲儿，找了个借口把一名士卒狠打了一顿，并扬言：“等我今晚劫了刘岱的营寨，回来再杀了你。”说完就假装睡着了。那士兵怀恨在心，半夜时分溜出军营，跑到刘岱营中，把张飞劫营的“消息”告诉了刘岱。刘岱知道张飞为人暴躁，又见那士兵伤痕满身，不由得 不 信。便 急 忙 下 令 出 动，在张飞的来路上布下了伏兵。

张飞并没去劫寨，派出一支部队正面攻打刘岱的伏兵，自己则率部抄了刘岱的归路。不一会儿，刘岱的军队便被击溃了，刘岱本人也当了俘虏。

# 班超散敌
班超调集于阗等国军队两万五千多人，打算再次进攻莎车国。龟兹国派军五万援救莎车国，形势变得对班超不利。于是，他召集各国主将，对他们说：“这仗不能打了，各自回国吧。于阗军往东撤，长史军向西撤，夜间擂鼓行动。”然后故意放走了龟兹军队的俘虏。俘虏回去后报告了班超的决定，龟兹王亲率一万骑兵到西边堵截班超，又派温宿国八千骑兵向东拦截于阗军队。班超得到敌军行动的密报，立即率领各部兵马进军莎车国。天还没亮，班超率军杀进莎车兵营，一举全歼了莎车军队，占领了莎车国。龟兹等国的军队听说后又惊又怕，纷纷撤回本国去了。

# 韦皋离间云南王
唐朝时，吐蕃派出十万大军侵犯蜀地，同时胁迫力量较弱的云南王一同出兵。云南王虽然已经表示想归附唐朝，可又怕吐蕃，便派了几万人驻扎在泸水一带观望。唐朝镇守蜀地的将领韦皋得知这一消息后，便给云南王写了一封信。信中极力称赞云南王归附唐朝是明智之举，并约他一同进攻吐蕃。信写好以后，装入一个银制的盒子里，派人去送。又故意把消息透露给吐蕃，致使吐蕃收到了这封信。吐蕃王看了信后，随即抽出两万军队去把守云南到蜀地的要道。云南王得到消息，立即撤兵回云南，决心归附唐朝。吐蕃由于失去了云南王的支援，力量由强转弱，多次被韦皋击败。

# 假话吓退十万兵
北宋宣和年间，刘延庆率十万大军攻辽。辽国派萧干出奇兵，偷袭了宋军的粮草，并俘虏了几名宋军士兵。萧干命人把俘虏的眼睛蒙上，然后装作粗心大意，把俘虏留在自己营帐内。夜半时分，萧干装作漫不经心地对下属说：“听说这次宋军来了十万军队，而我们却有三十多万军队。明天咱们把军队一分为三，分头向宋军发动进攻，争取一举消灭他们。你们这就去行动，进攻时以举火为号。”萧干说完这番话，有意让俘虏逃走了。宋兵逃回后，把听到的话对刘延庆说了。刘延庆信以为真，心里很害怕。次日拂晓，萧干命人分几处点燃大火。刘延庆见火光冲天，以为辽军开始发动总攻击，竟下令后退。宋兵急于逃生，自相践踏，死伤不计其数。

# 谈笑除叛军
曹玮在渭州任职时，号令严明，治理有方，西羌人都很怕他。一天，曹玮正召集众将领饮酒，有数千名士卒叛逃出境，进入西羌地界。边境守军飞马来报，众将听了相顾失色，不知如何是好。曹玮却谈笑风生，不紧不慢地对报告的人说：“这是我安排他们去的，你千万可别说出去。”这话很快传到了西羌，他们以为叛军是受命来作内应的，就全都杀掉。

# 麻仁节上钩
天后年间，契丹大将李尽忠、万荣之攻破宋朝边城，用地牢关押着几百名宋军战俘。听说麻仁节率领宋军将要来到，李尽忠故意让战俘喝粥，还假惺惺地安慰说：“我们已经没多少粮食了，杀掉你们又不忍心，放你们回去怎么样？”众战俘感恩不尽，跪拜谢恩，李尽忠就把他们全都放了。

战俘们回到幽州后，说了契丹缺粮的事。宋军将士听了，认为这是立功的好机会，争先抗击契丹军队。行至黄盗岭一带，契丹又派了几个老兵来投降宋军，还带来了几匹老牛瘦马。麻仁节见了不再有什么怀疑，遂扔下步兵，率轻骑飞快向前，闯进了契丹军早已设好的埋伏圈。结果麻仁节当了俘虏，前来救援的宋军被全歼。

# 王子醇放敌探
枢密王子醇镇守熙河时，西戎准备袭扰边境，就派了个密探来探听虚实。那密探行踪诡密，返回时被边防军队拿获了，在他身上搜出了记有熙河一带兵马粮草分布情况的图表。将士们恨得牙根儿直痒痒，异口同声，坚决要求肢解了密探。王子醇不同意，下令打了密探二十大板，就把他放回去了。他在回返途中，恰巧遇上了另外一支前来骚扰边境的西戎骑兵。他们从密探口中得知熙河一带已经有了准备，便退回去了。此后很长一段时间，熙河一带没有遭受西戎的侵扰。

# 韩世忠骗使者
宋将韩世忠率军驻扎在扬州，抵抗金兀术进攻。他命解远把守承州，对付金兵步卒，并亲自率领骑兵驻扎在大仪，想在此地抗击金军。他下令砍伐树木筑成栅栏，自断归路，摆出决一死战的架势。可是金军由于害怕韩世忠，迟迟不敢发动进攻。正巧魏良臣出使金国路过此地，韩世忠知道他没什么胆识，又有亲金倾向，决定借他的嘴引诱金兀术上钩，便命令全军撤掉锅灶，整顿行装，作出要移防的样子。魏良臣不解，问要干什么，韩世忠故作神秘地说：“刚刚接到军令，要我移住平江。军队马上就要开拔，不能款待您了，还请多多包涵才是。”魏良臣信以为真，匆匆上马离去了。

韩世忠估计魏良臣已经出境，下令全军重返大仪，布设五阵，设伏二十多处，相约以击鼓为号，同时发起进攻。

魏良臣来到金军中，金将裴儿孛堇探问宋军的动向，魏良臣竟信口将其所见所闻全都说了出来。金将听后大喜，立即出兵，向大仪扑来。韩世忠见金军钻进了埋伏圈，传令击鼓。顿时伏兵四起，把金军打得大败。

# 张魏公巧用反间计
南宋统制郦琼捆绑着吕祉，率部反叛南京，去投降了金国扶植的傀儡皇帝刘豫。消息传来，张魏公正在宴请部下，满座的人听了无不大惊失色，相对无言。唯有张魏公坦然安坐，愉快地喝着酒，尽兴而归。

当天夜里，他写了一封信，用蜡丸封好，派遣一个敢死的人去送给郦琼，信中说：“我们合计好的事能办就办，办不成，马上率部返回。”结果这封信落到了刘豫的手里，他看了信后便对郦琼产生了怀疑。于是把郦琼带来的军队全部打乱，归属其他将领指挥。郦琼本人则被软禁了起来，失去了行动自由。因此，北部边境未因郦琼叛逃发生动乱。

# 岳飞假撤军
