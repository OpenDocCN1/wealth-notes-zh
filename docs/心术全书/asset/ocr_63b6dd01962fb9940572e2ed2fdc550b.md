# 陛下山河已定

太祖命画工周玄素在大殿墙壁上画一幅《天下江山图》，他笔下万一不称太祖心意，后果不堪设想，就说：臣未曾走遍九州，不敢贸然奉诏。请陛下画出草图，臣下加以润色。”太祖操起画笔，很快勾划出了草图，命周玄素润色。周玄素说：“陛下山河已定，臣下怎敢更动？”太祖一笑了之。
