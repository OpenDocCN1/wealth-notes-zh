# 得 情 术

一张口就颠倒黑白，权在手就指鹿为马，会使得坏人得逞，山鬼昼舞；好人蒙冤，愁魂夜哭。如能明察秋毫，识破奸人的动机和用心，岂不昭然若揭了吗？官吏治事的政绩，最显著的要属得出实情。如都能这样，天下恐怕就没有蒙受冤屈的人。

# 恐惧的哭声

春秋时，子产经过一个木匠的房前，听到屋里传出女子的哭泣声。听了一会儿，他决定进去看个究竟。进屋后，发现有个女子守在一具男尸旁啼哭。子产见她的双手紧紧地合在一起，握住后又感觉她的脉搏跳得很快，便喝令把她抓起来。经过审讯，那女子终于吐露了真情，是她亲手用绳子勒死了丈夫。事后有人问子产根据什么捉拿那女子。子产说：“按常理，一个人发现亲人病了，显得心烦意乱；亲人病危时，显得很害怕；亲人死了，心情很悲伤。可这个女子的哭声中充满了恐惧，据此我怀疑是她害死了丈夫。”
