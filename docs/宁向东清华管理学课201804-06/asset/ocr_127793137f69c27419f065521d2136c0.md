# 划重点

+   1. 在激烈竞争环境中强烈变动的时代，能否找到适合的人才并及时调整这些人才的配置和布局，决定企业成长能力的速度。企业会额外在重大人才入角色问题，即“职业力”——即时可用人，是否“能谋定必能取”、“战之能胜”。

3. 一定要记得你要的是跳槽，而不是跳坑。

牛工
今天老师讲了如何判断一个工作的好坏，也他说判断一个工作好不好，主要从以下几个方面去分析。
1. 看短/长期收入构成：也就是这家公司营收、业务规模和做客户服务等上面去分析。
2. 短期收入是什么构成的：有人说“其于颜一能”，有人颜是“做”，好的状态，对于公司和发展都重要，这点可以从公司入手到公司展开。
3. 判断公司在行业处于什么样的位置：判断一家公司是否有成长，还取决于，根是看它的成长是“核心竞争”，能够渗透到多少人，确定“专业”，就是能够到多少人。
4. 企业文化氛围：如果说薪资是外部条件，一家公司，看它内部是文化氛围是是什么样的，对对待员工，以及对待产品，如何对待客户。
5. 最适合同寻找他什么工作的工，这个最适的是多，就是，要更多的聚焦在点什么，保持希望中。
如何判断一个工作是否是好工作，也总结为了：外部越稳定，内部越成长，个人发展越优秀，看前景越远，就越容易出好的工作了。
