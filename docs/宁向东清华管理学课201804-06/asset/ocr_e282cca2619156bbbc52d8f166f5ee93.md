# 24讲：职业规划个人变 革的坐标

你好，欢迎回到《向奈总的清华管理学课》，这一讲我们谈职业规划的问题，这是个很核心的概念。我们可以把一个人的职业生涯分为若干阶段，每个阶段都应该有一个大的目标。而在这个阶段中，每天所做的事、做的目标都将围绕一个特定的目标。这个阶段很关键，这意味着你最后的一个目标。当然，这个目标，包括有长期和短期目标，并不是固定不变的、一成不变的。它们会被调整，会根据你外部环境的变化和自己的兴趣才能为来历时调整。

上一讲我们讲过“战略方法”，就是讲在一个局部进行调整的时候，该如何把一个目标（支点）找出来。但是，无论你在做局部调整、调整自己的方向或者给自己一个长周期做一个长远的职业规划，要给它一个必须要在一个长远的职业规划，或者它要有一个长周期。然后把这个方向找出来，这样才能保证你一生的努力都能聚焦在一种合力。合力这件事有多重要，我通过一个例子，讲给你听。

读大学的时候，我练习过一段时间的标枪。虽然我的标枪成绩没有多好，但很长时间的训练让我有了一些感觉和启发，这给我后半生影响的一生。把枪标投向远，本质上要做的，是两件事：第一，就是出枪的那一瞬间，把全身的所有力量都形成一个合力的方向，把力量转化为枪飞出得速度；第二，出枪的时候，要确保在环境中没有阻力，或者说，要减少阻力，让标枪能够飞得再远一些。具体地说，这包括抓握、反力、角度、侧向、出枪的角度都应该有，顺风投掷、侧风投掷。出枪的角度都应该有。

当时练习的时候，并没有想那么多。后来我的时候越想，越感觉到，每一次出枪其实就是一次规划的过程。形成合力的一个过程，更是让每一次规划越加有效的核心原则。我们在过去的一年中，讲了很多策略、战略，计划、团队的内容，不知你是否意识到，这些零散的词都可以帮助组织形成合力，形成方向。组织的内容，或者是不能用于个人努力上，但更多的方法，都可以有助于我们制定更好的人生规划。

每年，都会有学生找我聊天，谈他们的职业规划。我给他们的第一建议，就是先找到自己真正感兴趣的方向，然后花上一点时间去做这件事。

+   1. 这个你真正感兴趣的，是不是真的所有兴趣，是否可以依托这个兴趣来赚钱呢？
2. 你自己在这个兴趣上是不是有天分，有能力？

# 1、以兴趣为方向

兴趣，进行职业规划的第一个重要概念，就是人的兴趣，兴趣在人的初始阶段非常重要。什么东西，真正让你有兴趣，让你很非要做，难道它也能给你什么实在的东西，这非常重要。如果你对某个工作在自己上的职业，都不感觉到它的辛苦，更容易做出成绩。多讲一句，强调兴趣人生的意义和收益也很重要。一旦成为专业人士，当他们在人生的中年获得了足够的财富之后，他们往往会在人生的后半段回归到兴趣，有兴趣也可以让一个不在工作的状态中，也可以获得幸福感。

很多人进行职业规划，最大人生是不是最关心很多人，我觉得这是一个误区。人生最大的乐趣之一，就是追热点，所以，我一个一个建议就是千万不要根据当下的热点来规划自己的未来。比方说，现在一段时间中非常火的字就是商业，好像挣钱多。挣钱是很多目的，在乎华的不少学生因此把专业选为自己非常未来事业选择的。但我非常常的他们不冷不热，就找不到他们之所以这样选择，核心是因为赚钱，而不是因为热爱。绝大多数入这个圈子来，是没有机会的。

以前写过一篇文章，我认为是关于几年，中国的金融史对于50万的宽裕早已已经过去了美国，这是不正常的，也是无法持久的。如果用这样的热值的东西来指导自己的人生规划，就会出现一个非常错误的，就是会走很多弯路的。

# 2、判断个人天分和能力所在

职业规划的第二重要环节，就是要判断个人的天分和能力的判断。我们在这个世界的人，形形色色，每个人可能不完全是自己天分能力的判断。比如有的人有从0到1的创新能力，就像我比上节里讲过的“空军”，他特别善于抓住主要矛盾，有序地解决复杂问题。他做事的随性很很像，像第二梯队人来推动第二，就难免越做越不顺。从古自今，所以你可以，这个职位做第一从来不容易坚持。但，也可以老经验转转，做出负效应，从而得到盈利的事业。

而有才的人，则是具备从1到1的能力，可以平推地推进自己的片。这种人要不名人，一出来会有很大的市场。成为一个人不名人，还有一些人，他们不具备从0到1的能力，只具有从1到1的能力，从他们到可以非常好好的职业经理人。我最近和一些企业的后辈朋友聊，我发现很有意思的是他们，他们对公司有非常大的判断。这些人，虽然他像从0到1的能力，但他们非常清楚知道自己不具备那1的创新能力，所以不是去追那自己手里，就可以找到一个有远见、有力量的领导者，而他们的天才，全部都如何成为一个有能力的帮助者，你是找不到的。
