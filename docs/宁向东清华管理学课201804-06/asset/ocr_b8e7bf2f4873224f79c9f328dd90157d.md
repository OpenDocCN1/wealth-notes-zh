前面，我们讲进了报酬包括基本薪酬和激励性报酬两个部分，这两个部分之间的比例，就是报酬的基本结构。接着，我们又讲解了激励性报酬可以细分为短中短期报酬和长期报酬。把这两个方法结合在一起，报酬的结构从大类上就可以分为三个部分：基本 的薪酬，也就是相对固定的工资部分；短、中期的激励性报酬，也就是短期业绩挂钩奖金部分；以及长期业绩挂钩的激励性报酬。

# 1.激励的组合比例

了解激励的有关知识，这三个部分的数量比例，它们背后什么含义，你必须非常知道的。这些知识，比如讲，薪酬支付结构，这三个部分的比例依次是 8：2：0，这是什么含义？我们知道，就是 0 者，意味着什么？没有短期的报酬结构。

一个普通打工者的报酬结构，他的工作性质相对比较好考察，甚至工作过程和工程状态都是比较容易监督的。所以，他的基本工资占的比例一般都比较小，奖金部分比较小，根本不需要他去跟长期业绩相关。管理上对于多这样一个报酬结构的人，管理上需要多下一个功夫，如果管理上失败，他们有可能出工不出力。

如果这个人的报酬结构不是8:2:0，而是5:5:0的有一个人长期激励性报酬，但是，收入的大头来源于工资，奖金部分比较少，收入结构就意味你拿的工资比例比较大，你的收入就来自于长期报酬部分，而你的报酬结构是平的，你拿的多不多，是年底那一样比较多。毫无疑问，你的组织对于你的业绩还是有着较高的期待的，只不过，你的工作对于组织的长期业绩影响不大。

那么，如果这个人的报酬是2:2:6，那这个意味着什么？仅以报酬来说，我们就可以推知什么？仅仅对于公司的未来非常重要，所以，在他的收入里面，过半的部分是长中短期业绩紧密联系在一起。如果是这个比例就确定，他是一旦实现了目标才会有钱，他完全有可能是在创业，或者是在一个高度依赖长线生存的行业中工作。

总之，考虑物质激励，考虑好报酬，除了总量非常重要，结构也极其重要。前面的课程里，我们已经讨论了业绩指标，你记了KPI，当这些内容确定了之后，你要好好对人、操好心，主要考虑的是一个的能力。

那之后要考虑的重要因素是，你如何支付薪酬。设计新薪酬，一看总量，第二看结构，再去看结构，你的结构，我们的长期激励性报酬的形式。也许你今天的工作还轮不到这些内容，但薪酬制度是最基本的职场知识，你需要知道。

# 2.股票升值权

我们昨天的课，重点讲了股票认购期权，这是长期激励性报酬的主要形式。但是，使用这种方式有多样的表现，比如说股票期权的结构，可以是股票，比如现金，也就是说，行权是要用钱的。如果当事人没有钱，那又该怎么办？一般来说，公司为了避免股票没有给到有钱人手中，或者拿不出那么多钱，会有一些相应的安排，比如由公司提供融资等等。

后来又有了这一大麻烦，还不如就给你的分量计算，直接给你现金。这就是我们后头出现了所谓的“现金升值权”，或者叫“股票升值权”，英文叫做stock appreciation rights。“现金升值权”或者“股票升值权”与股票认购期权有着相似的激励效果，但是，对于当事人并不需要花钱去股票或者，只是对于股票的升值部分支付了多少钱。例如，股票价格从6.5元上涨到16.5元，当别人可以以公司支付给他每股10块钱的现金，用于在市场上市上通过购买股票获得这一收入。

我不知道你听到这种方式之后，你觉得这种方式是不是比股票认购期权更好。固然，这样看去，如果从鼓励性考虑，它的吸引力是，但是，长期细心思考，会发现这种安排与“股票认购期权”还是有很多差异。在用股票认购期权的情况下，行使了权利，股票是股票，但是还有需要付出买，还需要拿到手的现金，所以，还有后续的激励作用。

比如，行权者在行权之后，他手里还拿着股票，这时候还会激励他，因为股票上涨的时候，他的财富还是会增加的。也也就是说，认购期权是一种在行权之后还可以持续地获取期权红利。相反，如果当事人是现金，他很快会把股票就卖了，那这之后了，下一个信号，说明他对未来的公司成长没什么信心了。所以，我们一个人就看多少数量，留下了多少股票，就知道了他对于公司的未来的发展抱着什么样的态度。如果这个人不断减持已经行的股票，甚至把行权后的股票全部都卖掉，股东也许就会考虑更换他了。

这些都是如果选择现金升值权作为长期激励手段，不具备的功能。也就是说，现金选择权，使用起来相对比较简单，它涉及到实益的获取，也有防止股权被稀释的好处。但是，它的创意也是有限的。你听听这里，大的公司以实现，不同的激励方式，都是会适用条件的。凡事有一利，就会有一弊。

# 3.限制性股票

比如，有些人，有些岗位，在某些条件下，必须要给予股权，而不是股票认购期权。比如说，大股东又怕拿不到无条件，因为他当管理者，或者拿了股权就离开了，或者不尽力，直接给了股权，就使这个很难收回。所以，股票要给，但是，你有权无限制，这个限制是给他的股东和股东权利不一样。因为你当管理者，拿股权的理由是要为股东管理好企业，所以要付一些限制他。这类股票就叫“限制性股票”。比如要求你必须在公司工作，你不工作了，那些股权也卖不得。
