# **周末荐文|你的努力，我都能看到**

**宁向东**

这篇文章是我以前写过的文章，放在这里，希望可能错过一读的读者，请重新审视一下这个很快讲旧的内容，你可以和我们周五做的理性的复盘结合一下，看看有什么新的体会。

每个人在离开父母，踏进小学之后，就算步入了社会，与你幼时不同的是，小学生开始逐渐有了自己的认知能力，开始形成朝向。特别是在学校的最后两年，那就是走向成反的年龄，你遇到的老师不同，就会打上不同的生死底色。所以，我一直认为，小学老师是除了父母之外最重要的启蒙者。

假设你的和你们的，混淆其间。

按照大心理学家阿德勒的说法，人与生俱来的感觉，就是“自卑感”，这方人在出生之后的弱小有脆弱。弱小感会变成自卑感，而面对自卑的态度，又会决定一个人未来的走向，最后决定一个人是杰出、还是平庸。

每个人出于本能，会对自己的自卑感进行挑战。阿德勒说，这是一种补偿动作。若补偿动作作为以自己的存在价值，人就会形成“勇气，挑战目标，挑战未来。而这种补偿努力太过得理想，自卑感就会形成“自卑情结”，会影响人的一生。

![](bbox=[0.1, 0.19, 0.9, 0.26])

我是阿德勒的信奉者。写这篇文章，是因为常怀念我小学的一位小学老师，她让我形成了最初的勇气。因为无法再找到这位老师，每隔几年，我就会写篇文章记录这个感念。

我读小学期间一共经历了五位班主任，几乎是一年一换，我留下了最深印象的，是教我五年级的李雯玉老师。虽然从小学毕业，我她一直有机会见到她，但她始终是我最近的有机。

李老师之所以对我的生命重要，是因为两件事：第一，她让我看到了公正；第二，最力重要的，她让我感受到：“你的每一分努力，我都看得到。”我觉得，这两条是天下为人师表者，都要学习的。

上学的第一天，奶奶对我说：你一定要遵守纪律，争取参加小红小兵。在那个年代，学生加入“红小兵”，一年只有两三次，每班两三个人。第一天上学的时候，哪里懂得这些道理，以为就像幼儿园游戏，只要听老师的话，就可以做到。

老师提的第一个要求，就是坐端，要背着手。我坚持按老师的要求背着手，心里想着只要把手背好了，老师就会把自己我的算盘给我。那几天的情形，至今仍然记得：那就是我的一个追求。仿佛我上学的目的，就是为了加入红小兵。

我是班里的后尾，一排，整个上午，我一直坐在班里。心里想，再比比坐得更好，我一定要超过他。一上午结束了，一天结束了，一周年结束了，我认为表现很好，但没有任命让我当红小兵的意思。我后来一直没有当，但依旧失望。但是，最让我不平的是，我觉得那些当过红小兵的人，并不比我好。

李老师让我喜欢她的第一件上，就是上任第一天，把一位主要班干部给了她。她让我感到了起码的公正。在我的印象，那个被推举给我的，如果他也不是有权利有势，怎么可以做班干部！

当时我还不太懂，但现在我知道了，能够当上班干部的，大约有这么三种人：长得眉清目秀，帮助老师管理学生的；以及有校有势的。至于像我这种什么能够不上的人，又只知道读书，在那个年代，永远不会涉足。

李老师是我第一位表彰鼓励的老师，这让我在我的读小学的历史上都罕见。她还让我第一次参加学校的夏令营，以及代表班级去参加学校仪式。去主题会的，一个班只有两三个，在仪式之后，还能看到一部电影。在那个大年，这是巨大的荣誉。

李老师为什么选我去，我不知道。我小学毕业后，李老师也离开了那所学校，我再也没有机会见到她。我能清的一原因，我是做班级，做认真。那时，没什么孩子正经读书，而李老师，每次都会背几张题目在板上，看看哪一个做答。我常是第一个做的，除此之外，我吝啬可陈。

那年代，不是比比谁学习好的年代。所以，我做优，并不像现在是，是什么优点，也不是老师鼓励的主流。但我确实喜欢读书，而且勤快而努力。李老师的行动似乎告诉我：你的努力，我都看到。

**你的努力，我都看到**！这对于一个孩子来说，是莫大的鼓励。这是一个小学老师能够孩子的全部财富。

我有时，后来赶上了一个读书决定命运的好时代，今天毫无疑问，读书是，这其中很大的功劳，属于我的老师，特别是小学时的李雯玉老师。

年纪越大，反思越多。为什么我会念念不忘李老师？除了她给了我生命信念之外，更重要的，她教会了我：世界是不该太顺的，只要你努力，我都看得到。这世上还公平，努力就有机会。

今天，我们都希望给孩子找一个好学校，仿佛找到学校，就一好手大事。但进了好学校的，很多人后面会被筛掉出来；而没有进上面学校，也有不少很多孩子成长起来。这里嘛，家长的影响，老师的影响，是最大的力量，但我们常常忽视这些力量，特别是小学老师的力量。

我经常和人讲，决定人生命运的，不是大学，不是研究生，而是中小学。小学，特别是小学，从研究意义上说，小学是决定一个人性格和命运的总要时期。小学老师，更是关键的力量。对于小学生，什么最重要？我觉得还是两条，小学时勇敢感觉，有了这两条，孩子就会形成勇气，形成主动成长的力量。

这些年，在尝试去寻我像她一样的老师也会报答着去寻。我努力像她一样坚定地对待每一个学生。在我心中，所谓因材施教，不仅仅培养顶尖尖子生，而每一个人都能尊重下，让每一个学生都知道：你只要努力，我就能看到。

现在，是一个既讲精神、也讲物质的时代。在这个大背景下，难免有些老师会把更多的注意力放在那些有竞争机会的孩子身上，因为这确实会让老师收放实惠，办成事情方便。当然，在全民追求考试成绩的环境下，老师也会格外注意和喜欢那些学习好的孩子。

但是，我还是要建议：每一位老师要把眼光放长远一点，多花些功夫关注一下那些不出色、却努力用心学习的学生，因为他们是生活中的大多数，是我们这个社会的真正希望。请老师们在班评的名单里，给他们留些位置，让班级并不出色，却愿意努力的孩子，有得到鼓励的机会。

对老师来说，给孩子多一点关注和鼓励，并不需要太多心机，只要把心情稍稍调整一下，就够了。有情怀，你稍换个角度，就会发现一个完全不同的人，一个完全不同的班集体。

当然，老师也是生活在现实世界中的人，需要金钱，也需要有人力，这是导致一部分老师功利化的原因。家长们对于抱怨，不知不觉，我倒是感谢那些令人念念不忘的老师开始，让你的孩子感受到这种提愿文化。
