# 256讲：火热的心\|愿景、团队与文化

你好，欢迎回到《宁向东的清华管理学课》。

这一周，是我们最后一周的课程。时间过得真快，仿佛就是一瞬间，一年的课程就束了。我年少时，读到那句“时光，如白驹过隙”。我没法体会。但现在，我体会的到过了。这个时候，我有很多的矛盾，也会很为自己遗憾，因为毕竟这一年的工友没有出去。我的努力，影响了十几万人，我相信将来还会影响更多的人。

最后一周，我讲什么呢？我想讲几位中国的企业家。这一讲，我讲了很多的例子，我肯定不糊涂，也讲了很多外国企业的例子，你肯定不喜欢。在点我的中，会有很多不舒服的。我想有一个有-点民族主义情怀的人，也对自己的身世和经历有关，所以，我特别希望我们中国的企业强大起来。不是表面的强大，而是真正的强大。

十年前，国资委的老主任李荣融先生曾经对我说过，我们现在还是世界500大，我们一定要努力做成真正的世界500强。在国资委，我一直关心底，今天分享给你。我希望你也能和我一样，把它记住，记一点。也有我的协会听到这个故事，只有一篇故事，我本来也没有，企业一点服务的过程，我就有这-一点认识和启发，做出一个点头的反馈，我觉得这是值得了。我坐在毛主席的助讲：星星之火，可以燎原。一个-国家的强盛，或是希望这样的“不学”一点点，积累起来的。我是希望有一天，在没有中，有更多的中国案例被讲出，有更多中国学者的理论被讲出。

讲个旧事给你听，大约你可以理解我为什么这么“中国”了。1995年，我在美国访问学者，旁听一个著名的管理学课程。我们比较熟悉，私下里也会找机会坐，或者再办公桌上的点心里聊上一口。她想知道，她说我很好，友好或“友谊”的背景，就让我后面说的事情，格外值得品味。

这位数学教授，是完全用笔教书的，所以每节课，他都会从口袋掏出铅笔大小的毛笔，里面装着一只黑色墨笔，桌上还有墨粉。这是我们第一次接触，这个世界上还有一样叫做“无光粉笔”。粉笔的密度很高等，所以很硬，也可以用笔书写，很多粉。我-节要写满了黑板，一支粉笔还用不完，而我们那-种几个会写满黑板，每次擦黑板，那种就是马缰墨的-种化学分子完全相同，这粉粉笔质量更好，不用很大的力气，你们都擦不掉。

然而有一次，他的粉笔在写到中间突然断了。然后，他回过头来看着我，笑着问我：就这一支，是他引进来的。接着，我为他并没有什么可遗憾，他-直要把断了的粉笔，扔到了。你知道吗？卫生间没有-点什么字，我没有意思的轻描，在，他显出平时精心藏在心里的，对于-中国文化的认知。

那截粉笔被我省了起来，-直放在我书桌最里的一-个角。它在那里躺了很多人，我很多次想起这个心情，但现在还有机会全做到。不过，总的，-下，我完全可以做的。因为在我的产进讲题，只要中国企业家不断地努力，我们总有让他们从心里改变认知的那一天。

下图是我的第一部华为手机。那是华为作为礼品送给教授的，当时在美国商务上销售，最切的机型设置的是英文，我是在外文里找机，没有声音而选择，这个手机，我用了一年半，设为默认语音。后来手-机换机，不是因为功能不够，而是我保存的东西多了，存储功能不够。我用这-款机发手机，也用过了三星的S2、苹果6的iPhone 5。我个人认为，仅就系统功能，它在没有多少差异，但用了苹果，更难受。当你在用作为手机的时候，打开音乐的相册，再看到那些歌曲，心情也平静多了。开个玩笑，这-定是华为没有想到的产品功能。

听到这里，你也许会得今天的课有点远，干千，不要-口气。讲课马-上就要结了，我和你可能会-起心里谈话的，有时候你觉得我东西，有可能是最真实的东西，有你得很快的小东西，可能到了另-个阶段，你觉得我是很土东西。马-上就要结束了，我-以后听我讲“废话”的时间也不多了，所以，索性就把心里说的话都讲-讲吧。

最近很流行-个词，叫做“接地气”。这个词，建议你-定要学“会”“分文二”地用，象牙塔里的东西，确实知道的不接地气的东西，也不是寻找-上要去知道他，不接地气的也挺正。但你多去，你货得它多，它不接地气的，原因可能在这个-方面，目的是不通你的水平、你的发展阶段，这个事从另外一个角度说，是你自己还需要进步。

1984年，朱镕基先生进了清华大学经济管理学院。1985年，学院招收了-两个年级。-个是我们班，在-校三年级的同学里选了2000个级，三年级的时候转到经济管理学院。另外个级，是从全国的管理员会里系统选拔了30位处级干部，组成了另-个同学学经验的干部。后边这两-个都是-有十几年工作经验的学生。清华早期的学员里是有三年，所以，我们两个级在三年的时间里，-起上课，朝夕相处。

开始的时候，人家说不定-到，朱院长并不讲高深的老师，至少有-点自，听都不感兴趣，觉得特别，你知道这个-个的副校老师，却我觉得非常难。这就是认可-个校的好，我对你看学习。觉得告诉你-道题目么，特别是难题怎么，考你就特别有收获，我只知道小，我还有一个境界，就是难题，我还能进法，他更关注学习的办法，基至到学习的环境，他因为学习方与什么做到，到了一定的境界，最后的，也许就是最难的。

今天的课，我们的主题是愿景、团队到文化。这一周-特别是最后一讲，就是从无穷完整，我看到了清华大学管理学院的几次变化，-直到今天的复杂局面。1984年，当时担任经院的第一任院长，他是用自己的身力，带动了-个学院的发展，而院长不是住，他是很好的老师，他经常来学院来讨论发展的重大间题，就是主持常务会。

我还记得我们那时候，他来学院，给我们讲话，给我们讲了一个极端庞大的愿景，要让学院建设成为国际先进、领先世界-流的理学院。他跟我，我们的讲-个同学们都相信，他说学院里的讲法，是学院发展的好的，说不好听的，就-是-分。因为清华大学的学习学院是管理，就1952年根据要求北京大学，整建制地给走了。中国搞了30多年的计划经济，管经是市场经济中的产物，我们那时候，还没有市场经济体系，还是社会主义计划的商品经济，什么都没有，要说世界经济第-流，我们做什么，是开玩笑吧。

但是，朱院长这个人的令人佩服之处，就他会用自己的真柔和行动，让你觉得这个感是可以实现的，而且完全有可能是实现的。他全国内我们最优秀的那些学院，举-个例子，1986年学习-门课（复利学科）。今天，任何高校都 条件开设这一门课，但我们那时候，中国的金融业几乎没有发展，连复利都没想过，专业、金融只有复利。怎么办？是朱院长们下来到国市找复利专家的一一位驻院长，在北京饭店，每周给我们讲两次数。你知道吗？神奇的变化就这样一点点的开始了。

后来，-直斯他做院长，我们肯定可以搞到国际-一-流。因为靠信念奔走，市场经理对于大家最新的东西，我们又太老。我的老师都是文革前清华大学数学院的教授，本事都是安实安在的。所以，只要思想解放，-定会有机会在国内创-流，在国际上道-流。

1994年，院长在清华大学经济管理学院成立十周年之际，他把他的理想很管理版做了表述。他的这篇宣言，我也放在文章里面了，请你今天读后再看-下。很多人到清华办公，都看看这-百二十-个字。现在仍在学院大厅的-面墙上，但你也许不知道背后还有很大的故事。
