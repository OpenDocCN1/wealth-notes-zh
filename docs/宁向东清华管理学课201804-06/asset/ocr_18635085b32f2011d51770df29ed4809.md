# 226讲：控制公司与控制水温，道理是一样的

你好，欢迎回到《宁向东的清华管理学课》。

今天开始的新模块，我们讲管理学上非常重要的概念，控制。控制不仅是管理学中的重要概念，也是生活中无处不在的现象和概念。比如，你熬一盆水，这里面就有最基本的控制问题。

首先，你要明确这盆水要干什么用，比如，为了给你的孩子洗澡，那就不能太热，假如你说设定水温是37度，这就是一个目标。然后，你可以用一支可用的温度计，把它放在水里，这个温度可以精确计一个反馈信号，你能及时知道水温的情况，然后指导下一步动作，是再多加一点热水，还是多加一点冷水。这就是一个简单的控制过程，一个包含反馈的控制过程。

我把这个控制过程，画了一幅图，放在上面。你可以参考这个图示，来理解最基本的控制概念。从图示中，你可以理解到：加水水的这个动作，可以加的是热水，还是冷水，即引发了那一盆水的温度变化，变化后的数据就是你的“结果”。那这个结果是不是你想要的呢？你只需要把温度计上的数字，和预期数温度计上的数字，和预期的数字相比较，最后一定能够得出来。然后，你可以按照这个反馈机制进行下一步动作，如加热水或加冷水，最后逐步把水温调节到你想要的37度，这是一个控制过程的逻辑。

今天的课后，我建议你好好理解一下这个调水温的控制过程，几乎所有的控制问题，都可以从这个典型的物理控制模型中演变出来。比如，我们很多人怕怕失控，那么，每当我们感觉到失控的时候，我们可以借助于这个调水温的逻辑过程，深入分析到底是什么环节出现了问题。

# 1.对目标的共识

比如，问题很可能就出在我们要事先对37度这个水温，并不明确。很多时候调整目标的过程，往往事先对目标并没有共识，特别是在制定目标和执行目标这两个环节，分散在两个、两个或多个完全不同的工作领域的时候，事后的失控在很大程度上是因为事前对于工作目标，大家没有共识。甚至，不仅没有共识，连“共识”都没有。也是说，最开始就没有形成一个可控制的系统。

讲到这里，请允许我把话从这里叉出去一下。所有制与公司之间认关系的情况，我将其分为三种：

+   1. 双方对于一件事认知上完全没有交集；
2. 双方有一定的交集，但交集的部分比较少，少量的双方认可，但不同，这时，两者都认为是自己的共识；
3. 大家看法相同的地方比较多，但总还是有“他识”，就是要求知道对方是怎么想的。

我们现在很多管理中出现失控问题，按照我的“调整目标模型”来看，原因之一就是目标并不明确。目标不明确，即使有了结果，也没有办法根据前面所讲的机制和结果对照的模式，来进行反馈管理。这时，如果感觉情况还不错，一般也就有认为结果不理想，是这些会产生失控的感觉。而目标失控的感觉，本质上是由于相关内容双方共识。不仅有共识，而且“他识”都有，甚至完全是“共识”，在失控的情况下，是根本没有办法进行管理的。这也是康德，普兰夫这些管理大师们在讲：没有共识，就没有管理；没有计划，就没有控制。

当然，中国人中“共识”，或者是在“他识”的情况下，有一套“控制”的办法。这方面的内容，我们在这个模块后面的课程中，会详细加以介绍。今天讲，主要是你先给大家一个核心的框架，通过一个框架，我们通过三周的课程建立一个关于控制的知识体系。我们先说目标，再有是控制的结果。这两周的课程中，对于控制问题，已经形成了一个认识。这部分内容构成了现代管理学中一个非常重要的部分。所以，我们再学些内容作为的这一部分知识体系的底色。

# 2.业绩衡量

现在再回到调温模型。这个模型中，有这样一个概念，非常核心的，是理解控制逻辑的关键。首先，就是我们在前面说的“目标”概念。37度，就是一个目标。在管理理论中，计划和目标是最基本的两个概念。在某种意义上，管理学家认为目标达成，其实就是管理。而计划，最终就是关于目标的设定上。所以，在西方公司里面，计划和目标就是法律。如果没有了计划和目标，一切组织性、协调性就丧失了。

控制中的第二个概念，就是“业绩衡量”。在调温模型中，放在水中的那个温度计，就是业绩衡量的工具。如果没有那支温度计，我们就无法对现实进行评价，也就失去了对局面、对进展作出判断的能力。我们前面讲到的，卡普兰的平衡计分卡和诺德豪斯等的管理思想和工具，它们为什么重要？就在于它们都帮助我们朝向某个方向前进，走了多远，离目标还差多远。
