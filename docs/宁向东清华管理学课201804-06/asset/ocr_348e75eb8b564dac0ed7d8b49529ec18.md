# ## 1.企业的人性面

上一周，我留了一个作业，让大家想想，怎么样去激励自己家里阿姨的烦恼。这是一个很典型的题目，可能即将进入到一个超级老龄的社会，摆在很多人面前的，就是如何调动自己的阿姨，如何说服这位阿姨尽可能地帮助自己。同学们用了很多我们课上所教的招法，来为阿姨设计报酬方案。我从业来看，大家思考得非常精细，非常彻底。

其中，一些同学把薪资搞得很精，用哪些指标考核，怎么求薪酬比例，以及怎样给钱，不能再到位了。但是，他们和我们强调无关的点位，也就是我今天想跟你强调的一点，阿姨显然是你出钱建立关系的，你的权利，也应该去思考建立合理的激励机制，但你首先要去把阿姨当成和你一样的人来考虑。

![](bbox=[0.4, 0.4, 0.6, 0.48])

1960年，有一位管理学大师，名字叫做麦格雷戈，他写了一本非常重要的书《企业的人性面》。在这本书里面，他提出了著名的X理论和Y理论。这两种理论代表了对人性完全不同的判断。X理论假设，大部分人天生就是懒散的，不喜欢工作，只要有机会他们就会偷懒，就会逃避工作。所以，我们在管理的时候，就必须要用强制以及惩罚的手段，使得他们在恶劣的工种投入人力和财力。基于对人性悲观的X理论，我们就可以把下属视为激励因素，同时进行严格的监控。

麦格雷戈在《企业的人性面》里写下了以下这样一段话，非常具有思考：企业：由于企业满足了员工的生理需求和安全需求，因此，满足员工的重点都转移到了社会需求和自我实现的需求上。他认识到，除非这些高层次的需求有机会去得到满足，否则员工会产生剥夺感，而且他们的行为会反映出他们的剥夺感。

这段话是什么意思呢？就是当员工产生了高层次的需求的时候，企业当满足了这些需求的时候，作用十分有限。而在工作中，当企业找到了唯一的激励方式的时候，是满足了员工工作兴趣变成了最感兴趣的目标，员工会把注意力都放在金钱报酬上面，于是，他也不关注其它的那些需求了。

我们再回到阿姨的这个话题上，当你把阿姨带到你家，从事一种感情很自然包含在其中的家务劳动，这种劳动包含家庭，要很大的地方去工作。必须要包含家庭般的信任和价值，而如果你和她的之间只是建立一种金钱关系，而你在设计激励机制的时候，又特别强调这种物质激励的这种作用，这时你会发现自己越来越不再会这种激励机制，你会发现，最终开始不是这种激励机制所诱导，而是越来越开始不是这种激励机制所诱导的，最后也许会真的X理论所描述的那样。

我今天讲的麦格雷戈的《企业的人性面》这本书的相关内容，实际上是为了对前面讲的物质激励方案加补一针剂点。理想来说，物质激励是有科学的激励机制的，我认为是物质激励是必要的。所有人，包括阿姨，包括和你，出来做事，更多目的就是为了赚收入。所以，我们面前几千块钱的那物质激励的时候，肯定是希望你赚得好的。但是，我担心你走到一个极端，所以，今天的课程是往后拉一拉。

麦格雷戈当时提出X理论和Y理论，对于美国的企业家和管理学界的冲击是非常大的。说了，我们现代的这种物欲企业家的逻辑，是来源于美国的文化、美国企业经营的逻辑。你听了才知道，美国人在经营方面的逻辑，也就是所谓管理智慧的这套逻辑，比索罗的科学管理还要历史悠久。但是，在60年，麦格雷戈站在可能还不能看清这个逻辑的局限性，它可能是全面、不完整的。

针对X理论，麦格雷戈提出了关于人性假设的Y理论。Y理论是说，大部分人并不天生就厌恶工作，对于许多管理者控制得当的时候，工作会成为满足人们需求的一种资源。在合适的条件下，无论在任务的自报满足或适合实践的实现，需求的满足，会引个人人生组织目标的实现而努力的动力。在这种情形下，大部分人会愿意接受责任，愿意承担责任。大部分人，管理学者会会在自己和工作之间建立一种合作关系。

# ## 2.激励不应简单套用X或Y理论

当然，麦格雷戈是个绝对的聪明人。他提出X理论和Y理论的是说，并不是想用非即非的两分法来让人看待世界。他也给这两种假设，更多地是希望管理者抛弃X理论的旧习，更多地去关注Y理论情况下人性积极的一面。

就好像，我们考虑阿姨的报酬问题。如果我完全按照Y理论去思考问题，我觉得会麻烦，因为人们的境界还没有普遍达到这种高远的状态。上个月，我在香港开董事会，我所住下的酒店下面，有一条繁华的街道。这一对俄罗斯籍的白老夫妇在拍的照片。这句话听起来像是摄影家，正在游世界。一边游玩，一边用他们的相机记录这个世界的美好和名誉。

他们的照片拍得很有水平，印到成相片放大，摆在商店边出售。原来的意思我本来不知道，但看到商店正在摆着的一行说明上写着，每张照片十块一张，他们就想免费拍，免费摆着，想多赚钱，就多少块钱。无论如何，这是一个观察人性的视角，无论如何，罗斯信这个假设，我要看到在看看在最有经济消费的商人，内地人和洋人，人性竟是这样的。

坦率地说，我们将半个小时的观察员们挺不高兴的。不说了，人性摆在眼里，我们不应该只是针对几块块钱拿人家一张照片的。也许冲印也有代价，但是，旅行人、酒店、找电影等时间，假定他们对俄罗斯情侣的冲动没有一张照片的话，那么，自己会想一张照片不应该那么少的钱，就拿走人家一张照片。

我讲这个例子，主要是说我并不是个书呆子，会简单地相信人性的Y理论。我们可以还原简单地去掉推演的假设，但是，这不妨碍我们用Y理论的思想去全面地考虑问题。

我的一位朋友有个管家，她对待家里的阿姨，其实是太吝啬的，给她的钱，她只会给多少。但是，她在给零钱的基础上，更多要求一个人明明。她很真把阿姨看成家人。她说，她平时不在家，照顾家父母的事情，就是子女的事情。如果你不把阿姨当成姐妹，你怎么可以指望阿姨像孩子一样去关照她呢。我这位朋友总结出阿姨的经验，有三个核心点：好人，金钱，情绪。说这一，一条也不能少。
