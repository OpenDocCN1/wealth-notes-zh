# 周末复盘｜欢迎说说你的复习建议

本周末我们讲了控制活动的基本逻辑，最核心的内容就是第一天的那个架构图。请你周末花点时间把那个图复制一下下，最好把它记住，当知识，我觉得如果学到如下状态，就OK了。

第一个层次，就是核心内容一定要死记硬背。你可以通过给同事、给朋友分享的方式，边讨论边达到这个目的。总之一句话，关键内容不需要多，但一定要记住。比如，刚才控制中的控制模型，有控制的目的、周期和反馈逻辑的概念，就是必须硬记的内容。死记硬背，不是要一个字不差，而是自己用一张白纸，画一画，大概你能画出来，就OK了。

第二个层次，不需要死记硬背，但是你学过之后，在自己的头脑中一定要留有印象。别人说起这件事，可以接上别人的话。比如，本周我们讲到可控性失控的道理，就是因为没有方法控制结果，所以尽量控制别人的投入，控制这个过程。这里需要注意的是，控制是看不见结果，无法对工作进行追求的时候。通过控制别人的投入来追求进步的效果。当然，用忠诚的人，能够控制住他，这个人的能力可能就没有发挥的余地。所以，这个时候就要有一定的心理的底线。

这个道理，你学过这门课，虽然不用死记硬背，但这个道理你懂了，我觉得就达到了目的。第三部分没有，也许你还会到自学去讲得很彻底。没关系，只要有概念，别人提起这个话题，你作为旁观者，能接得比别人接得上的话；别人对你问，你说出这个想法来，就有交互互动的能力。比如别人说失控循环，你知道是什么意思。我觉得，达到这个层次，就可以了。

在清华读书，一门课程一个学期，我的学生基本要求就是这样：死记硬背的不到20%，而另外80%的内容，理解了，知道了，就够了。

至于第三个层次，会应用，那是后面慢慢练出的问题。有很多同学给我留言说，老师讲的课，我都听懂了，但还不会应用。我特别能够理解，你特别难。线上的教育服务平台，目前还比较难实现真正的教育功能，还是一种信息单项输送的媒介，在这个平台上，同学们还很难相互讨论，这也是我们下一步要解决的问题。

另外，很多同学有知识上的焦虑，有认知上的心态，我觉得是正常的，因为我们是自学的。记得我刚开始工作的时候，和同学们也交流，发现他们很多东西，我都不一样。即使是我当时就带着一半的教师的同事，去企业做课题，我就发现他们会的很多东西，我都不会。后来我发现，他们其实也很难。因为会的东西，他们也不懂。过了一段时间，大家就都自信了。认知有层级，当你把任何一门学问学深了，其实认知问题也相应解决了。

最后，我们的课程有一周就结束了。我先提前给大家说，希望大家一起复习一段时间，你还有什么建议，可以给我留言，我都会看。
