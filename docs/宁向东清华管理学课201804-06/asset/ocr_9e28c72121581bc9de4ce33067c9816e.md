# # 复盘：课程结束后的安排

复盘：课程结束后的安排

我们的课，还有一周就要完结了。很多同学都关心后面的安排，比如要不要开第二季。等等。今天，我把后面的安排和大家说一下。

第一，我 现在可以非常明确地告诉大家，我目前还没有开第二季的计划，但会对这门课的内容进行迭代。迭代嘛，会在我跟一些内容专家进行深入沟通， 那么，我目前的同学们都不用额外花钱， 就可以继续收到更新的。反正我额外的，就是一旦订好了，就可以一直听下去，所以， 我保证所有订阅这门课的同学，无论是想在旧的，还是接着在旧的上面，都可以得到永久的服务。只需要只动脑子的话， 这门课就永远在那里等着你学习，一句话，无限续航。

第二，在6月13号左右，也就是我们的课程刚结束不久，我们会有一次 线上直播，算是 一个结课直播。我们就不会叫它毕业典礼了，有些课，你永远在路上，没有结课的那一天。管理学永远都处 于这个上了1门。我现在的态度是请你参加这门续课直播， 到时候，我将和你分享一些我 进一步学习管理学的方法。

第三，我这个人 干不成什么大事情，很多事情，我都是干过干过事必须干完，比如，回复留言，我不太喜欢用别人帮我回复留言。有时候， 我因为在想别 故者，或者出差、不能及时地回留言。应说，在留言功能上，我做得还真够好。 但我确实告诉你，很多新进来的同学，在前面课程中的留言我都没有看到。结课之后，我会慢慢清理前面的留言，有些留言，我会认真回复。特别有意见的留言，以及有同学提出的得有共性的问题， 我 将 在个人公众号“宁向东的管理学 读”，做更 深度的分析和回复。请你关注！
