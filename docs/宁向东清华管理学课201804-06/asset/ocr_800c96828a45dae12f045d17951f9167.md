# 2.控权先控人

今天花了这么多的耳笔，来说讲蒋介石和孙元良的故事，其实就是想证明中国式控制的底层逻辑：控权先控人。我们下面仔细研究一下。任何事，你得请人去故，如果能能解一件事件的细节说清楚，你也能监督每一个细节，或者即便像一个模块中所说的，你当然监督不了细节，你还可以设计这层激励制度，在这种情况下，你想想是不是谁干不于干这些事都可以，是不是事情无所所谓。能一切可控，一切结果，亲人听我们都能估计到底。根据任务的目标，就可以建立起我课上所讲的“反馈机制”了。有了这个反馈机制，就可以控制了。

但最大的问题是，在很多情况下，不仅细节不知道，任务事先也没有确定不知道。通过场域化的方式，通过不定的方式来做决策就是这么做。在这种情况下最好的办法就是借线的人品行，这时权威是第一位的。因为忠，所以，你做任何变化，这个人都不计个人得失，紧随着我变化。

什么是控权？控制就是随时间变化，朝向既定的目标，如果目标看不清，就是朝向愿意的方向。当必须设定过程里又有空理、核心关系加关注法，过程里是又有空理性和坚定性的两个方面。用计划，用死性，就是解决定过程的任控。所以，控制了任性，实际上就控制了任，控制了过程。

于是，有人问了。在控权先控人的这个控制过程中，两个方面里，是效率更重要，还是稳定性更重要？我说，对于这个问题，我没有答案。不同的情况，谁轻谁重、轻重缓急的观念。但你可以解的和不确定性是用稳定解决；确定性解和的是有有效的问题。效率问题是多和少的问题，你说，哪一个重要？
