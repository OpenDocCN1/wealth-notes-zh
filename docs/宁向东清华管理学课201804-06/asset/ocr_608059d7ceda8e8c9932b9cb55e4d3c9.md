# 谢谢你，我们一起做了件有意义的事

宁向东

你好，这篇加餐是一篇告示，主要说三件事：

第一件事，也是最重要的，谢谢你的支持！

我在之前的课中提过，希望你留言写下对于复习安排的建议。其实，何止是在课程尾声，从开课那天起，你就是重要的参与者，我通过你的留言、反馈，逐渐摸索着互联网教学的新形式。

坦诚讲，一开始没有知道怎么做。我不知道每个概念，如果没有黑板，该怎么讲给你听最好，也不知道课是讲难了还是简单了，每周是不是该为你复盘一下。我不知道，那些本来讲给经理人的管理工具，通过我的改进，是否真的会帮到你。

如果你细心，就会发现这种摸索的痕迹，没有你的参与，这门课不会是现在的样子。

我曾经在课里说过，很高兴能和你形成亦师亦友的关系。这一年，通过这门课，我们超越了普通的用户关系，甚至超越了师生关系，如果《宁向东的清华管理学课》能够在将来，帮助到更多的人，那是我们共同的成就。

第二件事，课程最后两周是复习，我会打破模块的间隔，为你串讲内容。如果你是新加入的同学，到时候可以把最后两周的内容，当作你的学习指南，或者导游地图。

在这里，我想再次询问你的建议，尤其是新加入的同学。你可能还还没有看到课程整体的风景，当你看了标题，或者前几讲，你的困惑是什么，请告诉我，你的意见非常宝贵。

第三件事，对外我还没有说，先对你说，算是提前剧透。我会在全年更新完成后，定期迭代课程的部分内容，并且持续与你互动。

我会重新整理案例，加入到合适的位置，关于概念、观点的表达，我也会用更贴近你的方式重述。

我希望这门课，能够长期作为我们交流的平台，同时，我也希望这门课能够反映管理学基础理论发展的最前沿，所以，它一定是一个不断完善的产品。

最后，再次感谢你，近一年的时间，为你做课，感触很多。

结课时，我也会找一天再做次直播，到时候和你交流。
