# 257讲：冷静的脑 在趋势中找到机会

欢迎回到《宁向东的清华管理课》。

昨天的课，叫“热心的心”，讲的是做事需要有原愿。今天的课，叫“冷静的脑”，讲的是要看清方向，找对方法。今天，我们和你分享课件一位中国企业家的认识，也就是我在课程中多次提到的宁高宁。个人认为，宁高宁在比较把控、方向判断方面的能力，在中国企业家中是非常少见的。

举个例子，十年前，电商还没有像今天这样强大，既没有所谓的“互联网+”，也没有“+互联网”，明确提出，作为一家老牌国有企业，中粮集团已经开始布局了，这就是“是我网购”。

2010年，在中粮的负责人有个著名的“6号文”，作为中粮原来的负责人，宁高宁解读“6号文”时，说了这样一段话：我主网会带来一个崭新的销售模式，可以依托于中粮集团，但它也几乎可以成为一个独立的业务，如果做得好的话，我主网完全可以引领出一个未来的食品营销的主流方向。

宁高宁说，未来，随着人们对网络的依赖越来越强烈以后，可能会在很多产品是不需要一定到商店购买的，比如说水、面、油，它将来可以做成一个网店，可以到家，另外，这些东西在传统网络物流链中要经过二、二批、零售商等好几个流通环节，生产厂商和批发商的利益都搭进去了，如果我来做，只有一个环节，那我们的利润空间也会很大，我们给消费者，生产厂商的谈判空间也会很大，这里的消费者，中间就没有了，资金物流就变顺了。所以，当有人问我，我主网会做多大，我这么说。这个，如果做大的话，能大过中粮集团，未来发展潜力非常大。

> 请注意，宁高宁讲这番话的时候，不是现在，也不是在2010年这三通“大卡”争议的时候，而是在2010年，你不得不佩服，这就说明出一个超前的商业能力和布局能力。我买网负责我小区的那个快递小哥，来自河南商丘，我们定期取快递，每次他见客户，到门口或者会来敲门见几面。他每个月也可以拿到8000到10000元，所以，做得很头。后来，我买网开始有了带盖自式的快递站，纸箱是特制的，而且还会回收。“我买网”的网址和经营越来越复杂，做做得更加。那时候，我曾经想去“我买网”进行面试活动。所以说，我常笑说，“我买网”如果做不好，那真是起了个大早，赶了个晚集。

大约一年前，中粮集团推出了“五谷道场”这个方便面业务，收购方是做面线的光明面业。坦率地讲，看到这个消息的时候，我心里就猜测，我看到一个精准且当年收购“五谷道场”整个业务的战略行动，那么，今天推出的“五谷道场”业务，很可能就是一个欲出则生的埋伏。也许我的判断不对，不当家不知柴米贵，但我觉得“五谷道场”这个品牌是非常有价值的，绝不能轻易地处理掉。

五谷道场的创始人，叫王中旺，是我在清华EMBA的学生。受任王中旺，2006年我当班主任，我拜访了五谷道场的总部。记得当时我们东跑北走了不少地方，河北、北京。创始人也是我们清华的同学，叫陈淑华。老板那时候公司很难，产品太少，做企业的思路和动作都太拘束，今天，老板的企业已经有很大的影响，公司核心品牌叫“君乐宝”。

跟老魏相比，中旺就没有那么顺利，一路遭到业内大佬的质疑和淹没。但即使如此，中旺还是创造出了一个方便食品的新概念，他们打出了一个“非油炸、更健康”的概念。2009年，中旺没有能够抵住压力向大企业开放，把公司出售给中粮。对中粮，这是一次战略性行动，进行了收购。

前几年，我们到处都能看到“五谷道场”的广告，“五谷道场”这个广告，传递出了健康产品的概念，而且这个概念的信息越来越浓了，不过，在中粮道场品牌内部越来越有说道的同时，它的市场营销一直在今天为止。多年来，我一直把它当作一个典型的中国企业案例来研究，来看待，但我也没有想象到会有一个公司扭亏为盈的方法。

曾经有一段时间，我一直按照“在面上做不出文章，就比文章做到汤上，做到调料上”。但后来我意识到，这都是我的思路，当改变不能取得效果的时候，在战略上就应该想想转一个桥来，甚至有时到别的桥上去，比如说过个桥梁。一段时间，我“五谷道场”传递的健康概念，接触到中粮集团的其它产品。五谷道场的品牌营销是很强的，但是，五谷道场的产品不大，包吃的情况下，最佳的战略动作，就是转行。

但我无论如何设想到最后的结果是什么样的，而且出色的结果是，价格在我手上，也许我的想法，但这是价格在我手上，没有几个亿的价格，也没有任何巨大的，谢谢我们现在是钱、收企业、企业战略问题，如果仅仅考虑到一块。我一时，中情企业，行业不会缺一个大企业。一段时间，中粮集团旗下有不少品牌，这些品牌的影响不如“五谷道场”的有很多，所以，我运用新的方法，五谷道场的整个业务只要5000万，从战略上看着是一个巨亏。

当然，这只是个人的看法，如果你对不，不妨把这个专题作为案例研究一下。有同学给我写信，老师说，课时马上结束了，能不能写一下考题，让我们做一下，我还是说掌握了这个问题，有个什么填空些，选择考试的考题，你感觉怎么样，在学习，我觉得就这样，我无满希望不一样，在“得知”“得前”这样管理学的科学基础上更可能进行。而目前，管理学只考了100分，可能没有意义的，所以，可以说，我想法还少给你们一些实际的问题，引发你的思考。

五谷道场，在初始战局非常清晰的情况下，为什么，会做成什么样？这里面值得我们深思的原因很多，有行业的问题，有场有有打制的问题，有人产品力的问题，我们现在一说品经理，其实处在粗面油这块非常传统的行业领域，产品的逻辑，我们要更加清楚。如果，你如果有兴趣的话。不妨，可以用这样一个题目试试。

也许你会说，我没有资料，我建议你去网上查找资料。我也不会接问题，我不知道题目，我建议你，也可以去试试。你可以写，也可以写，这是你说，我写，你说，老师，你自己是想想，我写和你同心说，其实，是有机会和所有做五谷道场的当前人和访谈一遍，你不会得到真相。所有的，很多是事后归因，你还断的。这样的话有意思，很多时候，你必须亲自对你思维做分析的场景，对我猜述一遍，所有的真相，都事事后追回的。综合分析能力有些，不是真讲得不到。这句话也许有些学至今天还未能理解，等到将来有一天，你能够理解了，你的认知是真正提升了。

所以，完全可以写一些简单的资料去分析一个案例，一个真实案例，比空着大的，反之，你这不是发表，不是去给出一个重大结论，只为了学习。为了认知。我觉得，这是管理学习的正确做法，出一份考卷让我做做，更有价值得多。

最后，我再说说宁高宁，我一直好奇，作为一个成功的实业家，有深刻思考和作为的企业家，他的那种战略感觉是从哪里得来的呢？我想，这里面一定有原因，有能力的因素，但是，他的用和自边的因素，也是不可低估的。下图是一张写有宁高宁的简图，你可以看出他的那种用心，下面是每个企业家能够做到这一点的事。

宁高宁自成体系的一套管理思想，叫做“五步组合”，实际上就是我们“管”管理学的体系，我在“非专业管理”第一次看到整个体系的时候，那时他在华润集团担任总经理，我立刻对他印象深刻，得到很大的启发。他自己在阅读他的手稿的时候，得到了巨大的启发。

2007年，我第一次和宁高宁谈起研究“五步组合”的想法，那时，他已经是中粮集团董事长。2004年到2015年，他中间领国中集团了十一年，把一个散乱的公司带进了世界500强。2015年，他又转战到华集团，开始了新的“放牛”之旅。

在宁高宁的管理理论中，他特别强调团队学习和行动学习，无论采华润，还是中粮，中化，企业大家都发展得比较好。是什么？因为在宁高宁的管理理念中，培训不是一个独立的事情，培训本身就是企业管工的一部分，是领导者的核心就是经营管工组织的抓手。下图是一张宁高宁讲课中，坐在椅子上书写字幕的照片，其实，这个态度，值得我们每一个后来者学习的。
