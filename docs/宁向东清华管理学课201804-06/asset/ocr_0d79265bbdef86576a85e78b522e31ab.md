# 211讲：物质激励 I 为什么要给够钱？

你好，欢迎回到《宁向东的清华管理学课》。

上一周，我们讲了各种动机，讲了非物质激励的几种方式。这一讲开始， we 可以讨论一个经典的激励方式——钱。有一句话：叫做"天下熙熙，皆为利来；天下壤壤，皆为利往"，讲的就是物质激励的重要性。以前有一个电视是《编辑部的故事》，其中有一句台词，我记得很清，这句台词就是：钱不是万能的，但没有钱，却是万万不能的。所以，从今天开始的两讲时间，我们就讲给钱的技术。

# 1.为什么要给高报酬

把钱给好，绝对是一个技术活。比如，是给多，还是给少；是一次性给，还是分次给；是私下给给，还是当众发放，方式不同，激励的效果就会不同，也会产生出不同程度的激励机制。所以，把钱给好，不是小事，需要结合具体的情况，好好地思量。

今天，我们先讲第一个问题，激励的总量水平，也就是能给多少钱才合适。 理论上，取酬是给高-平均，就是付出报酬。我们讲的"按劳分配"就是这个意思。不过，劳动力的水平比较多难以衡量，劳动时产、工作收率，很多因素都影响着你的水平，所以，很难科学地量得到多少。至少，是我们一般采用对比的方式，再去判定一个岗位、一个人员的报酬是不是合理。

比如，一个人在一个岗位上每年的税前收入要是8万，这个8万的水准是不是合理，主要是通过比较来的，比如和类似行业、类似规模的企业相比，处于中位的岗位，大致就相到多少会，如果没有比较过，一般就会被认为是相对合理的。然而，一旦工作水平相对往高、在另外另一个企业的收人水平是1.2万，就会认为是分企业的。这道理很简单，因为别人比你高50%。在这种情况下，不仅很难产生激励效果，而且还留不住人。

我在很多企业的董事会上，都担任薪酬委员会主任得职务。当前我所遇到一个公司，就存在着工资管理的报酬偏低，如一家管理着几亿资产的公司，它的管理应该要多少呢？在一些企业里面，特别是国有企业的，报酬水平也许低的得令，有点地区性的几千块钱。也许也会觉得几百万已经得多了，其实，我告诉你，相对于同行，相对于管理层所管理的资产数度，这个钱少了，甚至到一种几乎不拿钱的程度。

我们大致算个账，一个经理人管着几百万、甚至上亿的资产，就真给点水平只有几个百分点，经理人给企业也挣回来几十亿，但他个的收入只有几百万。几千万了，个比概念上就是利润的几十万分之一。这个比例太低了。赚到了钱，拿不回家，他会怎么办？他就在积累消费，和工作经验之后，把钱花掉，是我职务的一个总结陈说话，就是拿不走，就把它花了。喝了、用了。这就是为什么公款消费没有人喊喊，管理团队为居高不下众的原因，因为最后形成了利润，和我也没有关系，那我总不如把它花掉。

其实，这种在消费还算不是很可怕的。比这种种可怕的是一半的。就是不好管理经理的资产业力。你不但不给他报酬，你也许还规定基本管理性行业的报酬，管的人最后赚到了钱，但是拿会分掉至少20%。这就是激励的资源。如果没有这样的分分制度，比如，管理人员拿基本管理性的分成，或者就是拿死工资，他是不可能精心管着基业财富的。

比如，在分配比例很低的情况下，管理人正在投资的时候，他会投资放弃一个项目。因为量小外，故意投一个项目可能会给带来好处，比如商面的一个公司给投资人带来利益私有，比如说，这个投资人正在正收益上没有净到多少钱，但是，收的利息会拿走很多。这个人就是为什么国的投资人一听说经理人就是比较少，而且和业绩不挂钩，他不敢干投资的原因。因为他不信不过你，他怕十万八千，不会把你给我赚钱这件事放在第一位。正是在这么一个意义上，我们讲激励总一定要足够，它必须在向上要有可比性。报酬总量上不够，什么都没得用。

# 2.多少钱是"高"

现在，再回到我前面讲的问题，当我作为薪酬委员会的主任，该给经理层多少元钱呢，管层管理的总水手多少合适呢？讨论这些问题的时候，我们该怎么样去思考呢？打个比方，资源的总水手和一个合起，多高、多亏，低的高总水平要与此接近，才起到一步。

比如，竞争对手的管理层中，管着500亿元资产的经理者，他每年的薪酬不到80万。那么，我们的经理人也差不多到，起点也要有500万。如果有80万，不仅不可能有任何激励作用，我前面说的那些负面的情况就会发生。

下面，我和你分享一个案例，是关于新加坡公务员报酬制度的。相比于企业的管理名，公务员的组织更难管理，因为它和企业不同，工资不容易评价。企业的管理者，不管是最高的大老板，还是基层的业务管理者，他们总是要有硬背到钱，最在里面说话。企业员工是没有到不到钱，是说不服力的员工。但是，公务员的工作没有用到，比如难以进行竞争。也正是因为在这一点，新加坡的做法就很有启发性。

新加坡的开国元首，叫李光耀。他有一个基本观念，叫做：人都是为了激励工作的。在他看来，如果新加坡的社会发展必须要依赖一个强有力政府，那就必须第一流的人才加入政府。要要要，要要要要要要要要要要要要，第一流的努力。否则，就有官员廉洁或激励不足，就会腐化和滞落。

李光耀说，"让拿薪薪水付不下去的公务员掌权，哪是小小小小，对于准备让谁用的人，所给他们工资不高，只等于他们在外面可以拿到的一小部分，而只是期待他们长期留在政府中，那是不可能实际的。"

关于这段话，我稍作一点解释。李光耀一直反对那种依赖于金钱的"民主选举"。你也不很了解，世界上有很多国家都采取官员选举制度，而许多所谓的"民主选举"，其实全是金钱选举。在金钱选举的国家里，候选人要获得很多的支持与认同，是要花要花去拉选票，选举人为什么要参与选举呢，本质上是是要来比选举投入的金钱有多少的。金钱，不仅要收回选举投入，还要有更多。所以，才可以有人来承认，否则，谁去做这么亏本的事呢？

所以，李光耀在新加坡坚决反对金钱民德模式，以证明新加坡就是要大别于其它出现的问题，用他的话说，就是要"减少腐败政府的先天劣病"。在李光耀看来，什么印度、菲律宾、泰国、台湾地区、韩国和日本的选举，都普遍有不同程度的贪污问题的根源。很多部是到根很深原，深入膏骨。什么舆论监督，其实都是一纸空文。

李光耀在新加坡避免金钱德道，甚至连车报选投票都取消了。他也是要在整个朝廷里推荐，让最有可能有作为的人来做政府的高级公务员。用他的话说，这些人即使不担任公职，也能享受高生活，而且收入也还挺当当的。那么，什么样的人有专业的人去做政府官员，应该支付多少报酬呢？

李光耀曾经说，"随着经济的高度增长，加比成年人设算的收人提高，部长的薪术必要要跟上私人企业家高极人员的收人。长积州政多过士国多士的应不应该为公事，而除了工资外还有多些的政府。为了使政治领袖和高极官员维持廉正操守的水平，给他们足够的的薪酬，是极其重要的。"

于是，新加坡的政府公务员有了这样一个报酬制度。首先，选择私人企业的管理人的薪酬作为参事标准。然后，根据岗位等因素来为务职的工资适当上下调整。一般认为，大约三分之一是私人企业管理人事正可以计入的三分之一点。这一点，意味着公务员的报酬和管理人员的报酬一样，是随着整个国家的经济水平浮动的。
