# 划重点

+   1. 职业规划是个人管理中的核心线索。职业生涯的若干阶段，每个阶段都应该有一个大致的目标。所有的阶段性目标，都应该向最终的目标。所有的阶段性目标，都应该向最终的目标。

2. 职业规划规划，首先要找到自己真正感兴趣的方向；其次，自己在这个兴趣上面是不是有天赋，有能力。一定要在自己的兴趣与能力方面做充分的调研基础上，避免碰暗礁，且能及时调整。

3. 年轻人进行职业规划时，多注意采用“专精”的原则。
