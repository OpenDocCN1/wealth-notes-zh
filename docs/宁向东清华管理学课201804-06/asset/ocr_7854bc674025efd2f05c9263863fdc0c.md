# 1、两条线的斗争

我们先看一个僵化是怎样起作用的。我们大脑中，有一个像‘公司’性质的组织，别看这个东西并不大，但它主导着影响我们基本情绪的系统，起到协调、整合的作用，简称‘反应系统’这样说来描述这个情绪系统，简单而有效，但是，自我控制系统中的两个模块。我们还有另外一个系统，是由前额叶皮层这个指挥来驾驭的。前额叶决定着你当下最主要的认知功能，当我们决定选择习惯时和意志力时，就是这个系统在主导。

下面这段话，可能不精确，但是我相信是正确的。人生所有的战争，根本上都是杏仁核反应系统和新系统系统的战斗。当你攻击竞争对手，每支军队自己拥有100个新干，按照常规部队，就是每支军队有100个新干，然后忘30个，或50个。然后，按照人的记忆曲线和遗忘规律，以一天为分界。再过几天，过后，记忆模糊，可以靠猜。但是，你知道吗？我们自己的实验，每支部队可指挥新干们部队和各种支持系统，都没有执行，坚持之路常常实苦。

我们的大脑有一种本能，会不断制造信息和偏差，不断通过这个节点发出信号，让我们有动力。这是通过杏仁核反应系统，它是以我们杏仁核前部神经为主，一种办法是可以通过控制前脑系统，比如制定新的，能够去以激励前额叶体系的计划和目标。

本周的课，我会讲一点点。我们对认知教育的了解。最近，我最关心我们的孩子。在中学校时，教育的问题不仅是在中学，在研究学历阶段，更多地是处在小学和中学。为什么这样说明呢？就是前额叶皮层发育的时间，在5、6岁的时候，才刚开始发育，到小学期期才发育成熟，而后期的教育与早期的教育又有着非常强的路径依赖关系。

# 2、设定目标与自我变革

你可能已经为人父母，或者即将为人父母，或者有孩子是家长，也是老师。请你记得，有些因素会受到影响你的孩子的脑力发育，会影响到认知如他的形成，会折磨的自利力，也会影响到维持自己正在进行的努力。

以下，来自科学研究的结果，请你一定要了解，最好牢记。

+   第一，尽早向孩子做出承诺，履行你对孩子的承诺。与科学家结论有关，对于儿童和成人的承诺，对幼小的实验结果来看，在情感方面，孩子和成人的反应关系，家长越严格就越承诺守时，到孩子翻前发育的时期就越大，也更容易发生发展危机。

+   第二，不要在压力非常大的情况下，强迫自己学习的新知识。实验发现，当一个人面临极大压力时候，他的前额叶体系的功能会受到影响，力量就会调去支持杏仁核，在这个过程进行实验，会使前额叶体系的压力下新工作时，往往效果不如人意。比如说，正处在一个项目实施的关键阶段，在这个过程里，希望你能减少新的关键信息，不太容易成功。所以，在自我变革过程中，尽量避免来自各方面的压力，其实，很多变革的失败，都是因为有压力过大而自我放弃。

+   第三，就要努力建立非可信的前景，建立清晰的标志。一个人的前额叶体系从来都是需要目标的。但是，我们的前额叶体系对发展起用，从来都是新的前额叶体系目标，能够看到目标，就是前额叶系统目标，它特别对目标进行反应，就是大量虚拟的，可操作的目标，来维持前额叶体系的前额叶目标。最终没有前额叶体系目标，而通过以期望前额叶体系前额叶目标。人，也就是不容易从梦里醒来。

当然，这些是反面的例子。如果从正面来看，用长效目标可以有支持。我们对前额叶体系，产生实际的能力。比如，在我读小学的时候，学习语文和英语，在小学时，下课去写英语，中间穿插英语。在，我小学时期，没有坚持每天坚持十分钟就不错了，更多的，是给自己做出各种理由，让自己心安理得‘明天再说’。

后来反思这个过程，并不是我不上心。因为我很好用，没有前额叶体系前额叶体系，更没有英语的目标却不明确。80年代，还没有那么多英文的工作环境，对学习的英文和简单学习研究，没多少有关。简单地，我学英语和写英语，不是以工作为目的。虽然，阅读许多书籍可以以工作为目的，英语，英语是一种应该的事情，而不是必须做的事。

我在某英文上的真正变革，始于1994年，因为那一年开始，年轻人讲英语要学来，不是为了因为我的第二次改革，什么？考到另一个难题，就是不知道，而那时，我考过‘这’目标，使用多次前额叶体系前额叶目标，我们前额叶体系的目标，都是自我。

每天都以坚持少于三十个半小时。某种意义上，对于我这只限于北京市场的级考试的人来讲，我的英语底子，就是在那段时间里打下了。

我今天和你分享我自己的亲身经历，是希望你认识到，个人变革能够成功，靠重要是制定清晰的目标，能够看到自己的名字的目标，有一位叫做约翰·邓普森先生的企业家，曾经写过一本通书的心理学著作，书名叫《黑点》。在这本书中，邓普森提出了这样的观点：我们每个人都拥有两个自我：一个是平凡的，淹没在芸芸众生中的自我；另一个是不甘于创新创造而独立的自我。这两个自我会在人生中会不时地进行竞争，并不停地争夺角色的转换，甚至会在同一时刻进行竞争。

我常常想，人的所谓进步、所谓追求，甚至发生人生的转折、变革，也许就是这两种自我交汇和斗争。而杏仁核体系和前额叶体系的斗争，也可以看作为两个自我的斗争。一个自我，是希望常胜自我的自我；另一个自我，则是希望是自我的自我，尽管我们对问题的判断，与希所期望表达的内容有着差异，但还是在意思表示两个自我的心理来理解人生，不同阶段应该追求自我的目的。
