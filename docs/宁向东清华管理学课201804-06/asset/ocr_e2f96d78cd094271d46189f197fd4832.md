# 250讲：创新者如何对产业发起进攻

你好，欢迎回到《宁向东的清华管理课》。

这一讲，我们从另一个角度来解读克里斯滕森的理论。虽然克里斯滕森并没有特别明确地说明他的理论适用于初创或新创企业，但你要是读他的几本书，你会发现：毫无疑问也是站在大企业、站在成功企业的角度来立论，来看问题的。克里斯滕森的第2本书，书名叫做《创新者的解答》，在这本书中，他的第一句话就是这样的：本书的内容围绕如何在企业内创造新的增长来展开。

# 1、从防守中找到攻击点

显然，克里斯滕森的书是写给那些已经在市场上领先、占据了行业优势地位的成功企业的，他希望帮助这些已经成功的企业应对“破坏性创新”的进攻。一句话，对这些成功企业如何防御，以及它们如何进攻，本文会讲些他的“破坏性创新”。不过，我在读克里斯滕森的几本书之后，发现，虽然克里斯滕森的初衷是为了帮助那些大企业，但他的理论对所有企业，对所有新企业开创者，可能更有意义。甚至可以说，破坏性创新的理论给予创新者的启示可能会更多。

也正是在这个意义上，我更多读那些创新者从失败过来的故事是读企业。坦率地讲，今天这节，就是讲给那些创业企业听的。当然，这也是为了讲和你一个书的缘起。我第一个管理课程一年，有很多收获，也留下了一些遗憾。其比较大的遗憾，就是内容上不够完整，有很多内容没有讲透。比如说创新的内容。我在清华的职位，是经济管理学院创新研究中心创新部的副部长，在我的课程，讨论到创新的讲课是很少，我自己是觉得有没讲完的，这些感受能否得到来课程进的时候，再想办法解决掉。

总之，今天，我是站在攻击者的角度讲的，我希望帮助你跟克里斯滕森一起研究，从大企业的防守中找到攻击点。你会发现，克里斯滕森所倡导的观点，就是管理非常优秀的公司，也会倒闭，管理很普通的公司，因为它有成功的管理经验，比如它在客户服务上都做得很好，有非常好的管理理念，都是大企业的老对手会站在台上。

但是，这些成功方程式会固化，会企业固化。当企业面对破坏性的技术、破坏性的商业模式，面对未来由新的创新的时候，会变得毫无办法。克里斯滕森的理论就是说：创新的外围企业很难保护创新。新的，小组组织，去夹击竞争对手。

那为什么放着资源来丰厚的成功组织不用，改用小组组织来夹击组织？克里斯滕森说，大企业总想取得更大成功，就是因为已形成定势，这种叫“组织惯性”，包括考核、配置资源的原则和逻辑，而这两个因素和创业者的底层原则，已经根深蒂固，是组织的主流管理原则。组织不可能自己的成功方案已经锁定了，因此，组织无法容纳不适合新业务团队的人。
