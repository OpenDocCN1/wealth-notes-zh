# 260讲：最后一课丨为你选一位伟大导师

今天，欢迎你回到《宁向东的清华管理学课》。

今天是你这一百订阅读的最后一讲。我和你分享一位中国企业家的故事，这位企业家的名字叫卢作孚。过去100年，中国出现了无数的企业家，也出现了数不胜数的企业家。如果你只能选一位企业家作为他们的代表，在我心目中，他应该是唯一选的那一位。而且，在我的日志中，他不仅是一位企业家，还是一位圣人。

### 1、卢作孚的管理之路

卢作孚的哪些方面会让会让我如此之敬佩？你知道吗？100年前的长江轮运，是中国主要的交通线之一，却是被英、美、日本等国的轮船主导控制。长江沿岸的码头、仓库，都是它们控制，它们招揽的。中国人自己的船，少得可怜，既没规模，也不成系统。

卢作孚在这些状况下，创办了民生实业公司。创办公司的那一年，是1925年，卢作孚32岁。生逢乱世，卢作孚的人生理念是：实业救国。

卢作孚从一只小轮船开始，一点点积累、一点点拓展。卢作孚非常有远见，将同民生轮船公司长期依循的管理理念引到民生轮船公司的运转过程之中。卢作孚借鉴了外资公司的管理经验，开始引入了“经理负责制”。

这一点很值得说。外资公司由于对中国人、路况、经营等多方面不熟悉，语言也多有障碍，所以它们实行“承包制”的管理方式，有类似于承包者的特点，就是享有承包费，可以为自己的实际利益和承包目的服务。它们肯定可以获得相对高的承包费，至于承包人怎么去经营船队，几乎深究不到细节。

于是，外资轮船的承包人，就只跟廉承包、廉价展现，甚至连用的船都是别人的。能用一样的，绝对不会投资到属于自己的资产成本。这样做的结果，就是工作效率和服务质量都无法得到保障。

针对这种局面，卢作孚在民生轮船公司采取了“经理负责制”，并且由企业统一聘用、薪俸收归公司。财务和油料管理都集中，技术业务由总经理统一负责。这是管理变革，也是企业不该在我们前面讲过的，西方同时代的那些管理先觉。

管理体系改善后，服务模式自然就可以上去了。在外资的轮船上，华人虽然是自己在国土上乘船，但不得不受到像二等游客的待遇。民生轮船公司为客户全程为卢作孚。在他管理下，公司的服务有改观，而且华人也享有自己的尊严。不仅有说起来很显“优”的尊严，还有很实惠的体验、服务，比如夏天在长江轮上洗澡，等等。

你可以想象细节多多，我只想参观参观卢作孚如此对待这段大历史的态度。你也应该参看卢作孚长外孙杨刚刚先生所写的《百年考水：卢作孚传》。

到了1937年抗战爆发之前，民生公司已经拥有了46艘各类轮船，总排水量2.4万吨。排水量，是衡量水上运输设施规模和水平的重要指标。2.4万吨是什么概念？就是可以容纳全中国一半轮船的数量。由此可见民生轮船公司在十几年间的发展速度和规模。

就这样，卢作孚就这样在长江轮运业中，在洋人的垄断下成立了属于我们自己的国民产业。当然，卢作孚的成就绝不仅于此，他还做了很多实业救国者。包括兴办大学、医院、学生、开矿山等，他还办学校，做发明，做很多公益，造福社会。

### 2、卢作孚的家与国

卢作孚为家与国仅仅做了这样一件事，他还不足以让我们永远纪念之作为中国企业家的第一人。1944年，一家美国杂志刊登了这样一篇文章，名字叫“卢作孚的长江轮船公司”。这篇文章中有这样一段话：在卢作孚的新船的一等舱里，他不惜从德国订进口刀叉餐盘，从柏林进口香皂，从丹特勒进口玻璃杯。但他在自己的餐桌上，却只放着三只青瓷的碗和筷子。甚至，他的家二层楼上有家居设备和器皿的机械，但为了强烈对照的是，他那被称为家的六间改修的农民屋中，围着饭桌坐下的却是一些光脚穿的旧式木条。

卢作孚的次子卢国纪先生曾经写过一本回忆录，书叫《我的家国怀抱》。其中有这样的记述：家里都是靠父亲的工资过活。不管是抗日战争时，还是抗日战争后，父亲的孩子是多是，但家里没有几日的日历，五个孩子在读书。卢作孚帮我家子的面条和零花的儿子的孩子。所以，经济相当困窘，但卢国纪先生仍忆道：为了节省，我们全家人的衣服，绝大部分都是我母亲自己做的。我们的鞋子，几乎我们的母亲一针一线做的。我只有母亲不会做的衣服，才难得到家里来做，不送到服装店去做。我们从小就穿家里做的布鞋，没有穿过皮鞋。

卢作孚家境如此，但他所创办的企业，在中国民商的历史中，是今日还在中国大地上扎根的。在《百年水国》这些书中，提到一个史实：1936年，在国共两党停攻时期，共产党为一致抗日，拟成二条双方双方成立五个部，每个部都有两个部长的候选人。但有多国系的部长，是作孚手一人，所有史实，在《民国资治通鉴》中也可见一面。于是，简子见，由此可见卢作孚在中国实业界的地位。

最近几年，很多中国企业家都在考虑家族事业的传承问题，也考虑二代的接管问题，希望后代的话能为这些企业家点点发。卢国纪先生记录过：1942年，有一位卢作孚的亲人活访问他，不知道替卢先生子女的解密自己知道为女子提钱放大，让子女家长不劳改，不愁吃穿。卢作孚一直不言不语，等到客人的长篇大论说完之后，他才告诉一个字：一个字地说：我没有给我的儿女留任何财产，我留给儿女的，是做事的本领。

卢国纪先生深有感悟地写道：这段话读得多么简洁，多么有力！它深深地刻在我的记忆之中，永不要忘记。

卢作孚一生多次出任公职，担任职务。每当他担任公职的时候，他就会将自己民生公司的薪水停领。日常生活中还可省则省，生活不讲奢华，把重要的机器设备、机关人员，甚至大学的图书报刊，用江水运输到重庆方向，为抗战出尽出力。卢作孚一生更不计个人，不计报酬工作。这又是如何做到的呢？

### 3、卢作孚：核心是人

核心还是人。

首先是人民安乐。民生公司不是只讲奉献、不讲利益的公司。公司员工大千几百，按照努力的程度和业绩的水平，分成五个级别来分红。有像今天的全员股份，也有典型的多劳多得、按劳分配的制度。一年，列名单的手头可以分到40多块银元。在那个年代，40块钱，就意味着很多。多说什么？你想知道任总经理的卢作孚拿多少？也是40块钱。

安居乐业是基础，而在此之后，则是帮助人进步。卢作孚曾经在一次演讲中对自己的前半生做了非常精练的总结。他说：“自己是在办学的事，也在同时办教育。在办学中的办学，同时还上一个教育，目前也在办教育，也就是办教育，是把教育事业当中全部工作人员，培养起来，提高他们的技术和管理能力。”

卢作孚曾经说过：“民生公司的事业，要想搞好，责全在人员工作上；所以，民生公司的问题，要靠职工来解决；同时，职工的问题，也要由民生公司给人们给解决。因此，我想在今天职工公上提出几点，将去年现得到万几水薪水，拿出当部建设工资公积金去，现在也给同职工在计算了。今年半年年主动工，明下年一定要的子息给职工。我就一座数学校修房都没有，废续着就要在那近设立学校，教育职工们的子女。”

这些文字，在人民日报出版社2016年出版的、三本套的《卢作孚全集》中，都可以看到。每次大家翻看这些文字，头脑中都会浮现出欧嘉，又清晰的一位中国企业家的形象。我很想在认知和社会企业之前，达到了那时的角度和认知。课程讲了一半，讲的无非是故事和认知。

1955年，毛主席说，中国的近代工业，不能忘记两个人：搞军工的张之洞，搞轻工业的张謇，搞交通事业的企业家卢作孚。卢作孚先生的企业，从战略的高度评价说，是“一个在当代大企业家的问题上，张謇的评价得格外高。他作为卢作孚先生心目中可谓是高山上松。在巨星家谱上，的那种人不但没有，为高不”的淡定超然，无人可及。

# 船说精选

抗战爆发后，卢作孚率船民以民生公司一家之力，完成了国民政府水陆军的战略撤退计划，为重庆大轰炸前大重庆工业的战略转移，为中国抗战工业取得了不可磨灭的贡献，民生公司实业家们这次出使被称作“国共谈判的国共谈判”和“国共谈判的谈判”。
