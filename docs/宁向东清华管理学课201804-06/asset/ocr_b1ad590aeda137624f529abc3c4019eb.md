# 周末复盘｜激励的经济学原理

你好，欢迎回到向东的清华管理学课。

上一周的内容，从心里学的角度来讨论激励的问题。这一周，则另一方面，主要从组织的角度、金钱的角度，来讨论激励的道理和操作原则。这也是思考从经济学的角度来看激励机制。

经济学有关这部分内容的基础知识，叫做"信息经济学"，信息经济学的核心概念是"信息不对称"。在1970年之前，经济学的"信息"是假设情况之下建立起来的，它特别强调市场竞争机制，以及由此建立起来的市场机制。1971年，经济学的这种平稳性被打破了，阿克洛夫、罗思、斯彭斯等人密集地发表了一系列的文章，把整个经济学的研究都推向了一大步。

这一大一步一直走到现在。有同学希望我推荐一些书，坦率地说，我不建议你花太多时间研究这个领域的问题，知道它皮毛，对你用处不大，深入地搞懂一些原理性的内容，也多半是过下去做某些数学推导，而这对于很多同学是不划算的。无论时间上，还是精力上，都不划算。另外，不用公式、不用数学，就可以轻松地掌握这部分内容，我觉得是太不现实的。

我们这周的课，只讲了激励设计的最基本原则，稍后关于"委托代理"。经济学将这一类问题结构化为"委托代理"问题。请你记住，委托代理关系不仅存在于企业之中，它是无处不在的。比如，当病人到医院找医生时，病人和医生之间就形成委托代理关系，病人希望医生给自己看得病，自己为自己希望买什么就一定买什么。学生和老师之间也形成了委托代理关系，教师付代理费，学生希望老师教得更多，学生是委托人，教师是代理人。

总之一，激励机制的设计应用场景很多，这一点是你需要记住的。
