# 1.动机产生激励

**首先，我们讲到：**激励并不仅仅来自金钱，很多内在的动机都可以产生激励，而有可能比金钱激励更加强大。比如，自

己的成长的行为动机，可以产生出极其强烈的动机。任由外部环境的顺应，这种激励都会让人产生承诺，承诺在追求目标的过程中不断进行自我约束。

当然，承诺升级是一把好双刃。最初的判断是正确的，承诺升级叫百折不挠；如果最初的判断是错的，承诺升级就叫一错再错。所以，很多表面上看起来完全不同的结果，背后的支撑逻辑是相似的。

复盘：承诺升级

# 2.环境与内容产生激励

第二个方面的内容，就是工作环境、工作内容可以产生出一定程度的激励。这就是设置的好的组织结构，不断完善组织文化的意义。环境好了，不仅可以使一个人有舒畅的心情，同时也可以产生工作的激情。

我们前面看领导力 的时候，讲到微笑的力量。领导者招牌式的微笑，就是非常好的激励。

昨天，一个偶然的机会，你碰到两位老员工轮流到车间一位新司机问操作设备，越起斥，那个新司机越紧张。我一下子就想到了以前在课堂上你分发的过“，这就是因为工作环境。我想那个员工会不会因为工作环境产生激励的效果，如果不是为了拿稿工，他一定会离开那个工作岗位。恶脸、恶语，只会让他产生离开的“激励”。

复盘：工作特性理论
复盘：工作再设计

# 3.工作目标设定理论

本周讲的第三个要点，是工作目标设定理论。设定较高的、员工可以完成的，同时员工认信的目标，可以产生出激励的效果。在这个目标中，员工从账非常重要，这一点你得记得。

复盘：目标设定理论

管理的这种心理学传统，我们八十 年来的哈佛管理学，来自于以前的梅奥、罗维·格兰等学者开创性 的工作。在那个时候，这个学 术分支叫做“产业心理学”。上世纪七十年代， 由于学者们开始研究得更细致，其结果就 是产生了我们这一周所讲的理论内容。

接下来两者都是 基于上个世纪70年代之后产生的的现代经济学理论。基于经济学视角的激励理论，所呈现出来的面貌是完全不同的。与心理学 不同，经济学家们讨论的内容，一切都基于两个 字：金钱。
