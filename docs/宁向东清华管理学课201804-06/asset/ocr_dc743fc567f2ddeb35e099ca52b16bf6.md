# 船说精选

抗战爆发后，卢作孚率船民以民生公司一家之力，完成了国民政府水陆军的战略撤退计划，为重庆大轰炸前大重庆工业的战略转移，为中国抗战工业取得了不可磨灭的贡献，民生公司实业家们这次出使被称作“国共谈判的国共谈判”和“国共谈判的谈判”。

到1949年，民生公司已经有148艘江河轮船，经营了76个多企事业部门，成为国内最大最富影响的民营航运企业。卢作孚是那个时代的一代霸主，是航运界里的船王，是时人所说的传奇人物。

只是令后人叹惋者，不读《船王》。未料到卢作孚的传奇结局竟然如此令人难抑。

通过卢作丰著的破航记和传记，我可以看到的是作为资产阶级企业家，他始终看到的是全民族大义，他管理理念是“实业救国”，他的社会理想是“社会改良”，他认为的民生公司宗旨，“救社会之贫，救民众之困”，“救民众之无知，救民众之苦难”。这种人文情怀正是他办事业、办教育的根本出发点。

民生公司，在中国抗日战争中发挥了重要的战略作用。抗战爆发后，国民政府军事委员会下令民生公司执行“宜昌大撤退”。这一任务极其艰巨，时间紧任务重，卢作孚先生带领全体员工夜以继日，在极其恶劣的条件下，完成了这一历史性的任务。

这段历史见证着民族的血泪与荣光！
