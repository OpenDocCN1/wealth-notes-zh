# 243讲：即战力法则丨跳槽的学问

你好，欢迎来到《于向东的清华管理专业课》。

在种种个人变革中，跳槽是最重要的变革。我前面的课提到过，像我们这个届 60、70后的人，一辈子为一家组织工作，是常态，跳槽对我来说，是不容做出的选择。但对于现在的年轻人，认为跳槽就是职业生涯的重要内容。一个人一辈子可能会几度企业服务过，将会是常态。所以，了解跳槽的逻辑、掌握跳槽的技巧，是一个必修课。

# 1、即战力法则

为什么这样说呢？因为企业的本质，就是资源的集合体。如果我们一提到资源，常常会想到实物资源，并且把实物资源看成企业的主体，比如厂房设备和资本。资金是主体，而人则是依附于厂房设备和资本的，在很大程度上，人是无足轻重的，是没有决定权和发展权的。但在未来，我认为，资本和资金，一定不是员工，以及附着在员工身上的无形资产，资金和装备是追在人流的。如果我们这个判断不离谱，那么企业的竞争在最低层逻辑上，就是对于人才的竞争。

一句话，在激烈竞争和环境剧变的时代，能否找到优秀和人才，就能不改变和调整这些人才的配置和布局，就是决定企业成长能力的关键。那么，如果企业的人员短缺，企业就会格外在意人才进入者的企业的，关键是即上，你这个人不像过去那样有耐心地去培养你，希望你成长，它会在意你在这个不是‘来之能战’；以及不是‘战之能胜’。有人将这一点称为人的‘即战力’，也是即时学、即时能力，我觉得是很确切的。即战力，也是这节课的核心关键。

如果说即战力是企业关注的，人才流动就会变得异常紧张。在这个大环境下，跳槽就会成为一个高阶事件。那么，我们该向谁去看待，如何把握跳槽呢？这节课是下课的，我就讲几个分享这个话题。这个话题，我是指从这个角度，下一节课将讲授职业规划这个话题。其实，这两个话题是一件事，是事件的两个方面。我认为，这也是个人变革的两个重要内容。

# 2、好的跳槽的标准

先从我一个学生的例子说起。这个学生在国外企业干了多年，年龄有35岁了，上下班通依然很不够勤奋，能力没有问题，领导也还算满意，但是，两个老板都不理想，使他很被动一动，有的有个跳槽的冲动。一家民营创业企业，去了的最好好处，就是固定的报酬可以翻一番，此外还有更大的空间，收入上可能会大幅地外边升。但问题是：还入到肯定原来的工作，因为民营创业企业，整个企业的舞台比原来的国企舞台要小。

第二个选择，是一家民营企业，报酬肯定是会比现在好一些，但不如前面那家民营企业高，目前唯一好处就是由他进入更专业部门的老大，也可能走向二层，并且更事更重的话，在他的舞台更大，他要去的那个部门是门企业正在企业平台发展的部门，要把学生企业的负责人非常看好他的学生，希望利用他的经验把这个业务做大。

我的学生在这两个企业之间选择，一时拿不定主意，跑来问我。其实，很多人面临同样的，或者选择跳槽的时候，遇到的问题都和他的学生一样，要么是工资好，但是发展空间有限；要么是舞台大，但是报酬待遇不理想，如何判断，这涉及到取舍方面来的，人选择问题的本质是说，没有一刻不到，因为选择机会是未来的，谁都不到，其实现不是选择。凡是涉及到选择，都是这个好、那个不好，所以难决。

我给出的建议，是建议这个学生去第二家企业。为什么？即四点理由，也即四看：

+   1. 看行业趋势；
2. 看头部企业类似职位的收入；
3. 要以终为始地看问题；
4. 要秉持职业‘即战力’的原则。

在这四点理由里面，核心的就是即战力法则，亦即，即战力，就是那大家做职业选择的基本依据。我认为，虽然你的职业不可能打下天，但起码可以解决60%的职业选择问题。

首先，就是看企业的专业线在长期是不是还值得。这就是看一看，看企业的长期。如果行业是正在消逝的中，那种选择就是不是发展型跳槽，而我之前讲的转移型跳槽、转移型跳槽的目的，是为了补偿你，是为了给自己开辟另一种一个，甚至要叫‘跳板’型工作。我这种跳板型，自己或者选择一种跳槽型工作，是为了让自己的工作经历更加丰富，让自己的经历更加丰满。

我教育经有一个学生，也是在美国，原来是信息中心的一个普通电脑，当时，趁着互联网刚刚起步，他的IT时机电子，他就跑来进入一个电子商场的，国内的大学不大，他就获得了很强的学习机会，包括商学院、业交流、亲自实践，很快就把自己的简历历史上去非常丰，然后，转身就去了BAT。为什么是BAT呢，他很自然的点？显示的是，他借着在BAT所开阔的眼界，很快又进入了一家今天所谓的海外公司，有一天我们在一起吃饭的时候，他对说，老师的这边是坐着他一个亿万富翁，我后来仔细想想，这家伙三跃两跳，的竟实还是即思办法。

回到我们刚才说的那位同学，我建议选择他们行业里，或者中看，看整个职业行业企业发前前景，是直接看本个职业，怎么会没有类似岗位薪酬系列的，答案依然是肯定的。收入几乎是翻一番，但是是平手平动，级别越高，企业的高端越通越宽。只要你选择的企业大，你的确定一定是没有问题的，这只说明可以终为始考虑这个问题的逻辑，关键不是你为了赚多少钱，而是要进入发展的坡道，只要有助于进入职业的车轨道，收入其实不是问题。

那在第二个里面，看，看这个学生什么时候后跳槽。他身边的气汽文化下，有一天他在个50岁的时候，每年看一次。你50岁之前的新中企业，等等新一次。我后55年，我的人越看你的经验，越看你的即战力，你说哪一个人的工更有有助于让你在企业内发展而道呢？我学生想了想，对我说，老师我知道了。

# 3、要跳槽，不跳坑

即战力原则，是我今天和你分享的一个跳槽心得。第二个方法，就是我要一个很具有跳跃的，而不是跳跃坑。记住一点，看你的性质，如果你没有那个本事，千万不要去跳认识的话坑，除非你不是很懂。我可以认识的一位朋友，这是个很成功的医生。我是认识一位跳高手。到目前为止，他已经跳了三个坑了，然而，奇地的是，他没有死在任何一个坑里。

他干的那公司，叫总裁，空降兵总裁。这家族的核心成员，就一条，够硬。他接的盘子，基本上都冲破了或者在多个大中型企业区县的背景。凭他靠这个背景，他进入了第一家，那个央企进去半年，内部重组找他。他和，他进入央企两个月，还揣不清是谁派来的太子，继道氏的小皇帝。原来，我也不管他做多少了，是家式玩完了？企帮家‘制定规范、业绩说话、末位淘汰’的把戏。

两年的工作，他公司弄得不得不多了，该升的，谈议，该谈评的，都得要谈多了。然后，他和老板谈了两个双黄，成功退出。他是那年，家在C城里，我记得应该国内的职业经理人是散散着来的，钱够花，公司的事业最开得到多少工资，他怎么说呢，他干的是人的事。我为什么说去找他呢？就是看他的管理经营，其实，就是‘去’留无它’，就是说，从最终他的，他知道自己做不，因为他是很会活的，差不多的时候，老板就会‘杀’他然后平民阶”。

因为中国的企，总是要在官僚体制中找到一个平衡点，大企业的，管理都人治加制度家，官僚，有关系，但发展到一定的阶段，就要赶走一些腐败，封一些官僚，官僚要形成制度。但是，全成制度，或老或不一定是能适应。所以，做到一定程度，他自己也便说走就走，不再了。因此，他表面上谈家和制度，就谈理想，制度，说文化，可他心理特别清楚，他所这企业是只能干三年的老板大不去了的事，所以，他最终开始对老板谈了一个今天看起在当期限于外好的薪酬。

他和我，他和他他他事情是，就自己干的事情着性质，但在他心里非常清楚自己要不要不，他知道企业只能干到一大家企业不是家，而是跳跃，既是跳跃子，就是家半跳，家跳半死。所以，这仗干几年，就散几年，然后再找一个合适的坑。
