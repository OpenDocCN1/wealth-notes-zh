# # 固守本文：不选捷径，就是捷径

Hi，你好
品读
宁向东

这篇文章是我在毕业季写的随笔。我们的课程结束了，又赶上学校的毕业季，就回想和回忆些心里话，对于你来说，读着就好。

最近，又到学生毕业的季节，我们的课程也快到结尾了，多数学生像刚跑进跑进满溢的内心，心里一定有很多想得到的。当然，也有一点焦虑，作为一名教师，我也看到过学生毕业时，最烦闷的时候作为一名教师，大意是你心里有方向，但一件很蠢的事，文章我没有打开看，但仅看标题，我就知道，我这辈子注定是刻意的了。

今天我想从毕业说说品质。意志品质，是从你身体中借用的词。我第一次听到这个词，是从清华大学的某位老师那里，老师曾经做过经理人的清华的博士，第一张我在大学读两年最难忘的老板。张成老师的名言是400米和800米，用他的说法，都是杀人的长跑，张成老师说，如在在杀人的项目中取得好成绩，就需要意志品质。

那么，什么是意志品质？其实，就的是一种死磕下去，古为志向的精神。运动员的训练，涉及到技术、战术，但同样重要的是意志品质。我相信你肯定听说过1500米，在这种中长跑项目中，有个极点，那是最难受的几百米，靠什么顶过去？就靠意志品质，就是死扛。

2006年，十多年前，我看过一场澳大利亚和日本在世界杯决赛阶段的比赛，临近比赛结束，澳大利亚领先两个球。日本队大比分，两队都进球，但他们还保持2球保持队形，努力进攻，后来，他们专门做了一篇文章，说中国和日与日本之间的差距。差距不在技术，而在自身，关键在于意志品质。

商业世界的逻辑，其实与体育运动没有什么不同，我自己在做商业咨询工作，能够个人和企业成长的，同样也是意志品质的因素，而且占相当重，我曾经担任过一家企业的项目顾问，当时，团队精心准备一个项目，花费了整整两周的时间，入围到最后的商务。在提交报告之后，你经过通知自己团队放弃这个机会，但你还是过场，还是继续努力，死马当成活马医？

如果你是，你会怎样选择？这件事让我终生骄傲，就是那个团队还是选择了抱着死马，去“搞砸”比赛。我们做了最好的演训、报告和研究花费两到个月，在提交资料之前已经知道了内定的结果，所以，一开始的时候有点心不在焉。但是，这团队打最后一场比赛，最后进入的是东方通，这个团队撤。最后，团队获得的比赛评价，招标方最后私下里说，在我的投标中，你们最专业，我投你。这一次，该团队确定没有获得机会，但是，后来这个团队还是获得了合作的机会。

这件事我过去10多年，但它一直给我以很强烈的过程，这么多年，我把它这真实的故事分享给你，希望也能鼓励你的职业生涯。

一个人的事业发展，漫长的就像一次马拉松过程，能不能跑得好，意志品质非常关键。

什么是你世界的意志品质呢？可以讲的内容非常多，我只说两句话：

# ## 第一句话：不选捷径，就是捷径

给集团的组织大王永庆先生我曾经讲过一个故事。有个东方大学的学生，毕业之后进入了一家台电公司，公司让他做最有挑战的工作。所谓设备保养公司，就是给所有的机油。他对他的安排非常满意，为什么这种都能做了，他，我告诉你说个名头是大学的毕业生呢？但是，他竟说是坚持了8个月的8个月之后，他发现了对公司所有的机器都有的毛病，零部件坏了就坏了，而正是他进行了对想要研究机种大工作的基础。后来他成为设备了那份具体的工作的基础，他有时对机种设备做了的了解，都来那做8个月的加油生。

今天这个时代非常现实，我们在哪里，可以已当不道德学生的那种态度，但是，我依然把王永庆喜欢了这个故事分享给你。你也在想，但是，作为一个好的企业的道理时没有，我就常人们王永庆说的意思：任何工作都有学问，只要你态度平，只要你够努力，一年就可以得其美差，三年则必有所成。

# ## 第二句话：从绝望中，找到希望

我写很多这样的文章，都劝人们该如何直面绝望，但是感受却相同，当一件事没有可指望的时候，你可能会不屈不挠，实际上都是大白话，所有那些带伤的人，其实都在看远方的远方的一句话，看到了可以争取到的目标。我相信“天无绝人之路”这句话。

罗永浩恰好要开发布会了，当他站在西门子上门门口喝冰镇的时候，我觉得他是一个笑话，后来，我看到了在锤子科技第一场发布会上演讲，我感到了罗永浩的另一个身份是相声界的角者，角了个大家可以使用的有腿知识，构成一个宏大的叙事。有营销味道。我反对对有腿角度，我曾经在清华的研究生课堂上，建议学生按照这个企业的后续情况。

之后的几年时间，没有得到锤子手机有什么你怎么人？前，那些纷纷的硬新闻？那些试过的时候吗？今年，罗永浩开看卖货。我会惊讶，他居然还在看，他的2017春季发布会也看了，但此时的我，已经不再关心在这个发布会上他讲了什么。

去年，我写下一段话：“我已经不再是看客，开始为他加油，我说了奶粉（当然，他不再是粉粉），我真心希望罗永浩成。尽管我觉得对老罗来说，相当相当，对罗永浩的潜在对手来说，而他的希望也，就像一个3岁的孩子对于金钱。就不必为他们开放就罗永浩，支持罗永浩。就因为他们：罗永浩代表了一种尊重人的力量，他的意志品质让我感动。你难道不在罗永浩流在旧上回复我留言的时候吗？凌晨3点18分，这个子难道不睡觉吗？

今年，我的看法没有变，加上一句：无论他未来是否成功，这种精神都是值得尊重鼓励的。

1968年，墨西哥城奥运会的马拉松比赛中，有一位来自埃塞俄比亚的运动员阿提拉，比赛的途中，他受了伤，本来可以退赛，因不仅仅坚持了下来，但他还带伤奔跑，但他也一瘸一拐地坚持着，故去人们纷纷重新回到他身边，为他加油，体育场馆也聚集着等他跑完体育场的观众。终于，阿提拉孤身在他后面进入了体育场。全场观众起立欢呼，为他鼓掌。

阿提拉是，是个英雄，是一位意志坚强的英雄。而墨西哥城奥运会并获得冠军的人有很多，但当时，却仅仅记住不获得了最后一名得马拉松运动员阿提拉是，而是因为他的运动成绩，而是因为他人格的意志力。

作为我们这门管理课程的弟子，当前，如果你想让我们做世界性的公司，这当然是你送你两句话：一句话“不选捷径，就是捷径”；另外一句话“从绝望中，找到希望”。
