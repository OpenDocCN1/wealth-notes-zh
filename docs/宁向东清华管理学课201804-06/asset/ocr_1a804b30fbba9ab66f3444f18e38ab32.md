# 238讲：打小报告也是一种控制

你好，欢迎回到《向史而读的清华管理学课》。

这一讲我们来讨论管理中一个常见的现象：打小报告。长期以来，“小报告”是一个负面的词，打小报告的人，在大家的道德中，一般都是个不大好的人。但是，大好家声，不好听，为什么在我的生活当中显得不是，不但不难接触？其实，小报告在古代和西方都是控制领域的一种重要手段，在东方西方都普遍存在。

# 1.对上级有价值的小报告

我们以前讲过，讲过“影响成本”的概念，这是由两位著名学者米洛尔森和罗伯茨提出的概念，指的是因为个人的行为上会施加措施信息、激励奖惩，而组织对你的约束的成本。在西方的政治学中，打小报告当然也是研究。在中国古代政治中，打小报告也是经常的研究信息的重要手段。只不过，在皇帝那里，话没有说得那么难听，比较高大上，叫做“秘密制度”。

小报告有两个档次：第一，小报告的内容，完全是从上报的信息出发，报告者可以随便的说。第二种，就是为打小报告的人，利益动机。第一种，是控制的重要内，是应对上级的信息约束。第二种，是上级信息的一种，但不是所有的打小报告没有价值，但与第一中相比，价值会打很多折扣。

上一讲，我们提到了军队斗笠戴笠。戴笠就是打小报告最厉害的高手。戴笠也是很多老都受到他小报告而信任的。戴笠打小报告就是从蒋介石的信息出发，帮助蒋介石来巩固权力的，所以，这种打报告对上级是有价值的。

这个国民党，由于它的历史，从最开始就是派系林立的。党内有汪精卫、胡汉民，党外也是有共党。小报告，所以，这个小报告是这两个势力都有利益。戴笠就深通其所。戴笠，一个黄埔六期都没有读的学生，凭什么都干起蒋介石的小报告和信任？就是靠小报告。戴笠，就总是把要报告的事情写在纸上，放在蒋介石的办公桌上，就为了引起老蒋的注意。

后来，到了重做国，戴甚，戴在革命时期，就给蒋介石做报告。他甚至拦过蒋介石的汽车，亲自做报告。他写了很多的纸，自己已经无从可以去过。他就这样留下了什么身边呢？但是，倒是对大家有利的结果。小报告，打小报告，上大家就看也没读不完。不过，很多人就说戴就是靠打小报告上去的，话里充满了不满，我们就觉得不要想听小报告。我们从蒋介石的视角来看，小报告，他小报告，从来没有不从自己的角度出发，而是处于从蒋介石的需求考虑。这种小报告，就进入了蒋介石的控制闭环中，就特别有价值。

# 2.密奏制度：从小报告到控制方式

其实，打小报告，在人类社会中是一个有趣的现象。你像像一个悖论，让我们很讨厌它，属于不文明的行为，但我们很依赖于小报告的信息。但是，当你在大的时候，你其实很期盼别人给你打小报告，去给某人一点提示，让你对基地多了一些了。小报告，就成了控制的一种方式，所以，有些领导对小报告是欢迎的。

前面提到，在古代中国，有一套密的传统。但到了清朝康熙和雍正时期，密奏制度发展到了极致，已经有所不观的方法。很多史学家讲到，将分析，有命有所不关。但是，这是历史习惯性的历史传统。我认为，这种看法只看到了问题的一面，但忽视了一个方面。千万不要以为庶子是子于继位，过程就太重要了，皇帝不但不过程中，形成了自己的队伍，然后，说不清楚一个太就就崩了，谁接掌了天下。所以，皇帝实际上不仅是皇帝，他不要过你通过，最好是一举一动都在他的眼底了，这样他才安心。

康熙执政的后期，包括雍正执政时期，对外一直在打仗，同时对所控制的执政也没有安定，这个时候就使重者如何了解下面的民情、政情和环境。靠什么？就有了密奏的奏折，也是因为这个原因，密奏制度在这个时期迅速规范化。
