欢迎回到《宁向东的清华管理学课》。

今天的课程，我们讨论一下如何让战略落地，快速成为执行力层面的问题。我将在中国企业发展史中，挖掘到几次大的战略动力，对这些企业是遭遇过冰点的，在2008年，对于潍柴动力来说，有着特别的意义。今年正是潍柴动力成立二十周年的纪念日，也是习近平总书记视察潍柴二十年的纪念日。在今天的课堂上，总书记已经听说了潍柴的大报上怎么说，总书记出了一份沉甸甸的、极限的答卷。

我先把几个时间：1998年，潍柴处于破产边缘；十年之后的2008年，潍柴的利润是一千九百亿，过了一九年，利润就超过了100亿。请你注意，这不是营业额，就是利润，而且这些利润是在以发动机为核心的主业里取得的。这一点我是完全发自于房地产小领域外的快乐。这一点是不容易的。今年三月份，是潍柴的欧四标准的公交车大巴在香港正式投入运营，我参加了公交车的交付，心里不禁又想起了书房抽屉里的粉笔头。

潘旭光这个人很神，我第一次见到他“当众吓人”，吓了一跳。那个场面给我留下了深刻的印象。那么一个技术人员，竟是跪坐在第一场的领导面前，摆起阴阳的架子来。我当时第一印象就是，怎么可以这样，中国人，一般是讲面子的，特别是对于那些拍得更大、因他的核心员工，说必要是加上几分面子。但是，他不是说，话话说谁重，而且当成整个集团一两万名核心管理着来。

大家看我的肩章，有一个身份是中央组织部干部局设立的研究生院，这是一个什么组织呢？就是每年十中部都会在中央直属管理的企事业，选择一批干部，送清华大学学习管教学程接选拔力，为期进三个月，我这三个管理学程的任务，就是负责这个课程的建构，选课教师的推荐。我们是全国范围内选择最优秀的资员。这个课程有企业家交流的环节，2017年我选了重董来和大家做分享。

我们的有授课老师，上完的课程后都是有学员反馈，那些意见不可小视，都是身经百战的管理者，他们的评分相当的严，你知道潘旭光得了多少分？是满分！当年晚上的时间，工作人员发信息告诉我这个打分结果的时候，我分明能够感受到他内心的那种震惊。其实这一点也不出乎我的意料，因为潍柴的经典案例，令人震撼，课间休息的时候，潘董就被大大包围了，整餐厅十分感动。下是我用手机拍下来的，大家可以感受到当时的热烈气氛。

今天我们提起潍柴动力，在行业内、社会上大名鼎鼎。大家都说在发动机上，这是1998年潍柴，是一家集资产在破产边缘上的企业。在破产之际，37岁的潘旭光站了出来，成为了现任这个企业救产人，也成为有这个企业的新一任厂长。潘旭光严格意义上没有上过大学，修过五年的大学，做了十年的产品和研：然后以7.110年的市场销售和际经验积累。上他具备了两个能力。第一，他知道市场一战的战斗，是以足够的成动力，第二，他知道了，是不是以快的成产品力，是否定他有市机会的关关的。

关于潍柴二十年的纪事，我的朋友都作出版社出版，值得得期待。其中，作中作仔细记述从1998年的第一场改革，可以说潍柴心而动。然而，改革只是表，只是开企业后恢复发制造机业务上。下面的国家产业重领在界界机台上一个接一片，还是要靠企业的好的战略，然后又能将战略落地。

我稍作总结一下。潍汽的管理之道可以用五个词来概括：分别是“布局、投资、预算、干部、奖励”。

# 1、布局

**第一，是布局。**潍汽动力原来是一家柴油机发动机的企业，它是六十天下来的动力，于天南本质上它是一个十八个月的大。2003年，它通过收购杭州、扬州客车，从柴油机到自动总成系，通过这了杠杠，一下子重型车的制造域获取了两年的联，重型汽车，后来一直视为潍汽动力的核心业务，不后得深为，我们潍机动力核心业务，就是在这一条产业线上。潍汽动力在它的动力车机领域里只有一个状态的问题。潍汽在配置行业里，有着名国际公司，CE在总时公有一张潍汽的片，用对记忆着中国有我们的。

潍汽动力的第二条业线，是海上动力。2007年世界金融危机之后，它在法国收购博杜安，学习海上动力；之后收购意大利的法拉第，在深化动与动力的同时，从2009年设动，向两业领域的布拓展，并用20亿欧元战胜重组了三十的德国造船集团。液，又是制造领域的短板，但欧根德的德德又是这两个业的业一步企。所以，潘旭光下决心购前买级，但是人没有达到，这一攻没有买上，美国打开了另外片天地。限于时，今天不多说了。

这里有个非常有故事。收购凯欣时，凯当CEO，过正在世当大元帅，潘旭光在十年前世当世，希望家观大，被经拒绝，他也没想到，潘旭光在年时间把潍汽动力从销售了亿弄到了100亿。后来这两个成力，为着，他们几不吧博杜大的打成了，直接潍汽动力进业务上的深合。所以，想到人取的方法，不是去，就是别让人你的业绩。

# 2、投资

**第二是投资。**投资，核心是如何决，以购决为例，如果做对，业会得常模的发展，如前一位讲的收购博社公司，例子中，要先问：一家企业，当时没有人相信，说博杜安为什么？潘旭光说，如果你们自己，也大家一起问，我不收博杜安了，他们才头始做水上动力，技术平做多少？

答案是大约十年。有了这个答，问题就不言明自，收购社的决策，本质上就不要自决一家企业，它的决策力根本先，但是，可以帮助它实从零时的，达到有十年积累的一段时，到五年，北大致文等，关于中国大飞机的，我特别赞同一个点，就是，的大机产业也不能作。

现在大家都说大重器，你知道造大重器，并不制一个产品，而是造个技术平台，A平台，成套系，个平台，大重器门了，可个子品为，一个大人都散了，一个制造设备散了。散了易，重新聚都散了，败了。

收购博杜，潘旭光还有一心思，是想博杜技术来，因为博杜有300名工，他在来看，国化要人小机，逐渐积累经验，一下子擒一个大材，胃口往往不消。

# 3、预算、干部与奖三

潘旭光管车销售十后，可以联系在一处：就是每年计划，可预留，随着动率增大，逐渐去，成为内业务的一部分，也是这算管理体系来规企业超力。干的管理，就是标、预算奖，预算成了情况，非奖了，预算了成，奖自然了，干部位也就有了，反之亦然。

比如在潍汽动力，直接中总经的中层干部有1000左右，在管了一个叫“功”的考模式。年，排在最的20%，要进一下程：第一，进行试，如果不行，下；如果进了，要考考虑走。所以，潍汽动力的负激励点，有通用电气在韦奇的时代是尾的尾。

与此对，每年获得前25%的管理干部，当考实绩效薪酬和奖金的奖。经三年获的干，直接，按潘旭光的说法，在潍汽动力，不是一个人才，是由业挑来的。在潍汽，想干事的、能的，你努力，就一定能够上去。
