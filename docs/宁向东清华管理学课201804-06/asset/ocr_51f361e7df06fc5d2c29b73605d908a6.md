# 1.交易效用

首先，我要强调这样一个法则，请你无论如何要记住：过了若干年，我这一章所教过的所有内容，都可以忘记，但下面这条原则你没有忘，而且，不仅有忘记，我能够把它应用在生活中、用在工作中，我能够作为老师，这么多年，一年的辛苦没有白费。这条原则是：不要小看表扬，要学会把每一次表扬给当成多次表扬。当然，你要控制不能把人表扬骄傲了。同时，不要经常批评人，批评人，一定要学会就少而准地、有深度地、一次就讲透。要掌握这个原则，把批评一步做到位。

批评的最有效的形式，就是动手打人吗？我是成长于一个打孩子的时代，我十岁以后，在我的时候，我十岁以后，我十岁以后，我的时候，我十岁以后，我十岁以后。比如说，我妈妈打孩子的技术、挨得重要，如果不是老天打，不知道打一顿是错的。成年之后，我发现这个道理可能是错的。比如说，管理员工要调整准备一点，每周一点，市场的货你要多给一点，经济生活就像被打了一巴掌。如果你留意，就会发现：很多教训，就半步，你一步都是发生一，效果就没了一半，这样来猛烈，来得有效。这和打孩子、批评人，是一个道理。

以前，我一直觉得这个东西就是一个体验，直到一天，读到泰勒勒等人的论文，我才发现这个东西，还是有科学依据的，泰勒勒就是行为科学的大师，去年诺贝尔经济学奖的行为学者。

泰勒勒从80年代开始发表了多篇重要的论文，在这些论文中，他探讨了人们在行为和决策时的心理相关性问题。有一个概念和今天的课程相关联，叫做“交易效用”，在传统的经济学理论中，交易的目的，是为了获取你需要的商品和服务。重要的是关于交易，交易要考虑到交易的位置，甚至是无关紧要的东西。但是，泰勒勒的研究发现，交易其实并不是，甚至是交易的内容。

泰勒勒认为，人们在任何交易中所获得的效用包含两个部分：

+   1. 是从所交易的商品中获得的利益；
2. 就是在交易活动的过程中所感受到的价值。在一种心态，泰勒勒称之为“交易效用”。

泰勒勒说，交易效用本质上来自于当事人在交易过程中对于感受者，当交易活动的实际成交价格远高于当事人的价格参考点的时候，他在内心中所获得的满足就不仅仅是所谓的“消费者剩余”，还包括一种心理上的满足感。

我们前面在第一课块讲工作关系、交易关系的互惠原则的时候，曾经提到过社会交换的对等含义。我买一件商品，在购买过程中，销售人如果是友善的，还蛮冷语，其实整体我会影响到我的购买体验。这就是交易效用。而每个人上桌都是出售者的一方为交易。在这个过程中，表说是一种工作，其实他半随意交易效用，问题是劳动力的“交易效用”问题。受到表扬，毫无疑问就是正面的交易效用；而受到批评，就是负的交易效用。

# 2.享乐偏辑

那么，我们每个人在心目中又是怎样处理“交易效用”，以及与之相关的心理感受呢？这引出了另外一个非常重要的“享乐偏辑”。享乐偏辑，是指当人们面对交易结果时，会在心理上有规律地评估这些结果，并且结合情境会感受到快感和痛苦。说得再具体一点，人们对自己在情感感受进行交易。当表扬和表扬一块来的时候，批评和批评一块来的时候，一块来的时候，就会一种新的交易效用，也是我今天前面多次强调的，要学会使用两个坐标。今天，我是第三次提到这个内容。

“加斯坐标”的底层逻辑，就是享乐偏辑的几个概念和做法，这也是今天课程的重点，和前课程特别强调过记住的，关于表扬和批评坐标，坐标。

首先，要注意利用收益。比如，有一个人一次获得价值200元的奖金，和另外一件情形相比，比如说他抽奖中了100元，之后又获得了100元的奖金。虽然两种情形下，这个人所获得的财产数量是一样的，但相比之下，后一种情况使他感受到更多的快乐。

导致这种情况出现的逻辑，是因为人对于收益的评价会集中呈出，如图所示那样的一个凹函数的曲线。这条曲线当成一条可信的曲线接受就好了。在一个人的财富状况和局部环境不变的情况下，这条曲线的说明原不想。于是，分开收益、给钱的事情，分次给，处理得当可以增加当事人所获得的价值总量。这是第一个原因。

还有一个原因，就是因为存在着我们前面说的“交易效用”。你记得，就是财务人员每次都会对着，给这种交易活动本身都会对当事人来说，有意思，有句话叫做：伸手不打拉裤人。你可以想想，就算多去一次某个领导那里，他天天看着你，你也不会反应效用。这是因为十年后的交易效用，那你就再想想，十年的年会，有一次你获得了三等奖、二等奖，哪一个交易效用更大？如果从交易效用的角度看，毫无疑问是后者。

其次，要注意合并损失。合并损失的逻辑，和分割收益的逻辑正好是相反的。按照对行为学的研究，人类对于损失的评估，在曲线上呈现出来的是一条凸原点曲线。所以，合并损失可以减少当事人所感受到的负能量，比如，某人先收到了100元的奖金，接着又失去了100元钱，他一共损失了200块钱；而另一种情况，他一次失去了200块钱，这两种情况，他的损失是一样的，但哪一个更让他难受呢？毫无疑问，是前者。

前者比这个人更痛苦，除了他感受到的总损失更大，还在于折磨了他两次，两次折磨比更大的交易效用，所以，痛苦更大、更大。借了个道理，就可以想办法去合并损失的经济活动，减少他的交易效用。我昨天说过，长痛不如短痛，其实就是这个道理。每天刺激人，还不知个批评效用，这不仅有助于你得更好的批评效果，还有助于让你的批评者也可以减少一些痛苦和煎熬。
