从大类上说，控制的手段是两种，一种是基于计划、基于指标、基于事情的，控制还有一种是基于关系的，是基于人情情面的，我多说一句，我尽量避免两种手段的使用是泾渭分明的，要么基于事，要么是基于人，很多时候是组合着来使用。我自己也编制了一些管理者控制手段，其实现就是二合一的，只不过比重不同而已。

# 2. 控制体系的僵化

接下来，我们再讨论一下控制体系的问题。首先，建立控制体系不是没有代价的，控制体系的运行同样是在控制系统的曲线内部，帮助领导者进行控制的可能会也风险并存。我们就前面讲的官僚化的程度，也可以想到官僚化蔓延到控制体系，相应的官僚化机制也会出现在控制体系中。

事实上，在“小组组织”中，有时候来负责控制的人权比正常大，如果处理不好，有时会沦为权力大于责任的大领导，因为拒绝责任、担风险而不愿意积极做事。

当然，皇帝也好、公司的领导者也好，他们并不是傻子，他们也寻求一些方式努力去减少，因为监视体系本身而形成的巨大成本。比如，为了让控制人员尽责，官僚制度被层层放大，必须依赖关系。权力在员工的约束和上天的平衡中，以换取相对可靠，尽量保证控制体系的有稳定和完整，但又不能牺牲到，就是组织有缺陷。做了大量人之上的事，还在使用控制体系。比如，为了保留监控，组织控制系统的僵化，随着组织成长、规模发展，其中的一条罪状，就是在控制系统上太做文章。

除了在人体系中，控制体系中会存在这种盲目和惰怠的问题，就是，控制体系中，会存在因为控制体系僵化而带来的“副作用”，组织活力和创新能力受抑制。这是我们今天要重点讨论的第二个问题—组织僵化。

在一个著名的管理学教科书中，曾经记了这样一个故事。一位患痛病的患者夜里来到了一家社区诊所，但急诊室和急诊外科并非急诊骨科人员的，该去医院的急诊部，急诊室急诊科也转到了他的科室，然后一直等到第二天早上，在眼科科转科中医生，他才看到他的医生。此时，他却发现急诊科没有开转诊单，于是，他不得不回到急诊，这时，他又重新开始了转诊，再转诊医生诊断，他又要面对相关的诊断、检查、这些诊断，然后，他又要开始要去做进一步的检查。经过这一系列折腾之后，他最后终于看上了病，简单一位医生只用了30秒，就为他进行了手术。

我们大多数人，也许都经历过类似的折腾。在任何一个企业中，企业内存在的僵化的控制体系，都会使得企业组织在遵循着正常的程序，却忽略了一种既低效的、缺乏灵活性的官僚主义行为。

由于对于当下的中国，企业过于强调权威主义了，很多公司中存在大量的缺乏风险意识的，很多企业对风险有着过度的敏感性和不确定性，所以，我完全整个这个模块强调建立控制的价值和意义。但是，在我做这一切动作的同时，又不要走向另一个极端，就是要避免僵化的另外一个方向也就是所谓的“过度控制”。就是过分依赖人工去解决问题而带来的僵化，僵化，既破坏了控制的另外一个角度：僵化。拒绝僵化，我认为是继价值之后，最后一个需要记住的概念。

我前面讲过那么多西方学者的控制规范，难道这些公司所谓的，已经完美了，没有任何的问题可以改进之处吗？答案是负面。严格控制所带来的僵化危机，首先，它降低了企业创新文化，导致僵化危机，僵化，不仅降低了企业整体上服务客户的效率和能力，也导致了企业内部各级员工之间的交互关系变得无序，为了解决僵化问题，就成了最近几十年控制变革的重要任务。

你还记得我在第7讲中介绍的，格雷纳的组织演化模型吗？最后一个发展阶段，就是避免僵化阶段，所以，西方很多大师和专家都在将控制体系调整到这样一种目标，就是把控制效率最大化，同时把不良行为约束到最低的，做到这一点，甚至并不完全系统化，绝大多数，做到这一点，甚至并不完全系统化，大多数公司都已经以此为标榜而不断努力。

有很多管理者研究认为，对控制要求控制体系效率，还需要引入保持控制体系的张力和弹性，保护员工的积极性和创新精神。而有效的控制系统，被认为是起码应该具备如下特征：

+   1. 能够衡量标准尽可能符合实际情况；

2. 应该使控制体系的制定者和执行者与员工保持一致，有效协调不同员工的心理和行为；

3. 控制体系应该兼顾多种方法和多种手段；

4. 要把授权、赋能和控制协调起来，综合权衡；

5. 组织文化、价值观，应该成为控制体系中的重要内容。

# 3. 组织的新体制、新文化

不过，我们在这一个模块中所讲的，也是在图示中要示的，这一套到今天还不够强大，尽管学者管学家，尽管今天不够强大，尽管管学家家倡导过并不是要完全消灭对敌，而是要完善控制的文化，从而形成一个更加平衡的、稳定的、和谐的组织文化，去适应授权赋能的新体制和新文化。这一点，在高科技类的大公司中，表现得特别明显。在这一类大公司中，要去得到一种科学的方法来对组织进行衡量和监控，是非常困难的，这一类公司的人员往往又是具有极高自尊水平的人员。

在这样的情况下，公司与其进行极度严格的控制，还不如改变使用控制的方式，充分动员他们的主动性，去创造使用力量，给予他们行动的自由，致力于信任信息系统，而这一切，都是用以一种极其高大上的名义：授权、赋能。

# 划重点

+   1. 控制的手段有两种：一种是基于计划、基于指标、基于事情的；还有一种是基于关系的、基于人情情面的。这两种手段可以组合使用。
