望”(silver lining) 原则。比如，某人某一天丢失了900元钱；相比较的情形是他丢失了1000元，但在回家的路上拣到了100元。理论上讲，他回家的时候进门都丢失了900元，但毫无疑问，后一种情况会让他感觉上更好一些。也就是说，当较大损失的负价值无法像上一条编辑法则那样，可以用小收益所带来的正价值去抵消，无法通过“编辑”来消除损失厌恶的感受的时候，索性分开它们。也许，小收获所带来的交易效用会增加人们的快乐。

今天我们所讲的核心内容，是人们如何去看相待得失，人们在心理上，是会对得失进行享乐编辑的。所以，不仅不要吝惜你的表扬，还要学会“小步快跑式”地表扬人；同时，批评人、帮助人进步，则不要零敲碎打，而是要争取一步到位。

# 课后思考

今天的课后，请你想一想你最后一次表扬人，或者批评人，你是怎样做的，有没有达到自己的预期目的，有没有什么改善的空间？

# 划重点

+   1.不要吝惜表扬，要学会把一次大表扬拆成多次小表扬。批评人，一定要学会减少不痛不痒的小批评，要学会通过触及灵魂的一次大批评，就把批评一步做到位。
2.在工作中要学会将较大的收益和较小的损失放在一起。
3.将小的收益和较大的损失分开处理。
