# # 249讲：破坏性创新为何大企业会倒闭

你好，欢迎回到《宁向东的清华管理学课》。

这一讲我们讨论大企业为什么会倒闭。这是一个非常有趣的问题，最近几十年里，有很多著名的管理学大师从不同的角度研究过这个问题。这一讲中我讲的，角度集中讲到了一位大学者的研究，这位学者的名字叫克里斯滕森，是哈佛商学院的一位荣誉教授。克里斯滕森的核心概念，破坏性创新，也叫颠覆式创新 (disruptive innovation)。

# ## 1、破坏性创新与延续性创新

![](bbox=[0.15, 0.3, 0.85, 0.35])

什么是破坏性创新？比如，过去我们用感光材料来呈现图像，现在用数字技术核心技术，但是在同一个业务上，技术路线发生了根本性变化，这就是一次破坏性创新，与前面完全不同的创新。再比如，过去的电脑有主机，有显示器，有键盘，而现在大家常用的平板电脑，你所有这些部件全部集成在一起，操作方式手指而指，这是一种颠覆性创新。这种东西现在几乎每天都在发生在我们身边，不停数。

克里斯滕森研究的重点在，在这种破坏性创新的这种环境中，大企业为什么会倒闭。他所研究的那些企业，是曾经站在行业里星光一时的那些企业，这些企业的产品都是行业内众多企业的标杆产品。按照产品的描述说法，很多核心创新是因为企业的管理不够好、投资不够，更不要说这些企业，他研究的是那些有进取心，企业是努力，认知到消费者什么样积极改企业产品，管理也很好，但为什么会这样的企业也会倒闭？

克里斯滕森首先区分了技术创新的性质，他认为有两种创新，一个叫延续性创新，一个叫破坏性创新，两者的区别在于，技术是不是处于同一个轨迹。成功的企业都是按照延续性的技术改造提供自己，然后在特定的技术路径上，给消费者提供越来越先进的，而很多功能、满足了消费者需要的功能，也就是说，企业提供服务消费者的产品超过了客户的实际所需，也超过了消费者愿意支付的价格。一句话，性价比没有需求满足得更多，但是企业没有，它提供的不是满足，只发现平台也没，产品功能的增加和服务的增加也都在确定的路线上。

我们以我们熟悉的诺基亚为例，它在塞班平台开发出手机，然后手机功能不断翻翻。我到现在还没听说它的手机，它其实，和一群朋友聚会，讨论的话题就是诺基亚的手机和苹果，有多少功能都是我们需要的。的那时，克里斯滕森的书《创新者的窘境》出版没多久，大家一起讨论这本书，碰巧我们都用着好几千块的诺基亚手机，于是，拿着这个当时最贵的手机我们展开来讨论，最后大家得出一结论说，很多功能都是过渡服务。

但那个时候，研发的基于平台还没有出来，三星的智能手机也没有向的，鸿蒙，苹果还是在概念阶段。所以，诺基亚在原有平台上做一般地持续创新，我们自己的手机技术、最后，功能多，一款新N95，功能增强，但，很多功能都不是需要的。后来，台湾深圳开始市场，新的手持设计平台，在深深的市场上手机可以比论买卖的。再之后，三星和苹果开始推出更贴合客户的产品，诺基亚的日子越来越难过。

诺基亚为什么不去变革？这就是克里斯滕森的理论有价值的地方，因为技术不是平进的，所以，诺基亚可以做延续性创新，但是，遭遇破坏式创新，它就被慢慢吞并了，最后它只能手就掉。诺基亚在翻翻的时候，手机的出货量是四年后回追了。在这种一个时间窗口里，很多新和安卓的提前提出来了。逻辑很简单，就是图扔给硬件成本太大，一万块，一部手机亏损十块，四部手机就是亏损四十块，那这是一个天数了，所以，企业太反了后，一个最大的问题就是不敢变革，而不敢变革，就是死。

前段时间，和朋友讨论一个特别有趣的问题，就是企业大就做大，小而美，对比比较容，越大，就要做强大的强美能力，否则很容易被因分配问题，朋友用了个大家熟悉的话不变革就是，朋友变革，搞不好，就是找死。所以，这就是优秀企业的宿命。千万不要以为我们是在越乱，这话说得背后一个逻辑，就是企业是否存在最优规模的问题。
