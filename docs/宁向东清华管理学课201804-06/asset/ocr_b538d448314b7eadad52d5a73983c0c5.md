# 1. 激励报酬的发展趋势

长期激励性报酬的发展速度快，从六、七十年代发生开始，只过了20年，全球前500家大型上市公司中，就有90%的公司采用了某种形式的长期激励性报酬。现在，在市场经济的环境下，普及率则是进一步提高。为什么会这样快呢？就是因为人们普遍认识到，管理者、管理者是公司最主要的财富，吸引他们努力工作，很重要的内容就是有效的报酬制度，这是公司竞争战略中的重要组成部分，必须要给有能力的人比绝多的报酬。报酬不仅要数量足够，结构和方式也当恰。

我对未来有一个预测，不知道准不准，但我觉得，未来，长期激励性报酬在未来中越来越多样化，普化，低成化。比如说像高管的股权，认沽期权期，过去只是高级管理人员或者认沽认者的长期或成。但越来越多的人都以某种形式拥有公司的股份，分多公司长所长的长期或公司。你果有机会去留心一下中国现在的上市公司，都专门近来给普通员工的长期投长。从最初的不成熟，逐渐成，从新开的，激励作用微弱，到激发新渐渐大。

另外，在越来越来的中小企业中，期权已经成为一种惯性的激励手段，这可以保留干工，不去跳槽的事就，不仅去跳槽，还事努力干，对公司长长久久。我们知道，管理人员、科研人员，他们的利益企业的利益前是的一致，他凭什么和你一起前？除了公司价值观和愿望，很重要的就是经济的上手段，将你的个人利益与企业的利益长期绑定在一起，获得这种连的长期，也是最效的手段，就是建立长期激励性报酬计划。

总之，前面议了多，就是强调一点：长期前发方式，是管学的必修内容，也许每个一个对长期年龄人，都会下一个不断为学习取的年轻人，天到这个问题。所以，我建议你了解一下。

# 2. 排序激励

下面，和我分享一下叫做"排序激励"的方法。这种方法和我们要前讲的杠管理逻辑是一致的，具体做法是这样的。比如，我们认定107万作为一个激励单位，这个数是最约的。然后，我们就选择有比性的竞争对手，比如七个对手吧，这七家企业都成比你高的企业，八家形成一个小排比赛小组，第是定比赛的时间，比如说三年，那么，三年过了，我们小可以参照前在这竞赛小中的排名来发按排序激励，

比如，你在竞赛小组中最后两名，那是在竞赛中，处于相对比劣势的地，你原来就是这个水平，该得任何什么，对不对，不应该获任何奖励。如果你排到了第五，第六名，那就是有进步，这个时候，比如，你给一倍，就是给100万的长期激励性报酬，你如果排到了第三、第四名，成绩该属于相应不错，这个时候可以发放万3倍激励，也就是给你300万的报酬。

如果成绩到入前两名呢？那就是很不了的成绩了，该给的报酬？要回答这个问题，需要解几个课程前讲的知识点，你得知道，激励人们产出非常的结果，是要想办法激起他们的高于常的努力，而前提是要给其于常的报酬。中国人的话，叫做：重是比下，有上。我把它改一下，激励性，水平越高，激励人进步，报酬的越越。水平高，激励人进步，报酬的增越，能非线性的，增量必量越来越多才行。

所以，如果你入到了竞赛小组的前两名，我可能意发放8倍、10倍激励单位的长期奖，总金额可达800万、1000万。甚更定多，这就是我主要讲的"排序激励"方法，使用这种激励方法，有几点是格外要注意的。
