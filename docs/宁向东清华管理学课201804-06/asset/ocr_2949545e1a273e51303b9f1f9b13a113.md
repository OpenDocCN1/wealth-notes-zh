# 1. 设置激励的经济学条件

现代经济学与这一部分相关的内容，最早叫做“信息经济学”，因为最基础、最核心的概念是“信息不对称”。信息不对称的状况是，信息的一方就是信息没有信息的一方。比如说，经理人会不尽尽职，但他的股东确确实实的情况，败欠没有信息的那方股东。

具体来说，企业的股东是尽可能先设定一个盈利目标，但是，由于他没有亲自参与到企业的实际经营过程中，他们不仅缺少企业管理的信息，甚至也缺少关于经营环境的信息、关于所聘请的经理人具体行动的信息，在这种情形下，他们往往只能被动接受经理人所给予的某种信息。经理人会利用自己的信息优势，为个人谋取一定程度的隐藏报酬，而股东为了防止这样的情况出现，就需要进行激励设计，与经理人签订有一定约束力的合同。

由于这部分内容涉及的问题特别多，也特别复杂，所以，从这个领域70年代开始一众人，就在这个领域发表了很很多的论文，形成了现代经济学中一个非常重要的分支，关于这一部分的研究，有很多名字，比如委托代理理论、激励理论、契约理论等。这些理论虽然名字各异，但实际上所讨论的内容是相似的。

为什么这个领域的理论发展如此之快？就是因为不仅仅是经理人和股东之间存在这样的关系，企业的上下游之间也存在类似的的关系。企业与企业之间，企业与客户之间的很多关系，性质上也是一样的。我们不妨用以下三个标准来看企业内部所涉及的关系：

+   1. 信息不对称；
2. 利益不一致；
3. 监督困难。

在现代经济学看来，只要符合这三个条件，都需要设计有效的激励机制。

好多年前，我曾经读过一本书，里面讲了一个例子，大大影响了我对激励制度问题的理解。今天的话，我这本书的例子分享给你们，我不是说这个例子是真理，或者它在主题着正确的解释。或者，它是对于作者主导的人的另外一个角度来思考激励制度问题的。

这个题目是：出租车为什么会有起步价？在读这本书之前，我还没有想过这个问题。记得它时看这个题目时，我下意识地在想，因为出租车是了为了保护出租司机，减少乘客要去的地方太低，这个活就会浪费一台司机的工作机会，所以，要起步价补偿。读了这本书我知道，给你起步价有可能是为了防止出租车出逃。“有可能”三个字是我加了的，那本书的作者对此的解释是新打铁似的。

他说，司机和乘客的关系符合我们前面说的三个条件：出租车司机和乘客的信息是不一致的，司机比客人更了解路况的情况；其次，他们之间的利益是不一样的，乘客希望司机像他的自己服务一样选择近路，而司机却有可能希望多绕一点路；第三，由于乘客的信息劣势，所以，他没有办法监督司机，防止司机绕路。

于是，怎么办？解决问题的办法就是给司机一个定额费。比如，上车就收司机2块钱。之后，每行驶一公里给司机1块钱。北京现在的出租车，起步价是13块钱，包括6公里的车费，之后每公里5块钱。这样相当于你开始交欠付的起步价里面，有4块钱是和行驶距离没有关系的。

为什么这样安排呢？这本书的作者给出了面这样一个数学解释。

每一位出租车司机一天可以拉60个活，每个活距离是6公里，加上起步价，司机每一个活的收入是7块钱。那么，60个活的总收入是420块钱。如果这个司机利用他的信息优势绕路看卖兜圈子，比如，把每个活可要都像多挣钱一倍，那么，每一个活都可以接到12块钱，看上去是的多去了，但是，他一天就只能拉到30个活。作为一个理性的司机，为了完成一半的活，也就跟了，也就只能拉完一半的活了。那么，在绕路的情况下，司机可以赚到多少钱呢？就360块了。司机就为了起步价这个机制的制约，司机就不会绕路了，因为绕路是不划算的。

这个数字例子震撼吗？至少我当时觉得很震撼的。它的震撼重点不在真实地是这样，而在于它们如此清晰地解释身边的事机制。没错，就在我们身边，有很多激励制度，可能我们每天都会见到，但是，我们并没有意识到，也很少有它们背后的动因和深刻的解释。总之，这个例子让我对理解激励的机制，理解激励机制的功能，影响是很大的。今天，我把这个故事分享给你们。

不过，为了防止对你形成误导，我再多一句，当你用所学的理论知识逻辑解决现实问题的时侯，一定要注意是逻辑和应用的前提条件。学一个理论，其实没多分的事，但是，学会使用它这个理论，却是很难的时间的事。另外，要知道应用初期的经济学理论去指导，是有限。因为任何理论的成立，都有限多假前提条件。这一点，在经济学中，特别突出。

管理工作会用到很多的经济学观念，但并不是简单地套用，比如，就像我们刚才举的这个例子，它的版本是比较清楚的，需要更多的前提假设。比如，司机没有空转空间，拉活是一个接一个的，等等。很多假设，如果哪一个不成立，整个逻辑就不成立了。不过，即便如此，并不妨碍我们运用一个例子去理解激励机制设计的逻辑。所谓“激励机制”，就是通过事先设定的报酬方式，来引导人们在追求个人收益的过程中，完成他所期望的行为。

# 2. 四种报酬方式

与心理学的研究不同，经济学的研究是赤裸裸的利益导向，一切都有用理论说，我们上一节课讲，是基于心理学的，我们更强调动机和感受的力量。而这一周都是用理论讲，也许你如果能从经济学这一侧面找讲话的精神。如果你对经济学有一定基础的话，你一定能感受受到这两个学科思考角度和方式的不同。

下级之上，上级要监督，根据一个基本的情境假设不同的管理状态，这二不是同一个情境。在这种情下，我介绍四种常见的报酬方式：

+   1. 建立在下级表现能够观察到下级的努力程度下，下级表现能级观察到下级，并且能级被量化成下，报酬是由下级的努力程度或者绩效水平，报酬的方式可以选择“绩效报酬”。在这种情形下，上级可以选择向下级支付绩效的方式为工作的回报。在支付报酬之后，所有的其余收入被用于上级管理，下级到剩余全部为零。在这中情形下，风险也主要向上级承担。这种报酬方式比较适合用技术手段能精确的计量业绩，如果绩效技术不高，则费力程度较难观测，固定报酬失效率较高。

+   2. 叫做“佣金合同”，如果前一种方式的风险主要在下级，则佣金合同形式中的风险被分散到上级。取佣金的方式，在这种形式下，上级收取固定的租资费用，经营之外的全部剩余归下级所有，除了租金之外的全部剩余与下级无关，风险也全部归于下级。显然，在这种激励模式下，下级不仅取得了全部的剩余收益权，他们的就会充分发挥自己的努力，从而追求最大化的产出。当收益情况与下级的努力程度高度相关时，这种激励方式是最佳的。
