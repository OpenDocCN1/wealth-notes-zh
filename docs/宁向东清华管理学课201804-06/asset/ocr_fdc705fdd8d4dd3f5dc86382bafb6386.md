# 212讲：激励性报酬！什么岗位的报酬要给高

昨天我们讲到，报酬总水平必须要达到一个大家觉得很合理的水准，水平太低会让人觉得不合理，会留在你这里留不住。今天我们从这里往上讲，如果增加报酬水平，一定会产生激励效果，这又有中什么样的逻辑呢？

# 1.效率工资与失败成本

还是从上面那个例子开始，一个人在一个岗位上每年的初始收入是8万。在类似行业、类似规模的企业里，类似岗位、相似工资的人，收入大约都是8万左右，是一般，工资收入这个报酬水平就会被认为是合理的。但是，在这种情况下提薪酬，这个工作报酬会被人拒绝比较正常。这个工作报酬会被人认为是比较正常的大概就是不考虑员工的基本要求和公平性，不会去追求更高目标的机动和动力。

那么，如果报酬是8万，而是12万，会怎么样呢？毫无疑问，这个时刻就会产生更强的激励效果。这激励效果从哪里来的呢？我们还是从动机的角度来看，这时候，多数人会产生一种工作干得太好的后果，认为工作不可能会失败。而不愿意自己不够努力，以经过末位淘汰，就会失去这个工作。一旦失去这个工作，就只能到市场上去找类似的岗位、类似的工作。

类似的岗位，类似的工作，前面说了，市场的行情都是8万，这是所谓的“合理报酬”，也是市场上的一般报价。于是，你就失去了能够到12万报酬的机会。这会很可惜，就是这个原因，人们会产生激励感，就是一定努力工作，要严格约束自己，以免被老板开除，失去能够赚12万的工作机会。

前面的这个故事，始于一个故事。当年福特汽车公司招技术工人，给的报酬是一天5美元的日工资。你知道当时工业工人 的日平均工资是多少吗？2.5美元。福特给出的，是市场价格的整整一倍。现在有读者这个故事，很有点版本了。比如有人说，当时的情况是工厂的流水率特别大，福特这样做，是为稳定员工队伍，防止不断招收新工人，培训费很大，所以，福特就把培训费用节省下来，用于工资的发放。

反正不管故事是什么版本，福特中心又是如何盘算的，但结果大家都知道，福特是福特了，自己的工人大口地拿到两倍于市场平均工资。多给了一倍工资，效果怎么样呢？首先，员工非稳，第二，员工努力生产，防止因工作业绩不佳而被开除，这就是一种来自干金钱的激励，而且是一种来自于内心心理约束的高质量激励。

后来由此总结出来一个重要的概念，叫做“效率工资”，意思是说通过这样的报酬水平安排，可以引发高质量的工作的动力。这个工资就可以发生效率工资的效果。与效率工资相对应的概念，叫做“失败成本”。什么意思呢？就是叫为市场水平的效率工资，员工还不努力工作，但一旦发解雇，就没办法得到多出来的那部分工资。那就办法得到多出来的那部分，是一种失败成本。因为担心失败成本较大，员工就会让自己的业绩更好，行为更稳定，这就是刚才说的内在激励的来源。

# 2.什么时候该给高效率工资

了解效率工资和失败成本的概念，对于强化激励、搞好管理工作的意义是很大的。每一个管理者都应该经常性地思考一下：你的下属，你的失败成本究竟有多大？如果一个人的失败成本很大，他通常会进行自我约束；而如果一个人的失败成本不低，往往就会影响到这些重要的管理举措，就都动不成了，管理手段也会失效。

那么，什么时候该员工“效率工资”？也就是说提高市场薪酬水平要对外花钱呢？一般来说，员工的工作越难以被市场外部，部分监督越依赖对劳动者的责任和自我激励，就越应该给予比较高的报酬水平，也就具有潜在的激励性很强。

比如，一个企业的最高管理者，他们的努力对于企业业绩的影响是非常重要的。但是，对于高管者的所有行为，你就没办法去外部监督。

我们现在在体制内企业，当领导人离职的时候，都会有一个离任审计。但是，不管这个审计得多么到位，你没有那么多知道这位离任的企业负责人，是否违反法规的行为，甚至他在工作的过程中，是否尽职尽忠，所有他做的事情都做了，你不知道的。

其实，这种情况又何止是在企业的最高层，各级领导者，甚至是基层员工，其实都有可能没办法做他应该做的工作动力，甚至就没那么负责任的举措。不过，他们虽然不知道自己做的事事情都对位，虽然不知道，可是当事人的事非常清楚。那么，如何激励他把该做的事都做到位呢？就要充分调动最激励措施。很重要的，就是要通过激励性报酬，把报酬给到位。

福特的效率工资，就是一种把报酬给到位的方法，在这个方法里面，调动强化考核和淘汰，使失败成本大的逻辑完全发挥出来了，再进一步，将激励性报酬的作用机制发挥到了极致。核心概念，是整合‘逻辑链条的一个关口。人们可以想一下，如果没有严格的考核和淘汰，光给是高出来市场水平的报酬，有激励效果呢？答案简单：没有。否则，就会没有那么多所谓的“好”工作。

这种所谓的“好工作”，“性价比”极高，绝对别人虽然干不出，但我们没有淘汰，基本上就是混日子。一方面，拿着浮游优厚的工资，另一方面，又是在天养着水平，无事事清。你的单位收入水平，比外面风投口好，苦干收入的人不知道要好多少。但是，你给他诊断吗？他还不珍惜水，因为他没有任何的淘汰压力，所以，他并不珍惜这个还不错的“好”工作。

今年是改革开放四十周年，这四十年来，这种人事开岗位，在我们体制内已经太多了。在我们小的时候，身边只有这种报酬水平高，但没有考核、没有激励、没有压力的岗位，因为大家没有改变，所以，拿到高报酬，他们也不知道要珍惜，更不是上了级别的激励影响了。后来，改革开放了，有了逐渐严格的考核，岗位的利益越来越小，于是，凡是激励水平相对好一点的岗位，大家都会格外在意地对待。这就是“失败成本”这个概念在发挥作用，于是，报酬就有了激励的含义了。

总结一下，为什么要多给钱？就是要获得激励效果。因为如果只给市场上大家都认为合理的价，不可能有激励效果。要想有激励效果，就必须有多给钱。多给钱的配，还要意思有严格的考核和淘汰才作配，因为失败成本低，效率工资的激励价值才有可能体现出来。

# 3.什么岗位需要多给钱

接下里，你可能会问：什么样的岗位或者工作是要要多给钱的？我告诉各位，凡是外部不好监督工作好，不好监督工作努力情况，甚至是员工不好衡量，同时达到业绩结果的，需要多给钱，需要通过激励性报酬让个人的动机更充沛。

比如说，华尔街经常会有大案的地方。年给，每年发现，过两年你会发现，高级管理人员的报酬就会上涨不少。为什么？就是业绩工作不好监督，而自就靠是业绩体现出来了，不好短期内也没办法判断，这种业绩是不好短期看的，不是吗？报酬在长期来是长期可以获得的。那么，怎么来公司？就是增加报酬的水平，增加这些高管的失败成本，进而让他们进行自我约束。

想一想，我们什么某个影响影公司那样，他们一般没有有法律风限界岗位里描述的高职，就像电影和暴风舞那样，你在这个行业的薪酬，就没有了。

现在，我们总结一下这两天说的。思考激励性报酬，首先需要考虑报酬的总水平满不满足合理？ 我们还要还会达到，除了总水平多少，还需要考虑报酬的结构，工资多少，奖金多少，需要不要期权，是朝三暮四，还是朝四暮三。不过，你一定要想得，比报酬结构更重要的是，是总体的水平，总是关键的重，一定要不可能少。”
