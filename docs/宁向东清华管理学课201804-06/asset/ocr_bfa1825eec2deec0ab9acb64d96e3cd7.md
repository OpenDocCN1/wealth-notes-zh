# 划重点

技术创新分为延续性创新和破坏性创新。两者的区别，就在于技术是否处于同一个轨道。成功的企业大多按照延续性的技术轨道发展成果，然后在特定的功能上，给消费者提供越来越多的功能。一般由成功经验所形成价值网的能力，会逐渐进化，而成为大企业无法突破成功的死穴
