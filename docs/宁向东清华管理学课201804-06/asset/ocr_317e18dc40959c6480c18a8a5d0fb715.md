# 1.竞技比赛的奖金设置

先从一个我亲身经历的例子说起。80年代中期，格杀嘉卫平在中国围棋擂台赛上连续两局力挽狂澜，应昌期老先生将他的捐款成立了应氏杯，嘉卫平创立。应氏杯最初可以就是嘉为嘉卫平而设立的。这是第一个世界级的围棋比赛。应老先生就是期望我们中国人拿到第一个围棋世界冠军。

因为应氏杯的影响力，我格外留意了关于这个比赛的细节。我注意到这个比赛的奖金设置很特别，第一名40万美金；第二名10万美金；两个并列第三名各2.5万美金。这个奖金设置造成了很多人关于奖金差距的认识，第一名和第二名之间的差距是30万，第二名和第三名奖金之间的差距却只有7.5万。

当时，我的想法很简单，以为这是应老先生大私人，他就是希望嘉卫平能冠军，所以，才把他/她的奖金设置得非常高。后来，看了最勤励的基本道理，才知道我最初的想法完全不对，不是应老先生的“私人”使得应氏杯的报酬呈现了这样的面貌，而是所有锦标赛的设置均如此。几乎所有的排名、锦标赛，奖金的设置都是阶梯式的，奖金的递增也是阶梯式的，差距越来越大。简单地看，奖金都是递增的。

比如，高尔夫最最高级别的比赛，美国巡回赛中的联邦杯快速排名，第一名的奖金都是1000万美金，第二名是300万，第三名是200万，第四名是150万，第五名是100万，第六名是80万。你看，名次往前推一位，报酬就会高很多。第六名比第一名增加20万，再往前推一名，增加50万，如果从第三名往第二名推，奖金之差只有100万，而从亚军到冠军，奖金之差会达到700万。

与高尔夫相比，羽毛球的奖金水平是比较低的。但即便如此，奖金的设置也依循着同样的逻辑。我们看一下全英羽毛球锦标赛，2016年的奖金就是这样分配的。单打的第一名是30000英镑，第二名的15200英镑，而止步于四强，获得列举第三名，奖金是8500英镑，止步于十六强是2400英镑。也是向上走一步，奖金的增加都是递增的。

# 2.报酬上的边际递增

为什么要进行这样的递增设计呢？我的解读就是尊重“按劳分配”的原则，我们都知道，经济学上有一个很重要的法则，叫做“边际收益递减法则”。具体地说，当其它影响因素不变的条件下，每多投入一份努力，所获得的回报是边际递减的。什么意思呢？我举个例子来说明。

比如我参加某一门考试，复习的话，我可能得到40分，如果花上十天的时间复习这门课，我可以增加30分，也就是十天可以获得3分。回报是30分，平均每天可以得到3分的回报。我再复着投入十天的时间继续复习，也许只能有10分，总分只到80分。第二个十天后，平均每天可以得到8分。这我继续投入时间复习，第三个十天、第四个十天，毫无疑问，获得的回报会逐渐减少。假如我还能达到95分，要花10天，我只能获得1分。回报大约只有1分。

这个努力的力度越大，但获得分值回报越少的逻辑，就是边际收益递减的逻辑。但是，如果我们反过来想想你的体会，你得到一个有趣的问题，虽然最后十天才只获得了1分，但是投入的努力却是质良价实的，也就是说，最开始的时候，水平是40分的水品，每获得1分的成就感，只需要花三分之一天的劳动。如果一天的劳动值300块钱，水平低的时候，增加的一分，只值100块钱。然而，水平进一步提高，到70分的水品，增加的一分，值300块。再往上走，水平提高到了95分的水品，还能增加，水平，需要六天的努力，这一分回报值多少钱呢？是3000块钱。

这就是与投入努力“边际收益递减法则”相对的，给子激励性报酬时，必要要考虑“报酬上的边际递增原理”。我在清华的MBA同学多年的“管理经济学”课程，每年我都为同学们讲这个道理，尽管在教科书上必须有这一点，但是，所有做管理的人也不理解这一状况，这是一个看待激励问题的基本逻辑。很多时候，激励高贡献，领导会给我们付更多多酬，会不低给，特别是中国，平均主义文化是传统性的，根深蒂固，所以，对水平高的人的关心，总是提不上去。我觉得这是我需要点观念上彻底改变的。

坦率地说，要激励出高回报，必须要多给报酬。水平越高，你要激励他出进步，就必须大给他超过一般水平的回报，要有别人回报的基础。只有大回报的差距，才不会让大家在较低水平下，还留势力，不。否则，大家就会安于现状了，不会付出超水平努力。今天的课后，我建议大家再读一下“内驱之神”那一讲，不妨从今天课程的内容，再回顾一下相关的知识，并思考一下我们这个社会的激励机制。也是有助于催生“工匠精神”。这也是今天的作业。

# 3.报酬封顶

这两周的课，我们讨论的问题一直集中在这样的个飞线上，就是：努力越多，业绩会越好，因而绩效越高，当激励也可以得到越多。这是基本的底层逻辑。今天课，我们进一步向前去了拓展，就是要在高位上付出好成绩，要把高底层逻辑进一步提升上去。应该说，这个事情逻辑，影响关系就是很容易说清楚的，在这条逻辑链条里面，不存在着任何，除了因果关系是一一对应的。比如，除了努力之外，没有其它任何因素会影响业绩。

然而，现实中的多时候，影响业绩的，并不完全靠努力，还包括很多界因素，如环境、运气等打包的因素。好坏运气不完全来自于努力，可能很大程度上来自于好运气，好运气也同时带来了高奖金、高规模。那么，这报酬最发，还是不发掘？
