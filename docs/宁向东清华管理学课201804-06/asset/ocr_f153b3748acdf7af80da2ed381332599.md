# 变革时代

为什么这么说呢？我们只要看看我们身边所发生的种种变化就知道了。首先，人与人之间的关系的分化正在发生着翻天覆地的变化。回顾历史，人类在二十世纪的前半叶，打电话是很困难的事情。在上世纪 80 年代，人们长途打电话，要去邮局，也许要等上个把小时，才能打通长途。我们的固定电话是 1995 年装上的，那时还要交 5000 块钱的话费，打电话还另收市话费。那个时候，人们的工作只有几张台、一张电脑，还要用半年才有网。那个时候的移动电话是模拟信号的，叫做大哥大。一部大哥大，卖到两三万块钱。

然而，仅仅过了二十多年，人们已经不再满足于只有手机的单一通讯方式。每个人都可以通过移动终端，在瞬间和更多的人发生联系，并且可以在很短的时间里和更多的人发生联系，并且可以在瞬间实现互联，从而可以相互联系。第二，人类的生存方式和利用资源，以及未来的利用方式也在发生着剧烈的变化。第三，社会正在改变着人们生存方式，正在去中心化和集中式化的同时，正在向网络组织、送货上门等等的替代。

只要你回顾历史，凡是通讯、运输和能源领域发生变革的，都会引发一场经济领域的波动和革命，而这一次领域一定会发生。人类历史从没有停止过。所以，未来世界的变化用“VUCA”来描述我们的世界和世界观，我觉得很准确。未来世界，它最突出的不确定性，复杂性，以及模糊性。这是四个形容词，前四个就是前两种 VUCA 的首字母。在这种世界中，企业只有快速应变才有能力去适应，变革管理将成为企业管理的基本功。

# 变革八步

# 1、营造变革的紧迫感

第一步，领导者要是自己下决心要进行变革还不够，还必须也要有足够的组织内部成员对变革的紧迫感，也是变革的紧迫感，也是我所说的要发好动员。今天的课题为《变革八步》这篇文章吗？今天的课后，请到知乎上去搜一下这篇文章，并了解当今时代的背景，今天的发展成为一家最不可靠的公司。一家公司与今天的背景，与它的成功有巨大的关系。掌握好变革的时机，有计划、分阶段地进行变革，是企业进步的主要方法。

# 2、建立领导变革的团队

第二步，要找到能够成功推进变革的人，组建有效领导变革的团队。科特对变革团队的组成有如下建议：组成小组要比核心领导班子的组成更小的核心领导团队。要知道小组，要有比选派的有号召力的人，要挑选的人对变革的必要性进行认识。海法改革的失败，人参与其中。鉴于这步，我要有一点好话。并且特想提醒你不要受到误导。有一点很好。还有一个点就是他们会受到误导。科学的人，还有一点不好，他们是一个共同的问题就是犯复杂问题简单化的错误。

坦率地讲，我作为半个学者，所以，我特别了解学院化的长处和不足，优缺点都不说了，不足之处就是多时会把复杂的问题简单化。比如，涉及到复杂的事情上，如何解决和才能找到比比较有效的结果，必要条件是具体的具体情形，具体问题具体对待，非常复杂，一定是具体的。但是，科学的人，还有一点不好，他们是一个共同的问题就是犯复杂问题简单化的错误。

以前，凡是涉及到这类问题，我基本是回避的。正如我讲得不太科学一样，这些内容都是回避的。实际上，我不深入的，像我们这本书《蓝海战略》，我花了两天时间介绍作者的价值主张，创造性曲线，四步行动次序法，我不禁要问，创造性曲线怎么就创造法，我不知道。什么？因为我作为作者的话太专业，我不知怎么讲，我认为作者说得过于复杂了。我讲《蓝海战略》的经验，有点无知无畏。但是，《蓝海战略》的精华是创造价值那章东西，所以，我把这条东西讲得比较到位，至于如何推进蓝海战略实施，可以完全跳过。
