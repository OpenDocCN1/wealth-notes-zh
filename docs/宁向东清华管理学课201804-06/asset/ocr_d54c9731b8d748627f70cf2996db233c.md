# 划重点

+   1. 成功的公司，都有它们各自的成功方程式。但是当着成功方程式的固化，开始企业里，当企业面对破坏性环境的变化，破坏性的商业模式，面对着由破坏而来的创新的时候，会变得无可奈何。大企业需要在组织内部对外部去拥抱破坏性创新的新的方式。

+   2. 克里斯坦森是否破坏性创新是否有效的三个判断：现有有无破坏性创新的潜力；你的创新对于低端市场是否有名；是否可以破坏你内所有的主要竞争者。
