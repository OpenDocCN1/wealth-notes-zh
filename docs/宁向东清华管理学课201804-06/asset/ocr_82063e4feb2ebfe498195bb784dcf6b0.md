# 划重点

+   1. 架构是从从一个概念开始推导至另外一个概念，从一个线条展开，再到一个线条，再延伸到整个图案的可能性，最终连接所有的能力。
2. 水平思考法就是能够不顾及问题的回答是否满足这种思路，而是让思路顺着想法往下走，看看能不能走通的思考方法。有一种跳跃、不连续的思路，提出有方法的解决方案。
3. 我们今天已经来到跨界越来越频繁的时代，只有把水平思考和垂直思考相结合，才有可能适应这样一个跨界时代的逻辑。
