# 221讲：激励相容丨财散人聚，财聚人散

你好，欢迎回到《宁向东的管理哲学课》。

到目前为止，我们已经讲了三周的激励了。这一周，我们再给补缺，讲一些重要的激励概念和状态。今天的课，讲讲股份的问题。我不知道你会不会想到，我们为什么要通过发股权来激励人？发了股权，可以解决哪些问题？股权是现在我们企业里很主要的工具。不过，为了把这件事说清楚，我们先从激励机制的两个约束说起。

# 1.参与约束与激励相容

关于激励，有两个约束特别重要。第一条叫做“让别人和你玩，一定是和他玩你能给他最大的参与度”，经济学里就是这条叫作“参与约束”。什么意思呢？就是人如果去跑游戏确实要做一件事，他在事上的收益，一定要大于他的机会成本。

人在某种意义上都是经济动物，人们时时刻刻都在做选择。人的选择，本质上就是决定把更多的时间投资投入到哪件事情上。经济决策如此，一个人是否选择某一件事，一定是意味着这件事可以给他最大的收益。这就是所谓的一定制下约定与约束，讨论是否做这件事的前提，首先要看这个人在某一件事上全情投入，是不是可以满意。否则，均不具备讨论激励的前提。

第二条规则，就是激励者和被激励的人之间，一定是共赢的，也就是说他们的“激励相容”。绝不能是一个人的赢，是以另外个人的输为前提。为个例。毫无疑问，股权关系，有机会实现双方的共赢。股东出大钱，让其他人占小头，经理人通过奋斗自己利益，把股东的利益带出来，这就是共赢。

正是因为这个原因，股东在一定时期愿意让经理人、管理骨干、技术骨干持有公司股权。持股后资源，不仅可以满足经理人、管理骨干和技术骨干的参与约束，更是有解决企业是激励相容的。所以，有股权激励解决问题是大方向。然而，给了股份，真的就万事大吉了吗？

# 2.参与约束的动态特性

先说“参与约束”，也就是一个人要专心做一件事，他在事件上的收益，一定要大于做其它事情的收益。也就是大于他的机会成本。人们时刻都选择参与这句话，其实意味着着他的机会成本是历历时更迭。先能满满足参与约束，到后保量以后总会能保满足参与约束，当情境变化的时候，股东利益也有可能发生变化，由帮手变成了麻烦。

我认识的一位企业家，深谙“财散人聚”的道理。我之所以关注关系好，就是他对这方面的智慧常常让我佩服，他虽然没念过什么书，但是，他的做法和说法常常给我很大的启发。我曾经问认识的商界绝对对大牛的那种，多年来一直保持着非常基本特征，十几年如一日，这一点非常不容易。

在这位朋友的事业发展道路上，职业经理人一直扮演着重要的角色，他不得花钱，每年都付出超过大额额的报酬激励，而不都涨着薪水。我曾经问他为什么会这样做，他就有过我这样看。他说的，比如某某某，我从国有大国企把他挖出来的时候，他在全企业只有5万块钱工资，有一位老板他给30万，我说，他说50万，他老他自己说了的算的，我就说，这是不是有吸引力的安排？我说是，有吸引力，而且是最大的吸引力。

这个话，首先分析一下，就是前面我们讲过的，首先满足了参与约束，我们是请老板给了这位某某某30万年，这就是这位经理人的市场价，也就是他的参与约束。我们这位老板是这位经理人挖出来，给他了50年薪，就满足了他的参与约束。又过了一年，我是这位老板吃饭的时候，他告诉我是，说这位经理人的报单已经做到了300万。我问他在什，他说了一句特别简单的话：行情在变。

我后来想了一下，你看到我这位老板朋友没来读过书，他的所作所为还真符合学者们研究了一辈子研究出来的这个道理：研究我们刚才说的，“满足参与约束。不仅仅要入伙的时候，而是要参与约束，以后，时时刻刻都要满足参与约束。

这位经理人加入的时候，参与约束是30万，但是，他的能力在民营企业的这个平台上得到了极大的施展。在新的平台上，他不断地创造出了新的价值，比如，他开始考虑50万的薪酬对他们来说，是一种感恩戴德的心态，别人开了30万，老板到了50万，他感恩戴德，很和谐，也能感受到老板的善意。但他们了平台，浑身全部都展开了，业绩也和他原来完全不一样了。他在这个时候，对自己已有了一个量重的判断，他突然意识到自己的能力是值50万的。

又过了一年，竞争对手就来抢人了，开价就是100万，这个时候，他的能力就被变成了100万，所以，我们这位朋友就按照他们上算的重新原局，基本薪酬加上线上激励，总算上给他控制在120万左右，这一次满足了某某某的参与约束。我学一句诗来描述这个变化，叫做：年年花相似，岁岁年人不人。

在考虑激励问题的时候，必须要学会动态看问题，不能一成不变地看一个人的身价，每个人参与约束都会变化，每个人的积极性都会发生变化。所以，作为领导者，作为管理者，作为老板，必须要对下属的参与约束动态的方面。

另外，这种洞察不仅只停留于物质层面，很多时候，人常常还会产生精神层面的需求。比如说，我们以往在讲企业对待精英人员的态度时，曾经讲过一个例子，下属的辞并非仅仅是为了多赚一点钱，更重要的是，希望得到一个自己完全能够掌控的舞台以及发展机会。我常常说，当下属产生了非常强的意愿以后，物质激励的逻辑就不成立了。也就是说，当一个人有了成就事业的意愿之后，激励的性质就必须发生变化了。

# 3.股权是一把双刃剑

再说到股权和激励的关系。我的朋友给什么人挖进来一年300万之后，基本就没有什么人挖这某某某来了，因为这个身价太高了。我就问这位老板朋友，为什么你不给他股份，而他给这么多现金？我的朋友有直接回答我的问题，他反问我：如果给股份，要多少呢？

我按照这位经理人的报酬水平和企业当时的利润反推回去，我说大约5%左右吧。这位朋友接着问我，是永久的，还是暂时的？也永远是现在老板里工作是有利的，如果是永久的，那么我经理就比他还赚得多，是不是也要按着他看？如果说着，两个人只要拿走他的10%，那么，如果人才是被拿走，后面那个人不会去不想拒绝他的这个股权。股权真是的？如果没有股权的经理人，干了一段时间觉得不合适了，怎么办？

这件事发生在十几年前，那个时候中国企业的股权激励的环境和现在还不像今天这样成熟了，所以，这位老板还在，还是用现金付钱。我后来仔细想想，虽然股权激励确实保证股东和经理人利益一致的一种通用办法，但给了股权也会导致新的差异性，也就是说，有一利就可能又带来了一弊。

比如，那个时候的身份证还仅仅是管理人的身份，那种敏感意识还不太高的环境下，他就一心要把老板交代的事情做好就行了，反正进了市场300万，这个收入水平已经远远超出行情了，他也不会太多的想法。如果进了股权，经理人的身份意识就会发生一些变化，他会记得公司自己的会是一盘棋心态的给公司办公，他这个时候就会从全公司的角度去开发想法。一摸配，他的可跟不一定就非是。

很多股东之间的矛盾，其实都是由于权力和控制权的争夺而来的。

我的朋友是执事者不糊涂，他就是想进来的人心太多。所以，他从根本上就有想过要送经理人股份。用他的话说，给了股，300万钱分红下来，其实就差不多了。

这就回到今天讲的激励的第二条规则：就是寻找合适的办法，做到激励相容。无论是什么样的方式，只要有激励和能够被双方利益诉求，让大家的利益诉求
