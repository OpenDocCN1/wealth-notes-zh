# 1. 时间的维度

在前面这段话中，我讲了两个重要的维度：一个是时间维度，共用了两个专业术语：前馈和反馈，另外一个维度，是关于控制目标，我用了微观和宏观两个词。下面，我分别解释这两个维度。

先讲时间维度。控制活动按照时间来区分，可以分为前馈控制、周期控制和反馈控制三种。前馈控制的主要目的，是为了预防问题的发生，它发生在目标活动之前。周期控制自的是在行为活动进行的正过程中，控制自的是为了减少不当行为发生，出现问题及时纠止。而反馈控制，自的也出现了问题之后进行的控制，控制的对象是为了投入、过程和指标等循环进行改善和补正。某种意义上可以说，前馈控制和周期控制是为了防止未然，反馈控制是亡羊补牢。

比如，仓库保管员会发生在窃物品的情况，属于组织中非常重要的岗位。那么，其进行控制，就是在雇佣保管过程之前，对其进行全面考察，通过设计必要的选机制来加以甄别。而周期控制，则包括对他们的业务能力形成震撼，或是通过技术手段加强监督，减少或避免盗窃行为发生。反馈控制，则通过追查盗窃数量，加强保管管理，来实现反馈，及时完善制度，奖惩相关人员。

比保管员更需要前馈控制的，是重要管理岗位上的人。这是重要的管理岗位，并不仅仅指公司的经理层，甚至还包括财务管理人员和采购管理人员，很多企业会安排重要企业会较偏要求让家庭成员参与管理，甚至安排财务和采购由更高级的人执行。其实，除了家族企业的利益更紧密的岗位和制度一致性，很重要的，在于这是一种前馈控制。如果家族成员会到管理。本身就不允许，比如家族企业不允许别人入。一般常情况下，如使股东在邀请这些家庭成员加入的时候，都会仔细斟酌过利弊了，他们早就计划，那些职位会必须要放弃。可派责的人手管理。学手今天的课，你一定更知道：家族企业虽管水平的地位，但是全在企业中大权在握，本质上是一种前馈控制机制。

这些岗位如果能交给能力的外部人手里不行吗？也可能，但对于很多小型企业，这是要冒风险的。一旦外出的人滥用你对他的信任，那种莫大比保护员要对你伤害更了。对于某类企业，主要管理岗位的人用信任和信作，会比拟效容易多太多关键，比较直接就会使组织危险很多关键时，比如知道水落青红水，一点地点失去竞争力。

总之，在外部环境不明确的情况下，找不到值得信赖的人，让人们只尽尽一股工作，可信任度也变了。单看人手。一般情下，位置越高岗，则馈管理越重要，但易发现，一个组织或者一个团队，不管易出现小问题，越是自己身边、给了他重的人，不尽心尽力地帮忙，甚至会拆他们的台。
