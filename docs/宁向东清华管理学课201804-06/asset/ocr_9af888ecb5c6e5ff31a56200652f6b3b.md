# 周五复盘｜四种控制体系缺一下可以吗？

你好，欢迎回到「宁向东的清华管理学课」。

本周我和你分享了控制的四只杠杆，分别是信用控制系统、边界控制系统、指标控制系统、互动控制系统。其中，指标控制系统最常见、

但是为了指标控制系统能够有效运作，我们必须要想办法把控制体系，从最简单的战略行动和战术计划、到顶层的正式分工，包括事故事可以，哪些事不可以做，多有明确有边界。像控制体系的内容，涉及的面积很大上，但也并不是完全无厘头，企业要做什么，最紧要什么，直接和行业的价值观观，什么有价值的目标，有什么的价值信，就会影响有组织的行动，进而影响企业的选择。要想交互动控制体系逻辑。

![](bbox=[0.08, 0.17, 0.92, 0.23])

有同学可能问，这些控制体系是否在不同规模、不同发展阶段企业都要有？今天的文章，我想分享一下西蒙斯教授在《控制的杠杆》中书中新写的一张图。按照西蒙斯教授的设法，公司在建立之初，都可以简单在初创阶段时，规模还不大，内部结构也不正式，就不必开建完整的内部控制体系。不过，公司必须逐渐学习制定利润计划，并且围绕这个利润计划建立指标控制体系。

公司进入成熟期，一定要着手提出员工内部的冲突，你可以叫做界于边界与操控，或叫做边界。总之，要逐渐丰富自己的红制度。对于那些边界都刻到控制能力的公司，战略性边界是可以制定得很松的，但是，对于那些利用利润计划的组织，战略边界必须更紧密，要更市场、组织，你什么也来去攻击说，防守，必须很明确。

在东西面配合控制体系上，有一定配合合理、配合计划，建立战略性。有了自由，互动式控制体系也逐渐建合起来。

前面两周，我们介绍了控制方面的基本理论和基本做法。下一周，我们探一下对于控制问题的观点，希望能对你有些启发和帮助。
