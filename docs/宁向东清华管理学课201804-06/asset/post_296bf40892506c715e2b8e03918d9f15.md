# 246 讲：变革八步（上）| 不盲崇崇拜经典

你好，欢迎来到《宁向东的管理课堂》。上一单元，我们讲了个人的变革，这一单元我们讲有关组织的变革。我认为，由于外部环境的变化、经济环境的持续变化，未来的时代可以毫无疑问地将是一个动荡剧烈的时代。转向与变革将在未来十年里是主旋律。无论是公司、个人，还是社会，无一能够幸免。组织变革的知识点和意识，在未来十年里是主旋律。

## 变革时代

为什么这么说呢？我们只要看看我们身边所发生的种种变化就知道了。首先，人与人之间的关系的分化正在发生着翻天覆地的变化。回顾历史，人类在二十世纪的前半叶，打电话是很困难的事情。在上世纪80年代，人们长途打电话，要去邮局，也许要等上个把小时，才能打通长途。我们的固定电话是1995年装上的，那时还要交5000块钱的初装费，打电话还另收市话费。那个时候，人们的工作只有几张台、一张电脑，还要用半年才有网。那个时候的移动电话是模拟信号的，叫做大哥大。一部大哥大，卖到两三万块钱。

然而，仅仅过了二十多年，人们已经不再满足于只有手机的单一通讯方式。每个人都可以通过移动终端，在瞬间和更多的人发生联系，并且可以在很短的时间里和更多的人发生联系，并且可以在瞬间实现互联，从而可以相互联系。第二，人类的生存方式和利用资源，以及未来的利用方式也在发生着剧烈的变化。第三，社会正在改变着人们生存方式，正在去中心化和集中式化的同时，正在向网络组织、送货上门等等的替代。

只要你回顾历史，凡是通讯、运输和能源领域发生变革的，都会引发一场经济领域的波动和革命，而这一次领域一定会发生。人类历史从没有停止过。所以，未来世界的变化用“VUCA”来描述我们的世界和世界观，我觉得很准确。未来世界，它最突出的不确定性、复杂性、以及模糊性。这是四个形容词，前四个就是前两种VUCA的首字母。在这种世界中，企业只有快速应变才有能力去适应，变革管理将成为企业管理的基本功。

提到变革管理，有一位学者是必须要说的。他的名字叫做科特（John Kotter），是哈佛商学院的教授。此人特别会讲故事，演讲得好极了。三十几岁就成为正宗教授，点名仅次于卡普兰（Kaplan）或诺尔（Nohria）。科特专著出版了二十几本书，其中因变革管理的八步骤成为管理学殿堂的经典性人物。

# 变革八步

## 1、营造变革的紧迫感

第一步，领导者要是自己下决心要进行变革还不够，还必须要有足够的组织内部成员对变革的紧迫感，也是我所说的要发动好动员。今天的课题为《变革八步》这篇文章。今天的课后，请到知乎上去搜一下这篇文章，并了解当今时代的背景，今天的发展成为一家最不可靠的公司。一家公司与今天的背景，与它的成功有巨大的关系。掌握好变革的时机，有计划、分阶段地进行变革，是企业进步的主要方法。

## 2、建立领导变革的团队

第二步，要找到能够成功推进变革的人，组建有效领导变革的团队。科特对变革团队的组成有如下建议：组成小组要比核心领导班子的组成更小。要知道，这个小组要比选派的有号召力的人，要挑选的人对变革的必要性进行认识。鉴于此，我要有一点提醒，你不要受到误导。有一个共同的问题就是犯复杂问题简单化的错误。

坦率地讲，我作为半个学者，所以，我特别了解学院化的长处和不足。不足之处就是把复杂的问题简单化。比如，涉及到复杂的事情上，如何解决才能找到比较有效的结果，必要条件是具体的具体情形，具体问题具体对待，非常复杂，一定是具体的。但是，科学的人，还有一点不好，他们是一个共同的问题就是犯复杂问题简单化的错误。

以前，凡是涉及到这类问题，我基本是回避的。正如我讲得不太科学一样，这些内容都是回避的。实际上，我不深入的，像我们这本书《蓝海战略》，我花了两天时间介绍作者的价值主张、创造性曲线、四步行动次序法，我不禁要问，创造性曲线怎么就创造法，我不知道。什么？因为我作为作者的话太专业，我不知怎么讲，我认为作者说得过于复杂了。我讲《蓝海战略》的经验，有点无知无畏。但是，《蓝海战略》的精华是创造价值那章东西，所以，我把这条东西讲得比较到位，至于如何推进蓝海战略实施，可以完全跳过。

这套东西，有个专门的技术，我虽然不是强迫这“东西”，但主要用于一个特点的强固的东西。在变革中，是有一个不断的、需要变革的局面，仅仅会一个大方向来解决问题。你解决不了，甚至自己的老命有的时候也不会保。所以，多亏古罗马来用古罗马的方法，可以用古罗马的方法来解决问题。古罗马，不会发怒出上面就是简单的，起码不少于引敌人，这就是简单的技术。

上一讲我们讲过了科特变革八步的前两步，第一，营造变革的紧迫感，第二，建立领导核心团队。今天我们继续讲后面的第三步到第六步。四步变革的核心理念，用科特的学术语言，叫做营造变革的愿景。

## 3、塑造变革的愿景（序号接上一讲）

一般来说，从领导者来看，推进变革有三种方法。第一，就是强力压制，有点像我们前面讲过的领导力情境模式，能干什么，不能干什么；第二种，就是串联手段，像妈妈对孩子；第三种，就是靠树立一个吸引的变革愿景。

在科特的《领导变革》里面，他也说有三种，也是提出一个大家好的愿景，避免变革只是对着一个人对对对，应该让大家感觉到它是共赢的，大家都好处，大家原意积极地参与进来。

![](img/17b87b436c90c966960c6a3171fa356b_88_0.png)

科特的书里面有一张图，从这张图中，你可以看到他，他认为所有的方案变革都很有独特性，他说只是只说对的方式是没有错的，可以深入到人心。

但是，这张图有一个假设，就是那些意愿改变的、支持愿景实现的那一部分是加我的，如果没有的过程，就可能是有些细节的，甚至可能要换个一些比较深的人员，也许其实手段并非不是可以达到的方式。

至少可以罗列大样本，几种方法并用。

但不管怎样说，科特的理论集中在变革愿景上，我就不管说什么了思想中下载。科特认为，愿景一个好的愿景愿景是要办的，而设计一个好的变革愿景从下几个方面入手。

1. 好的变革愿景是让人有想象力的，它能够传播一个关于未来的比较清晰的图景，以前有同同学问，什么叫想象力？这个是个好问题，我想我生学会做下一个清晰的开发经验。

变革市场是竞争分的，你之前比如和一家公司商量，是为自己设计师给与他来一份图。那种图他传递了一个愿景，至于要修改之后不是清晰的，在最后他仍然感受到不好的，但是图确实是清晰的，每个角度，每一局部，是什么，都可以从效果上有个清晰的感觉。

2. 好愿景一定是参与变革的人愿意达到的（desirable）。你之前说了你最后参与变革的人因为你想效果啊，是你想要的，对你有吸引力。科特非常强调这个愿景是对公司、员工真正有好处，只有这样，才能吸引员工共同参与。

3. 变革的愿景一定要具有可行性，讲起来会让大家觉得行得通。科特专门强调的，如果是专家是调程序好的人，组织内部的的确确是按照程序组织来说的，没有办法实现这种途径进行分担的，所以说，没有办法形成合力，达到更好服务客户的变革愿景。

如果是这样，大家都两下，发现行不通，也就不信你的变革计划了。

4. 变革的愿景一定要聚焦，可以给员工在变革的过程中什么先做导向，什么必须要做，什么可以先放的时候，都放，我们可以清理房间，或者需要的时候，都要有效的经验，就是只要有一个顺序，什么先动，什么行动，只要有个顺序的逻辑是清楚的，行动才有可能高效。

5. 变革的愿景要有弹性，对大家的创新活动要有包容性。这一条非常不容易，非常多。为什么大型组织的变革不容易成功？无非是因为公司的规模是特别多的。我们在制造的一模模糊的经经许多讲过，在大型公司里非常地关键，是概率，概率基础上的英雄主义，所以，小集团的创新就不容易被到组织的保护。

你在今天的课上可以研究一下诺基亚，其实，诺基亚是一家研究的手制制造者。因为芬兰人对于产品的研究态度的，它们的手机是非常好。

选择在研究这过程中它的手机之后，在写《国家竞争优势》这本书时，特别强调国内市场对于企业发展的意义，是十分重大的。芬兰人口十分多非常小，所以，诺基亚一旦受到严格的考验，这它后来成长为了一个全球市场占了很好的包络。

我第一次听评讲下这个观点的时候，就在想我们这么态度，很多时候是“差不多就行了”。我不知道能不能解到说，他们中国人是很‘差不多主义’，我们对产品没有那么多人的要求，我们很宽容，而且你的价格不够有包容性，在这种情况下，我们的产品结果是在全球市场上检验过，质量水平一般般就木不行。

说回回到诺基亚，一家产品品质非常好的公司，为什么有今天可下，可除了有很多误区就因为它够大，规模也存，概率上的东西大就难以改变。这一点，诺基亚的手机出货量是亿部，任何一项变革，只需要在一个局部展开都到整个体系，只要愿意愿意想象，就可以制造出有包容性的变革计划，它很难去维持一个市场量的小创新计划，最后只能一头扎入青者的巨量，翘翘板下。

当我听到诺基亚下的声音时，其实内心是很难受的，因为我所有手机是诺基亚的，我给难得最老的手功能手机的时候，我尝试上学生上洗手手的，用也的诺基亚手机，手机，当我把桌面上戴着的电池和手机主上，后盖弹起来，然后告诉学生这是诺基亚的一项专利技术，用能来设计，保护这个手机弹起来的时候，我无法能让它学生惊叹的手机啊。你现在已经在用手机拆手机了。但也不可能上知道，这个后来手机布机应用采用手机上的向导技术，最终开发者都是基亚的。

而，也没有让诺基亚性技术应用在基亚，宁可在自己的手机上面插着一根很容易丢失的手写笔。

总之，变革的愿景是很容易制定的，但保持愿景的弹性是非常非常不易的。这一点，我们一定要记住。

6. 愿景要可以清晰表达，便于组织内沟通。科特对此有一个描述，就是能够在5分钟清晰地表达出来。

清晰表达这件事，说起来很容易，但是做到并不容易。我最近跟朋友进行的交流特别多，有些人做了很多年里自己很懂很懂，我都跟他们分享了，但是话讲来，我虽然给每个人讲过，讲过大的技术，但我需要对我自己的很多对话，我发言太大需要太多的地方。

我的课程马上又要结束了，我今天强调的，管理技术的事情是没有毕毕业的，5分钟讲清楚这件事是不有，常需要反复练习。我最近听自己交流录音的时候，发现很多时候，连我这个老师，做得都不好。

## 4、和员工充分沟通

第四步，要把变革的愿景和变革的策略，和员工做充分的沟通交流。这里我要强调一下，在大型组织的变革过程中，在当中高层管理者的沟通是非常重要的，在很多事情，中间在下一做转变变革愿景的时候，他们忘记自己在推进变革最原的时候，曾经经历的煎熬，他们往往花更多的时间去面对众人的反对。

在《领导变革》一半出版之后，科特后来专门写了《变革宣言》等专着，进一步拆解这八个步骤的细节。其中，沟通是他强调最多的内容之一。

## 5、给员工更多的授权

第五步，要想办法给员工更多的授权，让他们有更多的行动空间。科特特别强调在观念上和制度层面，要保证员工在变革中有积极的行动。

科特举的例子，公司在愿景里面提到基层的员工变革理念，发现你的愿望，但在激励机制上却没有相应的支持，在中低领导承担责任的时候，有中层管理者因人不愿意思承担授权的责任，常常扮演事后诸葛亮角色，并对员工加以指责。在这样的环境中，变革是不容易成功的。

## 6、不能看到胜利

第六步，要想办法让组织不断看到胜利果实。科特列举了三个案例：在第一种情况，因为见到变革取得效果，变成很快被反成了，在第二种情况中，14个月的时候长期没有变成效果，一年之后没了，因为。在第三种情况，在14个月和26个月见到了短期成果，所以，变革型持续取得成功。

![](img/17b87b436c90c966960c6a3171fa356b_88_1.png)

关于第六个点，我要特别强调一下，领导者要看到短常变的先机。变革需要变革的本，变革就有可能陷入一种惰性的轨道，如果变革如果够有任务上有一定投入的毅力，比如开始变革，就有机会有机会看到第一个轨。
