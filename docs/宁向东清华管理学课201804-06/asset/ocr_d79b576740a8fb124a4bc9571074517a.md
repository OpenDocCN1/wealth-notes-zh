# ## 1.隐蔽信息与隐蔽行动

前几天，我的一位朋友找律师咨询。他不太懂法律，这件事对他非常紧迫，他希望律师能够尽全力帮他解决，但又怕律师敷衍他。比如，表面上说说，也显得很尽力，但实际上不投入。为此，我的这位朋友就提出一个报酬的协议。他先支付一笔报酬，基本上算是一个定金，之后当案子开始时，只支付短期费用算约定好的报酬，再等案子部分结案时，再算一份报酬。最后，当案子尘埃落定时，再根据最终的结果，支付一个分成的报酬。

这种报酬的支付形式，其实比较多见。在很多难以观察努力的情况下，都会被采用。比如，员工的报销、管理骨干的报酬，一般都采用类似的报酬形式。这种报酬形式，兼顾了当事长短期的努力和长短期的业绩，并能将短期激励的业绩分期支付报酬，有一种有效抑制激进行动和短期行为的报酬方式。

下周，我们会更加详细地讲到股权激励。在很多企业，要搞搞经理经营股、骨干员工持股。为什么要搞经理经营股、骨干员工，甚至全体员工股权激励？本质上，是要把前期相关人员的隐蔽信息和隐蔽行动，解决当前和过去所讲的利益不一致的问题，信息不对称问题，以及由此而带来的监督困难问题。

就以经理人来说，他们的长期报酬都是有限的，这就使得他们的自身利益和股东的利益高度不一致。经理人的主要，是他们在这几年业绩一定能够达到标准，然后只拿到比较稳定的工资和奖金。但是，股东要的，可不仅仅是经理任时间段的业绩，他们不仅要当下的业绩，而且还希望业绩能够一直升下去。

比如说企业有广告宣传，这个钱花多、花多少，一般没有一个标准。如果这个钱花得好，企业对企业的形象一定会产生长期而显著显现，一定会对企业的未来收益产生长期而正面的影响。再比如，我们前面讲过的，经理人并不想花费更多的时间和精力去长期布局，不会花太多的时间思考未来多年后，公司可能会有什么有潜力的新增长点，而只去挖掘那些短期容易实现的。经理人任时期是有限的，他怎么愿意花时间去做长期的规划与建设？

还有，我前面有一个作业题，是关于如何仅考核员工以报告一个指标。经理人会怎么做呢？很明显，这个指标的分子利润，分母是资产总份额。在绝大部分情况下，股东所期望的是分子不变的情况下，怎么让这个数值变大。但是如果是在考核中把指标设计得让关注这个分子的人，就可能会通过分母变小，把分子调高，进而使得整个指标达到要求。而这样的情况的结果，则很有可能会影响企业未来的竞争力。

总之，经理人由于在一线，信息非常充分，而股东远离一线，对于具体情况较少信息，加上监督非常困难，所以，只能依据激励制上一些监管。这个文件就提供做短期和长期报酬的结构。也就是说，经理人的报酬不仅有短期的报酬，还有长期的报酬。

# ## 2.报酬是一种牵引的手段

这种设计的基本逻辑是这样的。每个经理人的努力，都会转化为业绩。我们经理人的努力分为两种，目标是对于短期业绩而付出的努力，我们称之为“短期努力”，目标是长期业绩的努力，我们称之为“长期努力”。经理人的努力，都是隐形的行动，我们可以从结果去观察，可是观察的成本太高，无法实施。但是，在经理人的内心，他知道自己是有一个管理活动，从短期对于企业的目标实现，还是对于长期业绩帮助，于是，股东不知道经理人是怎么想的，就只能往报酬设计做文章，希望由此调动他的正向能力。

# ## 3.把球踢给经理人

当股东把报酬结构说清楚，特别是把业绩目标利报酬水平之间的关联说清楚之后，经理人就把球怎么交了。我们前面的课程讲了业绩分解，讲了平衡计分卡，讲了杠杆管理，讲了指标体系。其实，对股东来说，与确定这些关联同样重要的，还是去理解好这些业绩目标里面，哪些是代表的长期利益，哪些是代表的短期利益。你要支付的报酬结构，就体现长期利益和短期业绩之间的关系。

当你把这个大的游戏规则讲清楚了之后，球就被踢到经理人手里了。有一个原则，就是“谁踢球，谁负责”。我们说过了当球员是死不能碰的，比如下属没有球，你不能输。死不能把球踢进，谁就负责；谁有责任，谁就该负责。股东设好了激励的结构，其实就是踢着把球发出去了，这时候，着急的是经理人了。

经理人到球后，头脑中就不能开地盘旋。不是哪一天要盘算，只要在任期内面，每天都要盘算。盘算什么呢？就是考虑自己每一个工作，究竟是不断地是给股东交了企业的业绩目标。哪些努力是为了长期而服务的，哪些努力是为了企业较长或长期服务的。经理人努力这些激励，股东其实毫不需要知道的。甚至可以说，很多时候知道也无从知道。在这种情况下，会考虑不知道了。因为有的报酬结构那个但架的激励结构钱，经理人一定会按照这个逻辑想钱，思考问题，付出判断。

在这个时刻，什么隐藏行动之类的事，股东不需要太操心。这就有点像如来佛和孙悟空。孙悟空的事再大，只是如来佛的小心舒大。孙悟空翻不出如来佛的手心。也许在这个时刻，股东如果说这个能力。怎么办呢在某些大公司，特别是上市公司，设计经理人报酬这件事，是由股东的顾问团、董事会的新颖部或资本方委的，由人力资源顾问负责去做的。在特定方案的设计上，可以专门的人力资源顾问机构来辅助设计。也就是说，必要的话，动用外援。
