
# 232讲：信仰控制 | 塑造崇高的理念

公司赚钱，我们首先希望帮助更多的人恢复健康。美敦力的这个理念，是1949年由它的创始人制订的，至今没有改动一个字。它的创始人贝肯先生强调，公司首先要让病人的价值最大化，然后，很自然地就有了股东利益的最大化。

美敦力的每一位新员工加入时，他们都会看到介绍公司创始人的一段录像，会收到一个小牌牌，上面是一位因为恢复健康而站立起来的人像，以及公司信仰体系里面的一句话。公司的总裁会对员工强调他们工作的意义，这家公司存在的意义。总裁最常叮嘱他们的话是：在你遇到困难的时候，你应该记得你正是在实现一个崇高的理念。

# 233讲：边界控制 | 员工行为守则的价值

你好，欢迎回到《宁向东的清华管理学课》。

今天我们讨论控制手段中，非常重要的一部分内容，叫做边界控制。昨天我们讲了信息体系建设，但你必须认识到，靠价值观、靠信仰来约束一个组织，还是远远不够的，所以还必须要给管理层、无论是基层员工，还是公司的最高领导者一个行动边界的控制，就是你可以干什么，不可以干什么。

## 1. 大型公司的边界控制

下面有三家资讯公司的“职业行为操守”，英文叫做 code of conduct。这份行为操守已经跟随我将近 20 年了，我征集了其中大型跨国公司的，可以活很多年而不出大事，因为这些行为操守已经把很多对公司有风险的员工行为限制在一个边界里面了。

![](img/17b87b436c90c966960c6a3171fa356b_50_0.png)

你也许会讲，很多西方大公司也不衰落了吗？比如诺基亚，比如柯达。但你问问任何人，他们死在公司的战略上，死在公司的产品竞争力上，但是，很少公司是因为犯了对员工的行为控制不足而从内部瓦解的。

有一句话，叫做“吃亏上当就当一回”，用在西方大公司员工身上特别合适。生意没有不出事的。林子大了，形形色色，人一新了。如果强调这些行为，从目标去衡量，工作，也在某一个时期，要出来的结果是很像指标都裁了，市场扩张的速度也很快。但是，留下了很多风险，有些风险会让企业倾家荡产。

坦率地说，中国还是市场经济中的后来者，中国工业还没有成熟的欧洲家谋家样的底子。企业，在我清清的 EMA 课上给那些企业家们讲过这个边界控制，原来那么多企业家不太在意。道理特别简单，靠打擦边球一路走过来。在我们的某些地方、某些领域，中国人讲究边法，本来违法成本低，一变造，就几乎没有犯规则，所以，你给他进行法控制，边界控制，他都听不进去。

这些年的情况稍微好一点。原因有很多方面，第一是我们的市场经济意识还在加强，大环境在变化；第二，是现在的企业家，素质比新一代的企业家要提高很多，他们的眼界更开阔，能够认识到这个方面的重要性；第三，也是最重要的一个方面，就是中国企业的主营业务大大打开，很多人的生意早已做到了国外去，他们遇着的事情告诉我们，边界控制非常重要。没有一个好的边界意识，真的是风险很大。

新一代的中国企业家有一部分来自于外国名门大公司的，在海外的公司经历让他们养成了比较好的意识习惯，他们知道深浅；还有些企业，自己虽然没有遭受到事情，但是自己看了很多国外企业被处罚的情况，让他们非常震惊，所以，他们在心里有敬畏。很多事，有敬畏就好办。

有这样的规定，就是可以接受的礼品上线是多少，比如 15 美元，如果你没有办法搞清楚是不是超标，一定要向你的上司汇报。

每个成熟的西方公司，都会有这样一套行为操守。有趣的是，这套行为操守绝对不会只是你入职的时候发一份给你，然后就再也不闻不问了。各个公司的情况不一样，有的公司是每半年，有的公司是每一年，会抽出一个专门时间，也许是半天，也许是一天，业务不做，专门重新学习这个行为操守。当然，这个行为操守也会根据实际情况历时修订，不断加入新情况，新的规定。

大家学完之后，要同公司签订学习之后的承诺。表明你过了半年，或一年，又强化了一遍公司的做事规矩。你签了字，意味着你接受了这个规矩，你以后做事，就要按照这个规矩来做了。也许你觉得这是形式主义，但如果你在一个法律至上的国家工作过，生活过，你就知道这个东西的厉害了。

其实，美国是一个标榜自由的国家，但你如果在那里生活过，它的很多东西实际上是不自由的。中国与之相比，其实在某些方面自由度太多了。比如，你现在约了一个出租车，你很可能就走掉了。在中国，走掉了无所谓。但在美国，这个东西就有可能进入到你的个人信用记录。比如闯红灯，交通上的罚款，肯定是要进这个记录的，而这个会影响你的信用交易行为。比如你去买保险，申请信用卡，如果留下这些记录，一定最后都会惩罚到你身上。你因为操守的问题被开除，你的下一份工作一定难找。

## 3. 行为操守要“反着写”

你听了我的课，也许开始要制定自己公司的行为操守了。你记得关键的一条是“要反着写”，限制人的行为边界，不要写“他应该干什么”，而是应该写“他不应该干什么”。“要”是向外发放的，而“不要”是向内收敛的。只有明确不要，才能实现边界控制的目的。

我曾经研究过清华大学的学生守则，我觉得写得很不好，都是什么要认真学习，要努力学习之类的话，基本全是提倡的“正确的废话”。学生守则就应该是，上课不能吃东西，上课不能说话，上课不能看手机，上课不能开电脑上，网，看与课程不相关的东西，只有这样，才能真正把一个人的行动边界控制住。

## 课后思考

今天的课后，请看你自己所在的组织有行为操守吗？如果没有，那又是为什么？

## 划重点

- 必须要给所有的员工，无论是基层员工，还是公司的最高领导者一个行动边界的控制，就是你可以干什么，不可以干什么。
- 员工守则“要反着写”，限制人的行为边界，不要写“他应该干什么”，而是应该写“他不应该干什么”。

# 234讲：指标控制 | 为什么要定红线

你好，欢迎回到《宁向东的清华管理课》。

在西蒙斯教授四种控制杠杆的体系中，指标控制是非常重要的一个部分。请注意，我不仅仅是非常重视，而且是非常关注，因为信号控制和边界控制，都是希望你做出正确的动作，无论人是主动的，还是被动的，都是激发人去去做动作，而动作的结果如何，这方面是检验动作和过程最终效果、最可说性的东西。

## 1. 指标控制的前提

动作的结果，体现为业绩指标，实时的业绩指标，就像我在前面讲调节模型时的温度控制，第一要即时，第二要准确，即时效性和准确性出了问题，水温无论如何是调不好的。问题是在前面讲会计体系时，很认真，也都有数据，我们统计出了经营结果，但分析都有问题，数据的最难的情况，就是经营活动的结果，是一个月之后才能公布，这就让管理者没有办法及时对市场情况做出反应，没有办法依赖数据进行有效的指挥。

也正是因为这个缘故，最近二十年里，管理控制的信息化一直是企业界非常关注的，很多企业进入信息，引进 SAP，包括过去很流行的 Oracle 系统，还有国内用友和软件等财务软件系统，都是为了加快指标和重要财务控制时间，提高针对这项决策的效率。但是，做出了这些投入，一定能做到结果吗？未必。为什么呢？因为下属会束手无策。

下属束手无策，就会说管理层在最高级的指挥台上，看到的信息完全是不可靠甚至是假的，这些管理判断者不可接受的情况，因此，数据传到司令部，影响决策，指挥层根据数据指挥打大仗，不可能仅仅是靠错误。管理控制系统建设中，不仅要强调选择重要的、核心的指标，比如战略地和平衡记分卡系统就是通过提高决策决策决策，我们的最佳目标的目的。同时，还要保证通过数据系统上反映出来的这些指标的数据，是真实的、准确的。所以，有建设有效的指标控制体系，一个前提性的任务，就是保证数据的真实性。

## 2. 让组织有红线意识

那么，怎么才能形成指标都是真实的呢？核心就是靠对问题的正面处理，甚至让组织有红线意识。什么叫做红线？就是企业里绝对不可做的规定，犯了这条规定，不管你出不出现在问题，在这些单位，你不仅仅会当时的，而且会面临人的一生。

你现在花点时间想想，你现在的组织里面有什么红线？你有很强红线意识吗？我做过一点调查，对于当下的中国企业，很多从业者是没有的，这是事实，我们国家在体面上还属于发展的早期阶段，这个国家需要完善的东西还太多。

最近，我的朋友那里面讨论的一个很有趣的话题，就是网络课程的盗版，甚至线下课程里很多人录音，然后，拿到课程上去卖。

199 块钱一年的专栏课，很贵吗？其实，不算贵，但很多人就是想要去免费，甚至不付费的盗版，甚至我认识的有一些收人民币水平不错的学生，也在想，淘宝有卖盗版，要不要去承担连带责任。我觉得应该没有，但是，我还是给一个忠告的是管理者，都是出现了问题，朋友里有个人说他们部门跟盗版里卖盗版，我觉得有人卖盗版不配在这条线上，盗版你都有点抬举了。一个做付费专栏，既然管理者还游离在盗版，一点红线意识都没有，这就是我们目前的现状。

2001 年我在哈佛商学院里受到的最大震撼之一，就是说每一个有意义的别人研究完成的时候，都会说明我的哪跟别人不同在哪里，都是说明哪跟别人不同的研究。比如卡普兰教授的平衡计分卡图示，很多老师自己的 PPT 里面，都会专门命名引用卡普兰的书，多少页，用一个圆圈画引号，就是版权的意思，表示：这里引用的内容，是当时感受到的就是差距。在尊重知识产权的环境下，大不愿意知道大家不分享出来，在咱们知识版权的环境下，大家只能把一些简单的东西拿出来，核心的东西，花了大力气创造出来的东西，不会拿出来。

我们现在经常抱怨创新不足，其实，早期的创新现在是不可能从无到有完全获得足够的收益，就没办法去线去继续进行创新，大家就会知道破坏。但是，我们有这样的红线意识吗？显然没有。越过了红线会受到惩罚吗？也不会。这就是当下的现状。

大环境如此，小环境组织也差不多。所以说，在你中间企业，十年前八年前也没有足够多的红线，没有必要的红线去，踩了红线也有事。其实，我在约上门工作，一件线所到管的事情，就是有的学生，或者希望，多少人是 65 到 95 年出生的，我希望能稍微影响他们，等你到了像我这个年纪，你的企业就应该有红线的企业经营状态，我今天讲的这些东西也是企业经营状态的状态。所以，今天的课，是为了将来准备的。

## 3. 红线在哪里？

你也已经急不可耐了。卖了这么多亏字，红线到底在哪里？从基础的行为控制来说，红线往往先是“签证制”，也就是说，当外出做业务，花了多少钱，怎么花的，你要简单些，财务要按照规矩来记账，不能搞简单就要一为按照你的招牌，你招待了谁，几个人，用什么方式招待的，什么时间，所有这些内容在报销凭证上必须要清楚。

在控制规范的企业里，绝不出现报几个报销凭证，上级领导一签字就报销的情况。一个员工，你代表企业去有做事，可能会给企业带来收益的东西去做事情，你企业带来利益。所以，必须是要知道如何控制住，控制或指报，就是靠这些凭证来做，通过些凭证的处理来看着事件不是符合公司的要求，是不是风险可控的范围内里面。

在大型公司里面，每年都会例行性检查飞行检查，总部的合规检查人员、审计控制人员，或者其它管理部门的检查人员，会不断地在各个部门去巡查，试着发现体现在账面上的东西和记录实际发生的行动所产生的凭证是否不一样。只有可行性，才能完全部到要求的数据具有可靠性，总部决策者可以基于这些数据制定战略，指挥战斗。

前几天清华大学，我和一位外所的朋友聊天，请他去总览人员和财务。朋友看财务人员一看就知道，就是知道触动了红线，比如，你报销的出租车费，对的费用在，比如，你举报的火车票，叫叫难费的费用是不对的。他一个电话打过去，就知道你人喝咖啡，而不是一间房。总之，那些人特别有经验，一般发数据就可以，就查开了，看不到身份是不是有开，所有员工知道公司的红线不是站在墙上的口号，那是真的制度，是真的红线。碰了红线，要弄死很大事情，于是，大家都不敢去开玩笑，大老板都不开玩笑，管理控制体系的信，就是真的，信息是真实的，公司花力气搞的指标才有用武之地，卡雷的那些形式技术性东西，公司投入人力去研究，才真的会改变管理，真的有好处。

除了账证相符，财务上还有账实相符，就是账目上记载的，和实际上发生的，就不是一致，比如，你在账目上反映出来卖出去了，但是，仓库，记了收入。东实货，东西还在仓库里面，就是为了业绩。你就跟别人做配合，为了骗老板。等到出了问题，公司就会说，所以，销售人员一直保持，然后和账目一致，真相就会大白。

除了账证相符、账实相符，还有一个原则，就是做到账账相符，就是不同的帐相关的账相互符合。也就是说，从实物、行动、数据最底层的各方各方面、各条线所反映的内容高度一致，指标控制系统才能成立，这是企业管理进行监控逻辑进行立。这是专业管理基础，进行控制的关键，请无论你怎么理解。

## 划重点

- 最基本的红线就是账证相符、账实相符、账账相符。

# 235讲：交互控制 | 压力管理下的助推

你好，欢迎回到《宁向东的清华管理学课》。

今天我们讲交互控制。所谓交互控制，就是当指标控制出了问题情景，交互控制该怎么办。首先我举个例子，交互控制背后的内容特别多，很多东西，你的经验如果不够，听起来会很吃力。所以，我今天就只讲两个问题：

1. 面对高业绩，一定要及时怀疑；
2. 就是要给予下属压力，一定要懂得压力管理的逻辑。

## 1. 高压力与业绩造假

首先，我们讨论及时产生怀疑的问题。

我们从陕西联通的案例说起。去年大约这个时候，陕西联通公司爆出了一个大大的舞弊案件，媒体造假数额惊人，这个造假令人震惊的一个特点，是作案时间长，作案规模大，而且是以非常正当的旗号。

媒体报道，2011 年，陕西联通换了一把手，这位新上任校长三五年提出了一个大发展、两三年上台阶、三年进全国十陕西联通的目标。稍微有点常识的人，都可以看得出来，这就是在鼓励、不管实际需求的去跃进。在三大运营商竞争越来激烈，新的通信平台不断蚕食运营商利润的另一个地方打下了超异常的业绩，领导者一定要在中心打个问号：你凭什么？

其实，后来的调查显示，陕西联通的造假案件的后来并不新鲜，因为要翻案，所以，就定下了一个不太实际的副目标，而现实的情况不允许，达不到这个高指标。于是，每个月，每个季度不能完成计划的指标缺口，就成了造假的目标。陕西联通通过各种手段和业绩按照了造假标准通过各种手段让业绩完成，对应绩效数进行账面上的处理，由此形成大量虚假收入、虚拟利润和虚拟资产。

坦率地，如果确定的指标是到位的，这些问题肯定不会发生。如果完成的总部都听到过今天的事，知道对于异常业绩的第一反应是去相信相信，首先要先在那里打一问号，然后拿出相关人员进行研究调查，就不发现这些作假行为。最后，东窗事发，败坏了联通的名声。

其实，派出相关部门的人员进行调查，不是什么问题，而是，如果业务情况属实，要可以及时掌握市场的新动向，推介经验；要么可以及时发现问题，将造假扼杀在萌芽中，至少不会发展那么大。 对联通舞弊案的复杂来看，联通内部加上回避，而其问题的本质则是公司精力太过，管理者不愿意接受业绩成长是舞弊结果，而选择了一种和而不同的态度。 这意味着，联通公司的控制系统里面，不仅交互控制的体系完全缺失，而且信和控制体系也完全扭曲或劣缺失。

好，我们不再纠结于联通这个案例，接下来，我们把这个话题从案例出来再延伸一下。 高压力，因为，你的战略目标、计划管理的能力不强，预算体系无法建立在非常可信的基础上，这个时候，它们会采用某种目标性管理方式，用业绩一种高级的管理模式，这种做表面功夫管理，希望是高指标来压住团队的所有管理。

我们在前面的课，曾经提到过这样的管理方式，我的观念是不鼓励这种管理逻辑的。但你可能，现在现实中有很多企业就是这么做的。 要么，我出稳定设定一个不切实际的业绩目标。比如，台湾非常有名的台塑集团，我前面提到过的创始人王永庆，它的发家就是靠一种"永不实际"的高压政策取得的。
