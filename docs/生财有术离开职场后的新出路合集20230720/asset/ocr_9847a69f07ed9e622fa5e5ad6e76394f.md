# 饮食篇

![](bbox=[0.14, 0.36, 0.28, 0.5])

+   **理性选购**
不要贪便宜买特别便宜或临期的猫粮，根据猫咪具体情况选择有品牌保障且合适它的猫粮！

![](bbox=[0.14, 0.51, 0.33, 0.63])

+   **天天准备食罐**
骗水好东西，但是容易导致猫咪挑食，一些挑食又倔强的小猫咪真的可能会把自己饿死

![](bbox=[0.14, 0.64, 0.33, 0.76])

+   **换粮换期**
换粮需要周期，3~6月1换，千万不要1礼拜快1下，1个月快1下

![](bbox=[0.14, 0.77, 0.33, 0.92])

+   **益生菌当“饭”吃**
猫咪健康状态下无需喂食益生菌，普通、软便、猫咪生病、做完手术时等情况按医嘱喂食~
