# 一、前言

实话从过去开始我都想写一写这些年的创业总结回顾，不过那个时候创业才**9年**，我想等到创业**10年**的时候再来总结一下我那些年关于创业的血泪史。一方面是给自己**10年**创业小结复盘一下，另一方面也可以给大家一些参考借鉴。

到今年的**7月1日**我算正式从返利网离职创业**10年**了，原计划这篇文章应该是在**6月底**写完，然后准备**7月1日**那天发出来的。可是那段时间心情烦躁，具体是什么事情这里也就不说了，反正就是无法安下心来静静的写点东西。

于是“拖”，然后就拖到了现在，一转眼这就**9月**了，如果再不抽时间写出来，估计这篇文章很大概率会流产，因为这个选题在我的日程表里一而再、再而三被延期。

前段时间我看到曹大(**cao2**)写的一篇关于创业的**10万+**爆文，感慨良多，估计不少朋友都看过。

曹大在文章的开头写到"十年前，我一直在鼓动别人创业。5年前，我会注意区分什么人适合创业，什么人不适合。而现在，基本上，我会试图劝退每个想要创业的人。为什么？因为时代的机会窗口，越来越小，而创业的机会成本，越来越高。没看过的建议看看曹大的"还在做创业梦？醒醒！"这篇文章。"
