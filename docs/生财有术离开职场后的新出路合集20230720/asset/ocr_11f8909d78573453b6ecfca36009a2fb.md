+   3、重大决策后，自身的资源会被激活，要关注它的流向和产出；

# 三、转型中，当想做一款产品时，8年产品人的三个建议

+   1、定位，自己擅长什么和热爱什么，穷举做准备；

+   2、算账，测算清楚每个方案的财务模型，这是赚到钱的前提；

+   3、验证，做最小可行性产品（MVP），验证业务可行性，测试简易的业务流程；

+   4、产品设计过程中，我自己踩的坑；
