# 第四部分：产业生态的打造

项目发展到 2020 年 5 月，我们聚集了全国 70 万仪器使用方和数百家仪器设备生产商。基于此，我们开始在全国每个省份组建运营中心，加强我们的线下活动能力和线上在线课程的销售能力。同时由于科学仪器具有普适性，广泛应用在环境监测，食品安全，生物制药，医学检验等各个领域，从今年 3 月份开始，EWG1990 开始独立孵化环境学习网，食品学习网，生物学习网，制药学习网等垂直领域产业学习平台。

至此，为了将 EWG1990 仪器学习网继续带入科学仪器产业深水区，我们在 5 月份正式上线了科学仪器行业采购平台【仪学优选】，帮助科学仪器厂家更好的对接全国各地实验室用户，用户实验室也能更方便快捷在平台上采购实验室耗材。上线 2 个月，目前 100 家全国供应商已入驻。就这样，【仪学优选】成为 EWG1990 仪器学习网进入科学仪器产业贸易和供应链环节中的重要一环节。也让仪器学习网的产业互联网走向更深入的一步。在这里，也欢迎有 B2B 电商经验的人员加入合伙人，这个板块目前单独独立孵化，希望能用 1-3 年时间做成行业优秀的供应链采购平台。这条产业互联网之路，上市公司有【国联股份】，【找钢网】等，我相信，EWG1990 将会成为环境，食品，生物，制药，医学板块等国家科学技术行业高净值的产业互联网平台。

总结：

1 关于行业生态的构建从个人自媒体，到产业互联网平台。能否复制。我想是可以复制的，步骤如下：

+   - 第一步：分析行业的上中下游。研究聚集哪一方，另一方就会来找我投放广告或者合作。

+   - 第二步：聚集行业的某一端，通过内容，会议，或其他途径，在时间沉淀的前提下，做出影响力。

+   - 第三步：此处产业的另一端会开始关注并加入圈子。

+   - 第四步：搭建两端交易的供应链平台。
