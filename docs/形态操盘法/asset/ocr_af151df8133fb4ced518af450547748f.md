恆不滅的金剛關卡，市場回升就再也不能夠創新高，這個市場將走入死空頭，遲早有一天會跌到零點，加權指數會變成0.000 X。因為所有的關卡都無法再克服，新的關卡又不斷產生，舊關卡在新關卡之上，新關卡又在現在的股價指數之上，股價永無翻身之日，市場就死掉了！

由此可知，壓力線關卡的存在「並非永恆」，結論就是這麼簡單！

# 凡所有相，皆非永恆

看股價線路圖時，面對壓力線不妨思考以下重點，以便了解將來的漲勢會遇到什麼樣的阻力。

+   （1）各條壓力線在技術分析上所代表的力量強弱。例如：成交量愈大，套牢金額愈大，表示這條壓力線勝出（壓力線的阻力比較強）。

+   （2）用籌碼分析去尋找各個壓力區中，那一塊被套牢的大戶人口最多，愈多大戶被套牢，暫時不管金額，大戶都可能在那個點位倒貨，於是形成壓力。

+   （3）當中這波上漲的力量有多強？依據前面兩條思考路徑，建議可以用成交量當成是衡量力道強弱的參數。

+   （4）這波反彈力道的強弱，也可以用以「季節性」來判斷。例如，秋天以後所產生的反彈，會比較強勁。
