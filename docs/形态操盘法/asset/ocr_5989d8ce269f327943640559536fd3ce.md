# 趨勢線的心法

通常方向只要一條線就能被指引出來，如果有兩條線，就跟火車一樣，可以發展成軌道線。

我們都希望股價在軌道線上行駛一段時間，要不然它就繼續平穩地繼續向前行駛，最好突破現在的上升趨勢，升級到另一個更新穎的上升趨勢。從一條趨勢線發展到兩條軌道線，在技術上是一種進化，可是在心理上比較難以配合。我並不把軌道線看成是一種進步，我認為它是一種變形，所以我把兩條軌道線看成是型態學中「箱型整理」的靈感來源。

# 通道操作法沒有比較厲害

有人依照兩條軌道線發展出所謂的「通道操作法」，其實，該操作法的觀念跟軌道線差不多，上面一條是壓力線，下面一條是支撐線，在通道中行進的股價是安全的，摔破通道後就會換一個新通道，或者就此下跌說再見。

一般而言，通道的用處不大，因為通道的原始觀念是來自於趨勢線，而且把趨勢線變得較為複雜，但是功能沒有加強！它的功能並沒有因為趨勢線從一條變兩條而變得更強悍，頂多只是讓你曉得：當通道的壓力線被往上突破之後，它就會變一個新通道了。這是很普通的技術分析，談不上有太大的技術優點。
