# 尖頭反轉
現形記

面對股價走勢，學過型態學的人會用兩種方式對待股價線路圖。一種是之前談過的，把股價走勢想像成人體，用部位稱呼取名子，才會有所謂的「頭」、「肩膀」、「頸部」、「腰部」、「膝蓋」等稱呼；另一種方法，則是用「波浪」的觀念看待。

兩種方式各有利弊，用人體觀點看待股價，感覺比較親切；用波浪看待股價，感覺比較生硬，但因為在數波浪時，是用123456789等阿拉伯數字稱呼上漲或下跌的股價，所以從某個角度來講，直接用數字編號反而是種方便，這一派的想法，後來誕生著名的「艾略特波浪理論」。

那麼，波浪理論也算是一種型態學囉？我認為是的，因為波浪本身也是一種形狀。
