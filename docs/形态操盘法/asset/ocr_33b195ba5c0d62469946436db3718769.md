# 這個底部的技術面很簡單

911恐怖事件，造成了當年下跌段的加速趕底。過程中，很快就出現窒息量（詳見圖39），如9月13日的成交量竟然只有178億元，9月19日263億元，9月21日131億元，到了橫盤做小底部時（當然，我們也是事後才確定那個橫盤是底部，當時只知道它在走橫的方向，無法完全確定它不會再往下跌），10月2日有237億元，10月3日有295億元，10月8日有268億元……這麼多的日子裡，同樣都只有稀少的成交量，而且指數位置又在相對低檔的3400~4000點左右，不論以現在的知識或是當時的知識來看，都可以叫窒息量，所以，判斷3411是底部「在技術上並不是一件太困難的事情」——這是我們得到的一個反省的結論。

既然不是太困難，為什麼有那麼多人在3411那個底部沒有大量買進？還有一點就是，很多人都知道我在3411做了一個錯誤決定，就是我認為指數可能會跌到2000多點，所以我又重新放空，結果遭遇我進股市以來重大的損失，也成為日後最重要的操作經驗之一。有段時間，我幾乎三天兩頭就會想到那次失敗的經驗，警惕自己不要再犯。
