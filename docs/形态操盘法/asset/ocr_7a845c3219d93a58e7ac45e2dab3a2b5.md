# 收斂三角形
整理

收斂三角形是股價型態學的一種整理型態，在Google輸入「收斂三角」等關鍵字，就有許許多多的解釋。我掃描了一下，發現這些資料在我以前學技術分析時是沒有的。

我那個年代網路並不發達，大概就是一些大學BBS站，上網還得靠撥接，網上知識更沒有像現在那樣普及到幾乎免費的程度。不過我倒很懷念當年，因為知識取得不易，反而會珍惜。現在利用Google大神隨手一查，都有很多豐富的資料，反而模糊了焦點。智慧模糊成了知識，又把資訊魚目混珠，偽裝成了知識 —— 這種情況對新一代的學生來講，是不太好的。

網路上看到收斂三角形的解釋，大致來看不能說有什麼大錯，因為那都是歷年操盤者實戰經驗匯集而成的文字整理。每位操盤手都有權利把自己在實戰中的「感想」分享出來，於是就看到很多資料是在實戰過後檢討寫成的。可是其中有個問題：這些實戰經驗很難突破「一個人的私人經驗」，如果私人經驗沒辦法擴大到所有投資人全體，問題就大了。
