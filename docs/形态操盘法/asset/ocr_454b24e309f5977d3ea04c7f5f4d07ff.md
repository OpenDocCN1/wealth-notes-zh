# 壓力線的
畫法與運用

有人問：「頭部是怎麼形成的？」

由於股市的潛在動能逐漸衰竭，沒有多餘的力氣繼續往上攻，剩下一些殘餘力氣。而這點殘餘的力氣，只能夠提供股價停留在原地，不要跌下來就好，至於進一步向上漲價，就沒有多餘的能耐。

當這種動能逐漸衰退的現象還沒有被人發覺，市場仍然在追買，就是俗稱的「追高」。那時候大家不曉得這裡是高點，於是買歸買，買完後股價卻無法進一步上攻，只好在一個區塊裡打轉，該區塊就叫「震盪區域」，有人取名為「震盪箱」，意思是股價困在這個箱子裡裹足不前。時間久了以後，就會看到股價漸漸往右邊拖，形成團塊，未來假設真的力道接不上而掉下來，這個團塊即稱為「頭」。
