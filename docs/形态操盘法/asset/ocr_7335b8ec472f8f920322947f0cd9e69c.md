# 方法1

股價在三角收斂整理的時候，就技術分析而言，不論它的量是逐漸變小或是持續平穩（這種情況非常罕見），都說明一件事：轉折即將發生！請準備好新資金，以便在突破時買進，或在下跌的時候放空。

# 方法2

舊有的部位開始震盪時，先行賣出一趟，但有一個困難點，就是想抓到震盪時間的長短並非簡單之事，所以賣掉的貨要有心理準備，也許馬上就得買回來。

# 方法3

收斂整理的時候，不管手上部位有多少，都可以繼續從事基本面的觀察、分析消息及過濾資訊。若有什麼具體成果，也就是如果真的得到了某種啟示，能夠先預感整理完畢後會上漲或下跌，那麼，就把這個觀念「暫時」抱在心裡面，不要太熱情，只要有適當的暖度就夠了，然後一邊持有部位（或是丟掉部位），一邊繼續等待盤勢繼續發展之後的轉折。
