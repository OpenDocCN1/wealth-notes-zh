# 故事 2 1995年的底部

1995年的底部跟2008年金融海嘯的底部，同樣都是「收斂三角形」。有了這一層的因緣，2008年我就曾經「想到」這個正在進行的底部，可能會跟1995年那次的底部（詳見圖38）相同。

這個思想源由有個很重要的理論背景：如果時間夠長，大三角收斂型的底部是較優秀的整理型態，比長方型的整理底部要好很多。因為收斂三角形是採取漸進的洗盤方式，慢慢把震幅縮小，股價跌得不厲害，沒有破底，是一種很溫和的方式。而且，收斂三角形必定會走到非常狹幅整理的那一步才量縮，底部訊號更明顯。如果是方型的整理箱，震盪幅度可能過於劇烈，我們還要去找窪息量在哪裡，比較不方便。反觀收斂三角形的窪息量通常會發生在收斂的尾端，找起來方便許多。
