# 盾角2 找出支撐壓力區

傳統趨勢線的畫法是繪製一條或兩條：如果是上升，會在那一系列的K線低點附近大致連成一條直線，稱為支撐線；此外，這一個行進中的日K線隊伍，把高點連接起來，就成為壓力線。

這兩條線（支撐線跟壓力線），若以漲勢為例，都是往上的方向，兩者之間就是日K線 ── 我們也希望日K線能照著這個方向繼續往上攻（所以說，有時候技術分析的圖形繪製會帶著某種預測功能）。至於市場未來能不能真的沿著這兩條上升趨勢線的方向進行？很難知道（如果沒有做其他精密深入的分析，怎會知道？）或者根本沒人知道（知道的人也很難就是你）。

因此，我們就定出兩條基本規則：

+   （1）如果跌破下面那條上升趨勢線（支撐線），就賣出多單（詳見圖30）。

+   （2）如果價格突破上面那條壓力線，表示上攻趨勢進入另個新階段，可以考慮加碼買進（詳見圖31）。

至於這兩條上升趨勢線（壓力線跟支撐線）的中間路徑，就是俗稱的「軌道」。
