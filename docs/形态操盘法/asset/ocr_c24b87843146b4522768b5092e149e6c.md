# 1995 年不平靜

1995年（民國84年），台灣陷在一場史無前例的選舉風暴，因為當年3月要舉行中華民國第一屆民選總統的選舉，國民黨的代表是李登輝跟連戰，民進黨的代表是彭明敏跟謝長廷。由於是全民直選，選舉規模空前龐大，戰火炒得很熱。

或許有人已經忘掉那時候的政治氣氛非常嚴峻……1994年4月，李登輝接見日本作家司馬遼太郎，談到「國民黨是一種外來政權」還不打緊，言談間，李登輝以時任中華民國總統之尊，對日本充分表達孺慕之情，甚至聲稱「日本是他的祖國」。這番言論，不但搞得台灣島內許多人不以為然，對岸的中國共產黨更是看不過去，於是種下了因果。

之後，為了展現台灣是獨立自強且充分具有主權的國家，李登輝展開一連串的外交活動，以私人身份到美國康乃爾大學發表演講，講題是「民之所欲，長在我心」。大體說來，那兩年李登輝的思想言論，因為他給自己定的「多重身分」而呈現空前的混亂。他既是日本人，又是中華民國的總統，又是皇民，又是中國人，又是國民黨，又是民進黨支持者，
