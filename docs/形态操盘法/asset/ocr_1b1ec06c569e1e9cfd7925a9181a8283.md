# 5-4
3 2001年的
小長方形底部

2001年的底部是從9月中旬到10月上旬，時間並沒有很長，從頭到尾大慨是13天，形成了一個很小的長方型震盪整理箱，最低點是2001年9月26日的低點3411.68，這是一個非常有名的底部。

當年發生了什麼事，導致指數被打得這麼低？主要原因是美國網路股泡沫的破裂，帶動整個市場對電子科技股的疑慮。這個風暴老早從2000年就引發，真正看到會計報表上有虧損則是在2001年，所以2001年的跌勢從4月開始，一直跌到9月底。差不多是在八、九月的時侯，進入末跌段，接著就發生舉世聞名的「911恐怖攻擊事件」。

寫這篇文章時，距離911已經16年，但很多人，尤其是年輕投資人，其實不太清楚這段往事了。那晚我在7-11買東西，聽到廣播說是美國發生了恐怖攻擊事件，直覺很驚訝，又有一點覺得那是「意料之中」，為什麼？因為那年我本來就看空，而且也作空滿久的，對於一個滿手空單的操作者
