# 右肩變形之後
仍然是右肩

主力大戶如果有很多貨要出，而且也準備在這個整理段出貨的話，原則上會分批出，也就是左肩、中間的頭，以及右肩，都能看到出貨的影子。但是，因為大部分人還存著一點觀望心態，希望這個盤勢能不能多拉高一點，加上大部分大戶倉庫裡的股票還真的不少，基本上不可能把全部股票給出光，所以他們有選擇的權利，選擇在「最後的那個關鍵點」出最多的貨──以上是右肩爆量出貨的背景來源。

# 留意從多頭夢裡清醒的主力大戶
