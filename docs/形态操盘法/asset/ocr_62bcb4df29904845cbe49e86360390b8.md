# 市場充斥著鋪天蓋地的謠言故事

之所以會強烈建議各位要了解心理背景，再用自己的了解敘述故事，還有一個重要的原因：在我們的操盤生涯中，幾乎每天都會受到資訊的轟炸，有些人沒有受過基本的訓練，不覺得那是轟炸，反而覺得是一種知識的灌輸，所以每天很勤奮地看報紙、聽消息、看節目、看雜誌、參加券商公司的投資座談會，其實那堆資訊就是疲勞轟炸。對新手而言，因為才剛進來，尚未疲乏，在遭受資訊「填鴨」時還會產生飽足感，但等到真正要使用知識的當下，往往就只能訴諸於個人喜好，無法依賴理性。

新聞媒體關於「基本面」的消息，會在每個人腦海中不知不覺形成一種非常強烈的故事，也就是說，我們會感覺到有一個巨大的故事正在被述說。不過，說書的人是誰呢？有時是政府的刻意、有時是整個媒體文化無形中造成一種偏狹的共識，那都不是好東西，只是意圖在混淆真理，讓我們短視近利，變得更無所適從。

因此，我們要有定見，自己必須具備知識才能夠抵抗外界散漫零亂的故事。最好的方法，就是靠自己深入了解在整個操作過程中主力大戶的心態，能了解多少就了解多少，不能夠了解的話，就暫時利用技術分析或其他工具擋一陣子，然後私底下再慢慢培養心理分析的功力，才是正途。
