# 形式是外表，心態是內涵

型態學這個東西，是一門學問，博大精深的智慧，等待讀者們去學習。

我給翻開本書的讀者一個建議：不要太急著想直接獲取戰勝股市的捷徑，不要一下子就想抄小路。如果你是這樣的心態而又無法捨棄，那麼，本書恰恰就是你所需要的，因為我會反覆告訴你「型態學真正的意義在哪裡」—— 我會不斷地重複重點，目的是為了糾正長期以來大家對於型態學的錯誤認知。
