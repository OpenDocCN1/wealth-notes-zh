# 另一只靴子: 变狠的社会机制

# 39. 人们潜意识里惧怕认不出自己

我不知道当初你怀着理想踏入社会时, 是否有人曾经对你说过 “要适应社会”。在我的印象中, 很多人还会貌似智慧地说: 如果你不能改变社会, 你就要适应它。

也许还没等你碰得头破血流, 非常聪明的你很快就适应了。

但在最开始的时候, 你肯定感觉到, 你在做很多事情时, 都是违反自己内心的声音的。这是一个迷失自我或者说扼杀自我的过程。
