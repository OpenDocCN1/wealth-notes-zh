# ◇ 心理分析的原理，我们先记住几个规律

1. 排除炒作，凡是在网上“直播自杀”的人，他绝对（注意，是绝对）在骨子里还有生的留恋，无论他痛苦、绝望到什么程度。

原理：一心求死的人，已经对这个世界无话可说，既不想有人看到，也不想看到别人了。所以，他如果“直播自杀”，说明即使求死的程度很强烈，仍然想和这个世界打交道，即仍有生的留恋。

2.a. 一个人在网上“透露”要自杀时，如果语焉不详，所用的词语没有具体的信息，需要你去想象，比如“永别了，这个世界”、“我想我只能离开这个世界了”，可以断定，他或者是为了炒作，或者是为了逗大家玩，或者只是心情不好时发泄一下，这三种情况，都没有表明他在那个时候想自杀。而且，这种情况下，也没有“直播”，因为一“直播”，他所说的话一定会含有具体的信息，而这是他做不到的。

b. 一个人如果在网上说要自杀，并且所说的话含有具体的信息，比如，“安眠药”“父母”“工作”之类，那么，可以断定，他有玩真的倾向，而如果形成了“直播”，不只是扔一段话就走人，倾向就更强烈。如果连图片都上了呢？不用想了，他自杀的心已经非常强烈，因为他已经和自己、和大家在心理上赌上了。

原理：一个人如果真的想死，无论他痛苦、绝望到什么程度，都不会忘记给自己一个死的理由，即要对自己结束生命的行为选择一个合理的交代。对于一心求死的人来说，他已经挣扎过无数回，在心里说过无数回了。
