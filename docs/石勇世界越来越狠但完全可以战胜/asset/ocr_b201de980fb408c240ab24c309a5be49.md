# ◆ 官场神经症

孟立联怎么会有这种“官场神经症”？而其他官员的包二奶、微博开房、写“性爱日记”等其他形式的“官场神经症”，又如何理解？

收获的是利益，生长的是“官场神经症”。

如果不用利益把一大帮人召唤到官场，是玩不转的。但仅仅用利益，它也转不了了。所以今天的官场有它坚不可摧的组织逻辑：科层化。科层化特别讲究官僚机构的权力等级划分、规章制度管理、文凭、证书等。
