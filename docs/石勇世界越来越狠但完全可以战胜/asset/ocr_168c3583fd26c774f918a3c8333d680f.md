祝福我的朋友们，祝你们快快乐乐，健健康康成长。”

假定我们在网上看到有人这样预告自杀，从哪儿可以判断他有这个倾向，而不是炒作或逗大家玩？

+   a. 很简单，“半打啤酒”，这是有具体所指的信息。当一个人说自杀  
提到了具体的东西时，他已经把自己的信誉押上去了，因为具体的东西  
无法通过语言游戏等来辩解。

+   b. “谢谢这个世界……”这段话更是暴露了他的自杀心理。它的功  
能其实只是通过抒情让自己进入角色，得到一种死前的悲壮感。

+   2. 8分钟以后，他说了下面这番话，并且上了图：

“第三瓶了，我相信六瓶下肚我一定会有死的勇气。不要问我为什么。  
本来一个人在外面就很累了，可家人却还是嗜钱如命，把我个人置之度外，  
这样的父母实在让我太难过了。”

+   a. 他说出了自杀的理由。一个人如果说“我好痛苦啊，好想自杀啊”，  
但并不说明是什么人什么事让他这样想，那证明他只是有这种“感觉”而已，  
并不会玩真的，因为这可以合理地归结为心情不好，而谁都有心情不好  
的时候。但如果说到了具体的人和事，我们就必须高度注意了，他是要  
玩真的，因为这些事情可能在别人看来根本没什么大不了的，但在他看  
来却足以致命：他冒了被人视为缺乏处理某些关系和心理问题的能力  
的风险。

+   b. 上图是一个最能说明是玩真的的标志。相当于说：我不是和大家  
开玩笑，你看，证据在这里。

+   3. 他继续控诉父母，继续上图，回复网友一句“没有灵魂地活着，  
就像行尸走肉”。

他一直在按自杀的表演程序走：提供理由，提供证据，在众人的关  
注中投入角色。这表明，他自杀的心很强烈。
