# 18. 变狼的世界里，人们总会有“被迫害妄想”

被迫害狂坚信自己受到迫害、欺骗、跟踪、下毒、诽谤或阴谋对待等，往往会变得极度谨慎和处处防备，小小的轻侮可能就被放大，变成妄想的中心，时常将相关的人纳入自己妄想的世界中。这种人自己总认为有个别人或个别团伙要加害于他，每天都感到痛苦不堪。他抓住一些极为脆弱的事实充当蓄意谋害他的证据，这种情绪逐渐蔓延到他的生活，迫使他做出荒谬的举动，甚至是产生杀人的冲动。

当某些“官二代”“富二代”“军二代”“星二代”祸害平民时，要别人不愤怒是不可能的。

不仅愤怒，还有戾气。

我清楚地看到了一种心态：被迫害妄想。上层社会的人有，底层也有。
