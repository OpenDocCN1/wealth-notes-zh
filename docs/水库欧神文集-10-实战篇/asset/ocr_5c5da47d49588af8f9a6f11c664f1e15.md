# 五）申请信用卡姿势

申请姿势是有标准的流程的：带上所有能证明你有钱、收入稳定的材料（包括但不限于房产证、行驶证、收入证明、工资流水、大额存单、大额股票账户、税单、公积金等），然后按照四个批次，每次集中在一两天申请六七家银行。
