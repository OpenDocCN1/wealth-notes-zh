# 四）可笑的结论

中国的儒家文化，教育孩子方方面面，尽善尽美。但唯独缺乏教育孩子的“<u>勇气</u>”(注意：不是莽撞)。在投资市上，每次大机会时都需要大勇气。比如：全部身家都押注到一次几十年一次，大概率赚大钱的机会上。

很多朋友或许苦练功夫十余载，但在机会来临时，仍会患得患失，疑神疑鬼！

虽然有如此的层层筛选的投资好品种护体，但在股市上，明悟的高手知道：低风险的不是品种而是<u>人心</u>。
