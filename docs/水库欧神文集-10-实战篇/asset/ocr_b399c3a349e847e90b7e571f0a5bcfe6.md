# 1） 预算赤字。

政府收入来源无外乎 3 种：税收、政府债券、印钞机。

税收：这种方法不会导致通货膨胀。可这种方法民众可以直接感受到，必然民怨沸腾。而同时会降低并且中断企业生产，这种方法天然具有约束性。

债券：这处方法不会导致通货膨胀。可欠债还钱，还有利息。现实地方债的结果是：连利息都还不起，更别想还本金了。最后都是展期再展期。

印钞机：任何人短时间内都感觉不到痛。无影无踪的解决了问题。哪怕物价上涨，也是很久以后的事情，老百姓也找不到真凶是谁。媒体报道个“奸商”，政府严惩不贷，大肆宣传一番，以解民怨。

避免政府赤字，停止政府的巨大开支即可，但这需要小政府。可小政府意味着官员的权力变小，自己割自己的肉，谁有这个动力呢？

# 2）利率。

利率是市场对获取资金渴望程度的指示标。人为的规定低利率，便刺激了借贷的增加，从而导致了货币和信贷供应的增加。人为干预利率，是个无解的难题：要保持利率人为降低，就必须增加货币和信贷供应，否则利率必然提高。
