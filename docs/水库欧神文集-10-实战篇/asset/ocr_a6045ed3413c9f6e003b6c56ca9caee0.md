PMT 函数即年金函数，基于固定利率及等额分期付款方式，返回贷款的每期付款额。

# b) PMT 函数

PMT（rate，nper，pv，fv，type）

+   ► rate——各期利率
► nper——付款期总数
► pv——现值，
► fv——终值，缺省为 0
► Type_0 为期末，可缺省；1 为期初。

# c) PMT 示例：

已知贷款的年利率(4.9%)，贷款年限(30 年)，贷款总金额(200 万)，现在分别计算年偿还金额、季度偿还金额、月偿还金额。

=PMT (4.9%，30，2000000) 计算年偿还金额。

=PMT (4.9%/4，30*4，2000000) 计算季偿还金额。

=PMT (4.9%/12，30*12，2000000) 计算月偿还金额。(-10614.52)
