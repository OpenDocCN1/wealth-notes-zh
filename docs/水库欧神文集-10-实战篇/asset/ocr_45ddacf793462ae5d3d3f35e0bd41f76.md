# 一） RATE 函数：

# a) RATE 定义：

RATE 函数基于等额分期付款的方式，返回某项投资或贷款的实际利率。

# b) RATE 函数

```
RATE（nper, pmt, pv, fv, type, guess）
```

+   - nper：付款期总数
- pmt：各期应付的金额（年金）
- pv：现值
- fv：未来值
- Type：各期付款时间是在期初，还是期末（1为期初；0为期末）。

# c) RATE 示例：

举例 1）

Nper：假如你存钱的期限为 12 年；

Pmt：假如你每个月都存进去 500 元；

Pv：假如你第一次一次性存了 3000 元；

Fv：假如你想过了 12 年收到 300000 元（本金+利息）；
