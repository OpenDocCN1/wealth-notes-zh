# 举例 3)

某人 2018 年，受银行工作人员的忽悠，购买了一份定期保险，年缴费 2000 元，缴费期间 10 年，最后得到资金 22000 元。那么，年利率是多少？

PMT = -2000，NPER = 10，PV = 0，FV = 22000。

年利率 = RATE(10, -2000, 0, 22000, 1) =1.73%

银行工作人员，忽悠的水平确实不一般。如果早会用这个公式，就可以避免被忽悠了吧！
