
# 四）价格上涨

  无数的天朝经济学专家学者说现代货币是有“锚”的，呵呵呵呵。要我说那个锚就叫做“心情”。心情好了少印点儿，心情不好就多印点儿。自1971年，美元脱离金本位后，谁见过这个“锚”？

  然后有人提出，不对！央行负债太高不行。呵呵，你被教育得很好。我给个答案：多高都行。

  实际上货币供应，并非都是大家理解的现金，也可以是支票类提取的存款。

  以官方数据为准（假设是准确的），2003年5月与2018年5月的货币和准货币（也即M2）数据如下（注2）：

- 这个商品被世人所抛弃，没有价值了。

# 五）通货膨胀的特点

  除了要牢记通货膨胀的概念，即通货膨胀就是：货币增加了。
（注：本人实在不愿意在货币前面加个定语“过度的”或者“不恰当的”）

  还要记住通货膨胀有很多特点。
a) 货币增加。
除了现金增加，还有信贷的增加。
b) 货币增加预期。
比如当年的4万亿，只要有这种预期，聪明的人就清楚1年以后的RMB购买力比现在要低。他们很快就会采取行动。至于是什么，多军笑而不语。砖本位？
c) 货币质量。
自货币脱离金本位开始，纸币就已经没有什么质量可言了，也就是没有什么价值了，背后剩下的就是gun的力量。而在这纸币时代或者即将到来的数字货币时代，必然发生银行信用和货币的迅猛增长。至于其背后原理，这个说来话长，容有时间再讲。

  货币是几千年来人民自然的选择，其本身就是商品，无外乎流动性更好，所以大家愿意储藏。货币价值的变化与任何商品的价值变化是一样的，往往也是取决于人们的心理预期。就如人人关心的猪肉价格，不仅取决于目前猪的供应问题，也取决于成猪出栏的预期。

  所以多军吃通货膨胀这碗饭时，要**牢记通货膨胀的本质和特点**，不要被各种狡辩言论所干扰。科学这东西从不以人的意志为转移。

  关于物价，在宏观经济学中，有一项著名的“货币流通速度公式”：QP = MV
+ Q：商品数
+ P：价格
+ M：货币数
+ V：流转数

  也可以这样写：商品价格 P = MV/Q。货币价格与商品价格是反向关系。

  所以人们经常说货币的价值不仅仅取决于货币的数量，还取决于货币的“流通速度”。公式中货币流通速度增快，物价则上涨快，也就是货币贬值了。貌似很有道理，但这通常是理工生的思维。

  我们进一步反问一下：这个货币“流动速度”怎么会加快呢？它无外乎是人们担心货币会贬值，用脚对货币投票，加速购买商品罢了。也就是说人们相信商品价格会上升，加速抛出手中的货币。这才是根本原因。也就是说货币“流动速度”增加是货币预期的后果之一。

  理工生喜欢用公式来看待人世间所有问题。而人文科学是一门推演科学，普通人常常缺乏逻辑推演的能力。

# 六）对通货膨胀的几个误解

  **误解1：通货膨胀由“商品的短缺”引起,不是由货币数量的增加引起。**

  商品价格的上涨：可能是货币增加引起，也可能是商品短缺引起，或者由两者共同引起。比如：今年的猪肉涨价了。可能是因为货币增加，也可能因为出栏猪减小。

  在普通百姓中，通货膨胀是由“商品的短缺”所引起的误解最深。而政府官员最喜欢以这个为借口打击奸商。

  有的朋友喜欢以战争年代举例，事实上，即使在极端的战争年代，普遍的商品短缺也不会引起价格的普遍上涨。

  设想一下如果在战时，战时民用商品短缺。如果战争仅仅是通过税收，则用于军火炮弹的货币比例与从民用品挤占的那一部分货币相当。民用商品的短缺怎会让价格大幅上涨？通俗点讲：货币并没有增加，民用商品生产减少，其价格上涨。但是这种价格上涨是由于短缺引起的，并不是通货膨胀引起的。而真正的事实应该是：与此同时，因为用于民用品的货币会减少，所以价格不会上涨太多。

  **误解2：预算赤字引起了通货膨胀。**

  如果政府出售债券而导致的预算赤字，也就是从其它处借来的钱，并不会发生通货膨胀。欠债还钱这种事，从不会引起通货膨胀。

  预算赤字，只有在货币供给增加时才具通货膨胀性质。话说即便预算盈余，但只要货币供应增加，才会通货膨胀。

  任何情况下引起的价格螺旋式上涨，如果在之前，同时，或者很短时间后，没有新增的货币供应，这种现象都不会持续。

  如果人们的收入并没有增加，商品价格上涨无疑只会引起销量的下降。简而言之，我们的技能并没有增加太多，而所有人的工资却在大幅上涨，这通常是通货膨胀的后果。商品价格的普遍持续上涨，也是同理。

# 七）解决通货膨胀的办法

  解铃还须系铃人，既然通货膨胀的原因是货币和信贷的增长，解决通货膨胀问题，方法很简单：停止增加货币和信贷。

  说不容易。一般有下面几个原因：

  **1）预算赤字。**
  政府收入来源无外乎3种：税收、政府债券、印钞机。
  税收：这种方法不会导致通货膨胀。可这种方法民众可以直接感受到，必然民怨沸腾。而同时会降低并且中断企业生产，这种方法天然具有约束性。
  债券：这种方法不会导致通货膨胀。可欠债还钱，还有利息。现实地方债的结果是：连利息都还不起，更别想还本金了。最后都是展期再展期。
  印钞机：任何人短时间内都感觉不到痛。无影无踪的解决了问题。哪怕物价上涨，也是很久以后的事情，老百姓也找不到真凶是谁。媒体报道个“奸商”，政府严惩不贷，大肆宣传一番，以解民怨。

  避免政府赤字，停止政府的巨大开支即可，但这需要小政府。可小政府意味着官员的权力变小，自己割自己的肉，谁有这个动力呢？

  **2）利率。**
  利率是市场对获取资金渴望程度的指示标。人为的规定低利率，便刺激了借贷的增加，从而导致了货币和信贷供应的增加。人为干预利率，是个无解的难题：要保持利率人为降低，就必须增加货币和信贷供应，否则利率必然提高。

  **3）金本位。**
  政府之所以放弃金本位或者金银复本位，无外乎找个借口通货膨胀更容易罢了。金本位（或金银复本位）对信用的扩展有一个天然的限制。如果不回到这种本位上去，通货膨胀无可避免。

# 八）通货膨胀的未来

  制度是人定的，一切皆在人心！通货膨胀的效果之一是造成财富和收入的再分配（注意不是增加）。

  在通货膨胀的前期阶段（也就是还没有体现在大多数商品上涨时），部分先拿到新货币的人先受益，当然未拿到货币的人是受损的。受益的这部分人，当然希望维护通货膨胀。作为多军朋友，你心里是不是这么想的？！

  事实上，很多朋友虽然嘴上反对通货膨胀，但并不是真心的。很多朋友会认为增加自身收入的速度能够快于自己生活成本的增加，并最终成为获胜者。很多人想的是：“除了我的产品价格和收入之外，其他人的产品价格不要上涨，其他人的收入不要增加。”唉，普通百姓的智慧啊。

  当然最最虚伪的往往是政府，为了赢得民意，他们一边说坚决“反对通货膨胀”，而同时会加上一条保护“充分就业”，这一点，朋友们可以仔细观察每一次通货膨胀严重时期的政府官文。普通民众所不曾知晓的是：“任何充分就业政策的内容九成都是通货膨胀。”

  历史的经验告诉我们，通货膨胀必然以危机和萧条告终！但如果说萧条已经很糟糕了，比这更糟糕的是百姓错误的看法：萧条不是由之前的通货膨胀引起的，而是由资本主义“固有的缺陷”引起。资本主义还有个“固有缺陷”，这是什么玩意儿？

# 九）总结：

  总而言之，通货膨胀就是：货币与银行信贷相对于商品数量的增加。

  它的害处数不胜数：它使单位货币贬值；使人民的生活成本提高；它对全体人民征收相同的铸币税，穷人生活更加艰难；它使人们的储蓄价值大损，并打击人民储蓄的积极性；它打击节俭与勤劳；它使人民不再相信正义，它败坏公共与私人道德。

  政府（政客、官僚）操控了货币就等于配备了打开全国公民家门的钥匙，可以随时随地、随心所欲地使用通货膨胀盗窃公民的财产，而且永远不必担心被捉赃。人类社会的癌症，非通货膨胀莫属。说它是经济危机、大萧条乃至一切社会灾难的祸根，我也完全同意。

  时至今日，多印钱的形象词语如空气般消失。“通货膨胀”这个词被“价格上涨”所替代。形象的词语销声匿迹，无影无踪！你是智者吗？

# 房地产铁打的泡沫

# 日本房地产泡沫（一） #711

![](img/998d37a9a4955949ecbc2ff65f9f659f_183_0.png)

  综观全球市场，我所知道的有3个地方曾经发生过房地产暴跌。一个是日本，一个是我国的香港，一个是芝加哥。理论部分后面写文章补回来，本文来说说日本。

  在分析日本泡沫的研究中，大炮的研究方法我是比较认同的，这里写给大家。最后会写写我的见解，以飨库友。

## 一）前言

  日本1986—1991年发生房地产泡沫事件，最终房地产大泡沫轰然倒塌，随后房价步入漫长下跌之旅，日本经济陷入失落的二十年。一直到今日日本没有回来！

## 二）中国

  中国房地产繁荣和迅猛发展始于1998年，自朱相全面启动住房货币化改革开始，开始进入房地产大牛市。

  房价出现连续多年的增长，大约在15年前，也就是2003年，政府就已经开始了各种调控政策。泡沫言论就已经传遍街头巷尾。2003年！上海莘庄当时3000元/平可以买个不错的房子。

## 三）泡沫

  专家在谈论泡沫，普通百姓在谈论泡沫。可什么是泡沫呢？比较滑稽的是，时至今日（2018年），经济学上也没有给出一个明确的“泡沫”含义。凡是张口闭口谈“泡沫”的专家学者，俺是通通鄙视的。因为他们统统在“装”。

  因为日本发生过房地产泡沫崩盘事件，所以中国媒体、专家、百姓，总是拿日本来说事儿，一晃就是15年。年年都说，百说不厌。总是提醒我们日本式泡沫破裂的严重后果。但日本当时泡沫是如何产生和如何破裂的，与中国的现状是否相似却从未给出明确的答案。

  资产的暴涨是否合理，是否有泡沫。呵呵，你就别乱猜了。99.999999%的写报道的人连定义都不清楚的。

## 五）日本与中国的背景情况对比

  中国是否发生了日式房地产泡沫？可以对比一下日本和中国的情况：

| 日本1986-1991年的特点 | 中国目前的现状 |
| :--- | :--- |
| 1. 股票价格暴涨、金融成本降低 | 股票价格暴跌、基本丧失融资能力 |
| 2. 金融放松、给不动产巨额融资 | 金融管理严格、开发信贷几无增加 |
| 3. 土地私有并市场化、预期收益提高 | 土地国家垄断、政策性推动地价上涨 |
| 4. 土地价格上涨、家庭收入增加 | 土地价格上涨、家庭支出增加 |
| 5. 零付款土地抵押贷款增加 | 必须支付全部地价后抵押贷款 |
| 6. 股票与土地升值增加了消费与需求 | 家庭自住性消费占主导地位 |
| 7. 投机行为提升了股票与土地的预期价格 | 必须支付首付的少量投资与投机行为 |
| 8. 大量的非不动产企业与政府购买土地 | 土地购置与开发主要为不动产开发 |
| 9. 税收制度扭曲了土地的保有与使用关系 | 税收有利于拥有多套住房 |
| 10. 设备与房屋投资增加 | 实体经济因素促进全面投资增长 |
| 11. 汇率波动币值上升 | 汇率僵硬、币值稳定 |
| 12. 国际资本净流出 | 国际资金流入 |
| 13. 利率降低 | 利率升高 |

  中国与日本的极大差异，中国不会出现或者说各种可查的数据显示中国并不存在日本发生泡沫现象的前提。

| | 日本 | 中国 |
