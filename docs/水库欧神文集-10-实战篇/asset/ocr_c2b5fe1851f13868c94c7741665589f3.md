# 二）IRR 语法

格式：IRR(values, guess)

功能：返回连续期间的现金流量的内含收益率。如果我们借钱，这个值越低越好；如果我们投资算收益，这个值越高越好。我们只关心 values 这个参数就行了。对 guess 参数感兴趣的话，度娘吧。
