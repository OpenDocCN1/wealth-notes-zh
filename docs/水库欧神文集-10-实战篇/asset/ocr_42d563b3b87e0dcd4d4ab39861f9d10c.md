# 一）确定性

赚钱的品种的选择决定了你可以赚钱，参见上文《赚钱的紧箍咒 #20》，此乃定性分析。投资路上，要在确定性极大的情况下，敢于全力一博，下大注。人生第一桶金，往往来自日积月累学习后，一击必中的那次。赚大钱永远是抓住那几次稀有的机会。在所有赚大钱的技巧中，确定性+下大注，名列第一。

# 二）守拙

如何才能赚很多很多的钱？要持续的赚钱，积少成多。如何持续的赚钱？赚钱的事情持续做。见过太多的朋友在投资品种上选对了，但总是会“溜号”：赚点钱就收手的有之，赚点儿去投资亏损品种的更有之。在赚钱品种上的守拙，是赚钱的基本品质！

![](bbox=[0.5, 0.52, 0.62, 0.59])

有的朋友说，我守拙的品种，一直亏了10年。

为什么这么多朋友不能守拙？真正在市场上操作的朋友知道，市场就是人心。凡没有守拙的朋友，都是对自己投资的品种不了解，也不确信，换句话说理论不过关。

后面几篇文章很快会讲几个基本赚钱品种的理论，诸位稍安勿躁。

# 三）定量计算

如果一项投资不能定量的计算出大概时间的盈亏概率和幅度，这笔投资注定是感情用事的。

举个貌似欢乐的例子，假设投入100万，3年后极大概率将得到118万，极小概率只收回本金（这种再算是初级过关的投资者，普通大众往往会认为这是一笔保本的投资）。请问：这是一笔赚钱的投资吗？

很多朋友投入100万，即说不清可能赚多少钱？也说不清可能亏多少钱？更说不清多久可以终止投资？
