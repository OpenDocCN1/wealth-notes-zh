# 四）FV（未来值）

# a) FV 定义

FV 是 Future Value 的缩写，这里我们可以称之为金钱的未来值。

# b) FV 函数

```
```text
FV（rate，nper，pmt，pv，type）
```
```

+   - rate：各期利率
- nper：付款期总数
- pmt：各期应付的金额（或得到的金额）
- pv：金钱现值，缺省为0
- Type：各期付款时间是在期初，还是期末（1为初期；0为期末）。

注：pmt 简称年金，后面会单独讲与年金相关的知识。

# c) FV 示例一

假设现在有 100 元，做一笔投资，15%利率，以后每年都不需要继续投钱，那这笔现在的 100 元未来值是多少呢？
