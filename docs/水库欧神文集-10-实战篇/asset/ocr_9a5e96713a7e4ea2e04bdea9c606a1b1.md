# 六）对通货膨胀的几个误解

误解1：通货膨胀由“商品的短缺”引起,不是由货币数量的增加引起。

商品价格的上涨：可能是货币增加引起，也可能是商品短缺引起，或者由两者共同引起。比如：今年的猪肉涨价了。可能是因为货币增加，也可能因为出栏猪减小。

在普通百姓中，通货膨胀是由“商品的短缺”所引起的误解最深。而政府官员最喜欢以这个为借口打击奸商。

有的朋友喜欢以战争年代举例，事实上，即使在极端的战争年代，普遍的商品短缺也不会引起价格的普遍上涨。

设想一下如果在战时，战时民用商品短缺。如果战争仅仅是通过税收，则用于军火炮的货币比例与从民用品挤占的那一部分货币相当。民用商品的短缺怎会让价格大幅上涨？通俗点讲：货币并没有增加，民用商品生产减少，其价格上涨。但是这种价格上涨是由于短缺引起的，并不是通货膨胀引起的。而真正的事实应该是：与此同时，因为用于民用品的货币会减少，所以价格不会上涨太多。
