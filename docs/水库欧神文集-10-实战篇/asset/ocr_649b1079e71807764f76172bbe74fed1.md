# 误解2：预算赤字引起了通货膨胀。

如果政府出售债券而导致的预算赤字，也就是从其它处借来的钱，并不会发生通货膨胀。欠债还钱这种事，从不会引起通货膨胀。

预算赤字，只有在货币供给增加时才具通货膨胀性质。话说即便预算盈余，但只要货币供应增加，才会通货膨胀。

任何情况下引起的价格螺旋式上涨，如果在之前，同时，或者很短时间后，没有新增的货币供应，这种现象都不会持续。

如果人们的收入并没有增加，商品价格上涨无疑只会引起销量的下降。简而言之，我们的技能并没有增加太多，而所有人的工资却在大幅上涨，这通常是通货膨胀的后果。商品价格的普通持续上涨，也是同理。
