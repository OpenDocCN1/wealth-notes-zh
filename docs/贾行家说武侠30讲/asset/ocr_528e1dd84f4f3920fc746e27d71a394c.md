# 20｜说金庸：为什么全球华人都爱他

说古今论天下事，查奇索事行家事。谢谢你听我说夜话。

关于金庸的最后一讲，我想来说说金庸小说核心魅力的来源。

# 为什么是金庸？

世人评金庸，有句话叫，“有井水处，就有金庸”。金庸涵盖的是全世界的华水。

从来没有哪个用中文写作的小说家能像他这样，让不同国籍、不同阶层、不同文化和信仰的华人都喜爱。

如果仅仅归于通俗，那当时的琼瑶在商业上也很成功，但琼瑶只能覆盖特定读者群。

如果说因为武侠，其他武侠小说家都没这个待遇。那么，这个魅力是怎么形成的？

我上初中时，在历史课上讲着龙宫小说，老师批评我："你要看的是金庸，我都不小说，怎么这么好，好里面有历史知识。"

这件事，既体现金庸的不同，也说明了他为什么不同。大家以为，金庸能代言中国传统文化。所以，他的最爱等于古代人中国法。

海外华人常常鼓励孩子读金庸，对海外长大的华裔来说，金庸的小说等于中国传统文化教科书。

文化学者和教授，也普遍对金庸的文化修养评价很高，称他是既博雅，又通俗。

这就引出来第二个问题，用传统文化元素写作小说的作品，也不是只有金庸一种，学识渊博的也大不许多。为什么会有金庸有一种雅俗共赏的地位？

我觉得，这是因为金庸运用传统文化，有三个厉害招，分别是招式、法与内应力。它们分别是形式重构、混搭拼贴以及集成功能。

# 三重神功

下面我详细说说这重神功。

第一式"变形和重构"，怎么讲？

就是金庸从不照本宣科地描述历史，照搬传统文化素材，而是经过整修，变化成适合武侠场景、大小说理的形式。

最明显的例子就是他的江湖观。武侠小说的前身传奇，是建立个二元的江湖世界，既远离现实，又处处模仿现实。

金庸的江湖流造情形，无所不包。

在他笔下，五岳有五岳剑派，水路上有水寨船帮，大海有海龙王，市井有丐帮，西域有白雪山，少林寺有花。

还可以用价值观来分，佛教有少林，道教有武当峨眉，儒家名门正派和散外教，都一一对应，并开有派。

你注意到没有，这个江湖布局，我们接受起来一点就特别容易。为什么呢？因为我们不是在接收信息，而是在回忆，这些元素都眼熟。

比如，仓皇北去，既是武派创立传奇，我们的反应是"这下稳了"。

武当向来主持正义，剑法高妙，而你会盼着他们摆开"真武七截阵"，张三丰的七大弟子布阵，相当于64名一流高手出术。

我们的兴奋点，不是金庸个人的创造。

在道教体系里，以张三丰为祖师爷的道派有多复杂，修炼"隐逸派"，在民间道派里，张三多是仅次于吕洞宾的财神仙。

所以，金庸只是借力打力，进行整合。

他的整合变形，有一种内力支撑：金庸曾深刻总结地域文化的原理。他所虚构的情节，万年不复其形，符合禅道各家精髓，不会产生"违和"感。

比如，扫地僧在金庸小说里武功最高，但他在少林寺地位最低，只当个清洁工。

如果对佛教禅宗不熟悉，会觉得这个设计很妙，属于"神级反转"。

但让文化修养较高的读者看，这个设计又很亲切，完全符合禅宗特点。

在禅宗公案里，经常有地位最低的僧人开悟。传说六祖就是厨房里杂工的，很秀才度。少林正是禅宗祖庭，最合适出现这种神人。

在这里，金庸只是把玄妙的禅性，转换成了具象武打。但实现这种转换，不理解禅宗思想是不行的。
