# 26 | 纯文学和通俗小说到底哪儿不同？

据说古今无事，抄袭老齐家行囊，谢谢我听我说的哦。

课程最后的一个单元，我要带你走出武侠小说，做个小结，对比。

既对比说这种商业化小说颠覆严严肃文学，也中国的武侠和通俗小说的骑士文学、推理小说，日本的武士小说做一下比较。

最后，我们再来来说说武侠精神对于我们今天现实生活的意义。

在我看来，我们这个课有一个必须要讨论的话题，就是纯小说和严肃文学之间，真的一条明确的界线。

在以前的文学研究学术领域里，这个界限是明确的。二十几年前，严家炎先生第一次在北大中文系开文学史课的时候，就被看成是老经派。

一直以来，主流文学理论一直承接“五四”以来的新文学观念，这是一个和通俗对立的标准，肯定是要排斥通俗小说。这个传统对小说是搞禁忌，目前很难下定论。

但我觉得，这条界线只是出于想象。小说的本质是讲故事。

中国文人的个人化世俗化情绪的，一直在转移：当文文必须说成道德以后，文人也在纯粹趣味中消逝；到了诗也被彻底禁绝，表达某种高雅志趣，情趣转移到宋词和元曲；最后才从笔尖小说跳进了章回小说。

我们在讲清代武侠的时候，说起过当时的大才子俞樾，改写了通俗小说《三侠五义》。

在我看来，文学确实是一种历史，能影响先判断的你，当一本小说有足够多的是非冲突，形成了深刻的阅读共鸣，读者就会感受到文学性。

也就是说，一部小说够不够“严肃”的标准，其实和写作没关系，要看作品是怎么写。

这一次，我想把一篇当代小说经典《棋王》跟你做个比较，当然是不是武侠小说，但内容为下棋博弈，本身有着跟武打对决相同的风格。

通过它，我们来体验一下，一个严肃风格的武侠文学，到底是什么质感。

# 时局如棋

这篇小说叫《棋王》，作者阿城，发表于1984年。

故事的背景是上世纪六七十年代，讲诉者是第一人称的“我”。我父母死于运动，于是报名下乡，在返知青的火车上，我认识了一个叫王一生的人。

王一生长得精瘦，对车站的混乱、送别哭泣都没有反应，只是四处找人下象棋。

他的外号叫棋呆子，有很多传说：都说他的棋是一个绝对精尖的老头拿的，有通家私仇，曾战胜过国内许多高手。

除了下棋，王一生在乎吃，不是挑剔，而是吃得很杂面，什么都敢吃。王一生和我是同乡，所以互相信任，成了朋友。

插队的农放在大山里，生活清苦，但每月有20元工资，比我们在城里还多。
