# 05 | 兰陵老人：武侠的传奇性从哪人来？

说古论今天下事，抱琴负笈行天涯。谢谢听听我说话吧。

这一回，我们通过唐代传奇里的一个神奇侠者兰陵老人，来说道教对武侠世界的影响。

这种影响，既体现在法术内功的细节，也体现在脱离秩序的精神内核。

所谓唐传奇，就是唐代的文言短篇小说，因为总是写一些离奇异事，就被后人叫做了传奇。

# 兰陵老人

兰陵老人的故事出自唐代小说集《酉阳杂俎》，《酉阳杂俎》的作者是唐代大才子段成式。

故事发生在安史之乱以后，当时的京兆尹叫黎干。

京兆尹这个官职，可以理解成当时的首都长安市市长。这一年，黎干到曲江注意求雨，路上遇到了一个不回衙仪仗队的老者。

于是黎大怒，叫人当街杖打这个老者。

奇怪的事情发生了，奇杖打在死木板上。但看看打老者，像打了皮肤，砰砰地响。

老人被打后若无其事，站起来就走。

黎干很得此事非常诡异，派人跟踪老人，一直跟到兰陵坊。

那老人走进一户人家，大声命令主人，说：“今天我被官府给打。”

黎干听说这户人家，赶紧派人在衣服内套上铁甲，趁老客来兰陵坊寻访老人。

黎干说这户人家人，进门去就请求下。老人拉他来，问道：“是谁找到你来这里的？”

黎干就连说自己因天命不得已，若是丧失了官宅，就会影响国家政务系统。

然后着想着老人大概是为了命高，没有恶意，实在看不起人。要么是认为这种事里自己，可就说不上义了。

这番话，连黎都带德佩服，真是高明。

老人听了笑道：“让你这么一说，倒像是老夫的不是了。”就敢在床上摆下酒菜，和黎干、随行不一一起吃喝起来。

夜深人静，老人谈论起道教学的养生术，言语之精深，越发让黎干佩服。
