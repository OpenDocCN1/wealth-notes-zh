# 刘东山趁夜遇盗人

明嘉靖年间，北京城有个出名的捕头刘东山，江湖人叫连珠侠。刘东山靠掌过不少江汉大盗，积累了些家财，三十多岁娶了官家女。

有一年，他带着百两银子去张店，在某个店里常卖杂货自己靠两只手一张弓，提拿拿无数绿林好汉。

第二天他骑马东去，后面跟上来一个少年，央求着要他结伴走，好处结社。

刘东山看这少年是新斯文，身材矮小，衣着华丽，腰里还带着不少财物，不像歹人，也没当一回事儿。

路上，刘东山又烦恼了一顿他的书风，轻少年一顿，借了两头的一只毛兔，只见他年轻一拔，就把弓拉满了，连着放了许多下，像博格希杀似的。

这把刘东山看得大惊失色，不过少年的书看看着，用了百生之心也不让半分。

少年拿到弓，飞马向前，在百余之外停下，回头身拉开弦，对刘东山说：“听说足下箭法无敌，请足下听我的箭风。”

接连地向右边飞了十几下。

刘东山下马车来，趴在地上，双手捧着银子包，用膝盖挪动着到少年马前，叩头求说道：“银钱财物是身无二，只求脱命！”

少年拿了银子，策马而去。

刘东山到家，往门外开了个酒铺。三年后的一个冬日，店门外来了快骑着高头大马、衣着光鲜、背后背弓的客人，一共有一十一位。

其中年纪最轻的一个，只有五十六五岁左右，冲众人吩咐了几句，便来到刘东山面前站了上去。

剩下十个人进店去喝酒，不一会儿酒，吃了几十斤的冷肉，喝下六七坛黄酒，又从皮囊里拿出鹿角、野鸡肉来。

刘东山察察发现，在左边坐的那人，正是当年劫他的那个少年，心想当年那一个都不是对头，这一群肯定个个都是英雄。

他见少年也认出是了自己，赶紧跪下来求饶。

没想到少年也跪下扶他起来，很客气地说：“当年与兄台兄弟路过北京，听你夺口，才流我给我们打抱不平。”
