# 25 | 玄幻：爽文为什么会让人欲罢不能？

![](bbox=[0.1, 0.06, 0.35, 0.11])

说今论天下事，拾奇索贤行家言。感谢听我讲废话。

这一讲，我们来讨论近几年特别热的玄幻，我想请你聊聊武侠与豪是怎么延展进玄幻爽文的。

# 趋势：越边越高的临界值

你不一定看过多少玄幻小说，我先简单介绍一下。

武侠和玄幻渊源很深。“玄幻小说”这个词，就是香港武侠小说家黄易在1985年提出来的。全称是玄幻科学幻想，和科学幻想对应。

这个玄幻不局限于科学幻想，而是各种超经验、没法被感官感知的故事题材。

玄幻所描写的世界，在物理上不可能出现，但只要你设定得足够严谨，也能合理地运行。

从定义角度宽泛来说，玄幻一开始就是个“大筐”，什么都能往里装。

按网文爱好者的估计，现在的玄幻流派至少有几十个，这其中包括但不限于武侠到仙侠那里。

我们把这类划放在一起，有一个发现：各种玄幻流派，如五湖五湖八门，并且不是不平均的，内部其实有一个明显的进化脉络，这就是：玄幻小说一直在不断提高刺激快乐的临界值。

临界值也叫阈值，意思是改变某种反应所需要满足的数值。

在神经科学里，临界值就是能让神经元受到刺激所需的最小强度，但是，大脑反复接收同样的刺激，就不再引起脑内的反应了，也就是麻木了。

要想保持敏感，就得更刺激、更新鲜的方法来刺激新的临界值。

黄易开始写玄幻，就是因为当时他看到的武侠小说刺激点都固定了，需要新的兴奋点，于是差异化竞争。

他发明了一种叫“科幻武尊”的玄幻写法，就是把武侠小说的场景延展到了未来的宇宙星际。在这类小说里，科技和武功并存，既有武功，又有外星人，异次元生命、机械装甲。

在网络小说刚刚开始流行的20世纪90年代末，这是最热门的类型，代表作有作家阿朱莫仁的“天荒世纪”，这套书讲了跨度千年的星族战略故事。

但这类故事，读多了就不新鲜了。于是，在科幻武侠的基础上，出现了奇幻修真小说，就是从人修到佛开始，不断升级，最后成仙，纵横于魔界、神界。

这类网文和民国时的《蜀山剑侠传》不一样，它的故事以修为场，场景包罗世界和太空。从这时起，玄幻和武侠分家了。

修真小说泛滥以后，读者看前几章就知道后面，主角最后都会成为什么的，一开卷，也懒得没意思了。

这时候，又出现了一种新写法，把西方的宗教神话和魔法也拉进了玄幻小说。

东方修者和西方魔法师大乱斗，仙佛和天使满天飞。作者干脆直接自己创造各种文明和宗教。

该玄幻的爽，当然不是看别人爽，而是要把自己代入主角，跟着主角的路线，体验如何冒险，如何从地上人一路修，这是一种确定性。

比如热门的穿越文：一个人穿越到古代，成了先知，凭借着现代的知识、技能和思维，首先称霸，小说最早里的的穿越文是黄易的《寻秦记》。

后来又出现了穿越和后宫文的结合，就是主角从过去世界之后宫，得意洋洋地看着后宫佳丽为自己争风吃醋。

# 区别：玄幻爽感和武侠快感

你可能发现了，读武侠小说，主角都是有关怀的，看他们仗剑江湖、惩恶扬善，还是很有快感的。

但武侠小说传奇故事里的主角，跟玄幻小说的男主女主，却有着本质的不同，不同究竟在哪里？我来拆解一下。

比如，香港派玄幻幻作家那里，有一位很有名的小说叫《将夜》，作者猫腻，是一线的网络作家。

故事讲的是两个苦孩子学艺报修，修行之后，在天地讲演的故事。这个故事，是不是和《倚天屠龙记》很像？但二者的写法，是完全不同的。

首先，两本小说世界观设定不同。《将夜》全面落实地站在历史现实文化，《倚天屠龙记》的世界，人物、都有现实支撑，关于明清的描写，也是有相关记载的。

《将夜》中一上来就进入一个架空的世界，只有名词而已，但这个世界有它的信仰，各种神奇力量都修仙法术。

大背景是代表黑暗力量的冥王降临人间，带来比这千年的天灾。人间的修行者要阻止冥王之子。

网络作家是历史文化功力，肯定没法和金庸比。

这种世界观设定，是把中国的一些文化碎片和西方玄幻结合，比如《魔戒》《冰与火之歌》的写法，一塌加上人物想象力，杂揉在一起。你看，既然是自己编的，他们就有解释权了。

# 读者看玄幻，正是为了逃避真实世界，不希望那么真实。

正因为人们在现实世界太累了，一直焦虑得很无法释放，才特别需要加入脑洞。想一下子气了以后，打开电脑，刷剧集，进入一个完全不想，想要安全和全能的梦想。这种消遣，是他们最需要的。

其次的区别是写法不同，玄幻的整体故事经常是推进的，但一个单元内的情节推进，要比武侠快、密集。

在《倚天屠龙记》里，故事节奏是平缓发展，展现事件的完整链条，从张翠山夫妻自杀，到张无忌从小说改变身份，已经过了三分之二一张。

这个写法，是让读者先充分体验主角的历经，前面把剧情铺垫得压得深深，后面爽感翻番放大，让主角救人的快感得多强烈。

但玄幻不能这么写。《将夜》的主人公叫宁缺，他要与人分手，走到道门要道杀人物复仇的目的，就必须一路开挂：

+   - 先是拿一个接了个修行，获得天下至宝；
- 然后修身仙脉，达到修行最高无上限等级；
- 再不断奇遇赢车，拜鬼怪大的老师，给得最毒的法术，拥有超越时空的武器，近乎杀穿敌阵。

而且，主人公的身世也必须要独一无二。宁缺的角色，就是在自身处时达到最爽，这时候就颠覆了原型。原来他捡到的这个弃婴竟然是传说中的冥王之子。

于是小说进入第二轮升级，开始人界和天界的战斗。

武侠和玄幻的区别，有点儿像棒球和篮球的区别，武侠小说的节奏，可以慢慢享受矛盾的建立和展开，一场比赛只进一个球就足够。

但玄幻必须速度快，一节一个球地推高。我们前面说了，玄幻的利度早就超过了武侠的阈值。

五十年前，读者看到乾坤大挪移和九阳神功，就觉得匪夷所思了。而玄幻是一上来就改灭天地的。

虽然当有太多不同，但其实，玄幻的专业，就是把这个写作当成职业，用更专业化、职业化的商业逻辑在写作。

因为写网络文时，作者和读者之间保持着密切快速的反馈，形成了高度的互相影响，这是新的互联网时代才出现的过程。

结果就是，玄幻网文捕捉读者能力越来越精准。

如今，玄幻网文是短视频、网游对标的，因为是相同的产品思路，在吸引相似的一批用户。

网文作者们总结：进入这一行，要想维持热度，必须每天保持6000字以上的更新输出。如果销量下滑，只能比干法上重新来过。这完全是一套食物链的商业生存法则。

# 问题：一直刺激会一直爽吗？

那么，我有个问题：“读玄幻一时爽，真的就会一直爽一直爽”吗？

玄幻这种写作，一直高开高走的刺激模式，最后能走成什么结果呢？

这种无限竞争，其实首先伤害的是从业者。

玄幻经营着自己的竞速，出现过很多好作品。可是如今的网文竞争生态，已经导致网络创作了。

为了保持热度刷量，很多作者连完整的场景都不敢建，必须立刻加戏，故事变得简单粗暴，甚至一个自然段都不能超过三行。
