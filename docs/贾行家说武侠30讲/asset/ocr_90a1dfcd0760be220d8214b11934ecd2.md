# 发刊词｜说武侠，论江湖，见众生

说古论今天下事，俯拾案书赛行家。
在下发家君：这一次，请听我来说说武侠。
这是中国文化系列课的第三个课程。
有些形象，让你念念不忘，你没忘记也得记：
1982年的电影《少林寺》里，英气逼人的李连杰；
1983年，翁美玲扮演的娇俏黄蓉；
1995年，李若彤的冷艳小龙女；
2003年，胡军的英雄萧峰。
如果你喜欢文艺片，还会想起张国荣的欧阳锋、章子怡的郭二。当年，每到假日，厂矿电视台就会循环这些经典剧。
也许你还在怀念在手机上看剧，感慨那些被荧屏留住的风华绝代。
而我的这些经历，你应该也有：
把金庸藏在课本底下，化学课上提心吊胆地偷看；
趁着暑假父母上班，疯狂地看全套的古龙；
即便上大学了、工作了，还在兴致勃勃地跟别人争论谁是谁非下谁武功更高？
所以，这一次，我要邀请你，一起回青春那边去看一看。
你当然可以说，谁的青春没点侠气冲动？西方有维维小说（注：可能为《维埃纳》或特定翻译，保留原文语境），日有武士小说，占着武侠小说的千年江山，但武侠小说对于中国文化来说，绝不仅仅是用文艺的形式呈现暴力。

武侠是驰骋幻想之地，也是我们认同彼此的精神故乡。
侠，是操守和血性的融合，他们守护道义，勇敢率先，肯于赴险，快意恩仇，来去于迢迢的历史，说之于世的想象。
武，是力量和境界的统一，江湖中有刀光剑影、神秘法力的强大，更有无招胜有招的修为，有心无无欲的高尚。
几乎每个中国人，心里都有一个仗剑天涯的武侠梦。
你可能想问：武侠小说我也看过，而且还没少看，为什么还要听你说？
你想过没有，为什么武侠能点燃所有人的情绪？在这个现象背后，有层次深化的文化、历史和社会原因。
这一次，我不只要为你讲荡气回肠的故事，还要把武侠小说的过往，放到整个中国文化的大背景里，和你说说这些门道。
我所说的门道，至少有三个层次。

# 第一，武侠小说是中国人有血有肉的生活史。

武侠小说给了我们一个历史爱好者的福音，说不定，它已经成了中国文化史里，一部新的史诗。颠覆要用同一套话语，证明同一个概念。
帝王将相，平头百姓多少，但近年流行的重大历史研究，隐约指向多少，但又过于抽象。
而真正属于平民大众的历史，就藏在武侠小说为代表的俗文学里。至今，它还没有被作为史料充分挖掘过。
我的这门课，先从秦代的荆轲说起，一直说到当下的网络时代。
我从两千年前为朋友报仇的刺客说起，一路到唐代剑侠高人的奇侠，从宋代的传奇小说，到民国文人的武侠小说，
通过这故事，我会为你拆解：
- 刺客在什么时代出现的？
- 江湖规矩到底是怎么形成的？
- 一侠偷盗御家飞贼为什么能出现在宋以后？
- 女性隐娘为什么独具魅力？

# 第二，武侠小说是中国世俗社会的独特写照。

别看“世俗”，“世”字拆开，就是三十年，是一代人的意思，引申为世间大众。“俗”指风俗、风气，也就是现实生活中的风俗文化。
世俗也可以说是中国文化的底色，也是活波的生活真相。
武侠小说是一面通达人心的镜子，映照出了世俗社会的独特算法。
我也会为你分析：
- 守信重诺为什么是江湖第一法则？
- 江湖人士的总是官府对着干吗？
- 黑帮大侠为什么去当青管堂？
- 韦小宝凭什么活得风生水起？
武侠小说里的青帮，往往和中国文化的独特面貌和底层逻辑有关。
世俗生活秘籍最中中国式的真相和意义，它是一团大杂烩，却不是个社会学，它会带着自己的立场诠释，帮你理清江湖表象背后的规则和逻辑。

# 第三，武侠小说是全球华人的共同文化记忆。

今天的华人遍布全世界，各自的生活环境已经有很大的差异，但金庸笔下的家化里的武侠精神，几乎成了一个最大公约数。
很多海外身位的华人父母，都用武侠小说作为引经，帮助他们中文化世界的最初兴趣，所以，你会在很大部分华语电影里出现。
- 港台新武侠时代是怎么来的？
- 为什么全世界的华人都爱金庸？
- 金庸笔下的英雄有什么现代元素？
- 古龙给武侠小说带来了什么新风？
当然，这门课，绝不仅仅是回望历史的怀旧旅程。
我还会跟你分析，源远流长的武侠文化，如何借助当下的电影、电视、游戏这些新载体，实现跨界想象。以严肃文学为标准，它还有哪些可能？
武侠小说虽然是中国特有的文化概念，但我不完全局限在中华民族的想象，我会带你看中世界的目光，跨对话去武林精神和其它文化里的侠义美学有什么共通？为什么在本质上不一样？
如果你年轻，没有沉迷武侠小说和电视剧的青春记忆，我也欢迎你开启这武侠江湖之旅。
毕竟，那些曾经让我深陷其中的人物和故事，已化身影响我的“王者荣耀”“仙剑奇侠”。
这是专属于我们国人的生活梦境。
在这条路上，豪情纵横，长风浩荡，有迷人的过去，也有玄幻的未来。
