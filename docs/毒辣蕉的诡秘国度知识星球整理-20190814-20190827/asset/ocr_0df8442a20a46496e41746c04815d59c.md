# 【目的与规则】

小红圈本身是弥补公号的不足而选择的一个分发渠道，它肩负有三大功能：

+   （1）公号被删文章在这里会重新上架，但对于VIP付费阅读的内容还是要进到VIP区看，两个平台的定位是不混淆的；

+   （3）四方蕉友的一个互动区，蕉友可以把自己的一些亲生经历的事发上来，但为了保证贴的质量，我暂时不会把贴全部公开，能选的都必然会有回复的。
