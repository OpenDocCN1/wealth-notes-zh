# 8、合理控制增长速度

很多人可能不是太理解这一点的意思是什么。我的企业增长不是好事吗？为什么还要慎重呢？我增长了，企业不就做大了呢？想要在现在这激烈的竞争当中生存下来，活下来，公司当然需要增长，但是，是不是咱俩就得这个勒紧裤腰带，去追求增长速度呢？这个不一定啊，超级品牌啊，一开始往往会慢慢的增长，精耕细作的，我们要打好基础，这对以后的长期发展来说，不用说都知道有好处，也有利于产品、使命以及品牌故事的完善，我之前在商业模式顶层设计那本书中曾多次强调：“当你的产品或商业模式设计出来后，首先得小范围测试，如果好，那就大量的复制和推广，如果不好，还可以及时的刹住车，调整过来，这样你的损失会降到最少”。其实呢，控制增长速度的另外一个体现，就是保持品牌的独特性，当中就包括坚持公司的使命。
