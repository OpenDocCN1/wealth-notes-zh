# 押金增值抵现策略：

将缴纳的押金进行金额放大，抵现金购买其他产品，这种促销的策略，我们称之为押金增值抵现。

# 案例：培训公司的押金增值促销方案

2013年年底，我在广州的培训公司招募营销合伙人，就运用了这个模式，当时我们通过QQ群持续预热20多天，预告接下来要推出的项目，当时每天都有很多人关注，欲望也逐步推高，都很期待本次网络的项目说明会。

在项目说明会的前几天，我们开了一堂公开课，在课堂宣布：“由于本次合伙人的项目讲解，只能分享给最有意向的人听，所以凡是想听项目说明会的伙伴，需要缴纳1000元的押金，在项目说明会结束之后退钱，并且我敢保证，仅仅听本次项目讲解，你就能学到很多营销运作的奥秘……”
