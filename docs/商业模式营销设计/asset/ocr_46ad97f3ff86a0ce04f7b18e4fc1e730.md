# 后 记：

传统的物质文明的进展步伐已经开始放慢，工业化已经将社会各项硬性设施布局完善，物质的野蛮增长期已经过去，中国未来社会的完善，离不开一批有“匠心”的人，也就是那些脚踏实地、精益求精、用心创作的人。比如工匠、程序员、设计师、编剧、作家、演说家、艺术家等等，因为互联网已经把社会的框架搭建完成，剩下的就是灵魂填充，各种人工智能的出现让人们生活的方方面面变得越来越便捷，但是，人工智能永远也代替不了人脑，目前的智脑暂无自主思维，而人脑的想像力和创造力是无穷无尽的，所以接下来将会诞生的是各个行业的灵魂人物，而不再需要凑数做粗活的泛泛之辈！因为现在，再也不是物资匮乏的时代，各个行业已经到了白热化竞争的地步，尽心尽力力求完美都未必能够从众多竞争对手中脱颖而出，而敷衍了事者也只会淹没在碌碌无为的人海中，奥运冠军中没有业余选手。我愿陪伴大家在商业这条道路上携手同行、精益求精，力求做到极致工匠精神，为祖国的伟大复兴添砖加瓦！
