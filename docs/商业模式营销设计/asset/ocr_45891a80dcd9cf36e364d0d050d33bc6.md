# 六、鱼塘途径—老客户

自古有云“物以类聚，人以群分！”，你的老客户身边，就聚集着跟他们有着相同生活条件和属性的人，我们可以利用老客户进行病毒式转介绍，这样每个老客户都是你的小鱼塘。

老客户推荐过来的人，对你的信任指数是极高的，他们现身说法，塑造产品的价值，能够帮助你减少大量的沟通成本。
