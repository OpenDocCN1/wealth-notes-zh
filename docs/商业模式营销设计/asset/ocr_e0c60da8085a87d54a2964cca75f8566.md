# 两个办法：

# 第一、坚持一个和社会或者环境相关的责任，

比如说农夫山泉的品牌使命：我们不生产水，我们只是
大自然的搬运工。

# 第二、重新制定一套新的标准。

比如说：星巴克，他们的使命是激发并孕育人文精神，为此呢，他们开始努力的打造欧式特色的咖啡厅，给他们的产品一些特别的名字，就连星巴克的大小，中杯的这个说法也跟别人不一样，叫法都不同，而这些，都成了星巴克的代名词，让这个品牌在市场上占有一席之地，而这个标准啊，就属于星巴克的。

我们想想，我们想要打造自己的高端品牌，那他的独特使命是什么呢？比如说我们改变世界商学院的使命是：让人类更文明，更进步，打造一大批威振全球的民族品牌。

# 做企业必须要从长远规范，并坚持你的使命！
