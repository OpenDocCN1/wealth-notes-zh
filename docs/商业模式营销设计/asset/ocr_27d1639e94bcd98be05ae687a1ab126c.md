# 二、思路决定出路，“营”在思维

我们如何去理解这句话的意思呢？

比如说，你想去掌握某种技能或是购买一件商品，首先你得想有这方面的需求，接下来你就会去寻找到能满足你这需求的商品或是课程。最重要的是不是商品身，而是你对这件商品的思维才决定了你的购买行为。人的行为是由情感驱动，而情感是由思维驱动的。行为的激发过程是“思维—情感—行动”，所以说思维才是最重要的。

我们在买一个实实在在的东西的时候，通常会先考虑如：“什么样的东西是好的，什么样的东西是不好的”，“什么样的东西有价值，什么样的东西价值”等，这就是思维的组成模式。再如“你使用了这个产品，能够达到什么样的理想状态”，“使用这个产品需要注意什么细节”等等，这些都是思维模式。所以，我们一定要牢记：我们卖的不是产品，而是客户需求的解决方案。
如果我们掌握了如何去影响客户的这种思维模式，就决定了客户会不会选择你，并且立即采取某种行动。这一点非常重要，我们通常表述为：用你的思维，去影响客户的思维。所以，要想给自己的企业设计一个好的营销模式，就需要研究客户行为背后的动机，然后转化到自己的营销方式上。
