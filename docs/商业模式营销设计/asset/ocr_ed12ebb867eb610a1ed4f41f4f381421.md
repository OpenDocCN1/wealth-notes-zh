# 导 读：

可以说，这些无与伦比的商业案例研究是一笔巨大的信息财富，为此，你应该立即开始采取行动：

首先，“粗略地”通读一遍这本书。用即时帖对那些适用你本人、你的环境或事业情况的案例研究做出标记，放在案头或随身携带。随着进一步的“精读”和领会，继续找出能够针对自身的具体情况来借鉴和采用的营销模式。在这一过程中，基于时间、可用资金、努力程度、最有创造性的案例，最终找出与自我行业相似，能够模仿的那些案例研究。

在仔细研究上述这些案例的基础上，标出案例中成功的基本要素。并试着提出问题，如“这对我有什么启示？”“是什么模式、战术或动力使之成功？最重要的是我能从中学到什么，对我的事业有什么启示和适用性？”。

接下来，拿来笔和纸，优先记下我想要“创造性地应用”的那些案例模式。基于执行的容易程度和时间来将其排序。

最后，为我想要实施的每个策略建立一个详细的计划，确定何时实施。并根据具体情况进行测试、优化、改进，直至最终从中获得最大价值。

在此祝愿你所有的努力都能得到巨大的回报！
