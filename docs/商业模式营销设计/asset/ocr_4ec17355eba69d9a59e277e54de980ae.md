# 3、被动压力营销

他们都买了，你还不买吗？
大家都没有想过，为什么一群鸟可以整齐划一的飞行？一群小白蚁，能够建造巨大的蚁丘呢？科学家发现这其实靠的是一种集体意识，每一个体通过模仿其他个体，最终协调出一致的步伐，咱们人类也同样，凑热就是这么回事儿。如果你走在大街上，看到一堆人都在看着同一个方向，这时候你就会忍不住也过去看一下，这就是一种从众心理的表现。

科学家们做过这样一个实验，让 200 个人在房间里面自由走动，其中 10 个人被明确告知要往某个方向走，有了这么一个小个团休的带头，没过多久，大家就都朝着这个方向走了。这种现象就是所谓的同伴压力，为什么会这样呢？因为咱们人是社会动物，每个人都会本能的希望融入到群体当中，一但我们被排除在外，就会感觉很不舒服，因此在同伴压力的影响下，别人有什么，你也想要什么。比如在另一个实验中，在一个房间里发饼干，一开始只有 1/5 的人想要，接着呢研究者让一个托，进入房间里主动去拿饼干，结果呢，一开始没要饼干的纷纷起来自己去拿了，那如果把饼干换成商品会怎么样呢？其实结果是一样的。
