# 17、为顾客提供某种超水准的服务

你可以给顾客承诺，但你最好让你的服务的实际水平超出顾客的企盼。永远超出顾客的企盼，这是很重要的。

# 18、你要愿意把一些费用投资在数据软件上，用来分析和顾客相关的数据，尤其是那些真正的大顾客那些数据显示没有再回来的顾客，你要想办法和他们保持联系，让他们可以重新回到你的身边

# 19、引用别人的成功概念和策略协助自己，让自己的营销策略可以获得一定程度的提升

# 20、要向更多人推荐你的产品

名人的认可很重要，因为很多人还是会相信公众人物的推荐。所以看一下你的行销系统里面是否有名人见证这个部分，是否缺乏这方面的内容，或者比较薄弱。如果比较缺乏或者比较薄弱的话，你就要收集更多的名人见证。
