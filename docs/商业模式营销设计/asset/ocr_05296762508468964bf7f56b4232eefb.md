# 二、设计客户心中的梦想蓝图

# 1、什么是梦想蓝图

佛教的终极蓝图：西方极乐世界。

基督教的终极蓝图：天堂。

蓝图就是客户心中想要实现梦想。你需要用简单的语言告诉客户：“使用我们的产品之后，你能够得到什么样的好处。”人们对梦想的追求，对未来的幻想，是永无止境的。我们都希望自己的未来是光明的、清晰的，但是大部分人是想不清楚的，没有清晰画面。如果你能够给他一个明确、清晰的描绘：“未来你将达到什么样的状态”，威力将是十分巨大！就像我和一诺老师共同创立改变世界商学院，我们也规划了一个蓝图：“致力于帮助中小企业走出困境，打造更多的民族品牌，造就一大批威震全球的企业家队伍”！这是很多中小企业家的梦想。很多人去创业、做老板、经营企业，做了一段时间后，发现梦想很美好，然后现实却很残酷。当初创业时的满腔热情，最后却被现实磨得身心疲惫。这时候，他们最需要的就是找到一种好的商业模式，让自己的企业走出困境，做强做大。这就是改变世界商学院的蓝图。
