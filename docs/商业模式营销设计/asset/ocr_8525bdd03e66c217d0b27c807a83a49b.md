# 前 言：

“道”是中国（含东方与西方）哲学的最高范畾。“道”的概念是老子第一个提出来的：道生一，一生二，二生三，三生万物。由此可见：天地万物都是由“道”而生。“道”字的本义是运动的源头，即太阳，上帝。这就是天地万物的本源，即终极真理。鲁迅先生曾说：中国文化的根底，大抵在道家。这话一语中的，非常正确地指出了中化文化的起源。人类对道的追求最高境界是“明道”。像太阳那样发光发热，照亮人间，无私奉献，温暖他人，商业上大致解释为“利他”精神。

道，自然也。自然即是道。自然者，自，自己。然，如此，这样，那样。一切事物非事物自己如此，日月无人燃而自明，星辰无人列而自序，禽兽无人造而自生，风无人扇而自动，水无人推而自流，草木无人种而自生，不呼吸而自呼吸，不心跳而自心跳，等等不可尽言皆自己如此。因一切事物非事物，似乎有所统御，一切不约而同，统一逍循，无有例外。不生不灭，无形无象，其大无外，其小无内，无所不包，恒古不变。其始无名，故古人强名曰：“道”。

一切事物，只有遵循自然规律，才能繁荣昌盛，违背规律者，无一例外，终将烟消云散！让我们由此揭开商业的秘密…
