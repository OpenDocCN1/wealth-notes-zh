# 三、营销中常犯的错误

在营销中的错误，看起来非常简单，但影响却很大。
请记住：如果الحق犯了错误，那就立即停止。每一个错误就是你改进的机会（成功就是不断试错的过程，但是我们也可以通过正确有效的学习来尽量避免此类的错误）。这些错误是很多的企业家，不管他是有多大，有多小，或者是零售还是批发，或者服务业等等，都可能犯这些错误。所以你不要觉得只有小企业才可能碰到，大企业同样也可以碰到。接下来，我们找出一些典型的常见错误进行分析。

# 1、营销计划没有经过测试和验证

在无形当中，我曾经了解、分析、检查，价值百万以上的这种营销方式，广告的宣传方式我研究过，做过各种各样的测试，从一种方法换成另一种方法的测试，不同的销售、在客户服务、在制造业，在产量做过很多种测试。当你用不同的方法测试比较的时候，你会发现一种方法比另外一种会带来很大的好处。比如，如果在广告中做个调整，就能使广告产生几何式倍增的效果；如果是在营销方案当中，把你介绍的主题内容写对了，就可能会有3、4倍的人来关注这份文
