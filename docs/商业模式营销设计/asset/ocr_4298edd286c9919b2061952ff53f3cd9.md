# 2、劫流

劫流就是直接“打劫”同行的客流，在外界看来是比较阴险的手段，不过商场如战场，只要不触犯法律，不损害客户利益，就可以操作执行，劫流策略只要执行到位，是将非常厉害的，吸引的全部是精准客户。

# 案例：电动车店的自动化客流引爆模式

有一家新开的电动车专卖店，由于地理位置比较偏，没有在电动车销售集中的市场，所以业绩一直不理想，投了上万元的DM广告费，结果才卖出去了3辆车，一直处于亏损状态。

经过我不到20分钟的指导彻底解除了他的困惑，并实现了自动化客户倍增，下面是咨询对话全过程。

我：你说现在最缺的是客源，我想确认一下，你的成交率有多高？电动车老板：我自己本身是电动车维修出身，并且算是电动车发烧友，不管是电动车的性能调试把控，还是电动车改装，我都能一并解决，只要是购买电动车的准客户，60%的成交率是完全没有问题的！
