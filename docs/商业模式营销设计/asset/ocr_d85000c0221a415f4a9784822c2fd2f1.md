# 2、顾客需要、欲望及需求的商业价值应用

顾客需求——当有购买力做后盾时，欲望就变成了需求：

如：满汉全席，蛋炒饭

顾客欲望——指顾客需经由文化和个性塑造后采取的形式：

如：顾客饿了，有吃的需要，就形成以下形式：

+   1、满汉全席；2、蛋炒饭；3、面包。

顾客需要——是指顾客感受到匮乏的状态：

+   1. 对事物、衣物及房屋等物质生理需要；
2. 对安全的心理或物质需要
3. 对亲密忠诚和慈爱仁义的社会需要
4. 对知识和自我表达的个人（自尊或自我实现）

需要本身，并非是企业创造出来的，而是人类自身本能意识的基本组成。
