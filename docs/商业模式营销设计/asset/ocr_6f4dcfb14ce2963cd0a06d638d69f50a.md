# 三、超值折扣策略

通过上一节，我们知道了无痕迹引导销售的基本要素，在销售时到底用什么促销政策，才能实现无法抗拒的成交呢？常用的策略有五种，分别是：超值折扣、超级赠品、增值抵现、整体部分、诊断+方案，前面三种更多的是以价格优惠政策入手，后面两种则需要一定的布局策划，下面逐个展开讨论。

超值折很容易理解，持卡过来的顾客由于特殊的身份，可以享受到其他人无法获得的折扣待遇。

常用的超值折扣有两种形式：产品折扣和会员卡折扣；

产品折扣指的是，购买主营产品，在原价基础上享受优惠，比如，原价68元的火锅，现在只要48元就可以获得，或享受全场产品的7折优惠，这个非常容易理解。会员卡折扣指的是，不对引流进店的顾客销售产品，而是让他充值会员，今后享受到会员的超值折扣待遇。
