# 4、营销数据收集

如今的科技这么发达，什么大数据啊，人工智能啊，都让我们生活越来越方便，那么这也给了品牌更多操纵我们的机会。为什么这么说的？，大家平时上网购物的时候，可能都留意到页面，最下面会有一栏推荐商品，说你可能会喜欢哪些？我们仔细看一看之后，好像真的都是我想要的，大家有没有纳闷，他们怎么会知道我想要什么呢？这秘密就在于数据，不管你是在搜索引擎上查了点什么，还是在微博上发的东西内容，不管是在手机上查地图导航，还是在音乐网站上下载了一首歌，只要是在互联网上留下的痕迹，所有这些都会被数据收集公司给默默的收集起来，分析处理信息，然后一转身把这些数据卖给营销公司，你需要什么？想要什么？你的梦想，你最关注的事情和商品等等，包括你身体有什么疾病，你什么时候该吃药了，他们都知道，甚至比你自己记得还清楚！

商家利用这些信息，就能让你乖乖的掏钱，这个过程就叫做数据挖掘，说得好听点叫做消费者洞查。这种行为，就是利用对消费者行为的追踪和分析，更好的说服和操控人们购买商品。
