# 6、需要用符合期望值的产品维持声誉

好了，现在有了引人入胜的品牌故事了，那新顾客是兴趣满满的想要了解你的公司以及你的产品，怎么样才能保证他们看完之后真的会消费呢？我们要记住最重要的一点，超级品牌，你首先要能提供超级产品，也就是说啊，你故事讲得再好听没用，吹牛逼的。产品拿得出手那才行，产品得要货真价实，要不然你光说空话，你拿出来的产品一碰就碎，那不就成了自食其言了！

假如说你先给品牌设立了神话般的光环，但是最后产品没能达到，或者没能超过顾客的预期，那么这永远也成不了超级品牌的，这一点我们必须要牢记啊，一诺老师的课程中有说过，一个 100 分的商业模式+0 分的产品=0，我们做事一定要以终为始，不忘初心啊，不要搞了一大堆的各种设计、营销、到最后产品本身出了问题那就是个大乌龙！超级名牌也不是光靠广告吹出来，所以我们要用符合客户期望值的产品来维持良好的品牌声誉。
