# 1、礼品领取时间

礼品领取时间的选择非常重要，你要想明白，持引流卡过来的潜在客户，是随时享受服务，还是固定时间享受服务，要考虑到自己与顾客的便利性及节奏紧凑性。

自己的便利指的是当顾客持卡过来的时候，是不是店里的高峰期，如果人手不够，却在高峰期来了大把的人，就会导致场面混乱，很难完成后续的跟进与成交动作。

顾客的便利指的是他们的闲余时间，比如，你把日期设置为本周六之前持卡即可享受服务，结果目标人群大部分只有周日空闲，那么就会出现冷场或者领了礼品之后匆忙走人的局面。

节奏紧凑性指的是连贯程度，如果引流卡发出去之后，虽然60%都生效了，但是陆陆续续分批一个月才领完，就很难形成轰动效应，整个引流就会显得零零散散，所以控制多长时间完成每一轮的引流活动非常关键。
