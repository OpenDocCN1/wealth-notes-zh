# 二、四重引导销售

持引流卡过来的潜在客户在领取礼品或接受服务时，绝对不能赤裸裸的强制销售，而应该通过巧妙的引导方式，实现无痕迹销售。

下面为你分享引导销售的四个关键要素：

# 要素 1：身份感

如何体现身份感？比如，理发店赠送的烤鱼卡，在顾客持卡点完菜后说：“由于您是我们合作单位**理发店过来的贵宾，理发店的老板在团购我们的烤活鱼卡时，特意跟我们达成了协议，只要他们店过来的贵宾客户，除了特别招待之外，您还可以获得一次任何人都享受不了的优待……” 通过这句话术，对方瞬间有了一种身份感，也为你促销产品给了一个非常符合逻辑的理由。

# 要素 2：稀缺性

人群限制、赠品数量有限、产品数量有限等，都能营造稀缺的氛围。
