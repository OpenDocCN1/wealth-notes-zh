# 7、坚持企业使命

既然我们的品牌想要标新立异，引领潮流，那么，还有一部分群体是不能分开的，那就是公司的员工，你想想，在这样的公司里，公司的员工还会像传统的公司一样，每天坐在格子间里，朝九晚五的干活吗？这恐怕很难啊。

公司的日常运作，要符合品牌的使命和故事。

这个使命和故事体现在哪呢？首先，就是企业文化，你想想，这公司企业文化有了，但是，要是连员工都不实现品牌的理念，那消费者就会觉得这公司不够坦率，那你辛辛苦苦打造的企业故事，也就没人相信了对吧？所以我们一定要说我所做，做我所说！对于一些想打造酷炫形象的品牌来说，这一点特别关键，你想想，你这形象都酷炫了，那这工作环境不能不酷炫吧，那我们可以用别具一格的工作环境，来吸引一些充满创意，独立自主的员工，他们，也得酷炫，这样一来，你的品牌形象不就全面了嘛！这员工和环境也帮您实现理想中的公众形象了，除了员工之外，还需要一个合适的商业伙伴，把这品牌的使命，转化成能够赚钱的商业决策，
