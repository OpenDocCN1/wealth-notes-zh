# 案例：微信第三方平台的销售解决方案

有一个专门给商家做微信网站的企业，虽然技术一流，但在拓展业务的时候，收取商家几百元都成了很困难的事情。

为什么会这样，因为他们是在卖产品，而没有想到为客户提供一套解决问题的方案，要知道，客户购买的是结果，而不是一个简单的网站，如果能够让商家清晰的感知到，你的平台能够轻松实现商家渴望看到的几个场景，那么销售起来将变得非常简单。
