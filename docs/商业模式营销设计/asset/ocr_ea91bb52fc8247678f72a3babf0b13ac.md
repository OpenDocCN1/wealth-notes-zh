# 6、明确说明产品和服务能满足顾客哪些需求

很多人跟你握手之前，已经被握过很多次手了。在你拜访他之前已经有很多人拜访过他了。可能他对此产生了 quiz 的恐惧跟挫败感。你的任务是让他知道，这次你终于遇对人了！就像一个女孩子谈了很多人恋爱，受了很多伤害，最后终于遇到了白马王子，她这一生大概都会跟着这个人了。

# 7、把一个和你有关的故事讲给顾客听和营销有效结合

人人都喜欢听故事。你们有没有注意到，海尔就讲了一个很好的故事。海尔人反复讲述当年海尔把品质不好的产品搬出来用铁锤打烂的故事。这个故事就代表了海尔对品质的专注。肯德基也在说故事，说他们的炸鸡配方。可口可乐也说故事，说他们那个神秘的配方。所有成功的品牌都在说故事。你们要做的事情是给你的顾客讲一个最好的故事。这就是为什么那么多企业在广告里都用顾客做产品的见证，因为这就是故事最重要的一部分。
