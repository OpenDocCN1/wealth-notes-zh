客承诺：“你使用我的东西如果无效的话，我可以按原价退款。”当一个人得到这样的保障。就算是他后来真的因质量问题来退款也不会有太多的抱怨。而且这种情况通常会为你增加更多的销售量。为什么？因为人家看到的是你的信心、你的保证。信心就是能有这么大的能量。对自己的产品有信心，这是很重要的。

# 4、跟顾客保持长期的利益关系

你要随时随地通过你的服务帮助顾客创造他的价值，让顾客觉得，因为他成为了你的顾客，所以他也成为了收入更高的人。在我们的学员当中，我们经常会准确的调配各方资源，为学员们搭建好资源网络，高学习变得更有价值。你愿意主动去帮助顾客的时候，你跟顾客的关系就会变得更好。

# 5、开始去考虑要不要做更多的广告

比如网络广告你可以考虑去做，它是不必付费的。你要通过好的模式，把你的广告打出去，这样可以影响更多人。
