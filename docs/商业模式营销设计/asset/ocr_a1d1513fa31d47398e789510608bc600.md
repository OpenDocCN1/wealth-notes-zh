# 4、找到高端和亲民的平衡

当一个产品进入大众消费市场的时候，经常会出现一个情况，就是变得烂大街了，随处可见，谁都能买，那这么一来呢，这个品牌啊，也就不再特别了。

我们都知道哈根达斯冰淇淋啊，不过还有一个品牌您可能不知道，他就是美国的第二大冰淇淋制造商，斑杰瑞公司。这个斑杰瑞冰淇淋在很多地方都能买到，但是他依然保持着很酷的形象，怎么做到的呢？这就是打造超级品牌的第二个秘诀：找到专享和亲民之间的平衡！这个平衡点怎么找呢？我们来看看他们是怎么做的。
