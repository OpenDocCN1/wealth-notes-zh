# 3、确定品牌的独特使命

在物质泛滥的今天，你说一个产品他光是好看好用，就能打造出高端品牌吗？那是远远不够的，现在的消费者，他喜欢那些有内涵的东西，他觉得，要让自己花的钱啊，变得更加的有意义，所以，为了在激烈的市场竞争当中，脱颖而出，你的企业首先需要定一个，不惜一切代价去坚持的目标，这就是打造超级品牌 dog的第一个秘诀，确定品牌的独特使命。

既然我们知道客户想让自己的消费更加的有意义，咱们就问问自己，激励品牌存在的力量是什么，这背后有什么鼓舞人心的故事呢？当然啦，话说白一点啊，这大多数公司做生意不就为了赚钱吗？这个我认为对也不对，但是一定不能这样说。如果你把公司的宗旨定义成我要赚大钱，你说哪个消费者会买你的帐呢？至少这些有口味，高端的消费者是不会买啊，相反啊，咱们不要老想着挣钱，而是去找到一个更加有意义的目标，就算是这会让公司损失掉一批客户，但是我们做企业必须要从长远来，不是今天卖完一批产品明天就关门了，所以我们就算内疚也得去干！
