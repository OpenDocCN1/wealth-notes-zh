# 搞定鱼塘合作的话术模板1

很多高手不会以自己店里的名义谈合作，他会以消费者讨价还价的形式先做试探，这样能够减少对方的防备心理，并让他主动接见你，下面是对话参考。

高手：你这个产品太贵了，如果能送几十块的礼品，我感觉更容易促使我们购买！

塘主：这已经是很低的价钱了，我们的利润很低的！
