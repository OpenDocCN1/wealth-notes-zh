# 5、怀旧营销：

过去的总是最好的。卖的就是一种情怀，儿时的记忆，妈妈的味道。

看到这里大家明白了我们无论是对风险的恐惧还是对愉悦感的追求又或是想要融入集体的欲望，都能被品牌营销利用，促使人们去各种买买买。不过呢还有一种营销也会让我们把持不住，那就是：“回忆杀”！

人的年纪一大啊，就喜欢回忆往事，过去的照片、歌曲都能够让我们感慨万千，小时候吃过的东西，玩过的游戏，看过的电视节目，往往会给我们带来一种非常美好的感觉，那我们为什么那么喜欢怀旧呢？科学研究发现：沉浸在回忆里边能够改善情绪、提高自尊心，还能够加强人际关系，说白了，就是让人更有幸福感。另外，回忆一段美好的经历，会比当时带来更强烈的愉悦感，所以说，怀旧对身心都有好处！那么商家是如果利用这一点来进行品牌营销呢？通过重现曾经的影像、声音、和感觉向消费者出售产品，他们宣传的关键，就是抓住我们记忆中的某一个美好瞬间。从而引发独一无二的情感体验。
