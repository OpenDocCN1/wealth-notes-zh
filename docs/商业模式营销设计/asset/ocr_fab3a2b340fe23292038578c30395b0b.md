# 5、被充分利用的销售渠道

通过终端零售渠道，充分利用跟终端零售的关系，然后来改变业务模式，一定要意识到你有怎样的分销渠道，哪些渠道你没有充分利用的，同学⼉可以作好相关的记录并进行梳理、排列后重新制定你的渠道战略。
