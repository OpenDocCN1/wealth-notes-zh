# 5、需要深入人心的品牌故事

这就得要从人类围在篝火旁边讲神话故事，神话传说开始，讲故事就成了社交里头不可或缺的一部分，看过人类简史那本书的同学们应该知道，我们人类并不是地球上最强大的生物，但是为什么如今人类统治了地球？是的，就是因为人类创造了语言，学会了讲故事的能力！人们通过使用语言和讲故事组成了社会，有了国家，有了民族，有了宗教和信仰，有了道德和知识。我们掌握的一切技能都是听来的，比如成语故事，历史故事之类就像小时候你的父母告诉你：这个不能做，那个不能吃等等。。。！所以说，我们不是活在真相里，而是活在印象里。

在商业领域里，讲故事同样有着强大的力量。我们千万不要小看了讲故事的能力，更应该去学习如何讲好故事，在一诺老师的校长秘训班上，就有详细的步骤，一步步教你如何去讲故事，如何通过讲故事来提高营销的能力，以及让你的产品深入人心！如果说，你能够抓住人们对故事的热爱，再加上对意义的追求，那就有提升品牌声誉的强大武器。
