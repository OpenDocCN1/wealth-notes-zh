# 锁定鱼塘合作的话术模板 3

前面的两套话术是以顾客的身份进行沟通，本套模板为你展示的是以策划人员的身份整合鱼塘的话术。

策划人员：您好，我是浪淘沙理疗会所那边的，我们店准备过两天做活动，这里有一张卡，到时候持卡过来，可以免费享受市场价40元的能量药疗养肾服务，我们老板经常来您这里消费，所以特意要我给您送一张过来，邀请您参加我们的活动。

塘主：真的免费？不额外收费？

策划人员：当然是免费，老板特意要我来送给您的！

塘主：谢谢你啊！

策划人员：其实我是专门给浪淘沙理疗做策划的，我给您提个建议，或许还能让您借助浪淘沙的活动小赚一笔，我放一些卡到您这里回馈客户，您就说这些卡是自己花钱买的，反正你的同行那里没有，客户关系不就维护好了吗？你也可以挂个横幅在门口搞促销，进店消费就送服务，这样不就促销了你的产品吗？
