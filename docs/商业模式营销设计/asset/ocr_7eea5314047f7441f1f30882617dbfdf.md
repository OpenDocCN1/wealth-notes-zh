# 2、必须自己成一派

1873 年德国的哲学家尼采提出了一个著名的“超人学说”，什么叫超人呢？它构建了一种理想，而超人人格特别多，总是走在大众前列，有着自成一派的规则和价值观，这就叫超人。而在商业领域当中，这个超人学说也能用上，这个尼采口中的超人正如现在的高端品牌、超级品牌，他们呢，坚持自己定下的原则和理念，绝对不会追求那些，泛泛的，早已经存在的，满大街都有目标去发展。比如做汽车生产的，我要成为市场上速度最快的汽车；或者做餐饮的，我要达到米其林三星的餐厅级别等等；这些啊，其实也没什么毛病，但是我们不觉得这有点俗吗？说白了，想要打造超级品牌就不能按照别人的标准来，而是要自己来另立卓越！

那什么样的品牌才能算得上是超级品牌呢？
