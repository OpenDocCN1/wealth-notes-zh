# 1、恐惧营销

害怕吗？那就买吧！可能每个人都有恐惧或者说害怕的东西，比方说怕蝉螂，怕蜘蛛，怕看恐怖电影，怕黑，不敢走夜路，不过这些恐惧啊都比不上担心生命安全受到威胁，所以很多人愿意付出很大的代价去避免这种风险，什么买各种保险啊，还有很多各种保证安全的产品啊，也不管有没有用，反正呢为了自己和家人的人身安全很多人就会疯狂的买买买。

那为什么会这样呢？问题出在我们的大脑，正常的情况下，大脑会利用前额页做出理性的判断，但是在生命安全遭到威胁的时候，大脑当中负责处理恐惧情绪的区域，也就是杏仁核会被激活，他的反应速度要比前额页快和多，导致我们没有办法去理性思考，最明显的一个例子就是除菌洗手凝胶，每次出现全球性传染病暴发，比方说：流感，人们就会一窝蜂的去买洗手液，像机场，酒店，这些公共场所也会提供，大家这么做啊，无非就是不想得病。但是事实上，并没有证据能证明洗手液能有效抗击空气传播的疾病。最后，唯一得到好处的就是卖这些除菌产品的公司。还记得当年非典时期，全国上下疯抢板蓝根和白醋也是这么回事，其实这些都
