# 一、商业的本质

我们可以先谈谈商业经营的本质这个问题，有的人可能认为：
“无奸不成商”，对此本人完全不赞同，此观点可以说误导了一代又一代的人！从历史长河来看，最原始的商业应该起源于原始社会后期，当人类生产出现剩余的时候，出现了物质交换，那时候的商品交换是不存在欺诈的，因为大家都是面对面交易，所有的交换物品都是实物交易，自然不存在欺诈行为，大家都是非常讲诚信的。随着人类的进步，特别是思想的进步，生产力的发展，商品交换逐步普及，特别是到了近代及现代社会，商品交换的频繁，并为了便于商品的流通而出现了货币，由此应运而生的商业经营这个行业，吸引了大量的从业人员，也发展成为了社会生活的主要组成部分，商品流通成为人类生活中不可替代的部分，而此过程中也出现了大量的靠暂时的蒙骗和欺诈作为经营手段的经营者。
