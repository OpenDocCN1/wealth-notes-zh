# 有没有想过换个全新的自己？

我们中有些人，对我们的汽车和电视机的关心，比对我们自己的关心还多。汽车上轻微的刮伤，我们都要立刻送到服务站去维修。电视屏幕上，轻微的颤动，我们也要给维修商打电咨询。

给我们最宝贵的财富，我们的身体以同样的关怀，难道不是常识吗？

汽车，自行车都能换全新的。但是你不能换个全新的自己。你不能买一套全新的神经系统，一个全新的头，或胃。

你说，“乔应该看看这个信息”的时候，请停下来！这个信息是给你的！你可能也犯着同样的错误……

通常，你身体的“不适”——失眠，易怒——很容易调整好。
