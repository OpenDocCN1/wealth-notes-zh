於遵循下列 5 個步驟。

+   ①說服他人的五大要則

+   ①提出能引起聽者注意的故事或訊息

+   ②提出需要解決或回答的問題或疑問

+   ③對所提出的問題提出解答

+   ④具體說明提出的解答中所能帶來的好處

+   ⑤以行動號召

在有限的時間裡，卻又必須針對各式各樣的案件進行檢討會議或發表簡報時，必須如①中所提醒的，若話題中沒有能勾起聽者有興趣的內容，那麼對方也不會對你的話題感到興趣。除此之外，提出對方的問題點以及問題的解決方案（②③），讓對方能想像得到解決問題後所能帶來的具體效果（④），藉此來促使對方跨出行動（⑤）。
