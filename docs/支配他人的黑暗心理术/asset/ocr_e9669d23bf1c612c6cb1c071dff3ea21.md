# 你也正受到操控?!潛藏在超級市場中的心理術陷阱

不僅在政治領域，心理術正被活用在我們日常生活中的各種場合。例如：大家

日常生活中常去的超級市場。你是否察覺到，幾乎所有的超市或購物中心，都會將

店裡的客戶動線設計成「靠左側」呢?

當人類往心臟所在的左側方向移動時，容易對周遭的空間產生舒適的感受，相

反的往右側方向移動，則會覺得不自在。據說這個設計便是源自於這樣的人類心理。

也就是說，要讓客戶感覺店裡是舒適的空間，並延長停留在店裡的時間藉此提高銷

售量，因此才設計出這樣的動線。

此外，水果或蔬菜的販售區一定會在超市的入口處，也是一種基於人類心理的

銷售計畫。

這是因為心理學認為，人類會受到「顏色」所帶來的各種影響。因此在居家或

公司等多種環境中，皆使用了要讓人們更舒適且有效率的活動，被稱為「色彩調節」

的技巧。

例如：紅色或橘色等暖色系的顏色帶給人溫暖或正面的感覺，相反的，藍色或

綠色等寒色系的顏色則給人冷靜或涼意的感覺。
