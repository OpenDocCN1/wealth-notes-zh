# 【3】 支配他人的黑暗心理術
Psychological tactics to control others

「單純曝光效應」，或是藉由誇示品牌魅力等方式讓消費者對該商品的優越性有所

認知的「月臺效應」（Halo Effect）等，廣告就是巧妙地利用這些方式來刺激消費者

的購買慾。

大家是否曾在電視上看過，請來上班族或家庭主婦暢談商品功效的健康食品廣

告呢？當人們在認同對方與自己為同類型人物時，便容易增加親密度，而這種廣告

手法便是利用了這種稱為「類似性法則」的技巧，目的就在使觀眾對於廣告的演出

人員產生親近感，進而對商品也產生親近且隨手可得的感覺。

此外，美國的深層心理學家歐內斯特·迪希特（Ernest Dichter）則認為廣告應該

要切合消費者的深層心理，他曾說「在人類的心理裡，快樂與罪惡感隨時都在衝突著。

身為廣告人最重要的工作，不是將商品銷售出去，而是帶給消費者合理的安心感。」


迪希特將這樣的想法運用在糖果的銷售上。在一九五〇年代的美國，添加了砂

糖的零食被認為是形成蛀牙及肥胖的主因，因此造成了零食的銷售銳減。迪希特就

在大糖果盒中裝入可一口吃掉的小型糖果，並將這樣的零食進行販售。然後，消費

者的心中便開始產生了「我只吃一口而已，其他的可以丟掉」的安心感，結果也讓

糖果的銷售量直線上升。

像這樣探索出消費者內心深處對消費行為產生動機的手法，稱為「動機研究」
