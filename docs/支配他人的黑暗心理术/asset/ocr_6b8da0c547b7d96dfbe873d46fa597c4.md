# ④公共距離（Publicdistance）：3.60m以上

無法觸碰到身體的距離。在商務的場合或與上司對應時所維持的距離。

在演講等正式的場合，能夠面對面的距離。如同演講者與聽眾的關係，基本上與對方是不相識的關係。

由於在握手時能夠自然地築構起②的關係性，因此距離感一下子就會被縮短。

此外，在握手的時候，最好確實握緊並維持三秒左右。如此一來，被握的對方會覺得你很積極，同時也會留下好的印象。開幕的握手不但能贏得對方的信賴，更是能巧妙掌握對話主導權的第一步。在有利益關係的商務場合更是如此。想要讓交涉成功的時候，採取主動的姿態將會更加奏效。

# 在發表簡報時，能抓住對方視線的誇張肢體動作

「那個人的簡報做得真好！」當你這麼想時，表示對方的簡報一定相當有說服力，而且重點是容易使人印象深刻。
