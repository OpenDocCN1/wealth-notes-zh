# 支配他人的黑暗心理術

然而，黑色並沒有因此而遭到埋沒。相反的，黑色是無論在任何場合都能展現存在感的色調。正因如此，當你希望自己獲得信任，並且成為對方無可取代的存在時，就可以寄託於黑色。

黑色並非能動搖情緒的顏色，但卻能代表現出威嚴、氣度及穩重感，為人所帶來實際的價值感。

尤其全身穿著筆挺黑色套裝時，任誰都會感受到那股氣勢。商務人士的所穿著的套裝，以深藍色最為常見，正因如此，換上一套風格截然不同的黑色套裝，才能顯示出與其他人的差異。在進行像「關於這點絕對不退讓」的問題交涉時，以黑色為基調的裝扮風格前去，更具有效果。黑色不但能向對方展現威嚴，在與客戶交涉的過程中，也能將事物引導至有利於自己的方向。

此外，總理大臣、法官、教授、社長等社會地位較高的人士也大多給人穿著黑色的印象。黑色也同樣能顯現出各種幹練的氣度。

其他在出席一些正規的活動或婚禮、喪禮等場合時，也會使用到黑色。以往人們對於黑色服裝的印象，大多停留在參加婚喪喜慶時的裝著，在商務場合上黑色並不受青睞。但是，現代的時尚風格多變，同時也設計出不少帶有都會感的黑色外套或黑色套裝，一改以往帶給人只限於參加正式場合或喪服的印象。不如試著尋找一
