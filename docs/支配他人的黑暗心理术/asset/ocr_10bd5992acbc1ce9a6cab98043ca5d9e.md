# 巧妙活用顏色來製造氣場

你知道美國的曆屆總統，都有著一套在關鍵時刻用的決勝服嗎？那就是「白色襯衫」、「深藍色西裝」、「紅色領帶」。據說這樣的搭配能將顏色的特徵與效果發揮到極致。這也表示，顏色帶著各種不同的特性，並且暗藏著不同的效果。

上述的搭配正是美國總統的決勝服，白色襯衫代表清潔感與氣質品味，同時象徵了永遠；深藍色西裝代表冷靜沉著與才智，也具有男人味；紅色領帶則展現了熱情。除了考量到顏色的搭配，整體上也給予人正統的安定感，領帶則使用了代表熱情的紅色，是相當具有效果的組合搭配。

除此之外，從心理學的角度來看，綠色代表了安定與協調、黃色代表希望與光芒、紫色代表高貴與欲求不滿等，隨著顏色的不同也帶給人不同的印象。

若在與人見面時，能夠根據狀況巧妙的將顏色搭配使用，就能在該場合中帶給人深刻的印象。

例如：與第一次合作的客戶窗口打招呼時，可以穿著淡綠色的襯衫帶給對方安心感；在進行簡報的時候，則繫上紅色領帶一決勝負。此外，在暗罪的場面時，可以繫上藍色或灰色的領帶來達到緩和對方情緒的效果，到了晚上被邀請出席宴會
