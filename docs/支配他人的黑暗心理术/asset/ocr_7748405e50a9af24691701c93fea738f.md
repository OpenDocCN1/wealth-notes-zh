# ① 視線朝上、左上、右上移動時

當浮現視覺性印象時，視線會向上移動。此外，若視線從你的角度看來呈現在右上的方向時，表示對方「正在回想」，若在左上的方向，則表示「正在設法思考」。例如：當對方試著要回想起昨天的領帶顏色時，由於顏色是經由視覺處理的，因此從你的角度來看，對方的視線應該是朝著右上方。另一方面，當在思考想要的領帶顏色時，從對面看來對方的視線是朝著左上方。從這些傾向看來，視線的變動是看透對方是否說謊的手法之一。例如：當詢問對方昨晚去了哪裡時，若對方的視線從你的角度看來是往左上移動，則表示對方並不是在「設法回想」，而是在「設法思考」，因此，對方說謊的可能性相當高。同時，若只是單純的眼神游
