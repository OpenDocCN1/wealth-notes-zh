# 在關鍵時刻利用「決勝負的紅色」來激發熱情

根據不同情況來分別使用不同顏色，可以提升外觀所帶給人的印象。這次將特

別針對紅色的效果加以說明。看到「紅色」時，你有什麼想法呢？

紅色在心理學上，代表了能激起拼勁的顏色。我們一般認為有「元氣」的狀態，

是指腦內物質中的腎上腺素提升了血液及心跳速度，促使人呈現覺醒的狀態。而紅

色就帶著刺激交感神經、分泌正腎上腺素的效果。
