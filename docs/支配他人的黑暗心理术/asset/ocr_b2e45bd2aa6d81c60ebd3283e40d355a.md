# 對於前來挑釁的上司，以「沉默」使對方畏懼

有些壞心眼的上司會不斷挑釁，且抓住機會就想激怒別人。即使採取冷靜措謫對方不當的同步步行動，仍會被窮追猛打，試圖逼得你能如他所願反過來大發脾氣。

面對這樣的對象，請採取不管被怎麼辱罵都不回話，稱為「沉默」的同步步行動。
