# 利用人類罪惡感的惡魔技巧「以退為進效應」

與開始於小小願望的「得寸進尺效應」相反的另一個委託法，是先提出誇張的要求使對方拒絕，接著再帶出自己真正要求的「以退為進效應（Door in the face）」。英文原文是源自於，想像吃閉門羹時，門在自己面前被重重關上的情況。

例如：當你與上司交涉「如果要我負責這麼多工作，至少也幫我加個薪吧？」時，一定會被以「這有點困難，其他人也都是相同條件下努力工作著」「加以拒絕」。然而，若你在這個時候提出自己真正的請求「既然這樣的話，等這個專案結束之後，請讓我休個長假。」「那麼對方同意的可能性也會相對地提高。

這裡所運用到的心理技巧，是在拒絕對方的要求後，人會產生罪惡感的心理，或聽到對方讓步後，認為自己也必須退一步的「回報性原則」。

這項技巧的關鍵在於，如果不光是過分的要求被拒絕，就讓自己真正想提出的請求都被拒絕時，就必須節節奏明快地向對方提出替代的要求。

持續提出「如果沒辦法休長假，包含週末在內的連休也沒關係」「這天的話，對方應該也不會採取行動，所以放假也不會有任何問題」「等的要求，相信對方一定會說「YES」的。
