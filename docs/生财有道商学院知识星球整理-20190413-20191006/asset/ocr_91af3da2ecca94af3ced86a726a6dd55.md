# 什么是root?

ROOT是一种存在于UNIX系统和类UNIX系统以及Android系统中的唯一的超级用户，其相当于Windows系统中的SYSTEM用户，其具有系统中所有的权限，如启动或停止一个进程，删除或增加用户，增加或者禁用硬件等等。
