# 那些最终变成了牛的猪

昨天是作家王小波逝世二十周年忌辰。九七年的候，我还没有读过他的任何作品。一直到电脑出现光盘，我才在各种游戏光盘的角落里发现一个叫“王小波”的文件夹，里面往往就有一套小说文集。

回想这件事，情，就可以发现当初的网友和今天的网友之间存在在么大的区别。盗版商在光盘里放任何额外附送的內容，都是为了让光盘更好卖一些。很细想象，在今天的手机游戏店里有一个按钮，点开之后发现是某位作家的全集。

在王小波的笔下，有两种动物让人印象深刻。

一种是猪，能阅读王小波小说的人比较少，在过去二十年见，刚刚接触王小波的人喜欢他的杂文甚于他的小说。在这些杂文里，《一头特立独行的猪》和《我的精神病人》是王小波最著名的篇章。一头特立独行的猪》讲了王小波尊称为“猪兄”的一头猪，彻底逃离了生产队里被饲养和屠宰的命运，撕破民兵的包围圈，逃进了丛林，从一头家猪变成了一头野猪。读者被这位“猪兄”的勇气、智慧和果决所深深打动，因此往往过目不忘。尤其是对于当时我这样二十几岁的年轻人来说，“猪兄”那条逃亡之路想起来就让人振奋不已。

另外一种动物是牛。能够阅读王小波小说的人会一定会喜欢《黄金时代》，这部小说无论文立意、文笔、节奏上都是王小波的上乘之作。

在小说里，王小波写道：“那天我二十一岁，在我一生的黄金时代，我有好多奢望。我想爱，想吃，还想在一瞬间变成天上半明半暗的云。后来我才知道，生活就是一个缓慢的槌过程，一天天老去，奢望也一天天消失，最后变得像挨了锤的牛一样。这是我过二十一岁生日时没有预见到这一点。我觉得自己会永远生猛下去，什么也锤不了我。

锤，说的是农村里土法阉割牛的方法。把牛捆好按倒，一刀切开阴囊，掏出睾丸，然后一木槌砸个稀烂。据王小波说，这是对那些性子特别生猛的牛才可能做的特别处理。因此，牛挨锤带来的牛的意义非常强烈。它代表着顺从而服从，代表着生活低下头去。二十年前的年轻人们同样认为自己“永远生猛下去，什么也锤不了我”。认为自己一定会成为一头特立独行的猪，而不是一头挨了一锤的牛。

如今二十年过去了，当年的年轻人也步入了中年，送过了王小波创作这些小说和杂文的年岁。在低头冲向丛林，冲向野性，重新生猛的路上，猛然停下环顾四周，难免会问自己一个问题：那些猪呢？之前说好的特立独行呢？

二十年过去，并没有几头猪幸存下来。满眼望去，到处是安安静静吃草的牛。温和驯顺。可都是汪汪的大眼腴，睫毛还很长。你若友好，便是晴天。牛生是糖，甜到忧伤。猪还是做牛，都是一种人生选择。

认为自己会永远生猛下去的青年，或早或晚会发现做猪太辛苦，做野猪更是艰辛，还是做牛更为容易一些。事实上，很多人连这种选择都没有，满天的锤子铺天盖脸砸下来，并没有什么山林可以让他们逃避。一日接着——日，中间偶有喘息。

我如今也到了这样张皇失措的年岁，多少也明白了一件事。在这个世界，大多数人注定是要做一头牛的。为什么自由、独立和自我如此珍贵？因为它们的代价太高，做一头特立独行的猪的代价太高。而且，一个满是猪的世界，是可以想象的，但要是有一头牛，世界没有野猪的世界又太过乏味，太过无趣。看过头牛的生活，就相当于看过所有牛的生活。彼此交换一下，也不会带来多少不同。

因此，在一个牛组成的世界里，需要几头猪的存在。这样的话，当年安静静吃草的时候，偶尔想起自己在丛林里不多的朋友，此时和自己过着完全不同的生活，于是觉得这个世界有趣得多。尤其是想到大家在多年前曾经相约逃进丛林，跑避了，就会无由来地觉得有些感动，陷对于自己的伤疤中去。

就像此刻，有那么多人怀念王小波。你很难说他真的怀念一个作家，还是怀念自己的青春。或者说，是怀念在久远的岁月之前，自己面前拥有所有的可能。那种拥有所有可能的感觉，带来了未来的无限憧憬和对自我的无穷自信。那个时候，年轻人出发去寻找世界，而不像现在这样悄悄等待世界降临——那是何其动人的感觉！

这种怀念让我想起了很久以前的一幕：京城一群作家和文艺工作者举办了一次沙龙，大家探讨美国极简主义作家卡佛的作品。席间，人人盛赞卡佛的文学风格，缅怀他在如此清调和艰难的生活里依然坚持创作。看见他们端着红酒杯坐在高脚凳上高谈阔论，我注意到他们在年岁换条都价值不菲。我得承认，在那么一个瞬间，我觉他们中们是真心喜欢卡佛的。

请你相信我，我所说的每一句话，都是错的。

今天，订阅人数突破25000人。啊，生活！感觉就像是玉珞!
