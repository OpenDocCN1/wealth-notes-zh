# 宠物和植物

人们往往太小看了持续的点滴付出。在尚未付出之前自信满满，觉得完全可以永远继续下去。但是一过过多久，就会发现哪怕只是点滴付出，旦加上时间的因素，就会根本不会养，遗弃的人就不可能是我。而这个世界上有那么多被遗弃的宠物，遗弃它们的人又是谁呢？

没事不要轻易考验自己，哪怕是养一只宠物。

但我支持在家里放上一些植物。包括那些想要养宠物而不得的人，我也建议从养一盆植物开始。照顾一盆植物也需要耗费的心力远比一头宠物要少，如果一个人连仙人掌都养不活，那么他无论养什么宠物最终也会发展成为一次谋杀。养植物的意义不在此，此前我曾经用非常坚持的语气讨论过家里应该有个书柜的话题，基于类似 的道理，我认为家里应该有一些植物。并不是为了观赏，也非为了培养我们持续付出的能力，它关系到我们对生活的理解。

我在北京和深圳都住过一段时日。这两个城市都有那种称之为“睡城”的地方，在北京是天通苑那样的社区，在深圳则是龙岗或者宝安那样的区域，人们只在夜晚回来睡上8小时，剩下的16个小时都在市区通勤、工作或娱乐。过着这样疲惫不堪的生活，所谓 的家就是一个睡觉的地方。但我无论是在北京，还是深圳漂泊的岁月里，无论住什么样的房子，无论周围是什么环境，我都会在屋子里养一点植物。

人很容易习惯三点一线的生活，这是一件很可怕的事情。当初我们选择三点一线的生活，是为了获得经验值，为了积攒金钱，为了度过此刻的艰辛换取未来的美好生活。但这个过程可能会漫长忘记究竟为什么自己要过这种生活，以至于把眼前的一切视作了生活的本身。所以，无论到了哪里，我总要在屋子里养着一点植物。每周花一点时间去照料它们，看着它们在春天里一点点萌发，在夏季里茁壮长，在秋天里慢慢枯萎凋零，在冬天蛰伏潜藏。它们提醒我：眼前的一切是暂时的，生活中依然有值得追求的东西存在。

目前的栖居之所不尽如人意，但我不想它变成一个动物的巢穴，只是用来睡觉而已。哪怕只是书桌的一盆仙人掌，它也能让屋子里多一份生机。而我的生活中需要一点生机不，才可能有变化生 的可能性。有一盆植物，就像是此时此刻的自己对未来发出的问候。我不要自己习惯于目前这样的生活，我不打算就这样一直生活下去。所以，即便是如此艰难地活着，我也要活得像是已经抵达未来——在未来的生活里，我有一个自己的家，家里有郁郁葱葱的绿植，日光透过叶片在地板上洒下斑斓的影子。

人不会突然热爱生活，热爱是一种能力。你得小心地维护这种能力，不要让它在艰难岁月里被生活打磨干净。艰难的生活并不可怕，可怕的是它把人的心灵磨损得面目全非，失去了爱的能力，失去了关怀的能力，失去了付出的能力。养一盆植物，就是为了保全自己心灵的这种能力。

植物拥有根须，遇见土地的时候就会生长，这大概就是植物所蕴藏的隐喻。每一个在漂泊流浪的人，收起了自己的根须，在努力寻找一块适合自己的土地，这大概就是无关于园艺，无关环保，只是一种对生活的理解。

我曾经写过自己对生活的理解：家中有灯，阳台有花。无论什么时候，家里都有一盏灯点亮，等着自己回去；在那个亮灯的地方，阳台上永远有一盆花。对于我这样的凡夫俗子来说，阳台有花已经属于奢侈，那么，有一盆植物也算是足够美好了。
