# 推荐阅读：《美国众神》

端午节如果没有事情的话，我推荐你读一下英国作家尼尔·盖曼的作品《美国众神》。不需要你专门在假期里去书店选书，这本书在亚马逊、豆瓣和微信读书都有电子版，你可以购买之后直接下载，躺在沙发上慢慢看。

《美国众神》属于那种故事设定比故事本身强的小说。在这本书里，全世界各地的神随着移民移居美国，随着传说和祭祀的消亡，这些神也慢慢老去，失去了力量。而与此同时，美国也在批量制造新的神，比如说电视之神、电脑之神、网络神、汽车之神——作者尼尔作为一名英国人，在这地方总是忍不住流露出那种英国人独有的刻薄和揶揄之情。新神认为老神应该退休，彻底从美国消失。于是，老神和新神之间即将爆发一场终极大战。

一个有神存在的世界，一个神在凡人中隐藏身份，为了生活而苦苦挣扎的世界，这就是《美国众神》在设定上吸引人的地方。相对而言，故事本身要比较弱一些，尽管作者也设置了许多精彩的剧情，甚至有意想不到的反转，但是更令人遐思无限的还是故事设定——在每一条道路，每一处丛林，每1栋建筑里，都可能栖居着一位存活了数千年的神祇，一想到这里，就会让人产生无穷无尽的好奇心，想要知道这些神在做什么，以怎样的一种形态存在着。

从另外一个角度来看，《美国众神》也是一部非常忧伤的作品。人类早期都是泛灵论者，先民天然地认为雨雷、湖泊山川之后都藏着神意，否则无法解释自然和命运的喜怒无常。对于古希腊人来说，奥林匹亚诸神和凡人相去不远，他们也整天醉醉醒醒睡胡闹，彼此嫉妒争斗，不过是一群不死具有神性的人，在他们身上凡人的毛病一点都不少。而且，他们也并不总是躲在雷电环绕的奥林匹亚山巅，诸神行走于在人间，对于干涉凡人的生活和使命运有着浓厚的兴趣。

北欧有奥丁、托尔等一系列性格暴躁、力大无穷的神灵，英国在巫师梅林之前，丛林里依然住着精灵、矮人、独角兽。基督教在欧州的兴起，用一种替代了这些远古的传说和神话，当人们不再相信传说，不再奉献祭品的时候，古老的神灵也就被逐渐遗忘了，最重要的特征就是他们渐渐退出了世俗的生活，和凡人再没有任何关系。《美国众神》唤起了人们的回忆，这本书几乎是有史以来全世界各种神灵的合集。它让人想起人类最天真 的时代，那种对于自然和世界依然充满敬畏之情的时代，人和神混居在世界上，神灵的存在是不证自明的事实。

作者并没有明说，但是在《美国众神》里可以非常明显地感觉到，尼尔·盖曼把当代的美国社会视为一种无信仰的纯消费主义社会，生活在这样的社会里的人，都是拜物教的教徒。比如说电视就是一种新型的宗教，电视机就是它的神像，而客厅就是人们的礼拜堂。时间则是人们为电视之神奉上的牺牲。同样的，游乐场、手机、网络、电影院，无一不是新的宗教，沉溺其中的无一人不是信徒——世界似乎又回到了很久之前，那个满街神爷都是神灵的时代，但是这一次他们需要的不是羔羊、乳香和活人，他们需要的是时间和金钱。

所以，你可以把《美国众神》视为新旧大陆之间的文明冲突，也可以视为传统文化和消费文化之间的碰撞。只是在《美国众神》之前，并没有人把这样的事情写成长篇小说，用作故事背景，并在其中塞满了奇幻 想象和曲折的情节，这就是为什么《美国众神》会横扫雨果奖、星云奖、轨迹奖、斯托克奖、SFX奖、格芬奖，囊括6大奖项的原因——尼尔·盖曼提供了一种前人所没有的视角，让我们得以重新审视自己的生活，审视人类的历史，并且和无数优秀作家做的那样：追问生命的意义。

我建议你第一次读的时候，尽量跟着故事走，不用花太多时间在全世界迁往美国的各种神灵的名字和事迹上。先跟随着主人公的脚步，在美国大上四处奔波一番，有点深入那个神灵所组成的秘密社会。等到真相最终揭晓，土成尘埃落定，你再回过头去重新翻阅一下那些神灵的资料，再次感受作者行文逻辑上的精妙之处。如果你假期没有安排的话，这本书足够你打发两天时间了。和手头的电影相比，就娱乐性而言，这本书更值得你花时间。
