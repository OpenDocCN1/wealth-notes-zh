# 共同提高

我在自己的微信公众号里做了一个关于出轨的调查问卷。其中有一个问题是询问读者们，什么才是规避出轨的最强武器？

有18000多人选择了“共同进步”这个选项，占投票总数的46%，几乎是压倒性地超越了其它选项。

这个问题投票率第二高的是“同甘共苦”，占投票总数的10%。

其实它和共同进步也相去不远，这样算起来的话，有超过50%的读者认为夫妻/情侣共同提高才是降低出轨风险的方式，其它的选项诸如道德约束、社会舆论、抚养子女乃至暴力感，都没有获得那么高的认同。

最出人意料的是，有人在跟贴里问我：为什么没有“尽情”这个选项？我回答说：我喜欢这个笑话。这条答案在24小时内，获得了1319次赞同。

为什么是“共同提高”？提高什么？在我看来，这个选项获得了最高票数，说明了三件事情：

+   一、 对于两性关系存在普遍的焦虑。共同提高这个概念是近年来关于如何维系婚姻/情侣关系的讨论中最常见的答案。现在看起来这个答案也为大多数人所接受。它本身是不是真的那么重要，重要的是有那么多人接受这个观点，于是这个说法也就变成了某种标准答案。共同提高是一个心理的概念，人们在坚持正向概念的时候，往往在心理动机上是因为惧怕落入了这个概念的正面。因此，人们选择共同提高的时候，其实是在担忧自己掉队，和 自己的伴侣在个人发展上出现巨大落差。

为了验证这个看法，请回忆一下关于电影导演李安的做法。那些流传甚广的文字是在谈他的艺术成就吗？是在探讨他的电影风格吗？都不是，而是在谈他在一名不文的时代里，如何终日在家做饭做菜，而他太太又是如何经年累月里供他，始终没有放弃对李安的 信心。人们喜欢这个故事，不仅仅是因为婚姻中的忠诚，也不因为婚姻中的相互扶持，而是看到一个人在不能共同进退的情况下，他的伴侣仍然不离不弃。这也从反面说明，这种不离不弃何其少见。

+   二、 对于许多人而言，婚姻从过去 的经济联合发展到今天，变成了一个战斗联盟的状态。选择共同提高这个答案，意味着人们把生活视为一场和外部世界无足尽的战争，因此双方都有义务不断强大自己，为家造出这个战场里提供更强的人力支持。共同提高并不是一个自我放纵的看法，而是代表了一类人对这个世界的看法。如果我们认为外部世界是一个充满激烈竞争，而且随时都会出现变数的战场，那么就会很自然地认个人需要“提高”、“完善”、“进步”这样的字眼，很自然地，婚姻里 双方也应该共同提高，携手进步，不要成为对方的拖累。

这样的看法可能更接近于婚姻的本 来面目：婚姻出现的原因并不是我们今天宣称的爱情，而是某种社会资源的优化和重组，用家庭形态在社会竞争中获得更优越的位置。大家都是战士，而战士决定和什么人联盟，取决于对方的实力和未来的发展潜力。所以，战力拉低，提升缓慢，是战士之间彼此伤害的最大原因。

+   三、 唯一值得高兴的是，“共同提高”这四个字后面隐藏了平等 的思想。人们认为共同提高能够作为规避出轨的最强武器，是认定了一个假设前提：男女之间存在平等关系的时候，这种关系最为稳定长久，而这种平等关系体现在能力和收入的相对平衡。一旦打破这种平衡，意味着双方不再平等，存在某种形式的人身依附或者经济依附，那么就很容易出现问题。无论这种想法给人的压力有多大，它总是要比以往男权社会的那一套强得多。

总之，共同提高这个概念已经被如此之多的接受，让人群里都站满了 身着盔甲、手持兵刃的战士，随时准备投入无尽的征伐之中。

作为我个人，我只是希望一件事情：哪怕只有一瞬间，也应该有爱情来过。

> 请你相信我， 我所说的每一句话， 都是错的。

除了并肩作战之外，人生里还是应该有一些共同 温度的光明。
