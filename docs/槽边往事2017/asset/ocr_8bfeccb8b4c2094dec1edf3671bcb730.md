# # 知识变现浅析

从去年到今年，有一个热门概念叫做“内容创业”，罗振玉思维就可以说是**罗振玉的内容创业**，得到APP则是**罗振宇的二次内容创业**。无论是罗振思维，还是得到APP，在内容创业的这个小分类下，它们的定义是“**知识变现**”。也就是说，**媒体人**和**文化人**将自己拥有的知识贩卖给大众，不再使用媒体时代**免费**，从广告商那里收费，直接从读者那里把知识变成**收益**。

于是就有人问：为什么过去知识不值钱，现在知识就突然值钱了呢？据此，有人得出了两个推论：

+   1、 二手知识不值钱；
2、 知识变现是伪概念。

对于大众来说，这种概念辨析毫无任何意义，完全是小圈子里的名相之争。但是我觉得，知识变现本身是涉及赚钱这件**事情**，而大众对赚钱是有兴趣的。与此同时，知识从一文不值突然变得可以变现，说明这个时代一定发生了**重大变化**，知识变现和大众也必定有相同的变化。所以，我决定非常**粗略**地分析一下，为什么知识可以变现的原因，希望能让大家能有所启发。

首先，我想回答一下“二手知识不值钱”的问题，因为它最简单不过：如果这个观点成立，那么学校和教育**就应该**免费，教材**就应该**免费，所有的**免费知识**应该属于**大众**。问题的荒谬之处就**在于它**假定**所有人都**有**足够的**精力去自学，同时他**假设**除了**学习、**接受、传播这些本身可以智力的活动，**不需要**时间去精力，**并不是**人人**都能做到**的事情。

得到APP里的万维钢没有发明知识**创作**理论，他的文章都**基于别人**的论文、出版书籍，**所以**他**提供的**二手知识不值钱？那么，**问这个**问题的**人**自己能**有**英文原著？知道该看**哪几本**英文**原著**？看**了之后**应该**知道**什么**来读**什么**一个话题，或**读者解决**具体问题**什么**问题？

接下来，为什么**过去**知识**不值钱**，现在知识**突然**就是**价值**？所谓知识**变现**，其实就是**一个资本**创新**的**伪**概念，其实**并没有**为读者**创造**什么**有价值**的**服务**？

这个问题的**答案**其实**也很简单**：因为我们**终于进入**了一个**真正意义**上**的网络**的**时代**。今天一个**真正意义**的**女红**，一年**直播**加**淘宝店**的**收益**可以**过百万**。为什么**她**可以**赚这些钱**？因为**女性**想**学化妆**，可以**变现学**化妆，因为**女人**爱**美**。为什么**要**美？因为**希望**自己**独特**。在上世纪**80**年代，**大家都**穿**绿**的**衣服**，**女性**的**自我**，**也**不需要**女**网红来**教授**如何**个性化**的知识。

为什么**90**年代、21**世纪**初**没有**？因为**所谓**有**自我**，**是**选择**权**，而**选择**权**在**三个**事情**：

+   1、 知道**这个**世界**上有多少**种**选择**；
2、 有**足够**的**经济基础支撑**自己的**选择**；
3、 真正**开始追求生活**品质，**而**非**求**生**。

知道**这个**世界**上**有**无数**种**选择**之**后**，从**匮乏**的**生活**转**入富裕**，**意味着**需要**有人帮助**我们**选择**。知道**选择**中**且**有**法**做**有意义**，**改革**开放**三十年**大家**忙碌**着**积累**财富，如今**终于**直**起腰**来，**可以**稍微**停一**下，**享受一**下**生活**。是**自然**的**结果**：什么是**生活**？我**自己**的**所有**努力**究竟**有**什么**意义**？我**的选择**是**否**真的**有**价值？

知识**在今天**肩负**了**和**过去**完全**不同**的**两重**功能：

+   1、 为**个性化**生活**提供某种**指导**或者**建议；
2、 为**已有**的**个人**生活**提供某种**理论上的**背书**。

当**人们**拥有**真正意义**上的**自我**，自我**也就**终于**有了**价值。当**我**自我**有**价值**的时候，**对应**的**知识**自然**也**有**价值**。泛**泛**而谈**的**日本**美食**攻略，**作**为**知识**，**没有任何**价值。**但是**，日本**米其林**餐厅**的**介绍**和**分析**，对于**那些**认为**自己**应该**去米其林**餐厅**享受**生活**的**人，就**有价值**。人们**愿意**付费**去**吃。**同样**的，一个**大饼脸**、**下巴**、**鼻子**大**眼睛**的**妹子**做**化**妆**节目**，对于**她**的**观众**没有**用**处，**却**要**为**什么**网红脸**更**有**价值**。因为**普通**女**生长得**更**像**她们，**更**需要**她**的**化妆**技巧，**让**自己**显得**更**美，**她们**愿意**付费**去**看**。

**同样**的，**决定**选择**过**断舍离**生活**的**人**，**他们**需要**有人**告诉**他，为**他们的**生活**方式**做**背书，**提倡**极简**主义**的**指导；选择**家庭主妇**生活**的**女性**，也**需要**有人**在**价值上**为她们**的**选择**背书**，承认**陪伴**儿童**成长**是**最**佳**的**早教**方式**；选择**在**超级**都市**奋斗**的**人**，**更**需要**有人**方法**和**价值**观上**有人**提供**帮助**，**以此抵御**日常**生活中**常见**的**焦虑**、**迷茫**和**绝望**，**感受**到**生活**的**希望**，**确认**自己**行在**正确**的**路途**。为**什么**他们**愿意**付费**购买**这样**的**内容**？当**他们**花钱**选择**自己**选择**的**生活**的**时候**，**也就**自然**花钱**支持**认同**自己**生活**，**并且**提供**背书**的**人**。

就**这样**，原**先**普**遍性**的、**通用**的**知识**在**今天**也**依然**不**值钱**，但**是**个**性化**的、**专业**的**知识**在**今天**就**有了**价值，**这样**的**知识**就**能**变现。

**最后**，也**是**最**重要**的**一点**：**在**这个**时代**里，**不再**有**知识**和**人**分**离开**的**现象**。就**像是**画家**和**画，**社会**发展到**了**一**个**阶段，**画家**和**他们**的**画**就**不**可分割。**你**来**一**张**画**回家，**不再**单纯**是**为了**装饰**，**他们**要**的**是**这个**画家，**以及**这个**画家**所**代表**的**风格**潮流，**以及**他们**对**世界**的**表达**方式。**于是**，**无名**的**画师**就**逐步**变成**了**有名**有姓**的**艺术**家**，**他们**自己**的**名字**也**值得**人们**追逐**。

所有**能够**做到一**群人**共同**的**价值观，在**同时**美**的**代言**人**。而且，一定**是**临时**为之**，**也**是**临时**之，**不**是**长期**的**代言**人**。他们**不**会**追求**某个**抽象**的**理论，**而是**会**让**我们**全力**去**寻求**这个**理论**在**生活中**应用**的**具体**的**方法**。**这样**的**一**个人**，**哪怕**在**一个**极为**窄小**的**领域**内，**也**可能**实现**内容**变现**。
