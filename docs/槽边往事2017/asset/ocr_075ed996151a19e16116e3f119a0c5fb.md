# 回顾旅程｜和菜头给你推荐过的电影

在期待下一次相聚的时候，不妨先回顾这一年的旅程中，和菜头都曾经带给你哪些惊喜。

如果这一年和菜头推荐电影清单中，还有你没来得及去看的，不妨趁和菜头在短暂休息的时候，一一补上。

+   1.斯坦利·库布里克的未来三部曲：《奇爱博士》、《2001太空漫游》、《发条橙》。

+   2.李安的家庭三部曲：《推手》、《喜宴》、《饮食男女》。

+   3.朱塞佩·托纳多雷回归三部曲：《天堂电影院》、《海上钢琴师》、《西西里的美丽传说》。

+   4.约翰·卡尼的音乐电影：《情难独奏》、《再次出发》、《初恋这首情歌》。

+   5.音乐电影：《爆裂鼓手》、《放牛班的春天》、《生命因你而动听》。

+   6.重点推荐（一年中推荐了三遍）：《一个叫欧维的男人决定去死》。

+   7.故事类型电影：《追捕野蛮人》、法国电影《蝴蝶》、美国电影《冒牌老爸》、国内电影《清亮的小溪》、《孙子从美国来》。

+   8.集合温情、恐怖、色情、爆笑于一体的重口味电影：《瑞士军刀男人》。

+   9.好与坏取决于观众的电影：《驴得水》。

+   10.纪录片：日本NHK摄制的《不了之人：宫崎骏》、《寿司之神》。

+   11.真实事迹改编（中桐中矩）：《萨利机长》。

+   12.残酷战争片：《血战钢锯岭》。

+   13.奥斯卡荐片：《推销员》、《降临》、《生化危机：终章》、《海边的曼彻斯特》（偏文艺）、《爱乐之城》（和菜头评价一般）。

+   14.话剧：《暗恋桃花源》（上网搜索视频关键字：暗恋桃花源+金士杰版，3小时34分12秒的版本）。

以上这些电影，哪一部你还没看？哪一部让你深有感触？欢迎在留言中写下你的感想。
