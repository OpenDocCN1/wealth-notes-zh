# **第五十篇 SK#24 达叔这个月的见闻和思考**

这个月，达叔主要做了以下几件事情：

+   1、花了1299 元，网上报了个自媒体的班，学习一下如何写作和创作。
2、坚持每天一篇公众号文章，偶有遗漏，太累了，就睡过去了，整体还在保持节奏。
3、出了3 次差，郑州，合肥和南京，各待了一段时间。
4、读了几本书，还学了几门投资课，自己的作品也正在写作中了，出版社的姑娘都催稿了。

今天早上，送女儿去上英语课。

店长看到达叔，好久不见，激动的不行，一定要和达叔聊天，说这个疫情，三层楼的店面差点就倒闭了，让达叔给分析分析。

达叔问，你这个店几个人？

店长说，加上外教，十来个。

达叔问，一年的营收的营收能有多少？

店长说，去年营收 200 万左右，之前操盘过最好的店，一年 600 万。

达叔问，200 万的营收，除去房租、水电、10 来个人的工资，基本不赚钱吧？
