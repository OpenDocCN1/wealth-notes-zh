# 第十五篇 JJ#29 不要忘了，愚蠢的人，才是最难管理的

昨天，有个宣扬经济学的账号被封了，虽然达叔也不认识背后的作者，但总觉得怪怪的。

在人类历史上，但凡整个社会都满嘴仁义道德者，往往是大奸大盗之徒，社会秩序崩坏；而保护个人产权、尊重个人的社会，往往是有秩序和繁荣的。人人平等的穷，才刚刚过去没几年，就开始不让人好好说话了，这是不对的。

个别媒体平台的小编，自我阉割，主动阉割的觉悟，是一种高级黑。

不要忘了，愚蠢的人，才是最难管理的。
