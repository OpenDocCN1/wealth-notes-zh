所以无论是 IBM、华为，还是苹果、阿里、谷歌、腾讯，再伟大的公司，都不可能无限扩张，都有边界。

区别是上限的高低，边界的大小，这个在你选择行业时，基本就确定了。

达叔之前在文章里强调过一个观点，无论是创业还是投资，都要选对行业和赛道，不同的赛道适合不同的人来玩。

比如资金密集型的金融、地产，绝大多数就是权贵们的游乐场，你脑子好使、胆略过人，大概率就混成权贵的白手套。
