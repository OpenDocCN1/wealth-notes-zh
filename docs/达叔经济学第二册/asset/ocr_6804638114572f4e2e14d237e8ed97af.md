# 第二十八篇 SK#2 面对邱晨事件，我们该持有怎样的态度？

达叔从经济发展和人口流动的角度来聊一下：

中国经济经济最困难的时间点，人口流动是怎样？

改革开放后，中国前后有四次出国潮：

+   一、1985 年，“支持留学、鼓励归国、来去自由”十二字方针出台，史无前例的出国潮席卷全国，这一阶段主要是私人留学为主要特征；

+   二、八十年代末、九十年代初，苏联解体，个别事件发生，富裕阶层尤其是北上广等先富裕层集体逃离，鼓吹中国崩溃；

+   三、2000 年左右，年轻的富二代们陆续出国，留学热造就了新东方的崛起；同期一些富起来又解释不清资金来源的官员，寻求海外资产避险，家庭人员大量出国，裸官集体出现。

+   四、2010 年后，资本大佬、产业新贵，寻求资金避险，但同期的出国潮的同时开始出现归国潮。

前两个阶段中国经济困难，受意识形态影响，中国有能力、有资源、有资金的人才，对国家有幻灭感，为求自保，出国躲避。作为个人，无可厚非。
