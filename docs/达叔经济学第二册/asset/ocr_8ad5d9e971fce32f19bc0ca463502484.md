# 1 自己的王国。

达叔这个账号，叫达叔经济学，其中最扎眼的，应该是经济两个字。

每天明叨叨，除了经济系列，好像也没花多少文字，去认真写经济，为啥还叫这个名字？

达叔来解释一下：

经济，这个词，肯定是外来词，英文名字 conomic，在古希腊语里，

源头的意思，就是管理家庭。

在我们中文的世界里，变变大了，有经世济民的意思。

我们绝大多数人，都是普通人，没那个本事去搞经世济民，没必要去装大神，解读这个事件，分析那个大人物。

基本天天写大事件的，就是跑偏了。

我们就该老老实实回归本源，把家庭管理好，让老婆孩子，过上好日子。
