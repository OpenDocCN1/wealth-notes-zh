# 第四十八篇  SK#22 求求你，别再动脑筋省钱了，否则你会穷的很稳定

今天周六，达叔在家和达婶又拌嘴了，还激动的打了一下她的屁股。

原因是啥？

夫妻拌嘴，绝大多数是因为钱。

自从上次和达婶拌嘴后，达婶创造性地把自己全职太太的工作进行量化、货币化，要求在掌柜家庭财政大权的同时，给自己额外发 1.5万/月的工资。

达叔技不如人，认了。

今天月末，达婶喝下午茶的时候，突然想起来要给自己发工资，打开银行软件，达叔瞟了一眼，感觉数字不对，就多嘴问了一句，感觉这个金额少了几万。

达婶说，不可能，就这个数，哪里少了？

达叔说，有笔钱是不是两周前到你支付宝上了？

达婶打开支付宝一看，果然。

达叔当时心都凉了。

余额宝现在 7 日年化都跌成 1.5% 了，惨不忍睹。

稍微正常的货币基金年化都能做到 4% 左右，不动脑子的，至少也是 3.5% 啊。
