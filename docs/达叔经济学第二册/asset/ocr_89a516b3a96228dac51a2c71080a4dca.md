# 第三篇 JJ#17 对不起，在决策者眼中，穷人不缺钱，富人才缺钱

一群信口雌黄的家伙，把达叔给气笑了。

在疫情期间，达叔就写过一篇文章，JJ#3 如果大萧条来了，普通人应该怎么办？

现在股市、核心楼市火热，在疫情后期就可以预见的，所以达叔建议你有机会多学一些经济学，和达叔一起慢慢变富。
