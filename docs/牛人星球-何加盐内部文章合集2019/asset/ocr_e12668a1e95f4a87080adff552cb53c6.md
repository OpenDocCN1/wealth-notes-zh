结果是，第三天中午，甲和乙都自杀了。

同样，第四天中午，其他 998 人也会自杀。

3. 假如岛上有三个黑眼睛的人甲乙丙，那么，当游客说出那句话时，甲就会等两天，看第三天中午乙和丙是否自杀。如果他们第三天没有自杀，甲就立刻知道，除了乙和丙之外的其他 998 人里面，至少还有一双黑眼睛，而甲可以看到其他人都是蓝眼睛，黑眼睛的只能是甲自己。 乙和丙的心理活动和甲是一样的。

结果是，第四天中午，甲乙丙都自杀了。

同样，第五天中午，其他 997 人也会自杀。

4. 依次类推下去，有黑眼睛的 100 个人，会等到第 100 天，看其他 99 人是否自杀，如果他们没有自杀，就证明自己也是黑眼睛。结果是，第 101 天，黑眼睛的人都会自杀；第 102 天，蓝眼睛的人也会自杀。

总结一下，可以得出规律，如果村子里有 N 个黑眼睛的人，那么，当游客说出那句话的时候，在第 N+1 天，黑眼睛的人就会自杀。第 N+2 天，蓝眼睛的人也会自杀。

这种推论方法，也叫 “递归推理”。
