# 骂人的傅盛，踢人的张颖

前几天，创投圈出了一个瓜。

事情是这样的，有一家著名的风险投资叫经纬，由于他们投资的公司挺多，很多也比较成功，形成了一个“经纬系”。这些经纬系公司有很多群，其中一个是 CEO 群，都是经纬所投资公司的 CEO 们，以及一些关系较为密切的其他人员。

李医生事件后，这个群里有人说了自己的观点，另一个人表示赞同。而猎豹移动的 CEO 傅盛看了观点，勃然大怒，骂道“楼上两个 sb 可以去死”、“你们两个 sb，我退了，你们好好开心”。

群里几个人都附和傅盛，包括超级经纪人杨天真、易到用车创始人周航等。周航还直接开骂，说“耻与人渣为伍”，也要一起退群，并专门艾特经纬的合伙人张颖，说“你 tm 装个态”。

而张颖的反应是，让人把傅盛踢出所有的创投汇群，说他“太不成熟”了。

这起闹剧，引起了舆论的热议，在微博、朋友圈和微信群广泛传播。后来，张颖和傅盛又不得不当众表演重归于好。傅盛公开道歉说不该骂人，张颖把他重新拉回群。

这些人都是功成名就，早就实现了财富自由的，我们可以看到，他们在群里，其实也和大多数普通人一样，会吵架，会骂街，会退群，会踢人。而傅盛和张颖，由于是事件的核心当事人，也引起了最多的讨论。
