# 人生需要区别 4 种成本

上周发了一篇关于沉没成本的公众号文章，很多朋友反馈说对他们很有启发。其实每个人都需要有成本思维，要注意 4 种不同的成本。

第一种是沉没成本，就是已经付出、无法收回的资源。

在决策时，沉没成本不应该考虑在内。例如，我花 100 块钱买了一个榴莲，打开来看发现是坏的，不能说因为花了一百块钱，我就要把坏的榴莲吃掉，因为你就算吃掉，那一百块钱也回不来。

坏的东西要扔掉，还好理解。很多人不能接受的是，好的东西也要扔掉。最常见的是饭桌上和衣柜里。花了很多钱买的菜，我们舍不得倒掉，哪怕吃得再撑，还是要把它吃完；很贵买来的衣服，发现穿着不舒服不好看，却总舍不得扔。其实，吃东西是为了美味或健康，穿衣服是为了舒服或好看，当你吃的东西又不好吃，又让你长胖，你为什么要吃呢？当一件衣服穿着又难受，又不好看，你为什么要穿呢？舍得放弃，是一种智慧。

有人会说，人要学会坚持到底，放弃沉没成本与坚持到底是相悖的。

其实不然。我们坚持到底，是因为怀着对未来的期望，而不是为了可惜已经付出的东西。假如是因为可惜而坚持，那就完全错了。会害了自己的。
