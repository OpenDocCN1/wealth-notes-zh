# 产品的价值有三种

做任何生意,都可以把产品从销售到交付的过程,分为三个环节:销售环节、生产环节、交付环节。产品对客户的价值,其实有三种,第一种是在销售环节让客户感知到的价值,我们可以称为客户对产品的期待价值;第二种是产品真正能对客户起的作用,我们可以称为产品的客观价值;第三个是客户得到或使用产品时感受到的价值,我们可以称为交付价值。

很多时候,这三种价值,是互相背离的。不同的公司,往往会有不同的侧重。 销售型的公司,会侧重于给客户的期待价值。他们可能会把产品说得天花乱坠,让人产生满满的期待,轻易就能够把产品卖出去。但实际上,产品的客观价值,并没有他们所宣扬的那 么大。例如,老年保健品、陈安之成功学、小米一代二代手机、绝大多数化妆品、减肥药、生发剂等等,基本上都是此类。

这种你要说他是骗子吧,好像也不全是,有些是有些不是,还有些无法判定,但是总而言之一条,他们的产品并没有宣传的那么好。

这一类的公司是非常多的。而且商人和企业也不以为耻,毕竟他们养活了企业员工,也给国家纳税,所以一般只要不出现谋财害命的事情,法律也管不了,舆论也很宽容。有时候,企业家甚至会被视为成功者。例如史玉柱卖脑白金、杜国楹卖小罐茶、周鸿祎卖孕妇路由器等等。 产品型的公司,会侧重于给客户的客观价值。他们会尽量让产品真正具备价值,解决客户的问题。
