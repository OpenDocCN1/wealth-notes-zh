# 孩子做错事，该怎样制止

孩子在地铁上抓陌生阿姨的裙子，妈妈赶紧制止，说：“宝宝，不要这样，阿姨会生气的。”这个妈妈很有教养，但是却用错了方法。

经常受到这样教育的孩子，会形成一个印象：因为这件事别人会生气，所以我不能做。

久而久之，外人的反映和评价，成了他做什么或不做什么的依据。

这样的孩子长大以后，容易为别人的想法而活，忘记了自己真实的内心。正确的方法应该是怎样呢？

我们来做一个系统分析。让孩子放弃做一件事情，可以有很多种方法。常见的几种如下：

1，别人的喜厌。用别人的喜欢或厌恶来影响孩子。

文章开头那位妈妈用的就是这种。

让孩子不要迟到，妈妈说：走快点，迟到了老师会批评你的。让孩子叫奶奶，孩子不叫，妈妈说：你不叫，奶奶不高兴啦。让孩子放下IPAD，妈妈说：再看我就生气了。

喜厌，是别人的评价。

2，顺逆。用威权来影响孩子。

爸爸会倾向于用这种方式。“你给我停下，不许这样做知道吗？”“放下IPAD，我数到3！”“赶紧做作业去”。因为我是父亲，我比你强大，所以你必须听我的。
