# 不自信会影响人生重大决策

昨天和一位师弟聊天，颇有感慨。

师弟渐大硕士毕业后，进入国企工作。很短时间内就做到领导岗位，30 岁前就上了处级。现在又被一家年产值几亿的公司挖来做合伙人兼运营副总。

师弟的能力和成绩都是有目共睹的，但是在聊天中，我能明显感受到他的不自信。

例如，当他去负责集团下面某子公司时，总觉得自己这也没做好、那也没做好，觉得自己能力不够，压力很大。但事实上，他担任子公司总经理的时候，是该公司管理最好，发展最快的时候。

他一直有出来创业的心思，但是却迟迟不敢行动，直到 8 年之后，才被人三顾茅庐挖出来。 而出来之后，也是焦虑重重，不知道能不能干好。 他喜欢阅读，并且长期做阅读笔记。我建议他开一个微博或公众号，把这些笔记放到网上。可是他说，写得太烂了，不敢放到网上。

其实，我不相信一个常年阅读和做笔记的人，会写得很烂。而且，他的东西已经有了，只是放到网上而已，又不增加什么成本。何必要顾虑那么多呢？ 我安慰和鼓励他很久，并把“冒牌者综合症”那篇文章发给他看，也不知对他有没有用。

这种不自信，其实对人生的重大决策影响挺大的。师弟如果自信一点，可以在子公司老总的位置上做更久，或者可以更早出来创业，
