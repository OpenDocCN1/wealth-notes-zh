# 神奇的佛罗里达效应

如果你现在有空的话，我们不妨一起玩个小游戏。

请在下面五个词中，挑出四个，组成一个通顺的句子：

活泼的、小伙子、奔跑、轻松、运动场。

你可以就在脑海里组，如果反正闲着无聊，那么在电脑上、手机

上、或者纸上写下来也行。

想好了吗？

好。现在请站起来，走到门口，然后再回来接着看这篇文章。

请回想一下刚刚的脚步，你有没有发现，你的步子比平常更轻快，

你走到门口步伐更迅速，花的时间更短。

这种现象名叫“佛罗里达效应”，出自美国纽约大学教授约

翰·巴奇做的一个实验。

这个实验的方法和我们上面做的游戏完全相同，只不过他用的都

是与“老年人”联系起来的词，如佛罗里达州（佛罗里达是美国养老

圣地，老年人比例非常高）、皱纹、行动迟缓、健忘、秃顶、白发等。

参加试验的对象，走路的脚步全都变慢了。

约翰·巴奇认识到，我们的行为和情感，有时候会被一些我们完

全没有意识到的事物所影响，其原因就在于人类的记忆联想功能和意

识的涟漪扩展。

当我们看到与老年有关的词汇和句子时，我们心里联想的都是与

老年有关的画面，于是，我们也会想到，走路要慢一点，安全第一。
