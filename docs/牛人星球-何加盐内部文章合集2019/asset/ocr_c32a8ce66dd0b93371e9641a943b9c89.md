# **只有这样不屈的灵魂，才有资格说“感谢贫穷”**

# 1，只要站起比跌倒多一次我们就没有辜负韶光

刚刚以707分考入北大的河北女孩王心仪一篇《感谢贫穷》的文章看哭了无数人。90后、00后的孩子，很少有类似经历了。但是对70后和80后而言，文章说的就是我们大部分人的小时候。

王心 仪出身于极度贫寒之中。所幸的是，她没有被贫寒压垮，而是始终不屈地与命运作斗争，从贫寒中汲取前行的动力。王心 仪从来没有抱怨贫寒，没有抱怨父母，她只是默默做她该做的：保持努力，保持希望，等待美好的事物在转角处出现。她等到了707分的高考成绩和北京大学中文系录取通知书，她等到了亿万人的情感共鸣。

在4个月前的枣强一中高考誓师会上。王心 仪代表千千万万贫穷学子大声地喊出：“只要站起比跌倒多一次，我们便没有辜负这段青春、这段韶光！”从这句命运的宣言，我们便能知道，为什么一个贫穷女孩，能在寒门再难出贵子的今天，杀出重围，改变命运。

也只有这样不屈的灵魂，才有资格说：感谢贫寒！
