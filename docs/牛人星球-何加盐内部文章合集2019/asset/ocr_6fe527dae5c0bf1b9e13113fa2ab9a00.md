老婆：遥控器在哪儿？

老公：在茶几上。

# ## 改例二：

女儿：你来陪我玩！

爸爸：爸爸现在很忙，过会就来陪你。

# ## 改例三：

父母：你看我手机怎么又上不了网了？

儿女：应该是没有流量了。以后看到那些不明来源的链接，不  
要点就行了。

问句经常出现。不信你晚上听一听。

除了家庭以外，在工作场合，在学校，在日常人际交往中，类  
似的反问句也经常会岀现。你回忆一下老板和最常说的话，看是  
不是这样？

它是人际关系的毒化剂，我们应该尽量避免。
