# 我们的开心来自哪里？

我在一些关于人生战略规划的培训课上，都做了问卷调查，其中有一个核心问题：

一个月内，让你特别开心的事情是什么？

初看之下，每一个人对此的答案都不一样；但是，细细品味，却能发现很多共同点。

以下我们列举一些回答：

+   没有；

+   有，完全没想到的业务降临到自己的头上；

+   儿子会自己拉屎；

+   有 一对一和外教聊天挺开心的；

+   另一个企业成立的洽谈；

+   有，脱单；

+   好像真没；

+   跟几个知己在一起；

+   没特殊印象；

+   无；

+   儿子月考班上第二年级第五，区二十多个学校乒乓球比赛冠军；

+   无；

+   收到恋爱礼物；

+   好像没有；
