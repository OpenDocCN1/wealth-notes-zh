# 5G 的风口在哪？

电脑+互联网改变了传统商业，智能手机+移动互联网改变了传统互联网商业。

我们可以粗略地归类 1G（语音通话）和 2G（文字+图片+手机简单上网）为同一时代；3G（拥有了大部分上网功能）和 4G（大容量快速传播信息，基本无障碍得上网）为同一时代。

那么，5G 是还处于和 3G、4G 的同时代，还是将开创一个全新的时代呢？我认为，5G 将开创一个全新的时代。

与 4G 相比，5G 的改变是速度更快、容量更大、延时更少。

这意味着，很多 4G 时代还没法大规模应用的设备和技术，到 5G 时代都已经不成问题了。

对 5G 时代的预测，关键是看有什么关键设备和在哪些使用场景。

4G 的设备是智能手机，使用场景是打车、移动支付、外卖、看短视频、移动社交等。

5G 的设备，首先智能手机还将是一个重点；其次可能有：智能穿戴设备，如谷歌眼镜、全息投影戒指或手表，AR（增强现实技术）和 VR（虚拟现实技术），自动驾驶汽车，人工智能。使用场景：从出行上，未来无人驾驶和智能交通肯定将渐成主流。刚开始可能会在封闭固定路段推广，慢慢扩展开来。这个在技术上已经没有问题，关键的障碍有三个：安全性、稳定性和利益格局。
