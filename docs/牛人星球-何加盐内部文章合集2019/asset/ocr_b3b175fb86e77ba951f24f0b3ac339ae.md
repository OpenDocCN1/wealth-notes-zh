# 追求的四个层次

我把不同人的追求分为四个层次。

第一个层次是浑浑噩噩，从没想过自己要追求什么，只是凭着本能行事。很多没什么知识，平时也不愿意思考的人，就是这样。他们从来不会去想活着的意义，或者自己要追求一点什么。就是活着而已。

当然，他们也会想要吃饭、穿衣、享受性的快乐、希望儿孙幸福等等，但这些只是动物本能，是被无意识推着走的，并不是主动的追求。

用哲学活话说，他们缺少“自由意志”。

第二个层次是追求成功，想要更多的钱财、更高的官位、更大的名声等等。

大部分人都处在这个层次。人类孜孜以求，往往不过是出人头地四个字。这方面的追求，大多不是追求绝对值的增长，而是追求超过其他人。当人们追求成功的时候，眼睛都是向外看的。我比这群人成功一点，高兴了；回头一看比那群人差那么多，又不高兴了，回头再接着努力。

需要指出的是，这个追求，是个心理活动。有些人会落实到行动，更多的人只是想想而已，却又不愿意努力，所以最终成功的只是少数。而那些所谓成功的人，又会看到比自己更成功的，从而还是不能满意，仍然要继续追求。所以，大部分人永远焦虑。
