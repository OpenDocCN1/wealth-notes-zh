# 不用反问句，家庭矛盾少一半

如果你仔细观察一下，会发现很多家庭矛盾，其实都是由反问句引起。

我们以三组对话来举例：

例一：

老婆：遥控器在哪儿？

老公：不就在这儿吗？

例二：

女儿：你来陪我玩！

爸爸：没看我正忙着吗？

例三：

父母：你看我手机怎么又上不了网了？

儿女：跟你说多少遍了？那些链接不要乱点，你看，流量都用没了吧？

类似的对话，想必在很多家庭每天都会上演。

不要小看它们。其实，日常生活很多矛盾，都由这些反问句引发。它毒化了人与人之间本来应该温情脉脉的对话，使之变成了质疑、辩解和争吵。

同样的意思，如果换成陈述句来表达，就会好很多。
