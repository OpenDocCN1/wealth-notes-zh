# 你能接受的最大损失是多少。

由于世界是不确定的，很多时候我们没有办法计算出确切的收益，只能估算概率。这时候，就要用到最大成本可控法则了。

面对一个可能有很好的收益，但是也可能没有收益甚至有损失的事情，我要不要去做呢？这时候可以问一下自己，如果失败了，最大的损失是什么？在不在我可控范围之内？如果可控的话，那就大胆去做吧。如果最大损失是自己无法承受的，那就要小心行事了。

高手做事，都是追求概率上的优势，而不是追求百分之百的确定。他们愿意承担风险，所以也能有足够的回报。

人生就是不断的取舍。怎么取舍，就要看我们对待四种不同成本的态度。做每件事之前，不妨想一想你的四种成本都是怎样的，会对你的人生有很好的指导作用。
