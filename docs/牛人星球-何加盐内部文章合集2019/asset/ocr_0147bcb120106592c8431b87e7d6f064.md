# 生孩子那么痛，为什么有些妈妈愿意生第二个第三个？

分娩是人类所有疼痛中最痛的之一，每一位女性，在生产时，都要经历很大的磨难，想必有很多人，都会在最痛的时候，心里想着，生完这一个，以后打死也不再生了。

但是，这样发誓的不少妈妈，确又会在几年之后，再次怀孕，生下第二个宝宝，有的甚至还会继续生下第三个，第四个，第 N 个。而即使很多不愿再生的女性，也很少是因为生产时的疼痛，而往往是因为其他的原因（如没时间带、事业正在快速发展、经济不允许、不想再经历育儿的麻烦等等）

为什么会这样呢？是什么让这些妈妈们能克服恐惧，愿意再次去经历一遍地狱般的折磨？

女性的伟大和母爱的光辉，自然是其中一方面：生孩子的成就感，也赋予了生产超乎一般的意义，使得苦难具有了价值。但除了这些外，还有第三个原因：人脑的运行机制让女性在若干时间之后，会部分忘却生产的痛苦。

在《未来简史》中，由瓦尔 · 赫拉利认为，每一个人，都可以把自我分成“体验自我”和“叙事自我”，前者是正在经历一切事情的你，他体会到的是你的每一个瞬间的感觉；后者是时候回想的你，他会把你经历的一切，组合成一个个的故事和一段段的回忆。

叙事自我有时候会欺骗我们。他记录的不是我们每一个瞬间的真实感受，而是每一段经历里面的巅峰体验和最终体验的平均。
