+   2. 我们再设想另一个场景：有一个干净的水池，被一根横在中间的木棍分隔成左右两个部分，我在左边的水面洒满锯末，右边保持干净。然后，在木棍中间开两个小洞，让两边的水可以连通。

现在，我往左边的水池“duang”的一声扔了一块大石头，激起的水波，把锯末冲到了右边水池。

请想一想，如果我们在右边的水池里，树-一块可以粘锯末的板子，锯末在板子上会形成什么形状？

我们也很容想到，由于水是波纹式传导的，锯末不会只集中在板子上两个地方，而是会分布在很多地方。实际上，锯末的分布有点类似“| || | | | | | |”，这是因为同一条波在经过两个缝隙时，变成了两条波，这两条波会相互干涉，形成条纹式的分布。（图 3）
