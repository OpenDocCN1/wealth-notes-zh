面试的时候，也是重点考察价值观的时候。问问他对一些企业
和一些事例的看法，多追问几个为什么。了解其成长背景和上一次离职
的原因。了解其原公司的价值观是什么，其认同还是不认同。

一般来说，对方如果真诚作答，总会有一些分歧，这时，就要求
老板和人资的人定好标准，哪些分歧是绝对不可容忍，要一票否决的，
哪些分歧可以求同存异，哪些分歧是可以后面慢慢纠正的。例如，
雷军找一个顶级销售，听到对方说“我能把稻草卖出黄金的价钱”，
立马就否决——尽管其能力是自己急需的。马云偶然经过公司内部的
一个培训现场，听到讲师在讲“如何把梳子卖给和尚”，就冲进去把
讲师赶走了。这就是价值观的一票否决。

不排除有些应聘者会刻意迎合，隐瞒自己的真实心理。这个是没
法防范的，只能在后续中去发现。

# 第三，工作中的灌输与管理。

价值观问题不是一劳永逸的，不是贴在墙上就行的，要天天讲、
月月讲，并且要用价值观来指导一切行动、评判一切行动。

阿里巴巴的员工都要接受长期频繁的价值观教育，做专门的集中
