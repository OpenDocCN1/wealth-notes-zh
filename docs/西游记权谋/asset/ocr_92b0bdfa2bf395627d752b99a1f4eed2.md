# 缘起

四大名著作为中国古典文学的翘楚，地位尊崇，经世不衰。其中《红楼梦》更是傲视群雄、不可一世，由此敷衍出的红学最是绚烂夺目，光彩照人。《三国演义》、《水浒传》继之而起，也能煊赫一时，不负盛名。唯有《西游记》偏安一隅，难免不令人顿生“盛名之下，其实难副”之憾。作为一部小说，尤其是一部经典小说，九九八十一难连缀的情节作为一个整体被毫不留情的抛弃，不是落到神棍的手里被解说成比佛道经典更加难以理解的经典，就是被当成儿童题材图解成连环画、动画片，成为蒙学趣味十足的儿童读物。《西游记》的遭遇真是“冰火两重天”，令人难以理解：要么神秘的要死，要么简单的猖狂！

然而小说就是小说！小说最重要的就是情节！没有情节什么都没了。这么多年来，我们一直认为取经八十一难是单独成段，互相封闭的。正是由于这样的想法，书中有很多自相矛盾的地方都被我们放过了。我们没有仔细考虑过这些矛盾出现的原因，而是想当然的认为这因为作者身在凡尘，却妄言三界之事，故不能自圆其说耳。仔细阅读之后，就会发现原著各个章节之间的情节是紧密联系。《西游记》不是简单的故事连载，而是伏笔深藏，机缘不露，情节一贯始终。依着这样的思路，重读《西游记》，再仔细推敲原著中的只言片语，就有了新的发现。

孙悟空大闹天宫的时候勇冠三军，西天路上怎么会到处碰壁，灰头土脸？他能耐有多大？他到底是谁？

+   * 孙悟空的师父菩提老祖神龙见首不见尾，他的身份可疑吗？
* 玉皇大帝的对孙悟空束手无策吗？
* 为什么说唐僧的身世是谜？吃唐僧肉真的可以长生不老吗？
* 妖精们抓住唐僧为什么吃了露路，而是要先跟悟空赌斗不可呢？
* 为什么要西天取经，取大乘真经？取经为什么一定要唐僧步行，不可以驾云跟风？或者，也不可以由别人代劳？
* ……

其实问题还有很多，不再一一枚举。想要解开这所有的谜团，就必须打开思路，重新审视这部万世敬仰、千秋不朽的伟大著作《西游记》。

近三个月来，六铃披星戴月，辛勤耕耘，始有这斑斑残花、点点病果，不敢自珍，献丑愿与大家共勉。本文讨论的空间范畴，即版本为现行通行本百回《西游记》，谢绝珍藏本，亦谢绝其他善本古本孤本。不计论成书年代，成书意图，成书渊源，就该版本中的情节加以推敲辨辨。本文讨论的内容范畴，只涉及《西游记》，不涉及其他小说和文本，特别是《封神演义》。因此，不能以《西游记》之外的神话谱系及宗教体系对《西游记》中的情节加以证明和辩驳。当然，宗教经典和一般宗教常识的参考是必要的。否则，《西游记》将真的成为无根之水了。
