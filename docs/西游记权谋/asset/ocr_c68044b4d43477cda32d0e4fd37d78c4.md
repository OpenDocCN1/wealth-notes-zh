# 第二十四回 五庄观情归何处

孙悟空大闹五庄观这一节可以说是取经路上的第一次小高潮。为了能够复活人参果树，孙悟空四方奔走，最后在观音菩萨的帮助下才算是大功告成。那么这一节到底在讲些什么呢？真的就是悟空偷人参、毁树再复活这么简单吗？不是。本节真正的角，乃地祖之祖万寿山五庄观的主人镇元大仙，混名与世同君。五庄观中生有一般异宝人参果，其形状如出生未满三朝 的婴儿，其功效又如蟠桃一般极能延寿。这人参果就是理解五庄观的是是非非的关键之所在。我们来细细分析这一节。

这一日，唐僧师徒路经五庄观，意欲到观中借宿。恰巧，镇元大仙外出学术交流，前往上清天弥罗宫元始天尊处听讲“混元道果”。只留下了清风、明月两位最小的道童看守五庄观。镇元大仙临走时曾向清风、明月两位道童交待过，唐僧师徒取经会路过此地，不可怠慢了这位前世镇元大金榜长生转生的三藏和尚，可将人参果摘下两枚与镇元子参果。果然，镇元大仙刚脚刚走，唐僧师徒后脚就到了。这镇元大仙果真是神机妙算啊！分毫不差，料定了唐僧师徒会在他外出之际路经五庄观，于是事前做好了相关安排，可谓不谓不尽心啊！但是，事情果真如此吗？我们说过绝不相信天底下有神机妙算这回事，这个镇元大仙岂止是徒弟面前丢人。唐僧师徒前往西天大雷音寺取经的事情早就在三界传得妇孺皆知了。太上老君主办的《八卦》，玉帝主抓的九宫社的《三界时报》、《灵翁》、《九宫论衡》，四大天界联合推出的大型理论周报《三十三天道报告》，镇元大王主管的大型新闻类期刊《乾坤》，以及名下的《大日报》、《般若》等各大传媒均对取经队伍的一举一动做了详细的追踪报道。光是以保护神名义隐藏在取经队伍周围的专业战地记者（俗称狗仔队）就有三十九名之多：四值功曹、五方揭谛、六丁六甲、二十八位护教伽蓝。这些仔仔仔专为各大媒体爆料，提供一手资料。镇元大仙这样的大领对绝对不可能对这些极为敏感的舆论喉舌不闻不问。他对此一定早有关注。必定天天站到云端里仔细查探一番：取经队伍是否已经到达成山地区？多一日，他已经看到取经队正出现在他的视野中，于是就该命原天师的讲座在即，故意走开。那么，为什么说镇元大仙明知唐僧师徒的到来却又故意避开呢？原因只有一个，给悟空大闹五庄观创造机会。这么说的依据又在哪呢？

首先，我们先看镇元大仙给五庄观所留的交待。四十八个徒弟，他带走了四十六个，只留下两个最小的徒弟看守五庄观。【镇元子吩咐二童道：“不可违了大天尊的简称，要去弥罗宫听讲，你两个在家仔细。不日有一个故人从此经过，却莫怠慢了他，可将我人参果打两个与他吃，权表旧日之谊。”】这里的问题是镇元子没有向徒弟交待回程日期，一来，不了解，二 不安排都说明的。即便在这里元始天尊的简称没有提到讲道日程，时间不能不是一日， 至少也应当给下属明确一下大致的回程日期，起码也要提一下回程的事。这里镇元子非但 不交待其一日得回来，就在言语中似乎还肯定了这样一个事实：僧果来时我不在五庄观中，你们要好好替我招待他。而就在唐僧夜走五庄观的第二天上早上大仙就纠众弟子赶回到了五庄观中，难道仅仅是巧合吗？其实，镇元子这样的大仙对于老朋友元始天尊的讲座是可去可不去的。他也不需要修炼什么“混元道果”，无非就是与朋友捧捧场、叙叙旧而已。即便没有参加讲道 的简称，镇元子还是有其他理由离开五庄观。这是巧合，是镇元子故意安排的搅棍送徒之计。

就算是去听元始天尊的讲座，也没必要把全观的人都带走啊。难道元始天尊的 简称上还附有参选人清清单，必行一个个都不能少？留下个空的五庄观，五观之徒就空在园子里，这样做不是风险太大吗？难怪五庄师徒回来时不就说风月明，【众仙道：“他两个想是因我们不在，扔了东西走了。”】这里的东西不是指别的，就是指人参果。看来此次五庄观仅仅留下两个小道童看守之事，还是开天辟地头一回啊！要不然，众仙的猜测从何说起啊？
