# 第九回 喋血江州--唐僧的恩怨情仇

首先，我们来看唐僧是如何报仇的。唐僧知道自已的父母之事后，带着信物先是找到了婆婆，医好了婆婆的眼睛，安抚好婆婆再去长安相府报讯。此事，暂时按下不表。单说，殷丞相的反映：【“夫人休得烦恼，来朝奏知主上，亲自练兵，定要与女婿报仇。”】果然，第二天上朝，丞相近奏秦事：【“今有巨婚状元陈光蕊，带领家小江州赴任，被轿子刘洪打死，古女为妻；假冒臣婿，为官多年。事属异变。乞陛下立发人马，剿除贼寇。”】这里说了这么多，有四个字至关紧要：事属异变。为什么？这四个字，是对整件事情的定性：“事属异变”，定的什么性？造反也是！唐王一听，这还了得啊。立即拨付御林军6万由殷丞相带队前往平叛。

这里有三个问题：第一、刘洪李彪杀朝廷要员，刘洪还冒充赴任，这是欺君大罪，但这也够不上造府的罪名啊。这造反之事是殷丞相为女婿报仇，随句胡诌的吗？第二、为什么要派御林军平叛？还要有6万之众？抓刘洪要这么多人马？第三，为什么没有提到李彪？李彪是杀死陈光蕊的凶犯之一。

对于第一点，造反的事情是胡诌的，这种事情是能胡诌的吗？而且，为女婿报仇也不需要适应的这么大名头。光杀人造叛、冒充属员就足够叛他死刑了。那么造反就是真的咯？不错。真的有人造反。不过我们暂且不去讨论这个问题。接着看第二点，为什么要派御林军前往镇压？按照刚刚才的逻辑，如果的确有人造反，那么首先就该集禁结下的御王府部，就地镇压，何必劳烦众多？刘邦远征不是有家大业大。再说， viewpoint 大唐天下初定，就是有人造反也不稀奇，要是都派御林军前去镇压，京城都要空了。原因是这个造反的人，身份不简单，应该是皇族。御林军是皇家禁卫军，一般人是沒有资格让他看上的。想必御林军这些年来一真在追踪这个人。第三点，为什么没有提到李彪？这是故意的。

我们来看丞相是怎么领兵前去平叛的。【丞相领旨出朝，即使教场内点了兵，径往江州进发。晓行夜宿，星落鸟飞，不觉已到江州。殷丞相兵马，俱在北岸下了营寨。是夜女金牌下书唤到江州同知、州判二人，丞相也对他说此事，叫他提兵相助，一过下江南来。天尚未明，就把刘洪衙门围了。刘洪正在梦中，听得火炮一响，金鼓齐鸣，众兵杀进私衙，刘洪措手不及，早被擒住。丞相隔下两，将刘洪一干人犯，绑赴法场，众公军俱在城外接安去了。】整个过程可以说进展得非常之顺利，三两下子五，就把刘洪搞定了。

当然，这里也有一堆问题：1、丞相领兵为何径往江州，为什么不顺路先把在洪江渡口的李彪抓获？而是晚造道到江州之后，再让江州同知派人去擒获李彪？2、带了6万大军前来，为什么还要同知和州判提兵相助？3、捉拿刘洪同犯这样一个朝廷要员，丞相大人可没过手的机会？天尚未明，就把刘洪衙门围了。刘洪正在梦中，听得火炮一响，金鼓齐鸣，众兵杀进私衙；】连面都没见过，一上来就兵兵乓乓，搞个来个飞狗跳，万一弄错了怎么办？丞相是不是太草率了？4、【将刘洪一干人犯，绑赴法场】不处来刑讯的吗？这一干人犯是谁呢？

第一点，丞相领兵径往江州，就是为了先要控制往刘洪。我说过刘洪只是个小角色，他后面有人，最担心的是刘洪临死会咬出一些事情于是，这是丞相不愿意看到的。究竟是什么事呢？必然与丞相有关。同时，没有在先在洪江渡抓住李彪，就是为了不惊动刘洪，怕打草惊蛇。刘洪在江州经营18年，已然有一定的势力。第二点，同知和州判是洲主的左右手，让他们过江来，提兵相助并不是目的。这里面有两层考虑：一是做好说服教育工作，让他们和刘洪划清界限；二是先把你“双规”起来，万一当中有一些刘洪的坏心腹怎么办？这样比较保险。第三点，丞相一点也不草率，要的就是置刘洪于死地。至于真假除光蕊要不要验明正身，并不重要。因为，她相信他的女儿写给他的信。这封信里到底说了什么？不得而知，不过我们可以推测。
