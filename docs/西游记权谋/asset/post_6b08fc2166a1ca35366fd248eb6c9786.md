
# 第二十一回 乌巢国紫金钵兰禅 黑风山守心清真经

悟空弄巧成拙，玩出火了，把锦襕袈裟给弄丢了。要在平常，丢了也就丢了。唐僧也不能把他拉长了搓圆了。可惜啊！唐僧刚学会话紧箍咒。要是悟空找不回来锦襕袈裟，唐僧许愿说耍来自颅倒念上二十遍可以圆旧。悟空恨苦不提。为了要找回袈裟，悟空一产叠加盘，挖地三尺，也没搜出个头绪。

思了半晌，悟空才想到有妖精宝此可事。原来离这观音禅院三十里有一座黑风山，这个盗宝的黑熊精就是传说中的黑山老妖。悟空料定是黑山老妖搞的怪。于是，悟空只身前往黑风山打探妖精。就在芳草坡前，悟空窥见三个妖精席地而坐，正在商议召开“佛衣会”为黑熊精贺寿。悟空不由分说，举笔就打。当场打死白衣秀士一名，原是白蛇精化的。黑熊精和道人手脚利索，趁机悟空打死白蛇精的功夫就逃跑了。悟空紧追慢赶，一直追到黑风山黑风洞。在黑风洞前，悟空与黑熊精一番唇舌较量，没见高低。接着又是一番武艺赌斗，也未分晓。没想到，这个山野黑熊精诸却大得惊人。他主动与悟空停战，原因竟是为了按时用膳。黑熊精自顾自的罢战关门，悟空不答应也没办法。那怪虚嘠一枪，撤身入门，关了石门，收回小径，且安排定宴，书写请帖，邀请各山魔王庆会不题。看来，这个黑熊精根本没把孙悟空放在眼里。按理说，这不可能啊。明明白知道悟空是大闹天宫的弼马温，还这么阀怪情多，更不烦恼？

悟空回来报盘件时，素滞后依旧前往黑风山套贼。半路上，悟空遇见了前来观音禅院给金池长老送信的小妖。悟空杀妖夺信，方知这信是黑熊精邀请金池长老前往黑风洞庆赏“佛衣会”的。因此，问题来了：这个佛衣会是黑熊精从观音禅院到来的锦襕袈裟。俗话说的好，“偷来的锣鼓敲不响”。现在倒好！不仅要把偷来的锦襕袈裟拿出来大宴庆祝，并且还邀请这个名字上的“主失”前来观赏。这怎么说也说不通呀！那么这究竟是为了什么呢？其实，这封信并不是送给金池长老的，而是送给悟空的。黑熊精知道这锦襕袈裟是悟空在观音禅院丢掉的。他送信给观音禅院的主持金池长老言井及锦襕袈裟之事，其实是从侧面让金池长老给悟空带信，让悟空来黑风山。只可惜，黑熊精不知道此时的金池长老已然在投胎的路上了。问题是，一开始提出罢战的额是黑熊精自己，那么是什么原因让他又主动邀请悟空前来黑风洞呢？这黑风洞中必有玄机。

悟空打死送信小妖，化作金池长老模样，前来黑风洞中查勘。那怪大嗥道：“刚才差了小的去下唇他讲信，这时候还未到那里来，如何他就得这等迅速？想是小得不惯蹭着金，断是孙行者暗来讨了袈裟的。管事的，可把如来藏了，莫教他看见。”黑熊精派清楚金池长老来清赏佛衣，而金池长老到来之后，却又将佛衣藏起，莫让金池得见此宝。这不是“放了屁却使手掩”吗？黑熊精的脑子是不是坏掉了？这正说明了真正的收信人其实才是悟空。

悟空到了黑风洞中，没有应对几句，身分就暴露了。黑风洞中的情景并没有什么异常，只是装修规格过高，超标了，跟这个山野村夫的身份有点不相符。悟空的身份被识破，随即和黑熊精刀枪相向。一番赌斗，还没有分出胜负，黑熊精又鸣金收兵了。这回的理由和上一次不一样不看谁，竟然是因为天黑了。那怪道：“胜负的，你又住了手。今日天晚，不好相持。你去，你去！待明早来，与你定个死活。”注意这里黑精说的话。他不仅是鸣金收兵，而且还和悟空约定了明日再战。这又一次证明了之前的信其实就就是引诱悟空前来套贼。可问题是，黑熊精这么来回应明的折腾到底是为了什么之呢？引悟空来，又主动战悟空前来。黑熊精的举止岂无是前后矛盾吗？有一个案例，可能对理解这一矛盾有点帮助。金庸大侠的《笑傲江湖》中有一段这样的情节：令狐冲在华山山后的思过崖与涅骓丁里独行田间伯光比武时，令狐冲几次出入思过崖的洞口，每次都入功力就会大增一决。经过次数反复，终于反败为胜，制服了田伯光。这件事告诉我们，令狐冲之所以要反复复复的出入思过崖的山洞，就是因为洞中是有玄机的。同样，黑熊精之所以每次引悟空来战，悟空来了之后一经交手他却又罢战回洞，正是因为这黑风洞中有玄机。

### 有玄机。

但是，之前悟空已经进去勘察过了，是黑风洞中并无异常。其实，这黑风洞中的破绽就在那点破悟空身份的小妖身上。正查处，只见有一个巡山的小妖，来报道：“大王！祸事了！下请书的小校，被行者打死在大路旁边，他缔着袈裟儿，变化做金池长老，来骗佛衣也！”悟空打死小妖并趁机变化金池长老前来骗取佛衣这件事，这个小妖是如何得知？难道他看见悟空行凶了？理论上有可能。但是，这个小妖报名时，金池长老就在面前，他为什么不直接指出这个金池长老是假的，而是面对大王说出这一番极为精简而又到位话呢？被行者打死在大路旁边的这个称呼孙行者，而没有直指眼前的孙悟空，这说明小妖根本没有注意到面前的这个假金池长老修行。否则，他应该直指修行者说出这番话。从小妖说话的语气上看，他只知道悟空变化了金池长老来骗袈裟了，但是并不知道眼前的这个金池长老是真是假。事情必然是这样的：这个小妖前来报告是受人指使的，他跑来没头没脸的说出的这番话是别人教的。小妖只是在背书，既紧张又害怕，所以话语情境才不对。这番话虽然简单，但是这件事的前因后果全部说的清清楚楚，没有一点疑问，可谓精当！稍加留意就不难看出这话是事前准备好的。那么究竟是谁在暗中操纵这一切呢？正是因为这些人存在，黑熊精才几次三番的罢场回洞来请示下一步的动作。其实，并不是黑熊精想要来来回回的变悟空，而是因为悟空的每一处出现都有点令黑熊精措手不及。所以，仓促上阵的黑熊精还没明白下一步的指示就与悟空交手了。所以，黑熊精不得不找出来主持利弊的。

想要拨开云雾青天找出这事主使之人，就必须排除干扰找出这件事的最终受益者。黑风山一劫，真正的最终受益者只有一个人，那就是观音菩萨。因此，这个躲在黑熊精背后的人就是观音菩萨。观音菩萨欺骗唐僧，借他之手给悟空带上了紧箍儿。难道这件事就这么了？观音菩萨就用甩手手摔灰安心回落海落伽山了？不能。观音菩萨一定会关注悟空的反应。菩萨道：“这猴子说话，这等无状！既是熊精偷了你的袈裟，你怎来问我取讨？都是你这个孽獭大胆，将宝贝卖弄，拿与人观看，你却不知，唤风发火，烧了我的留云下院，反来我处说刁！”前面说过，从来不相信谁有什么知识文未来之事的能量了。就是关于菩萨一直在关注悟空的明证。果不其然，悟空借机烧毁了观音禅院。观音也趁此机会，教训一下悟空，力图真正当心志上收服孙悟空。于是，她瞒黑熊精前借袈裟的真实原因让黑熊精转趁盗取锦镧袈裟。但是，她又担心唐僧和悟空师徒不在这个新的圈袈裟。如果师傅让两个原地转几圈，我不就放弃，那么观音菩萨不是搬起石头砸自己的脚？所以，他就让黑熊精去请金池长老过来请赞佛衣。但是，事情出了意外，金池长老真的来了，黑熊精倒是真真的有点不知道该怎么办了。小妖点破了悟空的身份之后，黑熊更是不知该如何收场了。没关系，先不管方丈回去再说。

这个神通广大的黑熊精就在观音禅院附近，而且还与金池长老经常往来，时常出入禅院，不可能不起观音的关注。黑熊精之所所以那么听观音的话，八成是被观音骗了。观音一定跟他说过，如果办事得力，这锦镧袈裟就送给他是袈裟。所以，黑熊精虽然多次激动，要开什么“佛衣衣会”以示庆祝。而且，还那么有把握，明知道齐天大圣来托袈裟，却全不在意。自说自话的要开什么佛【party】会等备用，书籍呼唤，风风水火，搞得有鼻子有脸的黑熊精前到神院救火的，金池，他大执步，慢慢进去，正呼吹叫风火处，只见那后房无火，房脊上一片光灿。他却情知如此，急入里面看时，见那方丈间有些霞光彩气，案桌上有一个青毡包袱。这【情知如此】正是说明了，黑熊精前来印证了菩萨有关悟空纵火的预言。否则，这【如此】作何解？黑熊精走进方丈，又看到佛金袈裟，对菩萨的话更是深信不疑了，如果说一开始来救火的时候他对菩萨的话还是将信将疑。

这个时候黑熊精知道自己上当了。但是没有办法，铁血菩萨在此，黑熊精 “好歹不睁眼亏 ”，交出了袈裟。行者早已从鼻孔中出去。菩萨又怕那妖无礼，却把一个箍儿，丢在那妖头上。这个时候，菩萨为了使一招挤，出其不意的就给黑熊精带上了金箍。如来又取出三个箍儿，递给菩萨道：“…… 假若路上撞见神通广大的妖魔，你须是劝他学好，跟那取经人做个徒弟。他若不伏使唤，可将此箍儿与他戴在头上，自然见肉生根。各依所用的咒语念一念，眼胀头痛，脑门皆裂，管教他入我门来。可见，这三个箍儿分别是黑熊精、孙悟空和红孩儿三处，只有悟空的紧箍儿是依照如来法旨的，其他的用途都不对。红孩儿的暂且不说。为什么要给黑熊精带上金箍呢？因为，观音不能让黑熊精在悟空面前说出实话来，同时也不能当着悟空的面把他给杀了，情况紧急也只能使用金箍了。刚刚在悟空打死凌虚子时，观音还在口口声声的教导悟空要心存善念呢。可怜，黑熊精正要起身报仇，却不知道自己已经被菩萨暗暗宰了。否则，拼了老命也要喊声冤枉啊！

# 第二十二回 黄风岭上的 “ 左” 倾机会主义分子

黄风岭之难可算是西天路上取经队伍遇到的真正的第一难。黄风大王的虎先锋寻山，捉凡人与大王做个案酒，恰巧与取经队伍在坡坡上撞个正着。一番较量之后，虎先锋用了金蝉脱壳之计，使狂风搅走了三藏。

黄风怪见虎先锋捉来了三藏，弄清了指由之后，第一反应是【且莫吃他着。】为什么不等着吃呢？虎先锋也觉得奇怪。理由有三条：

- 唐僧的徒弟特别是孙悟空不好对付，担心吃了唐僧之后，悟空前来报复；
- 将唐僧馋条儿几刀，身子清翠，口味好；
- 等上三日三宿若不损闹之后，可以细想享用唐僧。

这就是三条经典理由。取经路上要吃唐僧肉的五妖怪抓住唐僧之后，不吃唐僧的理由，大致不出这三条。在这一点上，黄风怪可算是开了先河了。后面出场的无数妖怪在战略上无非都是在模仿黄风怪，复制黄风怪，不过战术上稍有不同罢了。这三条经典理由，真可谓是妖怪们出来打江山的 “ 三大注意（八项纪律）” 啊！这 “ 三大注意 ” 构成了取经路上所有妖怪和悟空斗智斗勇的战略理论基础，是妖怪们 “ 抓、等、斗三走 ” 经典战斗模式的理论渊源之所在。

我们说如来是推动整个谈判向前推进的主要力量，是谈判的幕后策划者。当然，玉帝是另外一个谈判幕后策划者。因为他也需要彻底解决势力范围的问题，至少是达成一个目前来说双方都能接受的妥协。但是，为什么三教队伍一上路，第一个跳出来找茬儿的就是如来的门下呢？如来不想谈判继续下去了吗？当然不是。

到目前为止，我们只是分析了天庭的政治局势，对于灵山大雷音寺的政局尚未剖析。按照我们一般的惯有的思路， “ 名门正派” 都是表面上团结互助、友爱尊重，其实背地里尔虞我诈、勾心斗角，结党营私、一盘散沙。 雷音寺上的政治局势就是这副调控。 而作为反派面皮出现的 “ 邪门歪道 ” 却都是义薄云天、肝胆相照、万众一心、表里如一。那么，在这如来领导下的佛派作为一支不择手段的扩张欲极强的反叛势力，是否真的是铁板一块、毫无破绽呢？答案是

### 否定的。

我们切忌将人与事的理解脸谱化、标签化。其实，佛派人部也是风云迭起、险象环生、暗流涌动、波涛汹涌。这个黄风怪的出现，其实暴露了佛派人各支势力表面上齐心合力、同气连枝，但实际上内部也是千戈绞绕、纷争不息。如来决意问鼎天下，玉帝坚持改革开放。两位帝尊，一位是一心要实现宏图霸业，另一位是要稳固基业永续。因此，他们既要外争国权，同时更要内求稳定，确保政权不易于。"攘外必先安内"，对内对外的政策一定要互相衔接，互相配合。因此，如何处理好内因与外因的矛盾，是一个摆在领导人面前的巨大难题。这不仅需要超凡人圣的领导艺术，更需要雄视三界 的宏 大目光、君临天下的王者气魄以及起苍龙振 的 军政能量。这就是两位领导人决意通过谈判来解决问题的国内外政治气候。从两位老人家的能量及智谋来看，可以说整体上没有问题，但是在局部地区还存在很大的变数，没有完全做到尽在掌控之中。

为什么说黄风怪暴露了佛派势力的内部裂痕呢？我们先来看看，灵吉菩萨是怎么来介绍黄风怪来历的。（灵吉菩萨）对行者道："他本是灵山脚下的得道老鼠，因为偷了琉璃盏内的清油，灯火昏暗，恐怕金刚拿他，故此走了，却在此处成精作怪。如来照见了他，该死罪名，故着我看辖，但他伤生造善，拿上灵山；今只冲撞大圣，陷害唐僧，我拿他去见如来，明正其罪，才消这场纠缠哩。"【这个黄风怪是一只得道的大鼠。"得道"二字在佛教之中是什么概念呢？根据大乘佛教的果位排名，"得道"二字意味黄风怪者至高可以是一尊佛，至少也是一个罗汉。也就是说，黄风怪的果位处于罗汉与佛陀之间，有可能是罗汉，菩萨或者佛陀。这样一个地位的得道者，会去偷如来的灯油吗？当然不会。因此，这是罪名是莫须有的。悟空刚到小须弥山道明来意的时候，灵吉菩萨对悟空解释到：【我受了如来法令，在此镇压黄风怪。如来赐了我一柬"定风丹"，一柄"飞龙宝杖"。当时被我拿住，饶了他的性命，放他去隐性归山，不许伤生造孽，不知他今日欲害师。有违教令，我之罪也。】从灵吉菩萨的入口里可以大致知道黄风怪为什么会在黄风岭作怪。黄风怪偷了灯油之后，逃到黄风岭黄风洞避难。结果被如来发现，如来派灵吉菩萨前来镇压。灵吉菩萨按黄风怪之后，就地释放，让他隐性归山（羁押 黄风怪），没想到黄风怪在黄风岭依然成精作怪、伤生造孽，并且无意中冲撞了唐僧师徒。那么，灵吉菩萨受如来法旨羁押黄风怪，为什么羁押地点不选在小须弥山而是选在离小须弥山 两 千里之远的黄风岭呢？ 我们再来看看这个佛先锋。虎先锋初遇唐僧师徒，一番交手，竟然虎口拔牙，从悟空八戒手里盗摄了唐僧。这说明这个虎先锋并不是等闲之辈。一观《西游记》里面的山大王，能有如此法力和智谋的妖精做先锋的，唯此一黄风大王耳。这里面有什么讲究吗？
