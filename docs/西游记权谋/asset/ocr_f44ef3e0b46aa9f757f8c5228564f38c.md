# 悟空收八戒 浮屠山玄奘受心经

# 中八戒自我介绍:

玉皇设宴会群仙，各分品级排班列。教封元帅管天河，总督水兵称节斧。只因王母会蟠桃，开宴瑶池邀众客。那时酒醉意昏沉，东倒西歪乱散泼。逞雄撞入广寒宫，风流仙子来相接。见他容貌挟人魂，旧日凡心难得灭。全无上下失尊卑，扯住嫦娥要陪歇。再三再四不依从，东躲西藏心不悦。在胆如天叫似雷，险些震倒天关阁。纠察灵官奏玉皇，即日旨当命运拙。广寒牢固不通风，进退无门难得脱。却被诸神拿住我，酒在心头还不怯。捱起灵霄见玉皇，依律问成该处决。多亏太白金星，出班俯朝禁言说。改刑重责二千锤，肉绽皮开将折折。放生遣贬下天关，福陵山下归家业。因我有罪错投胎，俗名叫做猪刚鬣。

从这里可以看出，八戒是因为在五百年前的那次补办的“蟠桃大会”上醉酒，并【逞雄撞入广寒宫】调戏嫦娥而被罚下界为妖的。这里【逞雄】二字，说明八戒撞入广寒宫调戏嫦娥是事出有因。并非是八戒独自一人来到广寒宫寻开心，而是跟三朋四友一起来放松放松的。八戒定是经不住挑唆，要在某些别有用心的人面前逞英雄，前去挑逗嫦娥。【风流仙子来相接，全无上下失尊卑，再三再四不依从，东躲西藏心不悦。】这几句说明，八戒的级别要比这风流仙子高级的多。嫦娥不敢得罪这个天蓬元帅。屡屡不能得手，八戒觉得太没面子了。于是，大光其火，【色胆如天叫似雷，险些震倒天关阁。】这个肯定是夸张了。但是，这个纠察灵官是怎么来的呢？肯定不是因为八戒叫声特大而从天关崩赶来的。可能是刚好经过这边，听到了声音，看了情况，于是直接跑到玉帝那边去打小报告了。可简直是八戒不走运了。八戒自己也是【即日旨当命运拙。】

但是这个借巧的可能性到底有多大呢？为什么纠察灵官发现天蓬元帅异常时不上前劝阻阻止呢？当然，不一定阻止了。但是，纠察灵官有处理现场问题的权力与义务。不可能发现情况什么都不做，就跑上去报告领导，而且还是大领导玉帝。这个治安小问题，纠察灵官就要报到玉帝那里去处置了，那玉帝岂不是死不了？而且，后面的反应也太过了。【广寒牢固不通风，进退无门难得脱。】把广寒宫围的水漏不通，这也太夸张了吧？仅仅是某个小领导醉酒滋事，怎么搞得跟孙悟空造反一样。找个大领导来骂一顿，领回去处理不就搞定了吗？有人说这是因为嫦娥的身份不一样，这个嫦娥是玉帝的小蛮。有多个大领导用明张胆的为小蛮出头？再说，就算是出头，没必要找这么多人出来吧！这不是指插过事，惹人非议吗？实际上抓住八戒根本就没费一兵一卒，没动一刀一枪。一个醉汉而已，诸神走将来就提走了。因此，我更加信是那些挑唆八戒来广寒宫的别有用心的人在暗中操控这件事。是他们把纠察灵官引过来，又让纠察灵官直接去报告玉帝的。那么到底是谁在策划整件事呢？谁发兵的呢，就是玉帝。不错，就是玉帝。另外，《西游记》里的嫦娥并不是我们通常理解的奔月仙子广寒宫的主人，只不过是月宫里的一個仙姝。第九十五回《假合真形擒八戒 真归阳正会龙神》中，【众抬头看处，又闻得孙大圣高声叫道：“天竺陛下，请出你那至后妃见者看。这宝镜下乃月宫太阴星君，两边的一个就是月里嫦娥。这个玉兔儿却是你家的假公主，今现真相处。】此处可以看出，嫦娥并不是一个人，而是指许多个仙姝。紧接着，【猪八戒动了欲心，忍不住，跳在空中，把八戒仙子抱住道：“姐姐，我有旧相识，我和你娶子儿去。”】这说明，当年八戒调戏的正是这名仙姝。最后，【那太阴星君令转仙幢与嫦娥众收回玉兔，径上月宫而去。】这说明，刚才悟空口称的【月里嫦娥】并不是特意的是专称，嫦娥和仙姝本就是一个意思。太阴星君才是广寒宫的真正主人，嫦娥充其量只不过是宫中的小娇媚。
