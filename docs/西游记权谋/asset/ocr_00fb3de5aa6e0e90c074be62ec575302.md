# 第二十六回 奎木狼--玉帝密使

黄袍者，星袍也。奎木狼思凡下界，其实质是钦差奉旨行事。此推断有金牌为证：【那怪腰间取出金牌，在殿下叩头纳罪。……玉帝闻言，收了金牌，贬他去兜率宫与太上老君烧火，带罪差操，有功复职，无功难加其罪。】黄袍怪回天庭面见玉帝时，什么都没说，第一步要紧是交出金牌。这分明是说他已完成任务，向玉帝先行报销。天庭诸仙与否都执金牌上闯呢？好像书中并没有交待。不过，《西游记》出现的金牌一般都是作为执行特殊任务时的皇室印信。比如，附录《陈光蕊赴任逢灾 江流僧复报世亲》中，【（殷丞相）星夜令金牌二丁唤到江州同知、州判二人，丞相对他说如此事，叫他提兵相助，一同过江而去。】又比如，第二十九回《脱难江流来国土 承恩八戒转山林》中，【（宝象）国王道：“你既这等说了一遍，寡人怕他怎的？宜进来。”】

即夸着金牌至馆驿相请。】再比如，第六十二回《涔垢谯心惟宝塔 缚魔归正乃修身》中，【三藏道：“现被小徒锁在金光寺里。”那国王急降金牌：“着锦衣卫快去到金光寺取妖贼来，寡人亲审。”】另外，悟空也曾在天庭为齐天大圣，也不见有什么上岗证金牌。因此，奎木狼此时上缴的金牌并非是上岗证，而是执行特殊任务的印信。

至于奎木狼下界的原因，其实是经不起推敲的。对此，玉帝却并没有深究。【奎宿叩头奏道：“万岁，赦臣死罪。那宝象国玉公主，非凡人也。他本是披香殿侍香的玉女，因欲与臣私通，臣恐他污了天宫胜境，他思凡先下界去，托生于皇宫内院，是臣负在前，变作妖精，占了名山，摄他到洞府，与他配了一十三载夫妻。一饮一啄，莫非前定，今便不敢到此成婚。”】

这是奎木狼给出的关于他为什么会私自下界的解释。不过这个解释是站不住脚的。如果真是披香殿侍香的玉女与奎木狼私通，并且不想玷污天宫胜境，就应当双飞双下，找一个无人知晓的世外桃源去逍遥快活。为什么玉女要下凡投胎转世呢？这个流程如此之漫长：百花羞公主成年，就让双方苦等了至少十五六年。同时，投胎转世这还是比较入耳的说法，其实说得好听就是自己找死。放着天庭的玉女不做，要自寻短见去转世托生。玉女是不是疯了？就算奎木狼不变心，真的找她继续前缘，双宿双飞，那么即使是无边风流浪与快活也与太守待香玉女无关了。因为，侍香玉女已经不存在了，活着的是百花羞公主。侍香玉女这一场当真是为他人做嫁衣裳了。因而，奎木狼在说谎。但是，玉帝没有抓住不放，而是让他蒙混过关了。其实，要揭穿他也很容易，就是去披香殿核实一下，是否有侍香玉女下凡？这本来应该是断电的一个必经步骤，但是主审人玉帝老爷此时并没有展开。这说明其中是有猫腻的。

【他原来是孙大圣大闹天宫时打怕了的神将，闪在那山洞里落荒，被水气隐住妖云，所以不曾看见。】这句话读着有点别扭。这里干嘛非要提到大闹天宫的茬儿？很容易给公众，以为奎木狼在悟空大闹天宫之后躲在山洞之中了。这里只不过是在强调奎木狼是认识孙悟空的。如果不认识孙悟空，他怎么会因为被孙悟空打怕而躲在山洞之中？难道是因为怕的时候久了，连怕得是什么都忘记了？但是，这个奎木狼却装作不认识孙悟空。不认识孙悟空的模样还情有可原，毕竟五六百年没见了。其实，悟空是认识他的。此事后文再提。在孙悟空自报家门之后，奎木狼一点反映都没有，好像脑子里完全没有这个人了，这就奇怪了。其实，奎木狼是真的不认识悟空的模样了。在悟空没有自报家门之前，他说了一句不杀的话，漏出了破绽：【那怪忽然省悟道：“我家有些认得你哩。”行者道：“我不打你，你再认认看。”】悟空自报家门之后，奎木狼立刻醒悟，就装作不认识孙悟空了。因为，他怕露出这一机。因为奎木狼下界的时候比较早，在取经之前，所以他认为荒野之地，并不知道取经这二一事。当时，玉帝也不可能对奎木狼讲取经的具体情况，玉帝本人对于取经的具体情况也并不是很了解。所以，玉帝派奎木狼下界时的目的就是盯住孙悟空，为难孙悟空，进而给整个取经队伍出难题。如果，
