# 第二十三回   莫家庄耆师大全

唐僧到底有没有色心？这个问题一直困扰着所有关心取经大业的人们。同样，一路走来这个问题也一直困扰着他的三个徒弟。八戒色欲心重，以己推人，他是不会相信师傅真的是清心寡欲的。悟空一路上对唐僧的清心寡欲是十分怀疑的。并多次对唐僧可能的不贞做了相应的安排：如果失了元阳，大家散伙；如果坚忍不泄，继续西行。比如，第五十五回《色邪淫魔唐三藏 性正修持不坏身》中，【行者道：“你且立住。只怕这怪物夜里伤了师父，先等我去打打听听。倘若被他呸了，丧了元阳，真个亏了老孙，却就大家散伙；若不乱性情，神心未动，却好努力耕持，打死精怪，救师父去。”】沙僧表面上是相信唐僧的，可是沙僧是个受了唐僧的人，对一切身外事物已经看淡了。对于感情这回事，他是宁愿相信师傅的清心寡欲，而不愿意对师傅有过多的负面想法。他对于师傅的坚守，与其说是充满信心，不如说是充满祈望。

为了能够一探唐僧师徒的虚实，四位菩萨化身美色，亲临现场实施考验。唐僧师徒初到莫家庄，女主人即开门见山提出要“坐山招夫”，给自己及三个女儿招赘。唐僧听说这话，当时的反应是【推拳妆哑，眼目宁心，寂然不答】。接着女主人接着往下说，唐僧的反应是【如痴如蠢，默默无言】。等女主人将具体情况都介绍完了，唐僧的反应是【好似雷惊的孩子，雨淋的虾蟆；只是呆呆挣持，翻白眼几打仰】。唐僧这一系列的反应说明了上面呢？惊讶。除此之外，有一点可以肯定，就是唐僧不开口。为什么他不开口呢？八戒也很奇怪，更着急。于是是【走上前，扯了师父一把道：“师父！这娘儿子告诉话，怎么个详子不睬？好道做个理会些！】那师父猛抬头，嗤的一声，喝退了八戒道：“你这个孽畜！我们是个出家人，岂以富贵动心，美色留意，成得个甚道理哩？”】其实八戒什么都没说过，只是提醒一下师傅做个理会。当然，他心里怎么想的，大家都知道。结果八戒的举动被唐僧训斥了一番。唐僧训斥得有根有据，在情在理。其实，我们通观唐僧在西路上的表现，就会发现唐僧对于美色的一贯态度就是不开口。不开口就是不说破，不说破就是有玄机。

那么玄机在哪呢？莫家庄女主人提出“坐山招夫”时说道：【适承长老下降，想是师徒四众。小妇女四个人，意欲坐山招夫，四位恰好。不知尊意肯否如何。】这里提出的配婚原则是嫁女四个配师徒四个。具体化之后，自然就是三个女儿与三个徒弟配婚，娘亲与唐僧配婚。这么一个分配方案，换作我，我也不会同意啊！为什么？唐僧师徒四众之中，唯唐僧的条件最好。偏偏让这个条件最好的唐僧娶老年色衰的寡妇，而把三个黄花大闺女嫁给三个相貌丑陋的妖猴徒弟，这不是埋汰人吗？为什么说唐僧条件最好？相面血迹，唐僧是南赡部洲大唐皇姓；论身世，唐僧的父亲是大学士陈光蕊，外公是开国元相 program；论背景，唐僧与大唐太宗皇帝是兄弟；论职务，唐僧是左僧纲、右僧纲、天下大阐都僧纲；论长相，三个徒弟根本不能与唐僧相提并论。那三个徒弟具体又是什么情况呢？大徒弟孙悟空，来历不明，在五行山坐了六百余年的大牢，刚刚刑满释放。要不是唐僧经过相救，恐怕今要把牢底坐穿。二徒弟猪悟能，是个吃懒做的，个调戏嫦娥的臭流氓，关键还是个有妇之夫。三徒弟沙悟净，神形木讷，是被天庭判了流放罪的囚犯，而且还被玉帝毁了容貌。所以，菩萨们一开口就错了，唐僧对这样的安排绝对是不满意
