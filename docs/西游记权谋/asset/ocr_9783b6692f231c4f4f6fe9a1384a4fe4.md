# # 第十八回 八十一难何其难

谁都知道西天路上困难重重，为了取得真经，唐僧师徒经历了九九八十一难。从唐僧出生时计算起，唐僧经历了全部劫难。悟空、八戒和沙僧先后加入团队，经历的难数亦不相等，依次为七十三难、六十九难和六十五难。这经历难数的多少，与他们师徒四人修成的果位排名完全一致。

从唐僧西出长安取经到取经回到长安，历时十四年，共计经历七十七难。这七十七难之中，有些劫难是同一个妖怪制造的，有些灾难是在同一个地方遇到的。因此，按照劫难的发生地或者肇事者对这七十七难重新进行分类，可以划分为四十六大难。这四十六大难中，凌云渡脱胎换骨这一难对唐僧没有伤害，只是渡过这一劫需要克服心理上的障碍，这一难在我们做分析时暂时剔除掉。因此，只剩下了四十五大难。

+   1、这四十五大难中的妖怪能直接率出背景来的有十六大难，没有背景的有二十九大难；
2、这四十五大难中，有难度需要请人帮忙的有十九大难，有难度自行解决的有四大难，没有难度自行解决的有十八大难，没有难度有人帮忙的有四大难；
3、这四十五大难中，不是一回篇幅的有两天，占一回篇幅的有二十一大难，占两回篇幅的九大难，占三回篇幅的有七大难，占四回篇幅的有六大难；
4、这四十五大难中，是妖怪性要吃唐僧肉才产生的只有九大难，其余三十六难原因各异。

对西天路上的这四十五大难，做了如上的分类之后，我们对西行途中的妖魔鬼怪基本有了一个细致的了解。后文将对其中意义重大、篇幅较多的劫难进行详细分析。对于一些因意外而发生的没有重大意义的劫难，进行合并梳理，归纳分析。
