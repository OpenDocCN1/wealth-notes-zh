# 第一章 大闹天宫

神仙和妖怪有什么区别呢？

一个代表正又善良，一个代表邪恶残忍？胡扯。神仙里面也有混蛋和流氓，要不然天条是干什么用的？令人憤慨的是，神仙里面更出道貌庄严的伪君子，经常让你防不胜防。当然，妖怪也不见得都是祸害。有些妖怪觉悟还是蛮高的，并且是一心向善，要求正果的。比如，白素贞就昰一例。就《西游记》中而言，一些山精树怪、巡山小妖之类的并无歹毒之心，甚至有些妖精还十分的单纯可爱。

一个是法力无边，一个是势孤力弱？胡扯。荒唐。牛魔王的法力，轧死一群神仙饭桶。诚所谓“道高尺，魔高一丈。”道行压人呀！同一个等量级的神仙和妖怪，法力没有高下之分，也就是个一物降一物罢了。

一个是道骨仙风、宝相庄严，一个是披牙咧嘴、神情猥琐？胡扯。荒唐。肤浅。不能因为人家不注重仪表就是说人家是妖怪吧？以貌取人可是可耻的。更何况，大千世界的审美标准到今天还没完全统一呢！

那么，区别究竟在哪里呢？是什么造就了这个不可逾越的鸿沟呢？

有人列出了神仙鬼怪妖魔的简单定义，判断时可以对号入座。具体粘貼如下：

+   - 神，是指人死后灵魂升天者则为神；（此处区别于上古大神。）
- 仙，是指活着的人（肉体）经过修行或奇遇而直接升天者则称之为仙；
- 鬼，是指人死后灵魂不能升天者则为鬼，鬼入地下、地宫或地狱，也有游戏孤鬼；
- 怪，是指没有生命的物体，例如木、石、物品、器具等，发生各种不正常的变异，称之为怪；
- 妖，是指禽兽一类的动物、某些花卉，经过修行等能幻化成人形为祟为祸者，称之为妖；
- 魔，是指人、神、鬼、妖等迷迷本性或未本面目，发生变性或变态，亦称“入魔”。例如，人心魔、魔障、“走火入魔”等等，人有神魔，鬼有魔鬼，妖有妖魔……所以魔不是独立的实体，而是一种状态。

那么，我们是不是就以以此来判别神仙妖怪吗？当然不是。这样是不是就成了十足的独立论者了吗？有道是“英雄孰问出身”嘛！二十八星宿，都是动物，可是他们明明是位列仙班，不是所谓的妖魔。因此，完全照着重面的标准来划分神仙妖怪，过于机械了，没有抓住事物的本质区别。

神仙和妖怪作为划分干部和群众阵营的两大身份标志，一定要把握住它的体制含义。根据目前国际国内形式，就像网友们提到的那样，他们的唯一区别就是：是否有正式编制。有正式编制的就是神仙，一切待遇从优；没编制的，或者是暂时没编制的，对不起，任你法力广大、道行高深，只有歧视，没有待遇。或者者，待遇霄壤之别。

那么神仙竟竟有什么待遇呢？引无数英雄竞折腰。人鬼动物，花草树木，都想修炼成神仙，占个编制。简而言之，神仙有两大待遇：1、长生不老；2、终身制。
