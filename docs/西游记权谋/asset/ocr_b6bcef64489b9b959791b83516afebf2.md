# 第二回 孙悟空的前世今生

孙悟空的身世来历，恐怕是解读《西游记》的最大难点了。目前为止，仍是谜团。

让我们来看看原著中关于他身世的表述吧。

【那座山正当顶上，有一块仙石。其石有三丈六尺五寸高，有二丈四尺围圆。三丈六尺五寸高，按周天三百六十五度；二丈四尺围圆，按政历二十四季。上有九窍八孔，按九宫八卦。四面更无树木遮阴，左右倒有芝兰相衬。盖自开辟以来，每受天真地秀，日精月华，感之既久，遂有灵通之意。内育仙胞，一日进裂，产一石卵，似圆球样大。因见风，化作一个石猴。】

就这么区区一段，可谓精简直。但是，我们能从这里面看出什么来呢？看了很多遍，只能得出这个结论：孙悟空乃是仙孕育的石猴。仅此而已，其他一无所获。取经团队里面有个大世外不凡，这个孙悟空的来历真的就这么单纯吗？答案是否定的。

如来佛为了确保他的“东扩计划”顺利贯彻，不惜将他的二徒弟金蝉子打入凡尘，从大唐中华万里迢迢西来取经。更是向阿弥陀佛来了观音菩萨这样精兵强将，运筹帷幄，善加扶择。那么作为取经保种神的孙悟空，又怎能够随随便呢？这个角色可以说，比唐僧和观音菩萨的地位还要重要。没有他，一切免谈。如果说，如来选取了观音菩萨，观音菩萨选取了唐僧，那么这个孙悟空的人选就是如来亲手敲定的。除了当事之外，如来瞒过了所有的人。想要瞒住敌人，先要瞒住自己人。

首先，我们来看，如来到底知不知道孙悟空的来历。第七回《八卦炉中逃大圣 五行山下定心猿》中如来在收伏孙悟空之前曾经对他说道：【趁早皈依，切莫胡说！但恐毒了害手，性命顷刻而休，可惜了你的本来面目。】这说明如来是知道孙悟空的本来面目的。但是，孙悟空对于自己的身世却是一概不知。他只知道自已是一石猴。后来，第五十八回《二心搅乱大乾坤 一体修炼真谛说》中，如来佛详细真教猴王的时候说道，【又有四猴混世，不入十美之种】。又继续解释说道，【第一是灵明石猴，通变化，识天时，知地利，移星换斗。第二是赤尻马猴，晓阴阳，会人事，善出入，避死延生。第三是通背猕猴，食日月，缩千山，辨休谷，乾坤摩弄。名是六耳猕猴，善聆音，能察理，知前后，万物皆明。此四猴者，不入十美之种，不达两间之名。】

这里的灵明石猴到底是不是孙悟空？如来没有直接说明。但是孙悟空确实符合这个灵明石猴的所有条件。第一，不在十美之种。第三回《四海千山皆拱伏 九幽十类尽除名》中有这样的表述：【裸虫、毛夷、羽虫、居虫、鳞介之属，俱有立道之名。又看到猴猴之类，原来这猴他相，不入人名；似裸虫，不居国界；似走兽，不伏麒麟管；似飞禽，不受凤凰辖，另有个簿子。悟空亲自检阅，直到那魂字一千三百五十号上，方注着孙悟空名字，乃天文石猴，该寿三百四十二岁，寿终。】原来，不光是孙悟空，整个猴类根本就不在十类之中。现在类归，孙悟空什么是猴子，而不是大象老虎之类了吧。世间动物分为五类，谁会注意到猴子原来不在五类之内。让你查无可查，而且这还是来历不明的天生石猴。第二，【通变化，识天时，知地利，移星换斗。】七时二般变化就是由此而来了。识天时，知地利，移星换斗。这一点，孙悟空在向别人介绍自己的时候曾多次提到。比如，第八十四回《风仙郡雨止关 孙大圣告施霖》中，行者说道："祈雨有甚难事！我老孙翻江搅海，换斗移星，踢天弄井，吐雾喷云，担山赶月，唤雨呼风，哪一件儿不是幼手弄子的勾当！何为换计，"。第六十六回《外道施威欺正性 心猿显圣灭诸邪》中也有提及。不一一举例了。因此，可以断定如来说的这个灵明石猴就是孙悟空。如来是知道孙悟空底细的。
