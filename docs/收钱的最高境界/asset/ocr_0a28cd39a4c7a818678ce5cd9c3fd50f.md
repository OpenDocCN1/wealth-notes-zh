# 修神法则一：权威定位

不管你是做什么行业，你要去“修神”，成为别人眼里的专家，那这一点你必须先做到，那就是权威定位。

你要做哪一方面的专家，比如你是卖衣服的，你就要把自己定位成服装搭配专家，不管你现在是不是，你要先假设定位，然后一步步去往这个方面实现。

![](bbox=[0.15, 0.45, 0.85, 0.59])

包括现在很多人做互联网一样的，你得先找好定位啊，你不要今天这里搞一下，明天那里搞一下，一诺老师问你，你这能做成什么事？

昨天见你，你在做直销，今天见你在做金融，这样别人怎么会相信你，会觉得你不靠谱，更别说什么专家了。

所以，第一点，你要先定位好，定位定江山，这点非常重
