# 第一掌：天堂地狱法。案例 3

大家都知道，一诺老师讲了很多技巧往往跟谈恋爱有关系，因为，这两个事情是非常相似的。

所以，天堂地狱法，同样可以用到谈恋爱上。

有很多人问：“请问一诺老师，我喜欢一个女孩子，你能教我怎么去征服她吗？”

![](bbox=[0.14, 0.45, 0.88, 0.58])

好，现在一诺老师老师就教你，如何用天堂地狱法征服你的梦中情人！

你刚开始就夸她，说她的好，哪方面都很优秀，（声音，走路的姿势，优雅，心态，性格，皮肤，修养）

她是不是情绪马上就上来了，会很高兴，就在这时候，你话锋一转，说：“不过，我想我们俩个应该不会走到一块。”
