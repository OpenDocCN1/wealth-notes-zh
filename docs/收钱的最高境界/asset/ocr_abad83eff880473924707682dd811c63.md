# 玄机一、有没有消费者？

一诺老师研究发现，凡是做大的企业，他一定符合整个商业生态系统，就是一定要有最基础的人，那就是——消费者。

也就是说，一定要有为产品买单的人，他不为别的，他就是进来消费产品的。

如果你一看，里面全是经营者，全是想一万换十万的人，铁定是骗局，因为只有无数的消费者，才能养活经营者。

![](bbox=[0.14, 0.48, 0.88, 0.62])

就像一诺老师课程现场，当一诺老师讲完课之后，有人觉得很实战，他想学习更高级的课程，于是就报名参加学习，这种人纯粹就是花钱买知识，这就是消费者。

有人学习完之后，可能十个弟子里面有三个想要跟一诺老师合作的，于是就加入一诺老师的全球合伙人。
