# 第一、文案

文案不是普通的文字，具有说服性的文字称为文案，所以，你必须要学会设计让人看了就欲罢不能的勾魂文案。

![](bbox=[0.15, 0.49, 0.89, 0.62])

文案分为短文案和长文案。

短文案可以用在朋友圈和微信聊天，为什么很多人发的信息石沉大海毫无音讯？因为他写的短文案根本没有吸引力，在本书后面的章节内容，你可以学到非常多勾魂短文案的技巧。
