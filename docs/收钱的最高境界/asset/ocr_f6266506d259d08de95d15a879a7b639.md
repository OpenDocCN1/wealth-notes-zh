# 第 78 课：能量格局

# 错误成交 1・介绍产品

你有没有发现，当你去见客户，介绍你公司的产品，你说：

“我是某某公司来的，我有一个很好的产品要介绍给你……”

当你这样一讲，其实你已经掉入了左下角这个“输局。”

因为你的客户觉得：“你需要我，但是，我不一定需要你，我还有很多选择。”
