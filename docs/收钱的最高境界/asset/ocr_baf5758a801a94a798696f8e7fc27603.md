# 第十四掌：状态利益法・三个模版

模版 1、未来的状态

想要达到实现的一种状态，或者说是欲望。比如做微商的朋友，他想要实现的状态可能是每天大批的人去主动加他为好友，可能是晚上睡觉时都有单子赚钱，可能是……等等太多了。

模版 2、曾经的状态

哪怕一个人现在非常的有钱，有权，但是很可能他以前是非常窘迫的，当你能把他曾经的状态描述出来的时候，他也会非常上心。
