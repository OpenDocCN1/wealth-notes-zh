# 什么叫低价格？

比如有一个人，一个卖豪华游艇的人，他跑到沙漠里面去卖游艇，价格是原价的十分之一，请问一下价格低不低？

可是请问一下沙漠里面的人会不会向他买游艇？很显然答案当然不会，为什么？

因为在沙漠里的人根本就不知道的游艇的价值，游艇对于他们来讲根本就没有用，就算价格低有什么用。
