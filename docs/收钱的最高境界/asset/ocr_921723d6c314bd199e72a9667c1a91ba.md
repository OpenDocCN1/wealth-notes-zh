# **第十七掌：词汇勾魂法。勾魂词**

那么这些词汇有哪些？一诺老师总结了一套：

强奸、流氓、毒辣、血腥、绑架、美女裸体、极度疯狂、想入非非、性幻想、杀手……等等，这里只列举几个。

![](bbox=[0.15, 0.38, 0.88, 0.51])

**案例 1：** 让顾客随时随地对你“想入非非”的绝密策略。

**案例 2：** 不花一分钱就彻底“绑架”客户的手段。

**案例 3：** 比“美女裸体”还让人手舞足蹈的布局秘术！

你有没有看到，简单的语句加入这些原始词汇，是不是瞬间让你非常渴望知道？是不是勾魂效果瞬间飙升？

因为，所有的原始词汇都触及到了你的原始需求，让你的心理产生压力，瞬间不得不采取行动！
