# 收钱秘籍·招招见血《收钱的最高境界》商业社会没有收不到的钱！

他说：“一诺老师教给他的演讲方法实在是太有效了，因为他在一次高端的会议上，他跟主办方讲好，让他上台讲半个小时，于是他就上去讲，没想到，他讲完之后，台下就有非常多的人要做他的代理商，现场他就成交了 400 多万，而且还有人说想要投资他。”

所以一诺老师为什么成为讲师？

当一诺老师把这些知识教给别人的时候，一诺老师看到那些老板因为学会了演讲，他就不用那么辛苦了！不用一对一的去成交，直接批发式的成交，去找到代理商，投资商，合作伙伴，这样他可以节省时间，快速的把企业做大，

20 年前，一诺老师最开始做销售类的培训，帮助很多企业打造销售团队，教他们销售，教员工懂得感恩，付出！

一诺老师看到员工业绩提升，看到公司整体业绩提升，看到老板不再为团队而烦恼，一诺老师内心有一种说不出来的感
