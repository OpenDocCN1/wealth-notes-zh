# 第10课：卖产品

# 3、成交系统

在一诺老师《……最高境界》课程上，有很多做自媒体的人，他们在互联网上吸引了很多粉丝，但是只能接广告，接广告赚的大钱都被别的商家赚走了，或者出书赚一些版权费。

他们有这么多粉丝，为什么还要学习一诺老师的课程呢？

因为他们的转换率并没有实现最大化。

很多人有了产品有了客户，他们的第二大问题就是不会成交，很多实体行业也是一样，成交率非常低。

接下来看一张收入公式图：

| 客户数量 | X | 利润 | X | 成交率 | = | 收入 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 100 | X | 50元 | X | 10% | = | 500元 |

在前面，一诺老师讲过，卖产品有三大玄机。

**第一个暴利产品，暴利产品决定你的利润。**

**第二个精准客户，客户的数量决定你的客户质量。**

**第三个成交系统，成交系统决定你的成交率。**
