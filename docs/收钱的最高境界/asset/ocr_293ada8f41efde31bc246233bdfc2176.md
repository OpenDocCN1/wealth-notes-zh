# 如何扭转主控权？

在前面我们可以在格局的表格发现：当你需要客户，客户就有价值，客户就有主控权，你没有有主控权，客户的权力就最大，当客户的权力最大，客户就可以赢得最多！

主控权的游戏规则，奥秘全在格局游戏里面。

![](bbox=[0.15, 0.41, 0.88, 0.55])

当你去到一家公司谈生意的时候，客户会觉得他有很多选择，客户觉得你的价值低过他，钱又在他的手上，怎样用钱是他的权力，所以通常主控权都会在对方的手上。

同时，男的追女的时候也会一样，女的会觉得主控权在她的手上，她有很多选择，除非你的价值比他高，主控权才会回到你的手上。

那我们到底该怎么办？你想不想知道如何化解？
