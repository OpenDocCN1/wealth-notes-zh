# 第81课：能量格局

# 错误成交4 · 要你证明

你想象一下，假如你是一个卖鞋子的，你一进去说：“刘老板，我是卖鞋子的……我们的产品可以帮助你节省省钱又能够赚钱……”

你……（谁的产品不是这样，你的竞争对手也是这样告诉他），你只要讲了这样一句话，你就会立刻失去主控权。

![](bbox=[0.15, 0.44, 0.88, 0.59])

因为，客户就会跟你说：“噢，其实你公司的鞋子我不需要，我们已经有很多供应商了，除非你可以给到一个很便宜的价格……”

或者客户会说：“噢，我们已经很XX公司配合了很多年……”

请问这客户这是在做什幺？他是想要你证明，你有没有资格，一旦这时候你去证明，你就失去主控权了，能明白吗？
