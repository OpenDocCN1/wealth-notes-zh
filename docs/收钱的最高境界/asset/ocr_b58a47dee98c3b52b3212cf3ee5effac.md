# 第六掌: 概念勾魂法。案例 1

比如你是卖衣服的, 如何用概念勾魂？

很简单, 有买衣服的去你店里, 你不要跟塑造什么价值, 你直接对她说:“我想问一下您了解现在的‘新女性’风范吗?”

客户肯定不知道啊, 这是你包装的概念, 这时候你就可以给她植入你的思想了, 后续成交就会变的很容易。

![](bbox=[0.14, 0.44, 0.88, 0.59])

比如你是做保险的, 你不要跟他说你是做保险的, 你直接问她了解过资产投资保障权吗?

反正, 就是你自己包装一些概念。

记住: 运用概念勾魂, 你一定要配合你的表情和口吻。
