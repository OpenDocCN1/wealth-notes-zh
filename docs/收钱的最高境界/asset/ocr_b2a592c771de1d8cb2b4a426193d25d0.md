# 勾魂的核心原理

什么是勾魂？四个字：打破传统。

就是反其道而行，打破传统，也就是你说一句话，或者做一个动作，他的大脑里找不到答案，一片空白。

他没听过这样的话，他很想知道答案，想追寻真相，他就瞬间被你勾魂了。
