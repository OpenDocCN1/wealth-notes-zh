# **第53课：勾魂十八掌**

# **第四掌：欲擒故纵法 • 案例1**

有一次，在一诺老师的课程上，有个弟子问：“请问一诺老师，我喜欢一个女孩子，但是很难约出来，怎么办？”

后来一诺老师老师教了她一招，让他轻松就把女孩子约出来了，那一诺老师到底教了他什么？

![](bbox=[0.15, 0.41, 0.89, 0.53])

先让你来看一下这个弟子的案例：

在很多年前，弟子和朋友一起去吃饭，介绍了个美女给弟子认识，介绍之后，就一起在一块聊了一会，留了联系方式，然后就各自回家了。

晚上的时候，弟子就发信息给她，你想不想知道弟子是怎么发的，想不想知道弟子是怎么勾魂的？

弟子是这样发的：“你怎么可以这样？”
