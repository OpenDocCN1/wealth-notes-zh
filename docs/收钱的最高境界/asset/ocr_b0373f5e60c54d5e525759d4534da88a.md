比如其他销售型的行业，一诺老师研究发现，凡是团队带不好的企业都存在两大问题：

# 第一：员工没有收钱的能力。

很多员工刚从学校出来，根本就没有经验，所以一般大企业，员工进入团队，都有专门培训员工销售的课程，比如保险行业，房地产行业，美业等。

# 第二：员工没有执行力

员工为什么没有执行力？
