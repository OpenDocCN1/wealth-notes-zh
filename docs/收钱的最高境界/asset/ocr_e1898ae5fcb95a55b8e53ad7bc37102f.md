# 第90课：造神玄机

# 敲串隆打术·法则

1、前提条件：别人首先对你说的话感兴趣，所以，一诺老师前面讲解那么多关于勾魂的技巧，然后再搭配这套技术使用。

2、通过旁敲侧击的方法问对方，然后观察对方的反应，一旦猜中，不管是好的还是坏的，马上就隆自己，卖自己的权威。

![](bbox=[0.15, 0.41, 0.88, 0.55])

3、不断地以可能性和肯定性这两种手法去说话，不要单一，只用可能性话语说话，让人感觉没主见，只用肯定性话语说话，让人感觉太主观。

4、当对方觉得你说的很有道理，觉得你就是专家的情况下，慢慢开始多用肯定性的字语。

5、隆和打的时候都用肯定性的字语，特别注意隆最好在对方给了肯定回答的情况下，不然容易让人觉得王婆卖瓜，自卖
