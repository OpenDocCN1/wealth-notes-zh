# 第24课：收钱能力

# 一股神秘的力量

你曾经有没有见到一些人，不管他们的相貌多么好看，讲的话多么好听，但你就是偏偏没办法相信他们？

但是，有些时候，你才见到一个人，他才讲了两三句话，你就好像跟他有一见如故的感觉，有没有这种情况？

如果待会一诺老师给你揭秘，如何让每一个人见到你，就像是一见如故的感觉，瞬间打开心门抓住他的注意力，甚至让他神魂颠倒迷恋上你。

在后面一诺老师给你讲解十八种勾魂绝学，你想不想学会这些技巧？

你应该见过那些训兽师，把小动物训练到让它站就站，让它坐就坐，让它滚它就躺在地上打滚，你有没有见过？
