# 第 93 课：造神玄机

# 敲车隆打术・案例 1

一诺老师记得在去年，在广州有一家美容连锁店的老板，请一诺老师去做销售顾问，一诺老师用这一套敲车隆打术帮他们的销售人员设计了一套如何变成客户心中专家的话术。

![](bbox=[0.15, 0.36, 0.88, 0.5])

他们用一诺老师的方法，基本上到后面要求成交，从刚开始成父率不到 30%，到后面提升到 80% 以上，那他们是怎么做到呢？现在，就给大家示范一下。

假如美容师在服务顾客的时候。

美容师说：“一般米说，我这样按你这里，你是会有反应的，要么感觉到酸，要么就有点疼”。

请问这是在做什么？这是敲。

美容师说：“请问你是感觉到酸还是疼呢？”
