# 第4课：商业本质

# 客户买单的真正原因

一诺老师研究发现，在原始社会，人类商业起源于以物易物，但是由于物与物不等价，比如我拿一只鸡，你牵一头牛，这样很显然不公平。

于是到商朝，人类发明了第一个货币——贝壳，后面发展成铜币、银币、纸币。

为什么我拿一只鸡，你牵一头牛不肯换？

因为，牵牛的人觉得一只鸡的价值没有一头牛的价值高。
