# 第9课：卖产品

# 案例：万能吸粉大法“一二三策略”

记得在 20 年前，一诺老师刚刚踏入培训行业不到两年，当时一诺老师开的第一场公开课，现场来了 13 个人。

这对于一个心怀改变世界之志的讲师来说简直无法容忍，虽然那场演讲一诺老师依然很用心在讲。

没想到竟然有 8 个人成为一诺老师的梦想合作人，有 3 个人成为一诺老师的弟子，其他 2 个听到一半就走了。

虽然成交率很高，但自从那次之后，一诺老师下定决心，一定要学会增加客户数量的方法，下次人数一定要突破 500 人。

![](bbox=[0.15, 0.57, 0.88, 0.7])

于是一诺老师大量研读营销书籍，投资自己的大脑一百万以上的学费，向世界上最顶级的营销大师学习增加客户吸粉引流的方法。
