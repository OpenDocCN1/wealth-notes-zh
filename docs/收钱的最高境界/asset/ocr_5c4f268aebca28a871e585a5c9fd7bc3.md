比如市场上培训课程分为三类：激励式课程，手段类课程和布局类课程。

# 第一、激励式课程：

在情绪受挫的情况下，通过各种激励，让你的大脑重回巅峰状态，但是这种激励效果并不持久，可能一个拒绝，你的情绪低落了，所以永远是激励，因为他没有成功的方法和策略。

# 第二、手段类课程：

这种相对好一点点，这些一般都是比较毒辣的狠招数，你用了马上可以见效，但是也有一个弊端，就是很容易被对手模仿去嘛，到时候你又陷入价格战了。
