# 第七掌：欲盖弥彰法

什么是欲盖弥彰，意思就是你想把一件事情掩盖住，但是又没有盖住，反而更明显的暴露出来了。

就像古代的风尘女子，想要勾引客人，就半遮半掩的，让你看到点什么，却又看不到点什么，挑逗你的欲望。

![](bbox=[0.14, 0.4, 0.85, 0.54])

那么这点用在勾魂上，也是非常杀伤力的。
