# 什么是招代理？

同样是卖水果的案例。

后来有一个客户，看见你在半年开了十家店，很赚钱，于是红，就问你，你能不能把你水果店成功的方法教给我，我交十万块钱给你，我用你的招牌，我从你那边进货。

你看见有这么好的事，于是你就收了他 10 万元，统一给他配货，统一招牌和培训等，这叫——加盟商。

于是这个客户从一个消费者，就升级为——经营者。
