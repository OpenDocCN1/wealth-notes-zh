# 第 8 课：卖产品

# 1、暴利产品

什么是暴利产品？假如你卖一个产品的成本是 100 元，卖价格 400 元，这不叫暴利产品，项多叫高利润产品。如果你能卖到 1000 元，那就是暴利。

根据一诺老师 20 多年前的研究，凡成大业者，标准答案——卖的都是暴利产品。

脑白金为什么能席卷全国？——**保健品暴利**！

许家印为什么身价 365 亿美元？——**房地产暴利**

比尔盖茨为什么蝉联几十年首富？——**软件暴利**！

亚马逊为什么成为全球最大电商？——**平台模式暴利**！

腾讯为什么成为最赚钱的互联网公司？——**游戏暴利**！

一诺老师为什么从负债逆袭亿万身家？——**教育培训暴利**
