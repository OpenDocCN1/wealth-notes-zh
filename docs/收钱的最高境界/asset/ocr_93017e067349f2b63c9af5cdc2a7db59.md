# 第79课：能量格局

# 错误成交2·顾客就是上帝

你有没有学过市场一些老师的销售的课程，或者书籍。

他都会告诉你顾客就是上帝，客户永远是对的，有没有？

在一诺老师看到，简直是一派胡言，误人子弟。

当你常常认定了客户永远对的时候，你就不断的掉进这个格局（客户有主控权，你没有主控权）。

# 一诺老师【弟子密训】能量格局图

| 男/你 <br> 女/客户 | 要 | 不要 |
| :---: | :---: | :---: |
| **要** | 成交 ✔ | 你有主控权 <br> 对方没主控权 ✔ |
| **不要** | 你没主控权 <br> 对方有主控权 X | 分开 X |

你就会想尽一切办法让你的客户开心，想尽一切办法去满足他所有的需求。

在这里，一诺老师并不是说满足客人的需求不好，只是要看你在什么时候满足，后面一诺老师会讲。
