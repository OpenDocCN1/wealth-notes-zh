# 第 21 课：找项目

# 玄机二、有没有零售系统？

当你以后要参加招商会，或者你想代理一个项目。

演讲人会给你讲，他们的产品有多好，公司有多好，未来要上市，未来趋势会怎样，加入的人赚了多少钱……

在一诺老师看来，这些都不是重点，一诺老师只会看一点，他有没有一套证明有效的零售模式。

也就是说，我加入之后，公司有没有一套教给业务员卖产品收钱的方法？有没有一套成交系统？

如果没有，掉头就走！

因为，如果你加入之后，你不会卖产品，或者你的员工不会卖产品，没有业绩，一切等于 0。
