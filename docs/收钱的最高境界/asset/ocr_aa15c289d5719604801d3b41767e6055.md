# 第 56 课：勾魂十八掌

# 第五掌：出其不意法。案例 1

有一次在，一诺老师的课程上，课程主题是——催眠。

当一诺老师讲到一半的时，台下有一个弟子站了起来，他不相信催眠，觉得一诺老师不能催眠他，他要挑战一下。

当时一诺老师并没有否决他，一诺老师就让这个弟子到台上来，让弟子介绍了一下自己。

弟子介绍完之后，这时候一诺老师就做出了握手的姿势，这个弟子也自然而然的伸出手，可是就快碰到手的时候，一诺老师突然弯下腰把鞋带系了一下，这个弟子当时一下就傻了，瞬间达到能量低点，站在那里。
