# 传统销售员是怎么死的？

客户有自动化反应，同样的，作为销售人员也有自动化反应，什么意思？

我们人类的成长，是一部进化史，正常情况下一个人在做一件事情的时候，当他发现用同样的方法，做一件事情得不到好的结果，于是他就会改变方法。

![](bbox=[0.15, 0.45, 0.88, 0.59])

比如，当时人类在石器时代，狩猎用的是石头做成的武器；后来发现石头不够坚硬，于是就发现了青铜器，走进了青铜器时代；后来发现青铜器还是不够坚硬，于是又找到了一个更好的解决方法，发现了铁元素，走进了铁器时代。

按照这个逻辑，只要是正常人，做一件事情得不到好的结果，他就会寻找另一种方法。
