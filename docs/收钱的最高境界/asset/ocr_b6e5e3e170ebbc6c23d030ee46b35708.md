# 恶性循环说服术

什么是恶性循环说服术？

比如为什么老公不爱她？因为她不注重保养自己。

当她不注重保养自己，老公看她没有以前漂亮，就会对她失去热情，她的心情就会变的不好，当心情变的不好，于是内分泌就会失调，当内分泌失调，于是就会长痘痘长斑，变的越来越丑。

于是老公就更加不爱她。她的两性关系就进入会恶性循环。

你想要说服客户，你要学会引导她，再不改变的后果。
