# 2、精准客户

当你有了暴利产品之后，很多人的第二大问题，没有客流。没有客户你就不可能会有成交。

在一诺老师的课程上，经常有人问：“请问一诺老师，我该如何设计公司的股权框架？我该如何设计一套商业模式？我该如何融资如何资本上市？我该如何带领团队？……”

![](bbox=[0.16, 0.46, 0.86, 0.59])

听完这样的问题，一诺老师首先会问他，你公司的客流量有多少？你公司的业绩做的怎样？

如果你现在公司连客户都没有，请问你的产品卖给谁？

请问，连客户都没有，就算你有再好的产品，谁来为你的产品买单。
