# **第十四掌：状态利益法**

人在实现梦想或者解决问题之前，都是处于一种状态的。

假如：我是一个创业者，可能我现在的状态就是，苦逼，没钱，吃泡面，坐公交……

假如：我是一个微商，可能我的状态就是每天累死累活的朋友圈刷广告，却没有订单……

假如：我是一个销售人员，却不知道怎么沟通成交客户，上了大量课程，依然没用……等等，太多了！

![](bbox=[0.15, 0.54, 0.88, 0.67])

那么你想一下，如果一个人能够很清晰的描述你此刻的状态，你要不要关注一下？

其实和算命先生一样，为什么觉得很神秘，就是他说对了你的事情，这时候再给他一些解决方法，给他描绘一个好的未来
