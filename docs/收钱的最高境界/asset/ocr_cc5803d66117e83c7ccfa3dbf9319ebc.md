# 第 18 课：卖商机

# 什么是卖商机？

一诺老师一语道破玄机，——就是卖发财机会。

也就是说——我有一套证明能够赚钱的方法，现在我忙不过来了，这个市场蛋糕很大，我把这套方法成功的模式分享出去，让更多人来一起分这个大蛋糕，懂了吗？

![](bbox=[0.15, 0.41, 0.89, 0.54])

所以，你就知道，为什么很多小老板他永远做不大？

不是因为他不懂这个商业玄机，他应该也听过加盟代理这个词，为什么他知道加盟代理，他还是不愿意把发财机会分享给更多人。

因为他突破不了自己！

他怕别人学会了他的模式自立门户成为他的竞争对手！

他怕公开了他的发财模式，就有很多人复制抢走他的生意！
