# 敦煌的胡汉互动历史

开始之前，还是先简单地说一下敦煌的由来。敦煌是著名的河西四郡当中的一个，河西四郡是汉武帝时期设置的，从东到西分别是武威、张掖、酒泉和敦煌，都分布在今天的甘肃省。

咱们的教材上经常说汉武帝打通河西走廊是为了通西域。实际上，通西域是个计划外的结果。汉武帝打通河西走廊的首要目的是“隔绝羌胡”，就是把在青藏高原上游牧的羌人和北方草原上游牧的匈奴人给隔绝开。
