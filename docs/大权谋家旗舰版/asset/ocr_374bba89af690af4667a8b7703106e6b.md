# 为什么领导都希望自己指定接班人？《岁月》深究之六

在《岁月》的电视剧里面，闻局长指定了梁志远继任局长，联系到以前有很多朋友问起，在体制内，为什么很多领导都希望由自己来指定接班人，自己在这样的权力变动里面又会有什么机会吗？

首先我们来说明一下，为什么领导都希望指定接班人：

# 一、路线的延续

只要领导既定路线能继续执行下去，那自己的政治生命就还在延续。很多领导把这个路线当做性命来抓，为了路线斗争，你死我活，当然路线斗争的背后其实是权力的博弈。

# 二、既得利益的保障
