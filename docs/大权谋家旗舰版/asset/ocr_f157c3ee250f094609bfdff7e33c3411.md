# 认知的虚幻、人性的现实之间的脱节，才是我们最大的问题

碰到很多朋友，在长久的生活和学习中，形成了一套对社会的认知。这套认知是虚拟的，而只有当这套虚拟的社会认知和人性的现实能完美贴合的时候，你才会发挥最大的能力。

不过在现实中，绝大多数人的思维模式和现实都是脱节的。因为现实是残酷的，人们往往喜欢回避现实，希望自己能过得舒服一点，尤其是内心要过得舒坦。所以，心灵按摩和心灵成长之类的书籍就大受欢迎，这样的心灵鸡汤把人们带入了小确幸的世界。

大众不需要真相，大众需要的是心理安慰，是娱乐！所以抖音这样的奶头乐的典型 APP 就大行其道。
